
## 1. 一句话概括

模型先将静态画像压成 8 个 NS Token；四路历史行为先编码为带相对时间的序列 Token，再由候选物品对每一路做前置注意力池化。候选感知摘要与静态画像共同生成 8 个 Query，经过两层「域内序列建模 → Query 读序列 → RankMixer 跨域融合」后输出 PCVR logit。

```text
静态特征 → 8 NS Tokens ───────────────┐
                                      ├→ 每域 Query Generator → 8 Queries
四路多字段历史 → Sequence Tokens → 前置 Target-Aware Pooling ┘
                                                     ↓
                    两层 HyFormer：读序列 → 跨域/动静态融合 → 再读序列
                                                     ↓
                                  8 个最终 Query → MLP → PCVR logit
```

## 2. 输入与静态 Token

每个 Token 维度为 `D=64`。当前运行配置产生 8 个静态 Token：

| 来源 | Token 数 | 作用 |
|---|---:|---|
| 用户离散特征 | 3 | 长期画像、偏好与高基数离散信号 |
| 用户稠密 UE 特征 | 2 | 单独投影，避免被大杂烩稠密特征淹没 |
| 候选物品离散特征 | 2 | 当前候选物品的属性表示 |
| 请求时间 | 1 | 小时/星期的 sin-cos 周期编码 |

对同 fid、且 ID 数组与统计值数组严格逐位置对齐的特征，先做：

$$
h_j = E(id_j) + W x_j
$$

再对有效位置池化。这样保留“哪个 ID 对应哪个统计值”；不要把不具备位置对应关系的字段强行套用该融合。

## 3. 四路行为序列编码

第 `m` 路原始序列张量为 `[B, S_m, L_m]`：`S_m` 是一条行为携带的离散字段数，`L_m` 是截断后的历史长度。对同一行为位置 `j`：

$$
c_{m,j}=\operatorname{GELU}(W_m[E_1(x_{1,j})\Vert\cdots\Vert E_{S_m}(x_{S_m,j})]+b_m)
$$

其中拼接只发生在**同一行为位置的字段维**，不会把整条序列展平。再加入请求到该行为的时间差桶：

$$
z_{m,j}=c_{m,j}+E_{time}(\operatorname{bucket}(t_{request}-t_{m,j}))
$$

最终每域得到 `[B,L_m,64]`。padding 的 ID 与时间桶均为 0，随后由长度 mask 排除。

## 4. 516 的关键：前置 Bilinear Target-Aware Pooling

两个 Item NS Token 的均值构成候选物品向量：

$$
q_{item}=\operatorname{mean}(N_{item})
$$

对第 `m` 域序列的有效位置计算：

$$
s_{m,j}=\frac{(W_m z_{m,j})^\top q_{item}}{\sqrt{64}},\quad
\alpha_{m}=\operatorname{softmax}(s_m),\quad
h_m^{target}=\sum_j\alpha_{m,j}z_{m,j}
$$

它是 DIN-inspired 的候选感知池化，但不是 DIN 原论文的完整 Local Activation Unit。准确称呼是 **Bilinear Target-Aware Pooling**。

每个域将 `flatten(NS)` 与本域 `h_m^{target}` 拼接，经 LayerNorm 与两套独立 FFN，生成 2 个 Query；共 4 域 × 2 = 8 个 Query。这一步的本质是：**候选物品先为每个域筛出相关兴趣，再决定后续如何读完整序列。**

## 5. 两层 HyFormer

每层的流程一致，但第二层拥有更充分的全局上下文：

1. **Sequence Evolution**：四个域独立 Transformer 编码序列，使用 RoPE 表示位置顺序；实现细节见 [[Sequence Evolution：四域独立Transformer与RoPE]]。
2. **Query Decoding**：每域的 2 个 Query 对本域完整序列做 Cross-Attention，读取候选相关证据。
3. **Query Boosting**：8 个 Decoded Query 与 8 个 NS Token 拼成 16 个全局 Token，送入 RankMixer；输出再拆回更新后的 Query 与 NS Token。

Block 1 得到的是“各域读取结果 + 跨域/静态上下文”；Block 2 使用这个更新后的 Query 再读一次本域序列，因此不是机械加深，而是一次条件更充分的二次检索。

## 6. 输出与训练

最终 8 个 Query 展平为 `8×64=512` 维：

```text
512 → Linear(512,64) + LayerNorm
    → Linear(64,64) + LayerNorm + SiLU + Dropout
    → Linear(64,1) → PCVR logit
```

- 目标：单任务 `BCEWithLogitsLoss`。
- 稀疏 Embedding：`Adagrad(lr=0.05, weight_decay=0)`。
- 其余稠密参数：`AdamW(lr=1e-4, betas=(0.9,0.98))`。
- 常数学习率；全局梯度裁剪 `1.0`。
