# 训练策略：为什么 Embedding 用 Adagrad、主干用 AdamW

## 结论

模型的参数不是一类数据：Embedding 是高基数、长尾、按行命中的稀疏参数；HyFormer、RankMixer、MLP 是每步都参与更新的稠密参数。因此采用分治优化。

| 参数组 | 优化器 | 配置 | 原因 |
|---|---|---|---|
| 全部 `nn.Embedding` | Adagrad | `lr=0.05, wd=0` | 每个 ID 自动拥有频率相关的有效步长，适合长尾 |
| 其他参数 | AdamW | `lr=1e-4, betas=(0.9,0.98)` | 适合 Attention/MLP 的连续、非平稳梯度；解耦 weight decay |

## Adagrad 为什么适合稀疏 ID

$$
\theta_{t+1}=\theta_t-\frac{\eta}{\sqrt{G_t}+\epsilon}g_t,
\quad G_t=\sum_{\tau\le t}g_\tau^2
$$

高频 ID 被反复访问，累计梯度大，有效学习率会下降；低频 ID 累计梯度小，仍能获得相对较大的更新。推荐特征频率高度不均，这个自适应特性比所有 ID 共用同一更新节奏更合适。

## AdamW 为什么适合稠密主干

稠密参数每个 batch 都参与梯度计算，主要风险是多层 Attention、残差和 FFN 的尺度不稳。AdamW 使用一阶/二阶动量稳定方向与尺度，并将 weight decay 从自适应更新中解耦。`1e-4` 是对两层 HyFormer 的保守步长；`beta2=0.98` 让二阶统计对近期梯度更敏感。

## 其他稳定性措施

- 常数学习率：避免在小规模、短训练试验中调度器额外引入混杂变量。
- 全局梯度裁剪 `1.0`：防止长序列或注意力极尖时出现梯度尖峰。
- Dropout：主干使用轻量 Dropout，而非靠大 Dropout 抵消结构噪声。

## 面试答法

> 我们没有把所有参数交给同一个优化器。稀疏 ID 的核心问题是频次不均与长尾更新，所以用 Adagrad 让每行 Embedding 自适应调整步长；HyFormer 和 MLP 是连续稠密优化问题，用 AdamW 获得更稳的动量更新和正则化。这个分治比“默认 Adam 一把梭”更贴合推荐模型的参数结构。
