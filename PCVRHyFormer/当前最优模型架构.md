# 0. 架构总览

当前最优模型采用多域序列建模的 **PCVRHyFormer** 架构，整体由静态特征 Token 化、多路行为序列编码、Query 生成、双层 HyFormer 交互以及候选物品感知预测头组成。

# 1. 静态特征 Token 化

模型首先分别处理用户离散特征、用户稠密特征、物品离散特征以及请求时间特征：

- 用户离散特征经过 Embedding、拼接和分块投影，生成 3 个 User NS Tokens；
- 用户稠密特征生成 2 个独立 UE Tokens；
- 物品离散特征生成 2 个 Item NS Tokens；
- 当前请求时间经过小时和星期周期编码，生成 1 个 Request-Time Token。

最终得到：

$$

3+2+2+1=8

$$

个静态 **NS Tokens**。每个 Token 的维度为 64，用于表示用户画像、候选物品属性及当前请求场景。

对于离散数组与稠密统计一一对应的特征，模型会先在元素级完成语义对齐：

$$

h_j=E(id_j)+W\cdot stat_j

$$

再对有效位置池化，避免丢失“某个类别 ID 对应哪一个统计值”的配对关系。

# 2. 四路行为序列编码

模型包含 4 路历史行为序列。每个序列域独立完成以下处理：

1. 对行为位置上的多个离散字段分别做 Embedding；
2. 将同一行为位置上的字段 Embedding 拼接并投影到 64 维；
3. 计算每条行为距离当前请求时刻的时间差；
4. 将时间差离散为 Time Bucket，并将时间 Embedding 加到行为 Token 上。

因此，第 \(s\) 个行为域被表示为：

$$

H_s\in\mathbb{R}^{B\times L_s\times64}

$$

这种表示同时包含行为内容和行为新近度。

# 3. MultiSeqQueryGenerator

Query Generator 的作用是把变长行为序列压缩成固定数量的兴趣 Query。

首先，将 8 个静态 NS Tokens 展平：

$$

N_{\text{flat}}\in\mathbb{R}^{B\times(8\times64)}

$$

然后分别为四个行为域提取多种全局表示：

- Masked Mean Pool：描述该域的整体行为兴趣；
- Time-Decay Pool：提高近期行为的权重；
- Cross-Domain Pool：融合四个行为域的整体活跃模式。

对于第 \(s\) 个行为域，将这些信息与静态画像拼接：

$$

G_s= [N_{\text{flat}}; \operatorname{MeanPool}(H_s); \operatorname{DecayPool}(H_s); H_{\text{cross-domain}}]

$$

随后输入两套相互独立的 FFN，生成两个 Query Tokens：

$$

Q_s^{(1)},Q_s^{(2)} = \operatorname{FFN}_s(G_s)

$$

4 个序列域各产生 2 个 Query，因此一共得到：

$$

4\times2=8

$$

个初始 Query Tokens。它们可以理解为每个行为域中的两个潜在兴趣槽位。

# 4. 第一个 HyFormer Block

每个 HyFormer Block 内部包含三个核心阶段。

# 4.1 Sequence Evolution

四路行为序列首先分别经过独立的 Transformer Encoder：

$$

H_s^{(1)} = \operatorname{Transformer}_s(H_s)

$$

该过程通过域内 Self-Attention 建模同一行为域内部不同行为之间的依赖关系。四个域使用独立参数，避免不同类型行为被过早混合。

# 4.2 Query Decoding

随后，初始 Query 作为 Query，更新后的行为序列作为 Key 和 Value，执行 Cross-Attention：

$$

\widetilde Q_s^{(1)} = Q_s^{(0)} + \operatorname{CrossAttn} \left( Q_s^{(0)},H_s^{(1)},H_s^{(1)} \right)

$$

Cross-Attention 会根据当前 Query，从长序列中选择与该兴趣槽位最相关的行为记录，生成更具针对性的 **Decoded Query Tokens**。

# 4.3 RankMixer 融合

将四个域产生的 8 个 Decoded Query Tokens 与 8 个静态 NS Tokens 拼接：

$$

X^{(1)} = [ \widetilde Q_1^{(1)}; \widetilde Q_2^{(1)}; \widetilde Q_3^{(1)}; \widetilde Q_4^{(1)}; N^{(0)} ] \in\mathbb{R}^{B\times16\times64}

$$

然后送入 RankMixer。

RankMixer 首先通过 reshape 和 transpose 对 Token 维度与特征子空间进行无参数重排，使不同 Token 的部分通道发生交叉；随后使用共享 FFN 完成非线性融合：

$$

\widehat X^{(1)} = \operatorname{TokenMix}(X^{(1)})

$$

$$

X_{\text{out}}^{(1)} = \operatorname{LayerNorm} \left( X^{(1)}+ \operatorname{FFN}(\widehat X^{(1)}) \right)

$$

这一步同时完成两类交互：

- 横向交互：不同 Query、不同序列域以及静态 NS Tokens 之间的信息交换；
- 纵向交互：每个 Token 内部不同特征通道之间的非线性组合。

RankMixer 输出随后重新拆分为：

- 4 路更新后的 Query Tokens；
- 更新后的 NS Tokens。

# 5. 第二个 HyFormer Block

第二个 HyFormer Block 不是简单重复计算，而是在第一层已经完成跨域和动静态融合的基础上进行二次推理。

其输入包括：

- 第一层 Transformer 更新后的四路行为序列；
- 第一层 RankMixer 输出的 Query Tokens；
- 第一层 RankMixer 更新后的 NS Tokens。

第二层依次执行：

1. 四路序列再次经过独立 Transformer，进一步建模高阶行为依赖；
2. 已经携带其他行为域和静态画像信息的 Query，再次对本域序列执行 Cross-Attention；
3. Query 根据跨域上下文重新读取原始行为证据；
4. 新一轮 Decoded Query 与更新后的 NS Tokens 再次进入 RankMixer；
5. 完成第二轮跨域、动静态和通道级信息融合。

因此，两层 HyFormer 形成了如下迭代过程：

```text
第一次读取行为序列
→ Query 与静态画像、其他域交换信息
→ 携带跨域上下文重新读取行为序列
→ 再次完成全局融合

```

第一层主要完成基础兴趣提取，第二层则利用已经融合的上下文对兴趣进行校正和细化。

# 6. Candidate-Aware DIN 增强分支

在两层 HyFormer 处理完成后，模型额外使用候选物品对应的 Item NS Tokens，对四路最终行为序列的拼接结果执行 DIN-style Cross-Attention：

$$

H_{\text{DIN}} = \operatorname{CrossAttn} \left( Q=N_{\text{item}}, K=H_{\text{all}}, V=H_{\text{all}} \right)

$$

它直接回答：

> 用户的哪些历史行为与当前候选物品最相关？

DIN 输出经过平均池化和零初始化线性层后，以残差方式加入主干表示：

$$

h_{\text{final}} = h_{\text{HyFormer}} + W_{\text{DIN}}\operatorname{MeanPool}(H_{\text{DIN}})

$$

其中 \(W_{\text{DIN}}\) 使用零初始化，使模型训练初期完全等价于原始主干，随后再逐渐学习候选物品与历史行为之间的相关性。

# 7. 输出层

第二个 HyFormer Block 最终输出四个行为域的 Query Tokens，共 8 个：

$$

Q_{\text{final}} \in\mathbb{R}^{B\times8\times64}

$$

将其拼接并展平：

$$

Q_{\text{flat}}\in\mathbb{R}^{B\times512}

$$

再经过：

```text
8 × 64 = 512
→ Linear(512, 64)
→ LayerNorm
→ 加入 DIN Residual
→ Linear(64, 64)
→ LayerNorm
→ SiLU
→ Dropout
→ Linear(64, 1)

```

最终输出单个 PCVR logit：

$$

z\in\mathbb{R}^{B\times1}

$$

推理时经过 Sigmoid 得到转化概率：

$$

\hat p=\sigma(z)

$$

整体上，该模型通过“静态画像 Token 化—多域行为建模—Query 压缩—两轮行为读取与跨域融合—候选物品感知匹配”的方式，同时建模用户长期画像、短期行为兴趣、行为新近度以及候选物品与历史行为之间的语义相关性。
