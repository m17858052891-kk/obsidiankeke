# 面试问答（精简）

## 1. 前置 bilinear pooling 是完整 DIN 吗？

不是。它借鉴 DIN 的 target-aware interest activation 思想：候选物品作为 Query，对历史做注意力池化；但实现是 `score=(W·history)^T·target/√D`，不是原始 DIN 的 Local Activation Unit。准确名称是 **DIN-inspired Bilinear Target-Aware Pooling**。

## 2. 为什么在 Query Generator 前做候选感知？

PCVR 的候选物品在请求时已经已知，因此应尽早参与兴趣提取。前置池化让 Query 在出生时就知道“当前要预测哪个物品”；后续 HyFormer 的两轮读序列会围绕该方向检索。完整序列仍保留，所以不是过早丢信息。

## 3. 为什么还需要 HyFormer，直接 DIN 不够吗？

DIN 擅长一次候选感知池化；HyFormer 还要建模域内时序、多个兴趣槽、四域交互与静态上下文。这里的组合是：DIN 提供候选感知的 Query 初始化，HyFormer 提供完整序列上的两轮条件检索。

## 4. 第二个 HyFormer Block 做了什么？

第一层 Query 只从本域读到局部证据；经 RankMixer 后，它带上其他域、静态画像和候选信息。第二层用这个更全局的 Query 再读本域序列，等价于用更充分条件重新判断哪些历史证据重要。

## 5. 为什么四路序列不直接拼一起？

不同域的行为语义、长度和噪声水平不同。先用独立编码器保留域内归纳偏置，再在固定数量的 Query/NS Token 上做跨域交互，更稳定、也更易控制计算量。

## 6. 时间桶和位置编码分别解决什么？

时间桶表达“距当前请求多久”，RoPE 表达“在本域序列中的相对位置”。同样排在第 3 位的行为，可能是几分钟前，也可能是几周前；两者互补。

## 7. 为什么 ID 与统计值用加法，不用乘法？

加法保留 ID Embedding 主路径，统计值作为可学习增量；乘法会让统计值尺度直接压制内容与梯度。前提是两个数组逐位置语义对齐，否则不应融合。

## 8. 为什么 RankMixer 而不是全局 Self-Attention？

序列内部和 Query→序列的交互需要 Attention；但全局侧只有 16 个固定 Token，更适合用 RankMixer 的 token/channel 混合控制成本和容量。代价是它的交互模式不如 Self-Attention 自由，因此只用于固定全局 Token。

## 9. 为什么 Embedding 用 Adagrad、稠密部分用 AdamW？

Embedding 是按行稀疏命中、频次极不均的长尾优化问题；Adagrad 适合自适应每行有效步长。Attention/MLP 每步都更新，使用 AdamW 的动量与解耦正则更稳定。

## 10. 你如何保证没有时间泄露？

要求所有历史时间不晚于请求时间；离线/线上统一时区、单位、时间桶和序列方向；采用严格未来时间验证，并按 seen/OOV、冷用户/冷物品分桶看 AUC 与校准。

## 11. 项目里最重要的反常识结论？

更长历史和更显式的硬匹配都不必然提升转化预估。应优先提高信息对齐与注入时机，让模型学习候选相关的软匹配，而不是添加看似直观的强规则。

## 12. 最大局限是什么？

历史最佳配置和全部训练日志没有完整不可变快照，因此不能把总增益精确分配给每一模块。后续必须固定数据切分、训练预算和代码 hash，补齐前置/后置池化的公平消融。
