## 如何读表中的证据

工具版本与接口以 2026-11-07 的评估为准。S 为有实际技能文件的 Agent Skill，M 为 MCP、API 或连接器，A 为独立 LLM 应用，D 为传统计算工具，R 为研究候选。多个字母表示同一项目的不同组件。

V0 为发现线索，V1 为读过官方文档，V2 为检查过关键源码或技能文件，V3 为运行过限定范围的最小示例，V4 为在目标业务上完成对照验证。重点工具大多到 V2。GitHub 公开读取和假设校验器的单个函数有局部实测。各工具页的调用示例供试用，目标模型或线上收益均待业务实验判断。
