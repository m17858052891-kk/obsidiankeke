# 收益链路与证据矩阵

本页回答“收益通过哪一步传递”。**E**＝论文实验直接支持；**T**＝在列明假设下的理论；**A**＝作者解释；**I**＝本知识库的迁移推断；**?**＝缺少识别证据。理论正确、离线提高、工业A/B有效是三种不同证据，不能互相替代。链接中的逐篇解释、原文版本和表号是本表的依据。返回[[00_总索引与阅读路线]]。

## 七种收益来源如何识别

| 来源 | 需要观察的中间量 | 最有区分力的负对照 |
|---|---|---|
| 信息增量 | 在既有特征/候选条件下，新增信息能解释持出残差；新方向/比较覆盖 | 等数量重复、时间合法的桶内置换、同候选随机语义 |
| 监督改善 | 成熟金标错误率、有效标签覆盖、目标与代理一致性 | 同保留率随机过滤、同难度采样、独立judge/成熟结果 |
| 优化改善 | 同步数/数据下真实更新方向、分块一步损失、达标时间 | 等有效步长、等调参预算、保留前向只切反向 |
| 表征改善 | 特定信息可读取且参与最终预测，而不只是探针分数 | 同容量随机分组、冻结编码器、保持信息量但改交互 |
| 决策对齐 | 动作变化落在高损失边界、regret/约束代价降低 | 同预测误差不同决策敏感性；强PTO+校准/选checkpoint |
| 泛化改善 | 机制明确的时间/策略/群体漂移中稳定，ID损失可接受 | 源域普通正则、固定预测只重配群体、独立留出切片 |
| 成本赋能 | 节约资源实际转为更长历史/更多候选/更快刷新/更大可用容量 | 同历史同刷新比质量；再固定服务预算比最优配置 |

一篇论文可走多条链，不据消融差值强行分配“多少百分比来自语义/优化”。模块交互、非线性指标和共享预算使贡献通常不可加。论文的整体A/B证明整套改动在该场景有效；要定位你的瓶颈，还需要中间指标与负对照。
