# 整理约定

[[00-首页|返回首页]]

## 页面职责

- 首页负责选择任务；导航页负责跨专题查找；每个项目入口负责指出当前主线。
- 论文笔记记录原文结构、版本与证据；方法笔记解释可复用知识；项目笔记记录实际实现与差异。
- 实验记录保留数据、配置、结果与当时结论；当前结论页维护综合判断并链接证据。
- 讲稿服务表达，更新时核对来源。已有历史拆分版保留原目录，页首指出当前入口。

## 属性

| 属性 | 约定 |
|---|---|
| type | 索引 / 知识 / 论文 / 方法 / 项目 / 实验 / 讲稿 |
| topics | 列表，例如序列建模、因果推断、自动出价、面试 |
| status | 草稿 / 维护中 / 已归档，指笔记状态，不等于业务上线状态 |
| aliases | 列表，只填确实会搜索的简称或旧名；没有就留空 |

保留原有 tags、作者、来源、论文版本和创建日期。新笔记沿用已有同类笔记的结构，按需补充属性。整理日期不替代实验发生日期。

## 链接与附件

- 跨目录链接使用从库根目录开始的完整路径；导航中的 README 链接加上项目显示名。
- 已有笔记用链接，待补内容用明确的“待补”文字。
- 新附件统一保存到当前目录的 assets 子目录；论文图片优先使用“论文简称-fig-编号”或“论文简称-table-编号”。
- 旧图片只有在能确认所属论文时才增加语义名称；来源待确认的历史粘贴图保留原名。
- 移动或重命名文件时同步更新引用，并检查图片显示。附件归档不表示可以删除未引用原图。


## 更新时的最小动作

1. 先更新事实所属页面。
2. 若结论变化，更新项目入口或当前结论，并链接新证据。
3. 若旧页已被替代，标明历史范围和当前入口。
4. 将新笔记加入一个相关索引，再检查链接。

## 统一知识区域

可复用原理写入 `知识体系` 的七个领域，按正文与专题组织。`复习` 是回忆提示，不另立事实版本。项目、论文与实验各保留证据来源，并从理论页建立具体联系。章节不要求固定模板字段；写清定义、机制、条件、例子与失效边界即可。
