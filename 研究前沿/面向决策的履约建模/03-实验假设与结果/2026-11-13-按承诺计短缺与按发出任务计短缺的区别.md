# 同一调度回放里，按承诺量训练是否减少履约短缺

来源为 [[研究前沿/面向决策的履约建模/02-可复用方法卡/GridDelivery-delivery-shortfall|按实际交付和承诺计算短缺]]，证据边界见 [[研究前沿/面向决策的履约建模/01-论文原文与精读/GridDelivery/精读|原论文精读]]。

## 可证伪假设

同一调度回放里，按承诺量训练是否减少履约短缺？只更换短缺标签。冻结资源预测与求解器，比较相同需求下的外部承诺缺口。

| 设计项 | 约定 |
| --- | --- |
| 必要数据 | 逐时承诺、发出指令、接受和最终交付时间、容量与真实需求。 |
| 基线和对照 | 按发出任务减交付计罚、按承诺减交付计罚。 |
| 主指标 | 相同实际承诺下累计欠交与 P95 欠交，辅报总成本。 |
| 实施约束 | 固定容量及最低承诺，避免靠降低承诺获益。 |
| 预算 | 离线回放；数据量、计算时长与可接受差值待设计时登记。 |
| 失败判据 | 若相同承诺和容量下欠交不降，或成本增过预先登记容忍度，则不支持。 |
