# 已知接口变化能否只校正动作映射而保住原状态模型

来源为 [[研究前沿/面向决策的履约建模/02-可复用方法卡/ActionMapLibrary-read-store|从动作效应读数识别并记忆执行映射]]，证据边界见 [[研究前沿/面向决策的履约建模/01-论文原文与精读/ActionMapLibrary/精读|原论文精读]]。

## 可证伪假设

已知接口变化能否只校正动作映射而保住原状态模型？在已有动作实测日志中人为置换指令编码或延迟，留出真实执行动作用于评分。

| 设计项 | 约定 |
| --- | --- |
| 必要数据 | 指令、真实执行动作及时间、前后状态、正常接口参考期。 |
| 基线和对照 | 恒等映射、只记最近映射、保留多个已知映射。 |
| 主指标 | 执行动作识别准确率、滚动状态误差和变化未发生时的误配率。 |
| 实施约束 | 固定模型和划分；注入错位仅离线，另做纯环境漂移对照。 |
| 预算 | 离线回放；数据量、计算时长与可接受差值待设计时登记。 |
| 失败判据 | 若正常接口误配明显，或不能区分动作错位与环境漂移，则拒绝进一步使用。 |
