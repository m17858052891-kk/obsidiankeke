# 低成本比较器能否取得大部分删失排序收益

来源为 [[研究前沿/面向决策的履约建模/02-可复用方法卡/LLMSurvival-comparable-anchors|只把可定先后的人配对，再以训练锚点汇总风险]]，证据边界见 [[研究前沿/面向决策的履约建模/01-论文原文与精读/LLMSurvival/精读|原论文精读]]。

## 可证伪假设

低成本比较器能否取得大部分删失排序收益？保持可比对、抽样与锚点同样，换线性比较器和现有轻量非线性模型；单独比较采样前后。

| 设计项 | 约定 |
| --- | --- |
| 必要数据 | 单一明确定义的服务事件、跟踪截止标记、决策时可见特征；先固定时间切分。 |
| 基线和对照 | Cox、同配对逻辑回归、同配对轻量非线性比较器。 |
| 主指标 | 留出可比对 C-index 与按天配对区间，报告每单推理耗时和锚点敏感性。 |
| 实施约束 | 训练锚点不得进入测试队列，分开报告不同删失率。 |
| 预算 | 离线回放；数据量、计算时长与可接受差值待设计时登记。 |
| 失败判据 | 若超过线性基线的差值区间含零或锚点变更导致排序不稳定，则不支持增加复杂度。 |
