# 预测裁剪是否抹掉可分配时段之间有价值的差异

来源为 [[研究前沿/面向决策的履约建模/02-可复用方法卡/ForecastProjection-clipping-regret|用同一预测分离裁剪与水平偏移的决策代价]]，证据边界见 [[研究前沿/面向决策的履约建模/01-论文原文与精读/ForecastProjection/精读|原论文精读]]。

## 可证伪假设

预测裁剪是否抹掉可分配时段之间有价值的差异？冻结预测、固定容量，重放原始、截断及只锚定水平后三种代价输入。

| 设计项 | 约定 |
| --- | --- |
| 必要数据 | 带原始预测和上下界的历史时段、真实需求/成本、可行约束、预决策可用的水平基线。 |
| 基线和对照 | 原始输出、现用截断、锚定后截断。 |
| 主指标 | 逐日配对决策遗憾，分越界比例，同时报告预测误差。 |
| 实施约束 | 相同解码器、并列解规则与终端约束；有反事实缺失时只使用可核实回放实例。 |
| 预算 | 离线回放；数据量、计算时长与可接受差值待设计时登记。 |
| 失败判据 | 若裁剪比例与额外遗憾无稳定关系，或锚定仅改善预测误差，放弃迁移解释。 |
