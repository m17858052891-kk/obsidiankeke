# 能否区分样本覆盖不足与随访途中丢失

来源为 [[研究前沿/面向决策的履约建模/02-可复用方法卡/SurvivalTRACE-bias-channel|分开诊断试验入组稀少与随访期间流失]]，证据边界见 [[研究前沿/面向决策的履约建模/01-论文原文与精读/SurvivalTRACE/精读|原论文精读]]。

## 可证伪假设

能否区分样本覆盖不足与随访途中丢失？在可完整追踪的实验日志分别注入基线子群抽稀、特定时段标签丢失及两者叠加。

| 设计项 | 约定 |
| --- | --- |
| 必要数据 | 原试验和目标样本共同特征、处理臂、观测结束与首终态时间。 |
| 基线和对照 | 仅入组阈值、仅留访阈值、联合诊断。 |
| 主指标 | 基线与删失子群精确率/召回、时间窗命中率及保留比例。 |
| 实施约束 | 用独立批次确认树规则，不把改写人群后的区间缩窄算作原效应改进。 |
| 预算 | 离线回放；数据量、计算时长与可接受差值待设计时登记。 |
| 失败判据 | 若只靠单一阈值即可恢复，或联合方法把纯基线抽稀反复归为失访，则不支持。 |
