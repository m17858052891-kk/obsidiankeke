# 目标进展与联合时序先验重排动作前缀

来源：[[研究前沿/面向决策的履约建模/01-论文原文与精读/LatentForesight/精读|LatentForesight 精读]] · [原文](https://arxiv.org/html/2611.04839v1)

## 输入与输出

输入候选动作序列、状态、目标和动作条件预测器；输出当前执行的短前缀。

## 计算、训练与推理流程

采样 N 序列 → 预测 h 步端点 → 计算目标距离减少 → 联合 GRU 给动作组协同能量 → V−beta E 排序 → 执行 K<h 步并重新观察。

## 效果证据与归因

Table VII joint 80.8%，factorized 71.7%，视觉65.8%，平滑67.5%/70.0%；固定预测网络的评分对照，120 episodes/config。

## 最小采用单元与耦合依赖

评分可作为候选重排器，但依赖候选覆盖、endpoint 可信度、目标定义、动作归一化与先验训练。

## 数据假设与失败边界

示范先验可压制有益的新动作；短 endpoint 看不到完整风险；未见状态与目标失配可能误导评分。

## 潜在迁移（推断）

重试/等待/分配序列的小步执行与稍长时距评估，加入多动作组耦合而非独立平滑。
