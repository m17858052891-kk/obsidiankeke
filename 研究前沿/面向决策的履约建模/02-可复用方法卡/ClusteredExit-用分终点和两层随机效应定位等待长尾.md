# 用分终点和两层随机效应定位等待长尾

[[研究前沿/面向决策的履约建模/01-论文原文与精读/ClusteredExit/精读|两种退出方式为什么有完全不同的长尾？]]

**输入与输出。** 每次进入/退出时间、原因、重复个体 ID、地点 ID 与入场时可见信息，输出各时点退出原因的累计概率。

**训练和使用。** 先统计全量分原因时长，分别拟合原因特异模型，按诊断加入分层和时长交互，两类随机效应共享事件风险集定义。在检查预测校准时分别留出时间和地点。最小诊断是拆出原因和分母；声称地点与个体贡献时才需两级建模。缺失离开时刻、无重复个体或地点样本过小均限制解释。

**证据定位。** 西西里 16 家急诊的 503,797 次合格访问中，离院与入院的时长 P90 分别为 7.10 与 34.95 小时；模型在其中随机抽取的 10,077 次访问上拟合。 [[研究前沿/面向决策的履约建模/01-论文原文与精读/ClusteredExit/精读|原表与限制]]
