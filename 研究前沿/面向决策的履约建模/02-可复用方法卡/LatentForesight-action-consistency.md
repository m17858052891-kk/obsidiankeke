# 真实与预测转移共享逆动作头的表示约束

来源：[[研究前沿/面向决策的履约建模/01-论文原文与精读/LatentForesight/精读|LatentForesight 精读]] · [原文](https://arxiv.org/html/2611.04839v1)

## 输入与输出

输入状态、真实/预测 endpoint 表示及首动作；输出保留动作相关信息的 endpoint predictor。

## 计算、训练与推理流程

冻结视觉编码 → 真实与预测特征差 → 共享 decoder 重建首动作 → 真实分支只训 decoder，预测分支反传到世界模型 → 与 feature loss 联训。

## 效果证据与归因

Table VI 固定视觉评分，4 任务120 episodes：55.0%→65.8%；比整体系统提升具有更直接归因。只评估该具体系统。

## 最小采用单元与耦合依赖

最小单元是共享逆头+两条监督分支；需有动作对齐轨迹和初始状态，decoder 只能约束可预测的动作部分。

## 数据假设与失败边界

同一结果可能由多动作产生；并不保证逆映射唯一，不代表已识别动作效果；只重建第一条命令。

## 潜在迁移（推断）

约束履约状态表示不要丢掉操作差异，先在有明确动作与结果对齐的离线轨迹检验。
