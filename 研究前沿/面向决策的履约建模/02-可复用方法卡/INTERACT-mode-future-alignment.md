# 按候选模式对齐未来实体状态

[[研究前沿/面向决策的履约建模/01-论文原文与精读/INTERACT/精读|INTERACT 精读]] · [[研究前沿/面向决策的履约建模/01-论文原文与精读/INTERACT/代码核验|代码核验]]

## 接口与计算

输入决策前状态和多个候选模式。训练找最接近真实轨迹的一项，仅在同一模式对齐轨迹 L1、冻结教师潜动作和真实未来编码槽 MSE；有候选级 oracle 标签时训练评分头。部署不读取未来，对候选评分选择。

## 最小单元与适用边界

最小单元需固定候选模式、真值匹配规则、未来实体目标和历史推理接口。未执行模式没有实测结果；冻结教师、候选数和评分机制会影响收益。

## 迁移推断与本地验证

订单候选可用同一实体的未来阶段状态监督实际动作模式，结合随机日志评价其他模式，并对照无未来目标或聚合未来目标。 本地未验证。
