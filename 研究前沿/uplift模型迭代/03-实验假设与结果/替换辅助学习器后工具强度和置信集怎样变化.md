# 替换辅助学习器后工具强度和置信集怎样变化

来源为 [[研究前沿/uplift模型迭代/02-可复用方法卡/按候选效应反演交叉拟合的弱工具稳健检验|按候选效应反演交叉拟合的弱工具稳健检验]]，原文见 [[研究前沿/uplift模型迭代/01-论文原文与精读/WeakIVCrossfit/精读|Weak-Instrument Inference and Model Diagnostics in Double Machine Learning for Linear Instrumental Variable Models]]。

## 假设与最小改动

控制真实效应、抽样簇及样本数，逐级减弱工具，冻结折后只替换辅助函数学习器或推断方式。

## 数据、对照与主指标

用已知真值的簇仿真，比较普通 Wald 与折外 Anderson–Rubin 反演；再以固定数据的多种残差学习器作压力测试。

主指标为 95% 覆盖、方向误判和无界置信集频率。若低强度状态下覆盖持续低于目标，或选模型后才达到显著，则不接受稳健性主张。
