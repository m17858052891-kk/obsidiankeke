# 逐站留出时哪些外推限制才会确定效应符号

来源为 [[研究前沿/uplift模型迭代/02-可复用方法卡/先汇总去偏矩再求跨地点效应上下界|先汇总去偏矩再求跨地点效应上下界]]，原文见 [[研究前沿/uplift模型迭代/01-论文原文与精读/ExternalValidityBounds/精读|A Sensitivity Framework for Assessing External Validity]]。

## 假设与最小改动

用同一组来源试验依次加入符号、幅度及交互约束，保留每个目标站的留出结果。

## 数据、对照与主指标

需要多个站点的随机组、处理、结局与共同基线。固定来源训练和目标样本，同无额外限制及点外推作比较。

记录上下界宽度、留出效应是否落入、端点置信区间及求解不可行率。窄界若频繁排除独立试验，撤销对应限制。
