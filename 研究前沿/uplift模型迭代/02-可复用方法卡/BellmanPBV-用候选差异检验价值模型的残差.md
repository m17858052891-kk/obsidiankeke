# 用候选差异检验价值模型的残差

[[研究前沿/uplift模型迭代/01-论文原文与精读/BellmanPBV/精读|没有线上真值时，怎样挑选估计策略价值的模型？]]

输入固定候选、目标策略、验证轨迹和折扣。逐对构造差分，计算经验矩与惩罚，取最差对手后选最优候选，输出候选 ID 与策略价值。最小实现先做未加权版本；依赖密度比的加权版本需另留样本及检查极端权重。表 1 是选择规则对比，表 S3 才能衡量惩罚项本身。

**效果证据与归因。** 表 1 的 Hopper 主设定中，PBV 的平均绝对策略价值误差为 1.78，归一化 LSTD 对照为 3.09，平方 TD 误差选模为 6.75。DeepOPE 上未归一化 LSTD 略优。 [[研究前沿/uplift模型迭代/01-论文原文与精读/BellmanPBV/精读|原文对照及限制]]
