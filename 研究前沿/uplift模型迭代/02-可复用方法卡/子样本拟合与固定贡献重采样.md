# 子样本拟合与固定贡献重采样

[[研究前沿/uplift模型迭代/01-论文原文与精读/arXiv-2603.13662/精读|不在每个 bootstrap 样本重训核模型，会损失多少区间覆盖？]]

## 计算、输入和输出

在小子样本上拟合干扰函数，留存个体的一阶贡献，在各子集内重加权并合并区间；无重拟合版本省去在每个 bootstrap 副本再次训练核模型的成本。

## 可复用的最小单元

子样本拟合与固定贡献重采样。历史修订稿。省计算适合局部样本仍有足够各臂支持的情形。若两臂几乎分离，名义 95% 区间可能大幅欠覆盖。
