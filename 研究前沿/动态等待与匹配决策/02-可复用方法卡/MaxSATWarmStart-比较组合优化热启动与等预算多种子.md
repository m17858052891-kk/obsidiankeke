# 比较组合优化热启动与等预算多种子

[[研究前沿/动态等待与匹配决策/01-论文原文与精读/MaxSATWarmStart/精读|用可微优化给组合求解器热启动，增益有多少来自额外并行？]]

输入硬约束、带权偏好和确切总时限，输出初始化方向或若干软引导及最佳可行解。最小单元是分支初值，可保持原 CPU 求解器。并行部分引导还依赖扰动、额外进程及原目标复核。

**原文证据。** 229 个 MSE 2024 实例、CPU 求解 300 秒下，SPB 单线程基线平均得分 0.926，使用 GPU 初值的单线程为 0.950，50 路部分引导为 0.970。GPU 前处理另计，中位 9.17 秒、平均 49.74 秒、最大 1,045.8 秒。 [[研究前沿/动态等待与匹配决策/01-论文原文与精读/MaxSATWarmStart/精读|原表与范围]]
