# 截止期触发并跳过放不下件的整批贪心

来源 [[研究前沿/动态等待与匹配决策/01-论文原文与精读/TimelyThrifty/精读|Online Timely Bin Packing Revisited: A Simpler Algorithm with Optimality in Special Cases]]。

**输入输出。** 当前已到达、可等待且未承诺的订单及其截止期、大小、稳定 ID；输出同一服务时点的一批或多批整件订单。批一旦封存就不可改动。

**执行。** 将最早截止的待定件设为时钟。当它到期时，先装触发件，再按截止期与稳定 ID 排序扫描所有待定件。每次只在容量足够时装入，用余下容量继续扫描；容量不足的件保留到未来批次。发出后若同刻仍有到期件则立即再开箱。按批只扫描到第一个装不下就停止会改变规则与证明。

**证据与接口。** §2 引理 1 表明两个箱的总装载若至多为 1，其触发件允许窗口必不相交，否则其中一件早已可入前箱。定理 2、4、6 给出等大、一般、两档体积的 1、2、1.5 界。触发与选择共同产生这些界；可单独借用时钟或装填顺序，但不能沿用整套保证。业务若到达时就须给出资源承诺，就缺少其核心待定池。
