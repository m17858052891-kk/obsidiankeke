# 从根节点观测决定是否分配并行副本

[[研究前沿/动态等待与匹配决策/01-论文原文与精读/RootGatedRacing/精读|哪些匹配求解实例值得多开三个并行进程？]]

输入根 LP 信号、剩余期限和资源限额，输出一次性追加 0 或 3 个副本的决定。最小实现是外层进程控制器，保留基础求解器和共同终止规则。按相同实例同时记录有效证明、可行目标和占用秒数；近乎满载时要测对其他请求的挤占。

**效果证据与归因。** 130 个实例、两小时期限下，按根节点信号决定是否并行的方案证明最优 77 个，单进程和始终四进程各 73 个。对比始终四进程，平均进程占用秒数减少 43.0%。 [[研究前沿/动态等待与匹配决策/01-论文原文与精读/RootGatedRacing/精读|原文对照及限制]]
