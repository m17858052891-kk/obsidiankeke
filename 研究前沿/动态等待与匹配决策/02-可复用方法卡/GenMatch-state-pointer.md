# 集合状态与硬mask的可行匹配指针

来源：[[研究前沿/动态等待与匹配决策/01-论文原文与精读/GenMatch/精读|GenMatch 精读]] · [官方正文](https://arxiv.org/html/2608.19751v1)

## 输入与输出

候选表示、业务logit、初始/已选/剩余候选集合；输出一对一匹配。

## 具体计算与训练流程

用集合均值加计数比例构造查询；cross-attention得结构分，加业务分后softmax；贪心选边，删除共享订单/司机的所有边；增量更新集合和与计数。训练随机排列完单集合、teacher forcing。

## 原论文效果证据

Table2去剩余状态A8 CR−1.07%，去进度A9−0.96%，固定首次logit交KM的A12−3.07%；说明状态随选择更新有贡献，不是指针生成都必然更好。

## 最小采用单元与耦合依赖

最小替换包含状态更新、mask、训练目标和推理停止条件；生产需稳定候选索引、锁定仲裁及回退。

## 数据假设与失败边界

无显式hold/stop动作，推理到无可选边；历史完单示范有选择偏差。贪心不保证全局最优。
