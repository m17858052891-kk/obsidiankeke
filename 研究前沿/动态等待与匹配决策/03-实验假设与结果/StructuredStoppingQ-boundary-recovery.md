# 供需跳变时，结构化动作值能否恢复等待边界

来源模块 [[研究前沿/动态等待与匹配决策/02-可复用方法卡/StructuredStoppingQ-generator-q|带停止罚项的生成算子 q 函数]]。原文见 [[研究前沿/动态等待与匹配决策/01-论文原文与精读/StructuredStoppingQ/精读|Continuous-time q-Learning for Finite-Horizon Portfolio Choice with Optimal Stopping in Jump-Diffusion Markets]]。

**假设。** 在可枚举最优动作、存在突发供给和候选离开的低维等待仿真里，显式建模跳跃价值差和立即匹配价值，可降低有限样本下边界附近的决策后悔。

**最小设计。** 从有限时域、单区域、有截止期的状态演化开始。固定同一奖励、动作空间、离散化与训练样本，主对照为自由 q 网络，另以已知转移上的后向动态规划作参照。预先指定生成算子错设的压力场景。数据需求包括到达/离开事件时间、候选价值、决策与等待费用，初轮允许全部为合成。仅把该假设与金融实验联系为机制启发。

**评估。** 以配对模拟的累计折现净收益差距为主指标，按距最优停止边界远近报告错误动作率、P95 等待及超时比例。独立划分到达参数、市场状态和随机种子，训练/验证集选 $K,\lambda$，锁定后测试。预算限小规模仿真，样本与计算时限待确认。若在同样的预算下主指标区间跨零，标未决；若留出跳变状态的后悔变大、或增益仅见于超时违反的策略，则判假设失败。

项目、代码版本、数据快照、配置和阈值待确认。尚未运行，无本地结果。
