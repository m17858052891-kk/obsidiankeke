# 等应答页表单与交互决策

业务关联与补充查询入口。每日通用模型检索见 [[研究前沿/推荐模型检索地图|推荐模型检索地图]]；本页用于解释业务迁移和选择后续验证。

等待阶段展示哪些车型或候选、如何排序和补勾、何时提示与确认，以及怎样联合估计点击、接受、继续等待、取消和完单？

这里按等应答页的展示与动作策略理解“表单”。以等待中的状态为条件，关注默认选项、重复提示与价格等属性对接受和退出的影响。曝光点击、接受、完单分别评估，并检查多次曝光和策略选择偏差。

公共短查询逐条执行，覆盖直接问题和跨领域机制。
