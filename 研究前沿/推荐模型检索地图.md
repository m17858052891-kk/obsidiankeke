# 推荐模型检索地图

每日 11:00，Asia/Shanghai。按 [[研究前沿/推荐模型检索地图|推荐模型检索地图]] 的六类通用方法分别发现论文，再结合预分单、换车、升舱、等应答页和模型自进化判断迁移价值。通用检索独立执行，关键词无需附带业务名。业务入口用于补充检索、解释适用条件和阅读排序。

主读依据为方法创新、明确机制与可信原文证据。推荐、广告、搜索、表格学习及跨领域论文，只要能解释它解决什么建模问题、怎样设计对照即可入选。业务尚未确定接入点的，明确“潜在迁移，业务落点待确认”，可以先设计同输入、同预算的模型级对照。具体业务收益与当下可接入性作为适配说明。

每篇主读开头回答两问。能改哪个通用建模环节，潜在服务哪些业务？第一步怎样固定数据、主干或算力做对照，查看哪个指标、什么结果否定假设？原文证据与迁移推断分别标注。模型级消融可以独立证明研究价值，预测收益向业务收益外推时需额外验证。

范围变更后按 active_scan_tracks 各自回查 90 天，之后滚动 7 天、优先 24 小时。每天处理旧待核验队列和新发现；存量以全库复筛后的登记为基础，按新证据或研究需求调整分层。

## 统一分层

按 [[研究前沿/检索与归档规则|检索与归档规则]] 与 [[研究前沿/论文库复筛与阅读路线|全库阅读路线]]，以方法价值和证据质量分为“近期主读、方法储备、待核验”。有价值但暂时不用的保留为储备，不因业务距离删除。已核验主读进入近期先读后备池，储备遇到新证据或阅读需求可升级；证据不足者先补核，不进首页。分层、索引、候选 JSON 和可读后备池每日同步，首页仅补空位。

- `"learning to rank" representation learning`

## 业务关联

预分单与等应答页可关联候选相关性、接受预测、列表交互和多阶段转化；换车可关联配对评分、序列状态和比较候选后的校准；升舱可关联动作条件响应、增量估计与成本约束；模型自进化关联持续训练、数据反馈和自动选模。映射用于解释与排序，允许先研究通用模块。业务 README 的查询作为补充，方法论文按最主要贡献只存一份正文。
