# AdaptiveBeamDiskANN｜ANN 动态省平均时间，会不会把尾延迟拉长？

来源：[[研究前沿/Scaling up 与效率/01-论文原文与精读/AdaptiveBeamDiskANN/精读|原文精读]]

## 输入、输出与最小采用流程

先执行小试探阶段，用观察到的搜索特征预测每条请求所需 beam，再沿已有状态继续。离线选 beam 时最小化平均距离计算，满足平均 recall；对照固定 beam 与提前停止。

## 首个验证
