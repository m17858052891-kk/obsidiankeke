# 过拟合

过拟合是指模型不仅学到了训练数据中的规律，还记住了噪声和偶然特征，导致训练集表现很好，但验证集、测试集或线上效果变差，泛化能力不足。

## 如何判断

- 训练集指标持续变好，但验证集指标先升后降，或训练/验证差距持续扩大；
- 训练集和验证集都差，通常是欠拟合、特征不足或没有充分训练，不应直接判断为过拟合；
- 先排查数据泄漏、训练与线上分布不一致、错误的切分方式等问题，它们会造成“看起来像过拟合”的现象。

## 如何解决

1. **增加或改进数据**：增加训练样本，清洗错标和重复数据；对图像、文本等任务可做不改变标签含义的数据增强。
2. **降低模型复杂度**：减少网络层数、隐藏层维度、特征交叉或 embedding 维度，使模型容量与数据量匹配。
3. **使用正则化**：常用 L2 正则或 Weight Decay 抑制过大的权重；也可使用 L1 促进稀疏。
4. **使用 Dropout**：训练时随机屏蔽部分神经元，降低神经元之间的共适应；比例过大可能造成欠拟合。
5. **Early Stopping**：当验证集指标不再提升时，停止训练并保留最佳 checkpoint。
6. **合理划分数据**：验证集和测试集必须独立；有时间顺序的数据应按时间切分，避免未来信息泄漏。

## 面试回答

过拟合表现为训练集效果很好、验证集或测试集效果较差。解决时我会先排查数据泄漏和数据分布不一致；确认后，再从增加或清洗数据、数据增强、降低模型复杂度、加入 L2/Weight Decay 或 Dropout，以及 Early Stopping 等方向逐项验证，而不是直接盲目增加正则化。
