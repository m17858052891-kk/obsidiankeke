# 过拟合诊断与控制：数据、模型与训练

过拟合不是“验证集差了就加 Dropout”这么简单。它指模型把训练样本中的偶然性、噪声或训练集特有分布也学成了规律，以致对未来样本的泛化变差。

## 1. 先用学习曲线判断问题类型

| 现象 | 更可能的原因 | 首先检查什么 |
|---|---|---|
| 训练集和验证集都差 | 欠拟合、优化失败、特征不足、标签噪声 | 学习率、训练步数、实现、特征覆盖 |
| 训练持续变好，验证变差 | 典型过拟合 | 正则、容量、数据量、时间漂移 |
| 训练很好，随机验证也好，时间验证差 | 分布漂移或时间泄漏 | 切分方式、特征截止时刻、标签延迟 |
| 离线好、线上差 | 样本/候选/特征不一致，或指标错位 | train-serving 一致性、负采样、校准 |
| 大模型训练 loss 更低、验证 AUC 不涨 | 容量未转成泛化能力 | 数据量、正则、充分训练与目标匹配 |

最有价值的诊断是同时看：训练/验证曲线、按时间的验证集、关键人群切片、以及线上与离线的特征和候选分布。只看一个最终 AUC 很容易误判。

## 2. 控制过拟合的四个杠杆

### 2.1 数据：最根本的正则化

- 增加真实样本覆盖，尤其是长尾用户、稀有场景和困难负例；
- 按时间划分训练/验证/测试，防止未来统计量穿越；
- 处理错标、重复样本和异常标签；
- 让训练样本尽量匹配推理时的候选分布；
- 对序列、文本、图像等可做语义不变的数据增强，但不能改变标签含义。

数据增强不是任何任务都适用。推荐/广告中更常见的是合理负采样、时间窗口扰动、mask 部分历史等；必须验证它不引入不符合线上分布的样本。

### 2.2 模型容量：表达能力要与数据量匹配

可减少层数、hidden size、embedding 维度、特征交叉阶数或序列长度。模型太小会欠拟合，模型太大而数据/有效监督不足会记忆训练噪声。容量调整后应重新调学习率、训练步数和正则，不能只改一个维度就下结论。

### 2.3 显式正则：限制参数和表征

| 方法 | 机制 | 常见注意点 |
|---|---|---|
| L2 / Weight Decay | 抑制过大权重，偏好平滑解 | Adam 类优化器通常使用 decoupled weight decay（AdamW） |
| L1 | 促使部分权重变为 0 | 对强相关特征会不稳定地选其一 |
| Dropout | 训练时随机失活部分单元 | 推理时关闭；过大可能导致欠拟合 |
| Early Stopping | 在验证指标不再改善时停止 | 验证集应是独立且时间合理的 |
| Embedding / 模型约束 | 限制词表、维度或范数 | 高基数 ID 尤其需要关注长尾覆盖 |
| Batch/Layer Norm | 稳定优化，可能有轻微正则效应 | 它们的主要目的不是替代正则 |

关于 L1/L2/Dropout 的原理见 [[正则化技术]]；Dropout、LayerNorm、RMSNorm 的关系见 [[归一化方法]]。

#### L1、L2 与 Elastic Net 的区别

$$
L_{\mathrm{L1}}=L_{\mathrm{data}}+\lambda\sum_i|w_i|,
\qquad
L_{\mathrm{L2}}=L_{\mathrm{data}}+\frac\lambda2\sum_iw_i^2.
$$

L1 的梯度（除 0 点外）是固定符号，容易把一部分参数推到 0，适合稀疏特征选择；L2 的梯度与 $w_i$ 成正比，主要抑制大权重、使解更平滑。Elastic Net 同时使用两者：

$$
L=L_{\mathrm{data}}+\lambda_1\sum_i|w_i|+\frac{\lambda_2}{2}\sum_iw_i^2.
$$

对于 Adam 一类自适应优化器，实践中常用 AdamW 的 decoupled weight decay：在参数更新中直接衰减权重，而不是把 L2 项混入自适应梯度。

#### Dropout 为什么能正则化

训练时以概率 $p$ 随机屏蔽部分激活，并对保留下来的激活按比例缩放；推理时关闭随机屏蔽。这样单个神经元不能持续依赖固定的搭档（co-adaptation），网络被迫学习对局部缺失更稳健的冗余表示。它不减少参数量；若数据量很大或模型本已受限，过大的 dropout 反而会造成欠拟合。

### 2.4 训练策略：避免把“没训好”误判成过拟合

- 学习率过高会导致验证波动，不等于泛化差；
- 学习率过低或训练步数不足会让更大模型看起来“无效”；
- batch size、warmup、scheduler、梯度裁剪、混合精度都会影响收敛；
- 固定随机种子之外，重要改动最好多 seed 或做置信区间检查；
- 每次只改变少数变量，建立可比较的实验矩阵。

## 3. 推荐/广告中特别常见的“假过拟合”

1. **时间泄漏。** 用到了预测时点之后的累计统计、后验行为或全量数据归一化参数；离线随机切分会掩盖问题。
2. **负采样偏差。** 训练负例比线上简单，AUC 高但真正候选内区分不开；改变采样率还会改变正例先验和校准。
3. **曝光选择偏差。** 日志只包含旧策略展示过的样本，模型并未观察完整候选空间。
4. **训练服务不一致。** 离线特征计算口径、词表、缺失值或时间窗口与线上不同。
5. **指标错位。** 训练 Loss 下降或全局 AUC 上升，但业务实际关心的是 Top-K、GMV、CPA 或某个人群。

这些问题不能仅靠加正则解决；应先修数据、样本和评估设计。

## 4. 一个可执行的排查顺序

1. 用几十到几百样本做 overfit test：模型是否能把训练 loss 明显压低？不能则先查代码、标签和优化。
2. 对照随机切分与严格时间切分：落差很大先查泄漏与漂移。
3. 画 train/valid 的 Loss、AUC、LogLoss 随 step 曲线，确认最佳 checkpoint。
4. 固定模型，只扫学习率、weight decay、dropout、训练步数；再比较容量。
5. 查看分桶/切片和特征覆盖，排除少数大流量群体掩盖退化。
6. 对候选、特征、标签和推理链路做 train-serving 一致性校验。

## 5. 高频问答

### 训练 loss 一直下降、验证 AUC 下降，怎么办？

先确认时间切分和特征不存在泄漏，再用最佳验证 checkpoint 作为基线。随后从数据覆盖、模型容量、weight decay/Dropout、early stopping 和学习率逐项做对照，而不是直接堆更多正则。若只在某些人群退化，要优先排查样本分布和特征覆盖。

### Dropout 为什么能正则化？

训练中随机屏蔽部分单元，迫使网络不能依赖固定的特征共适应，相当于训练许多共享参数的子网络并在推理时做近似集成；因此它偏好对扰动更稳定的表示。它不减少参数量，推理时也不随机丢单元。

### 如何区分模型上限、欠训练和过拟合？

训练和验证都差，优先怀疑欠训练、优化或信息不足；训练显著优于验证，优先怀疑过拟合或分布不一致；训练已经充分、增大模型也不改善且特征/标签质量受限，才更接近数据或模型上限。需要用学习曲线、小样本 overfit test 和等预算/充分训练两种对照共同判断。
