
在搜索、推荐、广告及因果推断领域，这四个指标是评估模型优劣的“度量衡”。我们将从物理意义、数学公式和代码实现三个维度进行拆解。

## 1. AUC (Area Under the ROC Curve)

**应用场景**：CTR 预估、二分类模型评估。 **物理意义**：随机抽取一个正样本和一个负样本，模型对正样本的打分大于负样本打分的概率。AUC 越接近 1，模型的排序（区分）能力越强。

### 🎓 计算公式

假设有 $M$ 个正样本，$N$ 个负样本。最常用的基于 Rank（秩）的计算公式如下：

$$AUC = \frac{\sum_{i \in \text{Positive}} \text{rank}_i - \frac{M \times (M+1)}{2}}{M \times N}$$

其中，$\text{rank}_i$ 是将所有样本按预测概率从小到大排序后，第 $i$ 个样本的排名。

### 💻 Python 代码

在实际工程中，通常直接调用 `sklearn`，但手动实现更能体现对其本质的理解：

```
import numpy as np
from sklearn.metrics import roc_auc_score

def calculate_auc_manual(y_true, y_pred):
    # 将真实标签和预测概率打包并按预测概率从小到大排序
    data = list(zip(y_true, y_pred))
    data.sort(key=lambda x: x[1])
    
    pos_count = sum(y_true)
    neg_count = len(y_true) - pos_count
    
    if pos_count == 0 or neg_count == 0:
        return 0.0
    
    rank_sum = 0
    # enumerate 从 1 开始作为 rank
    for rank, (label, pred) in enumerate(data, 1):
        if label == 1:
            rank_sum += rank
            
    auc = (rank_sum - (pos_count * (pos_count + 1) / 2)) / (pos_count * neg_count)
    return auc

# 使用 sklearn: auc = roc_auc_score(y_true, y_pred)
```

## 2. AUCC (Area Under the Uplift Curve)

**应用场景**：Uplift Modeling（因果推断/增效模型）、智能补贴、营销人群定向。 **物理意义**：衡量干预（Treatment）带来的增量效果。AUCC 是增效曲线（Uplift Curve）下的面积，数值越大，说明模型将高增效人群排在前面的能力越强。

### 🎓 计算公式

假设将样本按模型的预估增量（Predicted Uplift）降序排列，截取前 $k\%$ 的样本，计算其中的实际增量：

$$\text{Uplift}(k) = \left( \frac{Y_{T, k}}{N_{T, k}} - \frac{Y_{C, k}}{N_{C, k}} \right) \times (N_{T, k} + N_{C, k})$$

其中，$T$ 代表实验组（Treatment），$C$ 代表对照组（Control），$Y$ 是转化人数，$N$ 是总人数。AUCC 即为横轴为 $k\%$，纵轴为 $\text{Uplift}(k)$ 的曲线下方面积。

### 💻 Python 代码

```
import numpy as np

def calculate_aucc(y_true, treatment, uplift_pred):
    """
    y_true: 实际结果 (0或1)
    treatment: 是否受到干预 (0或1)
    uplift_pred: 模型预测的增量分 (CATE)
    """
    # 按预测分降序排序
    order = np.argsort(uplift_pred)[::-1]
    y_true = np.array(y_true)[order]
    treatment = np.array(treatment)[order]
    
    n = len(y_true)
    uplift_curve = np.zeros(n)
    
    # 累积变量
    t_count = 0; c_count = 0
    t_y_sum = 0; c_y_sum = 0
    
    for i in range(n):
        if treatment[i] == 1:
            t_count += 1
            t_y_sum += y_true[i]
        else:
            c_count += 1
            c_y_sum += y_true[i]
            
        if t_count > 0 and c_count > 0:
            # 累计增量转化人数
            uplift_curve[i] = (t_y_sum / t_count - c_y_sum / c_count) * (t_count + c_count)
        else:
            uplift_curve[i] = 0
            
    # 计算曲线下面积 (简单的梯形法则或直接求和)
    aucc = np.sum(uplift_curve) / n
    return aucc
```

## 3. NDCG (Normalized Discounted Cumulative Gain)

**应用场景**：信息检索、推荐系统 Top-K 排序评估。 **物理意义**：衡量排序列表的质量。它有两个核心假设：1. 高相关性的物品比低相关性的物品更有用；2. 相关物品排得越靠前越有用（位置越靠后，价值要被打折 Discounted）。

### 🎓 计算公式

首先计算第 $K$ 个位置的折扣累计收益 $DCG@K$：

$$ DCG@K = \sum_{i=1}^{K} \frac{2^{rel_i} - 1}{\log_2(i + 1)} $$

其中，$rel_i$ 是第 $i$ 个位置的真实相关性得分（例如点击为1，未点击为0，或者具体的评分等级）。 然后，计算理想状态下（按真实相关性完美降序排列）的 $IDCG@K$：

$$ NDCG@K = \frac{DCG@K}{IDCG@K} $$

### 💻 Python 代码

```
import numpy as np

def dcg_at_k(rel, k):
    """计算 DCG@K"""
    rel = np.asfarray(rel)[:k]
    # np.arange(2, rel.size + 2) 对应位置 i+1 (位置从1开始)
    return np.sum((np.power(2, rel) - 1) / np.log2(np.arange(2, rel.size + 2)))

def ndcg_at_k(rel, k):
    """计算 NDCG@K"""
    dcg = dcg_at_k(rel, k)
    # 将真实相关性降序排列，计算理想 DCG
    idcg = dcg_at_k(sorted(rel, reverse=True), k)
    if idcg == 0:
        return 0.0
    return dcg / idcg

# 示例: 真实相关性标签 (按模型预测给出的顺序)
# relevance = [3, 1, 2, 0, 0]
# print(ndcg_at_k(relevance, 3))
```

## 4. HR (Hit Ratio)

**应用场景**：推荐系统 Top-K 召回率评估（常用于 Leave-one-out 评测方法）。 **物理意义**：在给用户推荐的 $K$ 个物品中，是否包含了用户实际点击（或喜欢）的那个目标物品。命中就是 1，没命中就是 0。全局的 HR 就是所有用户的平均命中率。

### 🎓 计算公式

对于单个用户 $u$：

$$ HR@K_u = \begin{cases} 1, & \text{如果目标物品 } i \text{ 在推荐的 Top-}K \text{ 列表中} \ 0, & \text{否则} \end{cases} $$

全局 Hit Ratio：

$$ HR@K = \frac{\sum_{u \in U} HR@K_u}{\vert{}U\vert{}} $$

### 💻 Python 代码

```
def hit_ratio_at_k(recommended_list, target_item, k):
    """
    计算单个用户的 HR@K
    recommended_list: 模型推荐给用户的物品 ID 列表 (按得分降序)
    target_item: 用户实际交互的目标物品 ID
    k: Top K
    """
    # 截取前 K 个推荐物品
    top_k_items = recommended_list[:k]
    
    # 检查目标物品是否在 Top K 中
    if target_item in top_k_items:
        return 1.0
    else:
        return 0.0

# 全局评估时，将所有用户的上述函数返回值取均值即可。
```
