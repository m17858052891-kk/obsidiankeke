# 1. 预热 (Warm-up)：热身防爆

**直觉：** 在训练的第一步，模型的权重是完全随机初始化的，身处一个完全未知的极度陡峭地形中。此外，自适应优化器（如 Adam）内部用于记录历史梯度的“动量（一阶矩）”和“方差（二阶矩）”都还是空的或极度不准确。 如果此时直接给一个极大的学习率 $\eta_{max}$，模型会瞬间迈出极其离谱的一大步，导致 Loss 直接爆炸变成 `NaN`。因此，我们需要花几百或几千步，把学习率从极小值（通常是 0）慢慢“踩油门”加到最大。

**核心公式（线性预热 Linear Warm-up）：** 假设预热阶段总共持续 $T_{warmup}$ 步，我们希望学习率从 $0$ 爬升到设定的最大值 $\eta_{max}$。对于当前步数 $t$ （当 $t < T_{warmup}$ 时）：

$$\eta_t = \eta_{max} \times \frac{t}{T_{warmup}}$$

- **原理解析：** 这是一条从原点出发的斜向上直线。例如，目标最大 LR 是 $10^{-3}$，预热 $1000$ 步。那么在第 $100$ 步时，实际应用的 LR 就是 $10^{-4}$，保证模型初期稳扎稳打。

# 2. 余弦退火 (Cosine Decay)：平滑着陆

**直觉：** 度过了预热期，模型进入了漫长的“下山”阶段。早些年大家爱用“阶梯下降（Step Decay）”（比如每 30 个 Epoch 把 LR 砍半），但这太生硬了，容易导致 Loss 曲线在下降点出现剧烈的震荡。 余弦退火借用了三角函数中的 $\cos$ 曲线。它在初期下降得很慢（保持对未知区域的高探索力），在中期加速下降，在末期又变得极其平滑，让模型像落叶一样极其细腻地飘进局部最优解的最深处。

**核心公式：** 假设已经度过了预热期，剩余的总训练步数为 $T_{max}$。我们希望 LR 最终下降到一个极小的底线值 $\eta_{min}$（通常为 $0$ 或 $10^{-6}$）。 当步数 $t \ge T_{warmup}$ 时：

$$\eta_t = \eta_{min} + \frac{1}{2}(\eta_{max} - \eta_{min})\left(1 + \cos\left(\frac{t - T_{warmup}}{T_{max}}\pi\right)\right)$$

- **原理解析：**
    - 公式核心是利用了 $\cos$ 函数在 $[0, \pi]$ 区间内从 $1$ 平滑下降到 $-1$ 的特性。
    - 刚过预热期时，角度为 $0$，$\cos(0)=1$，最终结果完美等于 $\eta_{max}$。
    - 训练结束时，角度为 $\pi$，$\cos(\pi)=-1$，最终结果完美等于 $\eta_{min}$。

# 3. 重启机制 (Warm Restarts)：暴力跳坑

**直觉：** 深度学习的损失曲面（Loss Landscape）里有无数个坑（局部最优解）。当余弦退火走到末期，LR 变得极小，模型很可能已经死死地卡在一个不是特别深的“烂坑”里出不来了。 **重启机制（SGDR）的逻辑是：当你快要在这个烂坑里躺平的时候，我突然往你屁股上踹一脚（瞬间把 LR 强制拉回到最大值** $\eta_{max}$**），把你从坑里弹射出去，强迫你去寻找其他可能更深的“神仙坑”。**

**核心公式：** 引入重启后，余弦公式的周期不再是全局的总步数，而是**当前这个重启周期内的步数**。我们需要设定第一次重启的周期长度 $T_0$（例如 10 个 Epoch），以及每次重启后周期拉长的倍数 $T_{mult}$（通常设为 2，防止模型后期疯狂跳跃无法收敛）。

$$\eta_t = \eta_{min} + \frac{1}{2}(\eta_{max} - \eta_{min})\left(1 + \cos\left(\frac{T_{cur}}{T_i}\pi\right)\right)$$

- $T_i$：当前这一轮重启的总长度（比如第 1 轮是 10，第 2 轮是 20，第 3 轮是 40...）。
- $T_{cur}$：在**当前轮次内**已经走过的步数。每当发生一次重启，LR 瞬间满血复活回到 $\eta_{max}$，同时 $T_{cur}$ 归零，重新开始下一轮的余弦下降。
