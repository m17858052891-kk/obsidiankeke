# 模型评估指标

模型评估没有“万能指标”，要先明确模型如何被使用：

| 任务目标     | 常用指标                 | 核心关注点          |
| -------- | -------------------- | -------------- |
| 二分类、排序   | AUC、PR-AUC           | 正样本能否排在负样本前    |
| 有明确决策阈值  | Precision、Recall、F1  | 误报和漏报的权衡       |
| 推荐、搜索    | GAUC、Recall@K、NDCG@K | 同一次请求中前排结果是否更好 |
| 需要使用预测概率 | LogLoss、Brier、ECE    | 概率是否准确、可信      |
| 回归       | MAE、RMSE、$R^2$       | 预测值与真实值的偏差     |
| 干预/营销    | AUUC、Qini            | 干预带来的增量收益      |

## 1. 分类与排序指标

### AUC

$$
\mathrm{AUC}=\Pr(s(x^+)>s(x^-)).
$$

AUC 表示随机抽取一个正样本和负样本时，正样本得分更高的概率。它只衡量相对排序，对分数做单调变换后不变，因此：**AUC 高不等于概率准确，也不等于某个阈值下的 Precision 高。**

### Precision、Recall、F1 与 PR-AUC

$$
\mathrm{Precision}=\frac{TP}{TP+FP},\qquad
\mathrm{Recall}=\frac{TP}{TP+FN},\qquad
F1=\frac{2PR}{P+R}.
$$

- Precision：预测为正的样本中，真正为正的比例；适合误报代价高的任务。
- Recall：真实正样本中被找出的比例；适合漏报代价高的任务。
- F1：Precision 和 Recall 的调和平均，只适用于两者同等重要的场景。
- PR-AUC：汇总不同阈值下的 Precision-Recall 表现；正类稀少时，通常比 ROC-AUC 更有参考价值。



## 2. 推荐与搜索的排序指标

### GAUC

全局 AUC 可能掩盖不同用户或 query 的差异。GAUC 是先在每个 group（如用户、请求或 query）内计算 AUC，再加权平均：

$$
\mathrm{GAUC}=\frac{\sum_gw_g\,\mathrm{AUC}_g}{\sum_gw_g}.
$$

它更接近“同一次请求里，是否把更相关的候选排在前面”。比较 GAUC 时必须保证 group 定义和权重口径一致。

### Recall@K、HR@K、NDCG@K

- Recall@K：真实相关 item 有多少出现在前 K 个结果中；
- HR@K：单个测试正例是否命中前 K；
- NDCG@K：既看是否命中，也强调位置，排得越靠前得分越高。

$$
\mathrm{DCG@K}=\sum_{i=1}^K\frac{2^{rel_i}-1}{\log_2(i+1)},\qquad
\mathrm{NDCG@K}=\frac{\mathrm{DCG@K}}{\mathrm{IDCG@K}}.
$$

页面只展示前 10 个结果时，NDCG@10 往往比全局 AUC 更接近用户体验。离线比较时，候选集和负采样方式必须保持一致。

## 3. 概率质量：LogLoss、Brier 与校准

### LogLoss

$$
\mathrm{LogLoss}=-\frac1N\sum_i[y_i\log p_i+(1-y_i)\log(1-p_i)].
$$

LogLoss 对“高置信但预测错误”的样本惩罚很大，适合 CTR/CVR 预估、出价和阈值决策等需要概率输出的任务。

### 校准、ECE 与 Brier Score

校准指预测概率与真实发生率一致，例如预测为 0.2 的样本，长期真实正例率也应约为 0.2。常用指标：

- ECE：将样本按预测概率分桶，计算每桶预测概率与真实发生率的平均差异；越小越好，但受分桶数影响。
- Brier Score：$\frac1N\sum_i(p_i-y_i)^2$，衡量概率预测的均方误差；越小越好。

高 AUC、差校准并不矛盾：排序可能正确，但预测概率可能偏大或偏小。需要时可用 Platt scaling、isotonic regression 或 temperature scaling 校准，并使用独立、接近线上分布的校准集。

## 4. 回归指标

$$
\mathrm{MAE}=\frac1N\sum_i|y_i-\hat y_i|,\qquad
\mathrm{RMSE}=\sqrt{\frac1N\sum_i(y_i-\hat y_i)^2}.
$$

- MAE 表示平均绝对误差，对异常值更稳健；
- RMSE 会放大大误差，适合大偏差代价更高的场景；
- $R^2=1-\frac{\sum_i(y_i-\hat y_i)^2}{\sum_i(y_i-\bar y)^2}$ 表示相对“直接预测均值”的改进程度，可能为负，不适合跨数据集直接比较。

对于长尾目标，不能只看整体 MAE/RMSE，还应按金额、城市、品类、时间等维度切片查看误差。
