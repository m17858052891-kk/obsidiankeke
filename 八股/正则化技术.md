# 1. L1 正则化 (Lasso Regression / 绝对值惩罚)

- **直觉：冷酷无情的“裁员 HR”** L1 会极其激进地把那些对预测结果贡献不大的特征权重，直接“清零”。
- **数学公式：** 惩罚项是所有权重参数 $w$ 的绝对值之和（$\lambda$ 是控制惩罚力度的超参数）。

    $$Loss_{total} = Loss_{data} + \lambda \sum \vert{}w_i\vert{}$$
- **求导分析（为什么会产生稀疏性？）：** 绝对值函数 $\vert{}w\vert{}$ 的导数非常硬核：
    - 当 $w > 0$ 时，导数永远是 $1$。
    - 当 $w < 0$ 时，导数永远是 $-1$。 这意味着，只要 $w$ 不是 0，L1 惩罚项给出的梯度就是一个**恒定大小的力**，死死地把权重往 0 的方向推，直到它彻底变成 0 为止。
- **核心效果：参数稀疏化 (Sparsity)** 最终训练出来的模型，大量的权重参数变成了绝对的 `0.0000`。
- **💡 适用的数据/场景：**
    - **高维稀疏特征（如文本、用户画像）：** 假设你有一万个特征，但你怀疑只有几十个真正有用。加上 L1 后，模型会自动帮你把剩下的 9900 个特征权重变成 0。
    - **需要极强“可解释性”的业务：** 比如医疗诊断或金融风控。老板问“为什么拒绝贷款？”，L1 过滤后只剩下几个非零权重的特征（比如“逾期次数”、“负债率”），你可以直接给出清晰的规则，而不会被几千个微小的权重干扰。
    - **特征选择 (Feature Selection)：** 经常被当作机器学习流程的第一步，用来筛选有用特征。

# 2. L2 正则化 (Ridge Regression / 权重衰减 Weight Decay)

- **直觉：温和的“财富平均主义者”** L2 不喜欢任何一个特征“一家独大”，它会把权重均匀地分散到所有特征上，让大家的权重都变得很小，但极少有人会被直接裁掉（变成 0）。
- **数学公式：** 惩罚项是所有权重参数 $w$ 的平方和。

    $$Loss_{total} = Loss_{data} + \frac{\lambda}{2} \sum w_i^2$$
- **求导分析（为什么是衰减而不是清零？）：** 平方函数 $\frac{1}{2} w^2$ 的导数是 $w$ 本身。 这意味着，惩罚力度（梯度）是和权重大小成正比的：
    - 当 $w$ 很大时（比如 100），往回拉的力也很大（100）。
    - 当 $w$ 变得很小时（比如 0.01），往回拉的力也变得极其微弱（0.01）。 因此，$w$ 会无限趋近于 0，但**几乎永远不会真正等于 0**。
- **核心效果：权重平滑 (Smoothness)** 防止个别参数过大导致模型对某个微小扰动极其敏感，提高了模型的抗干扰能力。
- **💡 适用的数据/场景：**
    - **深度学习的绝对默认标配：** 几乎所有的现代神经网络（CNN, Transformer）默认开启的都是 L2 正则化（即 Weight Decay）。
    - **共线性极强的数据：** 当几个特征高度相关时（比如“面积(平方米)”和“面积(平方尺)”），L2 会给它们分配差不多的权重，而不会像 L1 那样随机抛弃一个。

> **🔗 梦幻联动：AdamW 中的 "W"** 我们之前在《优化器演进史》提到的 AdamW，里面的 **W** 指的就是 **Weight Decay（L2 正则化的工程实现）**。研究人员发现，如果把 L2 的惩罚项放在 Loss 函数里算梯度，在 Adam 这种带二阶矩自适应的优化器里会失效。所以 AdamW 的做法是：把 L2 的惩罚从梯度计算中抽离出来，**在每次更新参数时，直接让参数本身乘以一个衰减系数（比如 0.99）**。这就完美复活了 L2 正则化在 Transformer 等大模型中的威力！

# 3. 弹性网络 (Elastic Net)：成年人全都要

- **机制：** 简单粗暴，把 L1 和 L2 同时加到 Loss 函数里。

    $$Loss_{total} = Loss_{data} + \lambda_1 \sum \vert{}w_i\vert{} + \frac{\lambda_2}{2} \sum w_i^2$$
- **💡 适用的数据/场景：** 当你的数据维度比样本数量还大（$p > n$），且特征之间有很强的相关群组时。Elastic Net 既能像 L1 一样选出有用的特征群，又能像 L2 一样在选出的群组内保持权重的平滑。

# 4. 深度学习专属正则化：Dropout

虽然 L1 和 L2 很好，但在具有上亿参数的神经网络中，直接改 Loss 函数有时候不够高效。于是 2012 年诞生了简单粗暴的 Dropout。

- **机制：** 在每一次前向传播训练时，**随机“杀死（置 0）”** 一部分神经元（比如 50%）。
- **直觉：** 逼迫网络中的神经元不能互相依赖（不能“拉帮结派”）。今天这个特征不工作了，那个特征也得顶上，从而让每个神经元都学到了更独立、更健壮的特征表达。
- **💡 应用场景：** 主要用于全连接层 (Dense/Linear Layer) 之间。注意：在预测（Inference）阶段，所有的神经元都会被打开，并按比例缩放权重。
