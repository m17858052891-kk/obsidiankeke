# 术语和指标：先确认对象、分母与单位

[总索引](00_总索引.md)

| 术语 | 含义和必须确认的边界 |
|---|---|
| SID / RQ | 语义ID / 残差量化；码可代表一个或多个对象，也可只作特征。码命中不等于真实物品命中 |
| Atomic token | 一个真实对象对应唯一token；消除编码碰撞，但词表、数据量和可训练参数成本上升 |
| SFT / NTP | 监督微调 / 下一个token预测；优化日志目标概率，不自动对应长期增量收益 |
| LoRA | 以低秩适配器训练部分参数；“端到端梯度可达”不必等于骨干所有参数全量训练 |
| PPO / GRPO / DPO | 不同的策略/偏好优化方法；看到reward不能自动归类，实际目标以原文公式为准 |
| RM / Evaluator / judge | 奖励模型、列表评价器、评审器；代理分数需要独立人评/真实业务验证，不能改名为收入 |
| 近线 / 缓存 | 请求之外触发的计算与存储；必须说明更新对象、触发、TTL、命中、陈旧和回退 |
| AUC / GAUC / UAUC | 排序区分能力及分组聚合变体；数据集、分组权重和归一化不同不能直接比较，AUC提高不等于校准提高 |
| HR / Recall / NDCG / MRR | 命中、覆盖、位置加权相关性、倒数排名；全库/采样候选、每请求正例个数、K、平均方式必须一致 |
| PCOC | 预测转化总量/观测转化总量一类校准量；相对bias下降需明确bias是否为绝对偏离1 |
| OPE / propensity / support | 旧策略日志评新策略 / 动作曝光概率 / 两策略支持重叠；没有支持的动作不能凭加权恢复真实结果 |
| PBM / IPM | 位置点击模型 / 物品位置模型；假设强弱影响偏差方差，无偏保证有条件 |
| ESS | 有效样本量，反映权重集中后的信息量；日志行数大不保证加权估计稳定 |
| MDE / ITT | 最小可检测效应 / 按随机分配统计主效应；有效执行子样本用于诊断，不能替换随机化主比较 |
| 中介 | 干预到结果之间发生变化的可测变量；不能为“控制公平性”把它锁死 |

## 数字口径

相对提升=(新值/旧值−1)×100%；绝对差=新值−旧值。概率从.20到.22，是+0.02、+2个百分点、相对+10%，三种说法不能混用。指标本身如果以百分数记，5%对应概率.05。作者另定义ΔAUC=(AUC增量)/(旧AUC−.5)时，也不能当普通相对AUC。

新值是旧值2.7倍，不等于+2.7倍；“latency reduction 2.7×”最好同时给原始耗时和口径。算子、attention模块、单用户生成、粗精两阶段、整个服务不是同一成本。若论文未披露全链路P99，就不能据模块结果补算全链路收益。

CI跨0意味着未达到对应置信水平的方向结论，不证明效果为零；p≈.05或“接近显著”应照实保留，不四舍五入成“显著”。多目标有正有负时，把完整取舍留在表里。图中的标准差、标准误、fold极差和置信区间要分别读图注，不能统称95%CI。

“曝光增加→互动增加”可能只是量增；需看每曝光质量及系统总量。“某路召回贡献增加”可能挤占旧路，并非全系统净增。“估计收入、GMV代理、RM奖励”与实际交易额不同。HLT、留存、活跃时长、有效观看等同名近义词，以各文定义和窗口为准。

## 证据标签

- **【论文证据】**：原文实际给出的观察、实验或形式定义。它支持到哪里，须同时写对照和条件。
- **【作者解释】**：作者对结果的机制解释；没有独立中介/消融支持时不自动升级为事实。
- **【我的推断】**：本库的假设、迁移预测和实验建议；可用于提出下一步，不能冒充论文结论。
- **【证据缺口】**：未知、冲突或未识别的环节；待核验不表示论文必错。

复核表的“通过”表示笔记中对应字段与访问到的原文一致，不是实验独立复现、方法一定有效或所有原文论证正确。“已修正”可能是事实纠错，也可能是补充边界/实验，不等于旧稿所有内容都错；重大修正记录会区分。
