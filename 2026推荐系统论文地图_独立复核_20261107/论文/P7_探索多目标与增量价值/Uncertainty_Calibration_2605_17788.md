# Uncertainty Calibration

**完整题名：** Uncertainty-Aware Adaptive Recommendation across User Lifecycle

## 1. 身份与选题边界

Bob Junyi Zou et al；Stanford与ByteDance，线上是未命名的大型直播平台。abs仍显示旧题名“Uncertainty-Calibrated Recommendations for Low-Active Users”，v2正文题名扩大至整个用户生命周期；同ID去重。 首次公开：2026-05-18；会议日期：2026-08-09—2026-08-13（KDD 2026）；最新版本：v2；最新修订：2026-05-25。

主问题：P7_探索多目标与增量价值；次级标签：风险评分、经验Bayes、低活保护、高活探索。低活用户对负体验敏感、高活用户需要兴趣探索，且已有固定CTR主干时考虑；先验证risk是否真有增量信息。

一手入口：[版本原文](https://arxiv.org/html/2605.17788v2)；[作者与版本记录](https://arxiv.org/abs/2605.17788v2)。核验日：2026-11-07（Asia/Shanghai）。本轮重新取得原文与可用附录；旧笔记仅用于识别需要纠正或补充的说法。

## 2. 输入、计算与训练/服务路径


两种单次前向风险信号：EPE critic输入DCN共享表征、基础分数等，MSE拟合冻结旧checkpoint在新一天样本上的实际误差，按日训练，尽量避开同批拟合误差虚小；概率头学习输入相关Beta先验，$\alpha=1+softplus(a)$、$\beta=1+softplus(b)$，以type-II边际似然训练，方差 $\alpha\beta/[(\alpha+\beta)^2(\alpha+\beta+1)]$ 作概率风险。底座与critic阶段的冻结需遵循时序，不能用训练内误差当泛化风险。

EPE含偏差、方差和不可约噪声，不能直接叫“纯认知不确定性”。【我的推断】若按每样本一次二元标签的Beta–Bernoulli边际似然实现，则只识别均值 $\alpha/(\alpha+\beta)$，不单独识别浓度 $\alpha+\beta$；论文未充分披露额外重复观测、约束或正则如何识别这个量。因此Beta方差的“epistemic”解释比误差排序证据更弱，不能据该推导断言未公开实现必然错误。

用校准集分位数（示例95%）定阈值。月直播观看天数<7为LAU，任一risk超阈值即基础分减固定D；≥7为HAU，基础分加 $\omega\max(U_{point},U_{prob})$。这叫UCB原则，但没有统计置信覆盖保证；两个risk量纲如何统一未充分说明。仅在请求已可得特征上算分，未来反馈只用于训练，模型/阈值更新完整SLA未给。

## 4. 六环收益链与可证伪机制

①【论文证据】模型误差随样本变化，用户活跃度不同 → ②【论文证据】两risk头和分层调分 → ③【作者解释】低活避开脆弱预测、高活探索未知兴趣 → ④【论文证据】误差相关性、标签覆盖；【证据缺口】risk是否纯认知量、曝光→早退→长期活跃的因果中介 → ⑤【论文证据】HLT7小增但部分消费下降 → ⑥【我的推断】需risk含可行动信息、活跃分层稳定且可接受短期消费取舍。

**机制归因强度：弱。** 误差排序和随机降权对照支持risk含信息；纯认知不确定性识别、匹配干预强度及完整业务中介不足。

**替代解释与适用分层：** 降权新直播、内容年龄、整体曝光削减或改变内容类型都可能带来效果。高risk且低活群体可能受益；高活探索若只引入噪声、短期标签不对应兴趣则可无效。

**可证伪对照：** 在同活跃层、内容年龄、基础分和相同降权数量/幅度内随机打乱risk，另做活跃层×加/减分实验；不固定最终风险曝光这一中介。对Beta增加重复观测/已知噪声的半合成检验，区分均值校准与浓度可识别。若shuffle同样有效，则否证risk选择而非干预量起作用。

## 5. Pipeline、基线与选型关系


基线保留DCN与现有召回，增加风险critic/概率头和分层调分；多头、MC Dropout是风险估计基线，不是同成本系统替换。对照随机降权有价值，但若干预量不匹配，不能完全区分“选对risk”与“降权更温和”。


- URED：**互补**。风险调分可与回收召回同用，但URED高分池不等于低risk；须测交互。
- PinEqualizer：**仅思想相似**。两者有探索加分，但PinEqualizer先修全漏斗供给与校准，不能只拿一个UCB公式替代。

## 6. 七问迭代卡


1. **何时用？** 低活坏体验与泛化误差相关，且不同生命周期需要不同策略。
2. **改哪里？** 已有分数后的risk策略和时间外critic；不先重构全链路。
3. **最可信机制？** risk能排序部分误差；纯epistemic与长期机制未充分证明。
4. **最小实验？** 时间外样本校准，等降权量risk/shuffle对照，分活跃层试加减分，Beta浓度另做可识别检验。
5. **中介/护栏？** risk曝光、早退、复访/真实活跃小时、标签复消费；观看时长、供给年龄和低活流失护栏。
6. **失败怎么分？** 机制：只减少曝光而非选对内容；实现：分数尺度/阈值错；数据：误差泄漏或噪声混淆；场景：活跃分层不稳定。
7. **何时扩量/停止？** 建议先澄清主指标定义与时长取舍，CI排除预设伤害再扩；risk无增量或短期损害超过容忍则停，不照搬95%/D。
