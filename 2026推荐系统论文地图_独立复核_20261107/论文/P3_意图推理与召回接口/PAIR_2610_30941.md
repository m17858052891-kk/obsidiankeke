# PAIR｜独立复核笔记

> 本轮核验：2026-11-07（Asia/Shanghai）。按2026-05-01至2026-11-07首次公开窗口；阅读本轮重新取得的一手全文与可用附录，旧笔记仅用于比对。证据标签区分论文结果、作者解释、独立推断与缺口；机制强度不等于论文整体质量或效果大小。

## 1. 身份、来源与选型入口

**PAIR: Preference-Aligned Intent Retrieval for Premium People Recommendation at LinkedIn**。Zhongkai Shangguan et al.；LinkedIn。作者/组织：LinkedIn；实际上线范围见结果与pipeline，不把作者单位视为上线证明。

首次公开：**2026-10-22**；最新版本：**2610.30941v1，2026-10-22**。会议/出版：未在本轮一手页面确认会议发表日期。

一手来源：[版本摘要](https://arxiv.org/abs/2610.30941v1)；[原文](https://arxiv.org/html/2610.30941v1)。已读定位：§3–5；表1–2；方法公式与实验设置。本轮本地快照位于`audit_b/sources/`及`audit_b/new_sources/`；访问日志保留成功与失败，不以旧缓存冒充新阅读。

主问题：**P3_意图推理与召回接口**。次级标签：人员推荐、偏好对比学习、动态意图。应考虑的时机：通用画像相似召回与真实偏好错位，profile完整且可小时更新历史。

## 2. 数据流、目标与训练/服务边界

用户profile与候选profile经共享0.6B文本编码器得到向量；查询侧加最长K=10近期行为物品embedding，经位置注意力聚合后与profile向量归一化融合。历史注意力不以候选为query，因而可缓存；在线不调用LLM。匹配为余弦/点积ANN，Matryoshka支持200/256/512/1024维。

曝光日志构造1正3负，优先同曝光负例不足随机补齐。目标是 $L=-\log[\exp(\cos(q,p^+)/\tau)/\sum_j\exp(\cos(q,p_j)/\tau)]$，$\tau=.02$，不是带reference的DPO。意图融合 $q=\mathrm{norm}(e_q+\gamma e_{hist})$，profile与历史分支先归一化。编码器、历史注意力和投影训练；历史item向量预计算。训练209k查询/440万profiles，测试11.8k查询/93k profiles，按时间切分并过滤无profile样本。

离线每日计算profile向量，近线小时级或接近实时更新历史，历史聚合O(Kd)，索引接现有人员召回。§4.2称Qwen3-Embedding-0.6B，§5.1称内部Qwen-based模型，精确checkpoint未给。模型重训频率未披露。

## 3. 关键结果、负向与预算口径

|位置|对照/条件|结果|
|---|---|---|
|表1，离线|MAR@100，Holistic171 / generic / PAIR无历史 / PATT|.288 / .192 / .436 / .450；主要增量先来自偏好训练|
|历史聚合|GeM / mean或max / attention|.447 / .430 / .431，简单历史合并可能低于无历史.436|
|线上表2|用户随机，按Premium层级/活跃分层，同一下游ranker|CTR+7.5%、Premium retention+2.1%标显著；latency+0.1%、coverage−0.2%未标显著|

实验天数、流量占比、留存定义窗口、CI/精确p未披露。**固定100候选池却报MAR@100=.450**与常规全候选召回理解不一致，指标定义待核验，不能写“全库召回45%”。retention不等于已证实续费率。

## 4. 六环收益链与可证伪归因

1. 【论文证据】通用profile相似未必等于用户点击/职业需求，历史简单平均还可能噪声化。
2. 【论文证据】共享编码器用曝光偏好对比训练，再用位置注意力聚合近期行为并融合。
3. 【作者解释】表征由画像相似转向任务偏好与当前意图；“职业角色互补”是解释而非单独测量。
4. 【论文证据】无历史.436→PATT.450且一般聚合可退化；【证据缺口】缺少匹配难负例/角色互补标签及近期意图命中的专门中介。
5. 【论文证据】CTR与留存同时改善；【我的推断】多数离线收益更可能来自偏好训练，历史为较小增量。
6. 【证据缺口】需profile质量够好、近期行为反映真实需求、ANN更新及时、排序器保留这些人；长期职业成功/续费尚未证明。

**机制归因强度：中**（只评价改动→中介→收益的识别程度，不跨论文排序）。机制中等；偏好训练收益最可信，动态意图仅小增量。替代解释为行业/热门人群曝光选择、负例更难、编码器微调，不一定学到互补关系。新需求明确且有近期行为者预期较强；无历史/频繁误点者可能弱。证伪：同profile模型与负例比较无历史、真实、时间打乱/他人历史；等维等预算，单独评估角色互补配对和后续成功联系，核验MAR定义后再比较。

## 5. Pipeline、基线公平性与关系

条件替换原双塔人员召回，保留ANN与精排。与R2QRec条件替换查询表达；与OneLatent仅思想相似，PAIR不生成SID或隐式理由。依赖profile批处理和行为缓存，一侧LLM向量训练成本仍需单报。

- R2QRec：**条件替换**；人员画像匹配或生成文本查询。
- OneLatent：**仅思想相似**；都利用行为意图，但无相同生成接口。

跨论文数据、基线、资源和目标不同，不按收益数字排名，也不默认组合收益可加。相关论文此处是接口关系，不能替代其单篇证据。

## 6. 七问迭代卡

下列均为可执行建议，非作者已完成的实验或已证实门槛；先按实际GPU时间、吞吐/尾延迟、样本量匹配预算，不强行锁死被研究的中介变量。

1. **何时用**：通用画像相似召回与真实偏好错位，profile完整且可小时更新历史。
2. **改哪里**：共享文本双塔训练和查询端历史融合。
3. **最可信机制**：偏好监督比通用embedding贴任务；角色互补暂属解释。
4. **最小实验**：同候选池/维度/难负例，偏好训练×真实/打乱历史；时间外分新意图用户。
5. **中介/护栏**：核准MAR、独占联系人、真实联系率、历史贡献、覆盖/公平分布、缓存年龄/P99、留存窗口。
6. **失败诊断**：机制查历史是否只热门加权；实现查profile/历史归一化与缓存；数据查曝光偏置；场景查目标是认识相似人还是职业互补。
7. **扩量/停止**：建议先解决MAR定义再以同排序器AB验证真实联系及留存；覆盖显著下降或短期点击不带来后续效果则停。
