# 把论文变成可以证伪的模型迭代

[总索引](00_总索引.md) · [逐篇收益链](02_逐篇收益链路与证伪矩阵.md)

每篇都有独立七问卡；这里给共同记录协议。以下都是本库的实验建议，不是论文已得到的结论。业务阈值应由你的基线波动、成本和可检测效应制定，不借用他人的提升百分比。

## 一张实验卡至少记录这些事实

| 字段 | 应填写什么 | 常见误判 |
|---|---|---|
| 症状和人群 | 哪一步、哪类请求/物品、相对什么基线退化 | 用总CTR猜所有瓶颈 |
| 假设 | 改动通过哪个中介影响哪个目标 | “表达更强所以效果好” |
| 接口 | 输入输出、训练/离线/近线/在线、更新和缓存版本 | 把教师未来反馈当在线输入 |
| 干预 | 每个臂具体改变什么 | 模型/数据/历史/候选同时改却归因单模块 |
| 不变项 | 当前检验所需的混杂控制和预算 | 把待检验中介也固定，导致机制无法表现 |
| 预算 | 训练GPU时、参数/更新量、推理FLOPs、候选数、P99、刷新成本 | 单看参数量或同beam宽就称公平 |
| 中间量 | 有明确方向、单位和分母的变化 | 只看最终业务指标 |
| 验收 | 功效、MDE、CI、护栏、扩量/停机规则 | 方向正就上线；事后换指标 |
| 诊断 | 实现、数据、机制、场景各有可检查项 | 无效就结论“论文不适用” |

## 六类高价值对照

1. **新增信息与推理。** 同上游信息/下游接口，比直接映射、短答案、推理产物、打乱/错配推理；控制token与更新成本。打乱文本改变可读性也可能损害输入分布，所以需包含语义等长中性产物作补充，而非仅一个随机负控。
2. **模型结构与新鲜度。** 结构×刷新策略2×2；结构内比较保持数据快照和刷新相同，刷新对照允许缓存年龄改变。缓存年龄正是机制，不该在刷新两臂锁死。报告命中/陈旧度/P99与业务分桶。
3. **训练节奏与平均权重。** 比周期与同累计权重静态策略，保留逐步时序差异；不要同时匹配每一步梯度，那会消除被检验机制。控制batch归一和优化器，观测梯度分布/方差。
4. **搜索质量与资源。** RGD等带价值head的方法，对普通beam应匹配总推理时间/算力/最终K并报告Pareto曲线。普通beam没有reward调用，不能强行要求reward调用次数一致。生成段快不等于ANN、过滤和ranker端到端快。
5. **身份分辨率与直接监督。** ACT唯一token、冻结唯一token、SID+个性化消歧、扩码本按共同作者人群比较。候选覆盖和训练参数变化单列。码级Recall不能作为真实对象Recall的替代。
6. **评估反馈与额外优化。** ATLAS/Spotify/NOVA对照需同基础模型/工具/知识库及总预算，独立人评或业务标签不参与训练。候选搜索的best-of-N必须报告N和总失败；不能只展示成功上线模型。

## 失败后的四分诊断

**实现问题：**修改有没有实际进入服务？梯度到没到目标参数？冻结标志、loss路由、ID映射、mask、cache版本、策略白名单是否正确？用可审计小样本/梯度检查和训练-服务同输入一致性定位。

**数据问题：**时间穿越、重复、曝光选择偏差、未来标签成熟、稀疏token不足、负样本其实未曝光、特征缓存错位是否存在？先固定可回放快照并按事件时间验证。隐性泄漏能制造漂亮离线数字。

**机制问题：**具体改动生效、中介如预期变化，但目标不变，说明中介可能无效或只是伴随现象；目标变但中介不变，说明收益可能来自替代解释。不要用事后重新讲故事取代预注册假设。

**场景问题：**机制在部分桶成立，却被供给、下游截断、流量/成本或用户目标抵消。报告分桶及总体ITT；“有效执行子样本”用于诊断，不能替换按随机分配计算的主效应。

## 扩量与停止

先做数据/实现验收，再看预算匹配下离线中介和负控，最后做有功效的随机A/B。对短期质量、长期价值、财务目标分别定义观测窗口；未成熟14天复购不能拿第3天数据下结论。若主要目标CI未达预设门槛，就不能借其他显著指标“代替通过”。多次查看/多指标选择需在实验方案中处理。

扩量应同时满足：假设预测的人群和中介方向得到独立复现、主要业务目标达到事先定义的经济与统计门槛、资源和质量护栏满足、失败/回退与新增维护成本可控。停止条件包括机制负控同效、简单方案等效、只有自评升、预算超界、主要收益依赖不可用线上信息，或合理功效下重复无效。

最终以“这条机制在我系统的哪个范围成立”归档，而不是给论文贴永久有效/无效标签。
