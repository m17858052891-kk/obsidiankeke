## 哪些修正会改变模型迭代判断

| 修正 | 对选型/实验的影响 |
|---|---|
| SARA评估是5K条实例，不是55K；作者不重叠不等于5K名唯一作者 | 校准对评估规模与泛化证据强度的判断 |
| UniRec工业数据GAUC与RecFlow GAUC不是同一协议 | 撤销不同数据集数字被误判为冲突的结论 |
| OneLatent课程按用户活跃度高→中→低，而非转化/点击/长播阶段 | 复现时按真正的样本难度/人群分层设计训练 |
| LazFormer线上QPS−12.1%；UniPinRec FP8延迟+6.7%且业务A/B使用BF16 | 算子更快、吞吐更高不能替代用户延迟与业务配置核对 |
| OxygenREC补回折扣reward归一化；OneTrans-GSR区分分母ε与输出floor，规则优势独立标准化 | 避免loss尺度与reward实现错误，使最小实验可复现方法本意 |
| RGD/TSGR/UniPinRec的表文或单位差异未强行消解 | 使用原始值、完整协议和待核验状态，不按可疑百分比决策 |
| ACT跨不同标签空间的loss保证存在论证缺口，GPBM学习F的有限样本偏差仍可能增加 | 实测收益与理论/机制解释分开，保留小数据与真实曲线反例 |
| RecIS在2025已有同框架报告 | 2026新增披露与新增发明分开，不重复计算框架首创 |
| X-Rec/UniPinRec/RecGPT-V3等实验允许候选身份或唯一数随方法改变 | 固定输入目录、数量与资源等混杂条件，保留待验证的候选覆盖中介；等候选诊断另列 |
