## 2. 研究问题与旧 pipeline：先分清“预测长期结果”和“估计长期增量”

根据正式题名，任务是用短期实验数据离线估计推荐系统长期因果效果。其业务价值首先是**改进策略评估与上线决策**，不能自动归类为发券策略或长期RL策略优化器。

下面是问题的通用表示，**不是STEAL原文符号或公式**：新实验拥有决策前特征 $X$、随机策略 $T$ 和短期行为 $S$，但长期结果 $Y$ 尚未成熟；历史数据可提供 $S$ 与成熟 $Y$ 的关系。目标可能为 $E[Y(1)-Y(0)]$ 或 $E[Y(1)-Y(0)\mid X=x]$。究竟论文主对象为ATE、CATE还是策略价值，需原文最终确认，不能因为转载提PEHE就直接认定全部结论是CATE保证。

一个自然旧流程是：历史数据学 $h(X,S)\approx E[Y\mid X,S]$；把实验组和对照组短期行为都转为预测长期结果；再比较两组均值。该 surrogate-index 路线在[原始研究](https://arxiv.org/abs/1603.09326)中有明确条件，核心包括代理的充分性及跨样本可比较性。它不是“长期预测AUC高”即可成立的推断。

例如一个活跃用户自然拥有更高短期点击和长期留存，预测器可以很好地捕捉这种相关性；但若新策略靠诱导点击提高短期点击，模型可能把“自然活跃者的点击—留存关系”错误外推到“策略诱发点击”。实验随机化消除了策略与基线用户特征的混杂，**没有自动使处理后的点击成为对长期结果无偏的因果代理**。这是该类问题的识别难点，不是对STEAL具体假设的断言。

**待核的核心数据合同：** 样本单位是用户、请求还是实验；处理是短期冲击还是持续推荐策略；对照具体为何；长期outcome及起止窗、estimand、删失/复购重复计数、日志与RCT怎样连接均未知。训练所需伪标签、网络loss、约束以及部署仅评估还是参与策略生成也未知。下面通用符号不可填补这些空白。

## 5. 识别对象和假设需要逐项核对

正文未获，以下是审稿式检查清单，不是论文已满足的假设列表：

1. **处理持续多长时间？** 短期冲击与长期持续推荐政策是不同干预。持续政策可能在短期代理观测后继续直接影响Y；[Tran等的原论文](https://proceedings.mlr.press/v235/tran24b.html)专门说明了这种区别。不能把短期处理的远期效果偷换成长期持续处理的效果。
2. **历史数据与当前实验如何关联？** 仅特征边际重合，不保证同一短期行为对应相同长期结果；需要明确跨时间/跨策略的机制不变性。
3. **短期S是否足以承载政策影响？** 多个代理可能补足路径，也可能共同遗漏延迟/满意度路径。网络更复杂本身不证明代理充分。
4. **伪策略标签是否依赖S或Y？** S为处理后变量，若把按S筛选的群体当成随机处理组会产生选择问题；必须核对作者是否用识别式和独立样本校正。
5. **支持域与删失如何处理？** 新政策诱发的行为模式若历史中不存在，长期映射是外推；长期流失/活跃样本选择也可能污染训练标签。
6. **目标人群与权重是什么？** 实验总体ATE、条件效应、可观察用户群和平台总价值不能混用。个体PEHE无法在普通真实数据中直接观测，需要合成反事实或其他设计说明。

## 6. 收益链路：每一跳都需要独立证据

以下为【分析推断】与【待验证假说】，并非STEAL已经报告的消融；【原文事实】尚只到论文题名/登记，具体模块是转载线索。

|跳转|可能机制|当前论文证据|可证伪验证|
|---|---|---|---|
|历史/在线对齐→减少迁移偏差|历史成熟标签能更贴近当前策略诱发的短期行为|只有转载线索，无识别公式|按实验整组留出并向后滚动回测；比较原始/加权/候选对齐；只看训练分布匹配不能通过|
|区分自然行为与政策诱发行为→长期效应更准确|不把高活跃用户的自然长期优势全部当成干预贡献|没有可核机制消融|在短期响应弱、长期响应强的成熟RCT组上比较方向、偏差与分群校准；A/A结果应在统计不确定性内与零效应相容，并检查多次A/A的伪阳性率|
|异质建模→避免均值抵消|同样点击变化对新老用户可能代表不同留存路径|没有可核attention消融|固定参数量比普通MLP/分组模型；检查人群异质效应及跨实验泛化，不只比总体MSE|
|效应估计更准→上线选择更好|减少错上短期套利策略、漏掉长期有益策略|转载只有“真实A/B估计更好”，未见策略选择试验|以成熟长期RCT为真值，报告top-policy regret、正负号错误率和误上线率；PEHE改善不足以证明|
|选择更好→平台净长期收益增加|正确策略持续运行，长期留存/交易收益累积|没有可核净收入/利润增量证据|把“评估规则”随机分配到独立实验池或做前瞻验证，保留长期holdout；算净收益并看护栏|

【待验证假说】三个候选模块需各自闭合经营链：伪策略标签/对齐若减少历史到新实验迁移偏差，应让同一批候选策略的长期效应更准，冻结上线阈值后减少误上线；例如某新促销诱发的点击不能照搬自然活跃点击的LTV。替代解释是更多历史数据或一般重加权；等信息/等容量对照持平便不能归功伪标签。分离政策诱发行为若有效，应在短期强长期弱的成熟RCT中下调套利策略；若只是重标活跃人群、A/A假阳性增加则失败。交互attention若刻画异质性，应让新客/老客的相同短期变化得到不同且校准的长期效应，进而改变固定规则下上线决定；若同容量分组MLP相同、跨实验校准不改善，则attention贡献不成立。所有路径均要执行策略后由长期holdout确认净收益，当前没有原表支持最后一跳。

最后一跳尤其容易被跳过：在已完成A/B数据上估计得更准，证明的是评估能力；它并不等于已经用该评估器创造了新增GMV或LTV。

## 7. 实验、最强baseline和数值结论

**本轮不能报告STEAL的最强baseline、PEHE下降比例、估计误差值、线上业务收益或消融幅度。** 转载只说仿真PEHE和真实A/B估计优于基线；没有可核原表、实验时间、样本量、真实长期窗、数据划分、标准差或置信区间。不能据此写“SOTA”“已经在线提升LTV”或“显著优于LOPE”。

收到全文后应优先检查：合成DGP是否为方法定制；是否按用户随机切分导致同实验/同策略信息泄漏；是否按实验留出；所有方法是否使用同样成熟标签与短期窗口；上线前是否冻结选择规则；真实数据的效应真值如何定义；基线是否在相同调参预算下比较。

## 8. 可先做的最小迭代

| 项目 | 可执行约定 |
|---|---|
| 适用症状 | 短期指标与成熟长期RCT常反向，历史surrogate在新策略上系统失准。 |
| 数据前提 | 完整成熟实验档案：实验分组概率、处理持续时间、基线X、同窗短期S、长期Y、删失与成本；按实验划分。 |
| 最小改动 | 先建通用surrogate回测基础设施；全文缺失前不实现猜测的STEAL。 |
| 固定项 | 同候选实验/策略、短期窗口、成熟标签、样本权重、调参预算及预先冻结决策规则。 |
| 对照组 | 短期指标、简单surrogate index、条件符合的LOPE；将来模块逐一加。 |
| 中间诊断 | 跨实验/跨时迁移、A/A假阳性、代理支持、分群校准与区间覆盖、标签泄漏。 |
| 最终指标 | 长期ATE绝对误差/符号错误、policy selection regret/误上线率；前瞻净利润与留存。 |
| 失败判据 | 按用户随机切分好而按实验外推失败、A/A系统偏离、决策regret不降则不采用。 |
| 后续投入条件 | 成熟RCT回测显示可解决的偏差且取得论文/代码与识别说明后，才做方法实现；最终需前瞻评估规则验证。 |

这是通用验证方案，不是STEAL复现。即使回测ATE更准，也只支持评估模块；要证明创造业务增量，还要冻结评估规则并执行实际策略比较。
