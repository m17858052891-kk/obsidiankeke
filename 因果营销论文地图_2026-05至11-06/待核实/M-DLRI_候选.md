## 2. 这篇试图改变什么

题名与摘要索引对应的问题是：一个营销对象同时接受多类激励，各类又有多档强度，真正要估计的是整个组合相对于参照组合的增量。单杠杆分别估计后相加会漏掉交互；每种组合独立建头则会迅速耗尽参数和样本。以上方法线索来自摘要索引；具体到论文里究竟把“用户、商品、推广者”哪一个作为样本单位，尚需全文确认。

**【分析推断】为了说清问题而定义的通用符号，并非复写论文公式：**设决策前特征为 $x$，多杠杆动作 $a=(a_1,\ldots,a_K)$，结果响应为 $m(x,a)=E[Y(a)\mid X=x]$，增量为 $\tau(x,a;a_0)=m(x,a)-m(x,a_0)$。例如两个二值杠杆的交互是

$$
I(x)=m(x,1,1)-m(x,1,0)-m(x,0,1)+m(x,0,0).
$$

若两个补贴单独都能促成同一笔原本不会发生的交易，同时投放也只产生一笔成交，联合收益就可能小于两者单独收益之和；若一个激励吸引用户、另一个激励让推广者愿意投放，二者可能互补。这解释了为什么“各渠道单独ROI最高”未必对应“联合方案最优”。这是机制分析，不是该论文已报告的实验结论。

## 3. 旧 pipeline、候选新结构及替换边界

|原有层|典型做法及局限|M-DLRI目前可定位的候选变化|仍需保留/另做的层|
|---|---|---|---|
|实验与日志|各杠杆分别实验，组合覆盖少|未发现证据表明本文替换实验设计|联合随机化、处理概率、样本单位与干扰控制|
|响应/增量估计|独立单杠杆曲线相加，或每种组合单独建头|摘要指向联合单调编码与低秩交互，是主要替换层|混杂识别与数据支持不能靠架构自动解决|
|预算优化|将预测收益与成本交给MCKP/LP/启发式优化|可为优化器提供组合响应；是否提出新求解器未知|预算、频控、资格、成本及支持域约束|
|效果解释|给出单个预测值，难追溯杠杆贡献|摘要称支持 traceability；具体归因定义未知|归因的因果有效性、交互项分摊规范与可重复性验证|
|长期决策|单次干预/当期结果|没有证据支持替代长期MDP|状态转移、延迟价值、跨期成本仍需独立建模|

摘要索引提示的结构可概括为“多杠杆强度 → 联合单调表示 → 低秩联合响应”。**不能继续补写**其中的embedding维度、激活、对数门控式、rank、loss权重、propensity或训练细节，因为这些尚未直读。

低秩为什么可能有用？通用CP张量分解把组合参数张量写成若干逐维因子的乘积之和，参数规模可从 $\prod_k L_k$ 降为约 $R\sum_k L_k$，其中每杠杆有 $L_k$ 档、rank为 $R$。这是标准结构的解释，**不是已经核实的M-DLRI精确复杂度或原式**。它用共享降低稀疏组合的估计方差，也会引入低秩偏差；真实交互很复杂时，压得过低会抹掉有价值的组合。

单调结构是形状假设，不是识别假设。加强激励后响应不下降，可能对某个处理范围及某种转化指标有帮助；但利润扣除补贴成本后不必单调，过度促销、跨商品挤占、需求提前也可能破坏长期响应单调性。不能将摘要中的“严格联合单调”改写为“任意增加补贴都增加平台净收益”。

## 4. 因果对象与识别：目前必须留空的关键部分

**样本单位、处理/对照具体杠杆与档位、outcome、效果观察窗、estimand以及部署所需信息均未核。** 摘要的GMV/Sales只提示结果方向，不能补出因果数据定义。训练目标/约束精确式、部署分配器、成本、rank、超参和执行资格也未核。正文未取得，不能断言论文采用了随机数据、unconfoundedness、IPS、DML或任何具体因果校正。要将组合响应差解释为因果量，至少必须审查：处理前共同原因是否被控制；每个目标组合是否有正支持；处理定义是否一致；单位之间是否干扰；用户/商品/推广者层级是否混用。它们是我们对识别有效性的检查要求，不是宣称论文已写出并满足了这些假设。

尤其要区分“在未出现的组合上能计算一个数”与“该组合效果已被数据识别”。CP可以表达并外推组合，不能凭空创造随机对照证据。所谓“因果可追踪”也需核查究竟是代数分解、梯度解释、Shapley分摊，还是有独立干预定义的杠杆效应。

## 5. Baseline、结果和消融：哪些数字不能直接拿来讲收益

本轮没有主结果表，因此**最强baseline、是否同预算同容量、误差条、显著性、消融全部未核**。[XTNet原论文](https://arxiv.org/abs/2511.01641)确实处理多类别多档处理，分开基础效果与交叉效果，并使用动态mask；Crossref登记的M-DLRI参考文献包含该作。这说明比较对象相关，不能证明XTNet就是M-DLRI主表中最强基线。

|来源|出现的数字|本卡处理|
|---|---|---|
|OpenAlex摘要索引|GMV +5.35%，Sales +7.26%|仅记为摘要索引声称；未核基线、样本、时长、成本和置信区间|
|智源转载|15类处理下 Root-PEHE 1.145→0.854；ROI +0.86%|保留追查线索，不作为本轮正式实证结论|
|tool.lu摘要|incremental ROI约+7%|指标与前两者不一致；不可任选一个或混称“ROI最高+7.26%”|

以上数字未必互相矛盾：可能来自不同版本、不同实验或不同指标。但在正文缺失时不能替作者解释差异，也不能把GMV变化换成利润或增量ROI。PEHE更好不自动推出策略收益更高；有监督评价权重、政策实际选择的组合分布和成本都可能不同。

## 6. 收益链路逐跳拆开：机制、证据、证伪

以下是【待验证假说】，不是论文已证实的因果贡献分解；【原文事实】只到题名/元数据，架构为摘要索引声称。

|链路|为什么可能发生|目前论文证据边界|可证伪实验|
|---|---|---|---|
|联合表示→少漏掉杠杆替代/互补|同一预算的两种补贴可能重复购买同一增量；交互模型可避免重复计价|摘要索引支持设计动机，正文未核|对少数高流量两杠杆做2×2随机实验，检验交互差分的符号、幅度；与独立相加模型比较|
|低秩共享→稀疏组合误差下降|不同组合共享每杠杆因子，减少独立头的方差|没有可核rank扫描或稀疏度消融|按组合样本量分层，固定参数预算比较独立头、联合MLP和低秩；若只在密集组合改善，则“缓解稀疏”链未获支持|
|单调结构→响应曲线更稳定|排除数据噪声造成的局部倒挂，优化器不再挑伪峰值|没有可核形状消融|固定low-rank，仅切换单调约束；用随机剂量实验检查单调是否真实，观察错设时的损失|
|误差下降→选到更好的组合|优化器使用的是动作间差值，而非单个响应值|没有主表或选择规则证明此跳|固定同一成本/预算优化器，看随机holdout上的policy value、regret及净增量；不能只看事实MSE|
|组合改善→平台净收益提升|降低重复补贴、将预算挪向真正互补的组合|摘要索引有线上增量声称但设计未核|同时记录增量GMV、补贴成本、贡献利润、跨商品挤占、后续回落；保留no-treatment及长期holdout|

【分析推断】把逐模块链落到执行：联合编码让“广告+返利”可与各自单投比较，低秩让稀疏组合分数更稳，单调约束减少优化器挑伪峰值；三者均须经同一固定成本/资格/预算分配器改变动作，才可能减少重复补贴并增加平台净值。单看响应误差不能证明动作改得对。替代解释分别是更多参数/特征、一般共享正则与过拟合抑制；应加入同容量联合MLP、一般L2/早停及无约束模型。若等容量后优势消失、交互符号与随机2×2不符、真实剂量存在倒U且约束策略损失，分别推翻联合结构、低秩必要性或单调适用性。

归因展示本身通常只改变可解释性；除非证明它使运营纠错更快或策略改进更有效，否则不能给“可追踪”模块单独分配线上收益。【待验证假说】例如运营通过分摊解释发现某杠杆只是重复补贴，先复核后关闭该杠杆，才可能节省成本。替代解释是人工规则本就能发现；中间诊断为解释稳定性、随机干预后的贡献符号与纠错时间；若解释变化不影响任何决定或误导关停正增量杠杆，则该收益链失败。

## 7. 最小迭代顺序

| 项目 | 可执行约定 |
|---|---|
| 适用症状 | 多个补贴各自正向、叠加后ROI下降，组合样本稀疏。 |
| 数据前提 | 两杠杆有限档位的联合随机实验、组合分配概率、平台成熟结果和完整实际成本；先确定样本/干扰单位。 |
| 最小改动 | 通用联合响应基线；低秩与单调单独加入，明确不是论文复现。 |
| 固定项 | 同数据切分/标签窗/容量/计算与调参预算、候选支持、预算优化器。 |
| 对照组 | 独立相加、同容量联合MLP、XTNet式交互；低秩×单调2×2。 |
| 中间诊断 | 随机交互差分、组合/样本量分层误差、rank敏感性、单调违例与外推比例。 |
| 最终指标 | 目标预算下随机policy value、实际补贴/触达、平台GMV/净贡献和长期回落。 |
| 失败判据 | 交互不校准、强对照持平、单调错设导致亏损、支持外组合占优即停止。 |
| 后续投入条件 | 取得正式全文/配置且通用诊断证实本地痛点，才决定具体M-DLRI实现；线上需独立随机验证。 |
