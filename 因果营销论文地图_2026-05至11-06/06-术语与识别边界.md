# 快速术语表：避免把不同的“因果收益”混成一件事

返回 [阅读入口](00-阅读入口.md)。本页是阅读辅助定义；具体论文的单位、归一化和假设以单篇为准。

|术语|本库含义|易混淆点|
|---|---|---|
|Treatment / 干预|可执行的动作，如发券、触发召回、改变预算|核销、曝光、购买可能是其后果，不必然是同一个干预|
|ITE|同一个体两个潜在结果的差|通常只能观察其中一个，不能从日志直接取得个体真值|
|CATE|给定投放前特征的人群平均处理效应|很多论文称ITE网络，实际上输出CATE；不是复原个体真值|
|Uplift|一般指相对对照的增量，但具体定义依论文|营销日志的相关差异未必具有因果解释|
|Propensity|处理分配概率|业务“购买倾向”是响应概率，两者不同|
|Overlap / 支持|待比较人群或状态确实有机会接受各动作|模型能输出一个分数不意味着该动作可由数据识别|
|可忽略性|给定已记录投放前变量后，没有剩余影响分配和结果的共同原因|不能通过网络层数、IPS或DML名字保证|
|IPW / IPS|按分配概率重加权|概率错误、极小权重分母、未记录混杂均可造成问题|
|DR / 双重稳健|在规定识别条件下，结果或分配模型之一正确可使特定估计量一致|不等于对任意双错、截断、联合训练、分布外动作仍无偏|
|正交化|让目标对某些辅助模型小误差的一阶敏感度降低|降低估计误差影响，不创造缺失的识别信息|
|OPE|利用历史数据评估新策略|模型型OPE依赖转移/回报模型；线上随机试验是不同证据|
|ITT|按被分配的动作比较总体结果|发券未核销也保留在发券组；按未来核销筛选会改变问题|
|SUTVA / 无干扰|一个单位的结果不受别的单位分配影响等条件|分享、商家替代、共享供给可能违反|
|GTE|全量施行一套策略与全量另一套策略的效果差|网络场景中不一定等于混合流量下个体实验差|
|AUUC/QINI|排序后累计增量曲线的面积/相对基线面积|实现、归一化、数据分配不同，不能跨论文直接比较值|
|LP / MCKP|线性规划/多选择背包，按预算等约束选动作|求解器不会修复错误的增量输入|
|CMDP / occupancy|带约束MDP；状态—动作长期占用量用于表达策略|模型中的期望预算约束不等于线上每一天绝不超支|
|No-op|保持当前动作或不干预|在证据不足时是有价值的候选，不是优化失败|
|百分点与相对百分比|10%→12%为+2个百分点、相对+20%|15pp不能写成15%|
|nss|统计上未拒绝零差异|不等于零影响，也不等于通过非劣或等价检验|

有三种结果必须分开：**估计量更准确、策略在离线评估中更好、策略在线上带来经营增益**。前者可以促成后者，但不能代替后者的验证。另一个维度是估计对象：用户、商家、渠道、网络或跨期策略都可能合理，却不应混用。

## 第二轮补充术语

|术语|含义|迭代时的边界|
|---|---|---|
|CEM|粗化精确匹配，在离散协变量单元中配对|丢弃无共同支持单元会改变目标人群；不能消除未记录混杂|
|Matched ATT|匹配后处理人群的平均处理效应|不是自动等于全部曝光者或全渠道的效应|
|ROPE|实际业务上与零差异近似等价的区间|阈值要有业务依据；跨边界的区间不能判等价|
|HDI|贝叶斯后验最高密度区间|不是无条件的频率置信区间；反复查看保证需另校验|
|CVI|Teads中每单位支出的转化强度，是CPA的倒数|campaign平均log比与全平台加总转化/支出不是同一个量|
|CPC（Ad-POM）|Conditional Pairwise Correctness，同meta下奖励差正确|此处不是cost per click；比只保持排序更强|
|剪枝误差/对偶间隙|分别来自删除候选方案、整数问题放松|小的对偶间隙不能自动证明启发式剪枝几乎无损|

## 本轮新增的四个高频边界

- **条件客单不等于客单因果效应。** 各券档转化者不是同一人群；每档转化概率乘该档转化后客单可恢复该档期望GMV，再跨档差分。直接减两个转化者客单不能当共同总体因果客单差。
- **同窗潜在结果。** 一小时推荐后播放与两天自然播放不是同一个Y；两头概率可用于策略，但差值没有标准CATE解释。把网络称为causal不能修复结果定义。
- **ITT与处理后子组。** 随机分组全集的均值差与“看过/采纳建议的人”的差是不同对象。采纳可能受处理和能力影响，筛选后不能沿用随机化证明。
- **上线门槛的目标。** 混合代理显著、北极星显著、平均项目组合回报更高、每项目假阳性受控是不同目标。非显著、等价、非劣也分别需要不同假设与阈值。
