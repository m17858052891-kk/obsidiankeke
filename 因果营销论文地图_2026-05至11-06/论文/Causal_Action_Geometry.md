# Causal Action Geometry：需求水平会漂移，动作之间的相对优劣能否保留

论文：[Learning Deployable Causal Action Geometry under Temporal Non-Stationarity](https://arxiv.org/abs/2610.16644) · [全文v1](https://arxiv.org/html/2610.16644v1) · [PDF](https://arxiv.org/pdf/2610.16644v1)。作者Changjian Liu、Tianyu Wang、Yuwei Xu、Xiaoxuan Deng、Zhilin Zhang、Yong Gao、Chuan Yu、Jian Xu、Bo Zheng；首页明确淘天、北大、港中深等署名。

**独立审计2026-11-07。采用结论：需先补关键条件。** 适合有时间漂移的连续定价/营销响应研究；先确认本地动作排序确实可跨时迁移，并补齐生产reward和策略执行规则。**证据状态：全文及附录已核**（v1，32页；§2—6、附录A—H、Table1—10、Algorithm1）。这里的“已核”指已审阅原始材料，不表示生产配置齐全或已复现证明/实验。首次公开2026-10-12；未见修订；PDF首页自述NeurIPS 2026录用，具体会议日期/正式出版未核。线上实验2026-03-24—04-18早于论文时间，不是首发日期。

**范围：核心连续干预决策，生产案例是定价，不是发券CATE，也不是长期RL。** 本文在参考文献明确引用ReAlloc（2607.28182）；虽然部分作者相同，研究目标、动作、数据和实验均不同，应单独计数。

## 1. 旧流程为何会失败，本文要估计什么

旧流程是把多个时期的商品日志混在一起，学“历史状态+价格→需求”，再选预测收益最高的价格。假设旺季价格高且需求高、淡季价格低且需求低，池化回归可能把季节抬升当作涨价的作用，甚至把价格排序反过来。加入时间特征并不自动说明哪个响应部分能迁移到下一周。【原文事实】§2.2/附录C.2给出了这种排序反转构造；这是存在性反例，不是证明所有pooled模型都失败。

单位是商品—日，$H_t$为处理前历史，$A_t$为相对于历史14日正价格中位数归一化的有效价格，$Y_{t+1}$为下一步需求；参照$a_0\approx1$，目标是一时期条件响应$m_t(h,a)=E[Y_{t+1}(a)\mid H_t=h]$及其动作排序。数据为2025-12-01—2026-03-01的约5.463亿条、830万商品记录。附录H限制$A^*=[0.93,1.08]$，要求至少28个观察日、5个动作档、足够价格跨度和零销量率不超过10%；不能外推到大量零销量新品。

【原文事实】Assumption2.1要求一致性、无商品间干扰、连续动作局部overlap、给定处理前历史的一步可忽略性。跨时迁移还需要“形状近似持续”；这不是由去混杂自动推得。商品替代、商家未记录的库存/活动意图、状态摘要不足都可能破坏这些条件。

## 2. 方法：把漂移的水平与可迁移的动作形状分开

直观理解：先减掉同一商品在参照价格下的基线，再允许整条曲线正向放大/缩小，留下决定哪个价格更好的形状。水平相同不是要求，但动作排序若随季节反转，该假设就失败。

【原文事实】§3的关键对象为：

$$
\Delta_{k,t}(h,a)=\ell_k(m_t(h,a))-\ell_k(m_t(h,a_0))\approx s_t(h)\rho(u(h),a),\quad s_t(h)>0.
$$

候选link为identity与log。identity可消去加法水平漂移，log可消去乘法尺度漂移；log要求条件均值为正且远离零。$\rho$锚定在$a_0$、固定尺度/符号，选动作$\arg\max_a\rho$。profiled loss在每条曲线上优化非负尺度，再按曲线能量归一化，避免仅因数值尺度小而赢得模型选择。近零能量要稳定处理。

流程是 `时段/历史/价格/结果 → cross-fit结果与连续倾向模型 → 正交局部响应pilot → 独立样本选择link/表示/形状 → 可选独立refit → 支持网格内选动作`。§4式1的局部正交score由“残差×核权重/倾向密度”和“结果模型的核积分”组成；先交叉拟合nuisance，再在独立选择集比曲线，避免同一数据既构造pilot又挑模型。Algorithm1/附录F说明三套样本的职责，不能把普通随机训练/测试分割称为该流程。

**生产实现有别于理论估计器。** §6固定320维多模态编码器，按商品互斥cross-fit基线/处理模型并冻结out-of-fold预测，以三层锚定MLP和R-loss式残差目标拟合响应；表示库此时只有一个，按独立时间验证选identity/log。它保留目标与独立选择原则，但不是直接运行理论中的低维核score。完整生产loss、网络宽度、带宽/权重裁剪、统一基线调参算力、在线价格目标与护栏未充分披露，不能把核估计定理无条件套到该神经系统。

训练需要成熟需求、处理前历史、连续动作概率密度与日期；部署用冻结表示、选定link/形状、合法价格候选与业务约束，不需要未来需求。是否优化销量、收入或利润必须先定：附录H.2式9写最大化响应或相应收入/利润目标，未足以重建线上具体reward；最大化需求和最大化价格×需求一般不是同一动作。

## 6. 可执行最小验证

| 项目 | 可执行约定 |
|---|---|
| 适用症状 | 时间内拟合好、换季后价格/剂量排序反转，且业务允许小范围随机扰动。 |
| 数据前提 | 商品时序面板、处理前库存/需求/价格/活动、合法动作及实际利润；成熟一期结果；多个滚动窗口和随机子集。 |
| 最小改动 | 固定现有表示，先比较raw/log锚定及共同支持；再加独立link选择，不先重建大网络。 |
| 固定项 | 同候选价格、同anchor、同目标人群、相同reward/成本、同cross-fit和训练调参算力。 |
| 对照组 | 当前NPM/pooled、Fixed raw、Fixed log、选link；正交pilot/refit分别切换，必要时同护栏no-op。 |
| 中间诊断 | 条件密度/ESS、留出曲线profile残差、anchor敏感性、随机斜率/动作排序、次周形状漂移。 |
| 最终指标 | 时间外独立DR差值及区间、随机实际净利润/GMV/订单、价格幅度、回退与执行率、跨商品挤占。 |
| 失败判据 | 候选共同支持不足、随机动作排序不校准、几何持续频繁失败，或相同护栏Fixed log已持平则不扩复杂度。 |
| 后续投入条件 | 多个新时期稳定超过强基线且收益/费用口径澄清，再投入生产神经实现与规模化验证。 |
