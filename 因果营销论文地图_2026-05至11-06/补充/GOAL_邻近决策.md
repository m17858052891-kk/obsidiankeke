# 快手 GOAL：历史条件生成激励，并控制全局 ROI

论文：**Generative Optimization for Incentivized Advertising with Global Level Constraints**。快手与电子科技大学署名；[arXiv与版本](https://arxiv.org/abs/2608.04421)、[v1全文](https://arxiv.org/html/2608.04421v1)、[正式DOI](https://doi.org/10.1145/3770855.3818423)。审计：2026-11-07。

**采用结论：需先补关键条件。** 可以逐项试金额表示和条件策略；工业离线评估协议、线上分流和支持域不足以支撑直接复制整套收益。**证据状态：全文及附录已核**（正文§1–6、附录A–F），并不代表配置齐全。日期分层：首次公开2026-08-05，arXiv仅v1；正文写KDD会议2026-08-09—13；[Crossref出版记录](https://api.crossref.org/works/10.1145/3770855.3818423)明确online为2026-08-08、print为2026-08-09；不能用索引创建日08-07或会议首日替代。

## 1. 旧流程哪里不足，本文实际替换哪里

【原文事实】旧路线包括响应预测→预算优化、受约束offline RL，以及DT/CDT历史条件生成。作者认为静态响应忽略疲劳，Markov状态容易遗漏历史，固定约束权重需反复训练；普通attention还可能弱化近期行为突变。表1实际对照为DT、CDT、IQL、CAL、TREBI，**并未实比一个配置充分的静态uplift+knapsack**。本文在完整历史上生成金额，输入全局压力$\lambda$学习一族策略。它改变决策系统，不提供新的混杂消除或CATE识别定理；causal convolution仅约束时序不看未来。

处理是当前激励金额，对照策略是相同系统中的其他金额策略/生产策略；样本为用户交互序列。收入、激励成本与跨窗ROI是目标。§2优化累计收入并约束全局收入/成本；没有明确逐金额因果estimand或可识别反事实假设。工业历史是否随机、分配概率、完整观察窗和动作覆盖未披露；合成环境则显式给出疲劳状态与生成过程（附录E），不能混为真实因果证据。

## 2. 输入→模块→输出及训练部署

```text
用户历史状态/动作 → 动态因果卷积DCC + attention → 历史表示
连续金额 → 数据驱动词表 → 从粗到细可加和token
历史表示 + λ → MoE自回归decoder → 金额token → 求和还原金额
历史动作监督预训练 + 多任务奖励模型 → SCPO条件策略优化
上线：当前历史 + 经校准λ → 金额 → 激励广告系统执行
```

【原文事实】§3.2数值词表按分位动态构建，再贪心分解金额；前位代表大额，位置加权next-token目标加强金额精度。§3.1的DCC抓局部变化，attention汇总长历史。§3.3用$\lambda$条件专家门和decoder生成。§3.4除动作模仿，还用多任务行为信号学习奖励；SCPO在不同$\lambda$下采样候选，以**同$\lambda$组内**均值/标准差规范优势，再做PPO clipping与参考策略KL。部署需完整可用历史、词表、生成模型和校准后的$\lambda$；奖励模型主要服务训练评分，不能把其预测当真实干预收益。

【分析推断】收益—成本权衡可写成$r_\lambda=r-\lambda c$以理解；全局ROI约束要依论文§2的拉格朗日形式对齐。§2.2仅凭存在可行策略就声称strong duality，未交代非凸策略类或占用测度等充分条件；不能把条件生成能力解释成任意预算下的最优/硬可行保证。附录A的有限动作阈值推导也不证明复杂生成策略能达到该最优。

## 3. 逐主要模块的收益链

|模块与场景|改动→统计/优化变化→价值/动作→执行→潜在收益|原文事实与证据止点|替代解释、成立条件、诊断及推翻结果|
|---|---|---|---|
|数值词表+加权NTP：大量小额样本掩盖稀有大额|【分析推断】分解金额、增加大位误差权重→长尾金额表示/精度改善→大额与小额价值排序更稳→同预算发合适金额→减少多发/少发损失|【原文事实】§3.2/3.4；表2去tokenizer REV .29对.32，ROI4.89对4.93|【待验证假说】收益超出decoder容量/动作范围变化。固定历史编码、参数、支持域与预算，分金额档检重构误差/策略价值；若仅扩大金额范围才增益或大额校准差则否定|
|DCC+attention：连续看广告后骤然疲劳|【分析推断】局部动态与长历史并用→状态区分疲劳→调整当前激励价值→减少低效连续奖励→可能提高收入/成本效率|【原文事实】§3.1；表2去DCC REV .25，但ROI4.91近4.93、RVR12.29%近12.24%|【待验证假说】局部卷积优于同信息近期统计；普通短历史特征或更多参数也可解释。比同容量attention+显式近期统计；查疲劳分桶响应及动作变化。若相同信息即可追平，或DCC只改善模仿损失，不归因其因果识别|
|λ条件MoE与校准：预算压力临时上升|【分析推断】同模型条件化权衡→避免每预算单独训练→成本/收入曲线可调整→校准λ后生成低成本动作→快速守约保收入|【原文事实】§3.3、§4.3图4、附录D专家路由；表2无λ泛化RVR14.12%|【待验证假说】多λ路由能在相同经营点改善策略；路由变化不证明专家因果分工，选不同经营点也可造收益。相同目标ROI/真实花费比较固定λ、多λ条件普通decoder、MoE；查违约尾部。若只牺牲大量收入才守约或外推λ失稳，则需限制范围|
|多任务奖励模型：真实反馈稀疏|【分析推断】中间行为辅助监督→候选评分可能更稳定→策略有更密集梯度→奖励转向高价值行为→可能增加收入|【原文事实】§3.4；没有单独隔离奖励模型的收益表|【待验证假说】辅助预测带来真实候选价值排序改善；预测留存/深度不等于处理效应；代理偏好可被策略利用。固定策略候选，与独立RCT评分比排序、分布漂移和奖励作弊；辅助分数升而实际收入不升即否定|
|SCPO同λ归一化+clip/KL：不同预算组回报量纲不同|【分析推断】组内比较消除压力尺度差异、限制更新→不把低压力绝对回报误当策略更优→在每约束水平选高效动作→执行后减少窗口违约|【原文事实】§3.4；表2去SCPO ROI4.57/RVR15.64%；并未单独消融组内归一化|【待验证假说】组内归一化有独立收益；整体SCPO还增加训练阶段。固定额外训练量、KL、候选数，比全局/组内归一化；查每λ梯度贡献和RVR；若增益由更多步数解释，不确认组归一化贡献|

|§4.5线上|4周，收入+2.559%、ROI+2.184%，报告p=.03|生产baseline身份、实际花费和每臂人数、逐指标CI未给；“each group 65%”互斥分组下合计130%，待澄清，不能改成6.5%|

【原文事实】IA描述2025-11-05—12、日活约13万、每日曝光约184万，另称“前6天训练/最后1天测试”；日期跨度与7天划分存在未解释部分。工业离线REV/ROI如何对未执行金额评估、是否OPE或奖励模型评分，以及基线搜索/算力公平性未足够披露。附录F标题是Dataset Details但内容为baseline介绍，不能据标题声称配置齐全。合成默认$T=100$、1万轨迹、三种混合行为策略，疲劳按明确递推变化；这是受控机制环境，不是工业长期收益证明。

表2 prose把RVR写成CVR，按表头保留RVR解释。RVR为滑动窗口ROI不达标比例，窗口长度/重叠方式须补。上线DAU/时长“不显著恶化”不构成非劣证明；4周不等于生命周期效果。

## 6. 可执行最小验证（9项）

|项目|执行内容|
|---|---|
|适用症状|奖励长尾、连续交互疲劳明显、预算阈值常变化、固定λ需反复训练|
|数据前提|完整历史、决策前特征、真实收入/付费及成熟窗；局部随机金额覆盖；清楚ROI窗口与预算协议|
|最小改动|先固定当前编码器只比较标量/词表头；再比较同容量近期卷积、λ条件化；SCPO最后加入|
|固定项|支持域、候选用户、实际花费或同ROI经营点、算力/训练步数、奖励模型/评估数据、滑窗长度|
|对照组|标量头、DT/CDT、固定λ与条件λ、全局/组内优势规范、相同额外训练量；生产baseline并行|
|中间诊断|金额分桶误差、近期疲劳分桶动作、每λ校准/梯度、OOD比例、奖励模型与真实随机回报排序|
|最终指标|实际收入/净利润、成本、全程及窗口ROI、RVR与CI、DAU/留存非劣边界、服务延迟|
|失败判据|支持外动作驱动收益、独立评分反向、仅均值ROI达标而尾部违约恶化、真实花费增长解释全部收益|
|后续投入条件|先补线上分流/工业离线协议；模块独立有益且本地小流量同经营点收益达标，才投完整系统|
