# 快手 CASH：只让有证据支持的预测进入广告主补贴分配

论文：**CASH: A Capability-Aware Subsidy Harness for Advertiser Subsidy Allocation**。快手、复旦与天津大学署名。[arXiv及版本](https://arxiv.org/abs/2610.39244)、[v1全文](https://arxiv.org/html/2610.39244v1)。审计：2026-11-07。

**采用结论：需先补关键条件。** 最可借鉴的是“预测可靠范围→可选动作→共享预算”的接口。补贴响应的观察混杂、未执行档位外推和拍卖干扰仍需本地验证，不能把LLM或误差校准当因果识别。**证据状态：全文及附录已核**（正文§1–6、附录A–E）；工业日志、完整prompt/运营特征与部分训练配置未公开。日期分层：首次公开2026-10-29，arXiv仅v1；会议及正式出版日未核。2026-09-14—10-14是线上试验期，共31个锚定日期。

## 1. 问题与旧pipeline：先知道哪个预测可信，才分共享预算

【原文事实】平台用广告主账单折扣和出价提升扶持账户。旧Control是运营经验驱动的分层规则，难在单账户/每补贴档位细分响应。Tool用数值响应模型接预算分配，已经取得明显线上收益；LLM能使用经营背景，但数值准确性并不稳定。CASH将Tool和LLM Agent的收入曲线按已执行动作上的误差和支持度划定允许使用的档位，再决定是否调用LLM、选择哪条曲线、分配多少补贴。少量反馈用于更新可用范围。

独立预算下某账户预测整体乘以常数可能不改变自身最优档位，但共享预算价格会随预计收入/成本改变，进而改变其他账户动作（命题2.1）。这是**优化器内的账户耦合**；实际拍卖中补贴改变其他广告主流量是另一类**市场干扰**，论文的扰动实验不能验证后者的因果效应。

## 2. 处理、目标与三层证据边界

【原文事实】样本为账户—日/决策周期；状态$s$为决策前账户历史、补贴历史与运营信息，动作为账单折扣因子$k$，越小优惠越深。16档$0.50,0.52,\ldots,0.80$加不补贴$k=1$。预测扣费前收入$Q(s,k)$，扣费后平台收入与补贴为

$$
C(s,k)=kQ(s,k),\qquad S(s,k)=\frac{1-k}{k}C(s,k).
$$

策略最大化所有账户扣费后收入，约束$\rho_{min}\le\sum S/\sum C\le\rho_{max}$。附录B部署目标68%、容忍区间[67.9%,68.1%]，这是**补贴/扣费后收入比**，不是给广告主68%的账单折扣。论文没把增量相对no-discount CATE作为训练目标；对照定义在策略层是Control/Tool。

|层次|一手证据支持什么|不能推出什么|
|---|---|---|
|响应估计|§2明确假设状态充分控制旧策略选择，将$E[y\mid s,k]$当干预响应；§4.3只测历史实际档位预测误差|observational拟合好不证明未执行档位无偏；粗支持邻域不等于所有状态的positivity；LLM业务知识不消除隐藏混杂|
|决策系统|§4.1–4.2账户hash分组+A/A平衡，整套CASH对Control/Tool的线上收益|不能将整套收益分摊给LLM、license或EPCG；不直接识别全平台全量替换的市场均衡效应|
|LLM选择与校准|§3.3/3.5对随机审计调用概率$q_j$做IPW，校正哪些样本拿到Agent预测的抽样|这不是补贴处理propensity加权，不能修正旧补贴策略混杂；调用失败/行动外推仍需另查|

【分析推断】共享竞价流量可能使各实验臂相互影响；60% CASH/20% Tool/20% Control的结果对应该混合市场，而非无干扰个人效果。需记录竞争边界、随机化前余额/预算及分配概率，检查全量外推。

## 3. 输入输出、训练与部署模块

```text
账户历史/实际档位/成熟收入 → Tool收入曲线（滚动训练）
账户与运营信息/规则 → 选择性调用LLM Agent → 另一条收入曲线
两曲线 → 单调投影 → 误差范围+有效支持+区域准入 → 各来源许可档位
调用价值/审计抽样 → Judge默认路由 → 争议账户交给独立LLM复核
所选曲线+许可档位 → 共享预算多选背包 → 实际折扣/无补贴
延迟反馈 → 更新许可/模型；EPCG选择有限探索反馈包
```

【原文事实】§3.1 Tool在成熟样本上优化扣费后收入预测损失；LLM一次返回各档曲线。先对扣费前收入作单调投影，再乘$k$，不能对扣费后收入强行单调。§3.2用独立且时间更后的校准集，对误差尺度模型取分位数；许可要求同时满足相对误差界、历史支持和区域准入。支持按账户截断贡献，区域证据用账户级Kish有效样本量、衰减和近似Beta后验；该近似不是严格独立二项后验。

【原文事实】§3.3 Judge是梯度提升树，预测Agent是否胜过Tool；20%常规调用额度，未调用账户5%随机审计只用于学习。独立orchestrating LLM仅复核偏好不清、预测冲突/许可不相交等账户；只能在合法Tool/Agent/Fallback中选，失败回退。附录B预测Agent用Qwen3-Next-80B-A3B-Instruct，编排用DeepSeek-V4-Flash；这是作者版本配置，不是本地已运行。

【原文事实】§3.4把不补贴和探索账户的收入/成本作为固定外部项记入共享预算。两个率约束在正收入且上下界不同下不能同时紧，LP基本最优解至多一个分数账户（附录A）；实际算法仍须取整/单账户交换修复，不保证所有实例修复成功，不能把LP结论当离散全局最优保证。§3.5 EPCG估计新增反馈让当前Tool的**价值加权许可覆盖率**增加多少；固定模型和其他许可条件模拟区域准入变化，按反馈包做多选背包。它不是直接估计新探索动作的长期经营回报。探索账户在冻结合法候选池内随机抽取，记录抽样/取消/替换（附录C）。

## 4. 逐主要模块收益链与可推翻诊断

|模块与具体场景|改动→误差/不确定性→排序/动作→执行→潜在收益|原文事实定位与证据止点|替代解释、成立/失败条件、诊断与反证|
|---|---|---|---|
|Tool+Agent与曲线投影：冷启动账户少数据但有运营信息|【分析推断】利用知识与历史拟合互补、去除不合理金额跳变→响应曲线/尾部误差可能改善→预算器不偏爱虚高档→给合适折扣→收入可能提高|【原文事实】§3.1、图5/表5；Agent在48.77%账户日更准但平均MAE更差，未单独消融投影|【待验证假说】只是加入更多特征/参数也可解释，单调假设受竞价环境影响。统一信息/输出档位，比Tool、Agent、融合与无投影；查稀疏档真实随机响应。若投影压掉真实非单调或Agent只在训练分布有效则失败|
|误差校准+支持+区域准入：某档预测看似好但只有一个大客户反复样本|【分析推断】账户去重有效证据、局部误差范围和准入共同筛选→减少过度自信→剔除不可靠档位→避免共享预算被错误曲线占用→减少尾部经营损失|【原文事实】§3.2/3.5、表2；名义95%经验覆盖约94%，inside/outside超差率6.29/15.08%等|【待验证假说】选择更容易人群也可降误差；非反事实误差保证。固定60%准入/账户规模桶比较、验证未执行档RCT校准；若许可内真实干预误差高或放弃收益巨大，则许可阈值不合适|
|选择性调用+Judge+受限LLM复核：预算只够调用少数难例|【分析推断】预估调用价值选样，随机审计补盲区，许可约束复核→以更少调用获得互补曲线→动作仍限于有证据档位→降低计算费/错配补贴|【原文事实】§3.3、表5/8/10；6,119 calls，full report MAE466.96对无报告479.60，未许可选择66→0|【待验证假说】更小候选集机械使违规归零，并非LLM因果推理变强；表8full report RMSE1805.06略差于仅license1797.35。固定调用额度/预测/难例比随机、Judge、受限LLM；若普通路由同样好或审计样本有系统缺失，LLM额外价值被推翻|
|共享预算分配：一个大客户曲线成倍高估|【分析推断】先限制不可靠档位，再优化全局率→阻断误差通过影子价格影响别人→全账户折扣重分配→同率下收入可能增加|【原文事实】命题2.1、表3的672个数值扰动场景；许可外扰动传播变0|【待验证假说】删动作本就使扰动无效，不证明删的是正确动作；多数档位切换只是同值tie。固定曲线比较有无许可/同样随机删档，测严格切换、约束残差/真实价值；若仅少换档但收益无增则机制未兑现|
|EPCG反馈获取+后续更新：高价值区域证据将过期|【分析推断】模拟新增反馈对区域准入的边际价值→优先补临界证据→扩展可用Tool档位→更多账户可自动分配→减少调用并可能提高收入|【原文事实】§3.5/§4.7表7/9：日志回放按固定配额选已执行样本；覆盖增2.06–2.75点，随机−.37至+.35点；后续RMSE改善|【待验证假说】回放不是在线探索新档位的反事实效果；覆盖率升可能只是门槛变化。固定反馈费用/风险/账户池，随机比较EPCG、随机、误差优先；查后期许可内误差及实际策略值。若扩覆盖却超差/经营损失上升则不采用|

【待验证假说】完整链是“更可靠可用曲线→不同可执行折扣→真实补贴/竞价流量变化→账户及平台收入”。论文整套线上实验支持最后综合效果，但没有在线模块析因实验，无法量化哪一模块贡献了15.35%。

## 7. 可执行最小验证（9项）

|项目|执行内容|
|---|---|
|适用症状|响应曲线在少样本账户/档位误差很大，预算器易选择虚高档，LLM调用昂贵且并非处处更准|
|数据前提|决策前账户状态、实际折扣/分配概率、成熟收入/补贴、调用/失败/审计概率、账户ID、竞价关系；独立随机剂量校验流|
|最小改动|先固定Tool与allocator加账户级误差/支持许可和no-discount；确认净价值后才加LLM及EPCG|
|固定项|候选档位、账户池、历史窗口、同实际预算或同率经营点、LLM信息/调用额度、反馈成本、随机化/干扰边界|
|对照组|Tool、同准入率随机/支持筛选、局部校准许可；Judge/受限LLM；随机/误差/EPCG反馈选择；必要时模块析因|
|中间诊断|已执行/随机未执行档位误差分开、账户有效样本、许可覆盖/超差、call概率/失败、严格动作切换与tie、取整修复残差|
|最终指标|全eligible账户的扣费后收入、绝对补贴、净贡献/留存及账户/市场相容CI；LLM tokens/成本/延迟；长期实际经营价值|
|失败判据|许可内反事实仍偏、删动作损失大于降误差收益、LLM比Judge无增益、时间CI好但随机化CI不足、市场干扰/支出增长解释全部收益|
|后续投入条件|随机支持内证明许可减少尾部损失且不牺牲净值；LLM/探索各自带来超过成本的额外收益，再扩大自动化范围|
