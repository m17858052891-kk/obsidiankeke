# Netflix论文—代码独立交叉核（追加任务）

只读核查，不修改root所写卡片，不声称运行复现。材料：`work/round3/sources/netflix_blending_v1.txt`（论文[arXiv2606.21745](https://arxiv.org/abs/2606.21745)）与root下载的[作者仓库](https://github.com/winston-chou/blending)三个脚本。代码版本固定信息由root另记。

1. **P1：权重公式缺少显著性门槛惩罚。** 论文Eq6/11为$(\Sigma_X+(1+z^2)2\Omega/n)^{-1}\Gamma$，三个脚本都先令` sigma_hat = sigma_x + 2*omega/n`，再`solve(sigma_hat,gamma)`：sim01第55–68行，sim02第41–60行，sim03第39–59行。确实少了$z^2$加权的噪声惩罚，权重不随显著性阈值改变。代码按[Y,P]而论文[P,Y]，但矩阵/Γ已一致换序，不能把此差异归因列顺序。
2. **P1：sim01 launch标准差用总方差。** 论文Eq3/15门槛是$z\sqrt{A^\top(2\Omega/n)A}$，代码sim01第86/89/93行使用` sigma_hat`，其中包含跨实验真效果方差。它让launch规则更保守，且不同指标保守程度不同，改变入选实验、累积回报、winner’s curse；不是无关常数缩放。例默认n=1000时proxy的总方差1.05、采样方差0.05，标准差比约4.58；真实效应离散度被当成实验估计噪声。
3. **P1：sim02/03明确做双侧检测。** 论文§4固定z≈1.645、单侧α=.05；代码`alpha_two_sided=.05`，z取.975分位，最终`abs(t)>z`（sim02第75/104–106行，sim03第73/84–86行）。因此负向显著也计入power/FPR，和“显著大于0则上线”的论文定义不同；即使某些定性趋势相同，也不能据此称复现原图。
4. **P1：单纯绝对和归一不能保证simplex。** 三脚本`w/sum(abs(w))`保留负分量（sim01第62、sim02第46、sim03第44）。论文§3.3步骤4要求负分量剔除重算、步骤6要求小n不足时解Eq5约束优化。脚本没有该检查/fallback；rho=0且采样交叉协方差为正时，inverse covariance会给proxy负权重。这会改变可行策略集合，而不只是读数精度。
5. **P2：模拟次数不同。** 论文§4 R=1000，脚本默认sim01/02/03为500/3000/5000。影响MC精度与图中区间，不独自推翻定性趋势；应在复现配置明确记录。
