## 94. 二叉树的中序遍历

**题目描述：** 返回二叉树节点值的中序遍历（左-根-右）。

**示例：** 输入：`root = [1,null,2,3]`；输出：`[1,3,2]`。

**思路：** 迭代法：栈辅助，先沿左链入栈，弹出时访问，再转向右子树。

```python
def inorderTraversal(root):
    res, stack = [], []
    cur = root
    while cur or stack:
        while cur:
            stack.append(cur)
            cur = cur.left
        cur = stack.pop()
        res.append(cur.val)
        cur = cur.right
    return res		
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)

## 104. 二叉树的最大深度

**题目描述：** 返回二叉树的最大深度（根到最远叶子的路径长度）。

**示例：** 输入：`root = [3,9,20,null,null,15,7]`；输出：`3`。

**思路：** 递归，`max(左深度, 右深度) + 1`。

```python
def maxDepth(root):
    if not root:
        return 0
    return max(maxDepth(root.left), maxDepth(root.right)) + 1
```

**复杂度：**
- 时间：O(n)
- 空间：O(h)，h 为树高

## 226. 翻转二叉树

**题目描述：** 翻转一棵二叉树（镜像）。

**示例：** 输入：`root = [4,2,7,1,3,6,9]`；输出：`[4,7,2,9,6,3,1]`。

**思路：** 递归交换每个节点的左右子树。

```python
def invertTree(root):
    if not root:
        return None
    root.left, root.right = invertTree(root.right), invertTree(root.left)
    return root
```

**复杂度：**
- 时间：O(n)
- 空间：O(h)

## 101. 对称二叉树

**题目描述：** 判断二叉树是否关于中心轴对称。

**示例：** 输入：`root = [1,2,2,3,4,4,3]`；输出：`true`。

**思路：** 辅助函数递归比较「左子树的左 vs 右子树的右」、「左子树的右 vs 右子树的左」。

```python
def isSymmetric(root):
    def check(l, r):
        if not l and not r:
            return True
        if not l or not r or l.val != r.val:
            return False
        return check(l.left, r.right) and check(l.right, r.left)
    return check(root.left, root.right)
```

**复杂度：**
- 时间：O(n)
- 空间：O(h)

## 543. 二叉树的直径

**题目描述：** 找出二叉树中任意两节点之间的最长路径（经过的边数）。

**示例：** 输入：`root = [1,2,3,4,5]`；输出：`3`。

**思路：** DFS 计算每个节点的左右最大深度，路径长 = 左深 + 右深，全局更新最大值。

```python
def diameterOfBinaryTree(root):
    ans = 0
    def depth(node):
        nonlocal ans
        if not node:
            return 0
        l, r = depth(node.left), depth(node.right)
        ans = max(ans, l + r)
        return max(l, r) + 1
    depth(root)
    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：O(h)

## 102. 二叉树的层序遍历

**题目描述：** 逐层返回二叉树节点值（每层为一个列表）。

**示例：** 输入：`root = [3,9,20,null,null,15,7]`；输出：`[[3],[9,20],[15,7]]`。

**思路：** BFS，队列辅助。每一轮处理当前队列中的所有节点（即同一层）。

```python
from collections import deque

def levelOrder(root):
    if not root:
        return []
    res, queue = [], deque([root])
    while queue:
        level = []
        for _ in range(len(queue)):
            node = queue.popleft()
            level.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        res.append(level)
    return res
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)

## 108. 将有序数组转换为二叉搜索树

**题目描述：** 将升序数组转换为高度平衡的 BST。

**示例：** 输入：`nums = [-10,-3,0,5,9]`；输出：一个高度平衡 BST，例如 `[0,-3,9,-10,null,5]`。

**思路：** 取中间元素为根，递归构建左右子树。

```python
def sortedArrayToBST(nums):
    if not nums:
        return None
    mid = len(nums) // 2
    root = TreeNode(nums[mid])
    root.left = sortedArrayToBST(nums[:mid])
    root.right = sortedArrayToBST(nums[mid + 1:])
    return root
```

**复杂度：**
- 时间：O(n)
- 空间：O(log n)

## 98. 验证二叉搜索树

**题目描述：** 判断给定二叉树是否是有效的 BST（左子树所有节点 < 根 < 右子树所有节点）。

**示例：** 输入：`root = [2,1,3]`；输出：`true`。

**思路：** 递归传入合法范围 `(min_val, max_val)`，每次更新上下界。

```python
def isValidBST(root):
    def validate(node, low, high):
        if not node:
            return True
        if node.val <= low or node.val >= high:
            return False
        return validate(node.left, low, node.val) and validate(node.right, node.val, high)
    return validate(root, float('-inf'), float('inf'))
```

**复杂度：**
- 时间：O(n)
- 空间：O(h)

## 230. 二叉搜索树中第 K 小的元素

**题目描述：** 找出 BST 中第 k 小的元素。

**示例：** 输入：`root = [3,1,4,null,2], k = 1`；输出：`1`。

**思路：** BST 中序遍历结果即升序序列，第 k 次访问的节点就是答案。

```python
def kthSmallest(root, k):
    stack = []
    cur = root
    count = 0
    while cur or stack:
        while cur:
            stack.append(cur)
            cur = cur.left
        cur = stack.pop()
        count += 1
        if count == k:
            return cur.val
        cur = cur.right
```

**复杂度：**
- 时间：O(h + k)
- 空间：O(h)

## 199. 二叉树的右视图

**题目描述：** 从右侧看二叉树，返回每层最后一个节点的值。

**示例：** 输入：`root = [1,2,3,null,5,null,4]`；输出：`[1,3,4]`。

**思路：** BFS 层序遍历，每层最后一个节点加入结果。

```python
from collections import deque

def rightSideView(root):
    if not root:
        return []
    res, queue = [], deque([root])
    while queue:
        for i in range(len(queue)):
            node = queue.popleft()
            if i == len(queue):   # 当前层最后一个（已popleft后queue少了一个）
                res.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        res.append(node.val)   # 每层最后处理的节点
    # 修正：直接用下面更简洁的写法
    return res

# 更简洁版本
def rightSideView(root):
    if not root:
        return []
    res, queue = [], deque([root])
    while queue:
        size = len(queue)
        for i in range(size):
            node = queue.popleft()
            if i == size - 1:
                res.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
    return res
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)

## 114. 二叉树展开为链表

**题目描述：** 将二叉树按前序遍历顺序原地展开为链表（right 指针串联，left 置 None）。

**示例：** 输入：`root = [1,2,5,3,4,null,6]`；输出：`[1,null,2,null,3,null,4,null,5,null,6]`。

**思路：** 对每个节点，将左子树插到右子树之前（左子树最右节点接原右子树），重复直到所有左子树为空。

```python
def flatten(root):
    cur = root
    while cur:
        if cur.left:
            rightmost = cur.left
            while rightmost.right:
                rightmost = rightmost.right
            rightmost.right = cur.right
            cur.right = cur.left
            cur.left = None
        cur = cur.right
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 105. 从前序与中序遍历序列构造二叉树

**题目描述：** 根据前序遍历和中序遍历结果构造二叉树。

**示例：** 输入：`preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]`；输出：`[3,9,20,null,null,15,7]`。

**思路：** 前序首元素为根，在中序中找根的位置，左右两侧分别递归构建。用 HashMap 存中序索引加速查找。

```python
def buildTree(preorder, inorder):
    idx_map = {val: i for i, val in enumerate(inorder)}
    pre_idx = [0]

    def helper(left, right):
        if left > right:
            return None
        root_val = preorder[pre_idx[0]]
        pre_idx[0] += 1
        root = TreeNode(root_val)
        mid = idx_map[root_val]
        root.left = helper(left, mid - 1)
        root.right = helper(mid + 1, right)
        return root

    return helper(0, len(inorder) - 1)
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)

## 437. 路径总和 III

**题目描述：** 找出二叉树中节点值之和等于 `targetSum` 的路径数量（路径方向向下，起止节点任意）。

**示例：** 输入：`root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8`；输出：`3`。

**思路：** 前缀和 + DFS。记录从根到当前节点的前缀和，用 HashMap 存历史前缀和出现次数，当 `prefix - target` 在 map 中时说明存在满足条件的路径。

```python
from collections import defaultdict

def pathSum(root, targetSum):
    count = defaultdict(int)
    count[0] = 1
    ans = [0]

    def dfs(node, prefix):
        if not node:
            return
        prefix += node.val
        ans[0] += count[prefix - targetSum]
        count[prefix] += 1
        dfs(node.left, prefix)
        dfs(node.right, prefix)
        count[prefix] -= 1   # 回溯

    dfs(root, 0)
    return ans[0]
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)

## 236. 二叉树的最近公共祖先

**题目描述：** 给定二叉树和两个节点 p、q，找出它们的最近公共祖先（LCA）。

**示例：** 输入：`root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1`；输出：`3`。

**思路：** 后序遍历。若当前节点是 p 或 q 则返回自身；左右子树递归，若两侧都非空则当前节点即 LCA，否则返回非空一侧。

```python
def lowestCommonAncestor(root, p, q):
    if not root or root == p or root == q:
        return root
    left = lowestCommonAncestor(root.left, p, q)
    right = lowestCommonAncestor(root.right, p, q)
    if left and right:
        return root
    return left or right
```

**复杂度：**
- 时间：O(n)
- 空间：O(h)

## 124. 二叉树中的最大路径和

**题目描述：** 路径可从任意节点出发到任意节点，返回路径上节点值之和的最大值。

**示例：** 输入：`root = [-10,9,20,null,null,15,7]`；输出：`42`。

**思路：** DFS，每个节点计算「以自身为最高点的路径和」= 左贡献（正才取）+ 节点值 + 右贡献（正才取），更新全局最大。返回值只能选左或右一侧（路径不能分叉传回父节点）。

```python
def maxPathSum(root):
    ans = [float('-inf')]

    def gain(node):
        if not node:
            return 0
        left = max(gain(node.left), 0)
        right = max(gain(node.right), 0)
        ans[0] = max(ans[0], node.val + left + right)
        return node.val + max(left, right)

    gain(root)
    return ans[0]
```

**复杂度：**
- 时间：O(n)
- 空间：O(h)
