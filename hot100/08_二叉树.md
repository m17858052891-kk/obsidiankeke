## 94. 二叉树的中序遍历

**题目描述：** 返回二叉树节点值的中序遍历（左-根-右）。

**示例：** 输入：`root = [1,null,2,3]`；输出：`[1,3,2]`。

**思路：** 迭代法：栈辅助，先沿左链入栈，弹出时访问，再转向右子树。

**展开理解：** 栈模拟递归调用：一路压入左孩子，是因为中序必须先访问最左节点；弹栈访问根后转向其右子树，再重复同样过程。循环条件要同时检查 cur 和 stack，避免右子树为空时提前结束。

```python
def inorderTraversal(root):
    res, stack = [], []
    cur = root
    while cur or stack:
        while cur:
            stack.append(cur)
            cur = cur.left
        cur = stack.pop()
        res.append(cur.val)
        cur = cur.right
    return res		
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)

## 104. 二叉树的最大深度

**题目描述：** 返回二叉树的最大深度（根到最远叶子的路径长度）。

**示例：** 输入：`root = [3,9,20,null,null,15,7]`；输出：`3`。

**思路：** 递归，`max(左深度, 右深度) + 1`。

**展开理解：** 递归函数返回“以当前节点为根的子树最大深度”。空节点贡献 0，非空节点取左右返回值最大者再加当前层 1；这是典型自底向上的后序 DFS。

```python
def maxDepth(root):
    if not root:
        return 0
    return max(maxDepth(root.left), maxDepth(root.right)) + 1
```

**迭代 DFS：** 栈中同时保存节点和该节点的深度。每弹出一个节点就更新答案，再把子节点压栈。

```python
def maxDepth(root):
    if not root:
        return 0

    ans = 0
    stack = [(root, 1)]
    while stack:
        node, depth = stack.pop()
        ans = max(ans, depth)
        if node.left:
            stack.append((node.left, depth + 1))
        if node.right:
            stack.append((node.right, depth + 1))
    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：O(h)，h 为树高

## 226. 翻转二叉树

**题目描述：** 翻转一棵二叉树（镜像）。

**示例：** 输入：`root = [4,2,7,1,3,6,9]`；输出：`[4,7,2,9,6,3,1]`。

**思路：** 递归交换每个节点的左右子树。

**展开理解：** 翻转一棵树等价于：先分别翻转左右子树，再交换它们的位置。无论先交换再递归还是递归后交换都可，但要保证递归参数不会因原地交换而混乱。

```python
def invertTree(root):
    if not root:
        return None
    root.left, root.right = invertTree(root.right), invertTree(root.left)
    return root
```

**迭代 DFS：** 用栈访问每个节点，弹出后交换左右孩子。先交换再入栈或先入栈再交换都可以，只要所有节点都被处理一次。

```python
def invertTree(root):
    if not root:
        return None

    stack = [root]
    while stack:
        node = stack.pop()
        node.left, node.right = node.right, node.left
        if node.left:
            stack.append(node.left)
        if node.right:
            stack.append(node.right)
    return root
```

**复杂度：**
- 时间：O(n)
- 空间：O(h)

## 101. 对称二叉树

**题目描述：** 判断二叉树是否关于中心轴对称。

**示例：** 输入：`root = [1,2,2,3,4,4,3]`；输出：`true`。

**思路：** 辅助函数递归比较「左子树的左 vs 右子树的右」、「左子树的右 vs 右子树的左」。

**展开理解：** 不能只比较同一父节点的左右孩子，而要镜像比较两棵子树：外侧对外侧、内侧对内侧。任一结构不一致或值不同即失败，两边同时为空才匹配。

```python
def isSymmetric(root):
    if not root:
        return True

    def check(l, r):
        if not l and not r:
            return True
        if not l or not r or l.val != r.val:
            return False
        return check(l.left, r.right) and check(l.right, r.left)
    return check(root.left, root.right)
```

**迭代 DFS：** 栈中保存“需要互为镜像”的节点对。每次比较一对节点，并按外侧对外侧、内侧对内侧继续压栈。

```python
def isSymmetric(root):
    if not root:
        return True

    stack = [(root.left, root.right)]
    while stack:
        left, right = stack.pop()
        if not left and not right:
            continue
        if not left or not right or left.val != right.val:
            return False
        stack.append((left.left, right.right))
        stack.append((left.right, right.left))
    return True
```

**复杂度：**
- 时间：O(n)
- 空间：O(h)

## 543. 二叉树的直径

**题目描述：** 找出二叉树中任意两节点之间的最长路径（经过的边数）。

**示例：** 输入：`root = [1,2,3,4,5]`；输出：`3`。

**思路：** DFS 计算每个节点的左右最大深度，路径长 = 左深 + 右深，全局更新最大值。

**展开理解：** 经过某节点的最长路径等于左子树向下最大边数加右子树向下最大边数。递归向父亲只能返回单侧最大深度，不能返回直径；因此需要一个全局答案在每个节点处更新。

```python
def diameterOfBinaryTree(root):
    ans = 0
    def depth(node):
        nonlocal ans
        if not node:
            return 0
        l, r = depth(node.left), depth(node.right)
        ans = max(ans, l + r)
        return max(l, r) + 1
    depth(root)
    return ans
```

**迭代 DFS（后序）：** 直径依赖左右子树深度，因此必须先算孩子再算父节点。用 `(node, visited)` 标记节点是第一次进入，还是第二次回收结果。

```python
def diameterOfBinaryTree(root):
    if not root:
        return 0

    ans = 0
    depth = {None: 0}
    stack = [(root, False)]

    while stack:
        node, visited = stack.pop()
        if not visited:
            stack.append((node, True))
            if node.right:
                stack.append((node.right, False))
            if node.left:
                stack.append((node.left, False))
        else:
            left_depth = depth[node.left]
            right_depth = depth[node.right]
            ans = max(ans, left_depth + right_depth)
            depth[node] = max(left_depth, right_depth) + 1

    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：递归版 O(h)；上述迭代后序版因保存所有节点深度为 O(n)

## 102. 二叉树的层序遍历

**题目描述：** 逐层返回二叉树节点值（每层为一个列表）。

**示例：** 输入：`root = [3,9,20,null,null,15,7]`；输出：`[[3],[9,20],[15,7]]`。

**思路：** BFS，队列辅助。每一轮处理当前队列中的所有节点（即同一层）。

**展开理解：** 队列保存待处理节点。每层开始时固定 size，只弹出这 size 个节点，期间新加入的孩子留给下一轮；这样可以准确划分层边界，而不是把整棵树混成一维顺序。

```python
from collections import deque

def levelOrder(root):
    if not root:
        return []
    res, queue = [], deque([root])
    while queue:
        level = []
        for _ in range(len(queue)):
            node = queue.popleft()
            level.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        res.append(level)
    return res
```

**复杂度：**
- 时间：O(n)
- 空间：O(w)，w 为最大层宽，最坏为 O(n)

## 108. 将有序数组转换为二叉搜索树

**题目描述：** 将升序数组转换为高度平衡的 BST。

**示例：** 输入：`nums = [-10,-3,0,5,9]`；输出：一个高度平衡 BST，例如 `[0,-3,9,-10,null,5]`。

**思路：** 取中间元素为根，递归构建左右子树。

**展开理解：** 有序数组中点作为根时，左半全部小于根、右半全部大于根，天然满足 BST；每次尽量取中点还能让左右规模相差不超过 1。用下标区间递归可避免切片复制。

```python
def sortedArrayToBST(nums):
    def build(left, right):
        if left > right:
            return None
        mid = (left + right) // 2
        root = TreeNode(nums[mid])
        root.left = build(left, mid - 1)
        root.right = build(mid + 1, right)
        return root

    return build(0, len(nums) - 1)
```

**复杂度：**
- 时间：O(n)
- 空间：O(log n)

## 98. 验证二叉搜索树

**题目描述：** 判断给定二叉树是否是有效的 BST（左子树所有节点 < 根 < 右子树所有节点）。

**示例：** 输入：`root = [2,1,3]`；输出：`true`。

**思路：** 递归传入合法范围 `(min_val, max_val)`，每次更新上下界。

**展开理解：** BST 约束不只是父子大小，而是左子树所有节点都小于根、右子树所有节点都大于根。递归携带开区间上下界可传递祖先约束；使用严格不等号可以排除重复值。

```python
def isValidBST(root):
    def validate(node, low, high):
        if not node:
            return True
        if node.val <= low or node.val >= high:
            return False
        return validate(node.left, low, node.val) and validate(node.right, node.val, high)
    return validate(root, float('-inf'), float('inf'))
```

**迭代 DFS（中序）：** BST 的中序遍历必须严格递增。用显式栈完成中序遍历，只需比较当前值和上一个访问值。

```python
def isValidBST(root):
    stack = []
    cur = root
    prev = float('-inf')

    while cur or stack:
        while cur:
            stack.append(cur)
            cur = cur.left
        cur = stack.pop()
        if cur.val <= prev:
            return False
        prev = cur.val
        cur = cur.right
    return True
```

**复杂度：**
- 时间：O(n)
- 空间：O(h)

## 230. 二叉搜索树中第 K 小的元素

**题目描述：** 找出 BST 中第 k 小的元素。

**示例：** 输入：`root = [3,1,4,null,2], k = 1`；输出：`1`。

**思路：** BST 中序遍历结果即升序序列，第 k 次访问的节点就是答案。

**展开理解：** BST 中序遍历按升序访问节点，因此不必遍历完整棵树。每弹出一个栈顶就把计数减一，减到 0 立即返回；复杂度取决于到第 k 小节点前访问的节点数。

```python
def kthSmallest(root, k):
    stack = []
    cur = root
    count = 0
    while cur or stack:
        while cur:
            stack.append(cur)
            cur = cur.left
        cur = stack.pop()
        count += 1
        if count == k:
            return cur.val
        cur = cur.right
```

**复杂度：**
- 时间：O(h + k)
- 空间：O(h)

## 199. 二叉树的右视图

**题目描述：** 从右侧看二叉树，返回每层最后一个节点的值。

**示例：** 输入：`root = [1,2,3,null,5,null,4]`；输出：`[1,3,4]`。

**思路一（BFS）：** 层序遍历，每层最后一个节点加入结果。

**展开理解：** BFS 每层最后一个是右视图；DFS 则优先访问右子树，并在某深度第一次到达时记录。DFS 的关键不变量是右优先保证第一次看到的节点最靠右，而不是简单收集所有右孩子。

```python
from collections import deque

def rightSideView(root):
    if not root:
        return []
    res, queue = [], deque([root])
    while queue:
        size = len(queue)
        for i in range(size):
            node = queue.popleft()
            if i == size - 1:
                res.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
    return res
```

**思路二（迭代 DFS）：** 按“根—右—左”的顺序遍历。某一深度第一次被访问到的节点，就是该层最右侧节点。栈后进先出，所以先压左孩子、再压右孩子。

```python
def rightSideView(root):
    if not root:
        return []

    res = []
    stack = [(root, 0)]
    while stack:
        node, depth = stack.pop()
        if depth == len(res):
            res.append(node.val)

        # 栈是后进先出：右孩子后压，因此先访问右孩子
        if node.left:
            stack.append((node.left, depth + 1))
        if node.right:
            stack.append((node.right, depth + 1))
    return res
```

**复杂度：**
- 时间：O(n)
- 空间：BFS 为 O(w)，w 为最大层宽；迭代 DFS 为 O(h)；最坏均为 O(n)

## 114. 二叉树展开为链表

**题目描述：** 将二叉树按前序遍历顺序原地展开为链表（right 指针串联，left 置 None）。

**示例：** 输入：`root = [1,2,5,3,4,null,6]`；输出：`[1,null,2,null,3,null,4,null,5,null,6]`。

**思路：** 对每个节点，将左子树插到右子树之前（左子树最右节点接原右子树），重复直到所有左子树为空。

**展开理解：** 前序链表顺序是根、左、右。若当前有左子树，就找到左子树最右节点，把原右子树接到它后面，再把左子树整体移到右侧；当前节点左指针清空后继续向右即可。

```python
def flatten(root):
    cur = root
    while cur:
        if cur.left:
            rightmost = cur.left
            while rightmost.right:
                rightmost = rightmost.right
            rightmost.right = cur.right
            cur.right = cur.left
            cur.left = None
        cur = cur.right
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 105. 从前序与中序遍历序列构造二叉树

**题目描述：** 根据前序遍历和中序遍历结果构造二叉树。

**示例：** 输入：`preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]`；输出：`[3,9,20,null,null,15,7]`。

**思路：** 前序首元素为根，在中序中找根的位置，左右两侧分别递归构建。用 HashMap 存中序索引加速查找。

**展开理解：** 前序第一个元素确定根，中序中根左侧确定左子树规模、右侧确定右子树规模。用哈希表预存中序下标，可把每次找根从 O(n) 降为 O(1)，递归只传区间避免切片。

```python
def buildTree(preorder, inorder):
    idx_map = {val: i for i, val in enumerate(inorder)}
    pre_idx = 0

    def helper(left, right):
        nonlocal pre_idx
        if left > right:
            return None
        root_val = preorder[pre_idx]
        pre_idx += 1
        root = TreeNode(root_val)
        mid = idx_map[root_val]
        root.left = helper(left, mid - 1)
        root.right = helper(mid + 1, right)
        return root

    return helper(0, len(inorder) - 1)
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)

## 437. 路径总和 III

**题目描述：** 找出二叉树中节点值之和等于 `targetSum` 的路径数量（路径方向向下，起止节点任意）。

**示例：** 输入：`root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8`；输出：`3`。

**思路：** 前缀和 + DFS。记录从根到当前节点的前缀和，用 HashMap 存历史前缀和出现次数，当 `prefix - target` 在 map 中时说明存在满足条件的路径。

**展开理解：** 从根枚举每个起点会重复计算。前缀和 DFS 中，当前路径和为 cur，则祖先路径和 cur-target 每出现一次，就对应一条以当前节点结尾的合法路径；回溯离开节点时必须撤销当前前缀，防止串到兄弟分支。

```python
from collections import Counter

def pathSum(root, targetSum):
    count = Counter({0: 1})
    ans = 0

    def dfs(node, prefix):
        nonlocal ans
        if not node:
            return

        prefix += node.val

        # get 不会为不存在的前缀和创建值为 0 的键。
        ans += count.get(prefix - targetSum, 0)
        count[prefix] += 1

        dfs(node.left, prefix)
        dfs(node.right, prefix)

        # 离开当前节点时撤销前缀和，避免影响兄弟分支。
        count[prefix] -= 1
        if count[prefix] == 0:
            del count[prefix]

    dfs(root, 0)
    return ans
```

**迭代 DFS：** 关键是显式模拟递归中的“进入节点”和“退出节点”。进入时加入当前前缀和，退出时撤销，避免一条分支的前缀和污染另一条分支。

```python
from collections import defaultdict

def pathSum(root, targetSum):
    if not root:
        return 0

    count = defaultdict(int)
    count[0] = 1
    ans = 0
    # False 表示进入节点，True 表示退出节点并回溯
    stack = [(root, 0, False)]

    while stack:
        node, prefix, exiting = stack.pop()
        if exiting:
            count[prefix] -= 1
            if count[prefix] == 0:
                del count[prefix]
            continue

        prefix += node.val
        ans += count.get(prefix - targetSum, 0)
        count[prefix] += 1

        # 退出标记先入栈，保证两个孩子处理完后再撤销
        stack.append((node, prefix, True))
        if node.right:
            stack.append((node.right, prefix, False))
        if node.left:
            stack.append((node.left, prefix, False))

    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：O(h)，最坏为 O(n)

## 236. 二叉树的最近公共祖先

**题目描述：** 给定二叉树和两个节点 p、q，找出它们的最近公共祖先（LCA）。

**示例：** 输入：`root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1`；输出：`3`。

**思路：** 后序遍历。若当前节点是 p 或 q 则返回自身；左右子树递归，若两侧都非空则当前节点即 LCA，否则返回非空一侧。

**展开理解：** 后序递归返回当前子树是否找到 p 或 q。若左右子树分别返回非空，当前节点就是最近公共祖先；若只有一边非空就向上传递那一边；当前节点本身等于 p/q 时直接返回自己。

```python
def lowestCommonAncestor(root, p, q):
    if not root or root == p or root == q:
        return root
    left = lowestCommonAncestor(root.left, p, q)
    right = lowestCommonAncestor(root.right, p, q)
    if left and right:
        return root
    return left or right
```

**迭代 DFS：** 先用栈建立每个节点到父节点的映射；再记录 `p` 的全部祖先，从 `q` 向上走，遇到的第一个公共祖先就是 LCA。

```python
def lowestCommonAncestor(root, p, q):
    parent = {root: None}
    stack = [root]

    # 找到 p、q 即可停止，无需一定遍历完整棵树
    while p not in parent or q not in parent:
        node = stack.pop()
        if node.left:
            parent[node.left] = node
            stack.append(node.left)
        if node.right:
            parent[node.right] = node
            stack.append(node.right)

    ancestors = set()
    while p:
        ancestors.add(p)
        p = parent[p]

    while q not in ancestors:
        q = parent[q]
    return q
```

**复杂度：**
- 时间：O(n)
- 空间：递归版 O(h)；迭代版的父节点映射与祖先集合为 O(n)

## 124. 二叉树中的最大路径和

**题目描述：** 路径可从任意节点出发到任意节点，返回路径上节点值之和的最大值。

**示例：** 输入：`root = [-10,9,20,null,null,15,7]`；输出：`42`。

**思路：** DFS，每个节点计算「以自身为最高点的路径和」= 左贡献（正才取）+ 节点值 + 右贡献（正才取），更新全局最大。返回值只能选左或右一侧（路径不能分叉传回父节点）。

**展开理解：** 对父节点可贡献的路径只能选择左、右中的一条，并舍弃负贡献；但全局最优路径可以在当前节点同时连接左右两边。故递归返回单臂收益，全局答案更新 left+node+right。

```python
def maxPathSum(root):
    ans = float('-inf')

    def gain(node):
        nonlocal ans
        if not node:
            return 0
        left = max(gain(node.left), 0)
        right = max(gain(node.right), 0)
        ans = max(ans, node.val + left + right)
        return node.val + max(left, right)

    gain(root)
    return ans
```

**迭代 DFS（后序）：** 和直径题一样，父节点的最大贡献依赖两个孩子，因此用 `visited` 模拟递归后序。`gain[node]` 表示该节点向父节点最多能提供的单边路径和。

```python
def maxPathSum(root):
    ans = float('-inf')
    gain = {None: 0}
    stack = [(root, False)]

    while stack:
        node, visited = stack.pop()
        if not visited:
            stack.append((node, True))
            if node.right:
                stack.append((node.right, False))
            if node.left:
                stack.append((node.left, False))
        else:
            left_gain = max(gain[node.left], 0)
            right_gain = max(gain[node.right], 0)
            ans = max(ans, node.val + left_gain + right_gain)
            gain[node] = node.val + max(left_gain, right_gain)

    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：递归版 O(h)；上述迭代后序版因保存所有节点贡献为 O(n)
