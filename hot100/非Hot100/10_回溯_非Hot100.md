

## 216. 组合总和 III

**题目描述：** 找出所有由 1-9 中 k 个不同数字组成、且数字之和为 n 的组合。

**示例：** 输入：`k = 3, n = 7`；输出：`[[1,2,4]]`。

**思路：** 回溯，从 1 开始枚举，剩余数字不足时剪枝。

**展开理解：** 组合只能使用 1 到 9 且每个数最多一次，所以递归用 start 保证后续只选更大的数。路径长度达到 k 时检查剩余和是否为 0；还可用剩余可选数量以及最小/最大可能和提前剪枝。

```python
def combinationSum3(k, n):
    res = []
    def backtrack(start, path, remaining):
        if len(path) == k and remaining == 0:
            res.append(path[:])
            return
        if len(path) == k or remaining <= 0:
            return
        for i in range(start, 10):
            if i > remaining:
                break
            path.append(i)
            backtrack(i + 1, path, remaining - i)
            path.pop()
    backtrack(1, [], n)
    return res
```

**复杂度：**
- 时间：O(C(9, k) × k)
- 空间：O(k)
