## 283. 移动零

**题目描述：** 将数组中所有 0 移到末尾，保持非零元素相对顺序，原地操作。

**示例：** 输入：`nums = [0,1,0,3,12]`；输出：`[1,3,12,0,0]`。

**思路：** 慢指针 `slow` 指向下一个应填入非零值的位置，快指针 `fast` 扫描非零值并与 slow 交换。

```python
def moveZeroes(nums):
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != 0:
            nums[slow], nums[fast] = nums[fast], nums[slow]
            slow += 1
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 11. 盛最多水的容器

**题目描述：** 给定高度数组，选两条线使容器装水最多，返回最大容量。

**示例：** 输入：`height = [1,8,6,2,5,4,8,3,7]`；输出：`49`。

**思路：** 双端指针。容量 = `min(h[l], h[r]) * (r - l)`，每次移动较矮的一侧（移动较高侧无法增大容量）。

```python
def maxArea(height):
    l, r = 0, len(height) - 1
    ans = 0
    while l < r:
        ans = max(ans, min(height[l], height[r]) * (r - l))
        if height[l] < height[r]:
            l += 1
        else:
            r -= 1
    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 15. 三数之和

**题目描述：** 找出数组中所有不重复的三元组，使三数之和为 0。

**示例：** 输入：`nums = [-1,0,1,2,-1,-4]`；输出：`[[-1,-1,2],[-1,0,1]]`。

**思路：** 排序后，固定第一个数 `nums[i]`，用双指针在 `i+1..n-1` 区间找另两个数。注意跳过重复元素。

```python
def threeSum(nums):
    nums.sort()
    res = []
    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue
        l, r = i + 1, len(nums) - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s == 0:
                res.append([nums[i], nums[l], nums[r]])
                while l < r and nums[l] == nums[l + 1]:
                    l += 1
                while l < r and nums[r] == nums[r - 1]:
                    r -= 1
                l += 1
                r -= 1
            elif s < 0:
                l += 1
            else:
                r -= 1
    return res
```

**复杂度：**
- 时间：O(n²)
- 空间：O(1)（不计输出）

## 42. 接雨水

**题目描述：** 给定高度数组，计算能接住的雨水总量。

**示例：** 输入：`height = [0,1,0,2,1,0,1,3,2,1,2,1]`；输出：`6`。

**思路：** 双端指针，维护 `left_max` 和 `right_max`。当前位置的接水量由较低一侧的最大高度决定，移动较低侧指针。

```python
def trap(height):
    l, r = 0, len(height) - 1
    left_max = right_max = 0
    ans = 0
    while l < r:
        if height[l] < height[r]:
            if height[l] >= left_max:
                left_max = height[l]
            else:
                ans += left_max - height[l]
            l += 1
        else:
            if height[r] >= right_max:
                right_max = height[r]
            else:
                ans += right_max - height[r]
            r -= 1
    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)
