## 283. 移动零

**题目描述：** 将数组中所有 0 移到末尾，保持非零元素相对顺序，原地操作。

**示例：** 输入：`nums = [0,1,0,3,12]`；输出：`[1,3,12,0,0]`。

**思路：** 慢指针 `slow` 指向下一个应填入非零值的位置，快指针 `fast` 扫描非零值并与 slow 交换。

**展开理解：** 循环不变量是 slow 左侧已经放好了所有已扫描到的非零数，并保持原相对顺序。fast 找到非零数就放到 slow 处；当 slow == fast 时交换无副作用，扫描结束后非零区已稳定，剩余位置自然都是零。

```python
def moveZeroes(nums):
    slow = 0
    for fast in range(len(nums)):
        if nums[fast] != 0:
            nums[slow], nums[fast] = nums[fast], nums[slow]
            slow += 1
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 4. 寻找两个正序数组的中位数

**题目描述：** 给定两个分别升序排列的数组 `nums1` 和 `nums2`，返回两个数组合并后的中位数。

**示例：** 输入：`nums1 = [1,3], nums2 = [2]`；输出：`2.0`。

**思路：** 使用两个指针模拟合并有序数组。每次取两个指针所指元素中较小的一个，只遍历到中位数位置，不需要真正创建合并数组。

**展开理解：** `i`、`j` 分别指向两个数组中尚未取出的最小元素，`cur` 保存本次取出的元素，`prev` 保存上一次取出的元素。总长度为奇数时，中位数是 `cur`；总长度为偶数时，中位数是 `(prev + cur) / 2`。

```python
def findMedianSortedArrays(nums1, nums2):
    m, n = len(nums1), len(nums2)
    total = m + n

    i = j = 0
    prev = cur = 0

    # 只需找到合并后下标为 total // 2 的元素。
    for _ in range(total // 2 + 1):
        prev = cur

        if i < m and (j >= n or nums1[i] <= nums2[j]):
            cur = nums1[i]
            i += 1
        else:
            cur = nums2[j]
            j += 1

    if total % 2 == 1:
        return float(cur)

    return (prev + cur) / 2.0
```

**复杂度：**
- 时间：O(m + n)
- 空间：O(1)

> 原题进阶要求 O(log(m+n))，需要使用二分分割线；这里保留更直观、容易手写的双指针实现。

### 扩展：三个或多个有序数组

当有三个或任意 `k` 个有序数组时，可以使用 `heapq.merge` 进行惰性多路归并。它不会一次性生成完整的合并数组，而是按从小到大的顺序逐个返回元素，因此遍历到中位数位置后即可停止。

```python
import heapq

def findMedianOfSortedArrays(arrays):
    total = sum(len(arr) for arr in arrays)

    if total == 0:
        raise ValueError("所有数组都为空")

    mid = total // 2
    prev = cur = None

    for index, num in enumerate(heapq.merge(*arrays)):
        prev, cur = cur, num

        if index == mid:
            break

    if total % 2 == 1:
        return float(cur)

    return (prev + cur) / 2.0
```

使用示例：

```python
findMedianOfSortedArrays([
    [1, 4, 7],
    [2, 5, 8],
    [3, 6, 9]
])
# 5.0
```

设所有数组的元素总数为 `N`，数组数量为 `k`：

- 时间：O(N log k)，实际只读取到中位数位置
- 空间：O(k)

`heapq.merge` 内部使用最小堆。如果面试要求手写多路归并，则需要自己维护一个大小最多为 `k` 的最小堆；如果主要追求 Python 代码清晰，这个版本更合适。

## 11. 盛最多水的容器

**题目描述：** 给定高度数组，选两条线使容器装水最多，返回最大容量。

**示例：** 输入：`height = [1,8,6,2,5,4,8,3,7]`；输出：`49`。

**思路：** 双端指针。容量 = `min(h[l], h[r]) * (r - l)`，每次移动较矮的一侧（移动较高侧无法增大容量）。

**展开理解：** 当前宽度缩小时，面积想变大只能依赖更高的短板。若左边更矮而去移动右边，宽度变小、短板仍不超过左高，不可能超过当前面积，所以可以安全排除较矮边界。

```python
def maxArea(height):
    l, r = 0, len(height) - 1
    ans = 0
    while l < r:
        ans = max(ans, min(height[l], height[r]) * (r - l))
        if height[l] < height[r]:
            l += 1
        else:
            r -= 1
    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 15. 三数之和

**题目描述：** 找出数组中所有不重复的三元组，使三数之和为 0。

**示例：** 输入：`nums = [-1,0,1,2,-1,-4]`；输出：`[[-1,-1,2],[-1,0,1]]`。

**思路：** 排序后，固定第一个数 `nums[i]`，用双指针在 `i+1..n-1` 区间找另两个数。注意跳过重复元素。

**展开理解：** 排序把三数和对后两个数变成单调问题：固定 i 后，和偏小就右移 left，偏大就左移 right。去重要分三处处理：固定数重复要跳过，找到答案后左右指针也要跨过连续相同值。

```python
def threeSum(nums):
    nums.sort()
    res = []
    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue
        l, r = i + 1, len(nums) - 1
        while l < r:
            s = nums[i] + nums[l] + nums[r]
            if s == 0:
                res.append([nums[i], nums[l], nums[r]])
                while l < r and nums[l] == nums[l + 1]:
                    l += 1
                while l < r and nums[r] == nums[r - 1]:
                    r -= 1
                l += 1
                r -= 1
            elif s < 0:
                l += 1
            else:
                r -= 1
    return res
```

**复杂度：**
- 时间：O(n²)
- 空间：O(n)（Python `list.sort()` 最坏辅助空间，不计输出）

## 42. 接雨水

**题目描述：** 给定高度数组，计算能接住的雨水总量。

**示例：** 输入：`height = [0,1,0,2,1,0,1,3,2,1,2,1]`；输出：`6`。

**思路：** 双端指针，维护 `left_max` 和 `right_max`。当前位置的接水量由较低一侧的最大高度决定，移动较低侧指针。

**展开理解：** 左边更低时，当前位置右侧至少存在 height[r] 这堵不矮于左侧的墙，所以 left 的接水上限已经由 left_max 确定；右侧同理。每一步结算一侧后移动指针，不需要知道另一侧内部的完整形状。

```python
def trap(height):
    l, r = 0, len(height) - 1
    left_max = right_max = 0
    ans = 0
    while l < r:
        if height[l] < height[r]:
            if height[l] >= left_max:
                left_max = height[l]
            else:
                ans += left_max - height[l]
            l += 1
        else:
            if height[r] >= right_max:
                right_max = height[r]
            else:
                ans += right_max - height[r]
            r -= 1
    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)
