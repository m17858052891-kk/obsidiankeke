## 70. 爬楼梯

**题目描述：** 爬 n 阶楼梯，每次可以爬 1 或 2 阶，共有多少种方法。

**示例：** 输入：`n = 3`；输出：`3`。

**思路：** `dp[i] = dp[i-1] + dp[i-2]`，本质是斐波那契数列。

**展开理解：** 到第 i 阶的最后一步只能从 i-1 走 1 阶或从 i-2 走 2 阶，两类方案互斥且覆盖全部情况，所以状态相加。只依赖前两项，可用两个变量把空间降为 O(1)。

```python
def climbStairs(n):
    if n <= 2:
        return n
    a, b = 1, 2
    for _ in range(3, n + 1):
        a, b = b, a + b
    return b
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 118. 杨辉三角

**题目描述：** 返回杨辉三角前 numRows 行。

**示例：** 输入：`numRows = 5`；输出：`[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]`。

**思路：** 每行首尾为 1，中间元素为上一行相邻两元素之和。

**展开理解：** 第 i 行第 j 个内部元素只能由上一行 j-1 与 j 两个位置相加得到，边界固定为 1。逐行生成时上一行必须保持不变；若原地滚动，需要从右向左更新。

```python
def generate(numRows):
    triangle = []
    for i in range(numRows):
        row = [1] * (i + 1)
        for j in range(1, i):
            row[j] = triangle[i-1][j-1] + triangle[i-1][j]
        triangle.append(row)
    return triangle
```

**复杂度：**
- 时间：O(n²)
- 空间：O(n²)

## 198. 打家劫舍

**题目描述：** 相邻房屋有警报系统，不能连续抢相邻两间，返回可抢到的最高金额。

**示例：** 输入：`nums = [1,2,3,1]`；输出：`4`。

**思路：** `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`，滚动变量优化空间。

**展开理解：** 对当前房屋只有抢与不抢：不抢继承 dp[i-1]，抢则必须加在 dp[i-2] 后。二者取最大覆盖所有合法方案；滚动变量分别保存这两个历史状态。

```python
def rob(nums):
    prev2, prev1 = 0, 0
    for num in nums:
        prev2, prev1 = prev1, max(prev1, prev2 + num)
    return prev1
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 279. 完全平方数

**题目描述：** 给定正整数 n，返回和为 n 的完全平方数的最少数量。

**示例：** 输入：`n = 12`；输出：`3`，对应 `4 + 4 + 4`。

**思路：** 完全背包问题。`dp[i] = min(dp[i - j*j] + 1)` for all j where j*j <= i。

**展开理解：** dp[i] 表示凑成 i 的最少平方数个数，最后一个平方数枚举 j² 后，前面最优子结构是 dp[i-j²]。dp[0]=0 提供合法起点，其余初始化无穷避免错误最小值。

```python
def numSquares(n):
    dp = [float('inf')] * (n + 1)
    dp[0] = 0
    for i in range(1, n + 1):
        j = 1
        while j * j <= i:
            dp[i] = min(dp[i], dp[i - j * j] + 1)
            j += 1
    return dp[n]
```

**复杂度：**
- 时间：O(n √n)
- 空间：O(n)

## 322. 零钱兑换

**题目描述：** 给定硬币面额和总金额 amount，返回凑出 amount 的最少硬币数，不能凑出返回 -1。

**示例：** 输入：`coins = [1,2,5], amount = 11`；输出：`3`。

**思路：** 完全背包。`dp[i] = min(dp[i - coin] + 1)` for each coin.

**展开理解：** 把最后使用的硬币设为 coin，则剩余金额必须由 dp[i-coin] 最优构成。枚举所有硬币取最小；无法到达的状态保持无穷，最终需转换为 -1。

```python
def coinChange(coins, amount):
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0
    for i in range(1, amount + 1):
        for coin in coins:
            if coin <= i:
                dp[i] = min(dp[i], dp[i - coin] + 1)
    return dp[amount] if dp[amount] != float('inf') else -1
```

**复杂度：**
- 时间：O(amount × n)，n 为硬币种类数
- 空间：O(amount)

## 139. 单词拆分

**题目描述：** 给定字符串 s 和单词列表 wordDict，判断 s 是否可被空格拆分成字典中的单词。

**示例：** 输入：`s = "leetcode", wordDict = ["leet","code"]`；输出：`true`。

**思路：** `dp[i]` 表示 `s[:i]` 是否可被拆分。若 `dp[j]` 为真且 `s[j:i]` 在字典中，则 `dp[i]` 为真。

**展开理解：** dp[i] 只关心前 i 个字符能否被合法拆分。枚举最后一个单词起点 j：前缀 dp[j] 可拆且 s[j:i] 在词典中即可；找到一个可行 j 后可以提前结束。

```python
def wordBreak(s, wordDict):
    word_set = set(wordDict)
    max_word_len = max(map(len, wordDict), default=0)
    n = len(s)
    dp = [False] * (n + 1)
    dp[0] = True
    for i in range(1, n + 1):
        for j in range(max(0, i - max_word_len), i):
            if dp[j] and s[j:i] in word_set:
                dp[i] = True
                break
    return dp[n]
```

**复杂度：**
- 时间：O(D + n × L²)，D 为字典总字符数，L 为最长单词长度（包含 Python 切片成本）
- 空间：O(n + D)，D 为字典中所有单词的总长度

## 300. 最长递增子序列

**题目描述：** 给定整数数组，返回最长严格递增子序列的长度。

**示例：** 输入：`nums = [10,9,2,5,3,7,101,18]`；输出：`4`。

**思路（贪心 + 二分，O(n log n)）：** 维护一个 `tails` 数组，`tails[i]` 表示长度为 i+1 的递增子序列的最小尾元素。对每个数用二分找其插入位置。

**展开理解：** tails[k] 不是一条固定 LIS，而是长度 k+1 的递增子序列能取得的最小尾值。更小的尾值给未来留出更大扩展空间；对每个数替换第一个 >=它的位置，tails 长度就是 LIS 长度。

```python
from bisect import bisect_left

def lengthOfLIS(nums):
    tails = []
    for num in nums:
        index = bisect_left(tails, num)
        if index == len(tails):
            tails.append(num)
        else:
            tails[index] = num
    return len(tails)
```

**复杂度：**
- 时间：O(n log n)
- 空间：O(n)

## 152. 乘积最大子数组

**题目描述：** 找连续子数组中乘积最大的值。

**示例：** 输入：`nums = [2,3,-2,4]`；输出：`6`。

**思路：** 同时维护「以当前元素结尾的最大积」和「最小积」（负负得正），每次与当前元素组合取极值。

**展开理解：** 负数会让最大积与最小积互换角色，所以只维护最大值不够。每步从当前数、当前数×旧最大、当前数×旧最小三者重算新极值；更新时要基于旧值，不能先覆盖其中一个。

```python
def maxProduct(nums):
    max_p = min_p = ans = nums[0]
    for num in nums[1:]:
        candidates = (num, max_p * num, min_p * num)
        max_p = max(candidates)
        min_p = min(candidates)
        ans = max(ans, max_p)
    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 416. 分割等和子集

**题目描述：** 判断数组是否能被分割成两个和相等的子集（等价于：能否从数组中选若干数使和为 sum/2）。

**示例：** 输入：`nums = [1,5,11,5]`；输出：`true`。

**思路：** 0-1 背包。`dp[j]` 表示能否凑出和为 j，逆序遍历防止重复使用。

**展开理解：** 总和为奇数必不能等分；目标变成是否从每个数最多选一次凑到 total/2。dp[j] 表示容量 j 是否可达，容量必须倒序更新，否则同一个数会在本轮被重复使用，退化成完全背包。

```python
def canPartition(nums):
    total = sum(nums)
    if total % 2 != 0:
        return False
    target = total // 2
    dp = [False] * (target + 1)
    dp[0] = True
    for num in nums:
        for j in range(target, num - 1, -1):
            dp[j] = dp[j] or dp[j - num]
    return dp[target]
```

**复杂度：**
- 时间：O(n × target)
- 空间：O(target)

## 32. 最长有效括号

**题目描述：** 给定只含 '(' 和 ')' 的字符串，找最长有效括号子串的长度。

**示例：** 输入：`s = ")()())"`；输出：`4`，对应 `"()()"`。

**思路：** 栈（存索引）。栈底始终保持「最后一个未匹配的 ')' 的索引」作为基准，有效括号长度 = 当前索引 - 栈顶索引。

**展开理解：** 栈存下标而非字符，栈底记录当前合法段之前最近的无效位置。右括号导致栈空时把它设为新基准；匹配成功且栈非空时，i-stack[-1] 就是以 i 结尾的最长有效长度。

```python
def longestValidParentheses(s):
    stack = [-1]
    ans = 0
    for i, ch in enumerate(s):
        if ch == '(':
            stack.append(i)
        else:
            stack.pop()
            if not stack:
                stack.append(i)   # 更新基准
            else:
                ans = max(ans, i - stack[-1])
    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)
