## 200. 岛屿数量

**题目描述：** 给定 '1'（陆地）和 '0'（水）组成的二维网格，计算岛屿数量。岛屿由相邻陆地连接形成，四周被水包围。

**示例：** 输入：`grid = [["1","1","0"],["1","0","0"],["0","0","1"]]`；输出：`2`。

**思路：** 递归 DFS。遍历每个格子，遇到尚未访问的 '1' 就将岛屿数加一，再递归把与它上下左右连通的所有陆地标记为 '0'。

**展开理解：** 把 dfs(r, c) 理解为“从这个格子出发，把所有连通的陆地都变成 0”。越界或遇到水时结束递归；遇到陆地时，先标记为 0，再递归访问上下左右，避免相邻格子互相访问形成死循环。一次 DFS 标记完整个岛屿，后续遍历就不会重复计数。代码会修改原网格；大型连通岛可能触发 Python 递归深度限制。

```python
class Solution:
    def numIslands(self, grid: list[list[str]]) -> int:
        if not grid or not grid[0]:
            return 0

        rows, cols = len(grid), len(grid[0])

        def dfs(r, c):
            # 递归终止：越界，或者当前格子是水 / 已访问
            if r < 0 or r >= rows or c < 0 or c >= cols:
                return
            if grid[r][c] != "1":
                return

            # 先标记，避免相邻格子互相递归，形成死循环
            grid[r][c] = "0"

            # 递归访问上下左右四个方向
            dfs(r - 1, c)
            dfs(r + 1, c)
            dfs(r, c - 1)
            dfs(r, c + 1)

        count = 0
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == "1":
                    count += 1
                    dfs(r, c)  # 标记整个岛屿

        return count
```

**复杂度：**
- 时间：O(m × n)
- 空间：O(m × n)（递归调用栈最坏情况）

## 994. 腐烂的橘子

**题目描述：** 网格中 0=空，1=新鲜橘子，2=腐烂橘子。腐烂橘子每分钟将相邻新鲜橘子腐烂，求所有橘子腐烂的最短时间，无法全部腐烂则返回 -1。

**示例：** 输入：`grid = [[2,1,1],[1,1,0],[0,1,1]]`；输出：`4`。

**思路：** 按分钟分轮传播（多源 BFS）。用 `current` 保存这一轮负责传播的腐烂橘子，用 `next_round` 收集这一轮刚被感染的橘子。一轮结束后，换下一批传播，时间加一。

**展开理解：**

- 初始所有腐烂橘子一起放入 `current`，对应第 0 分钟，并统计新鲜橘子的数量 `fresh`。
- 遍历 `current`，将上下左右的新鲜橘子立即标记为 2，避免重复感染和重复计数，再加入 `next_round`。
- 新感染的橘子要等下一轮才能传播。执行 `current = next_round`，就表示这一分钟结束，换下一批橘子传播。
- 如果还有新鲜橘子，却没有任何橘子在这一轮被感染，说明无法全部腐烂，返回 -1；如果新鲜橘子数量变为 0，就返回已用分钟数。最初没有新鲜橘子时直接返回 0。

```python
class Solution:
    def orangesRotting(self, grid: list[list[int]]) -> int:
        if not grid or not grid[0]:
            return 0

        rows, cols = len(grid), len(grid[0])
        current = []
        fresh = 0

        # 找出最初的腐烂橘子，统计新鲜橘子
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 2:
                    current.append((r, c))
                elif grid[r][c] == 1:
                    fresh += 1

        minutes = 0

        while fresh > 0:
            next_round = []

            for r, c in current:
                # 检查上下左右
                for nr, nc in [
                    (r - 1, c), (r + 1, c),
                    (r, c - 1), (r, c + 1)
                ]:
                    if not (0 <= nr < rows and 0 <= nc < cols):
                        continue
                    if grid[nr][nc] != 1:
                        continue

                    grid[nr][nc] = 2
                    fresh -= 1
                    next_round.append((nr, nc))

            # 还有新鲜橘子，却已经无法继续传播
            if not next_round:
                return -1

            current = next_round
            minutes += 1

        return minutes
```

**示例推演：** 上述示例中，每个橘子变腐烂的时间如下（`·` 表示空格）：

```text
0 1 2
1 2 ·
· 3 4
```

最初腐烂的橘子记为第 0 分钟，向外扩散一圈就多一分钟，最后一个橘子在第 4 分钟腐烂，所以返回 4。代码会修改原网格。

**复杂度：**

- 时间：O(m × n)，每个橘子最多加入列表一次，每次检查四个方向。
- 空间：O(m × n)，用于保存当前轮和下一轮的橘子位置。

## 207. 课程表

**题目描述：** 有 `numCourses` 门课，prerequisites[i] = [a, b] 表示学 a 前必须先学 b。判断是否能完成所有课程（即有向图中是否无环）。

**示例：** 输入：`numCourses = 2, prerequisites = [[1,0]]`；输出：`true`。

**思路：** 拓扑排序（BFS-Kahn 算法）。计算所有节点的入度，将入度为 0 的节点入队。每次取出节点，将其邻居入度 -1，若入度变 0 则入队。若所有节点均被处理则无环。

**展开理解：** 课程依赖构成有向图，能完成全部课程等价于图中无环。Kahn 拓扑排序从入度 0 的课程开始，每学完一门就减少后继入度；最终处理节点数等于课程数才说明不存在环。

```python
from collections import deque

def canFinish(numCourses, prerequisites):
    graph = [[] for _ in range(numCourses)]
    in_degree = [0] * numCourses
    for a, b in prerequisites:
        graph[b].append(a)
        in_degree[a] += 1
    queue = deque(i for i in range(numCourses) if in_degree[i] == 0)
    count = 0
    while queue:
        node = queue.popleft()
        count += 1
        for nei in graph[node]:
            in_degree[nei] -= 1
            if in_degree[nei] == 0:
                queue.append(nei)
    return count == numCourses
```

**复杂度：**
- 时间：O(V + E)
- 空间：O(V + E)

## 208. 实现 Trie（前缀树）

**题目描述：** 实现前缀树，支持 `insert(word)`、`search(word)`（精确匹配）、`startsWith(prefix)`（前缀匹配）。

**示例：** 输入：`insert("apple"), search("apple"), search("app"), startsWith("app")`；输出：`true, false, true`。

**思路：** 每个节点用字典保存实际存在的子节点，并用 `is_end` 标记完整单词结尾。

**展开理解：** Trie 把公共前缀共享成路径。插入逐字符建边，查询完整单词还必须检查结束标记，`startsWith` 只需路径存在；否则无法区分已插入 apple 与仅查询 app。

```python
class Trie:
    def __init__(self):
        self.children = {}
        self.is_end = False

    def insert(self, word):
        node = self
        for ch in word:
            if ch not in node.children:
                node.children[ch] = Trie()
            node = node.children[ch]
        node.is_end = True

    def search(self, word):
        node = self
        for ch in word:
            if ch not in node.children:
                return False
            node = node.children[ch]
        return node.is_end

    def startsWith(self, prefix):
        node = self
        for ch in prefix:
            if ch not in node.children:
                return False
            node = node.children[ch]
        return True
```

**复杂度：**
- insert/search/startsWith 时间：O(L)，L 为字符串长度
- 空间：O(所有插入单词的总字符数)
