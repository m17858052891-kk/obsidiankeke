## 200. 岛屿数量

**题目描述：** 给定 '1'（陆地）和 '0'（水）组成的二维网格，计算岛屿数量。岛屿由相邻陆地连接形成，四周被水包围。

**示例：** 输入：`grid = [["1","1","0"],["1","0","0"],["0","0","1"]]`；输出：`2`。

**思路：** 迭代 DFS。遍历每个格子，遇到 '1' 就用显式栈将整个岛屿标记为 '0'，岛屿数 +1。

**展开理解：** 遍历网格，遇到尚未访问的陆地就说明发现一个新岛，答案加一，并用 DFS 把与它四连通的整块陆地全部标记。使用显式栈可避免大型连通岛触发 Python 递归深度限制；每个格子最多入栈一次，总复杂度 O(mn)。

```python
def numIslands(grid):
    if not grid:
        return 0
    rows, cols = len(grid), len(grid[0])
    count = 0

    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1':
                count += 1
                grid[r][c] = '0'
                stack = [(r, c)]
                while stack:
                    cur_r, cur_c = stack.pop()
                    for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                        nr, nc = cur_r + dr, cur_c + dc
                        if (0 <= nr < rows and 0 <= nc < cols
                                and grid[nr][nc] == '1'):
                            grid[nr][nc] = '0'
                            stack.append((nr, nc))
    return count
```

**复杂度：**
- 时间：O(m × n)
- 空间：O(m × n)（显式栈最坏情况）

## 994. 腐烂的橘子

**题目描述：** 网格中 0=空，1=新鲜橘子，2=腐烂橘子。腐烂橘子每分钟将相邻新鲜橘子腐烂，求所有橘子腐烂的最短时间，无法全部腐烂则返回 -1。

**示例：** 输入：`grid = [[2,1,1],[1,1,0],[0,1,1]]`；输出：`4`。

**思路：** 多源 BFS。将所有腐烂橘子同时入队为第 0 层，BFS 逐层扩散并记录时间，最后检查是否还有新鲜橘子。

**展开理解：** 这是多源 BFS：所有初始腐烂橘子同时作为第 0 层入队，而不是逐个做 BFS。每扩展一层代表一分钟；最后若仍有新鲜橘子则不可达，否则返回实际发生扩散的层数。

```python
from collections import deque

def orangesRotting(grid):
    rows, cols = len(grid), len(grid[0])
    queue = deque()
    fresh = 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == 2:
                queue.append((r, c))
            elif grid[r][c] == 1:
                fresh += 1
    minutes = 0
    dirs = [(1,0),(-1,0),(0,1),(0,-1)]
    while queue and fresh > 0:
        minutes += 1
        for _ in range(len(queue)):
            r, c = queue.popleft()
            for dr, dc in dirs:
                nr, nc = r + dr, c + dc
                if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                    grid[nr][nc] = 2
                    fresh -= 1
                    queue.append((nr, nc))
    return minutes if fresh == 0 else -1
```

**复杂度：**
- 时间：O(m × n)
- 空间：O(m × n)

## 207. 课程表

**题目描述：** 有 `numCourses` 门课，prerequisites[i] = [a, b] 表示学 a 前必须先学 b。判断是否能完成所有课程（即有向图中是否无环）。

**示例：** 输入：`numCourses = 2, prerequisites = [[1,0]]`；输出：`true`。

**思路：** 拓扑排序（BFS-Kahn 算法）。计算所有节点的入度，将入度为 0 的节点入队。每次取出节点，将其邻居入度 -1，若入度变 0 则入队。若所有节点均被处理则无环。

**展开理解：** 课程依赖构成有向图，能完成全部课程等价于图中无环。Kahn 拓扑排序从入度 0 的课程开始，每学完一门就减少后继入度；最终处理节点数等于课程数才说明不存在环。

```python
from collections import deque

def canFinish(numCourses, prerequisites):
    graph = [[] for _ in range(numCourses)]
    in_degree = [0] * numCourses
    for a, b in prerequisites:
        graph[b].append(a)
        in_degree[a] += 1
    queue = deque(i for i in range(numCourses) if in_degree[i] == 0)
    count = 0
    while queue:
        node = queue.popleft()
        count += 1
        for nei in graph[node]:
            in_degree[nei] -= 1
            if in_degree[nei] == 0:
                queue.append(nei)
    return count == numCourses
```

**复杂度：**
- 时间：O(V + E)
- 空间：O(V + E)

## 208. 实现 Trie（前缀树）

**题目描述：** 实现前缀树，支持 `insert(word)`、`search(word)`（精确匹配）、`startsWith(prefix)`（前缀匹配）。

**示例：** 输入：`insert("apple"), search("apple"), search("app"), startsWith("app")`；输出：`true, false, true`。

**思路：** 每个节点用字典保存实际存在的子节点，并用 `is_end` 标记完整单词结尾。

**展开理解：** Trie 把公共前缀共享成路径。插入逐字符建边，查询完整单词还必须检查结束标记，`startsWith` 只需路径存在；否则无法区分已插入 apple 与仅查询 app。

```python
class Trie:
    def __init__(self):
        self.children = {}
        self.is_end = False

    def insert(self, word):
        node = self
        for ch in word:
            if ch not in node.children:
                node.children[ch] = Trie()
            node = node.children[ch]
        node.is_end = True

    def search(self, word):
        node = self
        for ch in word:
            if ch not in node.children:
                return False
            node = node.children[ch]
        return node.is_end

    def startsWith(self, prefix):
        node = self
        for ch in prefix:
            if ch not in node.children:
                return False
            node = node.children[ch]
        return True
```

**复杂度：**
- insert/search/startsWith 时间：O(L)，L 为字符串长度
- 空间：O(所有插入单词的总字符数)
