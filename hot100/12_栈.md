## 20. 有效的括号

**题目描述：** 判断括号字符串是否有效（开括号必须由对应类型的闭括号关闭，且顺序正确）。

**示例：** 输入：`s = "()[]{}"`；输出：`true`。

**思路：** 遍历字符，开括号入栈，闭括号时检查栈顶是否匹配，最后栈空则有效。

**展开理解：** 栈保存尚未匹配的左括号。遇到右括号时，它只能与当前最近的未匹配左括号配对，所以必须比较栈顶；提前为空、类型不符或遍历结束栈非空都意味着无效。

```python
def isValid(s):
    stack = []
    mapping = {')': '(', '}': '{', ']': '['}
    for ch in s:
        if ch in mapping:
            top = stack.pop() if stack else '#'
            if mapping[ch] != top:
                return False
        else:
            stack.append(ch)
    return not stack
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)

## 739. 每日温度

**题目描述：** 给定每日温度数组，返回「下一个更高温度需要等待的天数」数组，若之后无更高温度则为 0。

**示例：** 输入：`temperatures = [73,74,75,71,69,72,76,73]`；输出：`[1,1,4,2,1,1,0,0]`。

**思路：** 单调递减栈（存索引）。遍历温度，若当前温度高于栈顶对应温度，弹出栈顶并计算等待天数。

**展开理解：** 栈保存尚未找到更高温度的下标，并保持对应温度单调不增。新温度更高时，它就是被弹出下标右侧第一个更高温度，因为中间位置已扫描且都不满足。

```python
def dailyTemperatures(temperatures):
    n = len(temperatures)
    ans = [0] * n
    stack = []   # 单调递减，存索引
    for i, temp in enumerate(temperatures):
        while stack and temperatures[stack[-1]] < temp:
            idx = stack.pop()
            ans[idx] = i - idx
        stack.append(i)
    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)

## 84. 柱状图中最大的矩形

**题目描述：** 给定柱状图的高度数组，找出能围成的最大矩形面积。

**示例：** 输入：`heights = [2,1,5,6,2,3]`；输出：`10`。

**思路：** 单调递增栈。遍历高度（两端加哨兵 0），当当前高度小于栈顶时，弹出栈顶计算以该高度为高的矩形面积（宽 = 当前索引 - 新栈顶 - 1）。

**展开理解：** 栈中下标对应高度单调递增。遇到更矮柱时，被弹出高度的右边界首次确定为 i-1，左边界是弹栈后新栈顶+1；两个 0 哨兵统一处理开头和结尾残留柱子。

```python
def largestRectangleArea(heights):
    heights = [0] + heights + [0]
    stack = [0]
    ans = 0
    for i in range(1, len(heights)):
        while heights[i] < heights[stack[-1]]:
            h = heights[stack.pop()]
            w = i - stack[-1] - 1
            ans = max(ans, h * w)
        stack.append(i)
    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)

## 155. 最小栈

**题目描述：** 设计一个支持 `push`、`pop`、`top`、`getMin`（O(1) 时间）的栈。

**示例：** 输入：`push(-2), push(0), push(-3), getMin(), pop(), top(), getMin()`；输出：`-3, 0, -2`。

**思路：** 用辅助栈同步记录每个状态下的最小值。

**展开理解：** 辅助最小栈的第 i 个元素记录主栈处于第 i 层时的最小值，因此 push/pop 必须同步。也可只在新值不大于当前最小时入最小栈，但弹出相等最小值时必须同步处理重复。

```python
class MinStack:
    def __init__(self):
        self.stack = []
        self.min_stack = []

    def push(self, val):
        self.stack.append(val)
        min_val = min(val, self.min_stack[-1] if self.min_stack else val)
        self.min_stack.append(min_val)

    def pop(self):
        self.stack.pop()
        self.min_stack.pop()

    def top(self):
        return self.stack[-1]

    def getMin(self):
        return self.min_stack[-1]
```

**复杂度：**
- 时间：O(1) 所有操作
- 空间：O(n)

## 394. 字符串解码

**题目描述：** 给定编码字符串如 `3[a2[c]]`，解码为 `accaccacc`。

**示例：** 输入：`s = "3[a]2[bc]"`；输出：`"aaabcbc"`。

**思路：** 栈辅助。遇到数字时累积，遇到 '[' 时将当前数字和当前字符串入栈，遇到 ']' 时弹出并重复拼接。

**展开理解：** 遇到 `[` 时，当前字符串属于外层、当前数字属于新片段重复次数，把二者一起入栈并重置局部状态；遇到 `]` 时完成一层表达式并与外层拼接。数字可能多位，需用 num=num*10+digit 累积。

```python
def decodeString(s):
    stack = []   # 存 (外层字符列表, 重复次数)
    cur_chars = []
    cur_num = 0
    for ch in s:
        if ch.isdigit():
            cur_num = cur_num * 10 + int(ch)
        elif ch == '[':
            stack.append((cur_chars, cur_num))
            cur_chars = []
            cur_num = 0
        elif ch == ']':
            prev_chars, repeat = stack.pop()
            prev_chars.extend(cur_chars * repeat)
            cur_chars = prev_chars
        else:
            cur_chars.append(ch)
    return ''.join(cur_chars)
```

**复杂度：**
- 时间：O(n + M)，n 为编码串长度，M 为解码结果长度
- 空间：O(n + M)

## 32. 最长有效括号

**题目描述：** 给定只含 `(` 和 `)` 的字符串，找最长有效括号子串的长度。

**示例：** 输入：`s = ")()())"`；输出：`4`，对应 `"()()"`。

**思路（栈）：** 栈中保存括号的索引，并用栈底记录当前合法区间左侧最近的无效位置。初始化时放入 `-1` 作为边界。

**展开理解：** 遇到左括号时，将其索引入栈；遇到右括号时，先弹出一个索引表示尝试匹配。若弹出后栈为空，说明当前右括号无法匹配，需要把它的索引作为新的左边界；否则，以当前索引结尾的有效括号长度就是 `i - stack[-1]`。

```python
def longestValidParentheses(s):
    stack = [-1]
    ans = 0

    for i, ch in enumerate(s):
        if ch == "(":
            stack.append(i)
        else:
            stack.pop()
            if not stack:
                stack.append(i)
            else:
                ans = max(ans, i - stack[-1])

    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)
