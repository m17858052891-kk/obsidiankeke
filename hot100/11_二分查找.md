# LeetCode Hot 100 — 二分查找

> 本章使用两种二分边界模板：普通搜索采用闭区间 `[l, r]`，循环条件为 `l <= r`；寻找边界的 `lower_bound` 采用左闭右开区间 `[l, r)`，循环条件为 `l < r`。两种模板的右边界初始化和收缩方式不能混用。

---

## 35. 搜索插入位置

**题目描述：** 给定有序数组和目标值，找目标值的索引；若不存在，返回应插入的位置。

**示例：** 输入：`nums = [1,3,5,6], target = 5`；输出：`2`。

**思路：** 标准二分，寻找「第一个 >= target 的位置」。

**展开理解：** 寻找第一个大于等于 target 的位置，也就是 lower_bound。代码维护闭区间 `[l, r]`：mid 小于 target 时答案一定在右侧，否则继续到左侧寻找更早的位置；循环结束时 l 就是插入点。

```python
def searchInsert(nums, target):
    l, r = 0, len(nums) - 1
    while l <= r:
        mid = (l + r) // 2
        if nums[mid] < target:
            l = mid + 1
        else:
            r = mid - 1
    return l
```

**复杂度：**
- 时间：O(log n)
- 空间：O(1)

## 4. 寻找两个正序数组的中位数

**题目描述：** 给定两个分别升序排列的数组 `nums1` 和 `nums2`，返回两个数组合并后的中位数。要求时间复杂度为 `O(log(m+n))`。

**示例：** 输入：`nums1 = [1,3], nums2 = [2]`；输出：`2.0`。

**思路：** 不真正合并数组，而是在较短数组上二分“分割线”。分别把两个数组切成左右两部分，使左半部分元素总数等于右半部分，且左半部分最大值不大于右半部分最小值；此时中位数只由四个边界值决定。

**展开理解：** 假设在 `nums1` 中取前 `i` 个数放到左边，在 `nums2` 中取前 `j` 个数放到左边。为了让左右数量平衡，`j` 可以由 `i` 唯一确定：

```text
i + j = (m + n + 1) // 2
j = half - i
```

正确分割需要满足：

```text
nums1 左侧最大值 <= nums2 右侧最小值
nums2 左侧最大值 <= nums1 右侧最小值
```

如果 `nums1` 左侧最大值太大，说明 `i` 取多了，二分向左；否则说明 `i` 取少了，二分向右。为了让 `j` 始终合法，只在较短数组上做二分。

找到合法分割后：

- 总长度为奇数：中位数是左右分割线左侧的最大值；
- 总长度为偶数：中位数是“左侧最大值”和“右侧最小值”的平均数。

```python
def findMedianSortedArrays(nums1, nums2):
    # 始终在较短数组上二分，保证分割位置合法
    if len(nums1) > len(nums2):
        nums1, nums2 = nums2, nums1

    m, n = len(nums1), len(nums2)
    half = (m + n + 1) // 2
    left, right = 0, m

    while left <= right:
        i = (left + right) // 2
        j = half - i

        left1 = float('-inf') if i == 0 else nums1[i - 1]
        right1 = float('inf') if i == m else nums1[i]
        left2 = float('-inf') if j == 0 else nums2[j - 1]
        right2 = float('inf') if j == n else nums2[j]

        # 找到合法分割线
        if left1 <= right2 and left2 <= right1:
            if (m + n) % 2 == 1:
                return float(max(left1, left2))
            return (max(left1, left2) + min(right1, right2)) / 2.0

        # nums1 左边取多了
        if left1 > right2:
            right = i - 1
        # nums1 左边取少了
        else:
            left = i + 1
```

**边界处理：** 当分割线落在数组最左或最右时，某一侧没有元素。使用正负无穷作为哨兵，可以统一比较逻辑，不需要为四种边界分别写分支。

**复杂度：**
- 时间：O(log(min(m,n)))
- 空间：O(1)

## 74. 搜索二维矩阵

**题目描述：** m×n 矩阵每行从左到右升序，每行首元素大于上一行尾元素，判断目标值是否存在。

**示例：** 输入：`matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3`；输出：`true`。

**思路：** 把矩阵视为有序的一维数组做二分，`mid` 转换为 `(mid // n, mid % n)`。

**展开理解：** 每行有序且下一行首元素大于上一行尾元素，所以矩阵按行展开就是一维有序数组。二分中的虚拟下标 mid 映射为 row=mid//n、col=mid%n，无需真正展开。

```python
def searchMatrix(matrix, target):
    m, n = len(matrix), len(matrix[0])
    l, r = 0, m * n - 1
    while l <= r:
        mid = (l + r) // 2
        val = matrix[mid // n][mid % n]
        if val == target:
            return True
        elif val < target:
            l = mid + 1
        else:
            r = mid - 1
    return False
```

**复杂度：**
- 时间：O(log(m × n))
- 空间：O(1)

## 153. 寻找旋转排序数组中的最小值

**题目描述：** 旋转排序数组（无重复元素），找最小值。

**示例：** 输入：`nums = [3,4,5,1,2]`；输出：`1`。

**思路：** 二分。若 `nums[mid] > nums[r]`，最小值在右半段；否则在左半段（含 mid）。

**展开理解：** 把右端点作为参照：mid 大于 right 说明 mid 位于旋转前的高值段，最小值一定在右侧；否则 mid 位于低值段且可能就是最小值，所以收缩右边界到 mid。

```python
def findMin(nums):
    l, r = 0, len(nums) - 1
    while l < r:
        mid = (l + r) // 2
        if nums[mid] > nums[r]:
            l = mid + 1
        else:
            r = mid
    return nums[l]
```

**复杂度：**
- 时间：O(log n)
- 空间：O(1)

## 33. 搜索旋转排序数组

**题目描述：** 旋转排序数组（无重复元素）中搜索目标值，返回索引或 -1。

**示例：** 输入：`nums = [4,5,6,7,0,1,2], target = 0`；输出：`4`。

**思路：** 二分时，先判断哪半段是有序的，再根据 target 是否在有序区间内决定收缩方向。

**展开理解：** 旋转数组至少有一半有序。先判断 mid 落在哪个有序半段，再判断 target 是否落在这个半段的闭区间内；若在就保留该侧，否则去另一侧，每轮排除至少一半。

```python
def search(nums, target):
    l, r = 0, len(nums) - 1
    while l <= r:
        mid = (l + r) // 2
        if nums[mid] == target:
            return mid
        # 左半段有序
        if nums[l] <= nums[mid]:
            if nums[l] <= target < nums[mid]:
                r = mid - 1
            else:
                l = mid + 1
        # 右半段有序
        else:
            if nums[mid] < target <= nums[r]:
                l = mid + 1
            else:
                r = mid - 1
    return -1
```

**复杂度：**
- 时间：O(log n)
- 空间：O(1)

## 34. 在排序数组中查找元素的第一个和最后一个位置

**题目描述：** 给定有序数组，找目标值的第一个和最后一个出现位置，不存在则返回 [-1, -1]。

**示例：** 输入：`nums = [5,7,7,8,8,10], target = 8`；输出：`[3,4]`。

**思路：** 两次二分：一次找「第一个 >= target」的位置（左边界），一次找「第一个 > target」的位置再减 1（右边界）。

**展开理解：** 左边界是第一个 `>= target` 的位置，右边界可转化为第一个 `> target` 的位置减一。这里的 `lower_bound` 维护左闭右开区间 `[l, r)`，因此右边界初始化为 `len(nums)`，并在 `l == r` 时结束。统一使用这个模板能减少边界错误；最后还要检查左边界是否越界或值不等于 target。

```python
def searchRange(nums, target):
    def lower_bound(target):
        l, r = 0, len(nums)
        while l < r:
            mid = (l + r) // 2
            if nums[mid] < target:
                l = mid + 1
            else:
                r = mid
        return l

    left = lower_bound(target)
    if left == len(nums) or nums[left] != target:
        return [-1, -1]
    return [left, lower_bound(target + 1) - 1]
```

**复杂度：**
- 时间：O(log n)
- 空间：O(1)
