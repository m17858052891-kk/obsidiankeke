## 121. 买卖股票的最佳时机

**题目描述：** 给定股票每日价格，只能买卖一次，返回最大利润。

**示例：** 输入：`prices = [7,1,5,3,6,4]`；输出：`5`。

**思路：** 贪心，记录历史最低价，每天计算「以今日价格卖出的最大利润」并更新答案。

```python
def maxProfit(prices):
    min_price = float('inf')
    ans = 0
    for price in prices:
        min_price = min(min_price, price)
        ans = max(ans, price - min_price)
    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 55. 跳跃游戏

**题目描述：** 给定跳跃长度数组，从索引 0 出发，判断是否能到达最后一个索引。

**示例：** 输入：`nums = [2,3,1,1,4]`；输出：`true`。

**思路：** 贪心，维护「能到达的最远位置」`max_reach`，遍历时若当前索引超过 `max_reach` 则无法继续。

```python
def canJump(nums):
    max_reach = 0
    for i, jump in enumerate(nums):
        if i > max_reach:
            return False
        max_reach = max(max_reach, i + jump)
    return True
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 45. 跳跃游戏 II

**题目描述：** 给定跳跃长度数组，求从索引 0 到最后一个索引的最少跳跃次数。

**示例：** 输入：`nums = [2,3,1,1,4]`；输出：`2`。

**思路：** 贪心，维护「当前跳跃能覆盖的最远距离」`cur_end` 和「下一跳能覆盖的最远距离」`far`。到达 `cur_end` 时必须跳一次。

```python
def jump(nums):
    jumps = cur_end = far = 0
    for i in range(len(nums) - 1):
        far = max(far, i + nums[i])
        if i == cur_end:
            jumps += 1
            cur_end = far
    return jumps
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 763. 划分字母区间

**题目描述：** 给定字符串，尽量多地划分成若干片段，使每种字母最多出现在一个片段，返回各片段长度。

**示例：** 输入：`s = "ababcbacadefegdehijhklij"`；输出：`[9,7,8]`。

**思路：** 先记录每个字母最后出现的位置。遍历字符串，维护当前片段的结束位置（取当前字母最后位置和已有结束位置的较大值），到达结束位置时分割。

```python
def partitionLabels(s):
    last = {ch: i for i, ch in enumerate(s)}
    res = []
    start = end = 0
    for i, ch in enumerate(s):
        end = max(end, last[ch])
        if i == end:
            res.append(end - start + 1)
            start = i + 1
    return res
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)（26 个字母的固定空间）

## 135. 分发糖果

**题目描述：** n 个孩子站成一排，每人有一个评分，要求评分高的孩子比相邻孩子获得更多糖果，每人至少 1 颗，求最少需要多少颗糖果。

**示例：** 输入：`ratings = [1,0,2]`；输出：`5`。

**思路：** 两次贪心。从左到右：比左邻高分则+1；从右到左：比右邻高分则取 max(当前, 右邻+1)。

```python
def candy(ratings):
    n = len(ratings)
    candies = [1] * n
    # 从左到右
    for i in range(1, n):
        if ratings[i] > ratings[i - 1]:
            candies[i] = candies[i - 1] + 1
    # 从右到左
    for i in range(n - 2, -1, -1):
        if ratings[i] > ratings[i + 1]:
            candies[i] = max(candies[i], candies[i + 1] + 1)
    return sum(candies)
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)

## 406. 根据身高重建队列

**题目描述：** 每个人 `[h, k]` 代表身高 h，前面恰好有 k 个身高 >= h 的人。给定打乱后的队列，重建它。

**示例：** 输入：`people = [[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]`；输出：`[[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]`。

**思路：** 按身高降序、k 值升序排列后，依次将每个人插入到索引 k 处（身高较低的人插入不影响已插入高个子的 k 值）。

```python
def reconstructQueue(people):
    people.sort(key=lambda x: (-x[0], x[1]))
    res = []
    for person in people:
        res.insert(person[1], person)
    return res
```

**复杂度：**
- 时间：O(n²)（insert 操作 O(n)）
- 空间：O(n)

## 452. 用最少数量的箭引爆气球

**题目描述：** 给定气球水平直径的区间，一支箭能引爆所有包含该 x 坐标的气球，返回最少箭数。

**示例：** 输入：`points = [[10,16],[2,8],[1,6],[7,12]]`；输出：`2`。

**思路：** 按区间右端点排序，贪心：一支箭射在当前区间的右端，能引爆所有与其重叠的区间。

```python
def findMinArrowShots(points):
    points.sort(key=lambda x: x[1])
    arrows = 1
    end = points[0][1]
    for start, finish in points[1:]:
        if start > end:   # 当前气球不被覆盖，需要新的箭
            arrows += 1
            end = finish
    return arrows
```

**复杂度：**
- 时间：O(n log n)
- 空间：O(1)

## 435. 无重叠区间

**题目描述：** 给定区间集合，找最少需要移除多少区间才能使剩下的区间互不重叠。

**示例：** 输入：`intervals = [[1,2],[2,3],[3,4],[1,3]]`；输出：`1`。

**思路：** 等价于找最多不重叠区间数（贪心：按右端点排序，尽量保留右端点小的区间）。结果 = 总区间数 - 最多不重叠数。

```python
def eraseOverlapIntervals(intervals):
    intervals.sort(key=lambda x: x[1])
    count = 0   # 需要移除的数量
    end = float('-inf')
    for start, finish in intervals:
        if start >= end:
            end = finish   # 保留该区间
        else:
            count += 1     # 移除该区间（与上一个重叠）
    return count
```

**复杂度：**
- 时间：O(n log n)
- 空间：O(1)
