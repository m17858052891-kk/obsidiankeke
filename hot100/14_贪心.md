## 121. 买卖股票的最佳时机

**题目描述：** 给定股票每日价格，只能买卖一次，返回最大利润。

**示例：** 输入：`prices = [7,1,5,3,6,4]`；输出：`5`。

**思路：** 贪心，记录历史最低价，每天计算「以今日价格卖出的最大利润」并更新答案。

**展开理解：** 遍历到某天时，若今天卖出，最佳买入一定是此前最低价。维护历史最低价就等价于枚举所有合法买卖对但不实际二重循环；必须先更新或比较时确保不会使用未来价格。

```python
def maxProfit(prices):
    min_price = float('inf')
    ans = 0
    for price in prices:
        min_price = min(min_price, price)
        ans = max(ans, price - min_price)
    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 55. 跳跃游戏

**题目描述：** 给定跳跃长度数组，从索引 0 出发，判断是否能到达最后一个索引。

**示例：** 输入：`nums = [2,3,1,1,4]`；输出：`true`。

**思路：** 贪心，维护「能到达的最远位置」`max_reach`，遍历时若当前索引超过 `max_reach` 则无法继续。

**展开理解：** 扫描到 i 时，max_reach 表示利用前面所有可达位置能到达的最远下标。若 i 超过它，后面再大的跳跃也无法被触发；否则用 i+nums[i] 更新覆盖范围。

```python
def canJump(nums):
    max_reach = 0
    for i, jump in enumerate(nums):
        if i > max_reach:
            return False
        max_reach = max(max_reach, i + jump)
    return True
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 45. 跳跃游戏 II

**题目描述：** 给定跳跃长度数组，求从索引 0 到最后一个索引的最少跳跃次数。

**示例：** 输入：`nums = [2,3,1,1,4]`；输出：`2`。

**思路：** 贪心，维护「当前跳跃能覆盖的最远距离」`cur_end` 和「下一跳能覆盖的最远距离」`far`。到达 `cur_end` 时必须跳一次。

**展开理解：** 把一次跳跃能覆盖的区间看作 BFS 的一层。在扫描当前层 [上一边界,cur_end] 时计算下一层最远 far，到达 cur_end 才统一增加一步并扩展边界，因此每层用能到最远的位置。

```python
def jump(nums):
    jumps = cur_end = far = 0
    for i in range(len(nums) - 1):
        far = max(far, i + nums[i])
        if i == cur_end:
            jumps += 1
            cur_end = far
    return jumps
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 763. 划分字母区间

**题目描述：** 给定字符串，尽量多地划分成若干片段，使每种字母最多出现在一个片段，返回各片段长度。

**示例：** 输入：`s = "ababcbacadefegdehijhklij"`；输出：`[9,7,8]`。

**思路：** 先记录每个字母最后出现的位置。遍历字符串，维护当前片段的结束位置（取当前字母最后位置和已有结束位置的较大值），到达结束位置时分割。

**展开理解：** 一个片段若包含某字符，就必须延伸到该字符最后一次出现的位置；延伸过程中遇到的新字符可能继续推远边界。扫描到当前确定的 end 时，片段中所有字符的最后位置都已被覆盖，可以安全切分。

```python
def partitionLabels(s):
    last = {ch: i for i, ch in enumerate(s)}
    res = []
    start = end = 0
    for i, ch in enumerate(s):
        end = max(end, last[ch])
        if i == end:
            res.append(end - start + 1)
            start = i + 1
    return res
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)（26 个字母的固定空间）
