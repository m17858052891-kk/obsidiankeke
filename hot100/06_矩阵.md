## 73. 矩阵置零

**题目描述：** 给定 m×n 矩阵，若某元素为 0，则将其所在行和列全部置零（原地）。

**示例：** 输入：`matrix = [[1,1,1],[1,0,1],[1,1,1]]`；输出：`[[1,0,1],[0,0,0],[1,0,1]]`。

**思路：** 用矩阵第一行和第一列作为标记数组，额外用两个变量记录第一行/列自身是否含 0，避免使用额外空间。

```python
class Solution(object):
    def setZeroes(self, matrix):
        m = len(matrix)
        n = len(matrix[0])
        # 1. 准备两个小本本，记录需要置零的行号和列号
        row_zeros = set()
        col_zeros = set()
        # 2. 侦查阶段：只记录，不修改！
        for i in range(m):
            for j in range(n):
                if matrix[i][j] == 0:
                    row_zeros.add(i)
                    col_zeros.add(j)
        # 3. 执行阶段：根据记录修改矩阵
        for i in range(m):
            for j in range(n):
                # 只要当前行 在黑名单里，或者当前列 在黑名单里
                if i in row_zeros or j in col_zeros:
                    matrix[i][j] = 0
```

**复杂度：**
- 时间：O(m × n)
- 空间：O(1)

## 54. 螺旋矩阵

**题目描述：** 给定 m×n 矩阵，按螺旋顺序返回所有元素。

**示例：** 输入：`matrix = [[1,2,3],[4,5,6],[7,8,9]]`；输出：`[1,2,3,6,9,8,7,4,5]`。

**思路：** 维护四个边界 `top, bottom, left, right`，依次向右、向下、向左、向上遍历，每完成一方向就收缩对应边界。

```python
def spiralOrder(matrix):
    res = []
    top, bottom = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1
    while top <= bottom and left <= right:
        for j in range(left, right + 1):
            res.append(matrix[top][j])
        top += 1
        for i in range(top, bottom + 1):
            res.append(matrix[i][right])
        right -= 1
        if top <= bottom:
            for j in range(right, left - 1, -1):
                res.append(matrix[bottom][j])
            bottom -= 1
        if left <= right:
            for i in range(bottom, top - 1, -1):
                res.append(matrix[i][left])
            left += 1
    return res
```

**复杂度：**
- 时间：O(m × n)
- 空间：O(1)（不计输出）

## 48. 旋转图像

**题目描述：** 将 n×n 矩阵顺时针旋转 90°（原地）。

**示例：** 输入：`matrix = [[1,2,3],[4,5,6],[7,8,9]]`；输出：`[[7,4,1],[8,5,2],[9,6,3]]`。

**思路：** 先沿主对角线转置（`matrix[i][j]` 和 `matrix[j][i]` 互换），再将每行左右翻转。

```python
def rotate(matrix):
    n = len(matrix)
    # 转置
    for i in range(n):
        for j in range(i + 1, n):
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
    # 每行翻转
    for row in matrix:
        row.reverse()
```

**复杂度：**
- 时间：O(n²)
- 空间：O(1)

## 240. 搜索二维矩阵 II

**题目描述：** m×n 矩阵每行从左到右升序，每列从上到下升序，判断目标值是否存在。

**示例：** 输入：`matrix = [[1,4,7,11],[2,5,8,12],[3,6,9,16]], target = 5`；输出：`true`。

**思路：** 从右上角出发。若当前值等于 target 返回 True；若大于 target 则左移（排除整列）；若小于 target 则下移（排除整行）。

```python
def searchMatrix(matrix, target):
    row, col = 0, len(matrix[0]) - 1
    while row < len(matrix) and col >= 0:
        val = matrix[row][col]
        if val == target:
            return True
        elif val > target:
            col -= 1
        else:
            row += 1
    return False
```

**复杂度：**
- 时间：O(m + n)
- 空间：O(1)
