## 1. 两数之和

**题目描述：** 给定整数数组 `nums` 和目标值 `target`，返回两个数之和等于 `target` 的下标。

**示例：** 输入：`nums = [2,7,11,15], target = 9`；输出：`[0,1]`。

**思路：** 遍历时用 HashMap 记录「已见过的值 → 索引」，对每个 `num` 检查 `target - num` 是否在表中，O(1) 查找。

**展开理解：** 关键是不先固定两数，而是在遍历到当前数时，把问题转成“补数是否已经出现”。先查后存可以避免同一个下标被使用两次；哈希表始终保存当前下标之前的元素，因此找到补数时答案一定由两个不同位置组成。

```python
def twoSum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        find = target - num
        if find in seen:
            return [seen[find], i]
        seen[num] = i
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)

## 49. 字母异位词分组

**题目描述：** 给定字符串数组，将字母异位词归为一组后返回。

**示例：** 输入：`strs = ["eat","tea","tan","ate","nat","bat"]`；输出：`[["bat"],["nat","tan"],["ate","eat","tea"]]`。

**思路：** 用 26 维字符频次数组作为 HashMap 的 key，相同 key 的字符串互为异位词。

**展开理解：** 异位词的本质是不关心字符顺序、只关心每个字符出现的次数。题目限定小写英文字母，因此 26 维计数元组可以作为规范表示，把每个单词的处理时间从排序的 O(k log k) 降到 O(k)。

```python
from collections import defaultdict

def groupAnagrams(strs):
    groups = defaultdict(list)
    for s in strs:
        counts = [0] * 26
        for ch in s:
            counts[ord(ch) - ord('a')] += 1
        groups[tuple(counts)].append(s)
    return list(groups.values())
```

**复杂度：**
- 时间：O(n · k)，k 为字符串最大长度
- 空间：O(n · k)

## 128. 最长连续序列

**题目描述：** 给定未排序整数数组，找出最长连续整数序列的长度，要求时间 O(n)。

**示例：** 输入：`nums = [100,4,200,1,3,2]`；输出：`4`。

**思路：** 先将所有数放入 HashSet。只从「序列起点」（即 `num-1` 不在 set 中）开始向后延伸计数，避免重复遍历。

**展开理解：** 若从序列中间每次向后扩展，同一连续段会被重复扫描。只允许 num-1 不存在的元素发起扩展后，每个数最多作为集合元素被访问常数次，所以嵌套 while 的总成本仍是 O(n)，而不是 O(n²)。

```python
def longestConsecutive(nums):
    num_set = set(nums)
    best = 0
    for num in num_set:
        if num - 1 not in num_set:   # 只从序列头部开始
            cur = num
            length = 1
            while cur + 1 in num_set:
                cur += 1
                length += 1
            best = max(best, length)
    return best
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)
