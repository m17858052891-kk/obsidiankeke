## 1. 两数之和

**题目描述：** 给定整数数组 `nums` 和目标值 `target`，返回两个数之和等于 `target` 的下标。

**示例：** 输入：`nums = [2,7,11,15], target = 9`；输出：`[0,1]`。

**思路：** 遍历时用 HashMap 记录「已见过的值 → 索引」，对每个 `num` 检查 `target - num` 是否在表中，O(1) 查找。

```python
def twoSum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        find = target - num
        if find in seen:
            return [seen[find], i]
        seen[num] = i
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)

## 49. 字母异位词分组

**题目描述：** 给定字符串数组，将字母异位词归为一组后返回。

**示例：** 输入：`strs = ["eat","tea","tan","ate","nat","bat"]`；输出：`[["bat"],["nat","tan"],["ate","eat","tea"]]`。

**思路：** 对每个字符串排序后作为 HashMap 的 key，相同 key 的字符串互为异位词。

```python
from collections import defaultdict

def groupAnagrams(strs):
    groups = defaultdict(list)
    for s in strs:
        key = tuple(sorted(s))
        groups[key].append(s)
    return list(groups.values())
```

**复杂度：**
- 时间：O(n · k log k)，k 为字符串最大长度
- 空间：O(n · k)

## 128. 最长连续序列

**题目描述：** 给定未排序整数数组，找出最长连续整数序列的长度，要求时间 O(n)。

**示例：** 输入：`nums = [100,4,200,1,3,2]`；输出：`4`。

**思路：** 先将所有数放入 HashSet。只从「序列起点」（即 `num-1` 不在 set 中）开始向后延伸计数，避免重复遍历。

```python
def longestConsecutive(nums):
    num_set = set(nums)
    best = 0
    for num in num_set:
        if num - 1 not in num_set:   # 只从序列头部开始
            cur = num
            length = 1
            while cur + 1 in num_set:
                cur += 1
                length += 1
            best = max(best, length)
    return best
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)
