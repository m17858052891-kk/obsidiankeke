## 53. 最大子数组和

**题目描述：** 给定整数数组，找具有最大和的连续子数组，返回其和。

**示例：** 输入：`nums = [-2,1,-3,4,-1,2,1,-5,4]`；输出：`6`，对应子数组 `[4,-1,2,1]`。

**思路（Kadane 算法）：** 维护「以当前元素结尾的最大子数组和」`cur`。若 `cur` 变负则重置为 0（抛弃之前的子数组）。

**展开理解：** 定义状态为“必须以当前位置结尾的最大子数组和”。前一状态若为负，只会拖累当前元素，所以从当前元素重新开始；否则接在前一段后面。全局答案要在每个结尾状态中取最大，且初始化必须兼容全负数组。

```python
class Solution(object):
    def maxSubArray(self, nums):
        cur_total=0
        max_total=float('-inf')
        for num in nums:
            cur_total+=num
            max_total=max(max_total,cur_total)
            if cur_total<0:
                cur_total=0
        return max_total
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 56. 合并区间

**题目描述：** 给出若干区间，合并所有重叠区间后返回。

**示例：** 输入：`intervals = [[1,3],[2,6],[8,10],[15,18]]`；输出：`[[1,6],[8,10],[15,18]]`。

**思路：** 按左端点排序后，逐个检查当前区间与结果末尾是否重叠（`start <= res[-1][1]`），重叠则合并（更新 end），否则直接追加。

**展开理解：** 按左端点排序后，尚未处理区间不可能从结果末尾区间的左边插入。若当前左端点不超过末尾右端点，两者属于同一连通覆盖段，只需扩展右边界；否则它与此前所有区间都不重叠，可以开启新区间。

```python
def merge(intervals):
    intervals.sort(key=lambda x: x[0])
    res = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= res[-1][1]:
            res[-1][1] = max(res[-1][1], end)
        else:
            res.append([start, end])
    return res
```

**复杂度：**
- 时间：O(n log n)
- 空间：O(n)

## 189. 轮转数组

**题目描述：** 将数组向右轮转 `k` 步（原地）。

**示例：** 输入：`nums = [1,2,3,4,5,6,7], k = 3`；输出：`[5,6,7,1,2,3,4]`。

**思路（三次翻转）：** 整体翻转 → 翻转前 k 个 → 翻转后 n-k 个，即可得到右移 k 步的结果。

**展开理解：** 整体翻转把末尾 k 个元素送到前面，但两段内部顺序都反了；分别翻转前 k 段和后 n-k 段即可恢复各自顺序。先做 k%=n 处理 k 大于长度，空数组还需单独判断。

```python
def rotate(nums, k):
    n = len(nums)
    if n == 0:
        return
    k %= n

    def reverse(l, r):
        while l < r:
            nums[l], nums[r] = nums[r], nums[l]
            l += 1
            r -= 1

    reverse(0, n - 1)
    reverse(0, k - 1)
    reverse(k, n - 1)
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 238. 除自身以外数组的乘积

**题目描述：** 返回数组 `answer`，`answer[i]` 等于除 `nums[i]` 之外其余元素的乘积，不使用除法。

**示例：** 输入：`nums = [1,2,3,4]`；输出：`[24,12,8,6]`。

**思路：** 两次遍历。第一次从左到右记录「左前缀积」，第二次从右到左乘上「右后缀积」。

**展开理解：** answer[i] 需要左侧所有数乘积与右侧所有数乘积。第一遍让 answer[i] 保存不含自身的左前缀积，第二遍维护一个滚动右后缀积并乘进去；全程不使用除法，所以天然兼容数组中含零。

```python
def productExceptSelf(nums):
    n = len(nums)
    res = [1] * n
    # 左前缀积
    prefix = 1
    for i in range(n):
        res[i] = prefix
        prefix *= nums[i]
    # 右后缀积
    suffix = 1
    for i in range(n - 1, -1, -1):
        res[i] *= suffix
        suffix *= nums[i]
    return res
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)（输出数组不计）

## 41. 缺失的第一个正数

**题目描述：** 给定未排序整数数组，找出缺失的最小正整数，要求 O(n) 时间、O(1) 空间。

**示例：** 输入：`nums = [3,4,-1,1]`；输出：`2`。

**思路（原地哈希）：** 将每个满足 `1 <= nums[i] <= n` 的数放到其"应在"的位置（`nums[nums[i]-1] = nums[i]`）。第二次遍历找第一个 `nums[i] != i+1` 的位置。

**展开理解：** 答案一定在 [1,n+1]：长度为 n 的数组最多覆盖 n 个不同正数。把值 x 放到下标 x-1，相当于用数组本身做哈希表；while 而非 if 是因为一次交换后当前位置换来的数可能仍需继续归位，重复值判断用于防止死循环。

```python
def firstMissingPositive(nums):
    n = len(nums)
    for i in range(n):
        while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
            nums[nums[i] - 1], nums[i] = nums[i], nums[nums[i] - 1]
    for i in range(n):
        if nums[i] != i + 1:
            return i + 1
    return n + 1
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)
