## 160. 相交链表

**题目描述：** 找出两个链表的交点节点。

**示例：** 输入：`intersectVal = 8, listA = [4,1,8,4,5], listB = [5,6,1,8,4,5]`；输出：相交节点 `8`。

**思路：** 双指针各走完自己链表后切换到对方链表。若相交，两指针走过的总步数相等时会在交点相遇；若不相交，会同时到达 None。

**展开理解：** 设 A 独有长度 a、B 独有长度 b、公共尾部 c。两个指针分别走 A→B 与 B→A，路程都是 a+b+c，因此会在交点同步；无交点时则同时走到 None。比较的是节点身份，不是节点值。

```python
def getIntersectionNode(headA, headB):
    a, b = headA, headB
    while a != b:
        a = a.next if a else headB
        b = b.next if b else headA
    return a
```

**复杂度：**
- 时间：O(m + n)
- 空间：O(1)

## 206. 反转链表

**题目描述：** 反转单链表。

**示例：** 输入：`head = [1,2,3,4,5]`；输出：`[5,4,3,2,1]`。

**思路：** 迭代法，维护 `prev`、`cur` 两个指针逐步反转指向。

**展开理解：** 每次反转前先保存 cur.next，否则改指针后会丢失剩余链表。循环不变量是 prev 指向已经完全反转的前缀，cur 指向尚未处理的后缀；结束时 cur 为空，prev 就是新头。

```python
def reverseList(head):
    prev, cur = None, head
    while cur:
        nxt = cur.next
        cur.next = prev
        prev = cur
        cur = nxt
    return prev
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 234. 回文链表

**题目描述：** 判断链表是否为回文结构。

**示例：** 输入：`head = [1,2,2,1]`；输出：`true`。

**思路：** 快慢指针找中点 → 翻转后半段 → 逐一比较 → 恢复链表。

**展开理解：** 快慢指针让 slow 到达中点，反转后半段后只需比较后半段长度。奇数长度时中点无需配对；工程上最好再反转一次恢复原链表，避免函数产生隐藏副作用。

```python
def isPalindrome(head):
    if not head or not head.next:
        return True

    slow = fast = head
    while fast.next and fast.next.next:
        slow = slow.next
        fast = fast.next.next

    # 翻转并保存后半段头节点。
    prev = None
    cur = slow.next
    while cur:
        nxt = cur.next
        cur.next = prev
        prev = cur
        cur = nxt

    l, r = head, prev
    is_palindrome = True
    while r:
        if l.val != r.val:
            is_palindrome = False
            break
        l = l.next
        r = r.next

    # 再反转一次，恢复输入链表。
    cur = prev
    restored = None
    while cur:
        nxt = cur.next
        cur.next = restored
        restored = cur
        cur = nxt
    slow.next = restored
    return is_palindrome
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 141. 环形链表

**题目描述：** 判断链表是否有环。

**示例：** 输入：`head = [3,2,0,-4], pos = 1`；输出：`true`。

**思路：** 快慢指针，若有环快慢指针必定相遇。

**展开理解：** 有环时快指针每轮相对慢指针多走一步，在有限环上相对距离必然取到 0；无环时 fast 或 fast.next 会先为空。不要用节点值判环，因为不同节点可以有相同值。

```python
def hasCycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            return True
    return False
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 142. 环形链表 II

**题目描述：** 找出链表开始入环的第一个节点。

**示例：** 输入：`head = [3,2,0,-4], pos = 1`；输出：返回入环节点 `2`。

**思路：** 快慢指针相遇后，将一个指针移到 head，两指针同速前进，再次相遇即为入环点（数学推导：相遇点到入环点距离 = head 到入环点距离）。

**展开理解：** 设头到入口为 a，入口到相遇点为 b，环剩余为 c；相遇时有 2(a+b)=a+b+k(b+c)，可推出 a=(k-1)(b+c)+c。因此一个指针回到头、另一个留在相遇点，同速走会在入口相遇。

```python
def detectCycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            fast = head
            while fast != slow:
                fast = fast.next
                slow = slow.next
            return fast 
    return None
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 21. 合并两个有序链表

**题目描述：** 将两个升序链表合并为一个升序链表。

**示例：** 输入：`list1 = [1,2,4], list2 = [1,3,4]`；输出：`[1,1,2,3,4,4]`。

**思路：** 哑节点 + 双指针逐个比较，较小值接入结果链表。

**展开理解：** dummy 统一处理结果头节点，cur 始终指向已合并部分的尾部。两表头是各自剩余部分的最小值，取较小者不会错过更优顺序；一表耗尽后直接接上另一表剩余有序段。

```python
def mergeTwoLists(l1, l2):
    dummy = cur = ListNode(0)
    while l1 and l2:
        if l1.val <= l2.val:
            cur.next = l1
            l1 = l1.next
        else:
            cur.next = l2
            l2 = l2.next
        cur = cur.next
    cur.next = l1 or l2
    return dummy.next
```

**复杂度：**
- 时间：O(m + n)
- 空间：O(1)

## 2. 两数相加

**题目描述：** 两个非负整数分别以逆序链表存储，返回其和的逆序链表。

**示例：** 输入：`l1 = [2,4,3], l2 = [5,6,4]`；输出：`[7,0,8]`。

**思路：** 模拟竖式加法，维护进位 `carry`，同步遍历两链表。

**展开理解：** 链表按低位到高位存储，恰好适合从头模拟竖式加法。每轮计算两节点值加 carry，用 divmod 得到新位与新进位；循环条件必须包含 carry，才能处理最后多出一位。

```python
def addTwoNumbers(l1, l2):
    dummy = cur = ListNode(0)
    carry = 0
    while l1 or l2 or carry:
        val = carry
        if l1:
            val += l1.val
            l1 = l1.next
        if l2:
            val += l2.val
            l2 = l2.next
        carry, digit = divmod(val, 10)
        cur.next = ListNode(digit)
        cur = cur.next
    return dummy.next
```

**复杂度：**
- 时间：O(max(m, n))
- 空间：O(max(m, n))

## 19. 删除链表的倒数第 N 个结点

**题目描述：** 删除链表倒数第 n 个节点，一次遍历完成。

**示例：** 输入：`head = [1,2,3,4,5], n = 2`；输出：`[1,2,3,5]`。

**思路：** 快指针先走 n+1 步，然后快慢同步前进，当快指针到达 None 时慢指针恰好指向待删节点的前驱。

**展开理解：** dummy 让删除头节点与删除中间节点统一。fast 先比 slow 多走 n+1 步，之后同步前进时二者间隔保持 n+1；fast 到 None 时 slow 正好位于倒数第 n 个节点的前驱。

```python
def removeNthFromEnd(head, n):
    dummy = ListNode(0, head)
    fast = slow = dummy
    for _ in range(n + 1):
        fast = fast.next
    while fast:
        fast = fast.next
        slow = slow.next
    slow.next = slow.next.next
    return dummy.next
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 24. 两两交换链表中的节点

**题目描述：** 两两交换相邻节点（不得修改节点值）。

**示例：** 输入：`head = [1,2,3,4]`；输出：`[2,1,4,3]`。

**思路：** 哑节点辅助，每次处理 `prev → A → B → ...` 变为 `prev → B → A → ...`。

**展开理解：** 每轮只重连三个接口：前驱指向 B、B 指向 A、A 指向下一段。完成后 A 成为这一组的尾部，也是下一轮的 prev；先保存 A、B 和后继关系能避免断链。

```python
def swapPairs(head):
    dummy = ListNode(0, head)
    prev = dummy
    while prev.next and prev.next.next:
        a = prev.next
        b = prev.next.next
        prev.next = b
        a.next = b.next
        b.next = a
        prev = a
    return dummy.next
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 25. K 个一组翻转链表

**题目描述：** 每 k 个节点一组翻转链表，不足 k 个的保持原顺序。

**示例：** 输入：`head = [1,2,3,4,5], k = 2`；输出：`[2,1,4,3,5]`。

**思路：** 找到每组的头尾，翻转该段，再拼接到结果链表。

**展开理解：** 先确认从 group_prev 后确实有 k 个节点，不足 k 个则原样保留。翻转时把区间视作 [group_start, group_next)，完成后旧组头变成组尾，再连接前后两段；边界比翻转本身更重要。

```python
def reverseKGroup(head, k):
    dummy = ListNode(0, head)
    group_prev = dummy

    def get_kth(node, k):
        while node and k > 0:
            node = node.next
            k -= 1
        return node

    while True:
        kth = get_kth(group_prev, k)
        if not kth:
            break
        group_next = kth.next
        # 翻转 group_prev.next 到 kth
        prev, cur = group_next, group_prev.next
        while cur != group_next:
            nxt = cur.next
            cur.next = prev
            prev = cur
            cur = nxt
        tmp = group_prev.next
        group_prev.next = kth
        group_prev = tmp
    return dummy.next
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 138. 随机链表的复制

**题目描述：** 复制含随机指针的链表，random 可指向任意节点或 None。

**示例：** 输入：`head = [[7,null],[13,0],[11,4],[10,2],[1,0]]`；输出：深拷贝后的同结构链表。

本题节点除了 `next` 之外还有 `random` 指针，使用下面的节点定义：

```python
class Node:
    def __init__(self, val=0, next=None, random=None):
        self.val = val
        self.next = next
        self.random = random
```

**思路：** 将复制节点插入原节点之后，利用相邻关系设置 random，最后拆分两条链表。

**展开理解：** 把复制节点直接插到对应原节点后面后，原节点 `cur` 的复制节点就是 `cur.next`，其 random 应指向 `cur.random.next`。这样原链表本身临时承担了映射表的作用；设置完成后再拆分并恢复原链表，可将额外空间降到 O(1)。

```python
def copyRandomList(head):
    if not head:
        return None

    # A -> B 变为 A -> A' -> B -> B'。
    cur = head
    while cur:
        copy = Node(cur.val)
        copy.next = cur.next
        cur.next = copy
        cur = copy.next

    # A'.random = A.random 对应复制节点。
    cur = head
    while cur:
        if cur.random:
            cur.next.random = cur.random.next
        cur = cur.next.next

    # 拆分复制链表，同时恢复原链表。
    copy_head = head.next
    cur = head
    while cur:
        copy = cur.next
        cur.next = copy.next
        copy.next = copy.next.next if copy.next else None
        cur = cur.next
    return copy_head
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)（不计返回的新链表）

## 148. 排序链表

**题目描述：** 对链表进行 O(n log n) 排序。

**示例：** 输入：`head = [4,2,1,3]`；输出：`[1,2,3,4]`。

**思路：** 自顶向下的归并排序。使用快慢指针找到链表中点，将链表断成两半；递归排序左右两部分，再合并两个有序链表。

**展开理解：** 链表无法随机访问，而归并排序只需要顺序扫描，因此非常适合链表。快指针每次走两步、慢指针每次走一步；快指针到达末尾时，慢指针位于中点附近。递归不断将链表二分，最后再逐层合并。每层合并的总工作量为 O(n)，递归深度为 O(log n)。

```python
class Solution(object):
    def sortList(self, head):
        if not head or not head.next:
            return head

        # 快慢指针寻找中点。
        # fast 从 head.next 开始，使 slow 停在左半部分末尾。
        slow, fast = head, head.next
        while fast and fast.next:
            slow = slow.next
            fast = fast.next.next

        # 从中点断开链表。
        right = slow.next
        slow.next = None

        # 分别排序左右两部分。
        left = self.sortList(head)
        right = self.sortList(right)

        # 合并两个有序链表。
        dummy = cur = ListNode(0)
        while left and right:
            if left.val <= right.val:
                cur.next = left
                left = left.next
            else:
                cur.next = right
                right = right.next
            cur = cur.next

        cur.next = left or right
        return dummy.next
```

**复杂度：**
- 时间：O(n log n)
- 空间：O(log n)，来自递归调用栈

## 23. 合并 K 个升序链表

**题目描述：** 合并 k 个升序链表，返回合并后的升序链表。

**示例：** 输入：`lists = [[1,4,5],[1,3,4],[2,6]]`；输出：`[1,1,2,3,4,4,5,6]`。

**思路：** 最小堆（优先队列）。将每个链表头入堆，每次取最小节点，将其 next 入堆。

**展开理解：** 堆中始终只放每条尚未耗尽链表的当前头，所以堆大小最多 k。弹出的节点是所有剩余节点中的全局最小值；把它的 next 入堆后仍保持该不变量，复杂度 O(N log k)。

```python
import heapq

def mergeKLists(lists):
    dummy = cur = ListNode(0)
    heap = []
    for i, node in enumerate(lists):
        if node:
            heapq.heappush(heap, (node.val, i, node))
    while heap:
        val, i, node = heapq.heappop(heap)
        cur.next = node
        cur = cur.next
        if node.next:
            heapq.heappush(heap, (node.next.val, i, node.next))
    return dummy.next
```

**复杂度：**
- 时间：O(n log k)，n 为总节点数，k 为链表数
- 空间：O(k)

## 146. LRU 缓存

**题目描述：** 实现 LRU 缓存，支持 O(1) 的 `get` 和 `put` 操作。

**示例：** 输入：`LRUCache(2); put(1,1); put(2,2); get(1); put(3,3); get(2)`；输出：`1, -1`。

**思路：** 哈希表 + 双向链表。HashMap 存 key → 节点，双向链表维护访问顺序（头部最新，尾部最旧）。

**展开理解：** 哈希表解决 O(1) 定位，双向链表解决 O(1) 删除与移动。`head` 后面是最新使用的节点，`tail` 前面是最久未使用的节点。`get` 命中后将节点移到最前面；`put` 已有 key 时直接更新节点并移到最前面，新 key 则创建节点。超过容量时删除 `tail.prev`，并同步删除哈希映射。

```python
class LRUCache:
    class Node:
        def __init__(self, key=0, value=0):
            self.key = key
            self.value = value
            self.prev = None
            self.next = None

    def __init__(self, capacity):
        self.capacity = capacity
        self.cache = {}

        # head 后面是最新节点，tail 前面是最旧节点。
        self.head = self.Node()
        self.tail = self.Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def _add_to_front(self, node):
        node.prev = self.head
        node.next = self.head.next
        self.head.next.prev = node
        self.head.next = node

    def _move_to_front(self, node):
        self._remove(node)
        self._add_to_front(node)

    def get(self, key):
        if key not in self.cache:
            return -1

        node = self.cache[key]
        self._move_to_front(node)
        return node.value

    def put(self, key, value):
        if key in self.cache:
            node = self.cache[key]
            node.value = value
            self._move_to_front(node)
            return

        node = self.Node(key, value)
        self.cache[key] = node
        self._add_to_front(node)

        if len(self.cache) > self.capacity:
            lru = self.tail.prev
            self._remove(lru)
            del self.cache[lru.key]
```

**复杂度：**
- 时间：O(1) 的 get 和 put
- 空间：O(capacity)
