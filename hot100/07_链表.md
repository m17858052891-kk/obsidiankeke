## 160. 相交链表

**题目描述：** 找出两个链表的交点节点。

**示例：** 输入：`intersectVal = 8, listA = [4,1,8,4,5], listB = [5,6,1,8,4,5]`；输出：相交节点 `8`。

**思路：** 双指针各走完自己链表后切换到对方链表。若相交，两指针走过的总步数相等时会在交点相遇；若不相交，会同时到达 None。

```python
def getIntersectionNode(headA, headB):
    a, b = headA, headB
    while a != b:
        a = a.next if a else headB
        b = b.next if b else headA
    return a
```

**复杂度：**
- 时间：O(m + n)
- 空间：O(1)

## 206. 反转链表

**题目描述：** 反转单链表。

**示例：** 输入：`head = [1,2,3,4,5]`；输出：`[5,4,3,2,1]`。

**思路：** 迭代法，维护 `prev`、`cur` 两个指针逐步反转指向。

```python
def reverseList(head):
    prev, cur = None, head
    while cur:
        nxt = cur.next
        cur.next = prev
        prev = cur
        cur = nxt
    return prev
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 234. 回文链表

**题目描述：** 判断链表是否为回文结构。

**示例：** 输入：`head = [1,2,2,1]`；输出：`true`。

**思路：** 快慢指针找中点 → 翻转后半段 → 逐一比较 → 恢复链表。

```python
def isPalindrome(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    # 翻转后半段
    prev = None
    cur = slow
    while cur:
        nxt = cur.next
        cur.next = prev
        prev = cur
        cur = nxt
    # 比较
    l, r = head, prev
    while r:
        if l.val != r.val:
            return False
        l = l.next
        r = r.next
    return True
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 141. 环形链表

**题目描述：** 判断链表是否有环。

**示例：** 输入：`head = [3,2,0,-4], pos = 1`；输出：`true`。

**思路：** 快慢指针，若有环快慢指针必定相遇。

```python
def hasCycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            return True
    return False
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 142. 环形链表 II

**题目描述：** 找出链表开始入环的第一个节点。

**示例：** 输入：`head = [3,2,0,-4], pos = 1`；输出：返回入环节点 `2`。

**思路：** 快慢指针相遇后，将一个指针移到 head，两指针同速前进，再次相遇即为入环点（数学推导：相遇点到入环点距离 = head 到入环点距离）。

```python
def detectCycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow == fast:
            fast = head
            while fast != slow:
                fast = fast.next
                slow = slow.next
            return fast 
    return None
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 21. 合并两个有序链表

**题目描述：** 将两个升序链表合并为一个升序链表。

**示例：** 输入：`list1 = [1,2,4], list2 = [1,3,4]`；输出：`[1,1,2,3,4,4]`。

**思路：** 哑节点 + 双指针逐个比较，较小值接入结果链表。

```python
def mergeTwoLists(l1, l2):
    dummy = cur = ListNode(0)
    while l1 and l2:
        if l1.val <= l2.val:
            cur.next = l1
            l1 = l1.next
        else:
            cur.next = l2
            l2 = l2.next
        cur = cur.next
    cur.next = l1 or l2
    return dummy.next
```

**复杂度：**
- 时间：O(m + n)
- 空间：O(1)

## 2. 两数相加

**题目描述：** 两个非负整数分别以逆序链表存储，返回其和的逆序链表。

**示例：** 输入：`l1 = [2,4,3], l2 = [5,6,4]`；输出：`[7,0,8]`。

**思路：** 模拟竖式加法，维护进位 `carry`，同步遍历两链表。

```python
def addTwoNumbers(l1, l2):
    dummy = cur = ListNode(0)
    carry = 0
    while l1 or l2 or carry:
        val = carry
        if l1:
            val += l1.val
            l1 = l1.next
        if l2:
            val += l2.val
            l2 = l2.next
        carry, digit = divmod(val, 10)
        cur.next = ListNode(digit)
        cur = cur.next
    return dummy.next
```

**复杂度：**
- 时间：O(max(m, n))
- 空间：O(max(m, n))

## 19. 删除链表的倒数第 N 个结点

**题目描述：** 删除链表倒数第 n 个节点，一次遍历完成。

**示例：** 输入：`head = [1,2,3,4,5], n = 2`；输出：`[1,2,3,5]`。

**思路：** 快指针先走 n+1 步，然后快慢同步前进，当快指针到达 None 时慢指针恰好指向待删节点的前驱。

```python
def removeNthFromEnd(head, n):
    dummy = ListNode(0, head)
    fast = slow = dummy
    for _ in range(n + 1):
        fast = fast.next
    while fast:
        fast = fast.next
        slow = slow.next
    slow.next = slow.next.next
    return dummy.next
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 24. 两两交换链表中的节点

**题目描述：** 两两交换相邻节点（不得修改节点值）。

**示例：** 输入：`head = [1,2,3,4]`；输出：`[2,1,4,3]`。

**思路：** 哑节点辅助，每次处理 `prev → A → B → ...` 变为 `prev → B → A → ...`。

```python
def swapPairs(head):
    dummy = ListNode(0, head)
    prev = dummy
    while prev.next and prev.next.next:
        a = prev.next
        b = prev.next.next
        prev.next = b
        a.next = b.next
        b.next = a
        prev = a
    return dummy.next
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 25. K 个一组翻转链表

**题目描述：** 每 k 个节点一组翻转链表，不足 k 个的保持原顺序。

**示例：** 输入：`head = [1,2,3,4,5], k = 2`；输出：`[2,1,4,3,5]`。

**思路：** 找到每组的头尾，翻转该段，再拼接到结果链表。

```python
def reverseKGroup(head, k):
    dummy = ListNode(0, head)
    group_prev = dummy

    def get_kth(node, k):
        while node and k > 0:
            node = node.next
            k -= 1
        return node

    while True:
        kth = get_kth(group_prev, k)
        if not kth:
            break
        group_next = kth.next
        # 翻转 group_prev.next 到 kth
        prev, cur = group_next, group_prev.next
        while cur != group_next:
            nxt = cur.next
            cur.next = prev
            prev = cur
            cur = nxt
        tmp = group_prev.next
        group_prev.next = kth
        group_prev = tmp
    return dummy.next
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 138. 随机链表的复制

**题目描述：** 复制含随机指针的链表，random 可指向任意节点或 None。

**示例：** 输入：`head = [[7,null],[13,0],[11,4],[10,2],[1,0]]`；输出：深拷贝后的同结构链表。

**思路：** HashMap 映射原节点 → 新节点。先创建所有新节点，再设置 next 和 random。

```python
def copyRandomList(head):
    if not head:
        return None
    old_to_new = {}
    cur = head
    while cur:
        old_to_new[cur] = Node(cur.val)
        cur = cur.next
    cur = head
    while cur:
        old_to_new[cur].next = old_to_new.get(cur.next)
        old_to_new[cur].random = old_to_new.get(cur.random)
        cur = cur.next
    return old_to_new[head]
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)

## 148. 排序链表

**题目描述：** 对链表进行 O(n log n) 排序。

**示例：** 输入：`head = [4,2,1,3]`；输出：`[1,2,3,4]`。

**思路：** 归并排序。快慢指针找中点，递归排序两半，合并。

```python
def sortList(head):
    if not head or not head.next:
        return head
    slow, fast = head, head.next
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    mid = slow.next
    slow.next = None
    left = sortList(head)
    right = sortList(mid)
    dummy = cur = ListNode(0)
    while left and right:
        if left.val <= right.val:
            cur.next = left
            left = left.next
        else:
            cur.next = right
            right = right.next
        cur = cur.next
    cur.next = left or right
    return dummy.next
```

**复杂度：**
- 时间：O(n log n)
- 空间：O(log n)（递归栈）

## 23. 合并 K 个升序链表

**题目描述：** 合并 k 个升序链表，返回合并后的升序链表。

**示例：** 输入：`lists = [[1,4,5],[1,3,4],[2,6]]`；输出：`[1,1,2,3,4,4,5,6]`。

**思路：** 最小堆（优先队列）。将每个链表头入堆，每次取最小节点，将其 next 入堆。

```python
import heapq

def mergeKLists(lists):
    dummy = cur = ListNode(0)
    heap = []
    for i, node in enumerate(lists):
        if node:
            heapq.heappush(heap, (node.val, i, node))
    while heap:
        val, i, node = heapq.heappop(heap)
        cur.next = node
        cur = cur.next
        if node.next:
            heapq.heappush(heap, (node.next.val, i, node.next))
    return dummy.next
```

**复杂度：**
- 时间：O(n log k)，n 为总节点数，k 为链表数
- 空间：O(k)

## 146. LRU 缓存

**题目描述：** 实现 LRU 缓存，支持 O(1) 的 `get` 和 `put` 操作。

**示例：** 输入：`LRUCache(2); put(1,1); put(2,2); get(1); put(3,3); get(2)`；输出：`1, -1`。

**思路：** 哈希表 + 双向链表。HashMap 存 key → 节点，双向链表维护访问顺序（头部最新，尾部最旧）。

```python
class LRUCache:
    class Node:
        def __init__(self, k=0, v=0):
            self.key, self.val = k, v
            self.prev = self.next = None

    def __init__(self, capacity):
        self.cap = capacity
        self.cache = {}
        self.head = self.Node()   # dummy head（最新）
        self.tail = self.Node()   # dummy tail（最旧）
        self.head.next = self.tail
        self.tail.prev = self.head

    def _remove(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def _insert_front(self, node):
        node.next = self.head.next
        node.prev = self.head
        self.head.next.prev = node
        self.head.next = node

    def get(self, key):
        if key not in self.cache:
            return -1
        node = self.cache[key]
        self._remove(node)
        self._insert_front(node)
        return node.val

    def put(self, key, value):
        if key in self.cache:
            self._remove(self.cache[key])
        node = self.Node(key, value)
        self.cache[key] = node
        self._insert_front(node)
        if len(self.cache) > self.cap:
            lru = self.tail.prev
            self._remove(lru)
            del self.cache[lru.key]
```

**复杂度：**
- 时间：O(1) 的 get 和 put
- 空间：O(capacity)
