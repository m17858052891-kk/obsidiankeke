## 62. 不同路径

**题目描述：** m×n 网格，从左上角到右下角，每次只能向右或向下，共有多少条不同路径。

**示例：** 输入：`m = 3, n = 7`；输出：`28`。

**思路：** `dp[i][j] = dp[i-1][j] + dp[i][j-1]`，第一行和第一列全为 1。使用较短维度作为滚动数组。

**展开理解：** 到格子 (i,j) 的最后一步只能来自上方或左方，两类路径互斥，故相加。第一行第一列只有一种走法；一维 dp 中 dp[j] 是更新前的上方值，dp[j-1] 是更新后的左方值。

```python
def uniquePaths(m, n):
    rows, cols = max(m, n), min(m, n)
    dp = [1] * cols
    for i in range(1, rows):
        for j in range(1, cols):
            dp[j] += dp[j - 1]
    return dp[-1]
```

**复杂度：**
- 时间：O(m × n)
- 空间：O(min(m, n))

## 64. 最小路径和

**题目描述：** m×n 网格，每格有非负整数，从左上角到右下角（只能向右或向下），找最小路径和。

**示例：** 输入：`grid = [[1,3,1],[1,5,1],[4,2,1]]`；输出：`7`。

**思路：** `dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])`，原地修改即可。

**展开理解：** 到每个格子的最小路径只可能从上或左进入，因此取两者较小值再加当前权重。首行首列只有单一路径需单独初始化；可直接复用 grid，但这会修改输入。

```python
def minPathSum(grid):
    m, n = len(grid), len(grid[0])
    for i in range(m):
        for j in range(n):
            if i == 0 and j == 0:
                continue
            elif i == 0:
                grid[i][j] += grid[i][j - 1]
            elif j == 0:
                grid[i][j] += grid[i - 1][j]
            else:
                grid[i][j] += min(grid[i - 1][j], grid[i][j - 1])
    return grid[m - 1][n - 1]
```

**复杂度：**
- 时间：O(m × n)
- 空间：O(1)（原地修改）

## 5. 最长回文子串

**题目描述：** 给定字符串，返回最长回文子串。

**示例：** 输入：`s = "babad"`；输出：`"bab"` 或 `"aba"`。

**思路：** 中心扩展。回文串一定存在一个中心；分别以每个字符、每两个相邻字符为中心向两侧扩展，记录最长区间。

**展开理解：** 奇数长度回文的中心是一个字符，偶数长度回文的中心是两个字符之间的空隙。对每个位置执行两次扩展，只要左右字符相同就继续；扩展结束后得到以该位置为中心的最长回文区间。

```python
def longestPalindrome(s):
    if not s:
        return ""

    def expand(left, right):
        while left >= 0 and right < len(s) and s[left] == s[right]:
            left -= 1
            right += 1
        return left + 1, right - 1

    start = end = 0

    for center in range(len(s)):
        left1, right1 = expand(center, center)      # 奇数长度
        left2, right2 = expand(center, center + 1)  # 偶数长度

        if right1 - left1 > end - start:
            start, end = left1, right1
        if right2 - left2 > end - start:
            start, end = left2, right2

    return s[start:end + 1]
```

**复杂度：**
- 时间：O(n²)
- 空间：O(1)

## 1143. 最长公共子序列

**题目描述：** 给定两个字符串，返回最长公共子序列（LCS）的长度。

**示例：** 输入：`text1 = "abcde", text2 = "ace"`；输出：`3`。

**思路：** 经典二维 DP 的滚动数组优化。`dp[j]` 保存当前行对应前缀的 LCS 长度。


```python
def longestCommonSubsequence(text1, text2):
    if len(text1) < len(text2):
        text1, text2 = text2, text1

    previous = [0] * (len(text2) + 1)

    for char1 in text1:
        current = [0] * (len(text2) + 1)

        for j, char2 in enumerate(text2, 1):
            if char1 == char2:
                current[j] = previous[j - 1] + 1
            else:
                current[j] = max(previous[j], current[j - 1])

        previous = current

    return previous[-1]
```

**复杂度：**
- 时间：O(m × n)
- 空间：O(min(m, n))

## 72. 编辑距离

**题目描述：** 给定两个字符串，计算将 word1 转为 word2 所需的最少操作数（插入、删除、替换）。

**示例：** 输入：`word1 = "horse", word2 = "ros"`；输出：`3`。

**思路：** 二维动态规划。`dp[i][j]` 表示将 `word1[:i]` 转换为 `word2[:j]` 所需的最少操作数。
- 字符相同：`dp[i][j] = dp[i-1][j-1]`
- 字符不同：`dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])`（删/插/替换）

**展开理解：** dp[i][j] 定义前 i 个字符变到前 j 个字符的最少操作。末字符相同无需新操作；不同则分别对应删除 word1 末字符、向 word1 插入 word2 末字符、替换末字符，取三者最小加 1。

```python
def minDistance(word1, word2):
    m, n = len(word1), len(word2)

    dp = [[0] * (n + 1) for _ in range(m + 1)]

    # 空字符串转换为另一个字符串，只能连续插入或删除。
    for i in range(m + 1):
        dp[i][0] = i
    for j in range(n + 1):
        dp[0][j] = j

    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]
            else:
                dp[i][j] = 1 + min(
                    dp[i - 1][j],      # 删除
                    dp[i][j - 1],      # 插入
                    dp[i - 1][j - 1]   # 替换
                )

    return dp[m][n]
```

**复杂度：**
- 时间：O(m × n)
- 空间：O(m × n)
