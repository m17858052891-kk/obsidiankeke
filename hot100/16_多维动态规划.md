## 62. 不同路径

**题目描述：** m×n 网格，从左上角到右下角，每次只能向右或向下，共有多少条不同路径。

**示例：** 输入：`m = 3, n = 7`；输出：`28`。

**思路：** `dp[i][j] = dp[i-1][j] + dp[i][j-1]`，第一行和第一列全为 1。使用较短维度作为滚动数组。

**展开理解：** 到格子 (i,j) 的最后一步只能来自上方或左方，两类路径互斥，故相加。第一行第一列只有一种走法；一维 dp 中 dp[j] 是更新前的上方值，dp[j-1] 是更新后的左方值。

```python
def uniquePaths(m, n):
    rows, cols = max(m, n), min(m, n)
    dp = [1] * cols
    for i in range(1, rows):
        for j in range(1, cols):
            dp[j] += dp[j - 1]
    return dp[-1]
```

**复杂度：**
- 时间：O(m × n)
- 空间：O(min(m, n))

## 64. 最小路径和

**题目描述：** m×n 网格，每格有非负整数，从左上角到右下角（只能向右或向下），找最小路径和。

**示例：** 输入：`grid = [[1,3,1],[1,5,1],[4,2,1]]`；输出：`7`。

**思路：** `dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])`，原地修改即可。

**展开理解：** 到每个格子的最小路径只可能从上或左进入，因此取两者较小值再加当前权重。首行首列只有单一路径需单独初始化；可直接复用 grid，但这会修改输入。

```python
def minPathSum(grid):
    m, n = len(grid), len(grid[0])
    for i in range(m):
        for j in range(n):
            if i == 0 and j == 0:
                continue
            elif i == 0:
                grid[i][j] += grid[i][j - 1]
            elif j == 0:
                grid[i][j] += grid[i - 1][j]
            else:
                grid[i][j] += min(grid[i - 1][j], grid[i][j - 1])
    return grid[m - 1][n - 1]
```

**复杂度：**
- 时间：O(m × n)
- 空间：O(1)（原地修改）

## 5. 最长回文子串

**题目描述：** 给定字符串，返回最长回文子串。

**示例：** 输入：`s = "babad"`；输出：`"bab"` 或 `"aba"`。

**思路一（对应本章分类）：** 二维动态规划。`dp[i][j]` 表示 `s[i:j+1]` 是否为回文串。

**展开理解：** 当首尾字符相同，且内部子串也是回文时，当前子串就是回文。状态转移为 `dp[i][j] = s[i] == s[j] and (j-i <= 2 or dp[i+1][j-1])`；由于当前状态依赖下一行，所以 i 需要倒序遍历。

```python
def longestPalindrome(s):
    if not s:
        return ""

    n = len(s)
    dp = [[False] * n for _ in range(n)]
    start = 0
    max_len = 1

    for i in range(n - 1, -1, -1):
        for j in range(i, n):
            if s[i] == s[j] and (j - i <= 2 or dp[i + 1][j - 1]):
                dp[i][j] = True
                if j - i + 1 > max_len:
                    start = i
                    max_len = j - i + 1
    return s[start:start + max_len]
```


**复杂度：**
- 二维 DP：时间 O(n²)，空间 O(n²)
- 中心扩展：时间 O(n²)，空间 O(1)

## 1143. 最长公共子序列

**题目描述：** 给定两个字符串，返回最长公共子序列（LCS）的长度。

**示例：** 输入：`text1 = "abcde", text2 = "ace"`；输出：`3`。

**思路：** 经典二维 DP 的滚动数组优化。`dp[j]` 保存当前行对应前缀的 LCS 长度。


```python
def longestCommonSubsequence(text1, text2):
    if len(text1) < len(text2):
        text1, text2 = text2, text1

    previous = [0] * (len(text2) + 1)

    for char1 in text1:
        current = [0] * (len(text2) + 1)

        for j, char2 in enumerate(text2, 1):
            if char1 == char2:
                current[j] = previous[j - 1] + 1
            else:
                current[j] = max(previous[j], current[j - 1])

        previous = current

    return previous[-1]
```

**复杂度：**
- 时间：O(m × n)
- 空间：O(min(m, n))

## 72. 编辑距离

**题目描述：** 给定两个字符串，计算将 word1 转为 word2 所需的最少操作数（插入、删除、替换）。

**示例：** 输入：`word1 = "horse", word2 = "ros"`；输出：`3`。

**思路：** `dp[i][j]` = `word1[:i]` 到 `word2[:j]` 的编辑距离。
- 字符相同：`dp[i][j] = dp[i-1][j-1]`
- 字符不同：`dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])`（删/插/替换）

**展开理解：** dp[i][j] 定义前 i 个字符变到前 j 个字符的最少操作。末字符相同无需新操作；不同则分别对应删除 word1 末字符、向 word1 插入 word2 末字符、替换末字符，取三者最小加 1。

```python
def minDistance(word1, word2):
    if len(word1) < len(word2):
        word1, word2 = word2, word1
    m, n = len(word1), len(word2)
    dp = list(range(n + 1))
    for i in range(1, m + 1):
        prev = dp[0]
        dp[0] = i
        for j in range(1, n + 1):
            temp = dp[j]
            if word1[i - 1] == word2[j - 1]:
                dp[j] = prev
            else:
                dp[j] = 1 + min(prev, dp[j], dp[j - 1])
            prev = temp
    return dp[n]
```

**复杂度：**
- 时间：O(m × n)
- 空间：O(min(m, n))
