## 136. 只出现一次的数字

**题目描述：** 给定非空整数数组，除一个元素外其余每个元素均出现两次，找出只出现一次的元素（线性时间，常数空间）。

**示例：** 输入：`nums = [4,1,2,1,2]`；输出：`4`。

**思路：** 异或。相同数字异或为 0，0 与任何数异或等于自身。对所有数做异或，最终结果就是只出现一次的数。

```python
def singleNumber(nums):
    res = 0
    for num in nums:
        res ^= num
    return res
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 169. 多数元素

**题目描述：** 找出数组中出现次数超过 ⌊n/2⌋ 的元素（保证存在）。

**示例：** 输入：`nums = [2,2,1,1,1,2,2]`；输出：`2`。

**思路（Boyer-Moore 投票算法）：** 候选人 + 计数。遇到与候选人相同的数 +1，不同 -1，计数归零时换候选人。最终候选人即多数元素。

```python
def majorityElement(nums):
    candidate = count = 0
    for num in nums:
        if count == 0:
            candidate = num
        count += 1 if num == candidate else -1
    return candidate
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 75. 颜色分类

**题目描述：** 给定包含 0、1、2 的数组，原地将其排序，使 0 在前、1 居中、2 在后（荷兰国旗问题）。

**示例：** 输入：`nums = [2,0,2,1,1,0]`；输出：`[0,0,1,1,2,2]`。

**思路：** 三指针：`lo` 指向 0 的边界，`hi` 指向 2 的边界，`cur` 是当前遍历指针。
- `nums[cur] == 0`：与 lo 交换，lo++，cur++
- `nums[cur] == 2`：与 hi 交换，hi--（cur 不动，因为换来的数未处理）
- `nums[cur] == 1`：cur++

```python
def sortColors(nums):
    lo, cur, hi = 0, 0, len(nums) - 1
    while cur <= hi:
        if nums[cur] == 0:
            nums[lo], nums[cur] = nums[cur], nums[lo]
            lo += 1
            cur += 1
        elif nums[cur] == 2:
            nums[hi], nums[cur] = nums[cur], nums[hi]
            hi -= 1
        else:
            cur += 1
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 31. 下一个排列

**题目描述：** 给定整数数组，将其重排成字典序上的下一个排列，若已是最大排列则重排为最小排列（原地）。

**示例：** 输入：`nums = [1,2,3]`；输出：`[1,3,2]`。

**思路：**
1. 从右向左找第一个「上升位」i（`nums[i] < nums[i+1]`）
2. 从右向左找第一个大于 `nums[i]` 的数 j，交换
3. 将 i+1 到末尾的部分翻转（变为升序）

```python
def nextPermutation(nums):
    n = len(nums)
    i = n - 2
    # 找上升位
    while i >= 0 and nums[i] >= nums[i + 1]:
        i -= 1
    if i >= 0:
        j = n - 1
        while nums[j] <= nums[i]:
            j -= 1
        nums[i], nums[j] = nums[j], nums[i]
    # 翻转 i+1 到末尾
    left, right = i + 1, n - 1
    while left < right:
        nums[left], nums[right] = nums[right], nums[left]
        left += 1
        right -= 1
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)

## 287. 寻找重复数

**题目描述：** 给定包含 n+1 个整数的数组，整数范围 [1, n]，只有一个重复的数，找出这个数（不修改数组，空间 O(1)）。

**示例：** 输入：`nums = [1,3,4,2,2]`；输出：`2`。

**思路（Floyd 判圈算法）：** 将数组视为链表（索引 → 值 → 索引），重复数对应链表的环入口。用快慢指针找环，再用双指针找入环点。

```python
def findDuplicate(nums):
    slow = fast = nums[0]
    # 找相遇点
    while True:
        slow = nums[slow]
        fast = nums[nums[fast]]
        if slow == fast:
            break
    # 找入环点
    ptr = nums[0]
    while ptr != slow:
        ptr = nums[ptr]
        slow = nums[slow]
    return slow
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)
