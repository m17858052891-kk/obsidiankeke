## 215. 数组中的第 K 个最大元素

**题目描述：** 找数组中第 k 个最大元素（非排序后第 k 个不同元素）。

**示例：** 输入：`nums = [3,2,1,5,6,4], k = 2`；输出：`5`。

**思路：** 维护大小为 k 的最小堆。遍历数组，超出 k 个时弹出最小值，遍历结束后堆顶即第 k 大。

```python
import heapq

def findKthLargest(nums, k):
    heap = []
    for num in nums:
        heapq.heappush(heap, num)
        if len(heap) > k:
            heapq.heappop(heap)
    return heap[0]
```

**复杂度：**
- 时间：O(n log k)
- 空间：O(k)

> **进阶 — 快速选择：** 平均 O(n)，最坏 O(n²)，适合对时间要求极高的场景。

## 347. 前 K 个高频元素

**题目描述：** 给定整数数组，返回出现频率前 k 高的元素。

**示例：** 输入：`nums = [1,1,1,2,2,3], k = 2`；输出：`[1,2]`。

**思路：** 用 Counter 统计频率，再用大小为 k 的最小堆（按频率）保留前 k 高频元素。

```python
import heapq
from collections import Counter

def topKFrequent(nums, k):
    count = Counter(nums)
    return heapq.nlargest(k, count.keys(), key=count.get)
```

**复杂度：**
- 时间：O(n log k)
- 空间：O(n)

## 295. 数据流的中位数

**题目描述：** 设计数据结构支持 `addNum(num)` 和 `findMedian()`，实时返回当前数据流的中位数。

**示例：** 输入：`addNum(1), addNum(2), findMedian(), addNum(3), findMedian()`；输出：`1.5, 2.0`。

**思路：** 两个堆：最大堆 `lo`（存较小一半，Python 用负值）和最小堆 `hi`（存较大一半）。保持 `len(lo) == len(hi)` 或 `len(lo) == len(hi) + 1`。

```python
import heapq

class MedianFinder:
    def __init__(self):
        self.lo = []   # 最大堆（取负）
        self.hi = []   # 最小堆

    def addNum(self, num):
        heapq.heappush(self.lo, -num)
        # 平衡：将 lo 最大值移到 hi
        heapq.heappush(self.hi, -heapq.heappop(self.lo))
        # 保持 lo 元素数 >= hi
        if len(self.lo) < len(self.hi):
            heapq.heappush(self.lo, -heapq.heappop(self.hi))

    def findMedian(self):
        if len(self.lo) > len(self.hi):
            return -self.lo[0]
        return (-self.lo[0] + self.hi[0]) / 2
```

**复杂度：**
- addNum 时间：O(log n)
- findMedian 时间：O(1)
- 空间：O(n)
