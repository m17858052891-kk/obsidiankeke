## 215. 数组中的第 K 个最大元素

**题目描述：** 找数组中第 k 个最大元素（非排序后第 k 个不同元素）。

**示例：** 输入：`nums = [3,2,1,5,6,4], k = 2`；输出：`5`。

**思路：** 维护大小为 k 的最小堆。先用前 k 个元素执行 `heapify`；之后只有当新元素大于堆顶时，才使用 `heapreplace` 替换堆中最小值。遍历结束后，堆顶就是第 k 大。

**展开理解：** 前 k 个元素直接建成最小堆，建堆只需 O(k)。此后堆始终保存已扫描元素中最大的 k 个，堆顶是这 k 个里最小的，也就是当前第 k 大。若新元素不超过堆顶，它不可能进入最大的 k 个，可以直接跳过；若超过堆顶，则用 `heapreplace` 一次完成“删除当前第 k 大并加入新元素”。

```python
import heapq

def findKthLargest(nums, k):
    # 前 k 个元素直接建成最小堆
    heap = nums[:k]
    heapq.heapify(heap)

    # 只有可能进入 Top-K 的元素才替换堆顶
    for num in nums[k:]:
        if num > heap[0]:
            heapq.heapreplace(heap, num)

    return heap[0]
```

**复杂度：**
- 时间：O(n log k)
- 空间：O(k)

> **进阶 — 快速选择：** 平均 O(n)，最坏 O(n²)，适合对时间要求极高的场景。

## 347. 前 K 个高频元素

**题目描述：** 给定整数数组，返回出现频率前 k 高的元素。

**示例：** 输入：`nums = [1,1,1,2,2,3], k = 2`；输出：`[1,2]`。

**思路：** 用 `Counter` 统计频率，把前 k 个 `(频率, 元素)` 直接 `heapify` 成最小堆；之后只有当新元素频率大于堆顶频率时，才用 `heapreplace` 更新堆。

**展开理解：** 最小堆始终保存当前频率最高的 k 个元素，堆顶是其中频率最低的一个。新元素频率不超过堆顶时不可能挤进 Top-K，可以跳过；超过时才替换。设不同元素数为 m，统计频率需要 O(n)，维护堆需要 O(m log k)；若按频率做桶，还能将整体时间降为 O(n)。

```python
import heapq
from collections import Counter

def topKFrequent(nums, k):
    count = Counter(nums)
    items = list(count.items())  # [(元素, 频率), ...]

    # 用前 k 个不同元素直接建堆；堆按频率排序
    heap = [(freq, num) for num, freq in items[:k]]
    heapq.heapify(heap)

    for num, freq in items[k:]:
        if freq > heap[0][0]:
            heapq.heapreplace(heap, (freq, num))

    return [num for freq, num in heap]
```

**复杂度：**
- 时间：O(n + m log k)，m 为不同元素数量
- 空间：O(m)，用于频率表和不同元素列表；堆本身为 O(k)

## 295. 数据流的中位数

**题目描述：** 设计数据结构支持 `addNum(num)` 和 `findMedian()`，实时返回当前数据流的中位数。

**示例：** 输入：`addNum(1), addNum(2), findMedian(), addNum(3), findMedian()`；输出：`1.5, 2.0`。

**思路：** 两个堆：最大堆 `lo`（存较小一半，Python 用负值）和最小堆 `hi`（存较大一半）。保持 `len(lo) == len(hi)` 或 `len(lo) == len(hi) + 1`。

**展开理解：** 最大堆保存较小一半、最小堆保存较大一半，并保持最大堆元素都不大于最小堆元素、两堆大小差不超过 1。奇数时中位数是较大堆顶，偶数时是两堆顶平均。

```python
import heapq

class MedianFinder:
    def __init__(self):
        self.lo = []   # 最大堆（取负）
        self.hi = []   # 最小堆

    def addNum(self, num):
        heapq.heappush(self.lo, -num)
        # 平衡：将 lo 最大值移到 hi
        heapq.heappush(self.hi, -heapq.heappop(self.lo))
        # 保持 lo 元素数 >= hi
        if len(self.lo) < len(self.hi):
            heapq.heappush(self.lo, -heapq.heappop(self.hi))

    def findMedian(self):
        if len(self.lo) > len(self.hi):
            return -self.lo[0]
        return (-self.lo[0] + self.hi[0]) / 2
```

**复杂度：**
- addNum 时间：O(log n)
- findMedian 时间：O(1)
- 空间：O(n)
