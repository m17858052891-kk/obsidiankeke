## 560. 和为 K 的子数组

**题目描述：** 给定整数数组 `nums` 和整数 `k`，返回和为 `k` 的连续子数组的个数。

**示例：** 输入：`nums = [1,1,1], k = 2`；输出：`2`。

**思路：** 前缀和 + HashMap。`prefix[i] - prefix[j] = k` 等价于 `prefix[j] = prefix[i] - k`。遍历时查询当前前缀和减 k 是否曾出现。

**展开理解：** 前缀和把任意子数组和转成两个前缀之差。遍历到当前前缀 pre 时，之前每出现一次 pre-k，就对应一个以当前位置结尾、和为 k 的子数组；先查询再把当前前缀计入表，避免混淆起止位置。

```python
class Solution(object):
    def subarraySum(self, nums, k):
        dist_map ={0:1}
        curr_sum=0
        count=0
        for num in nums:
            curr_sum+=num
            target =curr_sum-k
            if target in dist_map:
                count+=dist_map[target]
                
            dist_map[curr_sum] = dist_map.get(curr_sum, 0) + 1
        return count
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)

## 239. 滑动窗口最大值

**题目描述：** 给定数组和滑动窗口大小 `k`，返回每个窗口中的最大值。

**示例：** 输入：`nums = [1,3,-1,-3,5,3,6,7], k = 3`；输出：`[3,3,5,5,6,7]`。

**思路：** 单调递减队列（deque 存索引）。队列头部始终是当前窗口最大值的索引；新元素入队前，弹出所有比它小的元素（它们永远不会是最大值）；队头索引超出窗口时弹出。

**展开理解：** 队列中只保留仍在窗口内、且可能成为未来最大值的索引。若新值大于等于队尾值，队尾更小且更早，会比新值先出窗口，永远不可能再成为最大值，因此可永久删除；队首就是当前最大值。

```python
from collections import deque

def maxSlidingWindow(nums, k):
    dq = deque()   # 单调递减，存索引
    res = []
    for i, num in enumerate(nums):
        # 移除超出窗口的索引
        while dq and dq[0] < i - k + 1:
            dq.popleft()
        # 维护单调递减
        while dq and nums[dq[-1]] < num:
            dq.pop()
        dq.append(i)
        if i >= k - 1:
            res.append(nums[dq[0]])
    return res
```

**复杂度：**
- 时间：O(n)
- 空间：O(k)
