## 3. 无重复字符的最长子串

**题目描述：** 找出字符串中不含重复字符的最长子串的长度。

**示例：** 输入：`s = "abcabcbb"`；输出：`3`，对应子串 `"abc"`。

**思路：** 用 HashSet 维护窗口内字符。右指针扩展，出现重复时左指针收缩直到重复消除。

**展开理解：** 窗口始终满足“内部没有重复字符”。右端加入新字符若破坏条件，就不断删除左端直到条件恢复；每个字符最多进入和离开窗口一次，因此虽然有嵌套 while，总时间仍为 O(n)。

```python
def lengthOfLongestSubstring(s):
    char_set = set()
    l = 0
    ans = 0
    for r in range(len(s)):
        while s[r] in char_set:
            char_set.remove(s[l])
            l += 1
        char_set.add(s[r])
        ans = max(ans, r - l + 1)
    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：O(min(n, 字符集大小))

## 438. 找到字符串中所有字母异位词

**题目描述：** 找出字符串 `s` 中所有 `p` 的异位词的起始索引。

**示例：** 输入：`s = "cbaebabacd", p = "abc"`；输出：`[0,6]`。

**思路：** 固定长度（`len(p)`）的滑动窗口，用两个频率数组比较当前窗口与 `p` 的字符频率。

**展开理解：** 异位词窗口长度必须等于 p 的长度，因此右端每加入一个字符，就在窗口过长时删除左端字符。只有两个频率向量完全一致时才是异位词；固定字符集可用数组避免哈希比较的额外常数。

```python
class Solution(object):
    def findAnagrams(self,s,p):
        pcount = [0]*26
        scount = [0]*26
        res = []
        if len(s)<len(p):
            return []
        
        for x in p:
            pcount[ord(x)-97]+=1
        
        for i in range(len(s)):
            scount[ord(s[i])-97]+=1

            if i >= len(p):
                scount[ord(s[i-len(p)])-97]-=1
            
            if scount == pcount:
                res.append(i-len(p)+1)

        return res
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)（字符集固定为 26 个字母）

## 76. 最小覆盖子串

**题目描述：** 给定字符串 `s` 和 `t`，找出 `s` 中包含 `t` 所有字符的最短子串。

**示例：** 输入：`s = "ADOBECODEBANC", t = "ABC"`；输出：`"BANC"`。

**思路：** 变长滑动窗口。用 `target_count` 记录 `t` 中各字符的目标频次，用 `window_count` 记录当前窗口频次；当全部目标字符都达到所需频次后，收缩左边界寻找最短窗口。

**展开理解：** 窗口右扩负责让约束从“不满足”变成“满足”，一旦满足就左缩寻找当前右端下的最短解。计数必须处理 t 中重复字符；只有某字符达到所需次数时，已满足种类数才增加，缩窗跌破需求时再减少。

```python
from collections import Counter

class Solution(object):
    def minWindow(self, s, t):
        if not t or len(t) > len(s):
            return ""

        target_count = Counter(t)
        required = len(target_count)  # 需要满足的字符种类数
        window_count = {}
        left = 0
        formed = 0  # 当前已满足目标频次的字符种类数
        min_len = float('inf')
        start = 0

        for right, ch in enumerate(s):
            if ch in target_count:
                window_count[ch] = window_count.get(ch, 0) + 1
                if window_count[ch] == target_count[ch]:
                    formed += 1

            while formed == required:
                if right - left + 1 < min_len:
                    min_len = right - left + 1
                    start = left

                remove_char = s[left]
                if remove_char in target_count:
                    window_count[remove_char] -= 1
                    if window_count[remove_char] < target_count[remove_char]:
                        formed -= 1
                left += 1

        return s[start : start + min_len] if min_len != float('inf') else ""

```

**复杂度：**
- 时间：O(n + m)，n = len(s)，m = len(t)
- 空间：O(u)，u 为 t 中不同字符数
