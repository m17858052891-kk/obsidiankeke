## 3. 无重复字符的最长子串

**题目描述：** 找出字符串中不含重复字符的最长子串的长度。

**示例：** 输入：`s = "abcabcbb"`；输出：`3`，对应子串 `"abc"`。

**思路：** 用 HashSet 维护窗口内字符。右指针扩展，出现重复时左指针收缩直到重复消除。

**展开理解：** 窗口始终满足“内部没有重复字符”。右端加入新字符若破坏条件，就不断删除左端直到条件恢复；每个字符最多进入和离开窗口一次，因此虽然有嵌套 while，总时间仍为 O(n)。

```python
def lengthOfLongestSubstring(s):
    char_set = set()
    l = 0
    ans = 0
    for r in range(len(s)):
        while s[r] in char_set:
            char_set.remove(s[l])
            l += 1
        char_set.add(s[r])
        ans = max(ans, r - l + 1)
    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：O(min(n, 字符集大小))

## 438. 找到字符串中所有字母异位词

**题目描述：** 找出字符串 `s` 中所有 `p` 的异位词的起始索引。

**示例：** 输入：`s = "cbaebabacd", p = "abc"`；输出：`[0,6]`。

**思路：** 固定长度（`len(p)`）的滑动窗口，用两个频率数组比较当前窗口与 `p` 的字符频率。

**展开理解：** 异位词窗口长度必须等于 p 的长度，因此右端每加入一个字符，就在窗口过长时删除左端字符。只有两个频率向量完全一致时才是异位词；固定字符集可用数组避免哈希比较的额外常数。

```python
class Solution(object):
    def findAnagrams(self,s,p):
        pcount = [0]*26
        scount = [0]*26
        res = []
        if len(s)<len(p):
            return []
        
        for x in p:
            pcount[ord(x)-97]+=1
        
        for i in range(len(s)):
            scount[ord(s[i])-97]+=1

            if i >= len(p):
                scount[ord(s[i-len(p)])-97]-=1
            
            if scount == pcount:
                res.append(i-len(p)+1)

        return res
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)（字符集固定为 26 个字母）

## 76. 最小覆盖子串

**题目描述：** 给定字符串 `s` 和 `t`，找出 `s` 中包含 `t` 所有字符的最短子串。

**示例：** 输入：`s = "ADOBECODEBANC", t = "ABC"`；输出：`"BANC"`。

**思路：** 变长滑动窗口。用 `char_need` 记录各字符当前还需要的数量，用 `need` 记录窗口总共还缺多少个目标字符实例。右指针扩张到完全覆盖 `t` 后，左指针删除多余字符，并记录最短窗口。

**`need` 的含义：** 它不是“还缺多少种字符”，而是“还缺多少个字符实例”，因此初始化为 `len(t)`。例如 `t = "AABC"` 时，初始值是 4；窗口第一次加入 `A` 后变为 3，第二次加入 `A` 后才变为 2。当 `need == 0` 时，当前窗口已经覆盖 `t`。

**展开理解：** `char_need[ch] > 0` 表示窗口仍缺少 `ch`，`char_need[ch] == 0` 表示数量刚好，`char_need[ch] < 0` 表示该字符多余。窗口满足条件后，先跳过左侧所有多余字符；记录答案后，再主动移走一个必要字符，使窗口重新变为不满足状态并继续搜索。

```python
from collections import Counter

class Solution(object):
    def minWindow(self, s, t):
        if not t or len(t) > len(s):
            return ""

        char_need = Counter(t)
        need = len(t)  # 还缺少的目标字符实例总数
        left = start = end = 0

        # right 使用右开边界，所以窗口长度为 right - left
        for right, ch in enumerate(s, 1):
            if char_need[ch] > 0:
                need -= 1
            char_need[ch] -= 1

            if need == 0:
                # 删除窗口左侧的多余字符
                while char_need[s[left]] < 0:
                    char_need[s[left]] += 1
                    left += 1

                if end == 0 or right - left < end - start:
                    start, end = left, right

                # 移走一个必要字符，继续寻找下一个可行窗口
                char_need[s[left]] += 1
                need += 1
                left += 1

        return s[start:end]
```

**复杂度：**
- 时间：O(n + m)，n = len(s)，m = len(t)
- 空间：O(k)，k 为 `s` 和 `t` 中出现的不同字符数；若字符集固定，可视为 O(1)
