## 3. 无重复字符的最长子串

**题目描述：** 找出字符串中不含重复字符的最长子串的长度。

**示例：** 输入：`s = "abcabcbb"`；输出：`3`，对应子串 `"abc"`。

**思路：** 用 HashSet 维护窗口内字符。右指针扩展，出现重复时左指针收缩直到重复消除。

```python
def lengthOfLongestSubstring(s):
    char_set = set()
    l = 0
    ans = 0
    for r in range(len(s)):
        while s[r] in char_set:
            char_set.remove(s[l])
            l += 1
        char_set.add(s[r])
        ans = max(ans, r - l + 1)
    return ans
```

**复杂度：**
- 时间：O(n)
- 空间：O(min(n, 字符集大小))

## 438. 找到字符串中所有字母异位词

**题目描述：** 找出字符串 `s` 中所有 `p` 的异位词的起始索引。

**示例：** 输入：`s = "cbaebabacd", p = "abc"`；输出：`[0,6]`。

**思路：** 固定长度（`len(p)`）的滑动窗口，用两个频率数组比较当前窗口与 `p` 的字符频率。

```python
class Solution(object):
    def findAnagrams(self,s,p):
        pcount = [0]*26
        scount = [0]*26
        res = []
        if len(s)<len(p):
            return []
        
        for x in p:
            pcount[ord(x)-97]+=1
        
        for i in range(len(s)):
            scount[ord(s[i])-97]+=1

            if i >= len(p):
                scount[ord(s[i-len(p)])-97]-=1
            
            if scount == pcount:
                res.append(i-len(p)+1)

        return res
```

**复杂度：**
- 时间：O(n)
- 空间：O(1)（字符集固定为 26 个字母）

## 76. 最小覆盖子串

**题目描述：** 给定字符串 `s` 和 `t`，找出 `s` 中包含 `t` 所有字符的最短子串。

**示例：** 输入：`s = "ADOBECODEBANC", t = "ABC"`；输出：`"BANC"`。

**思路：** 变长滑动窗口。用 `need` 记录还需要满足的字符数量，右指针扩展时减少 need，满足条件后左指针收缩寻找最小窗口。

```python
from collections import Counter

class Solution(object):
    def minWindow(self, s, t):
        need = Counter(t)
        need_count = len(need) # 注意：这里是【种类数】，不是总长度
        window = {}
        left = 0
        have = 0
        min_len = float('inf')
        start = 0  #初始化 start，防止找不到解时报错
        for right, ch in enumerate(s):
            window[ch] = window.get(ch, 0) + 1
            if ch in need and window[ch] == need[ch]:
                have += 1
            while have == need_count:
                if right - left + 1 < min_len:
                    min_len = right - left + 1
                    start = left  # 记录起点
                remove_char = s[left]
                window[remove_char] -= 1
                if remove_char in need and window[remove_char] < need[remove_char]:
                    have -= 1
                left += 1    
        return s[start : start + min_len] if min_len != float('inf') else ""



```

**复杂度：**
- 时间：O(n + m)，n = len(s)，m = len(t)
- 空间：O(m)
