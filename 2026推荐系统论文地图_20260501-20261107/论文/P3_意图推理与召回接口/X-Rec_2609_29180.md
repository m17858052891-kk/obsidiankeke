# X-Rec Technical Report

- 机构：ByteDance/TikTok；垂类内容召回。首发2026-09-24，v1。
- 主源：[版本史](https://arxiv.org/abs/2609.29180)、[全文](https://arxiv.org/html/2609.29180v1)。
- 分类：连续生成召回、多兴趣覆盖与推理效率；位置：新增召回源→ANN→原有下游排序。

## 从两种旧范式的弱点出发

U2I把一个用户压成一个或少数确定向量，多峰兴趣难同时覆盖；SID自回归能表达分布，却要量化连续item embedding并串行解码多层码。X-Rec直接学习连续球面item分布，通过flow matching产生多个向量trigger，再用现有ANN取物品。它改变召回表示和生成器，没有直接输出最终曝光列表，也没有替代ANN。

## 输入和训练推理

每个视频是128维、L2归一化的多模态embedding；上下文包含历史正反馈和近期行为以及目标action属性。采用去掉词embedding后的Qwen3-0.6B骨干，约0.46B参数。先预测/采样anchor定位粗语义区域，再用Riemannian flow沿单位球面从随机初态走向目标embedding；预测速度投影到球面切空间，避免模型同时学习无意义的径向修正。

Late-interaction DiT将历史在prefill中经过骨干，迭代速度估计只放最后一层，时间与anchor经AdaLN调制。历史KV可共享，不同噪声trigger相互不可见。预训练一条序列产生多个prefix→next-item任务，mask确保每目标只读自己的过去；SFT用近期和长期正反馈组合，同目标采8个噪声/时间样本，仍相互隔离。默认推理anchor温度1.4、30步去噪、CFG3.0，每请求并行20个trigger，每trigger ANN取1个。

## 实验及必须保留的差异

§4采用47个连续分片、每片2.6M训练例和10K测试例，持续更新模型；总候选预算固定20，但U2I用1×20邻居，生成模型用20×1。SID比较把生成SID通过RQ码本还原成向量再做ANN，使检索接口统一；因此不是与“原生SID直接查物品桶”完整路径的严格比拼。

§4.2主结果：X-Rec平均Recall@20=10.65%，X-Rec-AR低0.53个百分点，控制骨干的X-Rec-U2I=6.98%。§4.3/4.4另一组消融报完整模型10.76%，去anchor8.71%、去RFM8.98%、无预训练5.49%；两组主值不同，本笔记不合成一个统一均值。anchor粗SID第一位Recall@20从28.57→41.37，提供粗语义定位的中介证据。

§4.3.3单层late interaction相对SID-AR生成吞吐3.46×；只统计trigger generation，不含ANN。相对14层迭代少约1.05个百分点Recall但吞吐4.50×。§4.4.1固定20候选从1×20到20×1，Recall从8.28→10.76；ComiRec式多兴趣控制模型反而6.98→5.32（1×20→10×2），说明向量分散不等于有效兴趣覆盖。

§5表3线上为**新增垂类召回源**两次连续launch：V1（RFM+late interaction，无anchor）垂类engagement+2.3779%；V2相对V1+1.7705%；论文合计报+4.1484%，general engagement+0.0111%。这个total是论文相加口径，不应改写为单次随机AB或精确复合增幅；V1 general指标不显著。论文未给足够细节把engagement再解读为时长或留存。

## 收益链路

**事实**：anchor提高粗区域命中；等候选预算多trigger提高Recall；同骨干控制中连续分布生成优于单U2I；线上新增召回源带来小而显著的全局指标改善。

**机制推断**：先确定粗兴趣再沿球面细化 → 减少量化误差与跨兴趣平均 → 有限召回预算覆盖更多真实兴趣mode → 下游获得原通道找不到的高价值候选 → 垂类消费增加。late interaction减少每步重复骨干 → 在时延内多采样而非被迫缩小预算。它证明的是互补召回价值，不能从+4.1484%推断替换所有召回必然同收益，也不能把向量空间更分散当用户多样性改善。

## 证伪实验与落地顺序

1. **H1：收益主要来自新兴趣mode覆盖。** 固定ANN、候选去重后数量、延迟和骨干，对比U2I、多U2I、SID-AR、X-Rec；记录独占召回成交/有效观看、与现有通道重合、trigger相似度。若新trigger仅同义近邻、下游独占贡献为零，多模态分布解释不足。
2. **H2：球面几何对齐而非迭代算力造成收益。** 同步数比较RFM、欧氏FM+逐步归一化、欧氏FM仅终点归一化；测角距离、Recall及等时延效果。如果简单逐步归一化即可复现，应采用更简单实现。
3. 先离线做anchor覆盖与量化重构损失诊断，再接一条影子ANN召回，最后固定总召回配额AB。30步降低到更少步时同时看长尾mode丢失，不能只看平均时延。

## 互补与局限

与UniVA的SID生成是召回层替代路线，但可多源并存；UniVA强调商业对齐，X-Rec重点是几何、多峰与吞吐，不能直接比HR/GMV。与ReST/OneTrans-GSR分别上下游互补。实验历史上限200，不是100K长序列论文；对在线变化的item embedding、ANN索引新鲜度和高价值广告约束仍需外部机制。训练/推理预算、流式评估协议和候选预算分配差异均限制外推。
