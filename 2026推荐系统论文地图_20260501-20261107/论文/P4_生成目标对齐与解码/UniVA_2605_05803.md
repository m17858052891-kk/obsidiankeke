# UniVA: Unified Value Alignment for Generative Recommendation in Online Advertising at Tencent

- 机构：武汉大学、Tencent、北京大学；腾讯微信视频号广告。
- 首发 2026-05-07；阅读 v2（2026-07-29）。v1 题名为 Unified Value Alignment for Generative Recommendation in Industrial Advertising。
- 主源：[版本史](https://arxiv.org/abs/2605.05803)、[v2 全文](https://arxiv.org/html/2605.05803v2)。
- 分类：生成召回的商业目标对齐；位置：SID 构造→生成解码→合法广告筛选与路径落地。

## 从什么问题出发

标准生成推荐拟合“用户下一次会交互哪个 SID”，但广告需要兼顾转化和出价。高生成概率不代表高 eCPM；如果高价值广告被分在缺乏商业区分的 SID 桶里、在 beam 早期剪枝时丢掉，后置排序很难追回。无效广告路径还会占据有限 beam 预算。作者因此把商业目标沿表示、训练和在线搜索贯通。

## 方法的数据流

广告内容先经 RQ-KMeans+ 得到上层语义码；最后一层换成商业码 CSID。商业码组合压缩后的优化目标、ROI目标、行业，再在组合内部按出价等频分桶，稀疏组合回退，按样本量分配词表容量。因此不是用一个“高出价”标签粗暴替换所有语义层。SID 仍多对一；请求内有效广告桶按出价优先解出实际广告，离线奖励与在线使用同一规则。

用户、自然内容行为、环境及历史广告 token 经 HSTU encoder 编码；decoder 一边读编码记忆，一边根据已生成前缀预测下一层 SID。共享 decoder 上有生成头和 action-value 头：前者拟合 SID，后者估计某前缀扩展的商业回报。离线由 beam 与 MCTS 联合收集路径，生产快照模拟器给终止 eCPM，PPO 和回报回归训练两头，并与监督批次交替。MCTS/模拟器不上线上。

在线每步融合 `生成 logit + 层级系数 × action value`，请求级 trie 屏蔽不可投放路径，再做 beam；无需额外在线 reranker 来实施这一步价值引导。MoR 参数共享递归和 sparse MoE 用于增加 decoder 能力，不能把完整收益都视为目标函数变化。现有用户 encoder、广告资格约束仍保留。

## 实验读数

§4.2 表2以工业 GPR baseline 为基准，递进配置 HR@100 相对增益：CSID +5.78%；Deeper Decoder +6.10%；MoR +13.56%；Sparse MoE +18.40%；加 eCPM RL +32.01%；完整更大模型 +37.04%。完整 decoder 为80M、23.2G FLOPs，故37.04%不是同算力纯算法净增益。公共 Amazon Industrial/Office 实验沿用语义 SID，用评分作效用，未验证商业 CSID，在不同最佳基线上 HR/NDCG 相对提升最高8.4%/7.8%。

§4.5 表4：2026-03-07至03-11、20%生产流量，实验时间早于论文公开时间但不影响首发纳入。相对共同生产控制组，V0语义SID+GRPO GMV +0.22%；扩大decoder V1 +0.36%；加CSID V2 +1.03%；PPO action-value 与线上GAR共同加入的V3 +1.50%，GMV(normal) +1.42%。最后一步同时改变训练和推理，不能单独认定是 PPO 优于 GRPO。

## 收益链路：证据与推断

**事实**：CSID 降低同路径出价离散性；同解码器下CSID有离在线增益；递进RL和GAR版本进一步改善；请求合法性进入搜索。

**机制推断**：商业分桶 → 同一前缀中的价值更一致 → value head 更容易学出可用的前缀价值 → 高价值但概率较低的路径存活 → 排序前候选商业质量提高 → GMV增长。这个链路最值得迁移的不是“所有阶段都加业务权重”，而是避免商业候选在无法补救的早期剪枝处消失。论文的逐版本实验支持组合有效，但没有随机化全部中介变量；不保证提高出价相关性一定提高用户收益或广告主长期ROI。

## 可执行迭代与证伪

1. **H1：商业分桶通过减少桶内价值异质性改善候选。** 固定码长度、词表、参数和 beam，比较真实商业码、等频随机码、语义第三层，分桶统计出价方差、value校准、ValueHR及GMV。若只有普通HR升、价值HR不升，商业对齐解释受损。
2. **H2：GAR的价值在于救回早期被剪掉的优质路径。** 离线记录每步被剪路径的终止模拟价值；固定模型扫描beam宽和融合系数，比较等时延增宽beam。若增益只来自额外计算，优先采用简单增宽方案。
3. 先做 request-valid trie，再做CSID回放与桶内冲突审计，最后引入价值头；线上同时护栏ROI、转化率、广告负反馈和头部广告集中度。追加“PPO无GAR/GAR无PPO”因子实验，隔离训练与搜索贡献。

## 互补与边界

与 X-Rec 连续空间召回在生成表示层竞争，二者可作为独立召回源；与 OneTrans-V2 的决策前缀都承担业务目标引导，但 UniVA 在SID路径和eCPM层对齐，不能直接比GMV百分比。与 OneTrans-GSR 分别位于召回和最终组单，可互补；后者无法找回这里剪掉的广告。主要风险是动态出价令码与线上状态错位、奖励模拟器偏差、trie维护成本及词表分辨率失配；8192语义词表配固定2048商业码的反例提示码更大未必更好。

**逐项复核**：v1/v2题名变化已核；机构已核；SL/PPO/value/MCTS在线边界已核；表2规模差异已核；3月实验与5月首发未混淆；GMV为整套处理的相对提升。
