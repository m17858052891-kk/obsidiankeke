# Uncertainty-Calibrated Recommendations for Low-Active Users

- 机构：Stanford University 与 ByteDance；业务为直播推荐。
- 首发：2026-05-18；阅读版本：v2，2026-05-25；KDD 2026 ADS。
- 主源：[arXiv 元数据与版本史](https://arxiv.org/abs/2605.17788)、[v2 全文](https://arxiv.org/html/2605.17788v2)。注意元数据题名如上，而 HTML 正文题名为 **Uncertainty-Aware Adaptive Recommendation across User Lifecycle**；它们是同一 arXiv ID，不应拆成两篇。
- 问题分类：低活用户可靠性、探索利用；位置：精排输出后的分群调分层。

## 旧方案为什么受限

确定性 CTR/时长模型只报分数，不能区分“预计高收益且可信”与“预计高收益但训练证据不足”。MC Dropout 要重复前向，多头共享底座又可能使各头误差高度相关；全局误差保证未必改变同一用户候选的相对顺序。论文提出的业务判断是：低活用户一次不良体验的代价高，高活用户可以承受更多探索。因此同一个不确定性信号应在两类人群里取相反的决策方向，不能机械地“置信度越高越好”。

## 输入、训练、推理的具体链路

点估计分支使用上一日检查点预测下一日样本，计算实际预测损失，再冻结主推荐模型，训练独立 EPE critic。输入拼接原始用户物品特征、主模型中间表示、最终预测，输出单样本期望误差；时间错位构造避免把训练内拟合误差充当泛化风险。概率分支输出 Beta 等条件分布参数，用边缘似然训练，从总方差中取模型侧分量。两个信号在独立校准集以分位数设阈值。

直播月活跃观看天数少于 7 天为 LAU，至少 7 天为 HAU。线上 LAU 任一不确定性超阈值即减去固定调分 D；HAU 以两类不确定性的较大值乘探索系数，加到相关性分数。候选集合、基础排序主干和商业链路仍在；替换的是风险/探索策略，不是召回或全套排序网络。无需在线多次随机前向，但新增 critic/概率头的实际资源成本仍需实测。

## 实验及准确口径

§4、表1：EPE 的 Spearman=0.6695、AURC/Base=0.0157/0.0271；Bayes=0.6881、0.0162/0.0277；多头 Spearman=0.2760，MC Dropout=0.1887。它们证明风险分数和误差的排序相关性，不等于识别了纯粹可约认知不确定性。

14 天线上实验、表2：相对生产 baseline，联合方案 HLT7 +0.0577%、App Stay Duration +0.16%、VWR +0.512%；单 EPE 的 HLT7 +0.0434%，单 Bayes +0.0468%，随机扰动 +0.0029%且不显著。表3高活组 Show Tag/U +2.1%，Top1 Tag UV Ratio −0.42%，直播时长 +0.16%且不显著。

**正文存在数据冲突**：§4.5段落称 LAU Live Watch Time −0.16%，表2是 −1.05%。表2的 HLT-efficiency=0.0549 与 0.0577/1.05 相符。本笔记保留表格数并明确冲突，不能写成“所有消费指标均提升”。HLT7 是过去七日累计活跃小时代理，不能直接翻译为 D7 留存率。

## 改动如何转成收益

**事实**：误差预测相关性提高；真正风险信号调分优于随机调分；低活组质量观看比例和活跃小时提高；高活组标签覆盖提高。

**机制推断**：critic/Bayes → 识别证据稀疏、刚开播等脆弱预测 → 低活组减少这些候选曝光，保留更稳的观看机会 → 降低早退概率，增加后续活跃；高活组则反向加分 → 更多潜在兴趣类别进入前排 → 标签覆盖扩大。论文没有完整的“降权候选→逐用户早退→长期留存”中介因果分解；不能把所有结果都归因为去除了认知不确定性，EPE 本身混有数据噪声，作者依赖分层后噪声近似相同的假设。

## 最小可执行迭代与证伪

1. **H1：收益来自识别错误，而非一般性压低新直播。** 固定各组降权数量，对比学习风险、按直播年龄降权、分桶内打乱风险；在相同新直播曝光率下比较 VWR、短退、HLT7。若打乱后收益相同，风险建模解释失败。
2. **H2：策略符号确实应随活跃度改变。** 做活动分层×加分/减分的因子实验，固定曝光预算，观测标签覆盖和长期活跃；若 LAU 加分同样更优，生命周期判断需修正。设置新主播覆盖护栏，避免稳健性变成长期供给枯竭。
3. 先只接冻结主模型的 EPE critic，在时间外数据测风险覆盖曲线，再加入概率头，最后做小流量阈值扫描；同时记录 critic 校准漂移和特征延迟。

## 互补、替换与局限

可叠加在 ReST/CCFormer 等新主干之后，也可作用于 X-Rec 新召回候选；但更强主干可能改变误差分布，旧阈值不可照搬。与推荐多样性规则部分替换，与骨干结构互补。直播年龄、活动分层、曝光政策三者相关，离线日志偏差与策略反馈都可能污染风险学习。论文无可独立复现的生产数据；未报告足够信息以估算同等收益所需在线算力。

**逐项复核**：首发/v2/机构已核；具体风险输入与冻结方式已核；表1–3逐项对照；百分比均为相对变化；HLT与留存含义已区分；表文冲突保留；系统AB与机制推断分开。
