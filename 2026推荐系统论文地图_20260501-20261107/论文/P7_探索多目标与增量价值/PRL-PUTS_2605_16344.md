# PRL-PUTS：不重训ranker的个性化多目标权重

[A Production-Ready RL Framework for Personalized Utility Tuning with Pareto Sweeping in Pinterest Recommender Systems](https://arxiv.org/abs/2605.16344)，Pinterest，2026-05-08 v1。[全文](https://arxiv.org/html/2605.16344v1)。

## 要解决的问题

多任务ranker预测保存、点击等概率后，通常用全局静态权重合成utility。同一权重未必适合所有用户，业务目标变化还要反复调参。本文在固定ranker上增加**请求级utility权重选择器**，既不改每物品预测，也不直接学习长程留存策略。

## 方法：一次学习，在线选择不同取舍

控制Repin与P2P impression两个权重，其余保持生产值；每个权重7档，共49动作。用已知均匀随机策略探索并记录state、动作与反馈。state由用户embedding、请求属性、历史序列编码组成。

双头Q网络输入state及动作向量，分别回归两种即时奖励；奖励把计数截断到0/1，MSE训练。因为$\gamma=0$，本质是contextual bandit，不带未来value bootstrapping。

上线枚举49动作，选择最大$\alpha Q_{p2p}+(1-\alpha)Q_{repin}$。改变$\alpha$即可换运营取舍，不必重新训练。用25个$\alpha$点在holdout探索日志估计回报，筛出经验非劣前沿；不是证明找到了连续动作空间全部Pareto最优点。

## 结果：必须同时看得失

两周用户级AB，每组1% Homefeed流量（§6.4）。

| Table 1线上策略 | Repin | P2P impression | Successful Sessions |
|---|---:|---:|---:|
| Repin-leaning | +2.26% | -0.21% | -0.09% |
| balanced | +1.35% | -0.04% | -0.02% |
| P2P-leaning | +0.66% | +0.30% | +0.13% |

这些为原表相对变化，不能把所有小负值都声称显著。另一个匹配静态权重实验（Table 3）中，静态重调为-0.24%/+0.07%/+0.02%，个性化策略为+0.12%/+0.21%/+0.11%。两表属于不同对照设置，不能混为同一组绝对效果。

## 收益链路

以下传导关系是本库的**机制推断**；其中引用的消融或A/B是支持证据，不代表每一环节都已被独立因果识别。

**异质性链路：**识别用户/请求对两种目标的响应差异 → 相同整体平均权重下仍采用不同局部权重 → 改变真正展示的排序 → 增加适合该用户的行为。Table 3匹配平均权重对照较直接支持“个性化而不只是全局权重重调”。

**控制链路：**拆开估计不同reward的Q → 运营取舍在推理时改变 → 减少为每组业务权重重新训练的成本。此处主要收益是迭代与控制效率，不能与用户指标混加。

**必要条件：**动作权重必须实际改变列表；若两个head高度同序，调权无效。回报只截断到一次行为，可能忽略深度参与；即时反馈改善不意味着长期留存改善。

## 与其他pipeline关系

最接近多目标融合、重排策略和contextual bandit。可叠加任何已有多头排序器，通常比换骨干低成本。与DragonBandit差别是这里优化即时响应，不估计不推荐时的反事实增量，也不处理跨用户总预算LP。与生成式模型的reward alignment可互补，但线上改变utility后需注意生成候选是否覆盖新的高权重目标。

## 最小实验

1. **假设A：用户异质性真实存在。**固定ranker，先做小网格随机探索，检验不同活跃桶的动作响应曲线；没有可靠差异就先用全局权重。
2. **假设B：不是平均权重变化造成。**必须加入与个性化策略流量均值相同的静态权重对照，保留相同流量和后处理。
3. **假设C：离线前沿可以选线上策略。**按真实propensity做OPE，报告动作命中样本量与置信区间；非均匀探索不能直接沿用Reward@HIT而省略权重。
4. ranker刷新后重复校验Q与动作响应；设置回退至生产权重，监控满意度、负反馈和长期指标。
