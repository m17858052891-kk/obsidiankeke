# 套餐选档与双策略实验

超值周卡有两个可以独立调整的价格。**售卖折扣**决定乘客花多少钱买卡，**SKU 折扣**决定卡内 5 张券在用车时能省多少钱。LR25019 在售卖折扣固定时逐人选券档，2025 年 7 月实验里，智能选档比人工按城市配置显著提升了套餐呼单用户渗透率。LR25030 再把售卖折扣交给独立模型，8 月实验里，两项策略叠加相对人工的提升显著，相对已经上线的单 SKU 策略只有方向性增益。[LR25019 原文](https://cooper.didichuxing.com/knowledge/2199610335356/2204724694085) · [LR25030 原文](https://cooper.didichuxing.com/knowledge/2199610335356/2205375971925)

## 单 SKU 怎样用曝光训练、用呼叫验收

原先同一城市的用户看到相同券档。V0 固定售卖折扣为原文所称的“50 折”（原价的 50%），固定券张数，每次曝光在 75、80、85、90、95 五个券档中选一档。业务希望**相同总 C 补率下，套餐呼单用户渗透率相对提高 5%**。曝光人群大盘总 C 补率容差为 ±0.1 个百分点，人均完单和人均 GMV 不能显著下降（p<0.05）。单次曝光容易建模，最终执行决策要回到用户和成本两个口径。[LR25019 §2–3](https://cooper.didichuxing.com/knowledge/2199610335356/2204724694085)

| 环节 | 原文做法及复用时要保留的口径 |
| --- | --- |
| 样本和归因 | 取随机折扣实验中的实际曝光。对同一用户当日的连续曝光，若相邻间隔小于 10 分钟就归入同一窗口，只留每窗首个 trace。购买前 1 小时内符合条件的曝光都记正样本，其余记负。同一笔购买可能对应多个窗口。 |
| 训练目标 | 对一次曝光估计各档购买概率。离线训练的标签是购买，PV 曝光购买率用购买次数除以曝光次数。随机分组后各档的实际曝光量仍会不同，因此需要检查进入曝光样本的机制。 |
| 线上主指标 | 套餐呼单用户渗透率 = 组内既呼叫又购买套餐的去重人数 / 组内呼叫去重人数。原 SQL 同时列有“全部购买人数 / 呼叫人数”的旧指标，两种分子不同。人均购买数、人均核销数分母均为购买人数。 |
| 成本与观察窗 | 总 C 补率 = 组内总 C 补额 / GMV。套餐 C 补率 = 券核销金额 / GMV，另算扣除套餐收入后的净值。SQL 对实验期发券向后多看 7 天核销，排除幸运盒子假 C 补类型 64 时 GMV 保持原口径。 |

## 从异常特征到可执行的折扣

**先查模型是否提前看到了要做的动作。** 项目用 XGB 初筛前 50 个历史特征，再加 11 个实时特征。双塔和多头模型均出现排序分组中处理档位占比（trt_ratio）明显波动。作者按档检查特征分布、非空率、非零率和入口构成，发现 75 档有 518,677 次曝光，95 档有 500,246 次，差异主要来自深折扣时完单收银台曝光增加。该入口与实际券档耦合。复用到等应答页时，应单独检查“谁被展示”和“展示后谁接受”两个环节。[LR25019 §3.2.2，含 7 月 21 日、28 日补充](https://cooper.didichuxing.com/knowledge/2199610335356/2204724694085)

| 特征类型 | 当时怎样处理 |
| --- | --- |
| 实际折扣、SKU 编号、券类型、张数和售卖折扣 | 折扣和编号会透露处理档，券类型和张数在此周卡固定。部分工程字段大量为 0 或与定义不符。逐项核验后剔除。 |
| 入口、已购标记、展示最高价和最低价 | 入口受券档影响。已购标记的离线 DINI 略负。最高价和最低价虽然提升 DINI，但只展示周卡时也受券档影响，深折处的处理占比更不稳，当期剔除，原文列为后续 A/B 候选。 |
| 历史及保留实时特征 | 原文按各档均值和分布剔除近 30/90 天实付金额、周中高峰完单距离、近 28 天平均预估接驾时长等异常项。保留历史购买、访问、领券、下单等特征，实时字段留 city_id 和已购套餐价格。该次组间分布用于排查，判断新特征时仍要核对产生时间与工程含义。 |

**模型选型。** 剔除异常项后，DR-CFR 多头模型分别输出各档购买概率，平均 DINI 为 0.2929，双塔为 0.2184，采用多头。由于核销有延迟，难以为每个曝光样本准确计算成本，离线用平均 DINI，比预算下的真实收益少一层成本信息。[结构图](附件/LR25019/图表02.svg) · [重加权](附件/LR25019/025.png) · [实际处理档损失](附件/LR25019/026.png) · [交叉熵](附件/LR25019/027.png) · [分布均衡损失](附件/LR25019/028.png)

**预算怎样变成选档阈值。** 对样本 i、券档 j，记预测购买率为 pᵢⱼ，档位核销金额统计值为 hⱼ，预期开销为 cᵢⱼ = pᵢⱼ × hⱼ。由浅到深检查折扣，去掉购买率下降的档位，以及导致边际 ROI 后一跳大于等于前一跳的中间档。对相邻可选档计算 (pᵢ,ⱼ₊₁ − pᵢⱼ) / (cᵢ,ⱼ₊₁ − cᵢⱼ)，跨样本按边际 ROI 从高到低累加新增花费。用人工组购买率及核销金额估算目标花费，找到累计开销低于 δ × 目标花费的最后一档，其边际 ROI 就是执行阈值。δ 控制预算水平。[LR25019 §3.3](https://cooper.didichuxing.com/knowledge/2199610335356/2204724694085)

**为什么线上五档只剩两档。** 当时 75/80/85/90/95 档的核销金额统计值约为 8.15/6.53/5.00/4.21/4.08，ROI 阈值约为 0.1918。原文一个样本从 95→90、90→85、85→80 的边际 ROI 分别为 0.2372、0.1994、0.1528，最终停在 85。另一个样本从 90→85 只有 0.1493，停在 90。购买率虽因人而异，各档统一的核销成本掩盖了部分个体差异，实际集中在 85 和 90。作者提出按档核算购买后的核销率、建模核销金额或调整排序指标，并补充多档离线评价。这些是后续改进方向。[LR25019 §4.4](https://cooper.didichuxing.com/knowledge/2199610335356/2204724694085)

## 7 月单策略与 8 月叠加实验

7 月 1–14 日全国按乘客 ID 分流，智能 SKU、人工按城市配 SKU、95 档空白组各占 1%。相对人工，**曝光购买率从 1.078% 到 1.273%（相对 +18.05%），呼单用户渗透率从 0.962% 到 1.203%（相对 +25.01%），均显著**。总 C 补率约为 10.428% 和 10.426%，套餐 C 补率则从 0.394% 到 0.464%。两者分开看才能识别预算转移。人均呼叫、完单、GMV 均未检出显著变化，套餐渗透基线约 1%。按主要依据客单价划出的 5 个城市框下钻，在原文定义的“渗透率 / 套餐 C 补率”较高的 4、5 框加补更多，渗透提升集中于此，2、3 框略降。该比值适合描述分组，不宜当作加一单位补贴的因果增量。[7 月分组和全量指标表，第 2 个工作表](附件/LR25019/033.xlsx) · [城市分框结果](附件/LR25019/034.png)

8 月 1–28 日全国按乘客 ID 分流，五组各 2%。人工对照维持售卖 50 档和按城市配置的券档，空白组售卖 80 档配 95 档券，单 SKU 组售卖 50 档，单定价组用人工券档，叠加组同时请求两个模型。定价端采用 DR-CFR 双塔，SKU 端采用上述多头模型，各自选择自己的动作。8 月目标为总 C 补率匹配时呼单用户渗透率相对提高 10%，人均完单和 GMV 仍为约束项。[LR25030 §2–4](https://cooper.didichuxing.com/knowledge/2199610335356/2205375971925)

## 回到人群和补贴机制

实验按**实验前** 14 天呼叫次数分为 0、1–3、4–9、≥10 次四组。14 天叠加相对单 SKU，低频组渗透率 −0.81%、人均呼叫 −0.16%，均不显著。总 C 补率 −1.13% 不显著，套餐 C 补率 −15.09% 显著。其余三组的渗透率和人均呼叫点估计同向上升。到 28 天四组均同向上升，无呼叫组渗透率相对增幅最大（+7.63%），中频组人均呼叫相对增幅最大（+1.37%）。这些人群结果用于定位收益来源，显著性以各组原表为准。[LR25030 §4.3.1](https://cooper.didichuxing.com/knowledge/2199610335356/2205375971925)

观察人群流转时还要写清对照。前两周，叠加组相对空白组的中频转高频、高频保持高频分别为 +0.34、+0.83pp，单 SKU 相对空白组分别为 −0.20、+0.07pp。低频转中频则是单 SKU +0.10pp、叠加 −0.17pp。到第 3–4 周，低频转高频仍由单 SKU 略占优，高频保持高频仍由叠加占优。原文解释，高频用户得到更深的券内折扣，低频用户得到更低的买卡价格。扩展购买者范围后，每位购买者的购买及核销次数可能下降，因此渗透率可以上升而总 C 补率点估计下降。统一给所有人最低售卖档会同时覆盖高频高核销人群，不能照此外推出预算可控。[LR25030 §4.3、§5](https://cooper.didichuxing.com/knowledge/2199610335356/2205375971925)

## 迁移到升舱、表单与模型迭代

- **升舱与表单。** 先分清补差、展示、默认选项分别作用在哪个时点，记录动作前资格、实际曝光、接受与最终履约。只在曝光后训练会改变样本构成，训练时就记录同一乘客多次曝光如何去重，线上按乘客核对最终完单和总成本。
- **多个动作一起上线。** 复用“现状、各单动作、组合”的实验对照，提前指定组合相对已上线动作的增量和预算容差，同时看动作实际分布。哪怕组合胜过人工，仍要从组合对单动作的差异判断是否值得增加第二个动作。
- **模型迭代。** 对每个档检查实际动作占比、估计成本、相邻档增益和最终入选比例。能预测出各档差异，却在线上只选择两档时，可从成本聚合与阈值入手。对长周期补贴，把延迟核销加入评估窗口，再比较分档策略。

**继续查证。** 单定价还有自动更新实验，复现模型更新或重算实验时可从对应资料进入。[初版定价](https://cooper.didichuxing.com/knowledge/2199610335356/2201832959001) · [定价自动更新方案](https://cooper.didichuxing.com/knowledge/2199610335356/2203570525921) · [自动更新实验评估](https://cooper.didichuxing.com/knowledge/2199610335356/2204020484348) · [套餐评估体系二期](https://cooper.didichuxing.com/knowledge/2199610335356/2204640152600)
