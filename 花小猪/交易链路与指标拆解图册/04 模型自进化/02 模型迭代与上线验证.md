# 模型迭代与上线验证

从业务结果和中间事件定位问题，决定这一轮该修标签、补日志、更新模型，还是调整策略。模型验证依次看**样本质量、预测、决策变化、执行以及真实业务收益**。

## 哪一步先出现差异

| 看到的结果 | 下一步查什么 | 可能对应的改动 |
|---|---|---|
| 预分单接受率变化 | 对齐触发时点和实际展现，固定候选与价格分层，看实际接受、明确拒绝和默认拒绝。再检查预测分桶均值与实际频率。 | 触达与人群结构变化先复盘策略。排序或校准在同类可比样本上退化，再改模型或校准。 |
| 预分单接受增加，但正式应答或完单变化小 | 看运力举手、原车型先应答、乘客接受到正式应答的转化，再对齐最终订单。 | 按差异出在触发、候选供给、竞争或履约选择动作。 |
| 可升舱订单变化，但举手和正式应答没有跟上 | 查是否发单、预算及资格过滤、实际有运力举手后的胜出与应答。 | 调整可行候选或约束。接受度阈值变化也要查看实际改变了哪些动作。 |
| 升舱数量／补贴变动，平台完单差异不明 | 对照原车型、自付预分单和升舱的终态。并列策略参与订单、全量归一完单、总补贴和城市时段分布。 | 用对照实验核净增与成本，避免把付费转化或承接品牌迁移计入平台增量。 |

历史 AR 材料曾分别定位到产品线归属映射问题和供需特征取 0 的问题。接受度模型也有线上、离线推理核对记录。遇到异常，先逐单核对决策时间、模型版本、特征值、标签及样本漏损，再判断是数据还是模型。[[AR模型数据质量：预测偏差、标签与特征修复|AR 数据质量历史排查]] · [[预分单接受度模型在离线一致性检验|接受度的离在线一致性检验]]

## 怎么判断新版本可以扩大流量

1. **离线留出。** 固定同一批具备真实反馈的样本，按时间留出，在相同口径下比排序、概率分桶和均值，分新客、流失用户、普通用户及等待、价差、商家看误差、覆盖与样本量。接受度、原候选应答与最终完单的目标时点分别记录。历史新流升舱接受度测试中，XGBoost 新流 AUC 从 0.663 到 0.717，预测均值从 0.149 到 0.288，实际约 0.295。复盘还能继续问该概率变化是否改变升舱决策。[[新流升舱：接受度模型、取消分析与实验结果|历史接受度测试与分层结果]]
2. **回放动作。** 用同一时点的候选集合和策略约束跑旧、新模型，核预分单触发和车型排序、升舱与普通预分单互转、被预算拦截和实际有运力的比例。同一订单不同轮次按当时状态评估。未执行候选的业务结果依赖实验支持，回放用于检查动作变化。
3. **固定线上对照。** 要拆模型收益，就尽量固定触发、候选和预算约束，仅换模型。要拆新增场景，比较同版策略有无该场景。要判断钱效，比较同预算的增量完单，或同增量完单所需的实际增量补贴。用原随机分配单位汇总全体，以实际触达和执行漏损解释过程，同时跟踪乘客 ETP、司乘取消、商家迁移和司机接驾。存在供给挤占时，再核不同实验组的司机暴露与按时空分组的可行性。
4. **回流再决定。** 结算、完单与取消观察期结束后，保存分组、策略版本、模型版本、完整候选和实际动作。根据覆盖、分层校准、触达和业务结果决定保留版本、回收流量或下一轮重训。模型自进化在此是建议建设的迭代过程。

例如新流升舱 3.0 的记录中，同一实验组相对空白组的 CAC 是 11.75，相对历史策略的增量 CAC 是 8.65。与同版、无新增场景的对照相比，司机取消后改派场景的 CR 增加 0.11 个百分点。三个差值各自回答不同问题。预估钱效依赖假设，实际增量仍需上述对照和成本读数。[[新流升舱：接受度模型、取消分析与实验结果#两期实验怎样比较|新流升舱实验的三种比较]] · [[新流升舱：决策公式、预算与工程链路#预算怎样变成逐单决策|历史升舱期望收益与预算]]
