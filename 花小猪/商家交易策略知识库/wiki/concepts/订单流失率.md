# 订单流失率

## 定义

订单流失率是指在分单（轮次播单）过程中，订单因长时间未被应答而被乘客取消或超时的概率。反映了当前订单的"紧迫程度"。

## 在 V2 策略中的作用

V2 架构引入订单流失率作为**动态阈值调节器**：

```
流失率低 → 订单不急迫 → 严格过滤 → 优先保证应答后履约率
流失率高 → 订单即将流失 → 放宽过滤 → 优先保证商家应答率
```

这实现了一种自适应的 exploration-exploitation 平衡：
- 当订单还"等得起"时，宁可少播几个司机也要保证质量
- 当订单快要流失时，扩大范围尽快找到司机应答

## 与取消率模型的配合

订单流失率决定过滤阈值，取消率模型决定过滤对象：
- 流失率 → "过滤多严格"（阈值）
- 取消率模型 → "过滤谁"（打分）
