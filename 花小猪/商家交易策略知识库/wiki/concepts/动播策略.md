# 动播策略

## 定义

动播（动态播单）策略是指在**运力充足的情况下**，对订单的初始播单半径进行**缩播**（缩小），从而缩短接驾距离、降低应答后司乘取消率的策略。

核心思想：当供需比高（司机多、订单少）时，不需要播到很远去找司机，缩小半径让近处的司机来应答，接驾距离短，乘客和司机都更满意。

## 触发条件

动播策略只在供需较好时生效。各版本的触发条件：

**V0 版本**：基于格子维度的 `空闲运力数 / 未播订单数`（[[花小猪/商家交易策略知识库/wiki/concepts/供需比]]）划分三档。

**V1 版本**：基于 `空闲运力数` + `供需比` + `竞争应答率` 三维度共同判断：
- 空闲运力数 ≥ N 且供需比 ≥ S 且应答率 ≥ A → 缩至 R1（最小半径）
- 空闲运力数 ≥ N 且供需比 ≥ S 且应答率 < A → 缩至 R2
- 空闲运力数 ≥ N 且供需比 < S 且应答率 ≥ A2 → 缩至 R3
- 否则不生效

## 与扩播的关系

动播和扩播是播单策略的两个方面：
- **动播**：决定初始半径（缩播 → 小半径开始）
- **扩播**：决定扩展节奏（随时间逐步扩大到最大半径）

在 V0 时代两者独立迭代；V1 开始统一为一套策略体系（"自适应动态播单"）。

## 演进历程

| 版本 | 核心改进 | 效果 |
|------|---------|------|
| 动播V0 | 供需比三档 + 固定缩播半径 | 自营 CR +0.06pp |
| 动播V1 | 多维供需刻画 + 统计值定半径 | 自营完单 +0.45%, CR +0.13pp, C取消 -0.08pp |

## Lowlights（历史遗留问题）

- V0：供需只用空闲运力和未播订单数，精确度差
- V1：全国相似供需格子配同一半径，忽略城市间路网差异
- V1：策播部分基于大盘统计值，未做到订单维度自适应
