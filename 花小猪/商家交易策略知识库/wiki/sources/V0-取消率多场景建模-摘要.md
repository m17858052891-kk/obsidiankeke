# 特殊场景取消率多场景建模

## 背景

扩播和连环派是两个「特殊召回场景」，有对应取消率模型过滤。两个可优化点：
1. **样本稀疏**：特殊场景样本少于正常应答场景（尤其扩播）
2. **模型数量过多**：各场景独立模型，维护成本高

探索方向：**多场景多任务建模**，一个模型服务多个场景。

## 模型对比

### 扩播乘客取消（双场景：扩播 + 非扩播）

| 模型 | 结构 | 离线AUC |
|------|------|---------|
| XGBoost (baseline) | - | 0.6485 |
| PLE | 多门控混合专家 | 0.649 |
| **PPNet (单任务版本)** | 参数个性化网络 | **0.6511** |

### 乘客取消（三场景：扩播 + 非扩播 + 连环派）

| 模型 | 扩播AUC | 连环派AUC |
|------|---------|-----------|
| XGBoost (baseline) | 0.6523 | **0.6962** |
| PPNet (单任务版本) | **0.656** | 0.6906 |
| PLE | 0.653 | 0.6862 |

## 关键结论

1. **PPNet 在扩播场景效果最佳**（AUC 0.656 vs 0.6523 baseline）
2. **连环派场景 XGBoost 仍然最优**（0.6962）——可能因为连环派特征模式不同
3. 多场景建模对扩播有帮助（借助非扩播场景的大量样本），但对连环派反而略有损失
4. PLE 表现一般，不如 PPNet
