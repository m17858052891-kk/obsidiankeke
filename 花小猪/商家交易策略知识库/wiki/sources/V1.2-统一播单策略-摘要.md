# V1.2 — 统一播单策略体系

## 核心突破

V1.2 是 V1 系列的巅峰：将动播和扩播**回收为一套完整策略体系**，基于供需状况、订单里程和等应答时长，在竞争视角下动态调整召回半径。

## 策略框架

```
发单 → 供需判断 → 确定初始半径(动播) → 基于预估应答时间T自适应扩播 → 最大半径
```

**关键创新**：引入 **Athena 预估应答时间 T** 作为扩播锚点（端外兜底60s）。

## V1.2.0 实验设计

- 全国乘客随机分流，10%对照 / 90%实验
- 周期：2024.10.25 — 10.31
- 三组实验对比不同扩播策略：

| 实验组 | 扩播生效时间 | 扩播终止时间 | 核心区别 |
|--------|-------------|-------------|---------|
| A | T/2 | T | 中间开始，线性扩至T |
| B | 2T/3 | T | 较晚开始，线性扩至T |
| **C** | **2T/3** | **2T/3** | **瞬时扩播（在2T/3时刻直接扩至最大）** |

## V1.2.0 实验结果（里程碑）

### 整体（实验组C，效果最佳）

| 指标 | 变化 | 显著性 |
|------|------|--------|
| **人均完单** | **+2.02%** | ✅显著 |
| **竞争CR** | **+0.30pp** | ✅显著 |
| 竞争AR | **+0.49pp** | ✅显著 |
| 应答后C取消 | +0.30pp | ✅显著 |
| 应答后B取消 | -0.04pp | 不显著 |
| 接驾距离 | +2.27% | ✅显著 |
| 举手率 | +0.62pp | - |

### 三组对比

| 指标 | 组A | 组B | 组C |
|------|-----|-----|-----|
| 完单 | +1.5% | +1.39% | **+2.02%** |
| CR | +0.21pp | +0.2pp | **+0.3pp** |
| AR | +0.34pp | +0.35pp | **+0.49pp** |
| C取消 | +0.24pp | +0.28pp | +0.3pp |
| 接驾距离 | +1.53% | +1.98% | +2.27% |

**结论**：瞬时扩播(组C) > 渐进扩播(组A/B)，扩播越快越有效。

### 短单（<5km，实验组C）— 动播效果

| 指标 | 变化 |
|------|------|
| 竞争CR | **+0.11pp** |
| 人均完单 | **+0.79%** |
| 竞争AR | +0.1pp |
| C取消 | **-0.12pp** |
| 接驾距离 | **-0.23%** |

短单收益来源清晰：缩播 → 接驾距离降低 → C取消降低 → CR上升。

## V1.2.1：供需特征优化

- 供需特征口径：两圈格子 → 一圈格子（更精确）
- 支持 by 城市维度配置半径
- 进行了两期实验验证

## 关键洞察

1. **+2.02% 完单是 V1 系列最大突破**：统一框架效果远超分别迭代
2. **瞬时扩播优于渐进扩播**：快速扩大范围在竞争态下更有优势，为V2"大半径"思路铺垫
3. **Athena预估应答时间是好的锚点**：个性化了扩播时机（而非全局统一T）
4. **C取消上升可接受**：+0.3pp C取消换来+2.02%完单，ROI极高
5. **短单证明动播独立有效**：即使不考虑扩播，动播缩短接驾距离也有净收益
