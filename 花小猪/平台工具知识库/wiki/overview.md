## 典型工作流

1. **离线特征生产**：数梦调度 Spark SQL → DUFE 同步到在线存储 → 注册特征
2. **模型训练**：EVE 可视化 DAG 或 Luban 脚本训练 → 导出模型
3. **模型部署**：EVE 集群/容器部署 → 特征映射 → 预发验证 → 上线切流
4. **策略上线**：模型+特征上线 → [[花小猪/平台工具知识库/wiki/workflows/模型策略上线校验SOP|一致性校验]] → AB 实验 → 效果评估
