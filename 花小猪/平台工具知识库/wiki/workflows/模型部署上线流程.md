# 模型部署上线流程

## 概述

模型训练完成后，通过 [[花小猪/平台工具知识库/wiki/entities/EVE]] 平台将模型部署到线上提供推理服务。支持集群部署和容器部署两种方式。

## 部署方式选择

| 场景 | 推荐方式 |
|------|---------|
| 非深度模型 | 集群部署 (model 集群) |
| TF 2.0 模型 | 集群部署 (dl115 集群) 或容器部署 |
| 深度模型（通用） | **容器部署**（推荐） |
| 需要资源隔离 | 容器部署 |

容器部署优势：支持更新 TF 版本、资源隔离、支持大模型。

## 集群部署流程

### Step 1: 创建部署

创建在线服务，配置模型版本。支持：
- 不同城市指定不同版本
- 同城市多模型 AB 实验（依托 [[花小猪/平台工具知识库/wiki/entities/Apollo]]）

### Step 2: 特征映射

将模型输入特征映射到线上数据源：
- **手动匹配**：逐一选择线上特征
- **自动映射**：复用历史部署的映射关系
- **批量操作**：批量设置传入特征开关
- **批量导入**：通过 JSON 跨部署导入

> EVE 特征库记录了线上特征的获取方法，配置映射后无需关心获取细节。

### Step 3: 部署预发

将模型推送至预发环境验证在线服务状态。

### Step 4: 提交审核（仅首次）

第一次部署需管理员审核，后续部署不需要。

### Step 5: 部署上线

点击"部署" → 平台自动生成线上配置并推送。

### Step 6: 切流

- 滑条控制新版本流量比例
- 100% = 全流量上线
- 切流完成后点击"上线完成"

### Step 7: 验证

- 通过部署页面"预估" tab 验证模型预估
- 执行 [[花小猪/平台工具知识库/wiki/workflows/模型策略上线校验SOP|一致性校验]]

## 容器部署流程

### 前提条件

- 项目已绑定 [[花小猪/平台工具知识库/wiki/entities/Luban]] 账户且有机器资源
- 模型仓库中有可部署的模型

### 配置

- 选择模型版本
- 配置特征映射（JSON 格式）
- 提交部署

## 深度模型导入要求

需要 `model.conf` 配置文件，关键字段见 [[花小猪/平台工具知识库/wiki/concepts/模型训练#深度模型导入 EVE]]

## 服务调用

| 方式 | 说明 |
|------|------|
| eve-sdk | 推荐，封装好的 SDK |
| thrift | 直接 RPC 调用，需提供 model_name |

调用时：
- `version` 为空 → 请求默认模型
- 指定 `version` → 跳过默认模型
- 不同城市不同版本时**必须**提供 version
