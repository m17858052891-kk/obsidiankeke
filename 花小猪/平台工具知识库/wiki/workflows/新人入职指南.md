## 2. 技术平台使用

| 平台 | 定位 | 地址 |
|------|------|------|
| **Luban** | 模型训练 & 开发机 | https://ml.intra.xiaojukeji.com/axe#/home |
| **EVE** | 模型上线、容器部署、可视化建模 | https://ether.intra.hongyibo.com.cn/ |
| **Apollo** | AB 实验 / 灰度 / 配置同步 | https://ab.intra.hongyibo.com.cn/ |

### 2.1 Luban 权限申请步骤

1. 进入 [项目组列表](https://ml.intra.xiaojukeji.com/axe#/projects)
2. 点击"申请加入项目"，搜索 `kflowerStrategyEnv`
3. 提交申请等待审批

> 详细使用 → [[花小猪/平台工具知识库/wiki/entities/Luban]]

### 2.2 堡垒机（非必须）

组内部分服务器需通过堡垒机连接：[堡垒机配置文档](https://cooper.didichuxing.com/docs2/document/2202927466640)

### 2.3 EVE 权限申请步骤

1. 进入 [项目管理列表](https://ether.intra.hongyibo.com.cn/projectManage/projectList)
2. 选择 **花小猪策略** → "加入项目"
3. 选择"自行申请"
4. 角色 → **实验平台用户**，标识位 → **花小猪策略**
5. 填写理由，提交

> 详细使用 → [[花小猪/平台工具知识库/wiki/entities/EVE]]
> EVE 用户群（D-Chat）：[加入链接](https://im.xiaojukeji.com/channel?uid=671154&token=a2ea5d50db9ff2d596b8e84720ad018c&id=232414279459543296)

### 2.4 Apollo（非必须）

进入 https://ab.intra.hongyibo.com.cn/ 后按页面倚天流程申请权限。

> 详细使用 → [[花小猪/平台工具知识库/wiki/entities/Apollo]]

### 2.5 Gitlab 权限

- 平台地址：https://git.xiaojukeji.com
- 操作指南：[Cooper 文档](https://cooper.didichuxing.com/knowledge/2199610335356/2201214419059)
- 权限获取：D-Chat 联系 leader 拉入 **bwh_stg** Group

组内代码库：

## 3. 本机环境配置

### 3.1 科学上网（Clash Verge）

- 下载：https://github.com/clash-verge-rev/clash-verge-rev
- 内网直连域名配置（系统代理 → 始终绕过）：

```
*.xiaojukeji.com,
*.didichuxing.com,
*.didiglobal.com,
*.diditaxi.com.cn,
*.talkingdata.com,
*.hongyibo.com.cn,
*.didistatic.com,
*.bigdata-nmg-hdprm00.nmg01
```

### 3.2 终端工具对比

| 工具 | 定位 | 优点 | 缺点 |
|------|------|------|------|
| **Terminal** | 系统自带 | 安全、低功耗 | 无分屏、无可视化 SSH |
| **Tabby** | 开源全能 | 可视化 SSH、高度自定义 | Electron 内存占用大 |
| **Termius** | 商业跨平台 | 云同步、AI 命令补全 | 需登录/订阅 |

### 3.3 Python 环境

推荐使用 **Miniforge**（无需商业 License）：
- GitHub：https://github.com/conda-forge/miniforge
- 安装参考：https://zhuanlan.zhihu.com/p/683756145
- 用法与 Anaconda 一致（`conda` 命令）

### 3.4 AI Coding 工具对比

| 工具 | 厂商 | 价格 | 模型 | Agent 能力 |
|------|------|------|------|-----------|
| **Smart Code** | 公司内部 | 免费 | doubao/qwen/deepseek/kimi/glm | 较弱 |
| **Copilot** | Microsoft | 较便宜 | GPT/Gemini 系列 | 中等 |
| **Cursor** | Cursor | 较贵 | GPT/Gemini/Claude 等 | 较强 |
| **Claude Code** | Anthropic | 视配置 | Claude/qwen/kimi/glm | 较强 |

> Smart Code 使用手册：[Cooper 文档](https://cooper.didichuxing.com/knowledge/share/book/dgjQ79AI1zfF/2201211809263)
> Cursor：https://cursor.com/
> Claude Code：https://code.claude.com/docs/zh-CN/quickstart
