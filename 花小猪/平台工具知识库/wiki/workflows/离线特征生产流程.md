# 离线特征生产流程

## 入口

https://dufe-v2.intra.xiaojukeji.com/new-task → 右上角【新增任务】

## Step 1: 基本信息

| 配置项 | 说明 |
|-------|------|
| 任务名称 | 体现业务场景和用途 |
| 接口人 | 组内同学，最少 3 人 |
| 任务告警人 | 多个实际关注人员 |
| 任务告警组 | `kflower_dups_dict` |
| 特征标签 | 订单类/地点类/司机类等 |
| SLA 时间 | 任务未产出时触发告警的时间 |
| 定时切换 | 自动切换 or 定时切换 |

## Step 2: 任务配置

### Dict 集群

根据业务场景选择依赖的集群。

### 基线选择

| 等级 | 适用 | 特点 |
|------|------|------|
| L2 | 普通任务 | 普通优先级 |
| L7 | 重要任务 | 较高优先级 |
| L8 | 重保任务 | 电话报警 |

### Spark 参数

详见 [[花小猪/平台工具知识库/wiki/entities/Spark#资源配置建议]]

### 特征前缀与主键

- 特征前缀 + 主键 → 拼接为 key
- **主键必须唯一**（否则导致重复）
- 不要给主键列加前缀

### SQL 编写

- 特征列必须加类型前缀（`odt_`/`d_`/`p_`/`o_`/`s_`/`b_`/`i_`）
- 主键列不加前缀
- 使用 `param_year-param_month-param_day` 作为日期变量

```sql
SELECT city_id, city_feature AS odt_city_feature
FROM dbname.tablename
WHERE dt = 'param_year-param_month-param_day';
```

### 依赖 Tag 与偏移量

- Tag = SQL 中查询的表（tag 就绪才触发任务）
- 偏移量：0 = 当天，1 = T-1 日（一般与 tag 偏移相反）
- 需要 HDFS 权限：https://pam.data.didichuxing.com/role/apply?type=project

## Step 3: 质检配置

- **行数校验**：结果行数是否正常
- **空值率检测**：空值行数/总行数 > 阈值时触发报警
- 质检通过后才触发 Fastload 同步

## Step 4: 工单流转

1. **预览**：验证 SQL 和配置正确性
2. **填写特征信息**：中文特征名（完整表达含义），检查英文名与列名一致
3. **审批上线**：找负责人审批 → 点击上线
4. 平台自动执行 HDFS 任务和 Fastload 任务
5. 等待 Fastload 完成 = 特征生产完成

## 常见问题

- **HDFS 权限失败**：需到数梦申请依赖 Tag 的 HDFS 权限
- **预览内存超限**：联系管理员（@yuhaotian @tidusfengxinjie）跳过预览
- **工单调整**：需管理员驳回后重新修改
