# 数梦 (DataDream) 数据调度平台

## 定位

滴滴内部的**大数据离线调度平台**，负责 ETL 任务编排、依赖管理、周期性调度执行。是离线数据处理和特征生产的核心基础设施。

## 核心能力

- **任务调度**：支持分钟/小时/天/周/月级别的周期性任务
- **依赖管理**：基于 Tag（表分区产出）的上下游依赖触发
- **Spark 任务执行**：通过队列（如 `root.kflower_strategy_prod`）提交 Spark 任务
- **变量系统**：支持日期变量（`${Y}${M}${D}`）自动替换

## 关键概念

### Tag 依赖

- 含义同数梦 tag，只有 tag 条件满足，下游任务才会触发
- SQL 中查询哪些表，tag 就设置这些表
- 离线任务只有当依赖的 tag 就绪时才可能运行

### 偏移量

- 代表 SQL 中日期参数的偏移量
- 0 = 当前日期，1 = T-1 日，以此类推
- 一般与 tag 偏移量相反

### 基线保障

| 基线等级 | 说明 | 适用场景 |
|---------|------|---------|
| L2 | 普通优先级 | 普通任务 |
| L7 | 较高优先级 | 重要任务 |
| L8 | 最高优先级（电话报警） | 重保任务 |
