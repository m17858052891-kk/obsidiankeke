# 来源摘要：业务术语表

> 原文：[[花小猪/平台工具知识库/raw/业务术语表.md]]

## 元信息

- **类型**：团队内部术语词汇表
- **覆盖范围**：交易策略全链路术语（指标 / 分单 / 定价 / 司机 / 平台系统）
- **条目数**：约 80+ 条

## 核心内容

### 按分类整理

1. **核心指标**：ASP、AR、BCR、CR、ECR、GMV、IPH、TPH、TR、CTR、CVR、CPO、NPS、TSH
2. **时间距离预估**：EDA、ETA、ETP、lumian
3. **定价与策略颗粒度**：OT、ODT、ODTP、OD 对、动调、补贴
4. **分单派单**：bubble/冒泡、播单、半指派、拉单、抢单、拉抢合一、连环派单、改派、topspeed、分单矩阵
5. **司机相关**：空闲司机、静默、升舱、CD、向下听单、服务分
6. **订单统计口径**：订单数、播单数、完成订单数、应答数等（明确了改派计数规则）
7. **平台系统**：duse、dfs、SDS、SDP、GCS、Gizzle、VRP
8. **产品线缩写**：hxz（花小猪）、hh（鸿鹄）、jp（竞品）、zy（自营）

### 关键口径公式

- BCR = ECR × CR
- IPH = 总收入 / 总在线时长
- TPH = 总完单量 / 总在线时长
- TR = (GMV − 司机应收) / GMV
- CPO = 当日总呼入量 / 完成订单数
