# 离线特征生产

## 概述

离线特征生产链路基于离线 Hive 表生产特征，并同步到在线存储，供在线服务通过 [[花小猪/平台工具知识库/wiki/entities/DUFE]] 查询使用。

## 核心能力

1. **SQL 特征计算**：平台上配置 SQL 实现特征计算
2. **特征质量检查**：行数校验、空值率校验、空值率环比校验
3. **特征同步**：Fastload 任务将数据同步到在线存储
4. **特征注册**：自动注册到 DUFE，同步完成即可在模板中引用

## 数据流

```
Hive 表 → SQL 计算(Spark) → 质检 → Fastload → 在线存储(Dict) → DUFE 可用
                ↑                                        ↓
          数梦调度触发                              模板引用特征
```

## 存储模型

- 每个同步任务生成一张 Dict 表
- 结构：`Key`-`Field`-`Value`（Hash 结构）
- Key = `特征前缀_${主键值}`
- Field = 特征名
- Value = 特征值

## 关键配置

### Spark 参数建议

| 数据规模 | minExecutors | maxExecutors |
|---------|--------------|--------------|
| 万条以内 | 10 | 20 |
| 千万级别 | 100 | 200 |
| 亿级以上 | 200 | 300 |

### 版本切换策略

- **自动切换**：Fastload 完成后立即切换
- **定时切换**：延迟到 cron_time 再切换

## 注意事项

- 主键必须唯一（否则导致 key 重复）
- SQL 特征列需添加类型前缀（`odt_`/`d_`/`p_` 等）
- 主键列不要添加前缀
- 需要 HDFS 权限才能访问依赖表
