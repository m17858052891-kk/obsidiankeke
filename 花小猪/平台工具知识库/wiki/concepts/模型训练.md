# 模型训练

## 概述

模型训练是策略算法迭代的核心环节，将准备好的特征数据输入算法框架，产出可部署的模型文件。团队支持两种训练方式：

1. **EVE 可视化训练**：拖拽式 DAG 编排，适合 XGBoost/SparkML 等传统 ML 模型
2. **Luban 脚本训练**：代码式开发，适合深度学习模型（TF/PyTorch）

## EVE 可视化训练

通过 [[花小猪/平台工具知识库/wiki/entities/EVE]] 平台：

1. 配置数梦信息（Hadoop 账户）
2. 准备数据（Hive 表 / 公共数据）
3. 创建实验 → 构建 DAG → 运行
4. 查看评估报告 → 导出模型

典型 DAG 组成：数据源 → 数据/特征处理 → 模型训练 → 模型预测/评估

### 支持的框架

- XGBoost（支持特征重要性可视化）
- SparkML
- 深度模型导入（TensorFlow SavedModel / PyTorch TorchScript）

## Luban 脚本训练

通过 [[花小猪/平台工具知识库/wiki/entities/Luban]] 开发机：

- 支持 GPU 训练
- 可直接读取 HDFS 数据训练
- 支持自定义 conda 环境
- 推荐使用 TFRecord 格式加速训练

## 深度模型训练框架

团队内部封装的通用框架，详见 [[花小猪/平台工具知识库/raw/模型训练框架介绍.md]]：

### 架构

```
config.yaml          ← 配置管理（超参、模型选择）
config.py            ← 归一化参数存储
models/              ← 模型库（DCN、MMOE、双塔等）
├── __init__.py      ← 工厂模式注册
├── basic_layers.py  ← MLP、Cross Network
└── Embedding_layers.py
main.py              ← 训练引擎
```

### 关键特性

- **工厂模式**：通过 yaml 配置选择模型，无需改代码
- **多任务支持**：自动管理多 Task 的 Loss 和指标
- **TensorBoard 可视化**：实时监控训练状态
- **ONNX 导出**：统一导出格式供工程上线

### 使用方法

1. 编辑 `config.yaml` 设置模型/超参/特征维度
2. `python main.py` 运行（首次自动计算归一化参数）
3. 训练完成自动保存最佳权重 `model_weights.pt`
4. 导出为 `.onnx` 格式

## 深度模型导入 EVE

导入目录结构：
```
<root-path>/online_model/
├── export_model/     ← 模型文件
│   ├── saved_model.pb + variables/  (TF)
│   └── model.pt                      (PyTorch)
└── model.conf        ← 模型元信息
```

`model.conf` 关键字段：
- `inputNames`：输入 tensor 名字（必填）
- `inputShapes`：输入 tensor shape（必填）
- `featureOrder`：特征顺序，决定在 tensor 中的位置（必填）
- `signatureKey`：TF 计算图名（仅 TF）
