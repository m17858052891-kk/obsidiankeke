# 模型定期更新

## 概述

在实际生产中，需要使用最新数据不断迭代模型。[[花小猪/平台工具知识库/wiki/entities/EVE]] 提供模型定期更新功能，实现**非增量训练**：相同建模参数 + 最新数据 → 新模型。

## Pipeline

```
模型训练 → 模型导出(到仓库) → 评估检查 → 部署上线
```

## 前提条件

1. 已有手工训练并部署成功的基础模型
2. SQL 中使用时间变量框定训练数据（如 `${BIZ_DATE_LINE}`）
3. 完成完整的首次部署流程

## 配置要素

### 调度配置

- 训练的时间、周期
- 支持自动重试 N 次

### 关联训练 ID

- **置空/0**：使用模型导出时保存的 DAG 图
- **指定 ID**：优先使用指定实验的 DAG 图（用于快速修改定期更新的训练配置）

### 部署配置

- 部署开关：产出模型后是否自动部署
- 创建新版本 vs 覆盖原有模型

### 评估标准

只有通过评估检查的模型才会部署到线上，防止劣质模型上线。

## SQL 日期变量

配置训练参数时，变量类型设为 `time`，在自定义 SQL 中使用：
```sql
SELECT a, b, c FROM db.table
WHERE dt <= '${BIZ_DATE_LINE}'
AND dt >= date_add('${BIZ_DATE_LINE}', -2)
```

## 注意事项

- 关联实验产出的模型语义需与线上模型一致（如特征数量）
- 创建新 version 需配置回调，让上游系统感知
- 回调配置支持 HTTP 地址通知部署情况
