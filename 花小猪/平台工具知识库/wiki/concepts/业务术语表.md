# 业务术语表

滴滴交易策略团队常用业务术语、缩写及其含义。按首字母排序。

---

## 核心指标类

| 缩写 | 全称 | 含义 | 口径 |
|------|------|------|------|
| ASP | Average Selling Price | 客单价/单均价 | |
| AR | — | 呼叫应答率 | 应答订单量 / 发出订单量 |
| BCR | — | 冒泡完单率 | BCR = ECR × CR |
| CR | — | 呼叫完单率 | 完成订单量 / 发出订单量 |
| ECR | Eyeball Convert Rate | 冒泡转化率（冒泡呼叫率） | |
| GMV | Gross Merchandize Volume | 流水（交易额） | 完单应付金额总和（不扣券/折扣） |
| IPH | Income Per Hour | 司机每小时收入（含补贴） | 总收入 / 总在线时长 |
| TPH | Transactions Per Hour | 司机每小时完单数 | 总完单量 / 总在线时长 |
| TR | Taking Rate | 抽成率 | (GMV − 司机应收) / GMV |
| CTR | Click-Through Rate | 点击率 | 点击量 / 曝光量 |
| CVR | Conversation Rate | 转化率 | 转化量 / 点击量 |
| CPO | Call-in Per Order | 单均进线次数 | 当日总呼入量 / 完成订单数 |
| NPS | Net Promoter Score | 净推荐值 | |
| TSH | Total Service/Supply Hour | 司机总服务/在线时长 | |

## 定价与策略颗粒度

| 缩写 | 含义 | 场景举例 |
|------|------|---------|
| OT | Origin + Time | 动调（起点×时间差异化定价） |
| ODT | Origin + Destination + Time | 呼返（起终点×时间差异化定价） |
| ODTP | Origin + Destination + Time + Person | 默勾（加用户特征的差异化策略） |
| OD 对 | Order-Driver 对 | 分单语境下的订单-司机配对 |
| 动调 | 动态调价 | 供 < 需时用户加价 |
| 补贴 | 区域盘古补贴 | 热区接单收入倍率加成 |

## 分单与派单

| 术语 | 含义 |
|------|------|
| bubble/冒泡 | 用户输入目的地后弹出价格的动作 |
| 播单 | 平台将订单推送给司机 |
| 半指派 | 平台一次指派一个司机，司机可无责拒绝 |
| 拉单 | 司机根据 token 从存储拉取订单信息 |
| 抢单 | 司机决定接单，点击抢单触发 |
| 拉抢合一 | 司机设置极速抢单，自动完成拉取+抢单 |
| 连环派单 | 行程临近终点时提前派下一单（减少空驶） |
| 改派 | 司机取消 → 系统给乘客重新派单 |
| topspeed | 快速匹配派单：附近最近 N 个极速司机中选最优 |
| 分单矩阵 | 进入候选池但不一定距离最近 |
| 就近指派 | 预约单临近出发前 30min 再指派（"近"指时间） |
| 乘客排队 | 发单密集地点，乘客排队分单 |
| 司机排队 | 司机密集地点，司机排队接单 |
| DA (DriverArrange) | 安排豪华车当班司机的分单场景 |

## 司机相关

| 术语 | 含义 |
|------|------|
| 空闲司机 | 不在接驾/送驾，可听实时单，未设目的地 |
| 静默 | 司机无法被派单 |
| 升舱 | 专车司机平峰时接快车订单 |
| CD (Cool Down) | 优享司机接快车单后冷却期内不可再接快车 |
| 向下听单 | 高级车型司机听低级车型单 |
| 服务分 | 基于大数据的司机综合服务评价（满分 100） |
| 卡单 | 司机说法：快达成奖励时平台不派单 |
| 扎针 | 司机用乘客端下假单再取消致他人有责 |

## 订单统计口径

| 术语 | 口径说明 |
|------|---------|
| 订单数 | 发单时间在当天，改派只算 1 单 |
| 播单数 | 播单时间在当天，改派仅计第一单 |
| 完成订单数 | 完成时间在当天 + 状态为完成 |
| 应答数 | 应答时间在当天，改派仅计第一单 |
| 应答时长 | 司机接单时间 − 订单发单时间 |
| 接驾时长 | 司机到达起始点时间 − 司机接单时间 |
| 应答距离 | 司机接单位置与乘客起始点的路面距离 |
| 播单距离 | 播单时司机与乘客起始点路面距离 |
| 应答后乘客取消 | 含：改派后抢单前取消 / 无改派应答后取消 / 有改派抢单后取消 |
| 应答后司机取消 | 含：不改派取消 / 改派后无响应 / 旧版改派失败 |
| 未播订单数 | (发单量 − 播出量) / 发单量 |
| 长单 | 起终点路面距离较长（>10km，无统一阈值） |
