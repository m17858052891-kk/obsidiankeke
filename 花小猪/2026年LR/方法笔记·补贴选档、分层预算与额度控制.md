# 补贴选档、分层预算与额度控制

做升舱或换车激励时，要分别回答三个问题：谁会因多给一档而改变选择，多给这一档要多花多少，总预算用完时从哪里撤回资源。对等应答页表单也可做类似拆解，把是否展示、展示哪种表单当作动作，另行定义打扰成本。下列研究实测的是套餐、券和司机倾斜，迁移到交易专项时需要重新测量动作响应。

## 从用户分层开始，检验该加补还是撤补

### 006｜套餐 SKU 的分层实验

**为什么先看分层。** 上一期套餐购买在呼单用户中的渗透从 0.96% 升至 1.20%，但总体访问、冒泡、呼叫、完单均无显著变化，连 75 折对 95 折的呼叫差异也不显著。研究先用倾向得分匹配（PSM）比较相似购买和未购买用户，结合生命周期、过去 28 天行业冒泡量及小猪份额寻找高钱效人群。匹配只控制已观测差异，人群收益再用随机实验检验。

**实际如何分配。** 行业冒泡 ≥15 且小猪占比 <30% 的 level 0 放宽至 75～95 折。其余行业冒泡 ≥10 且小猪占比 <50% 的 level 1 沿用原算法。非竞争人群按生命周期拆成 level 2、3，统一给 95 折。2026 年 3 月 13～19 日全国按乘客 ID 分流，分层算法、原算法、人工、空白各 2.5%。

**读实验时先看分母。** 分层组相对原算法，套餐 C 补率显著降 0.09pp，人均呼叫 +0.02（+0.55%，不显著），增量呼叫 ROI 0.31。相对空白，人均呼叫 +0.30%（不显著），呼叫 ROI 0.55；曝光后购买率显著 +1.07pp，呼单用户购买套餐的渗透仅 +0.03pp。Level 0 人均呼叫 +2.72%（不显著），总 C 补率 +0.66pp；level 2、3 套餐补率显著 −0.14、−0.05pp，呼叫分别 +0.60%、+0.56%，均不显著。撤补节省预算有实验证据，加补能否带动总体呼叫仍有不确定性。4 月 21 日分层策略放至 90%，人工和空白各留 5%。[LR26-006 原文](https://cooper.didichuxing.com/knowledge/2199610335356/2207399170533)

### 011｜让价敏标签回答「下一档值不值」

基于 TOP41 城市范围（除北京、广州）的联合决策随机价格实验，用 XGB 选出 50 个特征，以 DR-CFR 预测同一用户从原价到 73 折的十档呼叫转化率（ECR）。比较四种量：相对原价的呼叫绝对增量、相对增幅、增量呼叫除以增量花费的平均 ROI、继续加深一档的边际 ROI。历史 ECR 很低会放大相对增幅，平均 ROI 高也不能说明继续加补划算。折扣内做百分位排名，再跨折扣聚合成用户标签，可以同时查人和档。

对单人折扣—成本曲线，原凸包方法会跳过非凸档，边际 ROI 空值率 **48.83%**。ECR 未增长时置零；对非凸点分别试过线性插值、PAV 保序回归、衰减曲线和相邻档原值。四法均消除空值，但单调违规率依次为 6.23%、0、0、39.27%；PAV 与原可算值相关性 0.9821，排名偏移 3.5%，适合需要有序排序的投放。保序是后处理，对特定档位是否真有因果增益仍要用随机数据核验。

营销实测按 91 折呼叫 ROI 分层，关闭低弹弹窗，把一键领券和普通弹窗机会转给高弹人群。低弹范围较宽的组 1、较窄的组 2 和对照的呼叫 ROI 分别为 **0.3224、0.3168、0.2961**（较对照 +8.88%、+6.99%）。活动未设随机空白组，钱效基准通过同生命周期、活动前访冒呼完和 GMV/C 补匹配未参与者构造，保留了用户选择偏差的不确定性。[LR26-011 原文](https://cooper.didichuxing.com/knowledge/2199610335356/2207983255568)

## 从档位响应到在线选择

### 009｜两张券如何估算对当天呼叫次数的牵引

一键领券组件用五种首券/次券膨胀前折扣组合作为动作，由 98/95 到 80/75。当天最多计两次受牵引呼叫，呼叫超过两次的曝光占训练样本不足 10%。多次曝光时，领券之前未领取的曝光标签置零。这使估计量依赖组件归因规则，不能直接解释为全天所有呼叫的因果增量。

用 `P(至少一次呼叫) + P(至少两次呼叫)` 表示截断后的期望次数。V0.5 以条件概率输出第二次呼叫，遮罩导致深层头样本少。V1 把条件概率连乘写入模型结构，对边际事件用全量事实样本训练 BCE，再加分布平衡损失。上线按客单价、CR、有券/无券的一次与多次呼叫概率分桶，在补贴约束内用整数规划最大化呼叫数。

4 月 7～20 日按乘客分流。拉齐 C 补率后，算法相对人工旧策略（不膨胀）和人工新策略（膨胀），人均呼叫分别显著 +0.30% 和 +0.20%。对空白组，算法的呼叫、完单、GMV 分别显著 +2.29%、+2.36%、+2.80%，GMV ROI 2.50，呼叫 ROI 0.17；人工旧/新策略 GMV ROI 2.07/2.28。无领券组 GMV ROI 8.70，但呼叫只 +0.53%，说明资源规模不同会改变 ROI 的读法。5 月 6 日放至 100%，后续 RCT 待修复分流及后端访问问题。[LR26-009 原文](https://cooper.didichuxing.com/knowledge/2199610335356/2207596402237)

### 047｜流失召回的多档弹性模型与求解器

券面额收窄到 0、2～6 元。此前只用新一期随机数据重训未见收益，原模型在新数据上的 MTAUCC 一度低于随机。新版将用户、空间、时间、长短期需求和城市统计分别编码，做域间注意力交互，用 Set Transformer 自适应聚合，加入单调性及批内转化率、边际 ROI 与 RCT 曲线的一致性约束。离线消融依次记录 MTAUCC **0.07549 → 0.08842 → 0.09656 → 0.10515 → 0.10913**，分别对应结构、域融合、决策函数和 POI 表征。部分实验随机基线由 0.03962 变为 0.04086，跨批次改善要区分数据差异；生产实验验证整套方案，各模块线上增益不能拆领。

两种求解器复用同一组预测。分桶按无券访问完单率与各档弹性聚类分组；个体贪心删除非凸档，按边际 ROI 排序，在预算内逐级升档。约束为**完单 CAC = 核销金额 / 完单用户数**。在约 1.6 元完单 CAC 下，贪心组 46,644/143,188 人完单（32.58%，实际 CAC 1.605），分桶组 46,080/142,256（32.39%，1.586），人工组 208,917/649,465（32.17%，1.620）。贪心比人工高 0.41pp；这三组并未精确等成本，也没有给出贪心与分桶之差的显著性结论。LR 通过贪心方案，要求预算腾挪后在新 CAC 下再跑一周，显著正向方推全。未开定位的兜底人群需单独检验。[LR26-047 原文](https://cooper.didichuxing.com/knowledge/2199610335356/2209896035194)

## 在城市和司机之间分配有限额度

### 042｜先测城市边际成本，再做同成本策略实验

新客首单先在核销 CAC 5.6 的主流量外用小流量探测 4、5、6、6.5 元，观察多花一元换来多少新增首单，并关注 7/28 天呼叫价值。依据探测结果配置四类城市的核销 CAC：核心 5.6、行业增长大 6、行业增长小 5、战略收缩 5。只有「行业增长大」框在所列四个水位呈边际效用递减，其他框曲线存在波动，负边际 CAC 不能直接解释为稳定的免费增量。

第二阶段选实际全国核销 CAC 接近的两组比较（5.65 对 5.64）。分框差异化方案访问完单率由 38.95% 至 39.56%（**+0.61pp**），增量 GMV/增量成本由 2.66 至 2.91（+9.4%）。增长小、战略收缩框降补后转化基本持平，腾挪后核心和增长大框的转化上升。其他水位的组用于观察趋势，无法作同成本对照；正文未报此差异的显著性。评审通过，排期取决于新客与流失预算腾挪实验。[LR26-042 原文](https://cooper.didichuxing.com/knowledge/2199610335356/2209794347993)

### 035｜把司机倾斜的效率成本换算成订单额度

该例分配的是分单、PK 中的排序优先权。按城市×等级调高司机基础分或好单加分，目标为不含补小时收入 IPH（收入/在线时长）满足 L6>L5>L4>L3，高等级好单占比比 L2～L4 高 2pp。好单占比按合计好单完单/合计完单计算。目标控制器采用比例误差和有界积分，限制参数上下界、单次步长并保持等级顺序，样本太少或分母异常时暂停更新。

以近七天**因倾斜胜出的完单 / 同范围全部完单**作为全国额度，cap 为 3.5%。未超限时追踪 IPH 和好单目标，超限时冻结两个控制器，把超额换算成待释放订单数。先低等级，再按配置的城市框顺序、框内城市优先分逐项回收；任何候选会击穿框底线就跳过。先把所有保护底线换算为订单数，检查加总是否超过全国可用额度，并记录预计和实际释放误差。

全国随机分流中倾斜相对不倾斜，完单显著 **−0.11%**，在 0.3% 容忍范围内。原文观察期额度合计 3,269,523/97,831,555 = 3.34%，个别日超过 3.5%。71 城中广州、大理仍有明显 L6/L5 收入倒挂，L6 倾斜系数已打满，两周去重 L6 司机仅 134、50 人。好单口径正切换，当期未验收好单占比目标。43 城每小时反转的前置实验中 CR +0.09pp、完单 +0.12% 是实验前预估；正式全国分流以 −0.11% 为准。原文记录策略已推全。[LR26-035 原文](https://cooper.didichuxing.com/knowledge/2199610335356/2209493202595)
