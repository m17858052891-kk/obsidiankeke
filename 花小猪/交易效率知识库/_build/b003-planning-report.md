# B003 规划与历史资料提炼报告

本批实际通读 5 篇：2 篇 LR/实验材料、3 篇 2025 规划与复盘材料。新增 4 篇来源摘要、2 篇实验复盘、4 篇概念/诊断页。个人评价、人力和绩效内容未纳入 Wiki。

## 关键演进

- 升舱 V2 修正补贴概率推导，并通过同版本“无新增场景”组拆分场景增量；换车场景在该实验中负向，司机取消改派场景被选为放量方案。
- API 多轮举手通过三组设计隔离“多轮举手”和“半指派胜出条件”；阳光出行收益不能直接外推到所有 API 商家。
- 差体验分析从平均接驾指标扩展到高低供需、城市、运力、连环派、含改派和 bad-case 占比分层。
- 召回层高诱导过滤在来源中仍是规划，缺少上线与实验收益证据。

## 重要边界

- 升舱文档写有 2025 年放量记录，API 文档写有 2026.6 状态；均按历史记载处理，不声称当前在线。
- 关键图片和外链表格没有在本批解析；只使用正文显式数据。
- 计划目标、相关性分析和线上实验结果分开标记。
