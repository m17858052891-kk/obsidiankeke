# B070 项目源流：2025 H2 交易效率机会池

> 这是 2025 H2 的机会梳理与收益预估，不是 2026 排期、实验结论或当前线上状态。它仅用于说明后续项目候选从何而来。

## 候选机会

材料把提升小猪端 CR 的机会拆为八组：网出 Hold 放开、差供需丢单、预分单商家接入与策略改造、升舱预算、API 接换车、API 二次举手、API 接入平台规范、双呼端外删单，以及差履约司机倾斜过滤。另列出交易自由度、司机感知、愿等体系、表单运力差异、PK 模型/动态窗口、司机交易、兼职与特殊场景等探索项。

## 材料中的历史状态与测算

- 网出 Hold：材料称仍有约 `27.7%` 完单占比城市未放开，并估算全国 CR 约 `+0.1pp`；这是当时快照与预估，缺统计日期和实验结果。
- 预分单接入：列出部分已接与未接商家，并估算新增约 5k 单、CR `+0.1pp`；外部开发依赖仍未闭环。
- 预分单改造：估算新增约 8k 单、CR `+0.17pp`，但没有实验设计和结果。
- 升舱：以投入约 `0.3pp`、CR `+0.5pp` 描述钱效，材料同时标记“当前无预算”；不应视为获批预算或真实增益。
- API 接换车、二次举手和平台规范：材料将其列为推进项，并对换车和平台规范给出预估，未提供实现、分流、显著性或放量回执。
- 差供需置换比、差履约司机过滤和端外删单只保留方向性描述，证据不足以给出结论。

## 进入 2026 项目池的门槛

1. 逐项补齐现网版本、覆盖城市/商家、依赖方和发布回执。
2. 将收益预估与真实 AB/LR 结果分开，统一 CR、完单、取消、司机效率和预算口径。
3. 对 API 改造明确协议、失败重试、PK 后状态机、兼容范围和回滚方案。
4. 对 Hold、预分单、升舱和折叠的交互做联合实验，避免单项目收益重复计算。

## 覆盖缺口

- 差供需实验评估只以外链出现，本批未解析。
- 收益估算缺样本窗口、基线、计算过程、统计显著性和成本核算。
- 商家接入、预算审批、API 开发、实验与放量状态都缺独立回执。
