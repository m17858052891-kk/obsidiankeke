# B038 项目源流：DD both 举手调权开城

> 2022 年开城讨论与收益诊断的历史卡，不代表 2026 已立项、当前城市覆盖、现网调权配置或线上收益。

## 历史问题

DD 与其他商家同时举手时，开城收益曾按全国口径估算；但模型 PK 城市的第一轮 DD 出价缺少司机 ID，HNA 阶段只能得到偏低或不完整的模型分。完整信息要到 DD 已经胜出、进入 HNE 后才可获得，因此该分数无法直接参与首次竞价决策。

这意味着先前收益估算混入了距离 PK 城市：这些城市的 DD both 举手胜率更高，不能直接代表模型 PK 城市的可增益空间。

## 开城口径与历史样本

- 当时存在两个候选集合：128 个“模型对距离 PK”实验城市，以及 150 个“乘客司机全量模型”城市；讨论最终选择后者作为开城集合。
- 模型 PK 城市在 2022-09-02—09-08 的样本记录为：有效出价 291,648，both 出价 146,248，both 胜出 47,819。
- 同一窗口的有效出价平均分约 0.05，both 平均分约 0.04，both 胜率约 32.7%。材料据此判断，模型 PK 城市的收益可能低于先前全国估算。

以上数字是历史诊断样本，不是预算、上线回执或稳定收益。

| 层级 | 已有证据 | 不能推出的结论 |

## 历史实验与渠道差异

### 小猪端 DD both 举手调权（2023）

一份历史材料记录了 2023-02-18—02-24 与 2023-03-03—03-09 的两轮可用实验，以及此前两轮因预估或倾斜逻辑未生效而失效的尝试。第二轮可用实验按网约车乘客 ID 尾号分流，但小猪数仓乘客 ID 与网约车订单 ID 不一致，且与小猪端流量分发实验交叉，最终只能从“举手是否被倾斜”反推分组；因此人均发单、完单和成交率不能直接计算，正文中的大盘影响是沿滴滴勾选率、举手率与 both 举手率折算，不是完整随机实验估计。

第三轮以 10% 随机流量覆盖 39 个城市，来源记录 DD both 举手胜率由 79.10% 降至 18.89%，自营与三方胜率上升，但 both 举手完单率由 85.56% 降至 77.04%；折算端成交率约 -0.26pp。第二轮的倾斜组则记录 DD both 举手胜率从 90.58% 降至 55.51%，折算端成交率约 -0.12pp。两轮均显示三方承接强于自营，材料进一步排查认为“自营与 DD 两方举手”链路中的倾斜未生效。这里的点值是 2023 历史来源自报，缺少 SRM、置信区间与完整正交分流，不能当成当前稳定收益。

### PBD 百度渠道与寒潮临时配置

PBD 百度渠道材料记录 2023-03-25—04-07 与 04-14—04-27 两期时间片实验，分别覆盖 18 城与 12 城。来源称百度渠道成交率显著约 -0.39pp、-0.30pp，自营完单约 +3.40%、+2.75%，宏鹄和 API 完单亦上升；随后列出 04-17、04-18、04-20 分批扩至 30%、50%、100% 的历史计划。材料未附可解析 DS 报告、样本量、显著性检验细节或发布回执，因此“显著”保留为来源表述，放量日期不证明当前配置仍有效。

另一份 2022 年 11 月寒潮记录按预警等级选择城市，临时调整展示分组、Hold 路由与 UFS V2 策略，并写有 0.3 的应答率阈值。这是天气应急配置快照，不是通用调权算法版本；城市、实验链接与策略开关均未提供当前状态。

### 方案与离线测算边界

历史方案以最大 CR 折损约束反推可接受履约率，再从非 DD 获胜方模型分段寻找对应分数区间，最后用 DD 平均分与区间下界的差作为城市级负向调权值。该推导说明“城市供需与履约差异决定调权强度”的设计逻辑，但示例表存在缺值，且离线测算依赖履约稳定、分数可比和举手结构不变等假设，不能替代在线实验。

PBD 材料还给出“完全负向倾斜”的上界测算：按 2023-02-28—03-06 一周样本，估算大盘 CR 最大折损 1.38pp、自营与三方完单相对增益上界 15.25%。这只是极端情景推算；实际两期实验点值、渠道结构和履约变化不能与该上界拼接为同一因果结论。

## 进入 2026 候选池的门槛

1. 先确认 HNA/HNE 链路是否仍存在首轮缺失司机 ID 的约束，并梳理模型分真正可参与决策的时点。
2. 补齐 150 城清单、城市分层、调权公式、保护阈值和回滚条件；历史城市集合不可直接复用。
3. 在模型 PK 城市单独设计随机对照，评估增量完单、both 胜率、履约、接驾距离、商家结构和乘客体验。
4. 将“开城”拆成候选、配置、上线、稳定观察四个可审计状态，避免用讨论稿代替生产事实。

## 覆盖缺口

- [ ] 城市清单、配置、审批与发布附件未固化。
- [ ] 调权算法、模型版本、分数校准和首轮信息字段缺少完整定义。
- [ ] 未提供 AB 分流、显著性、预算、增量完单和长期履约结果。
- [ ] 缺少 2026 当前链路、现网城市与开关状态证据。
- [ ] 小猪端乘客 ID 映射与流量实验交叉导致分组不正交，折算公式尚缺独立复核。
- [ ] PBD 两期实验的 DS 报告与图片未解析，显著性、样本量和当前放量状态待补。
- [ ] 寒潮城市分组、UFS V2 配置及 0.3 阈值仅为历史应急快照，不能直接复用。
