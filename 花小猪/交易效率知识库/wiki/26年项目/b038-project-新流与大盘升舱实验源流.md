# B038 项目源流：新流与大盘升舱实验

> 本页把历史实验方案、预算测算、效果评估与放量记录分层保存，供 2026 项目筛选复用。材料中的“推全”、收益和参数均有时间边界，不代表当前线上配置。

## 项目源流

| 阶段 | 当时目标与做法 | 可确认边界 |
|---|---|---|
| 新流升舱 2.0 | 2025-09-18—09-24 评估扩量和策略迭代 | 只确认有评估窗口；正文未提供可独立复核的完整实验配置与结果表 |
| 新流升舱 3.0 | 2025-10-25—10-31 扩量、策略及场景，并比较多组参数 | 评估稿认为第 3 组最优，但仍是历史实验结论 |
| 大盘升舱方案 | 全国候选人群在等应答页按 PID 分流，排除摆动、新流等冲突人群；60% 空白、20% 老策略、20% 新策略，计划运行 14 天 | 是实验合同，不是结果；旧策略/模型 `lambda=0.13`，新策略/模型 `lambda=0.4` 被描述为等价旧策略 `0.13` |
| 大盘升舱预算 | 两个实验组各按大盘 GMV 的 0.3pp 预估，约 3.15 万元/日/组，总计约 6.3 万元/日 | 是按历史 GMV 与触发结构做的预算测算，不是实际消耗或当前额度 |
| 冲突治理 | 大盘与新流人群正交，并排除摆动实验线下圈定人群；材料以“226 分流”概括老升舱、新升舱、空白 | 协调稿只说明排期与隔离原则，缺少最终实验平台配置回执 |

## 历史评估与放量记录

新流 3.0 评估稿给出的历史结论如下，均应保留为“报告声称”，不得视为当前生产事实：

- 第 3 组新流人均完单约 `+0.85pp`，报告据此估算全量后日均增加约 1,637 个完单乘客；相对空白 CAC 为 11.75，相对对照增量 CAC 为 8.65。
- 大盘完单被报告为显著提升，应答率和转化率约各提升 1pp；但第 2 组应答后乘客取消约 `+0.4pp`，需要在后续方案里作为护栏。
- API 贡献占比超过 90%；自营与宏鹄完单下降约 1%—2%，第 3 组下降未达显著。收益不能无条件外推到各商家。
- 触发覆盖率从约 15% 提升到 22%，升舱转化率从约 11.3% 提升到 19%。
- 评估稿记录 2025-11-11 出报告、11-14 决策、11-17 配预算，并采用 10% 空白、10% 第 1 组、80% 第 2 组的新分流；同时记录 `lambda=0.16`（描述为等价旧策略 `0.08`）。
- 放量后表格记录第 1/2 组转化率约 `+1.4pp/+1.3pp`、完单约 `+0.84%/+0.98%`。该表缺少独立实验平台回执和当前版本校验。

## 进入 2026 候选池的门槛

1. 补齐当前线上版本、实验 ID、分流截图、参数配置与实际预算消耗，核对历史 `lambda` 的定义和等价换算。
2. 将方案收益拆为 API、自营、宏鹄及其他商家，验证总量提升是否伴随渠道挤出。
3. 统一新流、大盘、摆动等实验的人群互斥规则，并保存可审计的 PID 分桶与开关配置。
4. 用完单、应答、转化、应答后取消、补贴与商家结构作为联合门槛；只有评估结论不足以证明可持续推全。

## 覆盖缺口

- [ ] 多处实验流程、指标拆解和配置以未解析图片呈现。
- [ ] 数易看板及其他外链未固化，无法独立复算显著性、样本量和收益。
- [ ] 缺少 Apollo/人工配置回执、实际预算账单和完整实验 ID。
- [ ] “推全”后的持续观察期、回滚条件、当前线上状态和版本迁移均待补。
