# B023 项目证据：2026 专项配置与实验

> 本页汇总四份 2026 时点材料。配置、实验设计和历史执行记录分别陈述；没有正式评估或生产回执时，不推断当前线上状态。

## 专项证据

| 专项 | 文档记录 | 证据性质 | 当前边界 |
|---|---|---|---|
| 新增供需特征 | 订单中心格子、5 分钟窗口，按小猪端流量和自营/宏鹄/API 商家分别统计发单数与应答数 | 特征清单 | 没有训练接入、线上服务、消融或收益记录 |
| 联盟端流量调整 | 设计全国乘客分流：对照 95%，实验 5%；实验组对 API 共同 PK 施加负向倾斜，仅 API 举手时不倾斜；计划周期 2026-07-22 至 07-30 | 在线实验方案 | 没有样本量、实际启动、显著性、结果或扩量决策 |
| PK 模型自动更新 | 记录每周二自动训练部署、工程回调替换实验模型、每周一按上周结果人工决策；实验计划为 2026-01-13 至 02-02、全国 90:10 乘客分流 | 运维与实验配置 | 配置不等于成功运行；缺逐周版本、失败记录、评估结果和推全命令回执 |
| 指定商家完单控制 | 沈阳、福州评估 5/10/15 秒 Hold 与随机丢单；材料记录沈阳执行 `hold10s` | 策略测算与一次执行记录 | 端内历史分布不是因果折损；缺正式实验、护栏、恢复策略和后续状态 |
| 新司机系统倾斜评估 | `order_id` 随机分桶，全国除北京，2026-08-07 开始，分流点位于召回；申请评估 SQL 和正式报告 | 实验评估需求 | 未提供实际样本、结果或上线决策；API 单独举手订单不入桶，需单独换算 |

## 方案、数据与线上事实分层

- 联盟端倾斜是实验设计，不是正向收益结论；完单、CR、应答率、取消率和商家份额只是预设评估指标。
- PK 自动化页面证明流程与分流配置被设计，不证明三个更新节点均成功，也不证明自动更新优于固定版本。
- 沈阳/福州表格是 2026-06-04 至 06-10 的描述性应答时长分布。正文只明确沈阳执行了 `hold10s`，没有给执行后的完单损失或对照结果。
- 新增供需特征只定义了六组计数特征；特征有效性、延迟、缺失率和使用模型均待确认。
- 新司机倾斜材料是“请求评估”的口径说明，不是评估报告。计划按商家、自营、宏鹄、API 和整体拆分完单、成交率、接驾距离、应答与应答前后取消；评估方还需补 `order_id` 分桶下乘客/司机取消（含/不含改派）、预估与实际接驾时空指标，并为 PID 口径补实际接驾时长和乘客 ETP。API-only 举手订单不进入分桶，API/大盘指标需用“被呼叫订单减去入桶订单”换算，不能与 PID 分桶指标直接混算。
