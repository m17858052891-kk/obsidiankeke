# B018 项目证据：2026-04 中旬交易效率周报

> 本页合并 2026-04-10 与 2026-04-17 两个周报时点，只描述当时计划和进展。周报中的 `done`、部署、预计日期和点估计不自动升级为当前生产状态、最终实验结论或验收完成。

## 方案、离线和线上事实分层

### 方案与计划

- PK v3 拟用 DO 价值模型适配 PK，区分连环派与半指派，设计 POSO/Experts；这是研发方案，不是模型效果。
- 平台规范目标覆盖流量分发、分单、PK 与乘客透传四阶段；4 月中旬只到约束推导和建模。
- 匹配 v0 以“唯一连边城市先全 TP”为简化试验假设，仍需策略评审和实验验证。
- 接驾远换车 V2.3 的 5—6 月两阶段实验、端流量分发 4 月 28 日评审均为排期。

### 离线结果和风险

- 端流量分发的 LogMSE 方案在当时评估中更差，长尾大值被压缩是原文给出的解释；需要新损失函数和时间窗口复验。
- PEPNet 加序列特征与更小 batch size 同时变化，无法只把 AUC 变化归因于序列特征；相同数据下验证 AUC 高于训练 AUC 的现象尚待排查。
- 匹配离线模拟受轮次稀疏、同秒时间戳无法排序影响，模拟结果不能直接等同线上匹配收益。

### 历史线上实验事实

- PK v2 的 4 月短期实验提供分组点估计，但周报未给完整样本量、置信区间与长期护栏。
- API 两项实验只有启动记录，不能提前写成正向结果。
- 分单 V2.1 的链路变化和方向性结论需回链专项评估；三期商家竞争效率也尚无本批结果。
