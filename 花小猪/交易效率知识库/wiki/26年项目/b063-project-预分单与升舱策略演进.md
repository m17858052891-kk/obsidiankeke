# B063 项目源流：预分单触发、C 补与升舱决策

> 本页将历史流程、策略迭代、放量记录、WIP 建模和效果评估分层保存，供 2026 项目筛选复用。文档中的“全量”、阈值、效果和“当前”均只对原材料时点负责，不代表 2026 现网状态。

## 业务链路与策略入口

预分单解决的是：乘客已勾选品牌暂未找到运力时，系统额外呼叫未勾选车型；若额外运力举手，再由乘客接受或通过升舱直接承接。历史材料把可优化空间拆为可预分单车型、触发率与准确率、乘客接受度三部分。

流程梳理稿还记录了两套历史品类透出优先级：鸿鹄按特快盒子、实时计价品类、出行优选盒子、实时计价盒子、特价盒子、哈啰端特价盒子、幸运盒子排序；自营先按品类层级，再在同优先级比较价格，价格相同才使用绝对优先级。这些是材料中的规则文本，缺少生效版本、配置回执和当前覆盖证明。

## 预分单策略迭代

| 阶段 | 当时方案 | 材料中的结果与边界 |
|---|---|---|
| V1 | 所有场景等待超过 60 秒后，向自营或鸿鹄预分单，每次呼叫两个品牌 | 评估稿声称相对空白 CR `+0.21pp`；原始评估在外链，无法在本批独立复算 |
| V2 | 按 1/3 分钟、5/8/10 分钟、无车及非自营场景采用 60 秒或 30 秒触发；分别呼叫最低价两个车型或全部车型 | 相对 V1 无正向；材料指出全车型组接受度显著下降，但未给出完整归因 |
| V3 | 在触发策略上增加接受度模型过滤车型 | 多次实验对大盘 CR 均无显著正向；V3—V4 期间 API 接入没有 AB，材料仅以接入前后 AA 对比记载约 `+0.15pp`，不能归因为接入收益 |
| V4 | 从固定等待时长转为格子实时供需判断，接受度模型过滤车型数改为可配置 N 个 | 一期无显著正向；二期调参后材料声称大盘 CR `+0.14pp`，四组阈值中两组正向、两组不显著负向 |

V4 的历史触发合同以中心格及周围一圈近 5 分钟发单数、应答率为输入：差供需时按应答率阈值 A/B 选择等待 `T1/T2`，其他场景等待 `T3`；这些阈值和时间均是灰度参数。接受度模型材料记录离线 AUC `0.89`、线上 AUC `0.56`、线上阈值 `0.2`，显示离线到线上存在明显落差，不能把离线区分度当作线上能力。

## 历史放量记录

二期提效稿称实验大盘 CR 显著 `+0.14pp`，其中自营 `-0.03pp`、鸿鹄 `+0.12pp`，并称实验前 14 天四个实验组的小猪端 CR AA 均不显著。材料随后记录 12 月 18/20/22 日全国 PID 灰度 30%/70%/100%。这只能证明文档曾记录该放量节奏；缺少年份、实验 ID、配置截图、回滚条件和持续观察，不足以证明实际执行或当前仍全量。

## C 补与升舱联合决策 WIP

联合决策草案保持预分单触发不变，在每次轮询选出的两个车型上统一比较四种动作：升舱、给乘客补贴、不补贴预分单、不预分单。草案以以下量为核心：

- `P(W)`：原勾选品牌应答或完单概率；
- `P(A)`：找到预分单运力且被应答/完单的概率，草案在线上判断点近似为 1；
- `P(B|A,c)`：找到额外运力后，在补贴 `c` 下乘客接受概率。

方案分别计算升舱和不同 C 补档位的完单增量、期望花费与 ROI，再按城市参数 `lambda` 做在线贪心：选择超过阈值的最深补贴，满补贴时转升舱；若都不满足，再用无补贴接受度判断预分单或放弃。所需模型至少包括原勾选品牌应答概率、不同补贴下接受度；草案还提出接受度对价格、距离应具备单调性。

这是数学建模与 WIP 方案，不是已实现的线上决策。公式把 `P(A)`近似为 1、以应答/完单混合口径描述目标，且没有模型校准、预算约束、实验配置和发布证据，进入 2026 候选前必须重新定义并验证。

## 历史升舱评估

2024-11-12—11-18、27 个城市的评估稿给出以下自报结果：

- 策略组补贴率约 `0.26pp`，完单 `+1.03%`、GMV `+1.34%`、ROI `4.53`；触发面 `10.7%`。
- 随机组补贴率约 `0.23pp`，完单 `+0.46%`、GMV `+0.69%`、ROI `3.05`；触发面 `7.1%`。
- 策略组与随机组的 API 升舱完单份额分别约 `83%`、`89%`，升舱订单应答后乘客取消率分别约 `28.1%`、`28.7%`。
- 评估稿明确指出当时升舱策略导致自营折损，并提出简化乘客授权表达、支持同品牌跨品类升舱、优化取消漏斗和做人群差异化倾斜。

这些数字来自历史评估正文及汇总表，尚未通过附件明细复算，也没有显著性、实验分流、实际预算账单或后续持续性证明。策略组优于随机组可作为候选证据，但不能直接外推为当前收益。

## B072：新流升舱扩场景与触发时点

2025 年方案稿把新流升舱从原有链路扩展到应答前乘客取消、应答后换车、应答后司机取消，并提出补充 API 与自营运力覆盖。方案以城市预算约束下的收益/价差比做选择，拉格朗日化后形成 `(1-P(A|c))/price_diff > lambda` 的候选阈值；文中“约 2300 单”的收益是测算值，不是实验结果或线上收益。

同一方案记录了预分单接受度 XGB 的一次离线评估：训练集为 2025 年 6—7 月、测试集为 8 月 1—7 日，整体 AUC `0.737`、新流 AUC `0.717`，旧模型分别为 `0.692`、`0.663`。这些仅是离线模型证据；标签定义、校准、线上表现、预算消耗与发布回执均未闭环。文中的四组各 25% 分流也是实验设计，没有实验结果。

另一份时点分析给出描述性分布：即时举手约 `0.03%`，5 秒内约 `8.8%`、10 秒内约 `10%`，举手主要集中在 31—40 秒（`32.93%`）；乘客响应与接受响应均主要集中在 41—50 秒（分别约 `36.91%`、`39.35%`）。材料还称触发在 3 秒和 39 秒附近出现峰值、0—50 秒接受度整体较平、5—10 秒相对较高、50 秒附近下降。由于缺少统计日期、样本量、分母、置信区间和控制变量，这些只能用于提出触发时点假设，不能作为因果结论或直接配置依据。

## 模型与产品待验证项

1. 升舱改变了预分单接受数据分布，历史材料要求对接受度模型去偏；线上 AUC 明显低于离线，更需要按时点重训和校准。
2. 品牌 AR 模型未考虑乘客应答前取消和不同计价模式；材料建议目标向 CR 靠拢，但没有新模型结果。
3. 需要把 API 增益、自营折损、乘客取消和长期价值联合纳入护栏，避免只看总量完单与 ROI。
4. 需要统一品类透出、同品牌跨品类升舱、乘客授权与拒绝后的交易漏斗，并保存产品版本和配置证据。
