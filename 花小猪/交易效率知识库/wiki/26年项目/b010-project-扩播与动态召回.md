# B010 项目来源：扩播与动态召回

> 历史策略设计，不代表 2026 配置或服务状态。动态召回材料有 3 张未解析图片，旧/新逻辑图及示例覆盖不完整。

## 扩播触发实验能力

扩播距离取乘客侧扩大距离与司机听单距离的较小值。历史现状按接驾距离在 30 秒或 60 秒后扩播，而 API 商家可从 0 秒开始。需求提出支持 0 秒扩至 5 公里等多组参数，并兼容订单、乘客和时间片分流；材料没有实验结果。

## 动态召回 V1.0

- 将格子供需历史特征从小时粒度细化到 10 分钟，并与 5 分钟实时供需各以 0.5 权重计算需供比。
- 特征缺失或为零时，空车召回半径回退 3 公里；连环派读取灰度配置。
- 候选方案分别讨论把小于 3 公里的 BaseRadius 同时用于空车和连环派，以及增加 R2 区分空车与载人车半径。
- 支持 Apollo 时间片实验，覆盖自营缩/扩半径与宏鹄缩半径；正文给出 2023 年开发测试排期，但无实验结果。
