# 交易链路

> 基于 2026-07-12 复核的部门资料提炼，当前有效性待 owner 复核；不代表已核实的线上状态。

小猪端的撮合链路为：呼叫 → 商家召回 → 商家内部匹配 → 举手 → 平台 PK → 播单/应答 → 接驾 → 开始计费 → 完单。

商家决定在自身运力池中提交哪个司机，平台在跨商家候选中选择最终胜者。应答后取消可能进入改派、换车等回流链路。

外部平台/DD 入口的最终 PK 权可能属于外部平台，相同“举手”不保证有相同司机感知与归因。
