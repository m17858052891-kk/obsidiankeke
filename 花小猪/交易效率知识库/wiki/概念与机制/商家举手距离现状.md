# 商家举手距离现状

## 口径与现状

材料统计 2025-05-03 至 06-08、呼单后 0—5 秒内的举手。订单总体以 1—2 次举手为主；在 only 举手样本中，宏鹄占约 54.97%、自营约 33.08%、API 约 11.95%。以 3500 米为远距离阈值，商家内远距离 only 举手比例约为宏鹄 15.97%、自营 9.85%、API 2.86%。

## 策略含义

only 举手决定了“等待更多运力”和“立即结束 PK”的收益上限；远距离 only 举手较高时，过早胜出可能放大接驾与取消风险。来源观察到实验中宏鹄份额下降，并提出继续验证宏鹄 only 举手及远距离结构是否变化，但没有给出完整实验归因。

## 证据边界

这是描述性统计，未控制城市、供需和连环派结构差异。3500 米来自 V0 实验城市 0—5 秒约束的最大距离，并非普适最优阈值；长 SQL 未执行。
