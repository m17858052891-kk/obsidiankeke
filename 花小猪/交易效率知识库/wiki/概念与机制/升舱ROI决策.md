# 升舱 ROI 决策

## 问题

在预算约束下，选择哪些订单增加更高价运力，使增量完单最大。关键输入包括预分单接受度、升舱前后整体完单概率及价格差。

## V2 修正

V1 把补贴概率写成升舱后的整体完单概率；V2 改为升舱车型带来的增量完单概率：

```text
ΔP = P(up) - P(base)
```

因为只有由新增升舱车型促成的完单才产生这部分补贴。修正后，目标中的 `ΔP` 与预算约束中的 `ΔP` 可以约掉，固定 `λ` 时决策近似为：

```text
(1 - 预分单接受度) / 价格差 > λ
```

## 历史离线求解合同

另一份 2024 年历史材料把订单级决策写成 0/1 变量：输入包含无补贴预分单接受度、原始完单率、升舱后完单率/价格、原勾选最高价、补贴率与历史大盘 GMV；固定 `λ` 时逐单比较不升舱与升舱两种目标值，再用三分搜索寻找预算约束下的 `λ`。来源给出补贴率从 `0.01%` 到 `0.50%` 的离线 `λ` 表，并记录一次回放测算 ROI 约 `7.12`（若仅计入付费升舱订单，约 `4.48`）。

这些数值来自历史 SQL 回放而非随机实验；变量公式主要存在于未解析图片，正文中“预分单接受度”还出现重复定义。不能把该表直接当成当前生产参数，也不能与 V2 修正后的 `λ` 横向比较。

## 解释

- 接受预分单概率越低，升舱的边际价值越大。
- 价格差越高，达到相同边际价值所需的收益更高。
- `λ` 是预算影子价格，来源使用历史回溯确定；不同版本的 λ 不可直接按数值比较，因为公式已发生修正。

## 风险

- 完单概率、接受度和价格差存在估计误差，离线 AUC 提升不保证 ROI 校准准确。
- 新增换车或取消场景会改变样本选择，需要用场景对照实验验证。
- 当前模型、预算和 λ 状态未从新来源确认。
- 历史代码用三分法求凸目标极值，但未提供收敛诊断、参数稳定性和独立复算；SQL、图片公式及附件仍需补齐。
