# 差体验诊断框架演进

2025 Q1-Q2 的分析规划显示，差体验诊断从单一平均接驾指标逐步扩展为分层长尾框架。

## 核心拆分

1. 空间与供需：城市、格子、高低供需。
2. 运力与场景：运力类型、连环派、基础播单半径、扩播半径。
3. 时间链路：应答前等待、应答后接驾、真实接驾时间、ETA/EDA。
4. 结果：乘客取消、司机取消、含改派取消、bad-case 占比。

## 诊断顺序

```text
确认样本与是否含改派
  → 看平均值与bad-case占比
  → 按供需/城市/运力/连环派拆分
  → 对齐策略实验组
  → 分析取消与接驾链路
```

## 注意

- 阈值需要由正式分析页或看板确认，本页不固化计划材料中未给出的值。
- 接驾距离与取消相关不等于因果；策略实验应补充同版本对照和供需分层。
- 计划中的看板和实验平台指标是否已落地，需要后续来源验证。
