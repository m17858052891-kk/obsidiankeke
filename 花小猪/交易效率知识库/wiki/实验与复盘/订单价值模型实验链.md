# 订单价值模型实验链

## 从离线到在线的证据层级

1. **描述性分层**：新版模型的好单/差单差异更大，可用于验证排序方向，但因新旧周期不同不能归因。
2. **离线评估**：两版方案分别记录 AUC 预期提升 11.2pp、7.8pp；这是方案输入，不等于业务收益。
3. **乘客 PID 实验**：计划比较模型版本和阈值对竞争 CR、应答后 BC 取消、司机拒单率的影响。
4. **司机 ID 补充实验**：30% 对照不接模型、70% 实验接模型，用于补充观察宏鹄链路。

## 复盘时必须分开回答

- 模型是否更能区分司机拒单/取消风险：看一致样本、时间外的 AUC 与校准。
- 分单策略是否改善乘客侧交易结果：看 PID 随机实验及竞争 CR、取消等护栏。
- 对司机行为的影响：司机 ID 分流可降低司机跨组污染，但估计对象与 PID 实验不同。
- 阈值和模型版本的贡献：如果同时变化，结果只能归因于组合配置。

## 当前结论

本批来源建立了实验链路和候选指标，但未提供可核验的完整在线结果，状态保持 `proposed`。
