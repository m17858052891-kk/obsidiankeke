# API 多轮举手实验复盘

> `launched` 仅表示来源记录阳光出行已推全；其他 API 商家及当前状态待复核。

## 识别设计

| 组别 | 多轮举手 | 半指派胜出条件 |
| --- | --- | --- |
| 实验组 1 | 开 | 开 |
| 实验组 2 | 关 | 开 |
| 对照组 | 关 | 关 |

- `组1-对照`：两项能力合并效果。
- `组2-对照`：半指派胜出条件效果。
- `组1-组2`：多轮举手的附加效果，是判断该机制价值的关键比较。

## 结果

- 组 1 对对照：人均完单 +0.28%、人均 GMV +0.26%、成交率 +0.10pp，来源标记显著。
- 组 1 对组 2：人均 API 完单 +0.64%、阳光出行完单 +2.93%，来源标记显著；大盘人均完单 +0.12% 不显著。
- 机制指标：阳光出行举手数大幅增加，参与 PK 数约 +2.2%、PK 胜出数约 +3.7%，支持“失败后再次参与带来额外胜出”的链路。

## 解释边界

- 不能将组 1 对对照的全部收益归给多轮举手，因为半指派条件也同时开启。
- 商家收益集中于阳光出行，推广到其他 API 商家需要重新验证供给、举手和竞争结构。
- 正文记录 2026.6 正在引入其他商家，只是历史状态。
