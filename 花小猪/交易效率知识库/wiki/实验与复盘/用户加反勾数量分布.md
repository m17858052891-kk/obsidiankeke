# 用户加反勾数量分布

## 口径

- `select_cnt`：系统初始默勾品牌数。
- `send_cnt`：用户加勾或反勾后最终发送的品牌数。
- `cnt`：给定 `select_cnt` 与 `send_cnt` 组合的订单数。
- `all_cnt`：给定 `select_cnt` 的订单总数。
- `ratio = cnt / all_cnt`：在该初始默勾数下，某个最终发送数的占比。

这些字段描述品牌数量变化，不直接表示具体品牌、价格、应答或完单结果。

## 历史统计摘要

材料对 `1 ≤ select_cnt ≤ 30` 的样本做描述性统计：最终发送数等于初始默勾数、即未加勾也未反勾的订单占比最高，约 60%；反勾后只保留 1、2、3 个品牌的占比分别约 20%、10%、5%；其他最终数量合计约 10%。这些数字是正文中的近似读数，并未提供统计周期、城市范围和样本量。

该分布可为折叠策略的用户行为项提供先验：不应只估计“完全不调整”和“只保留一个”两种状态，高频的保留 2—3 个品牌也需要覆盖。但它不能直接替代动作后的反事实选择概率，因为折叠会同时改变可见品牌、价格排名与品牌心智。

## 使用边界

- 这是观察分布，不是折叠动作的实验响应；不能把约 20%/10%/5%直接当成某个城市或当前线上参数。
- 未按价格、品牌、城市、供需或用户分层，无法区分主动反勾与策略展示变化。
- 3 张分布图未解析，正文中的近似比例未从图表复算；附件未解析。
- 要进入模型或规则，需补充统计时间、去重键、样本分母、平滑/回退规则和线上校准。
