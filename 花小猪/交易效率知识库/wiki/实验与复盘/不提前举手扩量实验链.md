# 不提前举手扩量实验链

## 两类证据

- 阈值/Hold 配置实验显示，延长滴滴 Hold 后除滴滴大盘与自营竞争 CR 的负向缩小，但整体大盘 CR 负向扩大。
- 两批扩量城市汇总中，大盘 GMV 点估计均为负，自营以外的完单和 GMV 负向更明显；城市表现高度异质。

## 决策含义

该策略不能用单一自营竞争指标判定。至少需同时观察自营、除滴滴大盘、整体大盘以及城市样本量，并把选城条件作为实验适用边界。

第一批扩量材料进一步记录：下线提前举手对含滴滴大盘 CR 影响不大，但 GMV 负向，主要来自完单平均里程下降；除滴滴大盘的 CR 与 GMV 降幅更大。短里程订单因置换到取消更低的滴滴运力而完单改善，高里程订单因三方应答后取消较高而完单下降，形成“低里程置换高里程”的结构变化。

## 边界

- 表格未统一提供显著性，点估计不等于稳定因果收益。
- 两批城市和配置不同，不做简单合并平均。
- 历史扩量不代表当前仍在线。
- 第一批长表未给出完整显著性，里程结构解释仍需原始分流与置信区间复核。

## 第二次时间片结果

6 月 10—23 日的六城时间片实验报告小猪端完单 -0.10%、CR -0.07pp，均不显著；相比第一次实验的显著负向有所收窄。但自营子集完单 -4.85%、竞争 CR -2.22pp，而 PBD 自营完单 +3.27%、竞争 CR +0.49pp，体现明显端与商家异质性。原文没有统一置信区间，不能以聚合不显著覆盖自营负向，也不能据此推断当前策略状态。

## 2023 年 2 月扩量快照

另一份 02-22 至 02-26 的历史扩量材料将“订单价值决定交易模式 + 无提前举手”与“品类决定交易模式 + 有提前举手”同时变化，因此不是对提前举手单因素的干净识别。其覆盖北京及大量中小城市，聚合点估计显示：

- 自营竞争应答率 -4.79pp、竞争完单率 -2.72pp、单均 GMV -6.99%；应答后司机取消率则下降 1.25pp。
- 大盘应答率 -1.33pp、完单率 -0.10pp；去除滴滴后应答率 -3.41pp、完单率 -1.86pp。
- 分城市结果方向高度分散，不能用聚合均值代表单城效果；来源也没有给出城市权重、置信区间或 SRM 检查。

## 新增证据边界

- 扩量快照同时改变交易模式决策与提前举手，不能把负向全部归因于“无提前举手”。
- 正文中的城市长表只提供点估计；显著性、多重检验、样本量和分流稳定性均待补充。
- 图片和 Excel 附件尚未解析；历史实验不证明当前配置或线上状态。

## 提前举手机制与公平性争议

一份历史复盘解释，自营半指派给司机 8 秒决策时间；为避免等待司机决策而错失平台竞争，自营曾在司机未决策前向平台推送最优司机。PK 胜出后其他三方被告知失败，若司机随后拒单，订单只能在自营/宏鹄内部继续流转。来源把这称为“提前举手”，并指出它在提升自营完单的同时可能减少 API 运力的再次参与，形成公平性与大盘效率权衡。

材料记录的机制观察包括：自营履约率 87%、三方 78%，实验组/对照组 PK 胜利平均分数 8251/8302；来源据此推测去掉提前举手后的大盘负向与运力履约、8 秒等待及更远匹配有关。这些数值没有样本量、日期、显著性或完整实验表，仅是历史点估计与解释假设，不能确认因果。

来源提出“逐步下掉”与“先提升自营竞争力再下掉”两条历史放量路径，并建议用全指派缓解半指派等待问题；没有发布回执和当前配置，不能据此认定提前举手已经下线或仍在线。

## 自营与宏鹄拉齐的决策合同

一份“提前举手看清”材料提出用时间片实验比较两种拉齐方式：自营半指派不提前举手，或自营与宏鹄都提前举手。分析框架要求同时观察含滴滴大盘成交率、非滴滴完单量、自营竞争成交率及司乘取消，避免只用商家份额判断。

理论推导认为：若不提前举手导致自营错过当轮 PK，自营应答机会会损失；若能赶上当轮 PK，自营结果取决于司机决策和 PK。若自营胜出后司机拒单，API 商家已经收到失败通知，订单再次发起 PK 时可能失去原 API 候选，因此大盘应答也可能折损。该推导解释了机制风险，但正文中的一级指标结果均为空，不能当成实验结论。

来源没有实验日期、城市、分流配置、样本量、SRM、点估计、显著性或发布回执；当前是否已经完成自营/宏鹄拉齐仍待确认。
