# V3 应答时长模型实验

## 方案与上线前校验

V3 使用实时供需等特征预测小猪自有运力应答时长，实验组将模型输出在 `model_min` 与 `model_max` 之间截断后作为 hold 时长；对照组使用 V2 城市×格子策略。

2023-02-24 至 02-27 推送模型后发现线上/离线预测差异，且当时未开流量。排查定位到 city、day_of_week、hour 以及多个复合特征的线上算子/截断配置未生效；修复后重新校验一致。

## 实验结果

Apollo 按乘客 ID 分流，23 个城市，周期为 2023-03-07 至 03-13：

- 人均自营完单相对 +1.08%，显著；人均自营+三方完单 +1.09%，显著。
- 人均滴滴完单 -14.63%，显著；人均大盘完单 -0.08%，不显著。
- 实验组平均 hold 21.31 秒，对照组 10.33 秒；原文认为 V3 更接近订单真实应答时长，但大盘完单没有显著改善。

## 上线边界与覆盖缺口

快照记录了实验，不足以证明后续全量上线或当前仍在使用。滴滴完单的迁移风险必须与自营收益同时报告。
