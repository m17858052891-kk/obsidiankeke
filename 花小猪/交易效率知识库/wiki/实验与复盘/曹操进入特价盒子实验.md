# 曹操进入特价盒子实验

## 历史结果

来源记录曹操进入特价盒子后，曹操完单约 +14.7%、API 完单约 +2.95%、平台完单约 +0.31%。这是特定实验窗口的商家与平台漏斗结果，反映份额迁移和盒子新增成交的共同作用。

实验采用乘客 PID 随机分流，历史窗口为 2026-01-26 至 02-08，流量比例为 95%/5%。原始配置以“是否静默曹操特价盒子发单”定义组别，分析时将处理/对照方向反转来估计“曹操进入盒子”的增量；复算时必须沿用这一方向约定，不能直接按平台组名解释正负号。

## 解读

商家自身增幅远大于平台净增，不能把商家完单上涨等同于平台增量。来源同时给出 API 特价盒子完单约 +15.87%、非特价盒子完单约 -0.84%，以及大盘特价盒子完单约 +1.19%、非特价盒子完单约 -0.14%；这些点估计提示盒子新增与模式替代并存。复盘需要继续拆分其他商家份额损失和乘客重发影响。

## 证据边界

当前页保留原文结论，未复算长表、SQL、样本均衡、显著性和实验流量；城市明细、乘客级分流键及内部实验标识未复制。该历史结果不证明当前盒子配置或持续收益。
