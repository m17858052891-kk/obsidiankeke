# 商家竞争效率司机分流实验设计

该实验按司机分流，在一组试点城市的全流量中比较现状组与平台 PK 参数调整组。实验组对小猪端和联盟端分别设置 P/Q，并设置竞争阈值 A=0.1、等待参数 B=2 秒；其他端保持基准参数。原文还列出了具体城市编号、人员和实验平台地址，本页不复制这些运行与人员明细。

## 指标与判定

计划评估成交率、应答前/后乘客取消率，以及总完单、自营完单、宏鹄完单和 API 完单。司机分流能降低同一司机跨组污染，但平台竞争仍可能产生跨组运力挤占，因此不能只依据单一商家的完单变化判断平台净收益。

## 方案版本

- 初版把“PK 必败连边过滤”和“PK 失败司机重复连边加权”同时放入实验组，并额外观察 API 完单。
- V2 保留重复连边加权，但移除 PK 必败连边过滤；计划指标也不再列 API 完单。

两份方案均为 50%/50% 司机随机分流、计划运行七天，且面向同一类小猪/联盟交易流量。该差异说明 V2 是动作拆分后的归因实验，不能把初版与 V2 当成同一处理组，也不能从方案稿推断实际启动顺序。

## 证据边界与缺口

来源只证明多个历史版本的七天实验配置和评估计划，不含样本量、分流均衡、显著性、指标结果、异常日处理、实验结论或上线回执。具体城市、人员、实验链接与运行配置未复制；当前线上参数也未知。本页不能作为“实验有效”或“已上线”的证据。
