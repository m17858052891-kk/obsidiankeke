# 核心司机竞争倾斜历史分析

## 方案与分析窗口

2022 年材料记录在若干实验城市中，当核心司机与 API 司机共同参与 PK 时给予核心司机倾斜。报告用实验前后两个不等长窗口，分别按 API 与城市观察 API 的 PK 胜率和完单份额；它不是同期随机对照分析。

## 点值信号

聚合到 API 后，所列三类 API 的 PK 胜率在后窗均下降，但完单份额并非全部同向；城市层面也存在少数后窗上升。这个异质性说明倾斜对竞争胜出与最终份额的传导受城市、运力结构和基线影响。来源结论只能作为调权后的描述性信号，不能证明倾斜造成变化。

## 复核要求

- 使用同期实验/对照，而非仅前后窗；补齐样本分流、SRM、置信区间与多重比较处理。
- 同时看核心司机收益、平台完单/CR、API 份额、取消及接驾体验，避免单边优化。
- 城市与商家分层先报样本量，再解释方向；不得用聚合下降覆盖局部反向。

## 证据边界

材料没有倾斜参数、配置版本、发布/回滚记录和显著性检验，且一张图未解析；它不证明当前线上仍启用该策略。API 品牌、城市和内部标识明细不在 Wiki 复制。
