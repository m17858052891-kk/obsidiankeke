# 城市实验基础画像合同

## 目的

该历史 SQL 用于判断实验城市在供需视角是否具有代表性，以及效果是否集中于少数城市。画像以城市为粒度，组合日均呼叫、完单、GMV、ECR、CR，全国份额、端内占大聚合份额、端内各运力份额、供需分框和服占比。

## 口径约束

- 日均量按日期去重天数归一；全国份额与城市内部运力份额是不同分母，不可混称。
- 自营、宏鹄、API、滴滴运力份额以城市端内完单为分母；端内占大聚合则使用大聚合完单为分母。
- 服占比由在线时长与服务时长聚合，并区分自营、宏鹄；原 SQL 的日期、城市范围和供需分框月份都是待参数化快照。
- 原文示例行仅用于展示字段，不构成城市当前画像或实验结论；本页不复制城市级明细、底表名和生产 SQL。

## 覆盖缺口

- 未提供空分母、缺失城市、异常值和跨源口径一致性的处理规则。
- 未给出画像周期与实验周期如何对齐、代表性阈值、分层抽样或外推检验方法。
- SQL 文本存在别名复用等需执行前复核的细节；本批未执行 SQL，也未校验底表最新版本。
