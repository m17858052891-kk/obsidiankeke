# 乘客分流实验评估合同

## 分流与分析单位

来源给出两种乘客级分流：`passenger_id % 100` 取模，以及 Apollo bucket 随机分组。实验归因、AA 回溯和显著性都必须沿用同一乘客级分组规则，不能在订单级重新随机。

AA 窗口应早于 AB；历史人群限定为同时出现在 AA 与 AB 窗口的乘客，再按 AB 的 bucket 规则回填组别。该做法用于检查实验前可比性，不等于已经通过 SRM 或协变量平衡检验。

## 指标合同

- 人均呼单、应答、完单与 GMV：分母为去重乘客，分子分别为满足口径的订单数或完单 GMV。
- 应答前取消率：应答前取消订单 / 发单订单。
- 应答后乘客取消率：乘客应答后取消订单 / 应答订单。
- AR、CR：分别为应答订单 / 发单订单、完单订单 / 发单订单。
- 完单 ASP：完单 GMV / 完单订单。

来源 SQL 排除了短时预约和早鸟订单，并对部分指标排除 `source_type = 2`；复用前必须参数化日期、实验 key、商家范围及过滤条件，不能把示例日期直接作为当前口径。

## 显著性边界

率指标与均值指标使用不同样本量工具；均值指标还需要标准差。来源示例以最小组样本量是否达到所需样本量判断显著性，但没有给出完整检验参数、置信区间或多重检验处理，不能据此替代标准 AB 报告。

## 覆盖缺口

- 原文中的 Apollo 配置截图和显著性计算截图尚未解析，分桶映射与计算器输入不可审计。
- 未提供实际实验的样本窗口、SRM 检查、组间基线平衡、显著性明细或发布配置回执。
- SQL 是历史模板，未在本地执行；字段可用性与当前数仓口径待 owner 核验。
