# 归一单均司机接驾时长

## 历史口径

来源将司机每次应答后的接驾占用时长汇总到归一订单：从应答到司机到达、司机取消或乘客取消的终止时刻，覆盖完单和取消场景，再除以归一订单数。

## 使用约束

该指标衡量司机接驾资源占用，和只看完单司机的接驾时长不同。换车策略可能降低乘客 ETP，却增加司机空驶与多司机接驾占用，因此两项指标需要并列作为约束。

## SQL 合同快照

历史实现按运力是否可控、是否连环派拆分接驾时长。可控连环派以运力侧上一单完单时刻作为接驾起点；非可控连环派从应答至计费/取消时长中扣除 AB 段预估 ETA，负值归零；非连环派直接按应答到计费或取消计算。送驾时长只计完单的开始计费到结束计费，并同时输出接驾/送驾比。

实验样本按乘客分组，剔除窜组且只统计首次进组后的数据。归一订单、归一应答订单、归一完单订单三类分母都在 SQL 中保留，正式看板必须明确选用哪一个，不能把历史注释中的“每次应答”与正文修订后的“归一订单”混用。

## 证据边界

原文存在“应答订单数”改为“归一订单数”的修订痕迹，当前正式分母必须复核；历史 SQL 未执行，取消终止时刻、跨天完单、改派归并、连环派识别和 API ETA 字段均待确认。月度测算没有样本量、显著性或发布版本，不能视为线上效果。
