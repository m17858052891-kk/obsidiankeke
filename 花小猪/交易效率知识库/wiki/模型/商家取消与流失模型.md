# 商家取消与流失模型

> 依据 `qinjiatong/cp_trade_strategy_wiki` 提交 `27d0b572` 的历史记录；仓库最后提交为 2026-05-26。以下模型版本和阈值机制未核验为 2026-11 线上状态。

## 三类预测与决策位置

| 模型 | 预测对象 | 策略作用 | 已知边界 |
| --- | --- | --- | --- |
| 乘客应答后取消率 | 司乘连边下乘客取消风险 | 过滤高风险候选 | 具体标签时间窗、取消责任和训练样本过滤未齐 |
| 司机应答后取消率 | 司乘连边下司机取消风险 | 与乘客风险共同约束候选质量 | 是否包含拒单/改派要逐版本确认 |
| 应答前订单流失率 OCR | 订单尚未应答时的流失风险 | 调节每轮过滤阈值 | 样本、架构与校准文档缺失；不要将OCR当图片识别 |

V2综述记录“大初始半径召回 + 取消模型过滤”，并按每轮订单流失风险调节过滤严格度。V2.1原文举例 `CAA < OCR + 偏置项`：偏置越小过滤越严，越大越松。公式是来源中的策略说明，不代表所有场景同一线上参数。

## V2.0→V2.1的注册名证据

| 任务 | V2.0历史记录 | V2.1历史记录 |
| --- | --- | --- |
| 非连环派乘客取消 | `cp_pas_caa_model / cp_pas_caa_model_v2` | 合并至 `cp_pas_caa_model / recall_pas_cancel_v1_pas` |
| 连环派乘客取消 | `serial_pas_cancel_model / serial_passenger_cancel_xgboost_v12` | 与非连环派共用上述服务 |
| 非连环派司机取消 | `cp_dri_caa_model / cp_dri_caa_model_v2_zy` | 合并至 `cp_dri_caa_model / recall_driver_cancel_v2_dri` |
| 连环派司机取消 | `zy_serial_driver_cancel / serial_dri_cancel_xgb_v11` | 与非连环派共用上述服务 |
| 应答前流失 | `cp_loss_model / v_empty` | 原文保留相同注册名 |

原文的“5个模型→3个模型”是工程注册/调用合并证据，不能据此推断已采用某个特定多场景架构。`v_empty`是原文登记字符串，尚无证据说明它代表占位、规则模型或真实训练版本。

V2.1同时增加ETA与EDA联合召回限制、近距离连环派免模型过滤条件，并调整分场景偏置。架构合并、过滤位置与阈值变化应分开记录，不能把整体实验收益全部归因于模型精度。

## 多场景取消模型的离线探索

原始建模记录动机为扩播/连环派样本稀疏、独立模型维护成本较高，比较XGBoost、PLE和PPNet单任务版。

| 训练场景 | 模型 | 扩播乘客取消 AUC | 连环派乘客取消 AUC |
| --- | --- | ---: | ---: |
| 扩播+非扩播（不含连环派） | XGBoost / PLE / PPNet | 0.6485 / 0.649 / 0.6511 | 不适用 |
| 扩播+非扩播+连环派 | XGBoost | 0.6523 | 0.6962 |
| 同上 | PPNet单任务版 | 0.656 | 0.6906 |
| 同上 | PLE | 0.653 | 0.6862 |

在这份历史数据中，PPNet扩播AUC较高，连环派则XGBoost较高，不能归纳为一个架构跨场景全面领先。原文没有足够文本说明所有训练参数和上线结果，架构图是临时图片链接，本批未识别；因此不填补图中细节，也不把“PPNet”和其他来源的“PEPNet”直接视为同一部署模型。
