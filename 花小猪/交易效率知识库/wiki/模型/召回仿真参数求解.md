# 召回仿真参数求解

> `b015-model-recall-simulation-solver`。这是离线仿真与参数搜索工具链，不是直接部署的预测服务；来源材料的线上对应状态待确认。

## 用途

用离线仿真复现召回、TP/GS、Hold 与匹配过程，搜索统一价值公式中的参数和距离配置，并在进入线上实验前检查完单、取消和接驾指标的约束权衡。

## 输入与求解

- 输入包括订单/司机候选、ETA/EDA、召回与匹配模型分、历史事件和分场景配置。
- 参数候选涉及 Hold 激进度、TP 机会成本、距离上限和分场景阈值。
- 输出用于比较参数组合的仿真指标或生成离线配置，不应直接解释为线上因果收益。

ETA、EDA 与真实接驾时长的分析提示：预测偏差会改变候选距离和约束判断，仿真若复用预测时长而真实执行依赖另一口径，离线排序可能无法复现线上结果。

## 参数求解方案的有效边界

补充方案材料明确废止了“允许不派”的假设。由于承载完整算法的 `match_detailed.html` 附件尚未解析，目前只能确认这一约束修订，不能还原目标函数、可行域、求解步骤、参数上下界或收敛条件；也不能把此前基于“允许不派”得到的解继续视为可用版本。

## 2026-09 离线参数测算

这是离线回放评估，不是线上实验或发布记录。训练使用 `2026-09-01` 至 `2026-09-13` 的召回矩阵数据，验证集为 `2026-09-14` 召回矩阵抽样。材料称聚合口径满足“五项约束”，列出的约束域包括加权履约 `F_hat`、司乘取消率、匹配量护栏和 `W` 护栏；但原文没有展开五项逐一定义、公式、方向、阈值与统计口径，因此本页不补写。

| 观察 | 离线结果 | 解释边界 |
| --- | --- | --- |
| 城市×小时五项约束通过 | `8,520 / 15,313 = 55.64%` | 未通过组主要被归因于低流量长尾回放不足；这是来源判断，未见显著性或误差区间 |
| 通过组覆盖完整 OD | `97.29%` | 高业务覆盖不能证明每个城市小时线上均达标 |
| 验证 OD 的参数来源 | `94.27%` 来自“城市小时完整预算精搜”或“上轮城市小时可行参数继承” | 两类来源混合，继承参数的版本和漂移检查未给出 |
| 其余参数来源风险 | 约 `5.73%` OD | 具体求解方式、城市和业务量未展开 |
| GS 与 TP | 来源称 GS 更稳 | “TP 单边贪心结构不稳定”只是材料中的推测，不是已验证归因 |

材料同时提示局部城市小时可能出现指标代偿或退化，主要风险点为匹配量。它没有给出线上实验、显著性、发布城市、配置版本、灰度比例、当前线上状态和回滚条件，不能据此宣称参数已上线或产生因果收益。

## 证据边界

- Code Review 与参数求解文档描述了模块和求解流程，但完整代码、依赖版本、随机种子及回放覆盖未纳入 Wiki。
- 仿真使用历史策略生成的数据，存在策略选择偏差；不能把回放提升当成线上增量。
- 图片、表格和外链附件未解析，参数数值和逐城结果不做补写。
- 本批来源中的多张结果图片、`最终参数加权达标评估.xlsx`、`验证集20260914聚合口径达标评估.xlsx` 与 `match_detailed.html` 均未解析；逐项公式、城市明细、预算和参数值仍是覆盖缺口。
