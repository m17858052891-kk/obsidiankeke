# 语义 ID 与生成式检索

> 论文综述与候选技术卡，不代表交易模型已采用或上线。

## 问题与表示合同

随机哈希能压缩高基数 ID，但会把语义无关对象碰撞到同一行，也难以迁移头部样本知识到冷启动对象。语义 ID 则先把内容 embedding 离散成多级码字，让相近对象共享前缀；目标是在有限 embedding 表内同时保留记忆与泛化能力。

- 生成：TIGER 路线用内容编码器和 RQ-VAE 逐层量化残差，码字从粗到细；末尾冲突标记只保证唯一性，不等于语义质量。
- 使用：可把码字展开后由 seq2seq 生成下一对象，也可用 N-gram、SentencePiece 或前缀参数化映射回传统 DLRM embedding 表。
- 可靠性：生成式检索可能输出库中不存在的码字，需要合法前缀约束、过滤或 beam search；码本坍塌、冷启动和词表更新都需版本治理。

## 迁移到交易场景前的缺口

- 对象究竟是司机、乘客、订单还是时空格，以及内容 embedding 的可用字段与观测时点尚未定义。
- 需要与随机哈希、个体 embedding、已有 DLRM 做同预算离线比较，并分头部/长尾/冷启动报告。
- 缺少码本版本、增量对象映射、碰撞/无效 ID 率、内存、延迟和回滚合同。
- 原文实验结论来自外部推荐论文，不能移植为交易业务收益；多张架构图和效果图未解析。

## B062：OneRec 生成式推荐候选

OneRec 调研把传统召回、粗排、精排级联改写为语义 ID 的自回归生成。其 tokenizer 用多模态内容与协同信号构造表示，再以 RQ-Kmeans 形成分层语义码；编码侧并列静态、短期、正反馈与长期行为通路，解码侧逐 token 生成候选语义 ID，并以 MoE 扩展容量。RSFT/RL 与偏好、格式合法性、行业目标等 reward 是论文方案中的对齐机制，并非本业务已经实现的训练链路。

该材料属于外部推荐研究综述，不含交易场景样本、离线复现、线上实验、服务接入或发布回执。迁移评估至少要补齐对象定义、合法 ID 率、码本更新、冷启动分层、同预算级联基线、推理时延与回滚；原文图片、效果表和附件未解析，不能据摘要中的论文点值认定显著性或业务收益。
