# 连环派 V0 模拟基准

> 本页是第一个稳定版模拟系统上的历史测算，不是线上实验结果，也不证明当前连环派配置。

## 测算合同

- 样本来自北京、广州、深圳、长春、长沙、沈阳、南京、太原、杭州、武汉、厦门 11 城 5—7 月的真实司机与订单轨迹。
- 环境模拟司机随机上线/游走、订单生成/消失，在 GS 分单基线上比较有无连环派。
- 主测算按工作日/周末与早高峰、晚高峰、下午平峰分层，输出模拟完单 GMV 与完单量。

## 历史离线结果

| 时段 | 工作日 GMV 加权增量 | 周末 GMV 加权增量 |
| --- | ---: | ---: |
| 早高峰 | 3.5% | 1.2% |
| 晚高峰 | 1.0% | 0.9% |
| 下午平峰 | 1.2% | 1.2% |

材料另比较真实完单与 base 模拟：GMV diff 在工作日早/晚/平峰为 `7.1% / 10.1% / 6.6%`，周末为 `-2.7% / 2.4% / 5.8%`；成交量 diff 对应为 `5.6% / 6.8% / 4.8%` 与 `-4.1% / 0.4% / 3.7%`。这些 diff 描述模拟基线与真实完单的差异，不是策略收益。

## 解读与验收边界

连环派在该离线环境中的点估计均为正，但周末早高峰的模拟基线误差方向与其他分层不同，提示环境校准还不稳定。应以模拟—真实的策略排序一致性、分城/分时段误差和线上随机实验作为验收，不应把上表数值直接折算为大盘收益。
