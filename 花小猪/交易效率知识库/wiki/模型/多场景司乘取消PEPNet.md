# 多场景司乘取消 PEPNet

> 2024 年离线迭代谱系，覆盖常规、扩播、连环派。文档中的“线上 XGB”仅作当时基线，不代表 2026 年生产状态。

## 任务和样本

- 乘客取消：自营订单乘客取消为正样本；早期单任务版为避免潜在标签偏差，以司乘均未取消/拒单作负样本。
- 司机取消：司机应答后取消为正样本，司乘均未取消为负样本。
- 主要特征分为场景、实时供需、乘客历史行为、司机历史行为。早期来源的训练/测试周期是 2024-06-12～18 / 06-19～25。

## 架构与迭代

PEPNet 用 EPNet 的场景门控学习 domain-specific embedding，PPNet 对任务网络参数个性化。早期单任务乘客取消版尝试用常规场景补充扩播/连环派的小样本。

司乘双塔版在同一 PEPNet 中同时预测司机和乘客取消，但两种取消的互斥性导致梯度冲突和跃跃板。后续有两条路：分开建模；或保留多任务并试 PCGrad、Dynamic Weight Average、互斥样本 loss mask。另一份多场景研究比较 Meta attention/cross/gate、Triplet attention 和固定场景专家分布。

## 离线证据（不同条件不横比）

- 司乘双塔版：乘客取消 PEPNet AUC 整体/扩播/连环派/常规 = 0.726/0.654/0.691/0.712，低于同表 XGB baseline 的 0.739/0.746/0.697/0.738；司机取消多个分层则较好。
- 司机单独建模：PEPNet AUC 整体/扩播/连环派/常规 = 0.833/0.784/0.795/0.839，同表 XGB baseline = 0.825/0.765/0.782/0.832。
- 多任务优化：PCGrad 的乘客整体 AUC 0.728，司机 0.871；DWA 分层上有局部最优，但无统一全面胜出。
- 另一宏鹄多场景实验中，不同专家选择器的 AUC 大致为连环派 0.7480～0.7487、扩播 0.7659～0.7671、常规 0.7521～0.7532；训练数据与前述自营实验不同。

## B038：稀疏场景统一建模的早期对照

一份更早的乘客取消研究把扩播、连环派等小样本场景合并训练，目标是减少模型数量和维护成本。特征包括城市、时段、订单来源、派单场景、路线、ETA、等待与剩余距离，并为扩播和连环派补充司机历史行为。训练窗口为 2024-05-13～19，验证窗口为 2024-05-20～26。

| 离线结构 | 连环派 AUC | 扩播 AUC | 其他 AUC |
| --- | ---: | ---: | ---: |
| XGB base | 0.6955 | 0.6417 | 0.6742 |
| GDCN-P | 0.7027 | 0.6492 | 0.6838 |
| GDCN-P + LHUC | 0.7027 | 0.6491 | 0.6844 |
| PEPNet | 0.7032 | 0.6497 | 0.6841 |
| HIBNET + SEI GDCN，多 gate | 0.7028 | 0.6500 | 0.6848 |
| HIBNET + SEI GDCN，单 gate | 0.7025 | 0.6486 | 0.6839 |

这组结果只说明同一历史切分中的离线排序，各深度结构相对 XGB 的差距较小；来源未给出样本量、置信区间、显著性、校准、线上实验或生产注册。模型结构主要在未解析图片中，因此不据名称补造网络层级。

## B045：深度模型工程接入需求

一份业务 BRD 计划把扩播与连环派的司机/乘客取消 XGBoost 替换为多场景深度模型，并要求交易引擎补传新增特征、解析新服务返回值，同时支持不同服务版本间 AB。来源记录的离线 AUC 增量为扩播乘客取消 `+11pp`、连环派司机取消 `+3.6pp`、连环派乘客取消 `+1.5pp`；另引用扩播竞争 CR `+0.15pp`、连环派竞争 CR `+0.2pp` 的历史业务结论。

这些数字来自 BRD 汇总，缺少训练切分、基线版本、样本量、置信区间、实验 ID 与独立报告，不能据此认定新深度服务已上线或取得因果收益。当前还缺服务注册、QPS/P99、特征一致性、灰度比例、降级和回滚记录。

## B050：连环派深度模型空跑与回滚记录

另一份实验 BRD 记录乘客取消 AUC `+5.4pp`、司机取消 AUC `+4.7pp`，并把竞争 CR `+0.1pp`、司乘取消率 `-2pp` 写作预估收益。计划先以全国 10% 流量空跑统计分布和标定阈值，再做 PID 分流：90% 旧模型对照、10% 新多场景深度模型实验，覆盖小猪端、滴滴端 PBD、多品类及自营商家。

checklist 只确认流量监控、分流和部分模型访问曾被检查；随后日志发现端外特征异常，材料明确记录“修复，模型回滚”。因此该来源是接入失败/回滚的反向证据，不能据流量上涨或 AUC 提升认定发布成功。六张监控图未解析，且没有异常特征名、修复版本、重启实验、最终结果或当前服务状态。

## B064：2024 多场景取消迭代的可复核合同

本批重新通读五份原始材料后，可把同一条离线迭代链拆成四个互不等价的候选：乘客单任务 PEPNet、司乘双任务 PEPNet、司机单任务 PEPNet，以及双任务的梯度/Loss 优化。它们共享场景、供需、司机和乘客四类特征，但标签过滤不同，不能把表中的 AUC 拼成一个统一版本收益。

乘客单任务版使用 2024-06-12～18 训练、06-19～25 测试，训练/测试样本分别约 1632 万/1613 万，正负样本比 1:4。为减少反事实标签污染，司机拒单或取消样本不进入乘客负样本；PEPNet 的整体/扩播/连环派/常规 AUC 为 `0.763/0.772/0.708/0.756`，同表 XGB baseline 为 `0.754/0.763/0.704/0.744`。这只是固定历史切分中的离线比较，未给重复实验、置信区间或概率校准。

司乘双任务 V1 没有剔除另一方取消样本：乘客任务 PEPNet 整体 AUC `0.726`，低于 XGB baseline `0.739`；司机任务整体 AUC `0.868`，高于 XGB baseline `0.861`。材料将乘客侧退化解释为互斥标签带来的梯度冲突，但没有梯度夹角、损失曲线或消融，因此该解释仍是机制假设。司机单任务恢复互斥样本过滤后，PEPNet 整体 AUC `0.833`，同表 XGB baseline 为 `0.825`。

双任务优化页比较 Origin、PCGrad、DWA 和 Mask Loss：PCGrad 的乘客/司机整体 AUC 为 `0.728/0.871`，相对 Origin 的 `0.719/0.868` 有所提高；DWA 在司机扩播和常规分层分别达到 `0.812/0.873`，但没有一种方法在所有任务、场景全面领先。正文一处称计算 Loss 时屏蔽另一方取消样本，另一处又写“此版本没有剔除”另一方取消样本；这是实现口径冲突，未取得训练代码前不判定实际执行逻辑。

部署页只给出候选请求字段和“新建集群深度服务”的工程设想。字段覆盖城市、起终点坐标/格子、乘客/司机、商家、时段、预付价、接驾与行程距离/ETA、等待、改派、订单来源和交易模式；正文还存在 `passenger_id/driver_id` 重复、粗体字段含义依赖排版的问题。它不是最终 schema、服务注册或上线验收，亦未提供必填性、类型、缺失值、时点一致性、延迟、降级和版本映射。
