# 差体验连续剂量归因模型

> 该页合并归因探索 v0/v1。v0 是流失预测基线，v1 是连续处置因果方案；两者都不是已验收的线上归因系统。

## 任务与识别目标

目标是估计差体验剂量 `T∈[0,1]` 对未来流失概率的剂量反应，而非只预测哪些用户会流失。要把它解读为因果归因，仍需交代处置时点、结果窗口、可比性/无未观混杂、positivity 与干预一致性。现有文档没有完成这些识别检查。

## v0：预测基线，非因果归因

v0 分别训练 XGBoost 与神经网络预测流失。XGBoost 使用 binary logistic、深度 6、200 轮，记录 AUC 0.815962；神经网络的验证 AUC 为 0.815918。特征重要性主要集中于历史订单量、应答等统计。

这些数值只证明单次预测实验的区分度。来源没有完整记录数据切分、样本量、时间窗、早停、概率校准、多随机种子或显著性；高重要性也不等于差体验造成流失。

## v1：Hurdle-VCNet 方案

直接对比例剂量建模有两个难点：没有暴露机会和有机会但没有差体验都落在 `T=0`；同一比例 `C/N` 在不同机会数 `N` 下可信度不同。因此方案先分解暴露机会 `O`、是否发生差体验 `Z` 和正剂量 `R=C/N`，再设计四个头：

- Gate 头建模零/正剂量路径；
- Count 头以零截断二项分布建模次数；
- Zero Outcome 头建模零剂量结果；
- Positive VCNet 头用 8 个三次 B-spline 基函数表示连续剂量反应。

联合损失写为 `L = L_Y + 0.2 L_gate + 0.05 L_count + 0.001 L_smooth`，并延续 VCNet 的条件处置密度和 targeted regularization 思路。这是结构与损失函数设计，原文未给出业务数据复现、离线 uplift/安慰剂检验或线上实验。

## 验证与上线前缺口

- 泄露：历史统计特征、暴露机会数和结果窗口的观测时点未冻结，需要事件时间级排查。
- 显著性：缺少多 seed、bootstrap/置信区间、异质性稳定性和对照方法。
- 可识别性：需验证 propensity 支撑、极端剂量样本量、零膖胀分解和 count 分布假设。
- 成本：未提供参数量、训练时长、推理延迟、服务 schema 和监控方案。
- 线上事实：无上线版本、AB 或业务增量，不应写成已投产。
