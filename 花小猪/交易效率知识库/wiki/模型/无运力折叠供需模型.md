# 无运力折叠供需模型

## 任务边界

来源组合给出一次冒泡场景的特征合同和一轮历史 XGBoost 实验。实验标签为订单存续期间一圈/两圈内是否存在对应品牌运力；模型输出低于阈值时折叠该品牌车型。该证据能恢复历史任务和实验，但没有模型版本、城市清单、显著性明细或当前线上状态。

## 特征合同

- 请求上下文：城市、起终点坐标与格子、乘客、商家、品类、冒泡与链路标识、冒泡时间及 30 分钟时间片。
- 实时供需：按品类与格子邻域统计近 10/20/30 分钟运力数。
- 历史供需：按品类、格子和同时间片，聚合前 7 天邻域运力数与发单数。

这些字段混合了在线请求特征和离线周期统计，需要补齐生成时间、延迟、缺失值与线上离线一致性校验。

## 历史离线与实验

实验材料报告离线召回率 72.34%、准确率 90.31%，但没有给出切分方式、阈值、样本量或时间外验证。PID 实验把过去 30 分钟运力打点作为对照，以不同阈值的 XGBoost 为实验组：阈值提高时折叠率和召回率上升、准确率下降，体现展示覆盖与误折叠之间的直接权衡。

5% 初版与 20% 扩量表格记录了多轮阈值结果。部分滴滴/API 分项完单上升，同时宏鹄分项下降；整体人均完单、GMV、ECR/CR 没有稳定单调收益。原文只说明“标红为显著”，纯文本快照丢失颜色，不能恢复哪些单元格显著，也不能据此给出推全结论。

## API 商家随机折叠候选

另一份城市截面列出 API 商家折叠率与举手率，并建议对低举手、低折叠城市参考外部方案做比例随机折叠。该页是诊断和策略设想，不是训练证据或线上实验；城市值缺少统计区间、样本量与观察日期，不能直接转成模型阈值或当前城市配置。

## B041：全车型 XGBoost 离线训练

另一份离线记录以 2024-01-23～26 的 107,014,974 条样本训练、2024-01-29 的 27,511,290 条样本测试，正负约 1:1，XGBoost AUC 为 0.78。阈值从 0.2 提至 0.8 时，召回率从 81.2% 降至 43.4%，准确率从 47.9% 升至 82.4%，折叠率从 56.3% 降至 23.7%，说明阈值方向与前述实验材料的表述需逐版本核对，不能混用。

该材料还记录宏鹄司机打点表 `business_id` 与线上商家 ID 不一致，需经 `company_id` 映射；此前只采样自营车型时离线效果更高，反映车型条件分布差异。线上空跑日志只证明当时有数据采集，不证明模型已决策生效；训练未给城市时间外切分、校准、置信区间、模型版本和实验回执。
