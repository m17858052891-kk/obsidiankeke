# 生成式模型可靠性技术调研

> 两份来源是 2025 年技术综述与论文研读，不含交易业务任务、训练产物、实验或生产部署；本页只保存可供未来模型治理参考的技术合同，不能写成交易效率能力已经上线。

## 多模态架构边界

多模态大模型通常由模态编码器、输入投影/VL connector、LLM backbone、输出投影和模态生成器组成。理解型链路把图像、音频等编码后投影到语言空间，再与文字 token 联合推理；训练常拆为多模态预训练与指令微调。来源汇总了 ViT/CLIP、线性或 MLP projector、cross-attention、Q-Former 等候选，但没有在交易数据上比较，也没有定义本方向的图像、音频或文本任务。

若未来用于文档、截图或语音辅助，应先固定模态输入、标注、隐私权限、图像分辨率、连接器、冻结层、推理延迟和人工兜底。论文基准的相对表现不能外推到交易决策效果。

## 生成置信度方法

- 白盒：序列似然、最小/平均 token 概率或 DeepConf 式分组置信度，需要 token 分布访问；语言流畅概率不等于语义正确概率。
- 黑盒：`P(True)`、语言化置信度、多次采样一致性和 prompt 扰动，受提示词、温度与采样预算影响。
- 训练式：额外判别器或监督微调可学习置信度，但训练集构造与校准是核心风险。

置信度应区分排序能力与绝对校准。上线前至少报告可靠性图、ECE/Brier 等校准指标、选择性风险—覆盖曲线、OOD/分场景稳定性与拒答成本；早停和多轨迹投票还需同时报告 token 成本、延迟和错误拒绝。
