目前自营品类的扩播策略为呼单后1分钟起生效司机召回扩至5km.

对于里程5km以下短单而言，如果由3km以上扩播司机接驾且完单，则司机体验很差，并且扩播接驾后完单cr低；

因此

- 对于短单长接驾的订单要减少B补

- 播单方面需要去尾司机差体验

可以看出

- 里程在5km以下的短单出现过3km以上扩播找司机的占比接近7%(平均)；

- 短单找到接驾3km以上司机并完单的占比显著低于长单，5km以内最高2.32%；

- 且呼单后，短单第一次播单就出现扩播生效的占比非常高(高于50%)(扩播生效 <> 播到3km以上司机)

也就是说，按照自营当前的扩播生效策略，扩播找到司机后完单效率非常低，且由于扩播生效时间较早(1分钟)，短单里第一次播单就是扩播的占比非常高(说明呼单后周围一直没有自营的司机，无法连边只能通过扩播来找到自营运力).

因此，可以结合短单长接驾类型订单减少天降b补，延迟自营5km以下短单扩播的生效时间，达到

- 1\. 减少因为接驾距离触发天降b补的频率

- 2\. 减少短单扩播行为，提升司机体验、降拒单和应答后司机取消

另一方面，由于延迟了短单的扩播生效时间，会在一定程度上导致短单的完单gmv下降，因此可以同步配合提前长单的扩播生效时间：

### 实验设计

#### 实验策略

时间片实验2小时轮转

实验组：对自营呼单的5km以下订单延迟扩播生效时间至3分钟，5km以上订单提前扩播生效时间至(20-30s)，扩播接驾距离为5km以内

对照组：维持现有扩播策略，自营呼单1分钟起扩播召回生效

#### 实验指标

核心指标：自营完单gmv、自营竞争cr、自营客观cr(由于扩播修改导致会被三方应答)

二级指标：自营实时单司机拒单率、自营实时单应答前乘客取消率、自营实时单应答后司机取消率、自营实时单应答平均接驾距离

#### 预期收益

价格侧：3～5km扩播补贴率预计减少25%，从0.55pp -> 0.41pp

交易侧：自营效率gmv、竞争cr不显著负；客观cr提升1%，拒单率下降1%，平均接驾距离显著下降

```PlainText
-- 呼叫到播单表播出时长diff分布
-- 分送驾里程的每个组的平均订单播出时间
-- 1. 首次播单为扩播; 2.出现过3公里以上播单
-- 3公里以上播单一定是出现在扩播场景下, 但扩播生效未必一定找3公里以上司机
with broad as (
    select
        *
    from
        (
            select
                a.order_id as order_id,
                a.lumian_dist as lumian_dist,
                a.sdd as sdd,
                a.time_stamp as time_stamp,
                a.n as n,
                b1.kb as kb
            from
                (
                    select
                        param ['lowoid'] as order_id,
                        param ['lumian_dis'] as lumian_dist,
                        param ['start_dest_distance'] as sdd,
                        param ['timestamp'] as time_stamp,
                        row_number() over(
                            partition by param ['lowoid']
                            order by
                                param ['timestamp']
                        ) n
                    from
                        kflower_ods.ods_log_kflower_orderbroadcast
                    where
                        concat_ws('-', year, month, day) between '${begin}'
                        and '${end}'
                        and param ['anycar_type'] in (1, 2, 5)
                        and param ['area'] in (8,26,6,32,3,24,21,11,58,85,34,12,5,38,1,25,36,19,160,157,15,143,22,153,33,29,133,50,20,86,14,41,81,49,102,105)
                ) a
                left join (
                    select
                        order_id,
                        max(kb) as kb
                    from
                        (
                            select
                                param ['lowoid'] as order_id,
                                case
                                    when param ['lumian_dis'] > 3000 then 1 -- 3公里以上播单行为, 扩播生效不一定找3公里以上的司机
                                    else 0
                                end as kb
                            from
                                kflower_ods.ods_log_kflower_orderbroadcast
                            where
                                concat_ws('-', year, month, day) between '${begin}'
                                and '${end}'
                                and param ['anycar_type'] in (1, 2, 5)
                                and param ['area'] in (8,26,6,32,3,24,21,11,58,85,34,12,5,38,1,25,36,19,160,157,15,143,22,153,33,29,133,50,20,86,14,41,81,49,102,105)

                        ) b0
                    group by
                        order_id
                ) b1 on a.order_id = b1.order_id
        ) bb
    where
        n = 1
)


select
    gp,
    avg(time_diff) as time_diff_avg,
    avg(lumian_dist) as lumian_avg,
    count(order_id) as order_cnt,
    sum(tag_over_3km) as over_3km_cnt, -- 存在3公里以上播单行为
    sum(tag_kb_first) as first_kb_cnt, -- 首次播单为扩播
    sum(tag_kb_finish) as kb_finish_cnt
from
    (
        select
            a.order_id as order_id,
            a.call_time as call_time,
            case
                when a.product_1level = 1 and a.driver_start_dis is not null and a.driver_start_dis > 3000 and a.is_td_finish = 1 then 1
            else
                0
            end as tag_kb_finish,
            broad.time_stamp as broad_time,
            broad.lumian_dist as lumian_dist,
            broad.sdd,
            broad.kb as tag_over_3km,
            int(broad.sdd / 1000 + 1) as gp,
            unix_timestamp(broad.time_stamp) - unix_timestamp(a.call_time) as time_diff,
            case
                when unix_timestamp(broad.time_stamp) - unix_timestamp(a.call_time) > 60 then 1 -- 一分钟扩3-5公里不是说只在3公里以上找司机
                else 0
            end as tag_kb_first
        from
            (
                select
                    order_id,
                    call_time,
                    product_1level,
                    driver_start_dis,
                    is_td_finish,
                    is_td_answer
                from
                    kflower_dw.dwd_kf_trd_order_base_di
                where
                    dt between '${begin}'
                    and '${end}'
                    and is_td_call = 1 --and start_city_id in (8)
                    and source_type <> 2 --改派订单有重新播出的记录, 对应改派的订单id
                    and start_city_id in (8,26,6,32,3,24,21,11,58,85,34,12,5,38,1,25,36,19,160,157,15,143,22,153,33,29,133,50,20,86,14,41,81,49,102,105)

            ) a
            left join broad on a.order_id = broad.order_id
        where
            broad.order_id is not null
    ) combo
group by
    gp
order by
    gp
```

select
    gp,
    count(order_id) as order_cnt
from
    (
        select
            order_id,
            call_time,
            cancel_time,
            unix_timestamp(cancel_time) - unix_timestamp(call_time),
            int(
                (
                    unix_timestamp(cancel_time) - unix_timestamp(call_time)
                ) / 10 + 1
            ) as gp,
            cancel_type
        from
            kflower_dw.dwd_kf_trd_order_base_di
        where
            dt between '${begin}'
            and '${end}'
            and is_td_call = 1 --and start_city_id in (8)
            and source_type <> 2
            and cancel_type = 1
            and start_dest_dis > 5000
            and start_city_id in (8,26,6,32,3,24,21,11,58,85,34,12,5,38,1,25,36,19,160,157,15,143,22,153,33,29,133,50,20,86,14,41,81,49,102,105)
    ) a
group by
