# 一、关键概念

## On-policy vs Off-policy

1. On-policy: The agent learned and the agent interacting with the environment is the same.

2. Off-policy: The agent learned and the agent interacting with the environment is different.

## Model-Free vs Model-Based

1. The model of the environment means a function which predicts state state transitions and reward

2. Model-based: it allows the agent to plan by thinking ahead, seeing what would happen for a range of possible choices. (计算代价大）

3. Model-free: a ground-truth model of the environment is not available to the agent. （计算代价小）

## On-line learning vs Off-line learning

1. Offline means that we have a static dataset. （实现起来简单）

2. Online learning means that you are doing it as the data comes in. （实现起来相对较难）

## 3.1 PPO （Proximal Policy Optimization）

1. Policy gradient 的方法太慢了，每次我们更新一次policy后，都要再一次跟环境互动来获取reward。

2. 采用另外一个策略Policy_old来获取data, 然后根据这些data来更新我们想要训练的Policy。 这样做的前提是Policy_old和Policy不能相差过大

3. 所以引入了clip函数来限制Policy_old和Policy的差距。

4. 效果PPO2 相较于其他算法具有显著的优势

# 四、 Off-policy

Q-Learning. Methods in this family learn an approximator $Q\_{\\theta}(s,a)$ for the optimal action-value function, $Q^\*(s,a)$. Typically they use an objective function based on the Bellman equation. This optimization is almost always performed off-policy, which means that each update can use data collected at any point during training, regardless of how the agent was choosing to explore the environment when the data was obtained. The corresponding policy is obtained via the connection between $Q^\*$ and $\\pi^\*$: the actions taken by the Q-learning agent are given by

```PlainText
$a(s) = \arg \max_a Q_{\theta}(s,a)$
```
