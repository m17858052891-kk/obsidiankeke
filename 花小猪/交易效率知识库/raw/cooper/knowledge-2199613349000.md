愿等红包的计算需要考虑订单 不被取消且应答 的概率，但是红包时间只会影响 应答前取消 ，故将其拆分为 应答前取消 和 应答|不取消 ，且条件概率对场景识别更加适用

其中乘客画像和供需共同影响 应答前取消 ，供需影响 应答|不取消

由于存在删失数据，故用生存分析拟合应答前取消率和应答|不取消

# 二、理论分析

 目标：在预算约束的情况下，求解最大gmv   
$max$ $\\Delta gmv$   
$s.t. \\Delta cost \\leq \\sum^n gmv_i \\times$ 预算补贴率   
其中，   
$E(gmv) = \\int f$(订单未被取消且应答) $\\cdot asp = \\int f$(订单未被取消) $\\cdot f$(订单应答|未被取消) $\\cdot asp$   
$\\Delta gmv = E\_{红包}(gmv) - E(gmv) = \\int (f\_{红包}$(订单未被取消)- $\\int f$(订单未被取消)$f$(订单应答|未被取消)$\\cdot asp$   
$\\Delta cost = \\int\_{t_1}^{t_2} f\_{红包}$ (订单未被取消且应答) $ \\cdot r + \\int\_{t_2}^{t_3} f\_{红包}$ (订单未被取消且应答)$\\cdot 2r + \\int\_{t_3}^{600}f\_{红包}$(订单未被取消且应答)$\\cdot 3r$，其中设$r$为每个红包的金额

分析过程如下：   
根据生存分析原理，首先可以得到某一场景下的应答前取消和应答|不取消的生存函数，由未发放红包的应答前取消生存函数 $S(t)$，即可以得到对应的订单不被取消概率 $f(t)$   
$f(t)$为无红包时，订单不被取消的概率   
$f(t,\\vec{t})$为有红包时，订单不被取消的概率，$\\vec{t}$代表红包发放时间   
$f\_{ans}(t)$为应答率   
$r$为每个红包的金额   
则：   
  
$\\Delta gmv = \\int (f(t,\\vec{t})-f(t))\\cdot f\_{ans}(t)\\cdot asp dt$   
  
$\\Delta cost = \\int\_{t_1}^{t_2} f(t,\\vec{t})\\cdot f\_{ans}(t)\\cdot r dt+ \\int\_{t_2}^{t_3} f(t,\\vec{t})\\cdot f\_{ans}(t)\\cdot 2r dt+ \\int\_{t_3}^{600} f(t,\\vec{t})\\cdot f\_{ans}(t)\\cdot 3r dt$   
  
故，$roi = \\frac{\\Delta gmv}{\\Delta cost} = \\frac{\\int (f(t,\\vec{t})-f(t))\\cdot f\_{ans}(t)\\cdot asp dt}{\\int\_{t_1}^{t_2} f(t,\\vec{t})\\cdot f\_{ans}(t)\\cdot r dt + \\int\_{t_2}^{t_3} f(t,\\vec{t})\\cdot f\_{ans}(t)\\cdot 2r dt+ \\int\_{t_3}^{600} f(t,\\vec{t})\\cdot f\_{ans}(t)\\cdot 3r dt} $ 

# 三、求解过程

 由于线上红包发放时间可以及时更新，即可以只预测下一个红包最优发放时间；同时求解三个红包时间存在难度，故将$max$ $roi = \\frac{\\Delta gmv}{\\Delta cost}$ 进行分段化优化。   
即先优化$0-t_1$的第一个红包$roi$，再优化$t_1-t_2$的第二个红包$roi$，依此类推。   
由于$0-t_1$时间段没有愿等金发放，优化目标分别转化为：   
第一个红包$\\Delta gmv = \\int\_{0}^{t_1} (f(t,t_i)-f(t))\\cdot f\_{ans}(t)\\cdot asp$   
第二个红包$roi = \\frac{\\int\_{t_1}^{t_2} (f(t,t_i)-f(t))\\cdot f\_{ans}(t)\\cdot asp}{\\int\_{t_1}^{t_2} f(t,t_i)\\cdot f\_{ans}(t)\\cdot r}$   
第三个红包$roi = \\frac{\\int\_{t_2}^{t_3} (f(t,t_i)-f(t))\\cdot f\_{ans}(t)\\cdot asp}{\\int\_{t_2}^{t_3} f(t,t_i)\\cdot f\_{ans}(t)\\cdot 2r}$
