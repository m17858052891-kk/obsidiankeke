# 1 问题背景

## 1.1 什么是样本不均衡/长尾问题？

**长尾(Long-tailed)数据集**：少数类在数据集中占主体(head class), 而大多数类仅出现极少的样本(tail class)

由于数据样本数量的限制和样本极端不平衡的问题，长尾场景下尾部样本的识别效果差

## 1.3 产生这些问题的原因？

- 训练中每个batch中的多数类**出现频率**大于少数类 

- => **损失函数中的多数类的损失占主导**

- => **特征表征、分类器**均对多数类效果更好，即少数类在特征表征层面欠表征，分类器的边界更偏向于多数类

- => 模型效果（accuracy）在多数类上优于少数类

# 2 方法调研

## 2.1 训练阶段

### 2.1.1 数据增强 Data Augmentation

目标：增强模型对数据稀少（欠表征）类别的表征能力

1. **混合法 mixup based methods：**设计合适的样本选择和插值策略来修正有偏差的决策边界

mixup方法 融入先验知识：特征向量的线性插值应导致相关目标的线性插值，以此扩展训练分布

- 对随机选取样本的<u>线性插值</u>，丰富训练数据 $$\bar{x} = \lambda x_i + (1-\lambda)x_j, \ \bar{y} = \lambda y_i +(1-\lambda) y_j$$，$$x_i,y_i,x_j,y_j$$是 原始输入样本和标签，$$\bar{x},\bar{y}$$是生成的样本和标签

	- $$\lambda \sim Beta(\alpha,\alpha)$$ 

- manifold mixup: 在深度模型的特征空间的<u>隐藏层做 线性插值</u>

- Remix: 根据当前训练样本属于多数类/少数类来确定$$\lambda$$

- MixSMOTE: 当mixing up时 少数类有更大的几率被选中

![](https://s3-ep-inter.didistatic.com/didoc-upload-image-prod/17681001381520ca48ab9-5b9c-4500-8835-8573b473fee5/image.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKDD00000000000EBLCTZNRBJHX6ZS%2F20261104%2Fgzep%2Fs3%2Faws4_request&X-Amz-Date=20261104T093130Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=82e126fe5422a96a7015cea1fecc964cd7d4bb74f9643cf7366b112b4ac15cf4)![](https://s3-ep-inter.didistatic.com/didoc-upload-image-prod/1768100151310caf24e5a-0b3e-42c8-9ebc-12515017fa7c/image.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKDD00000000000EBLCTZNRBJHX6ZS%2F20261104%2Fgzep%2Fs3%2Faws4_request&X-Amz-Date=20261104T093130Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=88b97750994696082621c63e88169d56723d3899810a77cae04aee7de3dd6adf)

2. **GANs (generative adversarial networks)：**

通过**GAN生成**的方法，来增加少数类的样本多样性

具体有M2m, ImbalanceCycleGAN, MetaS-Aug, CAM-based sampling等方法，在此略过

缺点：使用GAN网络结构，计算开销大

> M2M: <https://openaccess.thecvf.com/content_CVPR_2020/papers/Kim_M2m_Imbalanced_Classification_via_Major-to-Minor_Translation_CVPR_2020_paper.pdf>

> ImbalanceCycleGAN: <https://arxiv.org/abs/2008.05524>

> MetaSAug: <https://arxiv.org/abs/2103.12579>

3. **半监督 semi-supervised learning：**

从相关的数据集中获得少数类样本，并通过半监督生成伪标签。这种半监督的方法可以减少标签的偏差

最大的问题是在少数类上的伪标签质量差

用类别均衡的采样来生成更准确的伪标签[[2105.00133] Semi-supervised Long-tailed Recognition using Alternate Sampling](https://arxiv.org/abs/2105.00133) 

CReST 提出了使用类别均衡采样的自监督方法来多次生成并训练模型的方法，来减少半监督的偏差 <https://arxiv.org/abs/2102.09559>

缺点：会受限于目标长尾数据集和辅助数据集之间的相关性

### 2.1.2 重采样策略 Re-sampling

随机采样时，类j的实例的采样概率为 $$p^I_j = \frac{n_j}{\Sigma_{i=1}^C n_i}$$，（C是种类数）（每个实例有相同的概率）

导致多数类主导了参数梯度下降的方向，因此模型在少数类上的效果差

重采样策略：在mini-batch中，调整类的采样概率，来降低mini-batch中样本的不均衡程度

### 2.1.3 损失函数策略 Cost-sensitive loss / Re-weighting

基于损失函数的方法，根据类别的频率、采样难度、到质心或类边界的距离等分配类别不同的权重，来校准交叉熵损失的偏差

这些方法通常是轻量级的，可以容易的在各种框架中实现。但是，在类别极端不均衡时，基于损失函数的方法若不结合其它重采样策略，效果将受限，因为在训练过程中尾部类极少出现。

### 2.1.4 多专家和迁移学习  Multiple experts and transfer learning

核心观点和方法总结：

- 在长尾数据集上，**模型在不同的采样策略下学到的知识会有差异**，因此将**运用不同采样策略的多个专家模型结合**，可以用来提高少数类的特征表征，改善模型的分类边界

- 长尾数据对模型的特征学习模块和分类器的训练有影响，**类别均衡采样法相对于实例均衡采样法有助于分类器的训练，但是有损于特征学习模块的训练。**因此**对不同的模块采用不同的采样策略**，并形成一个完整的端到端的训练流程

1. **bagging的方法**

最早就是结合RUS (随机欠采样）/ SMOTE 方法 和 bagging decision tree

**PT-bagging** (probability threshold bagging)

<https://arxiv.org/pdf/1606.08698>

结合bagging的集成方法和阈值移动的策略

**一句话概括**：使用bagging方法获得良好校准的后验估计，再根据最大化评估度量，合理地调整阈值

**流程**

Step1: bagging: 结合过采样和欠采样方法采样训练集，得到m个组，并学习得到m个分类器

Step2: 当测试时，对m个logits求平均，并计算最终的logit为 $$p(y=k|x)/p(y=k)$$, 其中$$p(y=k)$$可以用类别频率 $$n_k/\Sigma_{j=1}^C n_j$$估计

（阈值移动，阈值从0.5移动到$$0.5*p(y=k)$$）

为什么要**移动阈值**？

macro accuracy = (TPR + TNR)/2

为了最大化macro accuracy, 对类别k的最优阈值时该类的先验，即$$\lambda_k = P(y=k)$$(定理保证）

例如，在二分类场景中，对一个样本，多个分类器预测为类别0的平均预测概率是0.7，类别0的实例频率是0.8（$$P(y=0)=0.8$$)，那么类别0的最终分数是 0.7/0.8=0.875，类别1的最终分数是0.3/0.2=1.5，所以预测为类别1

**方法介绍**

- 用一个**双分支+Adapter**的网络结构，同时关注**表征学习和分类学习**；通过累积学习的策略，从学习**通用特征模式渐进转为学习尾部类的数据特征**

- 双分支包含Conventional Learning Branch(uniform sampler，原始数据分布)和 Re-Balancing Branch(Reversed Sampler，类别均衡分布)，分别负责表征学习和分类学习

- 两个分支的结果通过Adapter聚合，Adapter负责调节 trade-off 参数$$\alpha$$, 调整整个BBN网络先从原始数据分布中学习通用模式，再渐进专注于尾部类数据

- 数学公式描述过程

	- 两个分支的输入分别为 $$(x_c, y_c), (x_r, y_r)$$

	- 两个分支得到的特征向量分别为$$f_c\in \mathbb{R}^D, \ f_r \in \mathbb{R}^D$$，两个分支的特征编码（ResNet)除了最后一个模块外均共享参数

	- 记两个分支的分类器的权重分别为 $$W_c \in \mathbb{R}^{D\times C}, W_r \in \mathbb{R}^{D\times C}$$, 两个分支输出做加权得到logit为

$$z = \alpha W_c^Tf_c + (1-\alpha) W_r^Tf_r$$,

其中 $$z = [z_1, z_2, \cdots, z_C]^T \in \mathbb{R}^C$$ 是输出的预测，经过softmax函数后得到

$$\hat{p_i} = \frac{e^{z_i}}{\Sigma_{j=1}^{C}e^{z_j}}, \quad \hat{p} = [\hat{p_1}, \hat{p_2},\cdots, \hat{p}]^T$$

	- 对两个分支的加权损失函数 

$$\mathcal{L} = \alpha E(\hat{p}, y_c) + (1-\alpha ) E(\hat{p}, y_r)$$

- 预测时两个分支的输入相同，且$$\alpha = 0.5$$

## 2.2 推理阶段

通过**超参数校准logits分布**

认为在分类器的权重中，多数类有更大的权重因此有更大的分类边界，因此通过对**分类器的权重归一化来控制少数类的分类边界**

**WVN算法**

[Adjusting Decision Boundary for Class Imbalanced Learning](https://arxiv.org/pdf/1912.01857)

先用交叉熵损失、样本均衡采样来训练模型（不进行类别均衡的重采样）

**预测时**对分类器最后一层权重进行权重归一化，即 $$\forall i, w_i \leftarrow (\frac{n1}{n_i})^\gamma w_i$$,其中 $$n_1$$是最多数类的样本数量，$$\gamma \in (0,1)$$ 是超参数
