## 2.2 模型

### 2.2.1 历史版本模型

- V1、V2和V3使用逻辑斯谛回归模型，建模司乘对是否司乘履约 (is_od_finish) 的二分类问题。

- $$y=1/\{1+\exp[-(w_1x_1+w_2x_2+...+w_kx_k+b)]\}$$

### 2.2.2 本次迭代模型

- 建模司机履约和乘客履约两个任务。司乘分开建模，能够入模特征的意义更准确，例如接驾距离和单公里价格特征，在定义距离时可以区分司乘的视角。

- 使用Deep&Wide模型结构，对非司机差异化特征进行交叉和深度网络提取信息，为最终的逻辑斯谛回归输入有价值的信息。

	- Deep模块：包含乘客画像和供需画像

		- 乘客特征通过MLP提取得到乘客画像，供需特征联合订单特征通过MLP得到供需画像

		- 这些非司机差异化特征经过Deep模块，通过高维提取，为最终的Wide模块的训练输入有价值的信息（即逻辑斯谛回归中的b这一项)，优化可解释权重的学习

	- Wide模块：一层线性层。输入为司机特征、司乘特征<!--评论:[{"u":"rongbohui","c":"这个是哪些特征"},{"u":"dongtingdong","c":"是否连环派、指派模式、接驾距离、预估价等"}] -->、乘客画像、供需画像、订单特征。为保留可解释性，司机特征、司乘特征均保留原始形态，不会经过MLP变换。

- 输出模块：包括乘客履约率和司机履约率两个部分，等价于两个不完全独立的逻辑斯谛回归模型，共同决定PK打分。

### 3.2.2 改派次数对乘客取消的影响

在设计PK分中司机履约率和乘客履约率的权重时，出于「司机取消后存在改派，因此乘客履约率是决定完单和CR的决定性因素」的认知，我们倾向于增大乘客履约率的权重。但是考虑极端情况，如果完全不考虑司机的履约率，司机取消-改派次数的无限增多，一定会增加乘客的取消。

通过下钻各个组<u>不同司机取消-改派次数</u>下最后一单乘客取消率的变化，来看清司机取消-改派对乘客应答前/后取消的影响。

> 对于司机取消-改派单，乘客应答前/后取消其实只发生在最后一单，因此只需统计司机取消改派的最后一单

```PlainText
--应答前取消单的改派次数

with pas_tag as

            when group_name = 'treatment_group1' then 'treatment_group1'
            when group_name = 'treatment_group2' then 'treatment_group2'
            when group_name = 'treatment_group3' then 'treatment_group3'

    -- 改派2次

    count(distinct if(is_compete_call=1 and reassign_cnt >= 3 and is_grab_after_pas_cancel_without_reassign = 1, origin_order_id, null)) is_grab_after_pas_cancel_without_reassign_3
    
from (
    select 
        origin_order_id
        ,max(exp_group) exp_group
        ,max(b.passenger_id) passenger_id
        ,max(is_compete_call) is_compete_call
        ,count(distinct if(is_grab_after_dri_cancel = 1,order_id,null)) reassign_cnt --司机取消改派次数
        ,max(is_td_answer_without_reassign ) is_td_answer_without_reassign
        ,max(is_grab_after_pas_cancel_without_reassign) is_grab_after_pas_cancel_without_reassign
        ,max(case when reassign_desc_rn  = 1  and  is_td_answer = 1 then 1 else 0 end ) is_last_answer --最后一单是否应答（与实验评估中的应答保持一致）
        ,max(case when reassign_desc_rn  = 1  and  is_grab_after_dri_cancel = 1 then 1 else 0 end) as is_last_dri_cancel--最后一单司机含改取消
        ,max(case when reassign_desc_rn  = 1  and is_grab_after_pas_cancel_without_reassign  = 1 then 1 else 0 end) as is_last_pas_cancel_without_reassign --最后一单乘客不含改取消 
    from 
        pas_tag a 
        left join call b on a.pid = b.passenger_id
        left join unity_order c on b.order_id = c.order_id
        left join reassign d on b.order_id = d.order_id
    group by origin_order_id
)t
group by 
    t.exp_group
```

协变量选择依据
协变量只能用外生（不受实验处理影响）的变量来降方差，加入后点估计不应变动，只应让CI/P变小

考虑到：

- 指标服务计占比wgc订单频率是`is_wgc=1 AND csr_share>0.3` 的门控，csr_share 与cpm_share、sub_share、speed_share是耦合的，价格、补贴、车速的真实变化会改变各share的相对大小，从而影响哪些订单跨过0.3的阈值。所以服务计占比wgc订单频率相对价格/补贴的真实水平是敏感的

- 当前时间片实验是交易方向的时间片随机化，价格/补贴/车速没有在实验组、对照组强制保持一致，所以实验组、对照组的价格/补贴/车速可能不一样

分析价格/补贴/车速在实验组/对照组中是外生混杂还是中介变量：

- 将cpm_change,sub_change,speed_change作为协变量进行估计，发现点估计被搅动；进行组间平衡检查，发现两组间不平衡，因此价格/补贴/车速是中介变量。PK策略改变匹配，改变了市场供需，定价/B补随之反应，车速也被间接改变，是中介变量

- total_orders：两组平衡，加入后点估计几乎不变（−34.7% → −35.9%），而P值由0.11改善到0.06，是合格外生控制的特征，是干净的协变量
