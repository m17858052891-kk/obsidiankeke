## 三、选城过程

- 选城依据：用2025-12-01\~2025-12-21三周的全国城市数据，按照 1）平均接驾距离大于1500米，2）在全国订单份额0.5%～5%，3）大于2000米订单的应答后c取消率大于0.17 这三条标准进行实验选城

```SQL
select 
a.start_city_id,
c.city_name,
avg(driver_start_eda) as avg_eda,
sum(case when driver_start_eda >= 2000 then is_grab_after_pas_cancel else 0 end) / sum(case when driver_start_eda >= 2000 then 1 else 0 end) as over_2000_cancel,
sum(case when driver_start_eda < 2000 then is_grab_after_pas_cancel else 0 end) / sum(case when driver_start_eda < 2000 then 1 else 0 end) as below_2000_cancel,
sum(case when driver_start_eda >= 2000 then 1 else 0 end)/count(*) as ratio,
count(*) as order_cnt,
sum(case when is_td_finish = 1 then 1 else 0 end) as finish_cnt

from 
(
    select distinct
        start_city_id,
        order_id,
        driver_start_eda
    from kflower_dw.dwm_kf_trd_unity_trade_funnel_order_anycar_di

    where dt between '2025-12-01' and '2025-12-21'
        and channel_name = '花小猪打车'
        and is_td_answer = 1
)a --端内应答单
left join 
(
    select distinct
        order_id,
        is_grab_after_pas_cancel,
        is_td_finish
    from kflower_dw.dim_kf_trd_unity_order_label_di
)b on a.order_id = b.order_id --c取消label
left join 
(
    select distinct 
        city_id,
        city_name
    from kflower_app.dm_kf_trd_unity_trade_funnel_plat_mode_di
    where dt = '2025-12-01'
)c on a.start_city_id = c.city_id 
group by 1,2
```

- 结论：一二期实验效果差异原因有**整体供需差异和选城因素**

**选城1月和12月测算结果对比**

Q：一期二期实验效果差异是由于一期和二期**实验选城差异**吗，或者说二期选城的合理性？

A：**二期实验城市从测算周期（1201～1221）到实验周期（0110～0116）发生了比较大的变化，相比大盘受周期影响更大**。即使按照同样的选城标准，这批城市在实验周期的表现在某些指标上不如大盘（比如2km以上的取消率比大盘城市低）。**所以从实验周期的数据表现来看这批城市可能并不是最合适的选城，这是由于测算周期和实验周期的gap导致的结果。**
