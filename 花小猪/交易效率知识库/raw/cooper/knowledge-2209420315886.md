# ocr模型迭代


# 背景

- **本文目的：看ocr模型在等待时间分桶上的分布，本文核心探讨在距离分桶上什么样的caa分布是合理的。**

业务理解

不同供需 供需越差 能找的距离更远

# v0模型

模型架构

静态塔使用除 `wait_time` 外的全部特征，经 BatchNorm 和 MLP 提取表示；这里的“静态”仅指排除了等待时间。时间塔将等待时间的线性缩放值、对数缩放值和分桶 Embedding 拼接后输入 MLP，默认分桶边界为 6、12、18、30、45、60 秒。交互塔拼接静态表示、时间表示，以及静态表示与投影后时间表示的逐元素乘积，学习不同样本对等待时间的不同反应。

最终 `p = sigmoid(静态塔得分 + 时间塔得分 + 交互塔得分)`，使用 BCE 训练。相对 V0，核心变化是让等待时间有独立表达通道，避免其影响被其他特征淹没；类别 ID 仍作为数值归一化处理，模型也仍不保证等待时间单调性。

# v1模型 约束单调性

将 V1 的时间塔和交互塔替换为显式的正斜率时间项。类别特征改为逐列独立 Embedding，非法或越界 ID 映射到专门的未知类别；数值特征经 BatchNorm 后，剔除等待时间，与类别向量拼接进入静态 MLP。静态表示分别生成基础得分和时间斜率，斜率通过 `softplus + 最小斜率` 保证为正。

输出公式为 `p = sigmoid(基础得分 + 正斜率 × wait_time / 60)`，其中 60 为默认时间缩放值。基础得分和斜率都由其他特征决定，等待时间仅在最后线性加入得分。推理时固定其他输入，预测概率随等待时间单调上升；线性约束作用于 sigmoid 前的得分，概率本身仍是曲线。训练使用 BCE。

相对 V1，核心变化是从自由学习时间关系改为结构性单调约束，同时用 Embedding 替代类别 ID 的数值化处理。`main_mild.py`、`main_strong.py` 复用同一个模型，分别将最小斜率设为 0.5、1.0，属于约束强度配置变化。

# v2模型 增加最大值截断

沿用上述 Embedding、静态 MLP 和正斜率时间项，唯一核心架构变化是输出改为 `p = min(sigmoid(得分), 0.8)`，将预测概率硬截断到最高 0.8。

固定其他输入时，输出随等待时间单调不减，但达到 0.8 后保持不变。封顶在模型前向计算中生效，因此训练也使用截断后的概率计算 BCE，超过上限的部分通过截断操作回传的梯度为零。

# v_static模型 静态

对应 `model.py`，是固定概率基线：每个样本始终输出 `static_ocr`，默认值为 `0.053`（5.3%），不依赖输入特征或等待时间。模型参数支持配置该常数，当前 `main.py` 固定使用 0.053。

相对 V2，移除了 Embedding、MLP 和时间单调项，不再学习样本差异，直接生成形状为 `[批大小, 1]` 的常数输出。保留原有模型接口和 BCE 损失，并保留一个乘以零的可训练参数，以兼容要求模型包含参数的训练、导出工具；该参数不会改变预测结果。
