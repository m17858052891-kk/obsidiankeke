> 选城原则：1. 份额在 0.2%-4.5%中间，2. CR没有很高

城市列表为：


==城市名：广州市、杭州市、武汉市、济南市、青岛市、大连市、合肥市、成都市、重庆市、长沙市、南昌市、绵阳市、吉林市 、金华市、莆田市==

数据统计：by城市统计：接驾远的占比、接驾远的应答后乘客取消率和非接驾远的应答后乘客取消率及对应差值、城市订单占比

```PlainText
with
base as 
(
    select  *
            ,if (lumian_dis > 3000 and is_finish = 1, 1, 0) as far_finish
            ,if (lumian_dis > 3000 and is_finish != 1, 1, 0) as far_notfinish
            ,if (lumian_dis <= 3000 and is_finish = 1, 1, 0) as notfar_finish
            ,if (lumian_dis <= 3000 and is_finish != 1, 1, 0) as notfar_notfinish
    from    kflower_strategy.pk_hxz_modeling_data
    where   dt between '2025-04-24'
      and   '2025-04-30'
      and   is_finish is not null
      and   class in ('完单', '乘客取消')
)
select  city
        ,(sum(far_finish) + sum(far_notfinish)) / count(*) as far_ratio
        ,sum(far_notfinish) / (sum(far_notfinish) + sum(far_finish)) as far_notfinish_ratio
        ,sum(notfar_notfinish) / (sum(notfar_notfinish) + sum(notfar_finish)) as notfar_notfinish_ratio
        ,sum(far_notfinish) / (sum(far_notfinish) + sum(far_finish)) - sum(notfar_notfinish) / (sum(notfar_notfinish) + sum(notfar_finish)) as far_minus_notfar_cancel_delta
        ,count(*) as order_count
from    base
group by city
;
```
