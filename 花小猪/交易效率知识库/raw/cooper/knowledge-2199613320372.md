- cancel_type 和 order_status 的区别和联系

	- cancel_type 是取消类型：1:应答前取消 2:应答后乘客取消 3:应答后司机取消 4:应答后客服关单 5:系统取消（快车排队场景，勾选“同时匹配拼车”，匹配成功会自动取消快车单场景） 0:其他取消类型

	- order_status 是订单状态：  
0 未抢单（订单发出后，默认状态为0），1 已抢单，2 已到达接乘客，3 乘客上车(业务已下线)，4 开始计费，5 订单结束计费，6 抢单前取消（乘客），7 抢单后取消（乘客），8 已改派（业务已下线该状态），9 乘客和司机协商时间，乘客拒绝后订单状态（业务已下线该状态），10 乘客和司机协商时间，司机超时（业务已下线该状态），11 客服关闭，12 未能完成服务状态

	- order_status = 5 != is_td_finish = 1，因为订单只要有状态变化就会记录，一天内多次变化只记录最后一次的订单状态，可能订单在之前完单，但是今天付款，所以就会出现这种情况

	- order_status = 12但是cancel_type不一样

		- order_status = 12 且 cancel_type=0 代表订单改派 (如果is_td_reassign=0，则为第二天改派）

		- order_status = 12 且 cancel_type=3 代表订单未改派

			- cancel_type=3 且 order_status = 0 代表本订单为改派后的订单，未应答，记为source_type=2，原始订单被司机取消，但是记为is_td_cancel=0

			- 在业务指标中，因为cancel_type=3也会记录在改派后的订单中，所以不能用source_type<>2进行过滤，在模型训练中，无论是否继续改派都应该视为司机的取消行为

		- order_status = 12 且 cancel_type=5 发生补勾行为的订单，被系统取消

            complete_type not in (7, 13)

            source_type = 2

    when substr(if(order_status = 7, cancel_time, update_time), 1, 10) = '${V_1DAYAGO}'

    when substr(if(order_status = 7, cancel_time, update_time), 1, 10) = '${V_1DAYAGO}'
    and complete_type = 13
    and order_status = 12 then 5 --系统取消（快车排队场景，勾选“同时匹配拼车”，匹配成功会自动取消快车单场景）

--取消类型

```PlainText
select
    brt.order_id,
    brt.driver_id,
    (
        case
            when is_td_finish = 1 then 0
            else 1
        end
    ) label
from
    (
        select
            cast(param ['lowoid'] as bigint) as order_id,
            cast(param ['driverid'] as bigint) as driver_id
        from
            kflower_ods.ods_log_kflower_orderbroadcast
        where
            concat_ws('-', year, month, day) = '2021-04-06'
            and cast(param ['driverid'] as bigint) > 0
            and cast(param ['lowoid'] as bigint) > 0
            and cast(param ['DispatchType'] as bigint) in (1, 2, 3)
    ) brt
    left join(
        select
            order_id,
            driver_id,
            order_status,
            cancel_type,
            is_td_answer,
            is_td_finish
        from
            kflower_dw.dwd_kf_trd_order_base_di
        where
            dt = '2021-04-06'
            and is_td_call = 1
    ) base on base.order_id = brt.order_id
    and base.driver_id = brt.driver_id
```
