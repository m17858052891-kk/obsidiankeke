# 无单理由

## 司机连边情况

- 司机是否会找订单较多的地区

背景：存在订单连不到边而折损的情况，从司机的角度出发，试图通过探索司机平均连边情况寻找方向优化司机平均连边数，进而达到减少订单折损的占比。

衡量指标：司机平均每轮的连边数。

现状：大部分司机的连边数在2个以内， 占比**90%**以上。  
分析方向：连边数越多司机被播出的概率越大，是否可以提升司机的半径来提升连边数。

司机多端多开

在同一轮次下同意车主不同司机id被播单的占比约为0.11%by日、0.14%by周、0.16%by月

```SQL
with
broadcsat as 
(
    select  cast(param['uuid'] as string) as uuid	-- uuid
            ,cast(param['orderid'] as bigint) as order_id
            ,cast(param['driverid'] as bigint) as driver_id
    from    kflower_marketplace.ods_log_kflower_orderbroadcast_hh
    where   concat_ws('-', year, month, day) between date_sub('${BIZ_DATE_LINE}', 29)
      and   '${BIZ_DATE_LINE}'
)
,driver_detail as 
(
    select  cast(topic_msg['driverId'] as bigint) as driver_id
            ,cast(topic_msg['plate_no'] as string)as plate_no
    from    kflower_marketplace.kflower_honghu_driver_detail
    where   concat_ws('-', year, month, day) between date_sub('${BIZ_DATE_LINE}', 29)
      and   '${BIZ_DATE_LINE}'
)
select  ord_cnt
        ,count(distinct uuid) as uuid_cnt
from    (
    select  uuid
            ,plate_no
            ,count(distinct order_id) as ord_cnt
    from    broadcsat a
    left join driver_detail b
    on      a.driver_id = b.driver_id
    where   plate_no is not null
    group by uuid, plate_no
) a
group by ord_cnt
```
