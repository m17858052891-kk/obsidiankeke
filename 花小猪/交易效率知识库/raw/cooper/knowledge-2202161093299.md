### 背景

等待应答页ETA模型预估误差相对较大(半分钟左右)，不能满足大盘超时赔的诉求，尤其是极端bad case(模型预估时间小于实际应答时间X分钟)率较高,对超时赔等业务有较大影响。

### 核心收益

通过对深度模型损失函数以及模型输出优化将等待应答页及特快盒子应答时间预估MAE显著降低，同时评估了基于XGB的预估效果，相较于V1版深度模型也有较大提升。

训练集周期为4.8-4.14，测试集周期为4.15-14.21，各版本模型MAE对比如下

| 业务场景 <br> | 深度模型V1 <br> | 深度模型V2 <br> | XGB <br> |
| --- | --- | --- | --- |
| 等待应答页 <br> | 0.362 <br> | 0.286 <br> | 0.292 <br> |
| 特快盒子 <br> | 0.283 <br> | 0.251 <br> | 0.254 <br> |

### 模型优化

**V2版本对深度模型的优化主要为以下几个环节：**

1. 将损失函数由MSE更改为HuberLoss，提升了模型对异常值的鲁棒性；

```PlainText
def huber_loss(labels, predictions, delta=1.0):
        residual = tf.abs(predictions - labels)
        condition = tf.less(residual, delta)
        small_res = 0.5 * tf.square(residual)
        large_res = delta * residual - 0.5 * tf.square(delta)
        return tf.where(condition, small_res, large_res)
```

2. 将深度模型输出加一层Relu函数做截断，保证了模型输出的非负性；

```PlainText
 def get_output(data):
    return tf.nn.relu(tf.reduce_sum(data,axis=-1))
```

3. 增加了部分特征交叉，发单一圈及两圈格子的近5分钟平均应答时长均值作为特征；

**V3版本深度模型增加了GDCN特征交叉模块，引入门控机制对特征进行交叉筛选，更充分利用特征信息；**

```PlainText
class GateCorssLayer(tf.keras.layers.Layer):
    #  The core structure： gated corss layer.
        def __init__(self, input_dim=70, cn_layers=3):
            super(GateCorssLayer, self).__init__()

            self.cn_layers = cn_layers

            self.w = [tf.keras.layers.Dense(units=input_dim) for _ in range(cn_layers)]
            self.wg = [tf.keras.layers.Dense(units=input_dim) for _ in range(cn_layers)]

            self.b = [K.random_uniform((input_dim,), minval=-0.05, maxval=0.05) for _ in range(cn_layers)]

            self.activation = tf.nn.sigmoid

        def call(self, x):
            x0 = x
            for i in range(self.cn_layers):
                xw = self.w[i](x) # Feature Crossing
                xg = self.activation(self.wg[i](x)) # Information Gate
                x = x0 * (xw + self.b[i]) * xg + x
            return x
```
