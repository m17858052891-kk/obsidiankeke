# CBA建模

# 一、背景

在流量分发、召回、PK、乘客引导四个阶段实现交易价值统一（完单最大化），在O选D时需要建模应答前乘客取消CBA

# 二、问题

- 目标：在没有策略干预（无应答）下，乘客应答前取消概率 CBA(p,t)

- 建模维度：乘客p，发单后等应答时间t

- 有效数据：

	- 应答前取消样本：应答前取消时长

	- 应答样本：应答时长

- 建模难点：

	- 样本删失。当前应答率84%，对于应答的订单，缺少不应答时的应答前取消时长

	- 不是一个二分类问题，需要考虑时间维度。模型需要在流量分发、分单、PK、乘客引导不同阶段生效，且需要在不同轮次生效，因此需要考虑已等待时间

# 三、建模

由于样本删失，使用**生存分析方法**，建模**乘客在时间t前没取消的情况下的瞬时取消风险** $$\lambda(t) = \lim_{\delta \rightarrow 0} \frac{P(t\leq T < t+\delta)}{\delta}$$

> 生存分析中的符号设定

采用**Cox比例风险模型** $$\lambda(t,x) = \lambda_0(t) \cdot e^{h(x)}$$。其中，

- $$\lambda_0(t)$$是<u>风险基线</u>，代表所有乘客应答前取消的风险趋势，只与时间有关。尝试对数据进行多项式、指数分布、威布尔分布、对数逻辑分布的拟合，尝试Nelson‑Aalen

- $$h(x)$$建模<u>乘客的应答前愿等弹性</u>，使用深度模型预测，$$h(x)=h(p,o)$$ 特征$$x$$包含乘客特征$$p$$和订单特征$$o$$。实质是做**排序**，对订单在（发单后应答前）相同等待时间下进行风险排序（下文会详细介绍模型）；

- 最终订单随着发单后等待时间的乘客应答前取消风险  $$\lambda(t,x) = \lambda_0(t) \cdot e^{h(x)}$$

值得注意的是，这样建模有一个**强假设：乘客愿等弹性不随时间t变化**，即 $$h(x,t)=h(x)$$与时间t无关

那么，对于两个乘客（订单）$$x_1, x_2$$，它们的应答前取消风险比 $$HR = \frac{\lambda(t,x_1)}{\lambda(t,x_2)} = e^{h(x_1)-h(x_2)}$$与时间无关

## 2、乘客愿等弹性的深度模型建模 $$h(x)$$

**数据形式**

$$(x, T, E)$$

- $$x$$: 特征（要求特征不随时间变化）

- $$T: 生存时间,\ T=应答前取消时长，若乘客取消； T=应答时长，若司机应答$$ 

- $$E: 事件指示符, \ E=1，若乘客取消；E=0，若司机应答$$

**特征**

- 乘客画像，例如性别、年龄、累积100单-完单率等，来源表：  kflower_strategy.dm_user_common_behavior_stat

- 乘客历史应答前取消行为，例如近3天应答前取消时长均值，来源表： kflower_strategy.pas_cba_history（新建）

- 订单特征 

**模型结构**

深度模型即可，略

**损失函数**

为了进行Cox回归，可以用偏似然函数来对模型参数$$\theta$$进行优化 

$$L_c(\theta) = \prod\limits_{i: E_i = 1} \frac{\exp(h_\theta (x_i))}{\sum\limits_{j\in \mathcal{R}(T_i)}\exp(h_\theta (x_j))}$$

$$T_i, E_i, x_i$$分别对应第i个个体的生存时间、事件指示符、特征，$$\mathcal{R}(t) = \{i: T_i \geq t\}$$代表**风险集，刻画在t时刻仍然面临取消风险的个体**（即仍然在未应答且未取消的订单）

模型的损失函数设为负的log偏似然函数

$$l(\theta) = - \sum\limits_{i:E_i = 1}(h_\theta (x_i) - \log \sum\limits_{j\in \mathcal{R}(T_i)}\exp(h_\theta (x_j)))$$

这里的$$h_\theta(x_i)$$没有真值，损失函数的**优化目标是让‘取消’事件发生个体的风险函数在它对应的风险集中是最高的**。即当$$E_i=1$$发生时，个体i的取消概率应是当前依然未应答中且未应答的个体中最高的

**评估指标**

- C-index: ==Concordance index一致性指标。将研究数据两两组成pair，对于每一对‘病人’，如果生存时间较长的一位预测生存时间也较长，则称为预测结果与实际结果一致。 C-index = 一致的pair / 所有pair==

- ==Time-ROC曲线和时间依赖AUC：==

	- ==Time-ROC曲线为时间的函数，ROC(t)，在多个预设时间点t上分别绘制ROC曲线，每个时间点t下的预测样本空间是当前未删失的样本（正例：已死亡，负例：仍存活且未删失）==

	- ==Time-ROC曲线下的面积即为时间依赖AUC==
