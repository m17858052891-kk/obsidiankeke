# 一、需求背景（*）

* 曹操、哈罗、首汽、阳光已经接入预分单，每天规模为2w单；

* 预分单在乘客已勾选范围内无运力的情况下，给乘客提供额外的出口，对乘客、平台、商家三方都是有利的策略

* 现在需要推动之前没有接入的商家【享道、如琪、T3】接入预分单

 

# 二、需求类型归纳（*）

* 已有能力，扩展商家范围

# 三、需求收益判断（*）

* 预分单是在乘客没有勾选指定商家、且当前勾选范围内未应答的情况下，额外提供运力应答，根据以往实验带来的规模80%为纯增量；

* 按照运力规模换算，新增【享道、如琪、T3】三家带来的预分单规模为0.5 * 2w = 1w/天；

* 按照运力规模、升舱C补换算，新增【享道、如琪、T3】三家带来的升舱规模为4.3% * 20w * 2/3 = 5.7k/天；

# 四、需求说明和功能点（*） 

1、【享道、如琪、T3】接入小猪端预分单能力

2、【享道、如琪、T3】接入小猪端升舱能力

# 五、需求通用属性（*）

1. 覆盖范围:

   1. 生效范围：小猪端

   2. 生效商家：享道、如琪、T3

2. 前置依赖

   1. 无

 

# 六、效果评估方案

* 评估方案

   * AB实验，乘客id分流

* 预期收益：

   * 预分单：人均完单+0.2%

   * 升舱：人均完单+0.1%

* 收益评估指标：

   * 人均完单，人均GMV

* 预计初步效果时间：
