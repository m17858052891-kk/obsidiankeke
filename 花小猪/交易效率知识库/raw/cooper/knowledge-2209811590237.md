# 低胜率画像分析

1、竞争胜率与接驾距离关系？

在竞争胜率低分段，接驾距离确实呈现负向信号。但为什么竞争胜率>=0.8时，距离又会更高？进一步发现，这并不代表长距离提高胜率，验证原数据真实胜出标签也发现该特点，且这些长距离高胜率OD集中在“长等待、供给少、供需紧张和不同派单类型中”，符合预期。

2、策略必要性？与当前召回策略的重叠程度？

- 现有召回策略并没有在总体上优先过滤低胜率分数，主要过滤的是长接驾距离候选。

- 从订单维度而言，也可以发现低竞争胜率订单反而通过率更高。

- 同竞争胜率分桶，可以发现过滤掉的OD接驾距离确实明显大于策略未过滤的OD。

3、当前竞争胜率模型胜出画像？低分画像？

- 高分画像：

	- 轮次分单高竞争胜率往往对应更长距离（订单长等待、供需紧张），TopSpeed分单高胜率对应更短距离；

- 低分画像：【等待时间短、供给充足、且长接驾距离】

	- 自营极速分单、宏鹄极速分单（接驾距离越长，GS分数更低）；

	- 订单刚进入派单阶段，等待时间短；

	- 周围空闲司机多，供需相对宽松；

	- 全指派订单（低分组中全指派比例占88%，而高分组全指派降为50%）

4、最终结论

==由于当前存在长距离但竞争胜率高（供需紧张）的情况，即当前距离策略对这些长距离订单存在误伤。故低分过滤策略综合考虑可以定为：==`**==gs_value < 0.1 且 lumian_dis >= 500 ==**`
