## 背景

目前，在**极差应答场景**下，呼返（包括平台呼返、自营呼返和鸿鹄呼返在内的所有呼返C补）已建立熔断机制，且上线后观察效果符合预期，在实时运力无法承接的短时呼叫高峰，通过下掉呼返，实现一定程度上的呼叫抑制。我们认为在这样的场景下，对于滴滴的展示与发单hold可以进行联动，通过呼叫抑制与运力释放共同实现本场景下提升成交率的总体目标。

## 技术方案

<https://dufe.intra.hongyibo.com.cn/templates/1430>

通过flng,flat取

grid_1circle_last_5min_anycar_start_order_cnt_kf和grid_1circle_last_5min_anycar_start_answer_order_cnt_kf

通过city取

kf_low_answer_fuse_max_call_cnt和kf_low_answer_fuse_min_ar

当grid_1circle_last_5min_anycar_start_order_cnt_kf **>** kf_low_answer_fuse_max_call_cnt 且

grid_1circle_last_5min_anycar_start_answer_order_cnt_kf/grid_1circle_last_5min_anycar_start_order_cnt_kf **<** kf_low_answer_fuse_min_ar时

熔断的策略是：乘客冒泡时刻，实时获取每个冒泡的**中心格子及格子周围一圈格子过去5分钟**发单数**和**应答数

在满足发单数超过阈值**且**应答率（应答数/发单数）低于阈值的情况下，**触发熔断**；

其中发单数阈值和应答率阈值分城市、天级别产出至离线表后导入线上

流量分发联动策略需要做到：

1、在冒泡环节，在满足熔断的两个条件之下，小猪端滴滴车型**在首页与等待应答页同时露出**（无论线上策略是如何露出），同时勾选策略保持与线上相同不变

2、在发单环节，在满足熔断的两个条件之下，**小猪端滴滴车型hold时长为4秒**（无论线上策略计算出来的值为多少）

with t as (
    select
        concat_ws('-', year, month, day) dt,
        shiftleft(
            shiftright(cast(param ['order_id'] as bigint), 46) & 262143,
            32

        and '${BIZ_DATE_LINE}'
        and param ['is_pbd'] = 'false'

),
bad_ans as (
    select
        `time`,
        grid_id
    from
        t
    where
        is_bad_ans = 1
    group by
        `time`,
        grid_id
),
bubble as (
    select
        trace_id,
        passenger_id,
        is_from_waiting_response,
        bubble_id,
        product_2level,
        product_2level_name,
        selected_status,
        city_id,
        bubble_time,
        from_unixtime(
            unix_timestamp(bubble_time),
            'yyyy-MM-dd HH:mm:00'
        ) `time`,
        case
            when substr(cast(passenger_id as string), -1, 1) in ('6')
            and substr(cast(passenger_id as string), -2, 1) in ('5', '6', '7', '8', '9') then '空白组'
            when substr(cast(passenger_id as string), -1, 1) in ('5', '7', '8', '9') then '现状组'
            when substr(cast(passenger_id as string), -1, 1) in ('2', '3', '4') then '差应答释放组'

bub as (
    select
        bubble.*
    from
        bubble
        join bad_ans on bubble.start_grid = bad_ans.grid_id
        and bubble.`time` = bad_ans.`time`
),
call_log as (
    select
        a.order_id,
        a.estimate_id,
        a.product_2level
    from
        (
            select
                order_id,
                estimate_id,
                product_2level
            from
                kflower_dw.dwd_kf_trd_order_create_base_di
            where
                dt between '2023-02-15'
                and '${BIZ_DATE_LINE}' 
                and source_type <> 2
            union all
            select
                order_id,
                estimate_id,
                product_2level
            from
                kflower_dw.dwd_kf_trd_order_append_di
            where
                dt between '2023-02-15'
                and '${BIZ_DATE_LINE}'
                and log_type = 2 
        ) a
        left join (
            select
                order_id,
                product_id,
                estimate_id,
                is_compete_call,
                is_objective_call,
                is_platform_objective_call

        dt,
        product_2level,
        passenger_id,
        order_id,
        finish_cnt_1d_1028 as is_td_finish
    from
        kflower_dw.dwm_kf_trd_order_index_di

        dt between '2023-02-15'
        and date_add('${BIZ_DATE_LINE}',1)
),

    select
        bub.passenger_id,
        exp_group,
        count(distinct call_log.order_id) as call_all,
        count(
            distinct case
                when ord.is_td_finish = 1 then call_log.order_id
                else null
            end
        ) as finish_all,
        count(
            distinct case
                when call_log.product_2level in (80, 81, 82) then call_log.order_id
                else null
            end
        ) as call_zy,
        count(
            distinct case
                when call_log.product_2level not in (80, 81, 82, 384) then call_log.order_id
                else null
            end
        ) as call_sf,
        count(
            distinct case
                when call_log.product_2level in (384) then call_log.order_id
                else null
            end
        ) as call_didi,
        count(
            distinct case
                when (
                    ord.is_td_finish = 1
                    and ord.product_2level in (80, 81, 82)
                ) then ord.order_id
                else null
            end
        ) as finish_zy,
        count(
            distinct case
                when (
                    ord.is_td_finish = 1
                    and ord.product_2level not in (80, 81, 82, 384)
                ) then ord.order_id
                else null
            end
        ) as finish_sf,
        count(
            distinct case
                when (
                    ord.is_td_finish = 1
                    and ord.product_2level in (384)
                ) then ord.order_id
                else null
            end
        ) as finish_didi
    from
        bub
        join call_log on bub.bubble_id = call_log.estimate_id
        and bub.product_2level = call_log.product_2level
        left join ord on bub.passenger_id = ord.passenger_id
        and call_log.order_id = ord.order_id
    group by
        bub.passenger_id,
        exp_group
)
select
    exp_group,
    sum(1) as N,
    sum(call_all)/sum(1) call_all,
    sum(finish_all)/sum(1) finish_all,
    sum(call_zy)/sum(1) call_zy,
    sum(finish_zy)/sum(1) finish_zy,
    sum(call_sf)/sum(1) call_sf,
    sum(finish_sf)/sum(1) finish_sf,
    sum(call_didi)/sum(1) call_didi,
    sum(finish_didi)/sum(1) finish_didi
from 
    raw
group by
    exp_group
having 
    exp_group is not null
order by
    exp_group;
