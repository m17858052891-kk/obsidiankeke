# 一、背景

商家召回策略V1.0当前已完成完整实验，逐步放量中，但主要缺乏对播单 -> PK -> 完单中的PK关于竞争胜率的漏斗，导致实际value价值判断中并未考虑所选择OD的竞争胜率，缺乏对完单期望的整体估计。

# 二、目标与收益

### **核心目标**

> **在三端整体完单不负的条件下，提升端内完单+0.1%**

### **收益预估：**

过滤端外低胜率画像OD（约占总举手2%），使这些司机资源有机会参与更优订单举手，通过司机资源腾挪的方式提升端内完单量。

# 三、需求及工程要求

过滤掉端外流量中竞争胜率gs_value < 0.1且接驾距离>= 1000m的候选OD。
