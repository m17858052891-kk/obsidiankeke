# AR模型

by品牌的AR，如果第一个品牌AR是锚点价格内的最高，则不折叠

如果第二个品牌AR是锚点价格内的最高，则只考虑不折叠 和 折叠第一个品牌的情况

如果第三个品牌AR是锚点价格内的最高，则只考虑不折叠 和 折叠第一个品牌 折两个品牌的情况

# 品牌AR预测

默勾AR模型前置，预测每个品牌的AR，按价格排序

对于盒子的AR，整合计算，盒子$$AR=\prod_{i=1}^n(1-AR_i)$$，其中ARi是盒子中品牌的预估AR

提前过滤：

若最低价品牌的AR最高，则不做折叠

得到

若默勾数为1，2，3时，只需考虑1到默勾的品牌

# 预估本单AR

我们设预估AR=\[AR1,...ARn\]，勾选比例=\[S1,...,Sn\]

则$$AR=\frac{\sum_{i=1}^{n} (S_i)[1-\prod_{j=1}^{i}(1-AR_j)]}{\sum_{i=1}^{n} (S_i)}$$
