# 拟合公式

log(CR/(1-CR)) = density_coef \* log(密度) + sod_coef \* log(供需比) + intercept，其中density_coef，sod_coef，intercept三个参数可以通过查字典获取。

# Note

**密度** 展开源码

```PlainText
select
    city_id,
    dt,
    density as hxz_density
from
    kflower_marketplace.top_grids_city_hxz_day
where
    dt between '2020-06-01'
    and '2020-11-24'
```

**供需比** 展开源码

```PlainText
供需比 = 司机TSH总和 ／ 订单数


TSH总和：
select
    dt,
    city_id,
    sum(online_dur) as hxz_tsh
from
    kflower_dw.dwm_kf_dri_online_di
where
    dt between '2020-06-01'
    and '2020-11-24'
group by
    dt,
    city_id


订单数：
select
    dt,
    start_city_id as city_id,
    count(distinct order_id) as hxz_need_cnt
from
    kflower_dw.dwd_kf_trd_order_base_di
where
    dt between '2020-06-01'
    and '2020-11-24'
    and is_td_call = 1
    and source_type <> 2
    and call_time is not null
group by
    dt,
    start_city_id
```
