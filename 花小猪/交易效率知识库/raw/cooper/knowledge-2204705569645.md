# 1、背景

由体验侧分析，发现应答长时间后被司机取消的订单占比较高，且这部分取消对乘客留存伤害最重

由平台侧推动，在分单和PK考核中加重对司机长时取消行为的惩罚，通过可解释透传机制降低此类行为的发生频率

目标：约束大盘完单不负，降低司机诱导取消率、司机恶意取消率

# 2、技术方案

特征建设：建设司机近14天加权取消数特征，对司机超过4分钟以上的取消（不含司机真实到达上车点且乘客迟到的情况）作线性加权

- 加权程度：4分钟开始加权，4分钟加权至1.5倍，10分钟加权至3倍，最高加权至4倍

模型建设：利用建设好的司机近14天加权取消数特征，替换原先未加权的司机取消数特征，重复PK模型的建模链路

# 3、实验评估
