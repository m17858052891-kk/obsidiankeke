# 一、需求简述

- **背景**：商家召回重构 V1.0 重新定义了召回问题，将 TP、GS 和 HOLD 纳入期望完单的统一价值框架。经过三期实验，方案取得了商家大聚合完单及部分接驾效率收益，但也暴露出两类**问题**：

	- **目标表达不清晰**：V1.0 从最大化期望完单出发，实验中为降低距离又在 CAA 模型内加入距离加权。预测模型同时承担风险预测和业务目标调节，后续目标变化时难以持续调整，也不便解释决策原因。

	- **场景调节不足**：端内/端外、连环派/非连环派共用的价值调节能力不足。尤其在连环派场景，乘客视角接驾距离为 \\(ab+bc\\)，司机视角接驾距离为 \\(bc\\)；即使期望完单和乘客视角距离相同，司机效率收益也可能不同，现有公式没有显式表达这一区别。

- **需求**：V1.1 沿用 V1.0 的 TP、GS、HOLD 决策架构，**以最大化期望完单为基础目标，增加乘客视角和司机视角的接驾距离约束，并通过拉格朗日转换，将约束推导为可比较的召回价值。约束目标及其决策强度支持按端内/端外、连环派/非连环派配置**。

# 二、目标与收益

## 2.1 目标

- **核心目标**：花小猪端内乘客 ETP＋司机接驾时长降低 1%。

- **业务约束**：花小猪端内整体完单不显著负向

- **能力目标**：建立可按端内/端外、连环派/非连环派调节的召回价值框架。后续业务目标变化时，可通过调整价值约束及参数迭代策略，而不必将新的业务偏好写入 CAA 模型。

## 2.2 预期收益链路

- **双视角距离进入召回决策，改善接驾效率**：在期望完单基础上，显式约束乘客视角和司机视角接驾距离，使召回决策能够区分“完单价值相近、接驾成本不同”的候选。预期减少高接驾成本的无效召回，改善后续应答单的接驾距离与司机接驾时长。

- **识别连环派的司机效率价值**：连环派的乘客视角接驾距离为 \\(ab+bc\\)，司机视角为 \\(bc\\)。分别约束两种距离后，策略可以识别乘客接驾体验相近、但司机实际接驾成本不同的候选，改善连环派与非连环派的选择，而无需直接以提高连环派份额为目标。

- **分场景调节，控制收益分布**：按端内/端外、连环派/非连环派配置距离目标和调节参数，针对不同场景调整召回强度与候选选择。预期在保留整体效率收益的同时，缓解 V1.0 实验中端内完单承压、端内外收益分布不均的问题。该效果需通过分场景漏斗和最终时间片实验验证。

- **预测与目标解耦，提升后续迭代效率**：CAA 模型负责预测取消风险，距离目标在价值公式中表达。后续业务目标变化时，可以调整或扩展约束及参数，减少为改变业务偏好而重训风险模型的需求，并提高策略决策的可解释性。

# 三、需求内容

- **完善召回问题定义与价值公式**：沿用 V1.0 最大化期望完单、统一比较 TP/GS/HOLD 的框架，增加乘客视角和司机视角接驾距离约束，并将约束转换为召回价值中的显式项。TP、GS 与 HOLD 使用同一价值口径进行比较。

- **拆分预测模型与业务目标**：CAA 保持取消概率预测含义；距离偏好由价值公式和配置参数承接。明确 V1.0 距离加权 CAA 及近距离修正的切换方式，避免模型与公式重复表达距离偏好。

- **支持分场景配置**：按端内/端外、连环派/非连环派配置两种距离的目标值和调节参数。连环派分别计算乘客视角 \\(ab+bc\\) 与司机视角 \\(bc\\)；非连环派按对应实际接驾距离计算。配置支持实验隔离、灰度调整和回滚。

- **改造召回决策所需的数据与计算**：工程侧在召回链路取得场景标识和双视角距离，计算新版 TP、GS、HOLD 价值，并记录各价值项及最终决策。HOLD 的下一轮价值需补充与播单侧一致的距离预期，保证动作之间可比。

- **建设评估与监控能力**：按场景观察召回覆盖、TP/GS/HOLD 占比、连环派份额，以及召回至完单的漏斗变化；同时监控端内平台整体和商家大聚合结果，支撑参数调整与收益归因。

# 四、工程要求

- **距离与场景计算**：在召回时取得端内/端外、连环派/非连环派标识，以及对应的 \\(ab\\)、\\(bc\\) 或非连环派接驾距离；统一单位、缺失值处理和口径。

- **价值计算**：召回决策公式修改，在现有 TP、GS、HOLD 决策链路中增加双距离约束项，并保证三类动作使用同一价值口径。

- **参数管理**：支持分场景配置上限和乘子、实验组隔离、版本追溯、一键回滚；参数变更应能定位到生效城市、流量及时间。

# 六、主要风险

- **HOLD 估计偏差**：下一轮的完单和距离结果难以准确预测；若只更新播单价值、不更新 HOLD 价值，三类动作将失去可比性。

- **场景间资源转移**：分场景调节可能改变共享司机资源的分配。某一场景达标或完单增长，不代表端内平台与商家整体净收益为正。
