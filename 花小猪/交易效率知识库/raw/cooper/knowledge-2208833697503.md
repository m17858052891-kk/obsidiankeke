# 订单流失率OCR模型建模方法调研

1、离散时间竞争风险模型

hazard（风险率/瞬时发生率）：订单到第 t 秒还没有流失，那么它在接下来一小段时间内流失的概率有多大。

以“订单 × 轮次”为样本，每轮预测：如果本轮继续不播单，未来 3 秒内发生抢单、乘客取消或继续存活的条件概率。

- 建模方法：

	- 三分类，由于抢单/乘客取消导致的订单流失的样本特征可能存在较大差异，所以模型每轮要输出的是$$[p_{rob},p_{cancel},p_{survive}]$$（三分类模型），最终$$OCR_r=p_{rob}+p_{cancel}=1-p_{survive}$$；

	- 删失样本：不足 3 秒就被播单，播单前没有流失。通过**“删失似然”**参与训练：$$L_i=S(1.5\mid X_i)$$

		- 可以把每轮 3 秒再拆成 3 个 1 秒 bin（或0.5s一个bin），后续bin的hazard不参与训练。这样能利用“第几秒发生事件”的信息，也能保留只完整观测了 1～2 秒的样本；【减轻样本删失的影响】给删失前完整观察到的时间区间打条件存活标签，对于每个 bin，模型预测：

$$h_j=P(\text{本 bin 流失}\mid\text{进入本 bin 时仍未流失})$$

    最后将各bin的hazard累计为3s流失概率OCR：

$$P(T\le3s)=1-\prod_j(1-h_j)$$

     例如把 3 秒拆成 3 个 1 秒 bin：

$$h_1=10\%,\quad h_2=20\%,\quad h_3=30\%$$

     那么 3 秒内一直不流失的概率是：

$$(1-0.1)(1-0.2)(1-0.3) =0.9\times0.8\times0.7 =0.504$$

     所以 3 秒内流失概率是：

$$P(T\le3s)=1-0.504=49.6\%$$

Question：这是不是得意味着要拿到对应bin的特征，且特征有区分度？

Answer：不一定必须拿到每个 bin 的实时特征，有两种方法：1）只用本轮开始时的特征，每个bin复用，但同时加入bin序号$$h_j=f(X_t,j)$$，即使订单特征不变，模型也可以通过 `bin_index`、当前累计等待时长等识别；2）每个bin使用实时新特征$$h_j=f(H_j,j)$$。【关键：不能使用未来bin产生的特征，否则造成信息泄漏】

Question：如果按3s/轮、1s/bin切分形成的样本，线上如何预测？

Answer：这里需要注意bin的序号是本轮序号，即bin-1｜2｜3，同一订单的新一轮也是bin-1｜2｜3，因为要计算的是订单本轮hold是否流失，所以需要轮次单独记录，且第r轮OCR为：$$OCR_r=1-\prod_{j=1}^{3}(1-h_{r,j})$$，下一轮要使用最新的特征计算：$$OCR_{r+1}=1-\prod_{j=1}^{3}(1-h_{r+1,j})$$

Question：bin特征淹没（时间淹没）？

Answer：bin embedding + 轮次embedding（可选）

Question：一定要保证随轮次递增的单调性吗？

Answer：从定义上看，不一定应该强制单调。我们预测的是：$$OCR_r = P(如果第 r 轮开始后继续不播单 3 秒，会不会流失 | 当前仍存活, 当前特征 X_r)$$，下一轮是：$$OCR_{r+1} = P(如果第 r+1 轮开始后继续不播单 3 秒，会不会流失 | 当前仍存活, 最新特征 X_{r+1})$$

这两个不是累计概率，而是两个不同时间点的“未来 3 秒局部风险”。

所以理论上：OCR\_{r+1} 可以大于 OCR_r、OCR\_{r+1} 也可以小于 OCR_r，比如下一轮可能出现这些情况：附近司机变多了/供需缓和了/订单进入了更合适的策略阶段/高流失倾向订单已经在前面流失了，留下的是更有耐心的订单

总结-要区分两个东西，累计流失概率：随时间只会增加；当前未来 3 秒条件风险 OCR_r：不一定单调

- 模型训练：

	- 第一阶段：`Shared MLP → Linear(3) → Softmax` （不同正负样本差异大、数据量有限时可能更稳）

	- 第二阶段：`Shared MLP → 三个轻量 tower → Softmax` （适合取消的不同模式差异明显时）

	- 第三阶段：GRU/Transformer/DeepHit（输入需要包含完整历史轮次的序列）

		- 补充：DeepHit-对当前业务而言，离散 hazard 更符合“每轮订单仍存在，再判断下一轮风险”的语义【单区间竞争风险预测】；DeepHit 更符合“从当前时刻一次性预测未来完整事件时间分布”的语义
