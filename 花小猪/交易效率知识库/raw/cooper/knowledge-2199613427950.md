# 一、背景

GS分单算法：[00000000. 稳定匹配算法](https://cooper.didichuxing.com/cooper_gateway/metis/v1/knowledge/2199610335356/wikiFile/860100059.html?taskId=2199613477654)

目前GS分单已经全量，乘客侧价值 = 1000 / 司乘距离，即认为对于乘客，司机距离自己越近，分单价值越大；司机距离自己越远，分单价值越小

考虑到对于乘客，越容易完单的订单价值最大，故选取部分流量重新定义乘客侧价值，即1 - 应答后取消率

**负向效果评估** 展开源码

```PlainText
select
    gp,
    avg(busy_dur) as busy_dur_per_pid,
    avg(online_dur) as online_dur_per_pid,
    avg(finish_cnt) as finish_per_pid,
    avg(brt_cnt) as brt_per_pid
from
    (
        select
            tmp.driver_id as driver_id,
            cancel_ratio,
            case
                when cancel_ratio >= 0.9 then 0.9
                else int(cancel_ratio * 10) / 10
            end as gp
        from(
                select
                    distinct driver_id,
                    dri_cancel_cnt_30d / finish_cnt_30d as cancel_ratio,
                    --表中只有完单量，没有应答量，故用完单量做分母进行估计
                    dri_cancel_cnt_30d,
                    finish_cnt_30d
                from
                    kflower_marketplace.dwm_trip_dri_statistics_days_total_di
                where
                    dt = '2021-07-11'
                    and finish_cnt_30d >= 5
            ) tmp
            inner join(
                select
                    driver_id,
                    sum(online_dur) as online_dur
                from
                    kflower_dw.dwm_kf_dri_online_relate_wyc_df
                where
                    dt between '2021-06-12'
                    and '2021-07-11' --一个月出车司机
                group by
                    driver_id
            ) dri on tmp.driver_id = dri.driver_id
        where
            online_dur <> 0
    ) base
    left join (
        select
            driver_id,
            count(
                distinct case
                    when is_td_finish = 1 then order_id
                    else null
                end
            ) finish_cnt
        from
            kflower_dw.dwd_kf_trd_order_base_di
        where
            dt between '2021-07-13'
                and '2021-07-14'
            and is_td_call = 1
            and call_time is not null
            and call_time <> '0000-00-00 00:00:00'
        group by
            driver_id
    ) finish on finish.driver_id = base.driver_id
    left join(
        select
            count(distinct cast(param ['lowoid'] as bigint)) as brt_cnt,
            cast(param ['driverid'] as bigint) as driver_id
        from
            kflower_ods.ods_log_kflower_orderbroadcast
        where
            concat_ws('-', year, month, day) between '2021-07-13'
                and '2021-07-14'
            and cast(param ['driverid'] as bigint) > 0
            and cast(param ['lowoid'] as bigint) > 0
            and cast(param ['DispatchType'] as bigint) in (2)
        group by
            cast(param ['driverid'] as bigint)
    ) brt on brt.driver_id = base.driver_id
    left join (
        select
            driver_id,
            sum(busy_dur) as busy_dur,
            sum(online_dur) as online_dur,
            sum(serve_dur) as serve_dur
        from
            kflower_dw.dwm_kf_dri_online_relate_wyc_df
        where
            dt between '2021-07-13'
                and '2021-07-14'
        group by
            driver_id
    ) dri on base.driver_id = dri.driver_id
group by
    gp
order by
    gp
```
