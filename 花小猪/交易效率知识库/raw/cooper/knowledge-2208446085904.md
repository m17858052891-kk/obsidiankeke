# 接驾远换车V2.2.1实验评估


# 一、背景

brd：[BRD--连环派换车优化](https://cooper.didichuxing.com/knowledge/2204598041545/2206463390972)

prd：[PRD--连环派换车优化](https://cooper.didichuxing.com/knowledge/2204598041545/2206593491008)

望岳：<https://ddp.intra.xiaojukeji.com/requirement/story/R-KF-628825>

策略方案：[接驾远换车v2.2策略方案](https://cooper.didichuxing.com/knowledge/2199610335356/2206934749054)

- **做什么：核心是提升连环派订单换车触发面。**

	- **连环派策略调整**：扩大连环派换车触发面，**降低连环派换车触发eta阈值**；新增连环派顺路度判断，**对于低顺路度的连环派提高换车触发面**。

- **为什么：**

	- **为什么要提升连环派触发面：发现连环派换车仍有继续提升触发面空间，能够扩大c取消降低收益。**

		- 动机：若在连环派送驾阶段换车则不造成司机空驶，**连环车换车造成的司机空驶折损更少。**

			- 根据[V2.2实验评估结果](https://cooper.didichuxing.com/docs2/document/2206157884766)，连环派换车的司机平均空驶时间3s，非连环派换车的司机平均空驶时间22秒，连环车换车造成的司机空驶折损更少。

		- 可行性：**目前连环派触发面仍有扩大空间。**

			- 当前连环派订单中32%订单触发了换车（连环派中55%为较为不顺路订单、预期应该触发换车），连环派当前触发换车的eta阈值为470，阈值较为宽松。

- **收益测算**：连环派换车触发面预计从30%提升到60%。预计带来每天3000单完单收益，c取消-0.1pp，大盘完单+0.07%。

> ds评估报告：文件名称：连环派换车优化  链接：<https://cooper.didichuxing.com/docs2/document/2206551934682>  密码：827208

- 目标：最终归一乘客取消率（下降），CR（提升），完单（提升）；ETP（下降），司机接驾时长（下降）

- 约束：司机空驶时长

# 三、核心结论

- 从策略触发过程来看，连环派触发面由22%提升至55%，符合策略触发预期。

- 从核心指标收益来看，**扩大连环派触发后的组2组3相比组1 最终归一取消率基本持平且CR无提升**，**表明在组1连环派触发面22%基础上进一步扩大至55%没有带来乘客取消的额外降低，增量换车的部分本来也不会取消。**

- **从交易效率来看，扩大连环派换车触发进一步降低了乘客等待时长ETP（-0.6%➡️-1%）；由于目前策略是从乘客视角出发换更近的车，未考虑连环派场景司机实际接驾时长的比较，因此司机接驾时长上涨（+0.05%➡️+0.4%）。**

## 4.2 下钻分析

### 4.2.1 触发面和找车成功率

- 连环派的**实际换车率从22%提升到53%**，符合本期迭代「扩大连环派换车」的策略预期。

- 连环派换车触发的提升带来一定的找车成功率降低：**找车成功率从40%降低到33%**，原因是换车触发面扩大，造成运力挤占，找车成功率下降。

- 最终连环派**实际换车成功率从9%提升到18%**，是策略扩大触发和触发提升导致的找车成功率下降综合作用的结果。

### 4.2.3 交易效率

对于所有应答订单，根据其经过可能的换车/改派流转后的最终状态是否完单 区分为 **归一完单订单** 和 **归一未完单订单**，分别拆分其司机接驾时长和乘客等待时长ETP（包括等应答时长和等接驾时长）。

- 最终归一完单订单的单均乘客ETP均下降，且扩大连环派触发的组2组3（约-1%）降幅比组1（-0.64%）更大，**符合换车缩短乘客等接驾时长的策略预期**。

- 最终归一完单订单的司机接驾时长均上涨，且扩大连环派触发的组2组3（约+0.5%）涨幅比组1（+0.2%）更大，原因是目前的策略对于**连环派换车时仅从乘客视角比较新旧车的总eta**（连环派ab+bc的总eta），**而并未从司机视角比较连环派bc段（bc段是实际计入司机接驾时长的部分，ab段由于司机仍在上一单送驾中，因此不会计入司机接驾时长）和新车的司机接驾时长**，**因此会出现乘客视角等接驾时间缩短、但司机视角接驾时长反而上涨的结果。**

- 最终归一未完单订单的单均乘客ETP和司机接驾时长均下降，原因是换车策略将部分长时等待最终取消的订单 腾挪到 完单，因此拉低了这部分的时长。

```PlainText
origin_order_detail as (
    select
        *
        ,to_date(call_time_min) as dt
        -- === 等应答时间（完单/未完单通用）===
        ,unix_timestamp(answer_time_min) - unix_timestamp(call_time_min) as wait_answer_dur
        -- === 完单口径 ===
        ,unix_timestamp(begin_charge_time_min) - unix_timestamp(call_time_min) as call_to_firstcharge_dur   -- ETP总等待
        ,unix_timestamp(begin_charge_time_min) - unix_timestamp(answer_time_min) as finish_wait_pickup_dur  -- 等接驾
        -- === 未完单口径 ===
        ,unix_timestamp(cancel_time_min) - unix_timestamp(call_time_min) as call_to_firstcancel_dur         -- ETP总等待
        ,unix_timestamp(cancel_time_min) - unix_timestamp(answer_time_min) as cancel_wait_pickup_dur        -- 等接驾
    from
    (
        select
            origin_order_id
            ,max(passenger_id) passenger_id
            -- 首次呼叫 / 首次应答
            ,min(case when is_td_call = 1 then call_time end) call_time_min
            ,min(case when is_td_answer = 1 then answer_time end) answer_time_min
            -- 首次有应答子单的取消时间（未完单口径终点）
            ,min(case when is_td_answer = 1 and is_td_finish <> 1 then cancel_time end) cancel_time_min
            -- 首次上车计费时间（完单口径终点）
            ,min(case when is_td_answer = 1 and is_td_finish = 1 then begin_charge_time end) begin_charge_time_min
            -- 归一状态
            ,count(distinct order_id) as origin_ord_cnt
            ,max(is_td_answer) as is_td_answer
            ,max(case when order_status in ('完单') then 1 else 0 end) as is_last_finish   -- 本次发单是否完单
            -- 归一最终状态（按最后一个发单状态）—— 用于判定乘客取消
            ,max(case when reassign_rank_desc = 1 then order_status end) as order_status_reassign_rank_desc
            ,max(case when reassign_rank_desc = 1 and order_status in ('乘客取消无改派','乘客取消改派','有过应答且最后一单应答前乘客取消') then 1 else 0 end) as is_pas_cancel  -- 归一最终乘客取消
            -- ★ 新增：首单是否连环派（过滤换车未应答子单后, reassign_rank=1 的首单 is_serial_assign）
            ,max(case when reassign_rank = 1 then is_serial_assign else null end) as is_first_serial
        from
        (
            select
                a.*
                ,row_number() over(partition by origin_order_id order by call_time) as reassign_rank
                ,row_number() over(partition by origin_order_id order by call_time desc) as reassign_rank_desc
            from order_rank_max a
            left join
            (
                select distinct order_id
                from order_rank_max
                where is_callmoredri_sub_ord = 1 and is_td_answer <> 1 --未应答换车子单
            )b
            on a.order_id = b.order_id
            where b.order_id is null --过滤掉换车未应答子单
        )t
        group by origin_order_id
    )t

order_pickup_detail as (

        order_id,
        case
            -- 可控运力 × 连环派：走运力侧精算，这里记 0
            when platform_mode_name in ('花小猪自营','宏鹄') and is_answer_serial_assign = 1 then 0
            -- 可控运力 × 非连环派
            when platform_mode_name in ('花小猪自营','宏鹄') and is_answer_serial_assign = 0 and is_td_answer = 1 then
                case
                    when order_status in ('完单') then unix_timestamp(begin_charge_time) - unix_timestamp(answer_time)
                    else unix_timestamp(cancel_time) - unix_timestamp(answer_time)
                end
            -- 非可控运力 × 连环派：扣 ab 段预估 eta，负数取 0
            when platform_mode_name not in ('花小猪自营','宏鹄') and is_answer_serial_assign = 1 then
                case
                    when order_status in ('完单') then unix_timestamp(begin_charge_time) - unix_timestamp(answer_time) - driver_to_last_dest_eta
                    when (unix_timestamp(cancel_time) - unix_timestamp(answer_time)) > driver_to_last_dest_eta then unix_timestamp(cancel_time) - unix_timestamp(answer_time) - driver_to_last_dest_eta
                    else 0
                end
            -- 非可控运力 × 非连环派
            when platform_mode_name not in ('花小猪自营','宏鹄') and is_answer_serial_assign = 0 and is_td_answer = 1 then
                case
                    when order_status in ('完单') then unix_timestamp(begin_charge_time) - unix_timestamp(answer_time)
                    else unix_timestamp(cancel_time) - unix_timestamp(answer_time)
                end
            else 0
        end as pickup_dur
    from order_rank_max
),

----- open_oid → origin_order_id 映射（把运力侧 zyhh 挂回归一订单）-----
oid_to_origin as (
    select
        tripcloud_open_oid,
        max(coalesce(call_reassign_order_id, answer_reassign_order_id, order_id)) as origin_order_id
    from kflower_dw.dwd_kf_trd_unity_order_di
    where dt between '${start_dt}' and '${end_dt}'
        and is_hxz = 1
        and tripcloud_open_oid is not null
    group by tripcloud_open_oid
),

----- ② 运力侧 zyhh 连环派接驾时长，保留到订单粒度并映射回 origin_order_id -----
zyhh_pickup_detail as (
    select
        m.origin_order_id,
        z.order_id,
        case
            when z.is_td_finish = 1 then z.finish_pickup_dur
            when z.is_td_finish <> 1 and z.is_ab_cancel = 1 then 0
            when z.is_td_finish <> 1 and z.is_ab_cancel = 0 then z.cancel_pick_dur
        end as pickup_dur
    from
    (
        select
            order_id,
            serial_open_oid,
            is_td_finish,
            if(is_td_finish <> 1 and serial_cancel_time <= parent_finish_time, 1, 0) as is_ab_cancel,
            unix_timestamp(serial_charge_time) - unix_timestamp(parent_finish_time) as finish_pickup_dur,
            unix_timestamp(serial_cancel_time) - unix_timestamp(parent_finish_time) as cancel_pick_dur
        from zyhh_order
    ) z
    left join oid_to_origin m
        on z.serial_open_oid = m.tripcloud_open_oid
),

----- 合并两路接驾时长，按 origin_order_id 求和（全链路子单求和）-----
origin_pickup as (
    select
        origin_order_id,
        sum(coalesce(pickup_dur, 0)) as pickup_dur
    from
    (
        select origin_order_id, pickup_dur from order_pickup_detail
        union all
        select origin_order_id, pickup_dur from zyhh_pickup_detail
    ) t
    where origin_order_id is not null
    group by origin_order_id
),

----- 司机送驾时长，按 origin_order_id 求和（仅完单计入）-----
-- 送驾 = end_charge_time - begin_charge_time，统一走流量侧 order_rank_max，
-- 所有运力类型(含可控×连环派)的完单订单一致计算；zyhh 运力侧不参与送驾。
origin_dropoff as (
    select
        origin_order_id,
        sum(case when order_status in ('完单')
                 then unix_timestamp(end_charge_time) - unix_timestamp(begin_charge_time)
                 else 0 end) as dropoff_dur
    from order_rank_max
    where origin_order_id is not null
    group by origin_order_id
),

-- =====================================================================
-- 归一订单全量明细：接驾时长 + 等待时长 + 首单连环派，再做维度展开
-- =====================================================================
----- 归一订单 × (接驾时长 + 等待时长 + 首单连环派) -----
origin_full as (
    select
        d.passenger_id,
        d.dt,
        d.origin_order_id,
        d.is_last_finish,
        d.is_pas_cancel,
        d.is_first_serial,
        -- 乘客等待时长分量
        d.wait_answer_dur,
        d.call_to_firstcharge_dur,
        d.finish_wait_pickup_dur,
        d.call_to_firstcancel_dur,
        d.cancel_wait_pickup_dur,
        -- 司机接驾时长（全链路求和）
        nvl(p.pickup_dur, 0) as pickup_dur,
        -- 司机送驾时长（仅完单）
        nvl(o.dropoff_dur, 0) as dropoff_dur
    from origin_order_detail d
    left join origin_pickup p on d.origin_order_id = p.origin_order_id
    left join origin_dropoff o on d.origin_order_id = o.origin_order_id
),

----- 维度展开：每个归一订单复制为「其所属档 + 整体」两行 -----
origin_explode as (
    select
        f.*,
        dim.serial_cat
    from origin_full f
    cross join (
        select '首单连环派'   as serial_cat
        union all select '首单非连环派' as serial_cat
        union all select '整体'         as serial_cat
    ) dim
    where dim.serial_cat = '整体'
       or dim.serial_cat = case when f.is_first_serial = 1 then '首单连环派' else '首单非连环派' end
),

-- =====================================================================
-- 乘客×日期×首单连环派类型 聚合（含接驾时长 + 等待时长各分量）
-- =====================================================================
raw_split as (
    select
        dt
        ,passenger_id
        ,serial_cat
        -- === 订单数 ===
        ,count(distinct case when is_last_finish = 1 then origin_order_id end) as `归一完单订单数`
        ,count(distinct case when is_last_finish = 0 then origin_order_id end) as `归一未完单订单数`
        ,count(distinct origin_order_id) as `归一应答订单数`
        ,count(distinct case when is_pas_cancel = 1 then origin_order_id end) as `归一乘客取消订单数`

        -- === 司机接驾时长 ===
        ,sum(case when is_last_finish = 1 then pickup_dur else 0 end) as `归一完单接驾时间`
        ,sum(case when is_last_finish = 0 then pickup_dur else 0 end) as `归一未完单接驾时间`

        -- === 司机送驾时长（仅完单）===
        ,sum(case when is_last_finish = 1 then dropoff_dur else 0 end) as `归一完单送驾时间`

        -- === 乘客等待时长：归一完单 ETP/等应答/等接驾 ===
        ,sum(case when is_last_finish = 1 then call_to_firstcharge_dur else 0 end) as `完单_ETP`
        ,sum(case when is_last_finish = 1 then wait_answer_dur else 0 end) as `完单_等应答`
        ,sum(case when is_last_finish = 1 then finish_wait_pickup_dur else 0 end) as `完单_等接驾`

        -- === 乘客等待时长：归一未完单 ETP/等应答/等接驾 ===
        ,sum(case when is_last_finish = 0 then call_to_firstcancel_dur else 0 end) as `未完单_ETP`
        ,sum(case when is_last_finish = 0 then wait_answer_dur else 0 end) as `未完单_等应答`
        ,sum(case when is_last_finish = 0 then cancel_wait_pickup_dur else 0 end) as `未完单_等接驾`

        -- === 乘客等待时长：合计（完单用 charge 终点，未完单用 cancel 终点）===
        ,sum(case when is_last_finish = 1 then call_to_firstcharge_dur
                  when is_last_finish = 0 then call_to_firstcancel_dur else 0 end) as `合计_ETP`
        ,sum(wait_answer_dur) as `合计_等应答`
        ,sum(case when is_last_finish = 1 then finish_wait_pickup_dur
                  when is_last_finish = 0 then cancel_wait_pickup_dur else 0 end) as `合计_等接驾`
    from origin_explode
    group by dt, passenger_id, serial_cat
),

-- =====================================================================
-- 按实验组打包（只看用户首次进组后的数据；单均口径）
--   输出粒度：exp_group × 首单连环派类型(连环派/非连环派/整体)
-- =====================================================================
raw_pack_ab as (
    select
        a.exp_group
        ,b.serial_cat as `首单连环派类型`
        ,count(distinct a.pid) as `分流乘客数`

        -- === 订单数（人均 = 订单数 / 分流乘客数）===
        ,sum(nvl(b.`归一完单订单数`, 0))     / nullif(count(distinct a.pid), 0) as `归一完单订单数_人均`
        ,sum(nvl(b.`归一未完单订单数`, 0))   / nullif(count(distinct a.pid), 0) as `归一未完单订单数_人均`
        ,sum(nvl(b.`归一应答订单数`, 0))     / nullif(count(distinct a.pid), 0) as `归一应答订单数_人均`
        ,sum(nvl(b.`归一乘客取消订单数`, 0)) / nullif(count(distinct a.pid), 0) as `归一乘客取消订单数_人均`

        -- ============ A. 司机接驾时长（单均） ============
        ,sum(nvl(b.`归一完单接驾时间`, 0)) / nullif(sum(nvl(b.`归一完单订单数`, 0)), 0) as `归一完单_单均接驾时长`
        ,sum(nvl(b.`归一未完单接驾时间`, 0)) / nullif(sum(nvl(b.`归一未完单订单数`, 0)), 0) as `归一未完单_单均接驾时长`
        ,(sum(nvl(b.`归一完单接驾时间`, 0)) + sum(nvl(b.`归一未完单接驾时间`, 0)))
            / nullif(sum(nvl(b.`归一完单订单数`, 0)) + sum(nvl(b.`归一未完单订单数`, 0)), 0) as `归一应答_单均接驾时长_合计`

        -- ============ A2. 司机送驾时长（单均，仅完单） ============
        ,sum(nvl(b.`归一完单送驾时间`, 0)) / nullif(sum(nvl(b.`归一完单订单数`, 0)), 0) as `归一完单_单均送驾时长`
        ,sum(nvl(b.`归一完单接驾时间`, 0)) / nullif(sum(nvl(b.`归一完单送驾时间`, 0)), 0) as `归一完单_接驾除以送驾`

        -- ============ B. 乘客等待时长（单均） ============
        -- 归一完单
        ,sum(nvl(b.`完单_ETP`, 0))    / nullif(sum(nvl(b.`归一完单订单数`, 0)), 0) as `完单_单均ETP`
        ,sum(nvl(b.`完单_等应答`, 0)) / nullif(sum(nvl(b.`归一完单订单数`, 0)), 0) as `完单_单均等应答`
        ,sum(nvl(b.`完单_等接驾`, 0)) / nullif(sum(nvl(b.`归一完单订单数`, 0)), 0) as `完单_单均等接驾`
        -- 归一未完单
        ,sum(nvl(b.`未完单_ETP`, 0))    / nullif(sum(nvl(b.`归一未完单订单数`, 0)), 0) as `未完单_单均ETP`
        ,sum(nvl(b.`未完单_等应答`, 0)) / nullif(sum(nvl(b.`归一未完单订单数`, 0)), 0) as `未完单_单均等应答`
        ,sum(nvl(b.`未完单_等接驾`, 0)) / nullif(sum(nvl(b.`归一未完单订单数`, 0)), 0) as `未完单_单均等接驾`
        -- 合计
        ,sum(nvl(b.`合计_ETP`, 0))    / nullif(sum(nvl(b.`归一应答订单数`, 0)), 0) as `合计_单均ETP`
        ,sum(nvl(b.`合计_等应答`, 0)) / nullif(sum(nvl(b.`归一应答订单数`, 0)), 0) as `合计_单均等应答`
        ,sum(nvl(b.`合计_等接驾`, 0)) / nullif(sum(nvl(b.`归一应答订单数`, 0)), 0) as `合计_单均等接驾`
    from
        (
            select pid, exp_group, min(dt) earliest_group_dt --最早进组时间
            from exp_group_clean
            group by pid, exp_group
        ) a
    left join raw_split b on a.pid = b.passenger_id
    where a.earliest_group_dt <= b.dt --只看最早进组后的数据
    group by a.exp_group, b.serial_cat
)

select *
from raw_pack_ab
order by exp_group,
    case `首单连环派类型` when '首单连环派' then 1 when '首单非连环派' then 2 when '整体' then 3 else 4 end
```
