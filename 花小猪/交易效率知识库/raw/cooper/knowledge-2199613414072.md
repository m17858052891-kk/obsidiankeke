### 1.实验目的

在已有分流实验和时间片实验数据的基础上，V2策略**全国扩量20%**

### 2.实验方案

由于apollo人群自适应分流实验方式需要接入piccaso，暂时还不支持在霸王花项目使用。所以本次实验采用由司机driver_id 模1000分桶，将司机随机划分为两个组（0-200,200-1000）：实验组采用司机策略播单V2，对照组采用司机策略播单V1。实验指标为：司机人均GMV，过程指标为：司机平均接驾距离、司机拒单率、司机接单后取消率。若实验指标随机分流分出的两个组指标AA不平，则实验后DID拉齐，观察实验效果。

**出车司机当周人均日均GMV** 展开源码

```PlainText
select
    exp_group_name,
    count(distinct ta.hxz_driver_id) headcounts,
    sum(nvl(tb.gmv_week, 0)) / count(distinct ta.hxz_driver_id) gmv_week_avg,
    stddev(nvl(tb.gmv_week, 0)) gmv_week_stddev
from
    (
        select
            distinct hxz_driver_id,
            case
                when hxz_driver_id % 1000 >= 0
                and hxz_driver_id % 1000 < 200 then 'exp'
                when hxz_driver_id % 1000 >= 200
                and hxz_driver_id % 1000 < 1000 then 'ctl'
                else null
            end exp_group_name
        from
            kflower_dw.dwm_kf_dri_online_hxz_and_wyc_df
        where
            dt between '2021-01-14'
            and '2021-01-20'
            and hxz_online_dur > 0
    ) ta
    left join (
        select
            driver_id,
            sum(gmv_amt) gmv_week
        from
            kflower_dw.dwd_kf_trd_order_base_di
        where
            dt between '2021-01-14'
            and '2021-01-20'
            and call_time is not null
            and call_time <> '0000-00-00 00:00:00'
            and is_td_call = 1
            and is_td_finish = 1
        group by
            driver_id
    ) tb on ta.hxz_driver_id = tb.driver_id
group by
    exp_group_name;
```
