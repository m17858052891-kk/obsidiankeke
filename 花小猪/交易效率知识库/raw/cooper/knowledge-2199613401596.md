### 1. 如何分流

#### 1.1 乘客id取模分流方式

- 设置阈值作为实验组和对照组的分界

- 乘客id%100的值和阈值比较，以便区分实验组和对照组。代码如下：

```PlainText
case
    when passenger_id % 100 < 10 then "treatment" --设10为阈值
    else "control"
end as gp
```

3. 如何看AA

- AA对应的时间应该是实验之前的一段时间

- 回溯AA锁定的人群是，同时出现在AA时间段和AB时间段内的乘客

- 锁定的乘客根据AB实验流量划分原则，区分实验组和对照组

展开源码

```PlainText
select
    gp,
    count(
        case
            when source_type <> 2 then order_id
            else null
        end
    ) as order_cnt
from
    (
        SELECT
            case
                when hash_key % 100 >= 80 then 'treatment_group_2'
                else "treatment_group_1"
            end as gp,
            *
        from
            (
                select
                    passenger_id,
                    order_id,
                    source_type,
                    apollo_bucket("kflower_willing_wait_ab", passenger_id) AS hash_key
                from
                    kflower_dw.dwd_kf_trd_order_base_di
                where
                    dt between '2020-08-30'
                    and '2020-09-29'	--AA时间
                    and is_td_call = 1
					and (is_short_book_flag = 0 or is_short_book_flag is null) --非短时预约
					and order_type <> 1 --非早鸟
                    and call_time is not null
                    and call_time <> '0000-00-00 00:00:00'
            ) base
            inner join(
                select
                    distinct passenger_id
                from
                    kflower_dw.dwd_kf_trd_order_base_di
                where
                    dt between '2020-10-03'
                    and '2020-10-08'	--AB时间
                    and is_td_call = 1
					and (is_short_book_flag = 0 or is_short_book_flag is null) --非短时预约
					and order_type <> 1 --非早鸟
                    and call_time is not null
                    and call_time <> '0000-00-00 00:00:00'
            ) standard on standard.passenger_id = base.passenger_id
    ) tmp
group by
    gp
```
