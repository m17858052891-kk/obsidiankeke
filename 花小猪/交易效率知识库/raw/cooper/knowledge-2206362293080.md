# 测算过程

- 离线测算数据：1201-1207一周 实验城市 全量应答数据 

- 预算控制：

	- 每个组每天预计实花 = 每个组每天c补率==0.3pp==\*实验城市打包每天的gmv 1286万\* 实验组流量15% = 5800元

	- 分周中周末 按预计实花的1.3倍配置熔断预算

- 需要注意线上实际花费和离线测算可能存在的区别，开实验后需关注：

	- 出券人群的平均取消率：测算的取消率是「应该出券人群」的正常无券取消率，如果实际发券，这部分的取消率会降低

	- 延迟支付会导致在预算触顶的情况下实际c补略高于配置的熔断预算；目前熔断预算一周总和为5.25万，留有部分空间防止延迟支付导致的周预算超花
