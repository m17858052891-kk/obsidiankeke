## 实验前设计

> 实验时间：2021.05.25-2021.05.31
>
> 实验选城：大盘213城市
>
> 实验方式：10%流量司机AB
>
> 实验策略：V1，司机在完单或出车时按双开率高低hold或者不hold

hold参数产出周期调度（by周产出）：<https://schedule.data.didichuxing.com/v5/cycle/task/detail/kflower_strategy.hold_params_calculate>

双开率及AB实验灰度开关：<http://ab.intra.hongyibo.com.cn/launch/39/normal/54486>

## 实验中问题排查

1. **实验冲突**

2. 2021.05.28至2021.06.11，有78个城市做了driverid尾号00-05的的派单倾斜，覆盖了这些城市接近一半的实验组司机，对整体实验效果影响很大，导致此期间数据不可用。

2. **参数调度未打开**

3. 06.11起打开了213城市20%的流量，但在06.15日，查分单过滤日志kflower_marketplace.ods_log_kflower_driver_rl，发现只有63个城市存在实际因hold策略被过滤的司机；进而查看运筹的供需地图和供需回放，观察到其余城市hold参数均为空。查产出hold参数的kflower_strategy.hold_param表，发现表中是有213城hold参数的。最后定位到是线上读hold参数的调度在之前实验63城基础上未再开城调度，导致只有63城市是hold实际生效的，导致06.11-06.15数据部分不可用。

## 再实验及扩量节奏

由于近期策略、运营两侧进行实验的城市较多，之前实验冲突等对数据影响较大，故重新选城进行hold策略司机AB分流实验，保证实验城市与其他实验无冲突。

> > **badcase率** 展开源码
> >
> > ```PlainText
> > with T as (
> >     select
> >         cast(param ['driverid'] as bigint) driver_id,
> >         cast(param ['df_finish_time'] as bigint) df_finish_time, --司机最近一次完单或者上线的时间
> >         param ['uuid'] uuid, --分单轮次
> >         cast(param ['cd_time'] as double) cd_time,
> >         cast(param ['hold_iph'] as double) cd_iph,
> >         cast(param ['order_iph'] as double) order_iph,
> >         cast(param ['lumian_dis'] as bigint) lumian_dis
> >     from
> >         kflower_ods.ods_log_kflower_stgmatrix
> >     where
> >         concat_ws('-', year, month, day) between '2021-06-17'
> >         and '2021-06-23'
> >         and cast(param ['hold_iph'] as double) > 0 --只看生效的分单
> >         and cast(param ['area'] as bigint) in (13,21,26,32,35,36,37,39,40,42,53,55,58,59,64,65,84,88,132,145,157,166,167,170,198,254,294,305,306,308)
> > )
> > select
> >     count(
> >         if(
> >             max_is_min_lumian_dis = 1
> >             and max_is_broadcast = 0,
> >             1,
> >             null
> >         )
> >     ) c1,
> >     count(1) c2
> > from
> > (select
> >     t1.driver_id,
> >     df_finish_time,
> >     max(is_min_lumian_dis) max_is_min_lumian_dis,
> >     max(nvl(is_broadcast, 0)) max_is_broadcast
> > from
> >     (
> >         select
> >             driver_id,
> >             df_finish_time,
> >             uuid,
> >             if(
> >                 lumian_dis = min(lumian_dis) over(partition by uuid),
> >                 1,
> >                 0
> >             ) is_min_lumian_dis --是否是该轮次中距离最近的
> >         from
> >             T
> >     ) t1
> >     left join (
> >         select
> >             cast(param ['driverid'] as bigint) driver_id,
> >             param ['uuid'] uuid,
> >             1 as is_broadcast
> >         from
> >             kflower_ods.ods_log_kflower_orderbroadcast
> >         where
> >             concat_ws('-', year, month, day) between '2021-06-17'
> >             and '2021-06-23'
> >             and cast(param ['area'] as bigint) in (13,21,26,32,35,36,37,39,40,42,53,55,58,59,64,65,84,88,132,145,157,166,167,170,198,254,294,305,306,308)
> >     ) t2 on t1.driver_id = t2.driver_id
> >     and t1.uuid = t2.uuid
> > group by
> >     t1.driver_id,
> >     df_finish_time
> > )t;
> > ```

> ### Hold策略对于司机GMV有显著正向的提升作用，对司机TSH有正向的作用。
