### 排序价值方法：

1）MDP网络输出：配合线上hive表输出所有格子对应的中心点的时空价值v(s)

2) 价值融合：

v(s_0) = reward + f_gamma \* v(s_1)

其中，reward是在给定预估gmv，预估接驾送驾时长的total_duration计算的衰减值，

举个例子：

- total_dur = est_dur + arrive_dur = est_dur \* (1 + arrive_dis / travel_dis) --行程时长和接驾时长

- gmv = orders.est_price_amt

- iph = gmv \* 5 / total_dur

- nums = total_dur // 5 + 1

- surplus = gmv - iph \* (nums - 1)

- rg = np.arange(nums - 1)

- reward = dec(gmv, total_dur, iph, nums, surplus, rg)  
where, dec函数为

- def dec(gmv, total, iph, nums, surplus, rg):  
if total <= 5:  
return gmv  
  
gamma = 0.90  
s = 0  
  
for i in rg:  
s += iph \* (gamma \*\* i)  
s += surplus \* (gamma \*\* (total / 5 - 1))  
  
return s

而f_gamma为对于终点时空价值的衰减系数，具体计算为：

def f_gamma(total):

gamma = 0.90

if total < 5.0:  
return 1.0  
else:  
return gamma \*\* (total / 5)
