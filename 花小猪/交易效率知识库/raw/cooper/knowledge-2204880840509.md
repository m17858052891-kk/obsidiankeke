# 一、背景

1. **做什么：对于预估应答后取消率高的接驾远订单进行换车，进而降低应答后C取消、提CR&完单。**

	1. **新增预估取消率和用车意愿的模型，并分档触发策略**：对于接驾远的订单（预估接驾时长符合策略准入门槛），通过模型预估其取消率和用车意愿。高取消率&&高用车意愿**直接换车**，中取消率**手动换车**，低取消率不换车（每2min轮询判断）

	2. **提升连环派订单换车触发面，AB段符合阈值的连环派直接触发换车**：连环派的准入阈值和取消率阈值都更低，提高连环派的触发面；连环派AB段预估时长>90s，则直接发起换车

# 三、策略方案

## 3.1 问题定义

- 换车：平台或者司机没有满足乘客的诉求，在乘客自己取消前平台主动干预换车，短期提升完单，长期是乘客体验带来的用户价值

- 换车策略折损的是上一司机接驾空驶的时间（折损大盘的效率），收益来源于提前识别了高取消概率的用户并为其换车，从而降低应答后C取消，提升完单

- 而对于连环派，如果上一单司机还未完成之前就对其进行换车，则未造成司机空驶，从而在不折损大盘效率的情况下实现换车收益；同时，在相同的预估接驾时长和距离下，连环派的应答后B、C取消双高。因此，提升连环派的换车触发面有利于降低策略带来的折损并扩大降低C取消带来的完单收益。

## 3.2 技术方案

### 模型

根据当前问题定义和分析，新增一个**多任务的模型**，预测当前订单的乘客取消率和用车意愿：

模型输入：接驾距离、乘客应答前等待时长、订单类型（是否连环派）、应答时间（是否峰期）、周围供需等

- **预估取消率：**

	- 模型输出：乘客取消率

			- 根据阈值触发不同的换车策略（自动换/手动换/不换）；

			- 连环派/非连环派分别设置阈值

	- 离线训练标签：

			- 正样本：乘客取消

			- 负样本：完单 或 司机取消

- **用车意愿：**

	- 我们希望识别的是**仍有用车意愿的取消**，因此还需要预估乘客的用车意愿

	- 模型输出：乘客用车意愿

	- 离线训练标签：

			- 正样本（有用车意愿）：乘客取消&&填写的取消原因是“不用车了”之外的其他选项 或者 重发单了 ；完单

			- ==负样本（无用车意愿）：取消且不重发单且(勾“不用车了”或未写原因)== 

# 四、工程链路

1. 是否符合策略准入门槛判断（基于预估接驾时长，连环派/非连环派两套阈值），算法侧提供触发阈值，工程侧基于阈值判断是否触发换车策略

		- if 连环派AB+BC整体预估接驾时长>a秒（200s）：符合准入门槛，进入下一步取消率模型判断

		- if 非连环派预估接驾时长>b秒（300s）：符合准入门槛，进入下一步取消率模型判断

2. 符合准入门槛判断后，调用取消率模型和用户用车意愿模型，根据三档取消率&&用车意愿参数分别触发自动换车/手动换车/不换车

		- AB段>=90s的连环派：【AB段长的连环派：直接换车】

		- 40s<=AB段<90s：【AB段中等的连环派：使用较小的一套取消率阈值】

				- 预估取消率>=c1 && 用车意愿>=x1：直接换车 

				- d1<=预估取消率<c1：手动换车

				- 预估取消率<d1：不换车

		- AB段<40s的连环派 和 非连环派：【AB段短的连环派 和 非连环派：使用较大的一套取消率阈值】

				- 预估取消率>=c2 && 用车意愿>=x2：直接换车 

				- d2<=预估取消率<c2：手动换车

				- 预估取消率<d2：不换车

3. 轮询：对于不换车的订单（包括策略判断不换车 和 乘客手动不换车或无操作），每2min轮询进行重新判断

- **==每2min轮询判断时需要重新判断准入门槛==**
