# 1. 背景

已知**需供比**是影响成交率的重要因素之一。需供比反映了当前平台需求和供给的量级比例，是供给和需求侧总量的客观事实，**成交率**则是网约车平台在需供比这一客观事实下所达成的交易结果。理论上，**同一需供比下，成交率越高，代表平台的匹配效率越高**。

以需供比为因变量、成交率为结果变量，对不同时期的历史数据进行拟合，可以用来评估不同时期的**匹配效率**。该匹配效率主要由三类因素决定：

- 供给密度与需求密度

- 供给与需求自然分布的匹配程度

- 平台交易引擎系统能力

网约车按该方法，通过拟合$$成交率=f(需供比)$$，评估得到：

- DD 25年 H1 匹配效率高于 DD 24 年 H1 匹配效率

- DD 的匹配效率高于 GD

### 1.1 预期收益

**预期收益：**

沉淀一套可复用的平台匹配效率评估口径，在拉齐需供比后识别成交率变化来源，区分供需结构影响与平台交易能力提升，为运营复盘、城市分框诊断、季度追踪和后续策略优化提供量化依据。

## 2. 目标 & 约束

### 2.1 目标

本文目标是沉淀一套可复用的花小猪匹配效率评估方法：在拉齐需供比/供需比后，对比不同周期、不同城市分框在同一供需条件下能够达成的 CR，从而评估平台匹配效率变化。

具体包括：

- 明确 DSR 与 CR 的统一计算口径，支持运营、数分后续复用。

- 通过拟合 `CR = f(DSR)`，将供需结构变化与匹配效率变化拆开观察。

- 支持全国、城市分框等维度下的历史周期对比，判断同等需供比下 CR 是否提升。

- 本项为分析口径沉淀与效率评估，不直接对应线上策略实验目标；如后续用于策略放量或资源分配，需要另行补充 DDO 指标、实验目标和放量约束。

### 2.2 约束

- 口径约束：CR 使用“小猪端体验成交率”，即小猪端所有品类完单 / 小猪端所有品类呼叫。

- DSR 约束：本文后续统一采用 DSR5 口径，即小猪端呼叫 /（可控运力按端内完单份额折算的有效 TSH + 非可控运力服务小猪端订单的服务 TSH）。

- 粒度约束：拟合样本按周聚合；全国、城市分框等维度需要保持相同聚合粒度后再比较。

- 方法约束：当前采用 DSR5 + 二次多项式拟合方法，因其在 24/25 H1 数据上的平均 R² 最优；若后续数据周期、城市范围或供给口径发生变化，需要重新验证拟合效果。

- 使用边界：该方法用于历史分析、口径对齐和效率归因，不替代线上实验评估；涉及策略上线、放量或收益归因时，仍需结合实验结果和核心约束指标判断。

# 3. 技术方案

## 3.1 数据口径

| 指标 <br> | 口径 <br> |
| --- | --- |
| 需供比（**Demand-Supply Ratio**, **DSR**） <br> | 小猪端呼叫 / 小猪端 TSH <br> |
| 小猪端呼叫 <br> | 小猪端**所有品类**的呼叫订单数 <br> |
| 小猪端完单 <br> | 小猪端**所有品类**的完成订单数 <br> |
| 小猪端 TSH <br> | 根据不同的 TSH 计算口径，DSR 口径也有所不同，最终我们选择了拟合效果$$R^2$$最佳的口径为： <br>小猪端可控运力完单占比 × 可控运力去重**有效** **TSH** + 非可控运力服务小猪端订单的**服务 TSH** <br>- 小猪端可控运力完单占比 = 小猪端内可控运力完单 / 可控运力总完单 <br><br>- 可控运力去重有效 TSH：多商家司机的挤水 TSH（按身份证去重） <br><br>- 非可控运力服务 TSH：非可控运力接驾 + 等待 + 送驾时长 <br><br> |
| 小猪端**体验**成交率 CR <br> | 小猪端完单 / 小猪端呼叫 <br> |

备注：

- 可控运力：包含宏鹄 + 自营运力

- 非可控运力：指的是 API 运力（包含滴滴出行、百度地图等）

- 有效 TSH：司机身份证号挤水在线时长

- 服务 TSH：接驾 + 等待 + 送驾时长

- 小猪端体验成交率：是指顾客从小猪端呼叫能够体验到的成交率，包含来自**所有品类**的呼叫和完单数（含滴滴等）

## 3.2 拟合方法

### 3.2.1 初步分析

**每周**一个样本点，首先聚合计算每周的 DSR 和 CR，然后将 DSR 作为自变量 X，CR 作为因变量 Y，拟合数学模型 $$Y=f(X)$$。我们对不同的 DSR 口径和拟合方法$$f$$的组合进行了实验，由于可控运力可以获取有效 TSH 和服务 TSH，但非可控运力只能获取服务 TSH，遂定义不同 DSR 口径的 TSH 为：

- DSR1：所有运力（可控+非可控）的**服务** TSH

- DSR2：可控运力**有效** TSH + 非可控运力**服务** TSH

- DSR3：所有运力（可控+非可控）服务小猪端订单 **服务** TSH

- DSR4：可控运力**有效** TSH

采用不同的拟合方法如 Logistic 回归、二次多项式、多项式 Logistic 回归、线性回归等对 DSR 和 CR 进行了拟合，在 24/25 H1 数据上，发现 （DSR3 口径，二次多项式）的拟合在$$R^2$$指标上表现最优。

### 3.2.2  DSR3 拆分

在 DSR3 的基础上，增加了 DSR5，即 TSH 换为可控运力按端内完单份额折算的**有效** TSH + 非可控运力服务小猪端订单的**服务** TSH，在 24/25 H1 数据上，通过二次多项式拟合，24/25 H1上的 $$R^2$$分别为 0.968 和 0.931，平均 $$R^2$$ 为 0.9495，为最优拟合结果。所以在下面的研究中将采用 DSR5 口径和二次多项式拟合的方法进行分析。
