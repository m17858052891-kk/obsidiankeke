# 背景

通过密度&&供需比拟合成交率，可用于预算分配等。

# 拟合公式

log(CR/(1-CR)) = density_coef \* log(密度) + sod_coef \* log(供需比) + intercept，拟合采用岭回归，alpha=1。

其中，供需比=TSH／订单数，density_coef，sod_coef，intercept三个参数可以通过查字典获取。每周更新表中参数。

通过获取对应城市的density_coef，sod_coef，intercept三个参数，输入密度和供需比信息，按照如下公式，

CR = z / (1 + z)，其中z = exp ( density_coef \* log(密度) + sod_coef \* log(供需比) + intercept )，即可得到对应城市在该密度和供需比下的估计值。

说明：log以e为底数

# 拟合效果

用一个月的数据拟合，平均拟合r2 = 0.64，mae = 0.03。
