强化策略模型和iph分单理想的数据集上比较：司机、订单密度为正常早高峰的**两倍**.

这是为了让不调参的模型与iph比较时，尽可能少的出现某个分单时刻上没有可连边的情况，因此在现有模拟系统的功能上有两类超参数需要做对比学习：分单终止阈值、分单间隔.

1\. 分单间隔

目前，分单间隔采用2s和4s的对比，通过每个分单时刻上可连边数是否>=1的条件来规定此时分单或者将仅有的1单或者没有订单留存到下一个分单时间点，这样自动完成全局的动态播单 -- 动态控制的出发点来自于想尽可能的让网络学习在多一点订单的情况下处理分单顺序，而不要每次只有1、2单可分则对于训练网络没有意义；

2\. 分单终止阈值

每个分单时间点上存在一个固定的超参阈值(0.1 or 0.2)，当剩余可连边的占比<=阈值时停止分单，这是为了三个目的：

- 期待网络学习分单的重要性排序，有哪些单可以放在当前时刻靠后分出去或者即使无法分出去也可以留在下一个时间点再决策

- 期待网络学习远期利益，下探到d/o维度来决策要保留哪些订单或者司机

- 使用阈值来扮演空节点的角色，而不是人为制造一个空节点并且让网络学习(没有先验知识构造**空可连边节点**)

基本上训练中可以观察出，4s的分单间隔几乎不会出现1单or0单的情况，且每个时间点可连边数量较多，而2s的情况下，网络存在较多的不可学习的状态转移 -- 无可连边.

## Background

基于神经网络求解TSP、VRP等组合优化问题已经有了成熟的建模思想，这类问题通过seq2seq及其变种的Pointer把每个时间步上的输出映射成输入的概率分布并sample得到decoder的序列输出结果。

- Pointer Network: [paper](https://proceedings.neurips.cc/paper/2015/file/29921001f2f04bd3baee84a12e98098f-Paper.pdf)

- RL for VRP: [paper](http://wiki.intra.xiaojukeji.com/arxiv.org/pdf/1802.04240.pdf)

- Attention for routing problems: [paper](http://wiki.intra.xiaojukeji.com/arxiv.org/pdf/1803.08475.pdf)

这类方法由于是在每个时间步上需要根据当前信息对动作空间进行下一步的选择，因此理论上能够很好的结合RL建模并学习transition：*S ✖️ A → S.*

最接近司乘匹配分单场景中利用Pointer模型和强化学习结合的案例是百度提出的：[paper](https://arxiv.org/pdf/2008.11087.pdf)

他们尝试离线地对一段时间内多个时间片上的司乘节点进行匹配以优化长期的某类指标(如平台gmv等)，整体上文章对订单匹配建模为时序决策问题，并在每个时间步上将当前的司乘信息节点使用Pointer网络求解组合优化问题以期实现时序决策的长期影响，此外文章对未来一定时间内的订单、司机、环境变化建模了一个预测模块也作为目标同时优化。

## 方案

对于TSP、VRP等组合优化问题，序列决策是建立在整个路径选择的回合内；而对于我们的场景，多轮次分单则是联立了多个分单间隔上的组合优化，实际上background里提到的百度的文章是这样尝试的。因此我们需要尽可能优化一段时间内的考虑长期收益的匹配问题，在分单时间间隔框架不变的前提下，对含有未来信息的匹配过程整体建模，而不是拆解为多个子优化问题。

模型分为三个主要优化模块：

- 基于强化学习的匹配MDP策略模块；

- 满足未知生成时空分布的D/O预测模块；

- 学习动作对状态变化的影响以及状态表征以优化以上两个方向的模块.

## MDP模型相关定义

**状态State s_t**：每个匹配时刻t的状态S_t由三部分组成 -- available司机、available订单、环境特征.

司机特征：司机实时经纬度、预估时长(如果假设一段时间内司机不下线，则可以去掉该特征).

订单特征：订单起点经纬度、终点经纬度、订单gmv(normalized)、订单预估时长、订单预估生命周期.

环境特征：可连边D/O对的接驾距离、当前的环境时间、所有空车司机数、所有无连边的订单数.

将可连边D/O和司机、订单、环境特征进行拼接，e.g.，D1/O1作为一个状态的一个节点x1.

则如果当前时刻有m个可连边D/O对：x1, x2, x3, ..., x_m，以及一个提前设置的空白节点x_m+1，则状态是m + 1个节点的信息(类似NLP的seq_len, feature_len).

其中，空白节点为一个空的D/O对信息，用于在输出时作为终止标识.

**动作Action a_t**：动作a_t为在每个匹配时刻t上选择不定num_size：k_t个D/O对，e.g. a_t = (c_1, c_2, c_4)，where k_t = 3.

则在t时刻，agent选择choice1、2、4这三个D/O对，且由于下一个选择为状态输入中的空D/O对，因此终止.

**奖励Reward r_t**：当agent在t时刻给出a_t的D/O对选择后，环境将匹配action提供的选择，并得出完成匹配的订单的总gmv，

e.g., a_t = (c_1, c_2, c_4)，c1和c2成功匹配，则r_t = gmv_c1 + gmv_c2.

Transformer的attention输出结构：attns = softmax(Q\*K^T / sqrt(dk))

Encoder：W_k矩阵对输入的state做keys，keys为K = W_k \* state, state = (batch_size, seq_len, feature_len)；

Decoder：每个step t上输入S_0和已经被选择的可连边作为Query，Q = W_q \* s_0, s_0为双向RNN包裹的state，为了统一输出size；

最后利用scaled_dot_product计算attns，输出概率分布选出动作的第一个子选择，并重复这个process；

Critic：与Actor类似的结构，输入为query侧的state整体，输出为当前状态s_t的价值.

算法采用PPO模型进行训练，设定一个有终止的episode时长为20分钟(600 steps).

### RL matching 策略模块

idea：基于带baseline的Reinforce算法，分别建模policy网络和critic网络构造advantage函数.

Reference:

- [利用RL求解动态图控制问题](http://wiki.intra.xiaojukeji.com/arxiv.org/pdf/2010.05313.pdf)

- [RL的序列动作问题建模](http://wiki.intra.xiaojukeji.com/arxiv.org/pdf/1705.05035.pdf)

- [Factored action space](https://openreview.net/pdf?id=naSAkn2Xo46)

从RL建模的角度出发，动作空间的刻画是核心的步骤。每个时间步上对可连边D/O对的状态提取并给出相应的匹配是我们期待强化学习能够实现的，也就是说在每次状态转移时，policy不仅可以给出合适的匹配指导也能够一定程度地考虑到司乘其中一方在未来是否会有更合适的匹配者出现。而每给出一个匹配，剩下的D/O匹配空间才能确定，这样的动作可以被定义为autoregressive action 或者 factored action，i.e.，在每一个time step，匹配的动作空间是由候选集动作给出的先后顺序决定的。因此，factored action模型能够帮助policy-based算法更有效地在当前学习到一个由多个匹配选择构成的动作序列，a_t = {c1, c2, c5, c7}，的动作概率优化.

构造动作空间分解：

![](https://s3-ep-inter.didistatic.com/didoc-upload-file-prod/1653033735411/860100309.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKDD00000000000EBLCTZNRBJHX6ZS%2F20261104%2Fgzep%2Fs3%2Faws4_request&X-Amz-Date=20261104T103606Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=11d23209796c5e44d7f8db4d7c7886d366aefd7d42fbb65ac0f6444295383467)

如上图所示，分解transition：*S ✖️ A → S*为一个序列子动作构成的autoregressive factorization，这样每次的动作选择都会基于之前的动作选择概率来进行概率传播.

令

- sub_state spaces *U_i =* *S ✖️ A1 ✖️ A2 ✖️ ··· ✖️ Ai, where U_0 = S, u_t^i ∈ U_i；*

- *sub_policies π^i = U_i-1 → A_i;*

- *π\_θ(a_t|s_t) = ∏\_i=1 π\_θ^i((a_t|u_t))*

这样，策略网络能够较好地学习transition内部的动作转移概率变化，而并不是简单地以多个动作概率的乘积作为唯一指导信号：

1) 将可连边D/O对以及其他相关特征输入policy网络，用self-attention based单头或者多头模型提取状态信息，网络输出为dependent on输入size的normalized概率分布；

2）根据输出构造类别分布，从中抽取得到对应的动作及其概率值，并将剩余可连边重新送入policy网络；

3）重复以上2步，直到某些终止条件达成，比如所有司机被分配完导致无可连边 or 输出的概率分布最大值低于预设的阈值(即当前所有的动作都暂时可以不选).

在这种设定下，子动作不能够直接通过并行sample得出，而是序列得到所有子动作且对比seq2seq架构：

1）移除了mask等对网络的操作；

2）在同一个时间步上将决策选择的建模脱离RNN，只保留轻量化的attention.

也就是说，建模的Policy的假设是：在同一个时间步上对所有D/O对candidates的序列化匹配输出不是一个seq2seq的的时序关系问题，而是autoregressive factorization.

显然，这样的policy建模enable了基于actor框架的动作概率传播，能够学习到序列动作中每个子动作在时间步上应当如何更新当前的概率分布. (0.3 = 0.6 \* 0.5 = 0.8 \* 0.9 \* 0.417)

改进了actor框架下，pointer在一个时间步上只能用一个连乘的概率来表征所有的子动作，同时factored model 能够自适应PPO、A3C等主流框架.

通过动作与当前状态的高维表征预测下一时刻的状态高维表征，来学习当前状态下给出D/O序列动作能多大程度上影响下一时刻的状态. 通过拟合来强化网络对环境当中未知隐变量的理解，i.e.，下一时刻新的司乘进入的分布、环境的变化(包括当前给出的匹配关系是否能够应答成交)和当前策略给出决策后状态转移的差别；

由于新的生成分布、环境变化实际上在建模中的随机性很大，我们需要让策略更深度地感知到action能够多大程度上影响状态转移，并且高维表征很合理地表示了新的时空司乘分布、环境特征，通过拟合取代难以计算表达的变量，让policy在学习策略的同时学习环境.

### 表征学习

为了稳定学习状态的表征，需要一个inverse模型来更好地刻画状态的特征空间. 则类似地我们利用收集的当前和未来状态*s_t, s_t+1*的表征在inverse model中对于当前动作序列进行监督学习. 将inverse部分作为loss的正则一起优化.

不同与经典的ICM的是，我们可以用其他目标代替离散化的autoregressive actions输出.

比如，通过Inverse model输出预测当前动作序列的reward大小来拟合两个action. 这个模块除了稳定状态的表征学习，还能够offline自监督极大提高sample efficiency.

## 总结

多轮强化学习分单模型

- 对policy的动作表征建模为autoregressive factorization；

- 在多轮分单的背景下，剥离pointer模型保留attention对action的子序列概率生成进行逐层优化；

- 利用greedy rollout思想构造baseline降低training variance并让策略自我博弈提升优化能力；

- 优化方向是self-critical的，learning by testing；

- 通过预测未来状态的表征让agent学习环境变化，动作的影响，以及拟合一类不可计算的预测生成来达到长时间的整体目标优化；

- 在时间步单位上学习序列动作的生成策略，i.e.对动作空间做时空间解耦，人为masking，让网络focus在更少更重要的部分
