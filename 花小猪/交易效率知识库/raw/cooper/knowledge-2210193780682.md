# OCR数据分析


- **这篇分析核心想讨论的问题：目前的ocr真实数据分布是怎样的，我们是否可以依赖ocr模型在召回中实现“随时间扩”，要求ocr随时间增这个业务约束如何进行数据支撑；**

- **结论：**

	- **先看清真实label正例率，需要分端看，三端数据在开始阶段均存在明显高点；端外订单在5分钟似乎有关单设置；特殊峰值需要搞清其业务机制（端内85秒还有个峰 是什么？）**

	- **按照辛普森悖论的思路拆分后，认为是存在辛普森悖论的（组内上涨而整体下降）（目前分析中端外的数据比较能支持这点），所以通过ocr模型控制O维度的hold value随时间下降是合理的，因此在建模时对hold value的期望价值剥离t因素至少是可行的。**

**==正文主要是ai分析的 有些不是很认可 仅供参考，主要看图片结果和我高亮的文本。==**

# 一、背景

**结论：当前样本不支持“OCR 随等待时长全程单调上升”的假设。本次进一步按订单初始风险分层，检验整体曲线是否受到风险人群构成变化的影响。**

OCR 用于估计订单当前不播单时，在下一轮前发生流失的概率，属于**短时间窗口内的条件流失风险**，并非累计流失概率。等待时间增加，并不天然意味着该指标必须单调上涨。

前期分端分析发现，真实 label 正例率随等待时间呈现下降、平稳、局部突增等不同形态。对此，一个可能的解释是：

> 高风险订单更早退出，后续样本中的低风险订单占比提高，导致整体正例率下降；即使各风险组内部的正例率上涨，整体也可能下降。

本次分析围绕这一假设展开：

- 首先观察各 `order_origin` 的真实 label 正例率分布；

- 再按订单固定的初始风险划分高、中、低三组，观察**组内正例率、各组样本数及占比**随等待时间的变化，识别是否存在辛普森反转。

> \*\*口径说明：\*\*下文“真实 label 正例率”指现有筛选样本中的实际标签比例，尚不能直接等同于无选择偏差的真实流失率。因端编码映射未在本次材料中明确，统一保留 `order_origin=1/2/3` 表述。

# 二、真实 label 分布

**结论：三个来源均未呈现全程单调上涨。来源1、2呈现“前期下降—中段平稳—尾段陡升”；来源3整体较低，并在中后段缓慢下降。**

## 2.1 order_origin=1

**结论：正例率具有明显的阶段性，接近300秒时出现集中突增。**

- 全部样本行的加权正例率为 **8.489%**，样本量约 **1,300万行**。

- 开始阶段存在明显高点，例如4秒时正例率为 **27.88%**；随后快速下降。

- 约60～200秒主要在 **5%左右**波动，之后有所回升。

- 接近300秒时急剧上涨，295秒达到 **100%**，该时间桶仍有 **5,926行**样本，不能简单归为极少量样本引起的尖峰。

该分布提示，应分别分析前期、中段与临近结束阶段；尾部突增需要结合订单退出时间及标签构造规则核查。

## 2.2 order_origin=2

**结论：整体形态与来源1相近，中段正例率较低，接近300秒同样集中上涨。**

- 7秒时正例率为 **29.87%**，之后明显下降。

## 2.3 order_origin=3

**结论：正例率明显低于来源1、2，中后段总体下降，未出现同样的300秒尾部陡升。**

- 全部样本行的加权正例率为 **1.855%**，样本量约 **4,662万行**。

- 开始阶段存在短时峰值，5秒时达到 **7.87%**。

- 85秒附近出现另一处明显峰值，正例率为 **5.86%**。

- 除局部峰值外，中后段整体缓慢下降，后段大部分时间低于 **2%**。

# 三、数据分析：固定风险分层与辛普森效应

- **本章想说明什么：这里是想说 目前看到的整体流失率随时间下降不能说明个体ocr随时间下降；相反，在这个场景很容易举出辛普森悖论的反例；而且存在现有策略的选择偏差。**

- **结论：目前的数据分析结果表明是存在辛普森效应的，因此对ocr模型有个体流失率对时间单调增的业务约束是合理的，不能把整体趋势单调减当作是事实趋势。**

辛普森悖论的case构造解释：分组内趋势与汇总后的趋势相反。

- 高风险组：20% → 22%，上涨；

- 低风险组：2% → 3%，上涨；

- 总体：11% → 4.9%，下降。

> **ai结论：确实观察到风险组构成随时间变化，但当前图形未呈现典型的“各组内部均上涨、整体反而下降”。整体非单调不能仅由组间构成变化解释。**

## 3.1 分析方法

**分组方法：使用订单首次可见时的 OCR 固定分组，避免订单因后续预测值变化而不断切换风险组。**

具体方法如下：

1. 取每个订单最小 `wait_time` 时的 OCR；同一时点有多个预测值时取均值，记为 `base_ocr`。

2. 在每个 `order_origin` 内，按订单等权的 `base_ocr` 三分位，划分低、中、高风险组。

3. 每个订单后续组别固定，分别观察：

	- 各风险组及整体的 label 正例率；

	- 各风险组及整体的样本数；

	- 各风险组占当前时间桶样本的比例。

分层图默认每5秒一桶，每个订单每桶取首个有效时点计数。**这与第二章按原始样本行统计的口径不同，因此两类图的正例率水平不直接比较，主要比较各自的趋势。**

此外，`base_ocr` 是**首次可见风险的近似**，仍包含首次等待时长、当时供需等信息，不等同于纯粹的订单固有风险。

## 3.2 order_origin=1：存在风险构成变化，但组内也有前期下降

**结论：高初始风险订单在后续样本中的占比下降，与风险选择效应相符；但各组前期自身也下降，未呈现典型辛普森反转。**

- \*\*组内趋势：\*\*前期高、中、低三组均出现下降。中段以后，高风险组逐步上涨，中风险组略有回升，低风险组相对平稳；接近300秒三组均急升。

- \*\*构成变化：\*\*高风险组占比由开始阶段约40%，下降至中段约20%；低风险组在中段提高至约45%。

- \*\*样本数：\*\*各组随时间均明显减少，高风险组在前期减少较快。

这说明风险构成变化可能压低整体曲线，使其不能直接代表各组内部的风险变化。不过，**前期下降也发生在组内，因此不能全部归因于高风险组占比下降。**

## 3.3 order_origin=2：构成变化明显，但中段风险排序未持续保持

**结论：高初始风险组占比明显下降，但三组中段正例率接近，部分区间排序交叉，尚不支持严格的辛普森反转。**

- \*\*组内趋势：\*\*三组前期总体下降，中段逐渐接近，尾部共同上涨。

- \*\*构成变化：\*\*低风险组占比由开始阶段约20%，上升至中段约50%～55%；高风险组占比由约40%，下降至约15%～20%。

- \*\*风险排序：\*\*在部分中段区间，初始高风险组的正例率反而低于初始低风险组。

该现象说明：\*\*首次可见时的风险排序，在长时间等待后的样本中并不一定持续成立。\*\*其原因可能包括组内进一步选择、供需变化，以及初始分数对后续风险的区分能力减弱，现有图形无法单独区分这些解释。

## 3.4 order_origin=3：组内下降更明显，构成变化方向与原假设不同

**结论：该来源的整体下降不能用“高风险组占比减少”解释；高风险组占比反而增加，而各组内部总体下降。**

- \*\*风险区分：\*\*多数时间内，高风险组正例率高于中风险组，中风险组高于低风险组，排序较稳定。

- \*\*组内趋势：\*\*除开始阶段、约80秒及尾部局部波动外，三组中后段均呈缓慢下降趋势。

- \*\*构成变化：\*\*高风险组占比从开始阶段约15%～20%，上升至中后段约40%以上；低风险组占比则由约60%降至约20%左右。

在风险排序保持的情况下，高风险组占比提高通常会抬高整体正例率，但整体仍然下降，说明**组内下降是理解该来源曲线的重要因素**。

## 3.5 阶段结论与下一步

**结论：当前证据不足以支持“OCR 应随等待时长全程单调上涨”，也不足以将整体下降统一归因于辛普森悖论。**

本次分析得到三点认识：

- \*\*存在构成变化：\*\*来源1、2中，高初始风险组在后续样本中的占比明显下降。

- \*\*构成变化并非全部解释：\*\*三个来源均可观察到组内下降或非单调；来源3的构成变化方向还与原假设相反。

- \*\*存在明显阶段与来源差异：\*\*来源1、2的尾部突增，以及来源3约85秒的峰值，需要结合业务机制和标签规则进一步排查。

后续优先补充：

1. **固定组占比后的总体曲线**，量化组内变化与构成变化各自的贡献。

2. **分阶段分析**，分别比较前期、中段及临近结束区间，避免用一条全程趋势概括。

3. **核查首次可见时间与关键边界**，确认初始风险分组是否受到首次等待时长影响，并排查约85秒、接近300秒的局部特征。

**因此，现阶段不宜仅依据业务直觉，对 OCR 施加全程随时间单调上涨的约束；应先明确各来源、各阶段的标签生成机制与样本选择影响。**
