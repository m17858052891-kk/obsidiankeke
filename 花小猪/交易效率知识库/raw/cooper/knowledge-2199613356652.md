## 1.3 改进点

做出的改进点：

1、 添加KL相对熵计算：

考虑到不同的标签会带有不同的Noise，如果能通过物理意义将有关系的Label关联起来，一定程度上可以提高模型学习的鲁棒性，减少单独标签的Noise对训练的影响。

根据 1-(1-p(乘客取消)) \*(1- p(司机取消) = p(取消) 的业务意义，加入了一个KL散度的计算（相对熵），使得预测出来的 1-(1-p(乘客取消)) \*(1- p(司机取消) 更接近于 p(取消) 。

具体实现如下，设 1-(1-p(乘客取消)) \*(1- p(司机取消) = p(取消) 为概率分布P ， p(取消) 为概率分布Q，那么将概率分布P和Q的KL散度距离当做一个KL_loss加入到总的损失函数中，又因为由于KL散度是非对称的，即KL(P||Q) != KL(Q||P)，因此真正使用的时候，优化的是 KL(P||Q) + KL(Q||P)。

注：除添加KL相对熵，也添加1-(1-p(乘客取消)) \*(1- p(司机取消) 与 取消率的label之间的loss ，比较该loss和KL相对熵对训练结果的优化效果

2、整合损失函数：

根据论文 《Multi-Task Learning Using Uncertainty to Weigh Losses for Scene Geometry and Semantics》，最小化多任务的loss值相当于：

![](https://s3-ep-inter.didistatic.com/didoc-upload-file-prod/1653033739127/860101453.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKDD00000000000EBLCTZNRBJHX6ZS%2F20261104%2Fgzep%2Fs3%2Faws4_request&X-Amz-Date=20261104T095115Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=bff6ca9bc3ba5d2704f1562fb3679d17e750073389e7cf91d6406a1c6207f389)

由于加入权重乘积的log值，损失函数出现负数，且无法收敛，故在实际操作中，将loss值的尾项去掉

3、调整学习率

考虑到每个单独模型的收敛速率不同，本次DNN+MTL框架针对三个不同的模型采用不同的学习率，具体的包括共享隐层的学习率shared-lr（共享），乘客取消lr，司机取消lr，取消率lr。

通常来说，训练一个神经网络的tensorflow代码如下：

```PlainText
optimizer = tf.train.AdamOptimizer(learning_rate).minimize(loss)，其中AdamOptimizer定义了梯度下降的方式，minimize则计算梯度并最小化损失函数。
```

我们可以通过自定义一个minimize函数来对某个任务的变量设置合适的learning rate：

假设有a和b两个任务

**设置不同学习率代码**

```PlainText
all_variables = shared_vars + a_vars + b_vars
all_gradients = tf.gradients(loss, all_variables)

shared_subnet_gradients = all_gradients[:len(shared_vars)]
a_gradients = all_gradients[len(shared_vars):len(shared_vars + a_vars)]
b_gradients = all_gradients[len(shared_vars + a_vars):]

shared_subnet_optimizer = tf.train.AdamOptimizer(shared_learning_rate)
a_optimizer = tf.train.AdamOptimizer(a_learning_rate)
b_optimizer = tf.train.AdamOptimizer(b_learning_rate)

train_shared_op = shared_subnet_optimizer.apply_gradients(zip(shared_subnet_gradients, shared_vars))
train_a_op = a_optimizer.apply_gradients(zip(a_gradients, a_vars))
train_b_op = b_optimizer.apply_gradients(zip(b_gradients, b_vars))

train_op = tf.group(train_shared_op, train_a_op, train_b_op)
```
