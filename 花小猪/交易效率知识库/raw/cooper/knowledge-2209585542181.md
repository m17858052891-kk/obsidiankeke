# 数据集构造v1

当前数据按时间严格分为三个时间窗口

| 窗口 <br> | 开始时间 <br> | 结束时间 <br> | 在模型中的作用 <br> |
| --- | --- | --- | --- |
| W窗口 <br> | 2026-03-02 <br> | 2026-05-03 <br> | 提供协变量，混淆变量 <br> |
| A窗口 <br> | 2026-05-04 <br> | 2026-05-31 <br> | 差体验处理变量 <br> |
| Y窗口 <br> | 2026-06-01 <br> | 2026-06-28 <br> | 构造流失标签is_run，1为流失；0为没有流失 <br> |

```SQL
-- 乘客流失预测特征表 窗口A+窗口W+城市供需+用户画像
-- A: weeks 9-12 (2026-05-04 ~ 2026-05-31) | W: weeks 0-8 (2026-03-02 ~ 2026-05-03) | label: 2026-06-01 ~ 2026-06-28
WITH order_call_time AS (
  SELECT
    order_id,
    MIN(call_time) AS call_time
  FROM kflower_dw.dwm_kf_trd_hxz_order_base_view_di
  WHERE dt BETWEEN DATE '2026-03-02' AND DATE '2026-06-28'
    AND call_time != '0000-00-00 00:00:00'
  GROUP BY order_id
),

-- 2. 订单状态重构 取发单后7天内最新分区记录
order_latest_within_7d AS (
  SELECT
    d.order_id,
    d.passenger_id,
    d.call_time,
    d.answer_time,
    d.cancel_time,
    d.charge_time,
    d.finish_time,
    d.pay_time,
    d.is_td_answer,
    d.is_td_cancel,
    d.is_td_reassign,
    d.cancel_type,
    d.driver_start_dis,
    d.eta_second_pick_dur,
    d.source_type,
    d.dt
  FROM (
    SELECT
      od.order_id,
      od.passenger_id,
      od.call_time,
      od.answer_time,
      od.cancel_time,
      od.charge_time,
      od.finish_time,
      od.pay_time,
      od.is_td_answer,
      od.is_td_cancel,
      od.is_td_reassign,
      od.cancel_type,
      od.driver_start_dis,
      od.eta_second_pick_dur,
      od.source_type,
      od.dt,
      ROW_NUMBER() OVER (
        PARTITION BY od.order_id
        ORDER BY od.dt DESC,
          (CASE WHEN od.call_time != '0000-00-00 00:00:00' THEN 1 ELSE 0 END
           + CASE WHEN od.answer_time != '0000-00-00 00:00:00' THEN 1 ELSE 0 END
           + CASE WHEN od.cancel_time != '0000-00-00 00:00:00' THEN 1 ELSE 0 END
           + CASE WHEN od.charge_time != '0000-00-00 00:00:00' THEN 1 ELSE 0 END
           + CASE WHEN od.finish_time != '0000-00-00 00:00:00' THEN 1 ELSE 0 END) DESC
      ) AS rn
    FROM kflower_dw.dwm_kf_trd_hxz_order_base_view_di od
    JOIN order_call_time oct ON od.order_id = oct.order_id
    WHERE od.dt BETWEEN DATE '2026-03-02' AND DATE '2026-06-28'
      AND od.dt <= DATE_ADD(TO_DATE(oct.call_time), 7)
  ) d
  WHERE d.rn = 1
),

-- 3. 支付信息单独重构，不受发单后7天状态快照限制。
-- 只从 is_pay=1 的记录读取 voucher_pay，并取支付成熟截止日前最新支付快照。
-- A窗口最后一天为2026-05-31，扫描到2026-08-30。
order_payment_snapshot AS (
  SELECT
    p.order_id,
    p.voucher_pay
  FROM (
    SELECT
      od.order_id,
      COALESCE(CAST(od.voucher_pay AS DOUBLE), 0.0) AS voucher_pay,
      ROW_NUMBER() OVER (
        PARTITION BY od.order_id
        ORDER BY od.dt DESC,
                 CASE WHEN od.pay_time != '0000-00-00 00:00:00' THEN 1 ELSE 0 END DESC
      ) AS rn
    FROM kflower_dw.dwm_kf_trd_hxz_order_base_view_di od
    JOIN order_call_time oct ON od.order_id = oct.order_id
    WHERE od.dt BETWEEN DATE '2026-03-02' AND DATE '2026-08-30'
      AND TO_DATE(oct.call_time) BETWEEN DATE '2026-03-02' AND DATE '2026-05-31'
      AND od.is_pay = 1
  ) p
  WHERE p.rn = 1
),

-- 4. 订单特征计算 source_type: 1=用户发单 2=改派单 所有统计只算 source_type=1
order_features AS (
  SELECT
    passenger_id,
    o.order_id,
    call_time,
    answer_time,
    cancel_time,
    charge_time,
    finish_time,
    pay_time,
    is_td_answer,
    is_td_cancel,
    is_td_reassign,
    cancel_type,
    driver_start_dis,
    eta_second_pick_dur,
    COALESCE(p.voucher_pay, 0.0) AS voucher_pay,
    CASE WHEN p.order_id IS NOT NULL THEN 1 ELSE 0 END AS is_paid_observed,
    source_type,
    -- 周桶
    FLOOR(DATEDIFF(TO_DATE(call_time), DATE '2026-03-02') / 7) AS week_bucket,

    -- 计算应答单数
    CASE WHEN answer_time != '0000-00-00 00:00:00' THEN 1 ELSE 0 END AS is_answered,
    -- 计算完单数
    CASE WHEN finish_time != '0000-00-00 00:00:00' THEN 1 ELSE 0 END AS is_finished,
    --计算计费单数
    CASE WHEN charge_time != '0000-00-00 00:00:00' THEN 1 ELSE 0 END AS is_charged,
    -- 特征1：应答超时导致应答前取消（cancel_type=1 且 发单到取消>30s）
    CASE
      WHEN cancel_type = 1
           AND (UNIX_TIMESTAMP(cancel_time) - UNIX_TIMESTAMP(call_time)) > 30
      THEN 1 ELSE 0
    END AS no_answer_over_time,

    -- 特征2：应答超时（峰期>70s，非峰期>30s；峰期 06:30-09:59 或 16:30-19:59）
    CASE
      WHEN answer_time != '0000-00-00 00:00:00'
           AND (
             (HOUR(call_time)*3600 + MINUTE(call_time)*60 + SECOND(call_time) BETWEEN 23400 AND 35999
              OR HOUR(call_time)*3600 + MINUTE(call_time)*60 + SECOND(call_time) BETWEEN 59400 AND 71999)
             AND (UNIX_TIMESTAMP(answer_time) - UNIX_TIMESTAMP(call_time)) > 70
             OR
             NOT (HOUR(call_time)*3600 + MINUTE(call_time)*60 + SECOND(call_time) BETWEEN 23400 AND 35999
                  OR HOUR(call_time)*3600 + MINUTE(call_time)*60 + SECOND(call_time) BETWEEN 59400 AND 71999)
             AND (UNIX_TIMESTAMP(answer_time) - UNIX_TIMESTAMP(call_time)) > 30
           )
      THEN 1 ELSE 0
    END AS answer_over_time,

    -- 特征3：应答超距离（>3000米）
    CASE
      WHEN answer_time != '0000-00-00 00:00:00' AND driver_start_dis > 3000
      THEN 1 ELSE 0
    END AS answer_over_distance,

    -- 特征4：应答超接驾时间（>6min）
    CASE
      WHEN answer_time != '0000-00-00 00:00:00' AND eta_second_pick_dur > 6*60
      THEN 1 ELSE 0
    END AS answer_over_eta_time,

    -- 特征5：应答后乘客取消（cancel_type=2 且 应答到取消>20s）
    CASE
      WHEN cancel_type = 2
           AND (UNIX_TIMESTAMP(cancel_time) - UNIX_TIMESTAMP(answer_time)) > 20
      THEN 1 ELSE 0
    END AS answer_p_cancel_over_time,

    -- 特征6：应答后司机取消。改派订单单独归入特征7，避免重复计数
    CASE
      WHEN cancel_type = 3
           AND COALESCE(is_td_reassign, 0) != 1
           AND answer_time != '0000-00-00 00:00:00'
           AND cancel_time != '0000-00-00 00:00:00'
           AND (UNIX_TIMESTAMP(cancel_time) - UNIX_TIMESTAMP(answer_time)) > 20
      THEN 1 ELSE 0
    END AS answer_d_cancel_over_time,

    -- 特征7：原单发生改派
    CASE
      WHEN is_td_reassign = 1
      THEN 1 ELSE 0
    END AS reassign,

    -- 特征8：上车时间超时（charge_time - call_time > 6min）
    CASE
      WHEN charge_time != '0000-00-00 00:00:00'
           AND (UNIX_TIMESTAMP(charge_time) - UNIX_TIMESTAMP(call_time)) > 6*60
      THEN 1 ELSE 0
    END AS all_over_time
  FROM order_latest_within_7d o
  LEFT JOIN order_payment_snapshot p ON o.order_id = p.order_id
  WHERE TO_DATE(o.call_time) BETWEEN DATE '2026-03-02' AND DATE '2026-05-31'
),

-- 乘客周聚合 active_days by source_type
weekly_agg_base AS (
  SELECT
    passenger_id,
    week_bucket,
    -- 基础统计：source_type=1（不含改派）
    SUM(CASE WHEN source_type = 1 THEN 1 ELSE 0 END) AS week_order_cnt,
    SUM(CASE WHEN source_type = 1 THEN is_answered ELSE 0 END) AS week_answered_cnt,
    -- 含改派链路的应答机会数，作为特征7的业务分母
    SUM(is_answered) AS week_answer_hg_cnt,
    SUM(CASE WHEN source_type = 1 THEN is_finished ELSE 0 END) AS week_finished_cnt,
    SUM(CASE WHEN source_type = 1 THEN is_charged ELSE 0 END) AS week_charged_cnt,
    COUNT(DISTINCT CASE WHEN source_type = 1 THEN TO_DATE(call_time) END) AS week_active_days,
    -- 实际抵扣营销强度：voucher_pay=0 表示该订单没有抵扣
    SUM(CASE WHEN source_type = 1 THEN is_paid_observed ELSE 0 END) AS week_paid_cnt,
    SUM(CASE WHEN source_type = 1 AND voucher_pay > 0 THEN 1 ELSE 0 END) AS week_voucher_order_cnt,
    SUM(CASE WHEN source_type = 1 THEN voucher_pay ELSE 0.0 END) AS week_voucher_pay_sum,
    -- 特征1-5、8：source_type=1
    SUM(CASE WHEN source_type = 1 THEN no_answer_over_time ELSE 0 END) AS week_no_answer_over_time_cnt,
    SUM(CASE WHEN source_type = 1 THEN answer_over_time ELSE 0 END) AS week_answer_over_time_cnt,
    SUM(CASE WHEN source_type = 1 THEN answer_over_distance ELSE 0 END) AS week_answer_over_distance_cnt,
    SUM(CASE WHEN source_type = 1 THEN answer_over_eta_time ELSE 0 END) AS week_answer_over_eta_time_cnt,
    SUM(CASE WHEN source_type = 1 THEN answer_p_cancel_over_time ELSE 0 END) AS week_answer_p_cancel_over_time_cnt,
    -- 特征6：应答后司机取消，只统计用户原始发单
    SUM(CASE WHEN source_type = 1 THEN answer_d_cancel_over_time ELSE 0 END) AS week_answer_d_cancel_over_time_cnt,
    -- 特征7：改派，只统计发生改派的用户原始发单
    SUM(CASE WHEN source_type = 1 THEN reassign ELSE 0 END) AS week_reassign_cnt,
    -- 特征8：source_type=1，rate分母为计费单数
    SUM(CASE WHEN source_type = 1 THEN all_over_time ELSE 0 END) AS week_all_over_time_cnt
  FROM order_features
  GROUP BY passenger_id, week_bucket
),

weekly_agg AS (
  SELECT
    b.passenger_id,
    b.week_bucket,
    b.week_order_cnt,
    b.week_answered_cnt,
    b.week_answer_hg_cnt,
    b.week_finished_cnt,
    b.week_charged_cnt,
    b.week_active_days,
    b.week_paid_cnt,
    CAST(b.week_paid_cnt AS DOUBLE) / NULLIF(b.week_finished_cnt, 0) AS week_payment_coverage,
    b.week_voucher_order_cnt,
    b.week_voucher_pay_sum,
    CAST(b.week_voucher_order_cnt AS DOUBLE) / NULLIF(b.week_finished_cnt, 0) AS week_voucher_order_rate,
    CAST(b.week_voucher_pay_sum AS DOUBLE) / NULLIF(b.week_finished_cnt, 0) AS week_voucher_pay_per_finished_order,
    CAST(b.week_voucher_pay_sum AS DOUBLE) / NULLIF(b.week_voucher_order_cnt, 0) AS week_voucher_pay_avg,
    b.week_no_answer_over_time_cnt,
    CAST(b.week_no_answer_over_time_cnt AS DOUBLE) / NULLIF(b.week_order_cnt, 0) AS week_no_answer_over_time_rate,
    b.week_answer_over_time_cnt,
    CAST(b.week_answer_over_time_cnt AS DOUBLE) / NULLIF(b.week_answered_cnt, 0) AS week_answer_over_time_rate,
    b.week_answer_over_distance_cnt,
    CAST(b.week_answer_over_distance_cnt AS DOUBLE) / NULLIF(b.week_answered_cnt, 0) AS week_answer_over_distance_rate,
    b.week_answer_over_eta_time_cnt,
    CAST(b.week_answer_over_eta_time_cnt AS DOUBLE) / NULLIF(b.week_answered_cnt, 0) AS week_answer_over_eta_time_rate,
    b.week_answer_p_cancel_over_time_cnt,
    CAST(b.week_answer_p_cancel_over_time_cnt AS DOUBLE) / NULLIF(b.week_answered_cnt, 0) AS week_answer_p_cancel_over_time_rate,
    b.week_answer_d_cancel_over_time_cnt,
    CAST(b.week_answer_d_cancel_over_time_cnt AS DOUBLE) / NULLIF(b.week_answered_cnt, 0) AS week_answer_d_cancel_over_time_rate,
    b.week_reassign_cnt,
    CAST(b.week_reassign_cnt AS DOUBLE) / NULLIF(b.week_answer_hg_cnt, 0) AS week_reassign_rate,
    b.week_all_over_time_cnt,
    CAST(b.week_all_over_time_cnt AS DOUBLE) / NULLIF(b.week_charged_cnt, 0) AS week_all_over_time_rate
  FROM weekly_agg_base b
),

w_aggregate AS (
  SELECT
    passenger_id,
    -- 9周总量
    SUM(week_order_cnt) AS w_total_order_cnt,
    SUM(week_answered_cnt) AS w_total_answered_cnt,

    SUM(week_voucher_pay_sum) AS w_total_voucher_pay_sum,

    SUM(week_answer_over_eta_time_cnt) AS w_total_answer_over_eta_time_cnt,
    SUM(week_answer_p_cancel_over_time_cnt) AS w_total_answer_p_cancel_over_time_cnt,
    SUM(week_answer_d_cancel_over_time_cnt) AS w_total_answer_d_cancel_over_time_cnt,
    SUM(week_reassign_cnt) AS w_total_reassign_cnt,
    SUM(week_all_over_time_cnt) AS w_total_all_over_time_cnt,
    -- 9周比率（用总量计算，非简单平均）
    CAST(SUM(week_no_answer_over_time_cnt) AS DOUBLE) / NULLIF(SUM(week_order_cnt), 0) AS w_total_no_answer_over_time_rate,
    CAST(SUM(week_answer_over_time_cnt) AS DOUBLE) / NULLIF(SUM(week_answered_cnt), 0) AS w_total_answer_over_time_rate,
    CAST(SUM(week_answer_over_distance_cnt) AS DOUBLE) / NULLIF(SUM(week_answered_cnt), 0) AS w_total_answer_over_distance_rate,
    CAST(SUM(week_answer_over_eta_time_cnt) AS DOUBLE) / NULLIF(SUM(week_answered_cnt), 0) AS w_total_answer_over_eta_time_rate,
    CAST(SUM(week_answer_p_cancel_over_time_cnt) AS DOUBLE) / NULLIF(SUM(week_answered_cnt), 0) AS w_total_answer_p_cancel_over_time_rate,
    CAST(SUM(week_answer_d_cancel_over_time_cnt) AS DOUBLE) / NULLIF(SUM(week_answered_cnt), 0) AS w_total_answer_d_cancel_over_time_rate,
    CAST(SUM(week_reassign_cnt) AS DOUBLE) / NULLIF(SUM(week_answer_hg_cnt), 0) AS w_total_reassign_rate,
    CAST(SUM(week_all_over_time_cnt) AS DOUBLE) / NULLIF(SUM(week_charged_cnt), 0) AS w_total_all_over_time_rate,
    -- 发单数趋势：后4周平均 - 前5周平均（固定分母 4 和 5，缺失周补 0）
    SUM(CASE WHEN week_bucket BETWEEN 5 AND 8 THEN week_order_cnt ELSE 0 END) / 4.0

city_supply_raw AS (
  SELECT
    city_id,
    FLOOR(DATEDIFF(TO_DATE(dt), DATE '2026-03-02') / 7) AS week_bucket,
    distinct_city_time_bubble,
    distinct_city_time_send,
    distinct_city_time_finish,

  FROM kflower_strategy.city_time_history_statistics_data

  SELECT
    city_id,
    week_bucket,
    SUM(distinct_city_time_bubble) AS city_bubble,
    SUM(distinct_city_time_send) AS city_send,
    SUM(distinct_city_time_finish) AS city_finish,
    -- ecr 用 bubble 加权平均
    SUM(distinct_city_time_bubble * distinct_city_time_ecr)
      / NULLIF(SUM(distinct_city_time_bubble), 0) AS city_ecr
  FROM city_supply_raw
  GROUP BY city_id, week_bucket

-- 城市供需 9周汇总+后4周均+前5周均+趋势
city_supply_total AS (
  SELECT
    city_id,
    -- 9周汇总（量级 SUM，ecr 加权）
    SUM(city_bubble) AS city_total_bubble,
    SUM(city_send) AS city_total_send,
    SUM(city_finish) AS city_total_finish,
    SUM(city_bubble * city_ecr) / NULLIF(SUM(city_bubble), 0) AS city_total_ecr,
    -- W后4周平均（week 5-8，量级 AVG，ecr 加权）
    AVG(CASE WHEN week_bucket BETWEEN 5 AND 8 THEN city_bubble END) AS city_last4_avg_bubble,
    AVG(CASE WHEN week_bucket BETWEEN 5 AND 8 THEN city_send END)   AS city_last4_avg_send,
    AVG(CASE WHEN week_bucket BETWEEN 5 AND 8 THEN city_finish END) AS city_last4_avg_finish,
    SUM(CASE WHEN week_bucket BETWEEN 5 AND 8 THEN city_bubble * city_ecr END)
      / NULLIF(SUM(CASE WHEN week_bucket BETWEEN 5 AND 8 THEN city_bubble END), 0) AS city_last4_avg_ecr,
    -- W前5周平均（week 0-4）
    AVG(CASE WHEN week_bucket BETWEEN 0 AND 4 THEN city_bubble END) AS city_first5_avg_bubble,
    AVG(CASE WHEN week_bucket BETWEEN 0 AND 4 THEN city_send END)   AS city_first5_avg_send,
    AVG(CASE WHEN week_bucket BETWEEN 0 AND 4 THEN city_finish END) AS city_first5_avg_finish,
    SUM(CASE WHEN week_bucket BETWEEN 0 AND 4 THEN city_bubble * city_ecr END)
      / NULLIF(SUM(CASE WHEN week_bucket BETWEEN 0 AND 4 THEN city_bubble END), 0) AS city_first5_avg_ecr
  FROM city_supply_weekly
  WHERE week_bucket BETWEEN 0 AND 8
  GROUP BY city_id
```

差体验定义如下：

1. 应答超时导致应答前取消，发单到取消时间>30s

2. 应答超时，峰期>70s，非峰期>30s；峰期 06:30-09:59 或 16:30-19:59

3. 应答超距离，>3000米

4. 应答超接驾时间，>6分钟

5. 应答后乘客取消，取消到应答时间大于20s

6. 应答后司机取消

7. 发生改派

8. 上车时间超时，计费到发单时间超过6分钟

### W窗口

使用A窗口前已经确定的信息，包括：

1. 9周活跃度、发单数、应答数、完单数

2. 9周差体验次数和比例

3. 总订单量，活跃天数，比例，订单趋势，最近一次订单间隔

4. 使用优惠券相关信息（提供发券流失召回的间接混淆变量）

5. 城市供需信息和趋势

6. 用户画像特征

这些变量的作用是描述：

> 什么样的用户本来更容易遇到差体验，同时也更容易流失。

### A窗口

对于每一种差体验，只输入两个 A 期变量：

$$C_i=\text{该乘客A期差体验次数}$$

$$N_i=\text{该差体验的原生机会分母，发单数，应答数或完单数}$$

当前8种模型分别是

| 差体验 <br> | 次数  <br> | 原生机会分母 <br> |
| --- | --- | --- |
| 未应答超时 <br> | `a_total_no_answer_over_time_cnt` <br> | `a_total_order_cnt` <br> |
| 应答超时 <br> | `a_total_answer_over_time_cnt` <br> | `a_total_answered_cnt` <br> |
| 应答超接驾距离 <br> | `a_total_answer_over_distance_cnt` <br> | `a_total_answered_cnt` <br> |
| 应答超接驾时间 <br> | `a_total_answer_over_eta_time_cnt` <br> | `a_total_answered_cnt` <br> |
| 应答后乘客取消 <br> | `a_total_answer_p_cancel_over_time_cnt` <br> | `a_total_answered_cnt` <br> |
| 应答后司机取消 <br> | `a_total_answer_d_cancel_over_time_cnt` <br> | `a_total_answered_cnt` <br> |
| 订单改派 <br> | `a_total_reassign_cnt` <br> | `a_total_answer_hg_cnt` <br> |
| 全过程超时 <br> | `a_total_all_over_time_cnt` <br> | `a_total_charged_cnt` <br> |

### Y窗口

构造标签is_run，若用户在这个时间窗口有发单则未流失，is_run=0；反之则流失，is_run=1。

### 缺失值处理

1. 对于差体验特征

差体验次数缺失补0；差体验比例在分母大于0时重新计算，分母为0时补0。模型结合订单量、应答量或计费量等分母，可以区分“没有机会”和“有机会但没有发生差体验”。

2. 对于用户画像特征

数值特征缺失补0，并增加 `missing` 列标记是否缺失；类别特征转换为索引，其中0代表缺失。

3. 对于城市供需特征

缺失值补0，并增加统一的 `city_supply_missing` 标记，用于区分真实的0和城市信息未匹配。

4. 对于时间特征

日期转换成距观察窗口截止日的天数；日期缺失补0，并增加 `missing` 标记。W窗口没有历史订单时，最近订单间隔补为63天，并增加截断标记。
