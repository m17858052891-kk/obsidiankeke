# 拟合公式

log(CR/(1-CR)) = density_coef \* log(密度) + sod_coef \* log(拉齐量纲需供比) + b_coef \* log(b补率) + c_coef \* log(c补率) + + intercept，拟合采用岭回归，alpha=1。

修正后需供比(同量纲) = 期望需求时长/总供给时长={发单里程 ∗ (等驾时长 + 计费时长)/ 完单里程}/司机在线时长

CR = z / (1 + z)，其中z = exp ( density_coef \* log(密度) + sod_coef \* log(拉齐量纲供需比) + b_coef \* log(b补率) + c_coef \* log(c补率) + + intercept)，即可得到对应城市在该密度和供需比下的估计值。

采用包含当前周的4周数据拟合，表示本周的交易效率，每周更新。例如拟合2月22日～2月28日的交易效率，需要使用2月1日～2月28日的数据拟合。

GMV_CR拟合方式同上。

说明：log以e为底数

# 参数字典

数据落入表[kflower_strategy.cr_monitoring](http://datamap.didichuxing.com/detail?uri=hive://mycluster-tj:kflower_strategy:cr_monitoring)中，关键字解释如下：

city_id：城市id

density：城市近四周的订单密度平均值

sod：城市近四周的供需比平均值

subsidy_b：城市近四周的b补均值

subsidy_c：城市近四周的c补均值

cr_density_coef：CR拟合的密度系数

cr_sod_coef：CR拟合的供需比系数

cr_b_coef：CR拟合的b补系数

cr_c_coef：CR拟合的c补系数

cr_intercept：CR拟合的偏置

cr：CR近四周的平均值

cr_r2：CR拟合的r方

cr_mae：CR拟合的mae

gmv_density_coef：GMV拟合的密度系数

gmv_sod_coef：GMV拟合的供需比系数

gmv_b_coef：GMV拟合的b补系数

gmv_c_coef：GMV拟合的c补系数

gmv_intercept：GMV拟合的偏置

gmv_cr：GMV CR近四周的平均值

gmv_r2：GMV拟合的r方

gmv_mae：GMV拟合mae

# 运筹需求

hive表中 XX 存储每周每个城市的交易效率CR和GMV_CR的拟合函数，用五元组(density_coef，sod_coef，b_coef，c_coef，intercept)表示。

运筹上可以选择城市/时间，输入（密度，拉齐量纲需供比，b补率，c补率），然后根据下面的公式可以计算每周的CR和GMV_CR，绘制曲线。

log(CR/(1-CR)) = density_coef \* log(密度) + sod_coef \* log(拉齐量纲需供比) + b_coef \* log(b补率) + c_coef \* log(c补率) + intercept
