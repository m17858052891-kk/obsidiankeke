### 一、背景

随着需供比的提升，在峰期逐渐出现挑单的空间，结合之前hold参数的计算逻辑，通过双开模型，为双开概率低的司机进行挑单，观察大盘效果。

### 二、需求详述

结合v0 hold参数的计算逻辑，在司机完单or上线时刻，调取双开率模型，若司机双开概率小于阈值，根据司机所处格子读取缓存的hold参数，若cd_time>0，则触发hold，

在\[t0, t0+cd_time)时间内过滤掉订单IPH<cd_iph的订单不参与召回；否则，本轮未命中hold逻辑，正常派单。

### 四、实验评估

评估指标：大盘GMV

关注指标：

1、实验周期的分单中，Hold策略生效占比

 $$\\frac{\\text{命中Hold且生效的DO对数}}{\\text{所有DO对数(生效+未生效)}}$$ $$\\frac{\\text{命中Hold但因双开率大于阈值未生效的DO对数}}{\\text{所有DO对数(生效+未生效)}}$$ $$\\frac{\\text{在cd_time时段中，命中Hold且生效的司机听单次数}}{\\text{所有司机听单次数}}$$ $$\\frac{\\text{在cd_time时段中，命中Hold但因双开率大于阈值未生效的司机听单次数}}{\\text{所有司机听单次数}}$$

2、实验周期的分单中，Hold策略成功率

 $$\\frac{\\text{在cd_time时段中，命中Hold且有播单的司机听单次数}}{\\text{命中Hold未被播单而下线的司机听单次数+命中Hold且有播单的司机听单次数}}$$

3、实验周期中，双开率模型的badcase率

评估方式：

城市灰度+时间片轮转 <http://ab.intra.hongyibo.com.cn/abtest/v3/exp/234714>

            kflower_marketplace.ods_log_kflower_iph_hold

    ) B on A.driver_id = B.driver_id
    and A.order_id = B.order_id
group by city;

--********************************************************************--

--remind:请在资源引用中添加需要引用的资源,presto不能建表,无法使用自定义UDF

select
    count(*) total_DO_counts,
    count(if(cd_time > 0, true, null)) hold_take_effect_counts,
    count(
        if(
            order_iph < cd_iph
            and both_online_rate <= 0.3,
            true,
            null
        )
    ) hold_filterd_DO_counts,
    count(
        if(
            order_iph < cd_iph
            and both_online_rate > 0.3,
            true,
            null
        )
    ) hold_should_have_filterd_but_high_both_rate_DO_counts,
    city
from
    (
        select distinct 
            cast(param ['driverid'] as bigint) driver_id,
            cast(param ['orderid'] as bigint) order_id,
            cast(param ['city'] as int) city,
            cast(param ['gap_time'] as int) cd_time,
            cast(param ['cd_iph'] as int) cd_iph,
            cast(param ['order_iph'] as double) order_iph,
            cast(param ['both_online_rate'] as double) both_online_rate
        from
            kflower_marketplace.ods_log_kflower_iph_hold
        where
            concat_ws('-', year, month, day) = '2021-02-24'
            and minute(param ['timestamp']) < 30
            --and hour(param ['timestamp']) not in (7,8,17,18,21,22)
    ) T
group by
    city;
