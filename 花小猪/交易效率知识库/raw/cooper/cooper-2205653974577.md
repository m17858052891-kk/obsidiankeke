# 一、需求背景

1. 目前宏鹄扩播无接驾金转抢单规则不支持通过Apollo进行分流实验流量配置，无法单独对线上小流量实验组下掉该规则；**保持该规则前提下新版召回策略将无法达到预期效果**；

2. 商家新一版召回策略自营实验收益显著，大聚合完单约+3%，同时应答司乘取消也有显著降低；因此希望对宏鹄侧继续实验，为保证实验组新版策略正常生效，同时对照组保持现状进行合理评估，**需要支持仅对实验组将扩播无接驾金转抢单规则下掉**；

# 二、需求类型归纳

预判有收益，需开发新增功能；

# 二、需求收益判断

基于上一版部分实验结果，宏鹄大聚合完单+2%，应答后司乘取消率不显著提升；


# 三、需求说明和功能点

## 需求说明：

宏鹄扩播单无接驾金转抢单规则支持Apollo流量配置：

可以进行多分组PID分流实验，仅对对照组保持该规则生效，实验组静默本规则；

# 四、需求通用属性

**覆盖范围**：

商家分单引擎Common Recall模块；交易规则策略链路优化；

# 五、效果评估方案

**实验方式**：PID随机分流实验；

**核心指标：**商家大聚合完单；应答后司乘取消率；
