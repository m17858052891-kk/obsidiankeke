# 一、问题与假设

# 二、实验设计

- **R04实验的目的：（1）检验近距离规则的效果；（2）检验OCR截断的效果；**

- 对比内容：

	- CAA模型：对于近距离用两种方法实现近距离减少过滤：直接将近距离的caa输出置0，或者减0.1；

	- OCR模型：设置上限0.8，在等待时长很长时仍过滤极差履约（对应caa 0.86）

- 实验组设置：

	- 组1: CAA近距离1500caa置0；OCR单调

	- 组2: v5；OCR单调

	- 组3: CAA近距离1500caa-0.1；OCR单调+截断

	- 组4: CAA近距离1500caa置0；OCR单调+截断

- R04 可以形成三组有效对比：

	- 近距离置零规则：G1（rule1500）对比 G2（v5）

	- OCR 上限截断：G4（clamp）对比 G1（不截断）

	- 两种近距离规则：G4（1500米内置0）对比 G3（1500米内减0.1）

# 三、实验结论

### 3.1 OCR 截断结论

G4 相比 G1，两组使用相同的 `rule1500`，主要差别是 G4 增加 OCR 上限截断：

- 动机：OCR截断的动机是为了在等待时间较久、流失率较高时仍过滤极差履约的OD。G4vsG1。**预期是G4会过滤掉更多高CAA的OD，完单折损但是距离更好。但是实验结果和预期相反？**G4是否确实整体CAA更低、整体召回更少。**截断动作在方向上是加大hold**。而且主要是在长时间分桶上。

- **大盘结果：G4（截断）的大盘完单更好，但是距离更差**

- **过程机制解释**：

	- OD✖️轮次、Distinct OD、O✖️轮次维度的G4的召回率都更低，**证明G4确实过滤更多****；**

	- **但是Distinct O维度的召回率G4和G1基本一致，表明G4的过滤基本都是过滤的冗余司机，并不减少O维度的召回率。**

	- **同时发现G4的末次召回平均等待时长比G1更长，但是OD维度的召回距离基本一致、O维度的召回距离更远，说明在等待较长时间后的继续过滤，并无法通过等待更久来得到更近的召回司机，反而距离会更远。**

- 后续：当前 OCR 截断没有改善完单、覆盖或履约质量，反而加剧司机接驾时长和综合等待时长，不在下一版 baseline 中保留。

### 3.2 近距离规则结论

G3和G4对比两种不同的近距离规则方式：

- 结论：G3 更偏向保障召回和完单，G4 更偏向控制距离和接驾成本。

- 动机：G3减0.1保留了候选之间的相对排序，而且整体hold更多，仍会过滤近距离低履约的OD，**因此预期是G3在近距离分桶上的召回更少但是应答后履约更好**。

- 大盘结果：G3（减0.1）大盘完单更好，距离更差

- **过程机制解释**：

	- **近距离（1500米以下）分桶上G3、G4召回份额均明显大于无近距离规则组（G2）**，**近距离分桶G4召回份额相比G3更高，证明近距离规则有效**。

	- 但是发现在远距离上的召回份额G3和G4有较大差异，G3召回更多，不符合预期，待检验模型看原因。最终带来的影响是G3反而整体hold力度更小，最终完单更好，距离更差，但这无法说明在近距离分桶上两种规则哪种更优。

	- **后续**：**结论是两种近距离规则均能将0～1500分桶的召回率提升2pp左右，且G3的整体履约会更好，后续选择G3作为近距离约束规则；**同时发现远距离加权在这两版模型均未实现导致整体距离上涨，**后续模型同时生效距离加权和近距离规则。**
