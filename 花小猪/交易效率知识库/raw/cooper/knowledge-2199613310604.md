## 背景

应答后乘客取消订单中23%会重复发单，因此推测是接驾距离或者应答cp价格因素导致取消，这样，在乘客应答后为乘客透传持续寻找【更近更便宜】订单理论上会减少取消。

触发“改派”后并不会真实寻找司机，因此选取收益高的订单进行实验更合适。

考虑到订单里程、接驾时长、应答cp价格会影响应答后乘客取消率，故对此进行分析。

## 分析

- 20km以下的订单，随着订单里程的增加乘客取消率下降

- 相同里程订单，预估接驾时长增加乘客取消率增加；随着订单里程增加，乘客对接驾时长的容忍度增加

- 应答价格增幅>1.5的订单数较少，因此波动很大。 在相同里程，接驾时长<6min的订单中，随着应答价格增幅增加，取消率平稳增加；接驾时长>7min的订单会在应答价格增幅 =1.2时下降，之后平稳增加，推测是由于勾选cp价格范围在1.1以内的乘客更价敏，不过这部分订单较少，可不考虑

## 结论

大部分订单未在某个应答价格增幅处出现明显的拐点，而是随着价格增幅的增加，乘客取消率逐渐增加。综合考虑预估接驾时长和订单里程，可以认为，订单里程下降，预估接驾时长增加，应答价格增幅增加，应答后乘客取消率增加。可以根据订单量的分布和预期覆盖面划定阈值。

with ord as (
    select
        --总呼叫
        distinct order_id,
        bubble_trace_id,
        product_2level,
        est_price_amt,
        gmv_amt,
        p_total_fee_amt,
        cancel_type,
        cancel_dur,
        source_type,
        eta_second_pick_dur,
        case
            when int(eta_second_pick_dur / 60) > 9 then 10
            else int(eta_second_pick_dur / 60)
        end as pick_dur_gp,
        start_dest_dis,
        case
            when start_dest_dis <= 3000 then '3km'
            when start_dest_dis <= 5000 then '5km'
            when start_dest_dis <= 10000 then '10km'
            when start_dest_dis <= 15000 then '15km'
            when start_dest_dis <= 20000 then '20km'
            else '20km+'
        end as dis_gp
    from
        kflower_dw.dwd_kf_trd_order_base_di
    where
        dt between '2022-05-11'
        and '2022-05-17'
        and is_td_call = 1
        and is_td_answer = 1
        and product_1level not in (4)
),
bub as (
    select
        trace_id,
        --冒泡返回all品牌
        product_2level,
        selected_status
    from
        kflower_dw.dwd_kf_trd_bubble_base_all_di
    where
        dt between '2022-05-11'
        and '2022-05-17'
    group by
        trace_id,
        product_2level,
        selected_status
),
call_log1 as (
    select
        --冒泡页面呼叫
        order_id,
        product_2level,
        estimate_fee
    from
        kflower_dw.dwd_kf_trd_order_create_base_di
    where
        dt between '2022-05-11'
        and '2022-05-17'
    group by
        order_id,
        product_2level,
        estimate_fee
),
call_log2 as (
    select
        --相同order_id 追加日志追加
        order_id,
        product_2level,
        estimate_fee
    from
        kflower_dw.dwd_kf_trd_order_append_di
    where
        dt between '2022-05-11'
        and '2022-05-17'
        and log_type = 2 --追加呼叫
    group by
        order_id,
        product_2level,
        estimate_fee
)
select
    dis_gp,
    pick_dur_gp,
    round(answer_fee / min_estimate_fee, 1) as fee_times,
    count(distinct if(source_type <> 2, order_id, null)) as answer_cnt,
    count(distinct if(cancel_type = 2, order_id, null)) as cancel_cnt
from
    (
        select
            order_id,
            cancel_type,
            source_type,
            eta_second_pick_dur,
            start_dest_dis,
            pick_dur_gp,
            dis_gp,
            max(answer_2level) as answer_2level,
            max(answer_fee) as answer_fee,
            min(estimate_fee) as min_estimate_fee
        from
            (
                select
                    distinct ord.order_id as order_id,
                    ord.product_2level as answer_2level,
                    case
                        when ord.product_2level = call_log1.product_2level then call_log1.estimate_fee
                        when ord.product_2level = call_log2.product_2level then call_log2.estimate_fee
                        else null
                    end as answer_fee,
                    case
                        when call_log1.product_2level is not null then call_log1.product_2level
                        else call_log2.product_2level
                    end product_2level,
                    case
                        when call_log1.estimate_fee is not null then call_log1.estimate_fee
                        else call_log2.estimate_fee
                    end estimate_fee,
                    cancel_type,
                    source_type,
                    cancel_dur,
                    eta_second_pick_dur,
                    start_dest_dis,
                    pick_dur_gp,
                    dis_gp
                from
                    ord
                    left join bub on ord.bubble_trace_id = bub.trace_id
                    left join call_log1 on ord.order_id = call_log1.order_id
                    and bub.product_2level = call_log1.product_2level
                    left join call_log2 on ord.order_id = call_log2.order_id
                    and bub.product_2level = call_log2.product_2level
                where
                    call_log1.order_id is not null
                    or call_log2.order_id is not null
            ) as a
        group by
            order_id,
            cancel_type,
            cancel_dur,
            source_type,
            eta_second_pick_dur,
            start_dest_dis,
            pick_dur_gp,
            dis_gp
    ) t
where
    round(answer_fee / min_estimate_fee, 1) is not null
    and round(answer_fee / min_estimate_fee, 1) < 2
group by
    dis_gp,
    pick_dur_gp,
    round(answer_fee / min_estimate_fee, 1)
order by
    dis_gp,
    pick_dur_gp,
    round(answer_fee / min_estimate_fee, 1)
