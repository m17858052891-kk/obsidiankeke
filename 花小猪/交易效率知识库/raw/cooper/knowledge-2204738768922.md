# 1、背景

司机诱导取消是体验治理的对象。继PK引入司机长时取消因子之后，考虑以类似方法引入司机诱导取消因子，降低司机恶意取消率

目标：约束大盘完单不负，降低司机诱导乘客取消率、司机恶意有责率

# 2、技术方案

特征建设：建设花小猪端司机近14天诱导取消数特征

特征加权：将**司机近14天诱导取消率**乘一个权重，直接加进**司机近14天司乘取消率**，限制特征值不超过1

- 权重公式：$$w= (1 - 乘客取消中重发单比例)/司机取消中未改派比例 = (1 - 0.591)/0.0891 = 4.59$$

- 权重公式中，分子衡量乘客取消1单对完单的折损，分母衡量司机取消1单对完单的折损

模型建设：对司机近14天司乘取消率特征进行加权融合后，重复PK模型的建模链路

# 3、实验评估

实验方式：乘客随机分流实验

实验周期：2025-06-20～2025-06-26

实验城市：未被预留给模型自动化更新实验的城市，覆盖全国总完单数的80%

大盘指标：小猪端成交率不显著+0.04pp，完单数不显著-0.15%

治理效果：司机诱导取消率显著-0.04pp（-6.18%），司机恶意取消率显著-0.02pp（-4.89%）
