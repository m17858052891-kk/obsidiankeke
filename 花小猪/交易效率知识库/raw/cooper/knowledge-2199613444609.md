### 指定本地分支

```PlainText
git clone https://git.xiaojukeji.com/Zeroizer/athena-predict.git //直接从git上clone，方便不同分支之间互相切换
git pull//获取远程分支
git branch -a
git checkout feature_oe_intervals_random//切换分支
```

也可以git clone -b feature_oe_intervals_random https://git.xiaojukeji.com/Zeroizer/athena-predict.git只下载指定分支

### 编辑本地分支

指定本地分支后，即可在GoLand上继续编辑。注意配置[本地GOPATH、GOROOT环境](https://studygolang.com/articles/28913) 和 GoLand 上的GOPATH。

可以通过 echo $GOPATH 进行检验

GoLand上的GOPATH可以通过如图方式进行配置

![](https://s3-ep-inter.didistatic.com/didoc-upload-file-prod/1653034008701/860100936.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKDD00000000000EBLCTZNRBJHX6ZS%2F20261104%2Fgzep%2Fs3%2Faws4_request&X-Amz-Date=20261104T112240Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=af9212735fa857c1ea3a62623e34e1bbea74b10feaed6af0a631b1c0e6d700d2)

**提交代码**

```PlainText
git status //查看在上次提交之后是否有对文件进行再次修改
git add src/ //将需要提交的代码添加到暂存区
git commit -m"test fix"  //将暂存区里的改动给提交到本地的版本库
git push //如果push被reject，可以先git pull
```

git使用说明可以参考[git使用](http://wiki.intra.xiaojukeji.com/pages/viewpage.action?pageId=98841235)

### 主干同步

如果提示主干同步，可以在oe上同步。如无法自动同步，需要手动同步，可以按照提示进行

```PlainText
git clone https://git.xiaojukeji.com/Zeroizer/internal_common_recall.git
git checkout feature_oe_gs_order_value_change
git merge tag-oe-95-20210223112109326 -m "merge from master manually"
git add src/
git commit -m "merge-code-from-master"
git push origin feature_oe_gs_order_value_change
```

### 自测

在oe上下载编译打包任务

![](https://s3-ep-inter.didistatic.com/didoc-upload-file-prod/1653034009178/860100944.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKDD00000000000EBLCTZNRBJHX6ZS%2F20261104%2Fgzep%2Fs3%2Faws4_request&X-Amz-Date=20261104T112240Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=6632331a9e681eeb980d412ea824d074a9a7d5af5e5d489b3936974f8fbc6898)

复制编译任务链接地址后

```PlainText
wget 链接地址  //下载
tar -xvzf Zeroizer_athena-predict_parameter_centos7.2_20210222190900.tar.gz //解压压缩包
mv output athena_predict//可将解压文件夹重新命名
```

复制已经备份的压缩包dcm-mockserver.tar.gz、redis.tgz、ep.tar.gz

并配置好athena-predict.conf、disf.yaml、dirpc.json、nodemgr.json

配置好后在athena_predict目录下启动

```PlainText
sh control.sh start   //或者nohup bin/athena-predict > /dev/null 2>&1 & 强制启动
ps aux|grep athena
ps aux|grep dcm   //检查是否运行起来
cd /home/xiaoju/ep/as/store/toggles/  //可以在此路径修改apollo的配置
sh control.sh stop  //终止运行
```

在此之前，也可以先在dcm-mockserver和redis目录下sh start.sh start

运行起来后可以在GoLand中运行test文件，如test_willing_wait.go，注意修改ip地址

```PlainText
go run ./test_willing_wait.go
```

注意查看运行结果，和运行日志

```PlainText
less athena-predict/log/athena-predict.log.wf
less athena-predict.log.info
```

如在运行日志中出现配置报错，可以将athena_predict/bin拷贝到配置无误的机器上

自测无误后可以在oe上进行提测
