# 一、需求背景

小猪端目前乘客预期相关等待页及特快盒子应答时长模型预估为深度模型，部署方式为luban离线训练导出模型至eve集群部署。特快(大盘)超时赔等产品的赔付时间依赖于当前线上模型，反应模型预估时间误差较大，选用XGB作为base模型重新训练后在离线数据上误差显著降低(特快误差18s降至14s，应答页误差20s降至15s左右)。因此考虑将原深度模型替换为XGB模型，同时可以利用EVE提供的模型定期自动更新功能减少人力投入。

# 二、需求类型归纳

预判有收益，要新增能力。

# 二、需求收益判断

收益来源：

      a. 线上预估等待时间误差进一步缩小，超时赔等业务有更准确的模型数据支持；

b. 实现模型定期自动更新，减少人力投入；

# 三、需求说明和功能点

## 需求说明：

深度模型替换为XGB在日志采集等部分有不同，同时注意平稳过渡；

## 功能点:

工程侧将预期管理应答时长预估深度模型调用调整为XGB，保证线上特征传入及返回值无误。

# 四、需求通用属性

覆盖范围: Athena模块。

# 五、效果评估方案

应答时长预估误差降低；

模型定期自动更新；
