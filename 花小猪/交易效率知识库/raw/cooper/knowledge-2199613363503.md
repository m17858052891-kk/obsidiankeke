# 0. Objective

Q：短时的模拟系统是for什么目标？

A：通过模拟系统来优化迭代分单策略（比如hold，GS，km）；更理想的，通过对多个episode的订单回放，辅助策略调超参。

Q：为什么需要一个短时的模拟系统，之前模拟系统（工程团队模拟一整天分单的系统）不够用吗 ？

A：之前模拟系统跑一天的任务时间成本太高，且回放一天的数据评估效率的时候，司机调度策略（reposition）的效果和分单策略的效果（dispatch）很难拆清楚；

新平台不太关注调度，或者说调度是否有效果很难验证，我们希望能更多的迭代分单策略。短时模拟系统能更聚焦在短时司乘时空分布稳定的场景，分单策略直接影响效率。

Q：短时的模拟系统还可以？

A：考虑竞争态的分单策略

# 2. Features

- 短时模拟系统，更聚焦在一个时间片内（10min）调整分单策略来提升效率。有一些强假设：

	- 假设司机全程在线，且初始时刻就在线（不下线，空闲时间不游走）

	- 初始司机包括空闲司机以及10min内完单司机

	- 双开情况下，司机优先接wyc

	- 不考虑司机调度

	- 订单不取消（假设是通过愿等能拉长用户等待时长）

- 纳入hxz和wyc的订单和所有司机，模拟竞争环境下的策略效果
