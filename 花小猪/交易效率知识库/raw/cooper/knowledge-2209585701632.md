# 差体验对流失率影响指标v1

# 1. 全局降低差体验PP的反事实计算

在当前预测数据上计算目标差体验占全部订单的比例：$$G= \frac{\sum_i C_i} {\sum_i\text{order\_cnt}_i}$$，其中$$C_i$$是该差体验发生数量。若目标是绝对下降$$\Delta PP$$，则目标差体验率为：$$G'=G-\frac{\Delta}{100}$$，差体验事件保留比例为$$\rho=\frac{G'}{G}$$，对每位乘客的差体验次数进行二项稀释：$$C_i' \sim \operatorname{Binomial}(C_i,\rho)$$。在反事实计算中需要保持W窗口的协变量保持不变，订单数，发单数，完单数$$N_i$$不变，只减少目标差体验次数$$C_i$$。然后计算新的剂量：$$R_i'=C_i'/N_i$$，并使用结果模型得到反事实流失概率：$$\hat p_i^{cf} = \hat P(Y_i=1\mid W_i,N_i,C_i')$$，最终估计流失概率的绝对下降：

$$\Delta_Y = \frac{1}{n} \sum_{i=1}^{n} \left( \hat p_i^{obs}-\hat p_i^{cf} \right) \times100$$。

## 1.1二项稀释示例

假设某位乘客原来发生3次差体验，即C=3，保留概率$$\rho=0.8$$，那么$$C'\sim\operatorname{Binomial}(3,0.8)$$，各种结果的概率为：

| 稀释后次数$$C'$$ <br> | 概率 <br> |
| --- | --- |
| 0 <br> | $$0.2^3=0.8\%$$ <br> |
| 1 <br> | $$3\times0.8\times0.2^2=9.6\%$$ <br> |
| 2 <br> | $$3\times0.8^2\times0.2=38.4\%$$ <br> |
| 3 <br> | $$0.8^3=51.2\%$$ <br> |

保证了期望是3\*0.8=2.4，同时次数为整数，同时这个能模拟用户跨越Hurdle门槛的情况，即稀释后次数等于0，模拟完全消除这个差体验的情况。
