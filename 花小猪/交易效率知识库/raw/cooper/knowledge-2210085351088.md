# 一、需求背景

前序在商家匹配策略[【交易效率-商家分单-商家匹配重构V1.0-V2】](https://cooper.didichuxing.com/knowledge/2199610335356/2209500732798)中，重新定义了对全指派、半指派、抢单三个模式下各个动作得分Score的定义：

$$\boxed{ \begin{aligned} Score_{ijk} =r_{ijk}a_{ijk}(1-e_{ijk}) \Bigg[ &\theta_{c,h}+(\lambda_{c,h,0} + \lambda_{c,h,1}) \hat{f}_{ijk} -\frac{D_{ijk}}{D_{cap}}\\ &-\lambda_{d,c,h}(d_{ijk}-d_{0,c}) -\lambda_{p,c,h}(c_{ijk}-c_{0,c}) \Bigg] \end{aligned} }$$

从公式中我们可以发现，当候选OD的接驾距离较高或司乘取消率超出目标值，会在惩罚项上产生较大作用，从而使$$Score < 0$$。经过抽样数据发现，该负分目前占比约18%，负分候选OD虽然可能是由于约束不达标造成，但当前如果直接过滤或者降级走距离打分决策派单模式&PK价值模型定义OD得分，会造成匹配量下降及策略无法实际生效的问题。

**改造必要性：**

- 与倾斜得分兼容，虽然当前线上经确认未存在倾斜系数通过乘法作用OD分，但为了考虑后续策略加入的稳定性，理应避免有OD得分<0的定义；

**改造充分性：**

- 保证取值范围兼容倾斜得分，商家匹配策略V1.0中，已实现定义$$\frac{Score}{M_0}$$将Score量纲统一到$$[0,1]$$区间与当前OD价值一致，但当改为$$\frac{Score + x}{M_0}$$时，如果$$x$$不可配置且与Score量级存在较大差异时，$$M_0$$则只能将原Score生效在$$[\frac{x}{M_0},1]$$区间，从而造成在$$[0,\frac{x}{M_0}]$$区间无法生效有效OD得分；

- 保证排序性，通过将所有候选OD的得分Score改造为$$score+x$$形式，使所有$$x$$值相等且实现score相对0值的同量级偏移，保证了排序有效性，使Score在$$[0,1]$$区间生效。

# 二、目标与收益

目标：修正商家匹配策略V1.0中Score定义，避免负分Score，保证匹配策略V1.0完全生效。

收益：暂无

# 三、需求内容

在匹配策略V1.0中Score的基础上，对每候选OD的Score计算改造为$$score+x$$形式，$$x$$为appllo可配置参数。

# 四、实验方案

本次改造不单独做线上实验，统一在[【交易效率-商家分单-商家匹配重构V1.0-V2】](https://cooper.didichuxing.com/knowledge/2199610335356/2209500732798)中进行实验。
