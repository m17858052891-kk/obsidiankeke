# 对比学习、对抗学习

## **1.定义**

| 概念 <br> | 定义 <br> |
| --- | --- |
| **对比学习** <br> | 一种自监督表征学习范式。通过构造正负样本对，在特征空间中拉近语义/结构相似的样本，推远不相似的样本，从而学习更具判别性与鲁棒性的隐式表征。常用损失为 InfoNCE 或 NT-Xent。 <br> |
| **对抗学习** <br> | 基于极小极大博弈（Min-Max Game）的特征优化策略。在特征提取器与判别器之间构建对抗关系，迫使特征提取器生成对判别任务具有“欺骗性”的表征，进而实现特征解耦、域适应或任务不变性学习。 <br> |
| **本方案定义** <br> | 在 PLE 架构中**并行引入对比学习与对抗学习**：对比学习用于增强专家网络输出表征的类内紧凑性与类间可分性；对抗学习用于显式解耦共享特征与任务专属特征，提升多任务学习的泛化能力与稳定性。 <br> |

## 2. 方法（对比学习集成）

### 2.1 核心思想

在 PLE 的特征交叉层（SENet+Bilinear）输出后注入对比学习分支，通过**视图增强 + 投影头 + InfoNCE 损失**，使模型在优化主任务的同时学习更具判别性与鲁棒性的特征表征。

### 2.2 样本构造策略（代码对齐版）

- **正样本对**：同一输入样本经**不同 Dropout mask**生成的两个增强视图（`crossed_features1`, `crossed_features2`），保持语义一致但引入随机扰动。

- **负样本对**：Batch 内其他样本的投影特征，通过矩阵乘法隐式构造 $$N-1$$ 个负样本。

- **增强方式**：训练时启用 `F.dropout(p=0.2)`，推理时关闭，确保增强仅在对比分支生效。

### 2.3 损失函数（代码对齐版）

采用 **InfoNCE + L2 归一化** 实现，与 `torch.nn.functional.cross_entropy` 兼容：

$$\mathcal{L}_{\text{contrast}} = \frac{1}{N} \sum_{i=1}^{N} \text{CE}\left( \frac{\mathbf{z}_i^{(1)} \cdot (\mathbf{z}^{(2)})^\top}{\tau}, \quad y_i = i \right)$$

其中：

- $$\mathbf{z}^{(1)}, \mathbf{z}^{(2)} = \text{ProjHead}(\text{Dropout}(\mathbf{h}))$$为两视图投影特征 -$$\text{CE}(\cdot)$$为交叉熵损失，标签为对角线位置（正样本索引） -$$\tau$$ 为温度系数（代码默认 `0.1`），控制相似度分布的尖锐程度

### 2.4 伪代码实现（与代码逻辑对齐）

```Python
# === 对比学习核心模块伪代码 ===
class ContrastiveModule(nn.Module):
    def __init__(self, feature_dim, proj_dim=128, temp=0.1):
        super().__init__()
        # 投影头：feature_dim → 256 → proj_dim
        self.projection_head = nn.Sequential(
            nn.Linear(feature_dim, 256),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(256, proj_dim)
        )
        self.temp = temp  # 温度系数
    
    def _infonce_loss(self, z1, z2):
        # L2 归一化
        z1, z2 = F.normalize(z1, dim=1), F.normalize(z2, dim=1)
        # 计算相似度矩阵 [B, B]
        logits = (z1 @ z2.t()) / self.temp
        # 正样本标签：对角线
        labels = torch.arange(z1.size(0), device=z1.device)
        return F.cross_entropy(logits, labels)
    
    def forward(self, features, training=False):
        if not training:
            return None  # 推理时不计算对比损失
        # 视图增强：不同 Dropout mask
        v1 = F.dropout(features, p=0.2, training=True)
        v2 = F.dropout(features, p=0.2, training=True)
        # 投影 + 损失计算
        z1, z2 = self.projection_head(v1), self.projection_head(v2)
        return self._infonce_loss(z1, z2)

# === PLEModel 前向传播集成伪代码 ===
def forward(self, features, return_contrast=False):
    # ... [原始特征提取 + SENetBilinear 交叉] ...
    crossed_features = self.feature_cross(combined_features)  # [B, D]
    
    # 对比学习分支（仅训练时）
    contrast_loss = None
    if return_contrast and self.training:
        contrast_loss = self.contrast_module(crossed_features, training=True)
    
    # ... [PLE 路由 + 任务塔计算] ...
    
    # 返回结果
    if return_contrast and self.training:
        return tower_outputs, contrast_loss
    return tower_outputs

# === 训练步骤伪代码 ===
for batch in dataloader:
    # 前向传播（启用对比分支）
    preds, cl_loss = model(batch_features, return_contrast=True)
    
    # 计算主任务损失（如 BCE/Focal）
    task_loss = criterion(preds, labels)
    
    # 联合优化
    total_loss = task_loss + self.contrast_weight * cl_loss
    total_loss.backward()
    optimizer.step()
```

## 3. 对抗定义

### 3.1 核心目标

通过对抗机制实现**特征解耦（Feature Disentanglement）**，在本方案中具体为：

- 迫使 `SENetBilinear` 输出的交叉特征 **不包含二进制敏感信息**（如用户身份、场景标识等）

- 释放 `Task-Specific Experts` 专注学习任务相关判别信号，避免共享特征被任务特定噪声污染

- 显式抑制多任务间的特征干扰与梯度冲突，提升模型泛化能力

### 3.2 博弈结构（代码对齐版）

| 角色 <br> | 网络模块 <br> | 优化方向 <br> | 代码对应 <br> |
| --- | --- | --- | --- |
| **特征提取器** <br> | SENetBilinear + PLE 共享专家 <br> | 最小化对抗判别损失（"欺骗"判别器） <br> | `self.feature_cross` + `self.grl` <br> |
| **任务判别器** <br> | 轻量级 MLP (`adversarial_net`) <br> | 最大化二进制特征预测准确率 <br> | `self.adversarial_net` <br> |

### 3.3 数学表述

设共享特征为 $$\mathbf{h} = \text{SENetBilinear}(\mathbf{x})$$，二进制标签为 $$y_b \in \{0,1\}$$，判别器为 $$D_\phi$$，GRL 缩放系数为 $$\lambda$$，则对抗优化目标为：

$$\min_{\theta_E} \max_{\phi} \mathcal{L}_{\text{adv}} = \mathbb{E}_{(\mathbf{x}, y_b)}\left[ -y_b \log D_\phi(\text{GRL}_\lambda(\mathbf{h})) - (1-y_b) \log(1 - D_\phi(\text{GRL}_\lambda(\mathbf{h}))) \right]$$

其中 $$\text{GRL}_\lambda(\cdot)$$在反向传播时将梯度乘以$$-\lambda$$，实现特征提取器与判别器的对抗博弈。

## 4. 对抗方法：GRL（梯度反转层）

### 4.1 GRL 原理（代码实现对齐）

梯度反转层通过自定义 `torch.autograd.Function` 实现梯度符号反转：

```Python
# === 梯度反转层核心实现 ===
class GradientReversalFunction(torch.autograd.Function):
    @staticmethod
    def forward(ctx, x, lambda_):
        ctx.lambda_ = lambda_  # 保存缩放系数
        return x.view_as(x)    # 前向：恒等映射

    @staticmethod
    def backward(ctx, grad_output):
        # 反向：梯度乘以 -lambda，实现"欺骗"效果
        return grad_output.neg() * ctx.lambda_, None

class GradientReversalLayer(nn.Module):
    def __init__(self, lambda_=1.0):
        super().__init__()
        self.lambda_ = lambda_
    
    def forward(self, x):
        return GradientReversalFunction.apply(x, self.lambda_)
```
