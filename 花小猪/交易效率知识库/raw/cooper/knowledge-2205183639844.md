# 一、背景

接驾远换车：对于预估应答后取消率高的接驾远订单进行换车，进而降低应答后C取消、提CR&完单。

策略：根据阈值触发不同的换车策略（自动换/手动换/不换）；连环派/非连环派分别设置阈值

根据当前问题定义和分析，新增一个**多任务的模型**，预测当前订单的**乘客取消率和用车意愿**

# 二、问题建模

## 2.1 问题定义

对于换车场景，不仅需要预测取消率（对高取消率订单进行换车），也需要预测用户取消后仍有用车意愿（避免无效换车）

因此，可以建模为一个多任务问题，两个任务之间存在依赖关系

**模型输入**：接驾距离、乘客应答前等待时长、订单类型（是否连环派）、应答时间（是否峰期）、周围供需等

**模型输出**：**预估取消率、用车意愿**

### 2.2.1 标签

- 乘客取消率的标签：o_is_finish

	- 正样本：乘客取消

	- 负样本：完单 或 司机取消

```SQL
select
    *,
    if (class in ('完单'), 1, 0) as o_is_finish
from
    kflower_strategy.pk_hxz_modeling_data
where
    dt between '2025-06-30' and '2025-07-25'
    and is_finish is not null
    and class in ('完单', '乘客取消')
```

- 乘客用车意愿的标签：is_willing 

	- 正样本（有用车意愿）：乘客取消&&填写的取消原因是“不用车了”之外的其他选项 或者 重发单了 ；完单

	- ==负样本（无用车意愿）：取消且不重发单且(勾“不用车了”或未写原因)== 

```SQL
--重发单的口径：同一乘客十分钟内有同起同终的发单，则该单标为（后续有）重发单，is_call_again=1
WITH order_sequence AS (
  SELECT 
    dt, 
    order_id,
    passenger_id, 
    starting_lng, 
    starting_lat, 
    dest_lng, 
    dest_lat,
    call_time,
    LEAD(call_time) OVER (
      PARTITION BY dt, passenger_id, starting_lng, starting_lat, dest_lng, dest_lat 
      ORDER BY call_time
    ) AS next_call_time
  FROM kflower_dw.dwd_kf_trd_order_base_di
  where dt between '2025-06-30' and '2025-07-25'
)

SELECT 
    dt,
    order_id,
    passenger_id,
    call_time,
    starting_lng,
    starting_lat,
    dest_lng,
    dest_lat,
    call_time,
    CASE WHEN 
        next_call_time IS NOT NULL 
        AND unix_timestamp(next_call_time) - unix_timestamp(call_time) <= 600
        THEN 1 ELSE 0 
    END AS is_call_again
FROM order_sequence
```

```SQL
--用户反馈有用车意愿的口径：if 原因in（'行程有变，暂时不需要用车','已在其他平台叫到车','选错终点','推荐上车点不准确/找不到'）feedback_willing=0, else feedback_willing=1
SELECT 

dt,
order_id,
cancel_reason,
case when cancel_reason in ('行程有变，暂时不需要用车','已在其他平台叫到车','选错终点','推荐上车点不准确/找不到')
    then 0 else 1
    end as feedback_willing --根据反馈得到的用车意愿，0表示无用车意愿或者换车也无法解决

FROM kflower_dw.dwd_kf_pas_cancel_reason_di
where dt between '2025-06-30' and '2025-07-25'
```

### 2.2.2 数据分析

- 乘客取消的占比 0.16

- 乘客取消中重发单的占比 0.35

- 乘客取消中仍反馈有发单意愿的占比 0.63，**取消中有意愿（反馈+重发单）有0.75**

	- **——结论：有25%是无用车意愿的取消，这部分不应该给换车**

- 反馈仍有发单意愿中重发单的占比 0.30

- **取消后有用车意愿的（反馈+重发单）中 重发单占比0.42**

	- **——结论：有一半以上仍有用车意愿的用户取消后不会重发单，这部分需要给自动换车**
