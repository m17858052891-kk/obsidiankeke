# 一、背景

记录PEPNet做不同序列长度、不同序列特征、不同参数实验结果。

###  实验分析结论

- 加入序列数据后o的履约率不升的原因：

1.把O的tower单独拆解出来后训练不会有直接提升，说明不是o, d, od之间优化的tradeoff导致o的履约不升；

2.猜测是O的数据稀疏引发的履约率不升，约束passenger序列长度为10且时间跨度小于10天即不稀疏~~，实验结果d,od准确率大幅提升，O反而下降3.4pp。~~

**以上2未考虑数据量，过滤后数据仅有原来<10%(16384w->1174w)，重做数量量相当的实验，过滤后无提升。**

3.猜测乘客序列/司机序列对O塔是噪声，尝试只对d，od塔输入序列数据，而不对o塔输入序列数据，实验结果不升反降，排除噪声影响。

4.序列长度为20的情况下以及加入时空特征的序列实验中，o准确率有较大提升，可验证序列长度及特征对o塔有较大影响，尝试在多个数据集上验证序列长度20以及序列加入时空特征对o塔在6月数据有少量正向影响+3pp，在12月数据上无正向影响。

5.实验过程中发现Batch size对模型AUC影响较大，分别实验了学习率相同Batch size=128, 256, 512, 1024的训练过程。在25年6月、12月数据集验证，其中Batch size 256平均AUC提升+5pp及以上。[BatchSize对PEPnet序列影响](https://cooper.didichuxing.com/knowledge/2199610335356/2207265751646)

**结论：**加入序列特征后，特征空间维度增加且存在大量冗余，如司乘序列中存在10个仅时序不同或司乘归属不同的特征，导致优化 landscape 更加非凸。此时小 batch size 引入的梯度噪声起到了正则化作用，逃离局部最优，抑制对重复特征的过拟合。
