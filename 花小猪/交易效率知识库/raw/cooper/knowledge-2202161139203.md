## **特快盒子预估应答时长模型**

### **业务背景介绍**

小猪特快盒子（快优精选）需要展示预估司机应答时长；等待应答页面上方需要展示预计等待时长，需要根据乘客预计被应答时长来为乘客追加不同的车型。

- 输入模型特征

    new_dic = x.copy()

class NormalizationLayer(tf.keras.layers.Layer):
    def __init__(self,low_val,up_val):
        super(NormalizationLayer, self).__init__()
        self.low_val = low_val
        self.up_val = up_val

    def call(self, inputs):
        # 归一化操作
        normalized_inputs = tf.add(tf.where(inputs >= self.up_val, 1.0, 0),tf.where((inputs >= self.low_val) & (inputs <=self.up_val),(inputs - self.low_val) / (self.up_val - self.low_val),0))
        return normalized_inputs

def get_inputs_0(feature_names):

def get_normalized_inputs(inputs,bounds):
    normalized_inputs=[]

def mse(y_true,y_pred):
    conditions= [y_true <1, y_true >= 1]
    weight= tf.where(conditions[0], weights[0], 0) + tf.where(conditions[1], weights[1], 0)

    a = tf.square(y_true-y_pred) * weight
    return tf.reduce_mean(a)

- 改进想法

	- 特征交叉

		- 第1圈平均应答时长：周围第1圈的5分钟新业务司机总应答时长/周围第1圈的5分钟新业务司机总应答数

	- 模型结构

		- 通过68个基础特征，输出预测的应答时长

		- 将应答时长和第1/2圈平均应答时长进行attention，输出最终应答时长

class NormalizationLayer(tf.keras.layers.Layer):
    def __init__(self,low_val,up_val):
        super(NormalizationLayer, self).__init__()
        self.low_val = low_val
        self.up_val = up_val

    def call(self, inputs):
        # 归一化操作
        normalized_inputs = tf.add(tf.where(inputs >= self.up_val, 1.0, 0),tf.where((inputs >= self.low_val) & (inputs <=self.up_val),(inputs - self.low_val) / (self.up_val - self.low_val),0))
        return normalized_inputs
