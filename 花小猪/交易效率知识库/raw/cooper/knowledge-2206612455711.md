# 接驾远换车v2.2收益预估

产品BRD文档：[BRD--连环派换车优化](https://cooper.didichuxing.com/knowledge/2204598041545/2206463390972)

收益测算需求文档：[连环派换车优化数据提需](https://cooper.didichuxing.com/knowledge/2204598041545/2206537255648)

DS收益测算文档：[连环派换车优化](https://cooper.didichuxing.com/docs2/document/2206551934682)

# 一、背景

- **v2.3策略优化目标主要在于（1）扩大连环派换车触发面 （2）提升连环派换车成功率**

- **对应的策略改动：（1）放低连环派换车阈值**：换车eta阈值 由470s放宽到300s**（2）放低连环派换更近车的时间约束**：子单司机比父单司机更近eta 由更近90s放宽到 换更近30s或60s的非连环派

	- v2.2连环派换车策略：eta>=470且ab>=90 自动换，换更近90s的新车

	- v2.3连环派换车策略：（eta>=300且ab>=90 自动换，250<=eta<300且ab>=90且不顺路 手动换），换更近30s｜60s的非连环派

> 「顺路度」定义参考：[连环派订单c取消优化二期（hold）](https://cooper.didichuxing.com/knowledge/2204598041545/2206472238074)

- **需求：**预估应答后c取消的降幅和完单的涨幅

# 二、结论

- **结论：总的预估收益应答后c取消预计下降0.1pp，完单提升0.08%，主要来源于扩大换车触发面**

**【扩大换车触发面收益】**

连环派换车触发面由 470s阈值下的理论触发面**15%**、实际触发面27%（理论与实际的gap源于触发时连环派eta计算有误）上涨至 300s阈值下的**61%**，

**预估收益：****应答后c取消预计下降0.1pp，完单提升0.08%**

**【提高找车成功率收益】**

在扩大换车触发面的基础上，降低找车eta阈值（从找更近90s 降低至找更近60s｜30s的非连环派），470s以上部分找车成功率提升**+4.86pp｜+6.72pp**，「250-370s增量换车父单」部分找车成功率提升**+2.43pp｜+3.36pp**；

完单增量不到0.01%

# 三、收益预估

### 1、连环派扩换车触发面收益预估

- **线上策略：**连环派eta>=470s触发换车，全部为自动换，找更近至少90s的新车

- **优化策略：**

	- eta>=470s时策略保持不变

	- 新增：eta在300-470s区间触发换车，全部为自动换

	- 新增：eta在250-300s区间&&不顺路时触发换车，全部为手动换，需要乘客点击换车

- **测算逻辑：**

	- 预计减少的C取消订单量 = 新增的连环派订单量\*换车成功率\***（原eta区间连环派C取消率-eta缩短150s对应的连环派C取消率）**

	- 预计C取消率增量 = 预计减少的C取消订单量 / 含改应答数

	- 完单收益 = 预计减少的C取消订单量 \* (1 - 重发单完单占比）

- **测算结论：**

	- 连环派换车触发面由理论触发面15%、实际触发面27%（理论与实际的gap源于触发时连环派距离计算有误）上涨至61%

	- **连环派扩大触发面后 应答后c取消预计下降0.1pp，完单提升0.08%**

### 2、连环派提找车成功率

- **线上策略：**连环派eta>=470s触发换车，全部为自动换，找更近至少90s的新车

- **优化策略：**

	- 将更近90s限制拓宽至更近30s&&非连环派

	- 将更近90s限制拓宽至更近60s&&非连环派

- **测算逻辑：**

	- 换车成功增量父单数 = 子单未应答&&**(父单-举手非连环派子单)eta>=60s父单数**

	- 调整后连环派换车成功率 = (换车成功增量父单数+换车成功父单数)/换车父单数

	- C取消单减少量/完单增量 = 换车成功增量父单数\***==（原eta区间连环派父单C取消率-eta缩短60s对应的非连环派C取消率）==**

- **测算结论：**

	- 60s阈值下：470s以上部分 换车成功率**+4.86pp，**「250-370s增量换车父单」部分**+2.43pp**

	- 30s阈值下：470s以上部分 换车成功率**+6.72pp，**「250-370s增量换车父单」部分**+3.36pp**

> 待讨论：目前使用（原eta区间连环派父单C取消率-eta缩短60s对应的非连环派C取消率）预估完单增量的方式可能会**==存在低估==**

	- 原eta区间连环派父单C取消率 用的是450-500s的连环派c取消

	- eta缩短60s 用的是350-400s的非连环派取消

- 按照ds的测算，这部分的完单提升微乎其微，**主要原因：连环派 和 更近60～90秒的非连环派 之间的取消率gap小**

	- 参考之前关于连环派和非连环派在eta分桶下的取消率洞察 [不同接驾距离（时间）的取消率分析](https://cooper.didichuxing.com/docs2/document/2203933056637)
