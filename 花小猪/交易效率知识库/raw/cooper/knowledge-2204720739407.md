# 1 背景

- 小猪的司机诱导乘客取消率很高，乘客取消中诱导占比约20%，给乘客带来极差体验。

> 参考[花小猪服务体验FT2024年复盘+2025年规划](https://cooper.didichuxing.com/docs2/document/2203350494711)

- 2025年在交易链路各个环节加入对司机诱导乘客取消行为的治理，本策略是在分单召回层对诱导的干预。

- 约束与目标：约束大盘完单不显著负，降低司机诱导率10%

# 2 技术方案

- 在分单召回层，新增深度模型 **预测DO对的司机诱导乘客取消概率**。

- 根据供需情况，对高诱导DO对转抢单/过滤。差供需时过滤，好供需时转抢单。

	- 供需判断：根据小猪端一圈格子5min发单数+小猪端一圈格子5min应答率判断。

## 2.1 样本标签

- 在**应答空间**，训练高诱导DO对模型。

	- 正样本：取消单中的诱导取消

	- 负样本：非取消单 + 取消单且非诱导

- 取消单判责：存在机判和人判。

	- 机判：所有取消单均过机判，召回约20%，精确约90%

	- 人判：机判有责且司机不服选择申诉后，排队进人判，约0.5%

- 标签

	- 训练数据：受限于人判数据量，取消单采用「人判 优先于 机判」的规则确定是否为诱导，非取消单为非诱导

	- 验证数据

		- 验证集1：取消单采样「人判 优先于 机判」的规则确定是否为诱导，非取消单为非诱导（与线上实验评估方式保持一致）

		- 验证集2：进人判的取消单 + 非取消单 按照真实的诱导占比随机采样混合

	- 线上实验评估：受限于不是所有的取消单均过人判，取消单采用「人判 优先于 机判」的规则确定是否为诱导

- 正负样本占比：正/负约1:100

## 2.2 模型

### 2.2.1 模型结构

- 对**取消、诱导取消两个任务同时建模**，共享底层特征；正负样本比例较均衡（3:7）的取消场景来提供监督信号，增强底层特征编码能力。

- 运用**诱导取消是取消的子集**的先验，通过Cancel Tower识别取消，输出与原始特征Concate作为Induce Tower的输入。

- 损失函数：由于正负样本比例严重不均衡，尝试focal loss，对正负样本、难样本赋予不同的权重，提高正样本的准召。

	- FocalLoss  $$FL(p_t) = -\alpha_t (1-p_t)^\gamma \log(p_t)$$ 其中$$\ p_t = p \ \text{ if}\  y=1 \  \text{else }\    1-p,\ \alpha_t = \alpha \ \text{ if }\ y=1 \text{ else } 1-\alpha$$

	- （调参后）Induce $$\alpha = 0.9,\ \gamma = 2$$, Cancel $$\alpha = 0.75,\ \gamma = 2$$

	- （调参后） loss = 0.5\*loss_cancel + loss_induce

- 模型结构设计说明

	- 为什么用ESMM？「应答 -> 取消 - 诱导取消」和 CTR CVR预测中「曝光 -> 点击 -> 转化」有相似之处，都存在后一个分类任务的样本稀缺问题，ESMM共享底层特征编码是对此问题给出的解决方案。

	- 为什么将ESMM调整为现在的层级结构模型（HMCN）？

		- 当前诱导的标签非100%准确，取消的标签100%准确，ESMM中Cancel Tower的一部分监督直接来自pInduce的损失函数，HMCN中pInduce对Cancel Tower、Induce Tower串联的结果进行监督，能减少诱导标签不准确对Cancel Tower的负向影响。

		- ESMM中诱导取消和取消的关系为$$P(Induce) = P(Cancel)*P(Induce | Cancel)$$，对非取消订单，$$P(Induce|Cancel)$$可以是任意值，此时对Induce Tower没有任何监督；HMCN中放弃预测$$P(Induce|Cancel)$$,将Cancel Tower的输出作为诱导预测的中间结果，pInduce的损失直接监督Induce Tower.

		- 如何对「取消 - 诱导取消」存在包含关系的任务建模？[Hierarchical Multi-label Classification Networks（ICML2018）](https://proceedings.mlr.press/v80/wehrmann18a/wehrmann18a.pdf) 中提出了HMCN网络结构，对标签存在层级关系的文本分类问题建模，将类目树的约束添加到模型中。当前模型结构与HMCN一致。

# 4 Q&A

1. 为什么模型的评估指标是不同recall下的precision，而不是AUC？

	1. AUC反映的是模型对正负样本整体的排序能力，在给定recall下，AUC高不一定代表precision高

	2. 在对诱导识别这样的场景下，更关注一定recall下模型的precision，进而减少误判

2. 为什么模型的准召那么低？

	1. 正负样本不平衡本身会压缩模型的准召上限
