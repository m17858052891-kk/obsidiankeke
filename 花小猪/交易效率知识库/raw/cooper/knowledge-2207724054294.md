# 三、策略方案

## 3.1 问题定义

- 阶段一：**「TP模式判断」判断订单O进行TopSpeed还是流入轮次分单池**

- 阶段二：**「召回」单个OD对维度的删边**，包含平台规范过滤（caa<cba）和竞争胜率过滤。

- 阶段三：**「匹配」单轮次维度的带约束优化问题求解**，同时求解每轮播单结果、交易模式。

### 3.1.1 TP模式判断

- 紧急程度高，走TP；紧急程度低，流入轮次分单池

- 紧急度计算因子：

	- 乘客等待时长权重（乘客耐心）

	- 平台竞争强度（改订单的勾选情况；供需）

	- 订单价值（订单IPH）

### 3.1.2 召回阶段

下一轮次的双边供需是未知的；通过两种视角的hold实现多轮次的最优

- 平台规范过滤：（**订单视角的hold过滤**：应答后取消率 caa < cba 应答前取消率）这一步已经过滤掉需要hold的OD对

- 竞争胜率过滤：（**司机视角的hold过滤**：获胜率 > 下一轮有单率）比较竞争的价值和司机等下一轮的价值 

### 3.1.3 匹配阶段

- 优化目标：最大化期望完单

- 约束：平均应答接驾时长约束；应答后司乘取消率约束；播单约束

- 决策变量：每个轮次全局**每个OD对的播单模式**（不播单，全指派，半指派，抢单）**联合决策派单模式**

- **对于TP，当作是单个O的轮次，依然适用于联合决策框架**

现状 每个OD对会召回固定的派单模式（根据订单价值模型和阈值决定，通过这个阈值可以调控司机取消率）

将司乘取消率作为约束，同时控制播单和匹配模式

- 优化目标：最大化期望完单

$$max \sum\limits_{i}^{N}  \sum\limits_{j}^{M}  \sum\limits_{k}^{K}  finsih_{i,j,k} * z_{i,j,k}  * PK_{i,j,k}$$

- 约束：

	- 平均应答接驾时长约束：

$$s.t.  \sum\limits_{i}^{N}  \sum\limits_{j}^{M}  \sum\limits_{k}^{K}  eta_{i,j,k} * z_{i,j,k} * PK_{i,j,k}    \leq {ETA}_0$$

	- 应答后司机取消率约束：

$$s.t.   \sum\limits_{i}^{N}  \sum\limits_{j}^{M}  \sum\limits_{k}^{K}  BCAA_{i,j,k} * z_{i,j,k}  * PK_{i,j,k}  \leq BCAA_0  * \sum\limits_{i}^{N}  \sum\limits_{j}^{M}  \sum\limits_{k}^{K}   z_{i,j,k}  * PK_{i,j,k}$$

	- 应答后乘客取消率约束：

$$s.t.   \sum\limits_{i}^{N}  \sum\limits_{j}^{M}  \sum\limits_{k}^{K}  CCAA_{i,j,k} * z_{i,j,k}  * PK_{i,j,k}  \leq CCAA_0  * \sum\limits_{i}^{N}  \sum\limits_{j}^{M}  \sum\limits_{k}^{K}   z_{i,j,k}  * PK_{i,j,k}$$

	- 决策变量约束：每个订单Oi最多能播单一个司机Dj，每个司机Dj最多能播单一个订单Oi，每个播单有且仅有一种派单模式k

订单分配约束（每个订单最多分配一次）

$$\sum\limits_{j=1}^M\sum\limits_{k=1}^3 z_{i,j,k} \leq 1, \forall i \in \{1,...,M\}$$ 

司机容量约束（每个司机最多承接一个订单）

$$\sum\limits_{i=1}^N\sum\limits_{k=1}^3 z_{i,j,k} \leq 1, \forall i \in \{1,...,N\}$$
