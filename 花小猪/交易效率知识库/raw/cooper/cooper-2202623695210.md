# 一、需求背景

目前交易分单时缺少相关订单奖励信息，因此对有司机奖励订单(如免佣动调，加价红包等)并无特殊倾斜。然而对于提供奖励的订单会增强司机的接单意愿，如提升司机对更远接驾距离的接受度，同时在分单时D对O打分除IPH外也应该考虑补贴信息。因此针对这部分奖励订单可优化当前分单策略进行倾斜从而提升应答率，最终加速完单。


# 二、需求类型归纳

预判有收益，需新增功能；

# 二、需求收益判断

目前免佣，动调，加价红包等司机奖励订单占大盘约为10%；假设通过对该类订单进行分单策略的倾斜应答率提升10%，目前该类订单应答后BC取消约为25%，因此对大盘CR预估收益为10% * 10% *（1-25%）= **0.75pp**。

# 三、需求说明和功能点

## 需求说明：

	本次需求涉及API，交易引擎，交易引擎测试，产品团队；

## 功能点:

1. 分单时可获取订单的司机奖励信息，api透传duse；

2. D对O打分基于奖励信息进行优化；

3. 对有司机奖励订单配置相关扩播策略；

4. 司机端可感知订单的奖励信息；
