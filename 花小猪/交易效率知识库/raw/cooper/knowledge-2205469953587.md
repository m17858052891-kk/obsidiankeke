# 1 背景

        在司机应答后乘客等接驾过程中，司机诱导乘客取消、乘客长时间等待后被司机取消（实际多为诱导失败后司机取消）等场景严重伤害了乘客体验。**在乘客等接驾时，平台识别低接驾意愿的司机，在取消前为乘客主动换车或主动给乘客提示**，可以改善乘客体验，提升完单。

        24年小猪上线了低接驾意愿换车策略V0（见[01.低接驾意愿模型需求](https://cooper.didichuxing.com/knowledge/2199610335356/2203992691740)2.2下的已有人工规则），但是存在覆盖的场景有限、召回量有限的不足。当前接驾过程中的司机有责订单占应答订单的5%以上，策略V0的触发量占应答订单的1%，有较大的提升空间；策略V0的覆盖场景为司机拒接电话、IM文本出现关键词和司机停留在抢单点，覆盖场景较少。

        低接驾意愿实时模型V1在V0的基础上，新增规则和模型，在保证准确性下，策略触发量占应答提升至4%，提升完单。规则新增场景：司机偏航、行驶缓慢、到达后走远等。模型相对于规则，学习潜在模式，识别规则外的低接驾意愿OD对。

# 2 目标 & 约束

**目标：**

- 司机接驾意愿低场景的召回量占小猪端应答单的1%提升至3%以上

- 降低司机诱导率10%

- ==以订单是否取消作为限制条件，命中模型且不做干预的前提下，该订单被取消的概率要在70%以上==

**核心收益链路：**

降低应答后司机取消、应答后乘客取消；降低司机诱导乘客取消的发生

## 3.1 整体流程

在应答后等接驾过程中，轮询触发规则和模型，输出高诱导、低诱导和无诱导。

对高诱导订单，平台直接换车（替乘客取消并重新发单）；对低诱导订单，弹窗询问乘客是否换车。

对于无诱导订单，不做动作。

## 3.3 模型

**样本空间**

- 司机低意愿(即正样本）：判责为诱导 或 乘客取消勾选原因为下列之一的取消单

- 乘客取消勾选原因：司机要求我取消，司机不来接我（车不动/离我越来越远），司机联系不上，司机要求加价，司机态度恶劣，司机迟到，司机要求线下交易，司机离我太远（0.0005%），司机原地不动或越来越远。

- 正样本占应答订单约3%.

**数据采集方式**

间隔2min轮询，随着应答后等待时间的加长，同一个订单的特征会发生变化，逐渐接近最终司机意愿下的特征；同时乘客等待时间加长后被取消，也会给乘客带来更差的体验。

由于真实应用场景下，模型需要对同一订单的所有轮询进行预测，因此训练时我们也**对所有轮询样本进行训练**，而不是只用最后一条记录样本，以提高模型对前期轮询订单的鲁棒性，提高给定精确率下模型的召回率。

**特征**

使用了如下7类特征，具体特征名和含义见文档[02.低接驾意愿模型特征](https://cooper.didichuxing.com/knowledge/2199610335356/2204693864100)。

- 订单特征：预估订单价格、订单里程、应答时长、是否连环派、半小时时间点、星期

- 司乘沟通类：IM文本

- 时间、距离类：应答点停留时长、总停留时长，点击到达时离订单起点距离，司机已行驶距离、司机行驶直线距离，已行驶时长，预估接驾距离、预估接驾时间，预估剩余接驾时长，当前点离订单起点距离，点击到达上车点后的路面行驶距离，点击到达上车点到此刻的时长

- 地图类：司机偏航次数

- 通话类：总通话时长、乘客拨打次数、司机拒接次数、司机拨打次数、乘客拒接次数、司机拒接响铃总时长

- 司乘行为类：

乘客在过去14/30天的应答后取消次数、取消比例、乘客在过去14/30天的应答后取消平均等待时长

司机在在过去14/30天的（分是否连环派）应答后取消次数、取消比例、司机过去14/30的平均接驾时长

- 供需特征：格子与周围一圈格子近5min发单数、应答数、被司机取消数、乘客取消数

## 4.2 完单链路


- 目前，换车标记为改派，司机取消后多数订单也会发起改派。改派的父单和子单的原始订单号(origin_order_id)相同。为了不重复的计算应答和完单，**考虑原始订单的应答**，并考虑该订单可能经过多轮改派后的**最终完单情况**。

- 对于乘客取消后重发单，两单会有不同的原始订单号，因此**不需要额外考虑C取消后的重发单**。

- 对于命中本策略的订单，若是高诱导则直接发起子单呼叫进行换车，若是低诱导则弹窗让乘客选择是否换车，当乘客点换车时发起子单呼叫进行换车，当乘客未点或选择不换车时则依旧保持原单。**对于有子单呼叫且子单应答的订单，看子单是否最终完单；对于无子单呼叫或子单呼叫但未应答的订单，看父单是否最终完单**。

- 对于未命中本策略的订单，直接看本单是否完单。

补充：这里为了处理方便，只考虑第一单是否命中策略，对于第一单未命中策略 即使司机取消改派后子单命中策略进行换车，也直接归为未命中策略，这部分订单占所有应答订单不超过0.3%。同时，也不考虑命中策略后的子单再次命中策略的情况。

预期：应答后，命中策略的子单最终完单带来最终完单收益。命中策略的订单原本可能会被取消且不一定会重发单完单，命中策略后换车子单完单带来完单收益。

数据：

![](https://s3-ep-inter.didistatic.com/didoc-upload-image-prod/177276549704450f3c997-08da-4205-87cc-033b6114eac2/image.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKDD00000000000EBLCTZNRBJHX6ZS%2F20261104%2Fgzep%2Fs3%2Faws4_request&X-Amz-Date=20261104T093651Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=204f8311296d49a85c44c4540aba62cad8d7ad58a301f134a7d82b81e4df3831)

应答后未命中策略占比 = 未命中策略订单 / 原始应答订单，应答后未命中策略 最终完单率 = 最终完单 / 应答后未命中策略订单，其它百分数项同理。

完单 / 应答 = 未命中策略占比\*最终完单率 + 命中策略占比\*（子单应答占比\*最终完单率 + 子单未应答占比\*最终完单率）。

完单增幅（t vs b) = (完单t/应答t - 完单b/应答b) /（完单b/应答b) 【这里假设了应答不变】。

空白组 无应答后命中策略，上图中的30.97%为实验组3.88%命中策略的订单如果没有策略干预的最终完单率。 通过如下方式计算，假设空白组经过本策略空跑，其中96.12%的未命中策略的订单与实验组96.12%未命中策略的订单完全同质，最终完单率相同，那么当前空白组79.81%中有96.12%\*81.78%=78.61%为该部分订单贡献，剩下3.88%的订单的最终完单率为 1.2%/3.88%=30.97%。

由于这里只考虑原始订单是否命中策略，以及不考虑命中策略后再次命中策略，这里实验组 / 对照组的应答后命中策略在应答中占比为 3.88%｜1.02%，略低于3.1详细数据中的3.99%｜1.05%。

为与3.1中数据保持一致，以上数据均只考虑宏鹄和自营运力。

验证数据准确性：

- 以实验组 vs 空白组为例，完单增幅为1.3%（假设应答不变）；对应3.1中人均完单增幅为0.92%，人均呼叫数-0.49%，人均呼叫数（剔除重发单）+0.04%，从而人均重发单呼叫-0.45%，得到（应答不变时）人均完单增幅约为1.37%。

结论：

- 完单收益来源于命中策略且子单应答后的最终完单和命中策略但无子单呼叫或子单未应答时的完单提升（猜测是换车提高乘客愿等）。

- 命中策略的订单最终完单率远远低于未命中策略的订单，说明本策略较好识别司机低意愿订单。实验组未命中策略的订单最终完单率为81.78%；根据推算，实验组3.88%命中策略的订单如果没有策略干预的最终完单率为30.79%，两者存在约50%的完单率差异。

- 命中策略的订单在子单应答后，子单最终完单率远高于无策略干预，说明换车能够带来完单收益。实验组/对照组命中策略且子单应答的最终完单率为71.58%｜73.68%，远高于实验组3.88%命中策略的订单如果没有策略干预的最终完单率30.79%。

- 命中策略的订单若无子单呼叫或子单未应答时，子单最终完单率也高于无策略干预，可能原因是换车提高乘客愿等。实验组/对照组命中策略但无子单呼叫或子单未应答的最终完单率为51.46%和42.34%。

# 5 Q&A

本策略存在哪些问题？

- 目前的触发策略是简单粗暴的轮询，会出现司机离订单起点很近但命中策略后被换车，若误判会给司机和乘客带来较差体验。

- 目前的换车仅由策略输出的概率决定，未考虑供需等因素，也未考虑换车前后的司机远近等因素，若在司机较少时等不到新司机或者给乘客换了更远的司机，会降低交易效率和乘客体验。
