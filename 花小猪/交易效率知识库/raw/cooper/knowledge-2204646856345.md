# 1、需求背景

由产品侧分析，发现应答长时间后被司机取消的订单占比较高，且这部分取消对乘客留存伤害最重

由平台侧推动，在分单和PK考核中加重对司机长时取消行为的惩罚，通过可解释透传机制降低此类行为的发生频率

# 2、策略流程

特征建设：建设司机近14天加权取消数特征，对司机超过4分钟以上的取消（不含司机真实到达上车点且乘客迟到的情况）作线性加权。其中4分钟对应1.5倍，10分钟对应3倍，最高4倍

模型建设：利用建设好的司机近14天加权取消数特征，替换原先未加权的司机取消数特征，重复PK模型的建模链路

# 3、实验评估

分流方式：乘客随机分流

流量范围：全国约80%完单的城市

实验周期：2025-06-12～2025-06-16

# 4、结论与建议

PK引入司机长时取消因子后，实验结果基本符合预期，但策略优化的天花板较低

1. 大盘整体效率和商家份额均无显著变化，司机取消率不显著增加，来源于有过长时取消行为的司机行为变差

2. 司机长时取消现象有一定减少，体现在司机超过4分钟以上的取消占比-0.21pp（-1.62%）

3. 有过长时取消行为的司机更难拿到订单，体现在这部分司机举手占比-0.31pp，both举手PK胜率-0.47pp

4. 司机本单是否出现长时取消现象，与其过往是否有过长时取消现象的相关性不高，导致在PK引入这一因子的效果有限
