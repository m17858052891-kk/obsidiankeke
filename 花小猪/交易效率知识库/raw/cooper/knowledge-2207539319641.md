# 盲盒放量观察


# 一、背景

- 二期实验收益结论：二期实验拿到显著收益 应答后乘客取消率显著下降（-0.13pp｜-0.13pp｜-0.12pp）；由于花钱组钱效低，后续放量不花钱的实验组2 。

- 放量决策：放量二期实验的实验组2（盲盒中发放实物奖励，不发券）。

- 放量观察决策：由于发放奖品比例低（一天一单），需要观察长期收益。

# 二、放量节奏

- 4.21：实验组2放量至30%，空白组70%（停留观察一周）

- 5.6：实验组2放量至60%，空白组40%（停留观察一周）

- 5.13：实验组2放量至90%，空白组10%（长期保留空白组10%观察）
