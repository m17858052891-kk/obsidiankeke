# 一、需求背景

1. 目前自营订单价值模型在连环派场景也生效，但由于历史原因模型特征中并未进行对连环派场景的建模和区分，线上效果及业务解释性不及预期；

2. 因此希望对模型特别是连环派场景进行优化，新增是否连环派等相关特征，后续可尝试多场景建模进一步优化；

# 二、需求类型归纳

预判有收益，已具备初步功能，持续优化；

# 二、需求收益判断

**收益链路**

优化线上订单价值打分排序，交易模式更加合理化；

**预期收益**

自营商家完单+1%；
