### 1.实验目的

v0的4min听不到单扩播是由统计司机从听单到下线等待时间的中位数确定，会有部分司机未等到扩播就下线的case。

本实验的目的是希望通过模型预测出这部分会在扩播前下线的司机，提前为其扩大听单半径，同时TTS播报扩播信息。v1策略旨在v0策略的基础上实现更准确扩播（为相对更有耐心的司机晚点再扩播），从而进一步拉伸司机在线时长，提高司机的人均TSH和人均GMV。

### 2.实验方案

由于apollo人群自适应分流实验方式需要接入piccaso，暂时还不支持在霸王花项目使用。所以本次实验采用由司机driver_id 模1000分桶，将司机随机划分为三个组（0-334,334-668,668-1000）：实验组采用司机策略播单v1，对照组采用司机策略播单v0，空白组不采用策略，观察指标为：1.司机人均tsh，2.司机人均gmv。若随机分流分出的三个组指标AA不平，则实验后DID拉齐，观察实验效果。

### 4.实验过程与结果

实验时间：**2020.12.05 - 2020.12.12**

**周人均GMV** 展开源码

```PlainText
select
    --city_id,
    exp_group_name,
    sum(nvl(gmv, 0)) gmv,
    count(ta.hxz_driver_id) headcounts,
    sum(nvl(gmv, 0)) / count(ta.hxz_driver_id) gmv_p
from
    (
        select
            distinct hxz_driver_id,
            city_id,
            case
                when hxz_driver_id % 1000 >= 0
                and hxz_driver_id % 1000 < 334 then 'exp'
                when hxz_driver_id % 1000 >= 334
                and hxz_driver_id % 1000 < 668 then 'control'
                when hxz_driver_id % 1000 >= 668
                and hxz_driver_id % 1000 < 1000 then 'blank'
                else null
            end exp_group_name
        from
            kflower_dw.dwm_kf_dri_online_hxz_and_wyc_df
        where
            dt between '2020-12-05'
            and '2020-12-11'
            and city_id in (90, 98, 127, 135)
            and hxz_online_dur > 0
    ) ta
    left join (
        select
            driver_id,
            sum(gmv_amt) gmv
        from
            kflower_dw.dwd_kf_trd_order_base_di
        where
            dt between '2020-12-05'
            and '2020-12-11'
            and call_time is not null
            and call_time <> '0000-00-00 00:00:00'
            and start_city_id in (90, 98, 127, 135)
            and is_td_call = 1
            and is_td_finish = 1
        group by
            driver_id
    ) tb on ta.hxz_driver_id = tb.driver_id
group by
    --city_id,
    exp_group_name;
```
