## **4. 统计代码**

应答后取消逻辑**：[司乘取消逻辑](http://wiki.intra.xiaojukeji.com/pages/viewpage.action?pageId=199167419)**

**可以根据注释部分选择是否统计区县或者高峰期。**

```PlainText
select  dt
        ,(sum(A.pick_dis) / sum(A.answer)) as pick_dis
        ,sum(A.order_cnt) as order_cnt
        ,sum(A.answer) as answer_cnt
        ,sum(A.complete) as complete_cnt
        ,(sum(A.answer_dur) / sum(A.answer)) as answer_dur
        ,(sum(A.answer) / sum(A.order_cnt)) as answer_rate
        ,(sum(A.complete) / sum(A.order_cnt)) as cr
        ,(sum(A.pax_cancel_before) / sum(A.order_cnt)) as pax_cancel_before_rate
        ,(sum(A.pax_cancel_after) / sum(A.answer)) as pax_cancel_after_rate
        ,(sum(A.driver_cancel) / sum(A.answer)) as driver_cancel
from    (
    select  dt
            ,case   when source_type <> 2 then driver_start_dis
                    else 0
             end pick_dis
            ,case   when source_type <> 2 then 1
                    else 0
             end order_cnt
            ,case   when order_status = 5 then 1
                    else 0
             end complete
            ,case   when order_status = 6  then 1
                    else 0
             end pax_cancel_before
            ,case   when order_status = 7 then 1
                    else 0
             end pax_cancel_after
            ,case   when (complete_type not in (7, 13) and order_status = 12) or (source_type = 2 and order_status = 0) then 1
                    else 0
             end driver_cancel
            ,case   when (answer_time <> '0000-00-00 00:00:00' and source_type <> 2) then 1
                    else 0
             end answer
            ,answer_dur
    from    kflower_dw.dwd_kf_trd_order_base_di
    where       (
                    dt between '2020-04-14'
                and '2020-04-19'
            )
      --and   (
                    --hour(call_time) between 7
                --and 9
            --)
      and   is_td_call = 1
      and   is_cheat_flag = 0
      and   start_city_id = 44
      --and  start_county_id = 520302
) A
group by dt
;
```
