# 一、需求背景

由于调度初期缺少相关数据，目前司机调度接受度模型为与司机调度里程负相关的线性函数。经离线测算AUC仅0.512，基于司机调度已有数据训练新一版XGB模型，离线AUC为0.734。因此考虑部署新版XGB模型上线。同时将目前线性模型进行部分优化作为过渡。

# 二、需求类型归纳

预判有收益，要新增能力。

# 二、需求收益判断

司机调度接受度模型优化，离线AUC+23.3pp；

# 三、需求说明和功能点

## 需求说明：

将司机调度接受度模型更新为XGB，策略方EVE部署，工程同学dmaster-rec服务调用，同时可提供相关日志；

## 功能点:

* 对目前线性模型进行特征及系数的调整，作为中间过渡期，使用特征为：eta，司机里程费（单公里费用 * eda）和司机无单补贴，接受度预估公式如下：

```python
def sigmoid(z):
    return 1 / (1 + np.exp(-z))
y_pred = -0.6820 + (-0.0011 * eta) + (0.0016 ✖️ 司机里程费) + (0.0003 ✖️ 司机无单补贴)
y_pred_final = sigmoid(y_pred)

```
* 工程侧在dmaster-rec调用新版司机接受度XGB模型，确保入参数及返回值无误；

**需要线上传入特征**

city_id：城市id

tlng：调度目的地司机经度

tlat：调度目的地司机纬度

flng：调度下发司机经度

flat：调度下发司机纬度

driver_id：司机id

dispatch_hour：调度下发当前小时

tgrid：调度目的地格子id

fgrid：调度下发司机所在格子id

company_id：公司id

eda：调度预估行驶距离(单位:米)

empty_drive_reward_amt: 空驶补贴金额(单位:分)

wait_order_reward_amt: 等单补贴金额(单位:分)

total_reward_amt: 补贴总金额(单位:分)

**模型返回值**

0至1之间的浮点数，返回值异常或为空时可用上述公式兜底；
