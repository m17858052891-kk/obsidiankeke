1. 模型生效与调用的位置：

司机每次出车或者完成上一单开始听单时，调用一次模型预测司机是否正处于双开状态，同时落模型日志

2. label的关联

通过网花两边的司机在线表关联，得到每一分钟司机在线时的状态

```SQL
-- 花业务自营与宏鹄融合后，很多表可能产生了一定的变化，可取一些数据抽样看看
--司机该时刻状态
--1：HXZ听单，WYC离线
--2：HXZ服务中，WYC离线
--3：HXZ离线，WYC听单
--4：HXZ听单，WYC听单
--5：HXZ服务中，WYC听单
--6：HXZ离线，WYC服务中
--7：HXZ听单，WYC服务中
--8：HXZ服务中，WYC服务中（仅从落表信息表现为同时busy，可能是异常数据）
--0：未知状态

with id_list as (
    select
        driver_id hxz_driver_id,
        wyc_driver_id didi_driver_id
    from
        kflower_dw.dwm_kf_dri_online_relate_wyc_df
    where
        dt = '${BIZ_DATE_LINE}'
        and online_dur > 0
)
select
    coalesce(hxz_driver_id_hxz, hxz_driver_id_wyc) hxz_driver_id,
    coalesce(didi_driver_id_hxz, didi_driver_id_wyc) didi_driver_id,
    coalesce(hxz_online_time, didi_online_time) `time`,
    case
        when didi_is_online is null
        and hxz_is_online = 1
        and hxz_is_busy = 0 then 1
        when didi_is_online is null
        and hxz_is_online = 1
        and hxz_is_busy = 1 then 2
        when hxz_is_online is null
        and didi_is_online = 1
        and didi_is_busy = 0 then 3
        when hxz_is_online = 1
        and hxz_is_busy = 0
        and didi_is_online = 1
        and didi_is_busy = 0 then 4
        when hxz_is_online = 1
        and hxz_is_busy = 1
        and didi_is_online = 1
        and didi_is_busy = 0 then 5
        when hxz_is_online is null
        and didi_is_online = 1
        and didi_is_busy = 1 then 6
        when hxz_is_online = 1
        and hxz_is_busy = 0
        and didi_is_online = 1
        and didi_is_busy = 1 then 7
        when hxz_is_online = 1
        and hxz_is_busy = 1
        and didi_is_online = 1
        and didi_is_busy = 1 then 8
        else 9
    end as status
from
    (
        select
            hxz_driver_id hxz_driver_id_wyc,
            didi_driver_id didi_driver_id_wyc,
            `time` didi_online_time,
            is_online didi_is_online,
            is_busy didi_is_busy
        from
            gulfstream_dwd.dwd_driver_onlinetime_supply t1
            inner join id_list t2 on t1.driver_id = t2.didi_driver_id
        where
            concat_ws('-', t1.year, t1.month, t1.day) = '${BIZ_DATE_LINE}'
    ) A full
    join(
        select
            hxz_driver_id hxz_driver_id_hxz,
            didi_driver_id didi_driver_id_hxz,
            `time` hxz_online_time,
            is_online hxz_is_online,
            is_busy hxz_is_busy
        from
            kflower_dw.dwd_kf_dri_online_patch_di t1
            inner join id_list t2 on t1.driver_id = t2.hxz_driver_id
        where
            t1.dt = '${BIZ_DATE_LINE}'
    ) B on A.hxz_driver_id_wyc = B.hxz_driver_id_hxz
    and A.didi_online_time = B.hxz_online_time;
```
