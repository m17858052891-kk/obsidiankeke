# 1. Motivation

参照乘客侧和订单侧流程，定义司机做单主流程。便于策略优化和指标监控。

# 2. 乘客侧流程回顾

乘客：生命周期内多次发单

订单：打开APP → 冒泡 → 发单 → 应答 → 接驾 → 送驾 → 付费

指标：冒泡率、冒泡转化率、愿等时长、应答率、接驾时长、接驾距离、拒单率、应答后取消率等

# 4. 具体需求

离线

将司机流转化为session。

在线
