# 三、技术方案

- **问题定义**：盲盒中约10%订单会发放3元的随单优惠券，**因此策略对应答后发券问题进行求解和建模**。

## 3.1 优化问题求解

- **问题定义：是否发券的决策问题可以定义为一个优化问题，目标是最大化完单增量，约束是补贴金额。**

- **目标函数**：最大化完单增量 $$\max \limits_{z} \sum \limits_{i=1}^{N} z_{i} \cdot \left( p_{i} - \hat{p}_{i} \right)$$

- **约束条件**：实花补贴金额小于预算金额 $$\sum \limits_{i=1}^{N} z_{i} \cdot \left(1 - \hat{p}_{i}\right)\leq B$$

- **优化问题求解**：当前问题为含约束的整数规划问题，可通过拉格朗日乘子法转化为无约束问题求解：

$$L(z,\lambda)= \sum \limits_{i=1}^{N} z_{i} \cdot \left( p_{i} - \hat{p}_{i} \right)+\lambda( B-\sum \limits_{i=1}^{N} z_{i} \cdot \left(1 - \hat{p}_{i}\right))$$

当 $$(p_i-\hat{p}_i)-\lambda(1-\hat{p}_i)>0$$时，取$$z_i=1$$，**即发券决策条件为**：$$\dfrac{p_i - \hat{p}_i}{1 - \hat{p}_i} >\lambda$$

> 符号定义如下：

| 数学符号 <br> | 含义 <br> |
| --- | --- |
| $$p_i$$ <br> |  订单 𝑖 的原始应答后c取消率 <br> |
| $$\hat{p}_i$$ <br> | 订单 𝑖 补贴后的应答后c取消率 <br> |
|  $$z_i$$ <br> | 订单 𝑖 的发劵决策变量 <br> |
| $$N$$ <br> | 总订单数 <br> |
| $$B$$ <br> | 补贴预算上限 <br> |

> 盲盒放置点位策略：考虑到乘客沉没成本，盲盒均放置导航路线上靠近乘客一侧比例约0.4的位置。

盲盒放置点位的推导过程
- 符号定义：

	-  乘客位置距离司机 x 米

	-  盲盒放置在距离乘客 y 米的位置

	-  因此盲盒距离司机的距离为 (x-y) 米

- 独立性假设：假设两段的取消事件相互独立，定义两段独立的取消率如下：

	- 司机到盲盒段取消率 $$p(x-y|x)$$：司机从出发位置到盲盒位置的取消率

	-  盲盒到乘客段取消率$$p(y)$$：从盲盒位置到乘客位置的取消率

- 总完成概率 = $$(1-p(x-y|x))(1-p(y))$$，我们的目标是最大化总完成概率，问题模型如下

	- $$max   \ \ (1-p(x-y|x))(1-p(y))$$

	- $$0 \le y \le x$$

- 为了简化计算，一方面采取500m分段，另一方面使用$$p(x)-p(y)$$代替$$p(x-y|x)$$

- 求解结果：不同接驾距离分桶对应的盲盒放置位置（更靠近乘客一侧的比例）如下：

{"0-1500": 0.413, "1500-2000": 0.47, "2000-2500": 0.385, "2500-3000": 0.347, "3000-3500": 0.373, "3500-4000": 0.415, "4000-4500": 0.453, "4500-5000": 0.485, "5000-100000": 0.413}

```Python
def calculate_blindbox_placement(df):
    """
    根据输入的距离分档和取消率数据，计算最优的盲盒放置位置。

    核心逻辑:
    1. 根据 p(y) = p(x) / 2 求解理论最优解 y_opt。
    2. 计算理论最优比例 p_raw = y_opt / x。
    3. 应用 min(p, 1-p) 对称性规则，得到最终比例 p_final。
    4. 计算最终放置点 y_final = p_final * x。
    """

    # --- 1. 数据预处理 ---
    work_df = df.copy()
    work_df['x_mid'] = (work_df["bin_left"] + work_df["bin_right"]) / 2
    work_df = work_df[work_df['x_mid'] > 0].sort_values('x_mid').reset_index(drop=True)
    # 准备插值所需的数据点
    distances = work_df['x_mid'].values
    cancel_rates = work_df['cancel_rate'].values
    # 强制单调递增
    iso = IsotonicRegression(increasing=True)
    cancel_rates_mono = iso.fit_transform(distances, cancel_rates)
    work_df['mono_cancel_rate'] = cancel_rates_mono

    # 筛选出风险快速增长的核心区域 (<= 4500m)
    analysis_df = work_df[work_df['x_mid'] <= 4500].copy()
    
    # 在核心区域内，计算500米间隔的平均风险增长率
    mono_rates_filtered = analysis_df['mono_cancel_rate'].unique()
    rate_diffs_500m_filtered = pd.Series(mono_rates_filtered).diff(periods=1).dropna()
    confidence_boost_c = rate_diffs_500m_filtered.mean()
    print(f"confidence_boost_c: {confidence_boost_c}")

    # --- 2. 求解理论最优解并应用 min(p, 1-p) 规则 ---
    # Step 1: 计算理论最优解的目标 p_target
    p_x = work_df['cancel_rate']
    p_target = p_x / 2 + confidence_boost_c / 2

    # Step 2: 通过插值找到理论最优解 y_opt
    y_opt = np.interp(p_target, cancel_rates_mono, distances, left=0.05, right=distances[-1])

    # Step 3: 计算理论最优比例 p_raw
    p_raw = np.divide(y_opt, work_df['x_mid'], 
                      out=np.zeros_like(y_opt, dtype=float), 
                      where=work_df['x_mid'] != 0)

    # Step 4: 应用 min(p, 1-p) 规则得到最终比例
    p_final = np.minimum(p_raw, 1 - p_raw)

    # Step 5: 根据最终比例计算最终放置点 y_final
    y_final = p_final * work_df['x_mid']

    # --- 3. 整理并输出结果 ---
    results_df = pd.DataFrame({
        "distance_bin": work_df['distance_bin'],
        "split_position": y_final.round().astype(int),
        "split_ratio": p_final
    })
    results_df = results_df.merge(work_df,on='distance_bin')
    return results_df
```

2、补充实验期间（二期实验，为期一周）实物盲盒的发放比例、数量、以及成本

- 数量：实验期间实物盲盒的发放数量为一天一单。放量后预计实物发放数量仍为一天一单，如果市场部有东西就用市场部的。由于发放比例低，存在无预期收益的风险，后续会关注长期效果。

- 比例：以二期实验组2为标准测算，组2每天盲盒开启量约2万，实物盲盒中奖比例约为两万分之一。

- 成本：实验期间实物盲盒成本约为500元。

> 二期实验期间无用户领取实物盲盒，原因是需要填写地址，导致用户实际领取意愿低。后续产品会调整填写地址入口至端内的券列表。

3、补充放量节奏明细

- 放量节奏：已和产品同学确认已预留预算可以长期配置实物。后续计划等完成实物奖励采购后，于4月开始放量，放量节奏计划留10%空白组，并于30%、60%、90%流量节点停留一周评估观察。

- 长期效果：需观察最后10%空白组 和 最早放量组 30 天的长期效果。
