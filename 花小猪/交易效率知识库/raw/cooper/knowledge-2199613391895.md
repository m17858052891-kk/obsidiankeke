# 一、 分单流程

- **召回**：考虑当前的待匹配订单和可用司机，选取候选司机乘客对

（连环派单是召回政策）

- **价值**：计算每一个司机和乘客配对的价值

（衡量价值的指标包括成交率、取消率和距离）

- **匹配**：根据价值做最优匹配

（使用贪心算法或者KM算法）

# 二、 连环派单概述

在无连环派单的场景，只需召回空车司机；但当司机供应不足，即司机数量少于订单数量的场景，需要执行连环派单以提升平台效率。**连环派单是指，平台把一部分即将结束上一单的司机进行召回，提前作出对下一个订单的响应。**

策略原理：连环派单通过提前释放即将完成上一单的服务中运力，对等待中的乘客提前应答，通过提升乘客的有车确定性来降低乘客的应答前取消率，进而提升供需失衡场景下的平台成交率。

对于乘客来说，连环派单会降低乘客的应答前取消率；对于司机来说，连环派单使得相同距离的接驾效率更高；对于平台来说，从全局上进行分单，有着更大的决策空间，从而最终实现**订单成交率和GMV**的提升。

注：图来自[连环派单重构-吴炼](http://wiki.intra.xiaojukeji.com/pages/viewpage.action?pageId=239836392)

- A：司机载有当前乘客所在的位置

- B：司机所载乘客的终点

- C：下一位乘客的位置

- 第一段距离：A-》B的距离AB（当前所载乘客距离终点的剩余距离）

- 第二段距离：B-》C的距离BC（当前所在乘客的终点距离下一单起点的距离，司机空驶距离

- 下一单乘客看到的距离：AB+BC

## 3.2 策略优化逻辑

- 通过调整AB段距离的上限，可以决定分单中可召回的服务中司机数量，AB上限越高，召回司机越多，但司机实际可服务到下一单的等待时间越长；理论上，如果AB没有上限，则分单可召回全城所有的服务中/空车运力（所有在线运力）。

- 通过调整BC段距离的上限，可以决定分单中可召回第一单O1下车点附近多少范围内的待分配订单。BC上限越高，可召回订单越多，但司机后续接驾的空驶占比越高；

- 站在第二单O2的乘客视角，他能观测到的司机接驾距离是AB+BC，AB和BC的相对大小，对其体验的影响主要体现在绕路感知上。在AB+BC为定值的条件下，AB越高，绕路感知越明显，当AB为0，连环派单退化为空车派单，无绕路问题。

- 连环派单的正向收益主要来源于策略召回面扩大 → 应答前取消率降低（大盘应答率提升） → 大盘成交率提高，负向约束（风险）主要来源于司乘侧体验（表现为应答后取消率提高 → 大盘成交率降低）。

综上，连环派单的策略优化部分，主要围绕几段距离的合理设置和动态调整，在方案设计上需要trade-off效率和体验，当然也涉及一些业务上的刚性约束，详见工程文档：[连环派单—工程文档](http://wiki.intra.xiaojukeji.com/pages/viewpage.action?pageId=239836392)。

# 四、连环派单策略

## 4.1 策略一

- 设置：AB+BC ≤ maxD，其中maxD为AB+BC的最大值

- 存在的问题：乘客对AB和BC的敏感度不同，认为乘客对第二段距离即BC更敏感

- 方法：对AB和BC的加权和进行限制，且BC的权重要大于AB的权重

## 4.2 策略二

- 设置：

![](https://s3-ep-inter.didistatic.com/didoc-upload-file-prod/1653033279949/860100667.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKDD00000000000EBLCTZNRBJHX6ZS%2F20261104%2Fgzep%2Fs3%2Faws4_request&X-Amz-Date=20261104T103553Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=e4421b2f11868d2e1c6fc5a47b757f71cf8d151a7e3cf7ed5eb394727504fe9d)

注：图来自[连环派单重构-吴炼](http://wiki.intra.xiaojukeji.com/pages/viewpage.action?pageId=239836392)

其中：

- X为AB，X要小于等于maxD

- Y为BC，Y要小于等于dynamicR

- M为惩罚系数，M=1则退化成空车（超参数1）

- maxD为AB+BC的最大值（超参数2）

- dynamicR为动态播单半径（以司机为中心，司乘匹配对的最大召回距离）  
供需紧张时，dynamicR会变大；供需平衡时，dynamicR会变小（超参数3）  

扩大召回距离，使得乘客应答后取消率升高，从而效率折损。

思路：**引入应答后取消率模型（该模型既考虑司机也考虑乘客，本质是考虑接驾距离），提前过滤掉取消率较高的DO对（司机-乘客配对），从而生成价值更高的DO对，提升成交率和GMV。**

需要注意的是，应答后取消率模型是二分类模型，即结果是取消或者不取消，而连环派单过滤时需要使用应答后取消的概率，因此需要首先给定一个取消率阈值，然后去掉高于该阈值的DO对。在选择阈值时，会考虑**误召率/召回率**（**误召率**10%是指1000个DO对，筛去了100个，但这100个中有10个是原本不会取消的用户，所以误召率是10/100=10%）

## 4.3 策略三

- 出发点：如何进一步扩大召回？如何冲破现有体验约束？

- 思路：**借助取消率模型（见上）、乘客预期管理（乘客预期等待时间），根据乘客已等时间，逐步放大召回（让乘客知道当前平台在做连环派单）**

- 场景：主要生效于–乘客可明显感知到无车的场景

- 将第一段距离放大到最大播单半径外，并且不断放大；将第二段距离控制在最大播单半径内。

其中：

- X为AB，X要小于等于Xmax

- Y为BC，Y要小于等于Ymax

- a和b为权重

- maxD为AB+BC的最大值（超参数2）

# 五. 连环派单现有问题

## 问题一：连环派单召回的空间拆解

- 相比于国际化业务中的连环派单，国内连环派单的应答占比低了10pp左右，需要拆解差异原因。此外，在供需比较差的国家，连环派单占比高

- 原因：国际化业务中没有乘客排队，国际化是动态调整价格；但国内不允许溢价，且国内乘客排队要保证公平性，遵循先到先得，可能会因此错失一些连环派单。

- 图：分单召回漏斗（ppt未拍）

## 问题二：连环派单取消原因拆解

通过对乘客进行问卷调查：

- 绕路问题：50%的乘客会因为绕路取消订单，一方面是因为乘客视角与分单视角存在差异，另一方面可以通过对乘客侧导航轨迹进行分析、对连环派单第一段距离进行控制，来减少绕路问题的发生。

- 距离长：**需要分析第一段距离、第二段距离和总距离的长度与乘客取消的相关性**。之前的分析中，认为乘客更看重第二段距离，但后来发现，如果第一段距离过长，会使得下一单乘客认为司机存在绕路行为，因此要同时控制第一段距离和第二段距离

- 重复取消占比/核心取消乘客：在所有的取消订单中，30%的取消订单来自于15%的乘客。

# 六. 当前改进策略

为了提升连环派单召回率，即解决问题一，对策略三的模型进行更改：

aX+bY≤ maxD

其中：a=b=1

X ≤ maxAB

Y ≤ maxBC

maxD=maxAB+maxBC

通过分别变动maxAB和maxBC，来实现maxD的变动

同样应用取消率模型来筛选OD对。

- 模型版本：通用场景应答后取消率2020-09版本，模型阈值为20%fpr

- 评估方式：时间片轮转，30min

## 9.1 背景说明

连环派单策略（对照组）重新开城后面临乘客应答后取消率偏高，召回偏低的问题，期望通过扩大召回提升策略生效面，解决运力紧张的问题。

## 9.2 实验目的

放松策略约束条件，扩大召回，提高连环派单应答占比，提升GMV及成交率

## 9.3 实验策略

实验组策略：连环派单V3.1

- 连环派单第一段距离上限：3000m / 4000m（两期实验上限不同）

- 连环派单第二段距离上限：3000m

- 连环派单两段距离之和上限：1800m → 2500m(15s) → 3000m【二期】/ 4000m【一期】(30s)

- 连环派单两段距离之和计算公式：aX+bY <= maxD，其中a=1，b=1，maxD为连环派单两段距离之和上限，参照上面的配置

- 调权系数：0.95

- 模型版本：通用场景应答后取消率2020-09版本，模型阈值为20%fpr

对照组策略：连环派单V2.2

- 连环派单第一段距离上限：2500m

- 连环派单第二段距离上限：动态播单半径

- 连环派单两段距离之和上限：2500m

- 连环派单两段距离之和计算公式：X+Y\*（M\*maxD）/ dynamicR <= maxD，其中惩罚项M=2，maxD为连环派单两段距离之和上限，参照上面的配置

- 调权系数：无

- 模型版本：通用场景应答后取消率2020-09版本，模型阈值为20%fpr
