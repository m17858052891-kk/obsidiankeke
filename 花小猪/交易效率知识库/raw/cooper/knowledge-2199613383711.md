# 1.背景

目前hxz大盘交易模式是半指派，default yes形式（一天3次拒单权益）。

# 2.数据

- 45%的改派订单，司机已使用完拒单权益（拒单权益不够）；25%的改派订单，司机没有使用拒单权益（拒单权益没用，不如default no）

- 至少20%的应答后乘客取消订单有司机诱导取消嫌疑（司机应答之后无法完成服务，不如default no）

- 巴西default no模式，抢单率70%，应答率90%

# 3. 结论

- default no如果不做管控会有效率损失，平台定位弱管控，所以选择default yes

- 针对应答后司机改派或者诱导后取消对乘客的伤害

	- 教育司机合理双开 [何佳玲](dchat://im/start_conversation?name=hejialing)

	- 拒单权益运营，针对做单能力强的司机加拒单权益

	- 司机诱导取消管控
