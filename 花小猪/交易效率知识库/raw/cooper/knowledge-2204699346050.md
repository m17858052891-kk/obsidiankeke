盲盒的整体流程如下：

# 三、策略优惠劵方案

## 3.1 问题定义

针对是否对特定订单进行补贴（发放优惠劵）的决策问题，我们建立一个数学优化模型来**<u>最大化完单量提升</u>**，同时**<u>满足补贴订单数量约束</u>**

### 参数及决策变量

1. 参数

𝑁: 总订单数

𝜃: 补贴订单比例上限，0 ≤ 𝜃 ≤ 1

𝛿: 重发单概率，0 ≤ 𝛿 ≤ 1

𝑐𝑟: 重发单后的完单率，0 ≤ 𝑐𝑟 ≤ 1

$$p_i$$: 订单 𝑖 的原始取消率，0 ≤$$p_i$$  ≤ 1

$$\hat{p}_i$$ : 订单 𝑖 补贴后的取消率，0 ≤ $$\hat{p}_i$$≤ $$p_i$$ （取消率对于支付金额的单调性）

假设：重发单概率和重发单后的完单率是同质的

2. 决策变量

$$z_i$$: 订单 𝑖 的发劵（补贴）决策变量，$$z_i$$∈ {0,1}

	- $$z_i$$= 1 表示对订单 𝑖 进行发劵

	- $$z_i$$= 0 表示不对订单 𝑖 进行发劵

𝜆: 拉格朗日乘子，𝜆 ≥ 0

### 其他细节补充

1. 是否出盲盒：基于取消率模型和距离约束，控制一定比例的订单出盲盒

2. 盲盒的放置位置

假设：

-  乘客位置距离司机 x 米

-  盲盒放置在距离乘客 y 米的位置

-  因此盲盒距离司机的距离为 (x-y) 米

独立性假设：假设两段的取消事件相互独立，定义两段独立的取消率如下：

- 司机到盲盒段取消率 $$p(x-y|x)$$：司机从出发位置到盲盒位置的取消率

-  盲盒到乘客段取消率$$p(y)$$：从盲盒位置到乘客位置的取消率

总完成概率 = $$(1-p(x-y|x))(1-p(y))$$，我们的目标是最大化总完成概率，问题模型如下

$$max   \ \ (1-p(x-y|x))(1-p(y))$$

$$0 \le y \le x$$

为了简化计算，一方面可以采取500m分段，另一方面可以使用$$p(x)-p(y)$$代替$$p(x-y|x)$$

**输出：离线HIVE表，接驾距离，切分点（靠近乘客）,示例如下：**

| **d_pickup_distance** <br> | split_position <br> | dt <br> |

# 四、工程链路

1. 盲盒是否触发判断（基于取消率模型和接驾距离约束分组控制），算法侧提供触发阈值，工程侧基于阈值判断是否触发盲盒

	1. 特征输入：使用当前已有特征，无新特征

	2. 乘客实际支付金额说明（假设取消率模型使用的是调用两次的方案）：第一次传入的是**原始支付金额特征**和其他已有特征，第二次传入的是 **原始金额-3元** 和其他已有特征

	3. 如果为构建的新模型，则只调用一次，传入已有特征，模型同时输出两个对应的取消率

2. 触发盲盒且命中判断策略优惠劵条件后：读取线上$$\lambda$$，根据边际收益计算$$u$$并与$$\lambda$$比较：如果$$u > \lambda$$则给用户（对应订单）发放策略优惠劵，并结束盲盒策略决策流程，反之则不给用户发放策略优惠劵，继续判断剩下的盲盒策略流程

3. 盲盒触发位置：基于接驾距离读HIVE表参数

4. 触发的结果：给出放置盲盒位置，盲盒策略结果

5. 预算监控

6. 策略-工程传参

	1. $$\lambda$$表

	2. 放置位置距离表（策略），人工组的确定比例

	3. 取消率/距离阈值

	4. 策略优惠劵模块--使用随机时的随机概率
