# 一、需求背景

目前自营分单侧动播策略大多基于格子维度的供需，对格子内所有发单或某一类订单如长单同时生效，然而即使同样的供需场景下不同订单由于勾选品类(竞争商家)，订单价值不同在实际分单时也会有较大的差异。

因此可基于订单的预估应答时间以及运力举手率进行不同的扩缩播策略实现个性化分单，**在举手率较低(运力不足时)可通过扩播保证应答，同时基于预计应答(取消)时长进行扩播速率的配置；举手率较高时可通过缩播来寻找更优运力，从而提升PK胜率及降低应答后BC取消率，保证司乘双方的体验性**。


# 二、需求类型归纳

预判有收益，需新增功能；

# 二、需求收益判断

基于动态扩播自营竞争应答率提升0.4pp，此时应答后BC取消基本不变(大盘35%)；基于缩播保证竞争应答率不变(20%)的前提下，应答后BC取消率降低2pp；

综合两种情况对自营商家竞争cr收益为0.4pp*(1-35%)+1pp*20%=**0.46pp**。

## 功能点:

2. 分单侧基于订单的预估举手率及应答时长进行初始播单半径及扩播速率的配置；
