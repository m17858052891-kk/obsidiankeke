# 一、需求背景

此前[自营格子动态播单优化策略](https://cooper.didichuxing.com/knowledge/2199610335356/2202364906683)对自营商家CR显著**+0.13pp**，且对于长短单分别进行了[实验结果](https://cooper.didichuxing.com/knowledge/2199610335356/2202849366054)的分析。当前版本在动播策略触发条件的竞争应答率计算中分母选用的未播订单数，与实际计算逻辑不符；同时策略对长短单的收益链路也有较大差异。因此基于以上两点对该版策略进行优化。


# 二、需求类型归纳

预判有收益，已具备初步功能，持续优化；

# 二、需求收益判断

预期收益：小猪端自营商家竞争cr提升**0.1pp**，应答后乘客取消率降低**0.15pp**，短单接驾距离降低**2%**；

# 三、需求说明和功能点

## 需求说明：

	本次需求涉及交易引擎与交易引擎测试团队，为策略类需求；

## 功能点:

1. 目前计算竞争应答率分母为当前格子未播订单数，需修正为当前格子自营竞争呼单数；

2. 调整Apollo初始半径等对应参数，重新配置实验；

# 四、需求通用属性

覆盖范围：

交易分单环节common recall模块；

# 五、效果评估方案

全国PID随机分流实验(10%对照组，90%实验组)；

评估指标：商家竞争CR；竞争AR；应答后BC取消；接驾距离；
