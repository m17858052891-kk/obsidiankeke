# 二、考虑「约束完单/CR，降低乘客ETP+ 司机接驾时长」

| 符号 <br> | 含义 <br> |
| --- | --- |
| $$j$$ <br> | 司机下标 <br> |
| $$f$$ <br> | 模型预估应答后司乘履约率 <br> |
| $$caa$$ <br> | 模型预估应答后司乘取消率，等于 $$1-f_j$$ <br> |
| cba <br> | 模型预估应答前乘客取消率 <br> |
| $$d= dist$$ <br> | 司机到订单起点的路面距离 <br> |
| $$\lambda = \lambda_{PK}$$ <br> | 复用 PK 策略中的距离置换系数，含义与 PK 文档保持一致 <br> |
| $$()^{N+1}$$ <br> | 下一轮分单/PK <br> |
| $$F$$ <br> | 平台价值 <br> |

目标是「by订单维度，平台价值最大化」，当前平台价值是「履约率、乘客ETP和司机接驾时长」多目标的价值，结合PK策略[约束履约率并最小化接驾距离的PK策略方案v1.1](https://cooper.didichuxing.com/knowledge/2199610335356/2207928276868)对平台价值进一步简化。

对于一个订单，

- 司机$$j$$准入（播单/举手进PK）下的价值$$F_j = f_j - \frac{1}{\lambda} d_j = 1-caa_j -\frac{1}{\lambda} d_j$$

- 无司机准入，则订单会等下一轮分单/PK，价值是$$F_{\empty} = (1-cba)*(f^{N+1} - \frac{1}{\lambda}d^{N+1})$$

因此，**司机**$$j$$**准入的条件**： 

$$F_j > F_{\empty} \  \Longleftrightarrow \  1-caa_j -\frac{1}{\lambda}d_j > (1-cba)*(f^{N+1} -\frac{1}{\lambda}d^{N+1})$$

**各个符号的计算**：

- $$caa_j = 1-f_j$$ 通过PK履约率模型预估换算得到

- cba：应答前取消模型预估

- $$f^{N+1}$$：根据模型预估履约率的P90分位数估计

- $$d^{N+1}$$：根据多等一轮的司机接驾距离的P90分位数估计

- $$\lambda$$: 复用PK策略中的$$\lambda$$
