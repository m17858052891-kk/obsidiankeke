其中以所有播单订单的完单情况为例，做进一步解释。

对于如图所示订单orderA，1⃣️、2⃣️、3⃣️、4⃣️的司机分别为driverA、driverB、driverC、driverD，1⃣️、2⃣️、3⃣️、4⃣️均会出现在播单表中，但是只有4⃣️完单。即只有播单表中orderA和driverD对应的do对可以标记为完单。

附：[播单日志字段含义梳理](http://wiki.intra.xiaojukeji.com/pages/viewpage.action?pageId=375773453)

```PlainText
select
    brt.order_id,
    brt.driver_id,
    (
        case
            when is_td_finish = 1 then 0
            else 1
        end
    ) label
from
    (
        select
            cast(param ['lowoid'] as bigint) as order_id,
            cast(param ['driverid'] as bigint) as driver_id
        from
            kflower_ods.ods_log_kflower_orderbroadcast
        where
            concat_ws('-', year, month, day) = '2021-04-06'
            and cast(param ['driverid'] as bigint) > 0
            and cast(param ['lowoid'] as bigint) > 0
            and cast(param ['DispatchType'] as bigint) in (1, 2, 3)
    ) brt
    left join(
        select
            order_id,
            driver_id,
            order_status,
            cancel_type,
            is_td_answer,
            is_td_finish
        from
            kflower_dw.dwd_kf_trd_order_base_di
        where
            dt = '2021-04-06'
            and is_td_call = 1
    ) base on base.order_id = brt.order_id
    and base.driver_id = brt.driver_id
```
