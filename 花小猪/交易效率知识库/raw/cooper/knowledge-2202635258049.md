# 项目背景

目前交易分单时缺少订单奖励信息，因此对有司机奖励的订单(如免佣动调，加价红包等)并无特殊策略逻辑。然而对于**提供奖励信息提醒的订单会增强司机的接单意愿**，如提升司机对更远接驾距离的接受度，同时在分单时D对O打分除IPH外也应该考虑补贴信息。因此针对这部分奖励订单可优化当前分单策略，通过倾斜从而提升应答率，最终提升完单。

分单策略优化主要对全渠道订单在自营和宏鹄商家分单时**GS算法D对O打分的修正**。

# 收益测算

目前免佣，动调，加价红包等司机奖励订单占大盘约为10%，假设通过对该类订单进行分单策略的倾斜应答率提升5%，目前该类订单应答后BC取消约为25%（扩播会提高应答后BC取消，不过，向司机透传奖励信息可降低应答后BC取消，二者相抵，假设取消率不变）

因此对大盘CR预估收益为：10% \* 5% \*（1-25%）= **0.38pp**。

# 策略方案

## GS算法D对O打分优化

分单时基于获取到的订单奖励信息，如**动调、免佣、加价红包**等，此时基于奖励形式及预付价格重新计算该笔订单的IPH，具体实现方案如下：

1. 对于**加价红包，动调等奖励形式可直接将补贴金额加入到预付价格**一起计算IPH；

2. 对于免佣订单若能by订单获取佣金比例系数，新IPH = 乘客预付价格\*(1 / （1 - 佣金比例系数））；若不能获取by订单的佣金比例新IPH为乘客预付价格\*(1 / （1 - $$\beta$$）），其中$$\beta$$为历史近一个月内免佣订单(不区分商家)的平均佣金系数比例；

## 奖励订单扩播策略

奖励形式：**T+1围栏免佣、加价红包、动调（除了全城动调）**
