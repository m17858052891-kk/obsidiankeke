# 背景：

目前在连环派和扩播场景下，策略会根据场景提供不同的模型和过滤阈值。连环派和扩播策略会根据阈值和模型的输出值来判断是否需要过滤一个DO对。由于司机和乘客的接受度会随着时间进行改动，所以过滤阈值需要根据此变动来调整。

## 方案：

uplift DECFR 模型

目标 ： $$max CR$$

约束 ： BC应答后取消

问题定义：

$$z_{i,j} \in \{ 0,1\}$$决策变量， 给第i轮第j个过滤阈值

$$\tau_{i,j}  \geq 0$$第i轮第j过滤阈值带来的完单折损

$$\epsilon_{i,j} \geq 0$$第i轮第j过滤阈值带来的应答折损

$$\delta_{i,j}$$第i轮第j过滤阈值带来的BC应答后取消量变化

finish(0) 没过滤情况下的完单量

ans(0) 没过滤情况下的应答量

cancel(0)  没过滤情况下的BC应答后取消量

B 取消率约束

我们的总目标是在BC应答后取消的约束下来最大化CR 

$$max CR = min f(Z) = min \frac{\sum_{i}^N {finish(i)} }{\sum_{i}^N {call(i)} }$$

st $$g(Z) =\frac{\sum_{i}^N {cancel(i)} }{\sum_{i}^N {ans(i)} } - B \leq 0$$

我们认为阈值对call没影响

$$max CR = min f(Z) = min \sum_{i}^N {finish(i)}$$

st $$g(Z) =\frac{\sum_{i}^N {cancel(i)} }{\sum_{i}^N {ans(i)} } - B \leq 0$$

$$max CR = min f(Z) \Leftrightarrow min - \sum_{i}^N {finish(i)} = min - \sum_{i}^N {(finish(0) - \tau_{i,j}*z_{i,j})} = min \sum_{i}^N { \tau_{i,j}*z_{i,j}}$$

st $$g(Z) =\frac{\sum_{i}^N {cancel(i)} }{\sum_{i}^N {ans(i)} } - B  = \frac{\sum_{i}^N {cancel(0)+\delta_{i,j}*z_{i,j}} }{\sum_{i}^N {ans(0)- \epsilon_{i,j} *z_{i,j}} } - B \leq 0  \Leftrightarrow \sum_{i}^N {(cancel(0)+\delta_{i,j}*z_{i,j})} - B * \sum_{i}^N {(ans(0)- \epsilon_{i,j}*z_{i,j})} \leq 0$$
