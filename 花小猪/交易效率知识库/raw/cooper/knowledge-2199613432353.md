# 1. 背景

去除交易模式外，目前派单引擎的分单策略主流程为： 召回 → 价值 → 倾斜 → 匹配 → (改派)

特别的，对匹配环节，存在以下几种模式：

- KM：二分图最优匹配（全局最优）

- 贪心(Greedy)：按匹配价值(str)排序，贪心匹配

- Topspeed：按发单时间排序，贪心(greedy)匹配

网约车订单分配中，传统的方法是将可匹配的司乘间，建立一个二分图（如下图），二分图的边权为司乘匹配对的价值。而后计算二分图的最大匹配（即边权加和最大）作为最终的司乘匹配结果。

计算最大匹配一般使用KM算法，即大家比较熟悉的“全局最优”派单模式。

KM算法的优势在于其可得到理论上最优的最大匹配，即确定了一种匹配价值计算方法之后，KM可以保证得到的匹配结果是最优的。

但是在实际应用中，常常我们需要考虑多目标优化的问题，如平台需要同时考虑乘客诉求（接驾近，应答快，预期准）、司机诉求（接驾近、订单质量高）、平台诉求（最大化GMV or 成交量、司乘等级和倾斜等），故匹配价值函数的定义是非常复杂的。

在双边匹配市场中，存在另一种匹配方式，即双边分别有自己的一套对对方的排序体系，进而求双边的稳定匹配。

本wiki旨在调研稳定匹配在网约车场景上的应用可能性。

# 2. 稳定匹配问题定义

稳定分配理论是由2012诺奖获得者沙普利使用合作博弈的方法来研究和对比不同的匹配方法而创立的理论。

所谓稳定，指的是不存在这样两个市场主体，他们都更中意于彼此、胜过他们当前的另一半。其中双边模型和延迟接受算法是稳定匹配理论的两块重要基石。

“双边市场”是指存在这样一个市场，市场中有两类个体集合，第一类集合中的个体只能和第二类集合中的个体相匹配。

举例：一是如何使学校招收到更满意的学生，而新生也不必因报错志愿而落榜。二是如何使单身男女实现速配，又不发生与他人私奔的行为。

以男女配对为例，现在有N位男生和N位女生，每个男生都对N个女生的喜欢程度做了排序，每个女生都对N个男生的喜欢程度做了排序，现在需要确定一个稳定的约会状态。

稳定的定义：

如果原始匹配为：

男生i和女生a牵手，男生j和女生b牵手；

但男生i对女生b更喜欢，而女生b发现，相比自己的男朋友j，她更喜欢男生i；

则没有力量阻碍男生i和女生b的私奔，这即是不稳定的。

对应于网约车的场景，稳定匹配的结果，~~是对任意一个匹配完成的DO对(d1, o1)，都不存在o2使得 v(d1,o2) > v(d1,o1) and v(d1, o2) > v(d2, o2)，也不存在d2使得 v(d2,o1) > v(d1,o1) and v(d2, o1) > v(d2, o2)。~~

即对任意一个匹配的DO对，如果司机抱怨为什么没有分给他另外一个更好的订单，我们可以保证这个好订单周围有更合适的司机；反之亦然，如果乘客抱怨为什么没分给他一个更近的司机，我们可以保证这个司机周围有更合适的订单。

# 3. GS算法简介

1962年，沙普利和他的同事盖尔找到了一个叫做GS算法(Gale-Shapleyalgorithm，又叫延迟接受算法)的方法。

解决思路（以男生主动为例）

- 首先选择一个单身男生，他会按照他的喜欢程度对一个还没有表白过的女生表白。

- 如果女生此时处于单身状态，则恭喜，他们两人将进入约会状态。

- 如果女生已经有男朋友，则女生会比较当前男朋友与表白的男生，如果更喜欢表白的男生，则恭喜，男生成功上位，女生之间的男朋友则进入单身状态；若女生还是更喜欢自己的男朋友，则不好意思，男生表白失败。

- 当所有的男生都脱离单身状态时，此时的约会状态应是稳定的。

值得注意的是，GS算法存在方向性，对主动的一方有利。即男生会找到所有稳定匹配中最好的一个，女生会找到所有稳定匹配中最差的一个。

从某种意义上来说，相比于KM是“全局最优算法”，GS则是“司乘最优算法”。

# 4. GS算法与KM算法优劣势对比

GS优势

- 多目标

	- 可区分司机排序标准（如司机用订单gph）和乘客排序标准（如乘客用接驾距离）

- 倾斜实现

	- 由于区分排序标准，倾斜比较方便实现

	- 司机倾斜：接驾距离上加优势

	- 订单倾斜：订单金额（或gph）上加优势

- 司乘可解释性好

	- 司机问为什么某个订单没有分给我，可回答是因为订单周围有更近的司机存在

	- 乘客问为什么某个司机没有分给我，可回答是因为司机周围有更好的订单存在

	- 问题：是否可以把这个解释性更好的利用起来？

- 性能

	- GS最差条件O(N^2)，KM为O(N^3)

KM优势

- 最优性

	- 在目标确定的情况下（如多个指标的加权），保证求解结果的最优性

	- 方便优化平台指标（如成交率、毛利率）

- 稳定性&可靠性

	- 在DD已经运行多年，没出问题

	- 坑都踩过，如倾斜怎么实现，物理意义是什么等

另外还有一个价值观导向的问题

GS倾向于给排序高的司乘更好的体验（如高价值单更近的接驾），而KM更倾向于所有人平均体验，但是总的完单数更高。

故GS的核心其实在于去除大锅饭，给头部的个体倾斜更多的资源，但是资源包总额由于效率问题会下降。

GS有点像Airbnb的做让一部分人觉得100分，而不是让所有人觉得60分的产品。

对题图：

KM会选右边（全局最优，更多匹配）；GS会选左边（少匹配一对，但是匹配结果的司乘体验会好）
