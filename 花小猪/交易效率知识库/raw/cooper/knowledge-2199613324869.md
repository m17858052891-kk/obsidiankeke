## Why we need to investigate the graph neural network

1. 司机和乘客的关系本身就是一个图的关系

2. 我们想用一种更高级的模型来刻画司机和乘客之间的关系

3. 司机和乘客的数量往往是巨大的，graph neural network可以刻画这种large-size的graph

## How to embed node(vertex) into a feature space using convolution?

1. Generalize the concept of convolution to graph >> spatial-based convolution

2. Back to the definition of convolution in signal processing >> spectral-based convolution

## Spatial-based convolution

1. Aggregate: 用neighbor feature update 下一层的hidden state

2. Readout： 把所有nodes的feature集合起来代表整个graph

代表:

- graph attention network （GAT) 在基础的图神经网络上加上了注意力机制，需要去学习每个节点的注意力权重。

- graph isomorphism network (GIN) 更加具有理论基础
