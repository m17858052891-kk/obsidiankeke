## 0 摘要

本分享主要研读了paper《MM-LLMs: Recent Advances in MultiModal Large Language Models》，并适当加入了其它论文的comments.

试图讲清多模态大模型 MLLM / MM-LLM / LVM 的

- 主流模型架构（Image Encoder + VL Connector + LLM) 

- 训练流程 (多模态预训练 + 多模态指令微调），包括训练数据集格式、训练方法分类

并试图加入业界对不同模块选型、训练方法、数据集格式有效性的评价。

不包含具体模块/训练方法的细节。

## 1 背景

**从传统多模态到多模态大语言模型MM-LLM:** 传统多模态预训练研究近年来取得了显著进展，但随着模型和数据集的规模不断扩大，从头训练传统多模态模型遇到了**计算开销**上的瓶颈。鉴于多模态研究涉及多种模态的交叉应用，一种应对方法是充分利用现有的预训练单模态基座模型，尤其是强大的LLMs，来降低计算成本并提高多模态预训练的效果，从而催生了新的领域：MM-LLM.

**利用单模态大模型的优势来赋能MM-LLM**：LLM具有强大的**语言生成、零样本迁移和上下文学习(ICL)**等能力，同时其他模态的基座模型能够提供**高质量的表征**。考虑到不同模态的基座模型是独立训练的，MM-LLM的核心挑战是**如何有效连接LLM与其他模态的模型，以实现协同推理**。主要是通过**多模态预训练 MM Pre-Training(PT)** 和 **多模态指令微调 MM Instruction-Tuning(IT)**来优化模态之间的对齐(alignment) ，并保持与人类意图的对齐。

**发展历程**：GPT-4(Vision)(2023), Gemini(2023) 表现了强大的多模态理解和生成能力，引起了MM-LLM领域的研究热潮。最初的研究主要聚焦于多模态**内容理解**和**文字生成**，后来扩展到特定的**多模态输出**，包括图片-文字输出、演讲/音频-文字输出等。最近的研究致力于模仿人类做任意模态之间的转换。

## 2 模型架构

一般的MM-LLM 由5个部分组成，分别是**Modality Encoder, Input Projector, LLM Backbone, Output Projector, Modality Generator**.

前3部分强调多模态理解。训练过程中，Modality Encoder, LLM Backbone, Modality Generator处于冻结状态，主要的参数优化在Input\\Output Projector. 基于Projector属于权重轻量的组件，MM-LLM中可训练参数的占模型总参数量明显较低（通常约为2%左右）。总参数量取决于使用的核心LLM的参数规模。

最通用的其实是3个部分：视觉编码器（眼睛），VL连接器，LLM（大脑）。

### 2.1 模态编码器 Modality Encoder(ME)

模态编码器是将**多模态输入$$I_X$$编码为特征嵌入**$$F_X$$，$$F_X = ME_X(I_X)$$，其中$$X$$可以是图像、视频、音频、3D点云等。存在各种多模态预训练编码器选项。

| 模态 <br> | encoder <br> |
| --- | --- |
| 图像 <br>视频-&gt; 图像 <br> | NFNet-F6(2021), ViT(2020), CLIP-Vit(2021), Eva-CLIP ViT(2023), BEiT(2023d), Open-CLIP(2023), Grounding-DINO(2022b),  DINOv2(2023), SAM-HQ(2023), RAM++(2023i), InternViT(2023j), VCoder(2023) <br> |
| 音频 <br> | C-Former(2023b), HuBERT(2021), BEATs(2023g), Whisper(2023), CALP(2023e) <br> |
| 3D 点云 <br> | ULIP-2 <br> |

此外，为了处理众多异质的多模态编码器，一些MM-LLM（尤其是any-to-any) 使用ImageBind 来统一编码。ImageBind是一个涵盖6种模态（图像/视频、文字、音频、热力图、惯性和深度）的统一编码器。

**图像编码器**

以Google的Vision Transformer（ViT) 为例，说明一种主流的图像编码方式。

ViT 抛弃了==传统卷积神经网络 (CNN) 依赖局部卷积核的设计，开创性地==**将图像视为“序列化的文本”**来对图像进行编码。

首先，ViT对图像分块patch，==将连续的二维图像进行“离散化”；再将patch展平(flatening)得到一维向量，经过线性投影层得到patch embedding。这样就将每一个物理上的、具体的图像块，都转换成了一个数学上抽象的、蕴含了初步内容信息的“视觉词元”（Visual Token），其作用完全等同于自然语言处理中的“词嵌入”。==

==接着，会对Visual token添加位置编码。==

==最后就可以将这些带有位置编码的patch embedding送入标准的Transformer Encoder 中进行深度处理和全局信息融合。==

### 2.2 输入投影头 Input Projector / VL Connector

输入投影头/连接头$$\Theta_{X\rightarrow T}$$ 的目标是**将其他模态的特征编码 $$F_X$$与文字特征空间 $$T$$对齐**。

其输入是$$F_X$$, 输出是对齐后的prompt $$P_X$$，会和文字特征 $$F_T$$一起喂进LLM Backbone. 给定 X-文字 数据集 $$\{I_X, t\}$$,目标是最小化基于$$X$$的文字生成损失 $$\mathcal{L}_{txt-gen}$$

$$\argmin\limits_{\Theta_{X\rightarrow T}} \mathcal{L} _{txt-gen}(LLM(P_X, F_T),t)$$  (2)

其中，$$P_X = \Theta_{X\rightarrow T}(F_X)$$.

这个所谓对齐特征空间的过程主要涉及到特征维度的变化和特征的线性变换。

![](https://s3-ep-inter.didistatic.com/didoc-upload-image-prod/17658189008116f1c0787-d758-4b51-a7bd-39538fb26a05/image.png?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKDD00000000000EBLCTZNRBJHX6ZS%2F20261104%2Fgzep%2Fs3%2Faws4_request&X-Amz-Date=20261104T093034Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=acb986112eda83a6bc6af99bc6b4abb5f165bc1f74295a8b9a7a99aced8f64f4)

连接头可以直接通过**线性投影层或MLP**（代表为LLaVA系列）实现，更复杂的实现包括 **Cross-attention**（Flamingo）**, Q-Former**（BLIP-2）**, P-Former, MQ-Former**, **C-Abstractor, D-Abstractor**

**Cross-attention**将可训练的向量作为query,将特征编码$$F_X$$作为key, 将变长的特征压缩为固定长度。 **Q-Former** 用可学习的query从$$F_X$$中提取相关特征，然后筛选的特征被用作为提示词$$P_X$$. 而 **P-Former** 对Q-Former产生的提示词施加对齐约束，来生成“参考提示词” (reference prompts)。**MQ-Former**对多尺度视觉和文字信号进行了精细的对齐。 Q-,P-,MQ-Former均需要额外的微调(PT)过程来进行初始化。

### 2.3 大语言模型 LLM BackBone

MM-LLM能够继承LLM的优势，诸如零样本迁移、少样本ICL、CoT以及指令学习等。

LLM处理来自多模态的表征，<u>输出1) 文字t  2) 关于其它模态的信号token</u> $$S_X$$作为后续多模态生成的prompt. 除此以外，还有参数高效的微调方法（PEFT）也会用来微调MM-LLM, 如 Prefix-tuning, LoRA, LayerNorm tuning等。

- ==核心任务:**将经过“连接器”翻译对齐后的多模态特征，与用户的文本指令深度融合**==(concate)==，并通过强大的====**自回归生成**====能力，输出符合逻辑、切合情境的文本回复。==

- 输入：visual token + text token  或 交错排列的复杂序列

- 核心机制：（基于多模态）上下文的**自回归生成**Autoregressive Generation， 与纯文本LLM一致

- 架构演进：dense, MoE

文章也列举了MM-LLM中常用的LLM, 包括Flan-T5(2022), ChatGLM(2022), UL2(2022), Persimmon(2023), Qwen(2023), Chinchilla(2022), OPT(2022), PaLM(2023), LLaMA(2023), Vicuna(2023).

### 2.4 输出投影头 Output Projector (OP)

输出投影头$$\Theta_{T\rightarrow X}$$将LLM的输出$$S_X$$ 映射到token表征， $$H_X = \Theta_{T \rightarrow X}(S_X)$$.  其目标函数是

$$\argmin\limits_{\Theta_{T\rightarrow X}} \mathcal{L}_{mse}(H_X, \tau_X(t))$$   (4)

其中，$$\tau_X$$是$$MG_X$$中基于文字的编码器。

输出投影头用一个小型的带有可学习解码器的Transformer或MLP来实现。

### 2.5 多模态生成器 Modality Generator (MG)

MG用来生成多模态输出，当前常见的方法是使用现有的潜在扩散模型(Latent Diffusion Model, LDM)，如Stable  Diffusion, Zeroscope, AudioLDM2等。

输入$$H_X$$在去噪过程中作为conditional inputs生成多模态内容

损失函数 

$$\mathcal{L}_{X-gen} := \mathbb{E}_{\epsilon \sim \mathcal{N}(0,1),t}|| \epsilon - \epsilon_{X}(z_t,t,H_X) ||_2^2$$ (5)

优化 $$\Theta_{X\rightarrow T}$$和 $$\Theta_{T\rightarrow X}$$的参数。

## 3 训练流程

### 3.1 多模态预训练 MM PT

在预训练阶段，训练Input Projector和Output Projector来实现**不同模态之间的对齐**。

对于多模态理解任务的模型，优化目标是(2); 对于多模态生成模型，优化目标包含(2)(4)(5)。

预训练阶段通常使用X-文字数据集，有两种形式，以图像为例：

1）图像-文字对，<img1><txt1> （也称为带标题的图像 Captioned Images) , 文字简短，相关性高;

 2) 交替 图像-文字语料，<txt1><img1><txt2><txt3><img2><txt4>，文字较丰富，相关性较低

在mmc4的论文中提到，交替图像-文字格式不仅能够交替独立的监督（图像，文字）示例来实现少样本学习，而且能够支持更复杂的提示词，例如涉及图像之间交互关系的问题，比如“图像A和图像B有什么共同点“。

在MM1论文中提到，captioned/interleaved/text 比例为5:5:1时，多模态模型的表现好。合成数据对少样本学习有效。

### 3.2 多模态指令微调 MM IT

多模态指令微调是一类使用指令格式的数据集对完成预训练后的MM-LLM进行微调的方法，帮助MM-LLM**适应人类指令**，**提高在未见过任务上的泛化能力**。

MM IT 包含SFT和RLHF，旨在对齐人类指令和偏好，增强MM-LLM的交互能力。

SFT会将部分预训练中使用的数据转换为指令感知的格式。以视觉QA为例，举例两种格式：

1）“<Img>{Question}"  A short answer to the question is : ; 

2) "<Img>" Examinethe image and respond to the following question with a brief answer: "{Question}. Amswer:" . 

SFT 数据集可以是单轮QA的格式，也可以是多轮对话的形式。

RLHF有两个重要作用是适应人类偏好和减少模型幻觉。在Aligning Large Multimodal Models with Factucally Augmented RLHF中，人的打分标准是More Helpful & Less Hallucinated. 在RLHF-V中，人类反馈是corrections on hallucinations.

在RLHF-V 中，RLHF的流程是1）MLLM对输入的图像和提示词生成回答，人对回答中的幻觉进行细粒度的校正；2）在RLHF中，用校正后的人类反馈利用强化学习算法进行模型优化。

## 4 SOTA MM-LLMs

分类了126个SOTA MM-LLM 包括功能型和设计型两个角度。在设计型中，“工具使用型”指的是将LLM当作黑盒，并提供对某些多模态专家模型的访问权限，通过推理来执行特定的多模态任务。

现有MM-LLM的发展趋势：

1）从对模态理解的专门强调，发展到特定模态的生成，进而演变为any-to-any模态的转换（例如， MiniGPT-4 => MiniGPT-5 => NExT-GPT)

2）从多模态预训练(MM PT)到有监督微调(SFT)，再到RLHF，训练流程不断优化，力求更好的与人类意图保持一致，并提升模型的对话交互能力（例如，BLIP-2 => InstructBLIP =>DRESS)

3) 接纳多样化的模态扩展（例如，BLIP-2 => X-LLM 和 InstructBLIP => X-InstructBLIP)

4) 采用更高质量的训练数据集（例如，LLaVA => LLaVA1.5)

5) 采用更高效的模型架构，从BLIP-2和DLP中复杂的输入投影模块Q- P-Former，转变为VILA中简单但高效的线性投影模块。

对数据集的一些说明：

OKVQA包含需要进行推理的问题，涉及多种知识类型（比如常识知识、世界知识以及视觉知识），MiniGPT-v2和MiniGPT-v2-chat表现最佳，展示了其强大的推理能力。

IconVQA强调图表理解能力和基于图表的认知推理能力，同样MiniGPT-v2和MiniGPT-v2-chat表现最佳。

VQAv2是一个基于VQA的更加均衡的数据集，每个问题都配对有一系列的图像。GQA更关注场景图像，每个问题都有结构化的含义说明和详细的回答该问题的逻辑步骤，强调逻辑推理能力。

基于这些SOTA模型，总结能提高MM-LLM效果的训练方法。

1）**图像分辨率**与训练推理成本之间的权衡。图像的高分辨率能提供更多的**视觉细节**，有助于对细节有高要求的任务。例如，LLaVA-1.5和VILA的分辨率是336×336，而 Qwen-VL 和 MiniGPT-v2 的分辨率则是 448×448。然而更高的分辨率会导致**序列长度变长**，从而**增加训练和推理的成本**。MiniGPT-v2通过在嵌入空间中将4个相邻的视觉token进行concate来减短长度；最近，Monkey等人提出了一种方法无需重新训练高分辨率视觉编码器即可提高输入图像的分辨率。此外，为了增强丰富文本图像、表格和文档内容的可理解性，DocPedia等人提出了一种方法，将视觉编码器的分辨率提高到2560×2560，来克服开源ViT中低分辨率表现不佳的问题。

2）**高质量的SFT数据**的结合可以显著提高特定任务的性能，如通过将ShareGPT4V数据添加到LLaVA-1.5和VILA-13B，能提高性能（Table 2)。

VILA提出的若干关键发现：

3）对**LLM Backbone进行PEFT**(Parameter-Efficient Fine-Tuning) 能够提高深度嵌入的对齐，对ICL很关键。

4）**交替式的图像-文字数据**被证明是更有效的，而图像-文字对的数据是次优的。

5）在SFT过程中将纯文本指令数据（例如非自然指令）与图像-文本数据重新混合，不仅解决了纯文本任务的退化问题，还提高了VL任务的准确性。
