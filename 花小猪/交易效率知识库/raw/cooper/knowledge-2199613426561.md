### 1. 如何分流

#### 1.1 司机id取模分流方式

#### 在分单侧进行的实验，工程那边有现成代码支持，可以直接driver_id%100分流，不需要开发；但指标需要自己跑数。

#### 1.2 Apollo分流方式

#### 1、随机分流：首先在apollo平台建立实验，随后实验地址和名称提供给工程开发同学进行代码的接入。可以第一周先上线空策略，测得AA结果，第二周上实验策略，测AB结果。

#### 2、自适应分流：在apollo平台建立实验时，选自适应分组，选好平衡指标（例如希望使实验组和对照组司机人均GMV是平的，就选人均GMV为平衡指标），可参考[在线Adaptive自适应分组用户手册](http://wiki.intra.xiaojukeji.com/pages/viewpage.action?pageId=507907451)；不需要再计算AA。

对1.1实验方式，需要**实验周期中的司机**作为样本，看其在实验前的一个周期内，指标的数值。

对1.2.1可以空跑空白策略，在apollo平台看AA，再看AB；也可以直接实验，实验后通过apollo.exp_group_data表**取**得**实验中不同组司机的driver_id**，再看其在实验前一周期内指标的数值。

1.2.2分流方式不需要看AA。

### 4. 如何算算显著性

以实验周期内，每个司机的均值指标为一个样本，得到实验组和对照组的样本队列，计算这两列数的样本量、均值和方差，计算显著性。

以上述Hold实验中人均GMV为例，取实验周期内，以实验组和对照组每个司机在实验过程中的日均GMV为一个样本，计算两组样本的样本量、均值和方差

```PlainText
select
    gp,
    count(1),
    avg(nvl(gmv_amt, 0) / online_days),
    stddev(nvl(gmv_amt, 0) / online_days)
from
    (
        select
            count(distinct dt) online_days,
            driver_id,
            if(driver_id % 100 < 10, 'exp', 'ctl') as gp
        from
            kflower_dw.dwd_kf_dri_online_hi
        where
            dt between '2021-05-25'
            and '2021-05-31'
            and is_online = 1
            and city_id in (
                select
                    DISTINCT city_id
                from
                    kflower_dw.dim_kf_pub_city_group
                where
                    dt = '2021-05-25'
                    and city_activity_group_name = '213城-大盘213城-213个城市-v.1'
            )
            and city_id not in (13, 17, 19) -- 青岛，昆明，成都
        group by
            driver_id,
            if(driver_id % 100 < 10, 'exp', 'ctl')
    ) a
    left join (
        select
            driver_id,
            sum(gmv_amt) gmv_amt
        from
            kflower_dw.dwd_kf_trd_order_base_di
        where
            is_td_finish = 1
            and (
                is_short_book_flag = 0
                or is_short_book_flag is null
            )
            and order_type = 0
            and product_1level = 1
            and dt between '2021-05-25'
            and '2021-05-31'
        group by
            driver_id
    ) b on a.driver_id = b.driver_id
group by
    gp
order by
    gp;
```

随后可以用python中的统计库来计算p值，若p值小于0.05，则两组样本的分布有显著差异

```PlainText
from scipy import stats
stat,p_value = stats.ttest_ind_from_stats(avg_group1,std_group1,num_sample_group1,avg_group2,std_group2,num_sample_group2, equal_var=False)
print(p_value)
```
