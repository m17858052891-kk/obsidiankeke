**实验数据日期：2026-03-05～ 2026-04-09 except 03-12  By 司机人均**

**背景收益链路：**

长时间无应答订单&自营宏鹄PK失败的司机DO连边加权->播单上涨->举手上涨->PK获胜上涨->自营宏鹄应答提升->自营宏鹄完单提升->大盘CR提升

**分析：**

自营加权后应答完单增长**符合预期**。

**宏鹄应答完单量下降**：加权差单转半指派->宏鹄应答量下降->宏鹄完单下降

**宏鹄差单转半指派，**造成宏鹄派单模式由全指派腾挪半指派，宏鹄人均半指派单量(+0.52，2.96%)与人均半指派拒单量(+0.30，+3.73%)显著上涨，影响宏鹄人均应答量下降0.12(-0.32%)，**差单加权对宏鹄有负向影响**。

with win as
(
    -- 所有胜出的od对
    select
        shiftleft(
            shiftright(cast(orderid as bigint), 46) & 262143,
            32
        ) +(cast(orderid as bigint) & 4294967295) as order_id,
        driverid as driver_id,
        round_num as round_num
    from
        kflower_ods.ods_log_kflower_g_order_dusepk_auction a
    where
        concat_ws('-', year, month, day)="2026-03-19"
        and channelid = 3
        and pktype = 15
        and action = 'auction_time'
        and process_order_status_ok = 'true'
        and process_winner_ok = 'true'
        and cityid = 32
),

refuse as (
    select  
        b.hxz_driver_id as driver_id,
        order_id
    from    
    (
    select * from
        tripcloud_data.ods_log_honghu_g_hh_assign_callback a
    where   
        concat_ws('-', year, month, day)="2026-03-19"
    ) a left join (
        select
            other_driver_id,
            hxz_driver_id
        from
            kflower_strategy.pk_hxz_driver_id
        where
            concat_ws('-', year, month, day)="2026-03-20"
    ) b on a.driver_id = b.other_driver_id
),

-- 找出交集
intersection as (
    select
        w.order_id,
        w.driver_id,
        w.round_num
    from win w
    inner join refuse r
        on w.order_id = r.order_id
        and w.driver_id = r.driver_id
)

-- 查看交集结果
