> Q1:如何求解内部minimize优化问题?

> A1:z_i为0-1变量，将lambda视为常数时，内部优化问题等价于min(f(0), f(1))

```Python
func = lambda l: -l * gmv * subsidy_rate + sum(
        np.minimum(
            l * (np.maximum(upgrade_price - base_price, 0)) * ar_upgrade
            - (1 - pre_dispatch_acc) * (ar_upgrade - ar_base),
            0,
        )
    )
```

> Q2:如何求解补贴率对应下的最优lambda

> A2:在确定z_i的前提下，L(lambda)是凸函数，使用三分法求解

```Python
def triple_search(left: int, right: int, epsilon: float, func: Callable) -> float:
    """三分法求凸函数的极点

    Args:
        l (int): 所求变量的下界
        r (int): 所求变量的上界
        epsilon (float): 精确度要求
        func (Callable): 凸函数

    Returns:
        float: 凸函数的极点
    """
    while right - left > epsilon:
        m1 = left + (right - left) / 3
        m2 = right - (right - left) / 3
        if func(m1) > func(m2):
            right = m2
        else:
            left = m1
        sys.stdout.write(f"\r当前的lambda为{(left + right) / 2}")
        sys.stdout.flush()
    sys.stdout.write("\n")
    logger.info(f"最终的lambda为{(left + right) / 2}")
    return (left + right) / 2
```
