卢锐消融实验解释：

1. 对于拿掉gate:

`专家分组i_experts = \[(0, 10), (5, 15), (0, 10), (5, 15), (0, 10), (5, 15)\]` 里，因此**专家 0‥5**是第一个连环派头**，****专家 5‥10** 是第二个共享头**，专家 10‥15** 是第三个非连环派头。

```PlainText
self.gate_layers = nn.ModuleList([
    nn.Sequential(
        nn.Linear(gate_dim, end - start),
        nn.Softmax(dim=1)
    ) for start, end in i_experts
])
```

代码里 `gate_layers` 的权重向量长度 = `end-start`，对应连环派(0,10)，对应tower 135；非连环派(5,15)，对应tower 246

把gate 权重下标换算回全局专家下标就会发现：

		- 连环派场景里只有**gate 第 7 个分量有效**  → 对应全局专家 **0+7=7** 

		- 非连环派场景里只有**gate 第 2 个分量有效**  → 对应全局专家 **5+2=7** 

都对应共享**专家 5‥10**，因此只有底部共享第二头专家生效，根据实验结果拿掉gate能更好接收到连环派和非连环派特征，学到所有特征。

```PlainText
poso_processed = torch.exp(-poso_input ** 2 / 2.0)  # [B, 1]
        
# 计算专家输出
expert_outputs = []
for i in range(self.n_expert):
```

### 1. LHUC(Learning Hidden Unit Contributions)

==LHUC 最核心的思想，是为每一个 speaker 定制一个振幅函数 (amplitude function)，作用于== [==DNN==](https://zhida.zhihu.com/search?content_id=225348464&content_type=Article&match_order=1&q=DNN&zhida_source=entity) ==的隐层之上。==

LHUC 让网络自己学出一套逐维缩放系数，对主干网络的隐藏单元做精细的、输入相关的动态权重调整。

```PlainText
class LHUCBlock(nn.Module):
    def __init__(self, input_dim, output_dim):
        super(LHUCBlock, self).__init__()
        self.mlp = nn.Sequential(
            nn.Linear(input_dim, output_dim),
            nn.ReLU(),
            nn.Linear(output_dim, output_dim),
            nn.Sigmoid()
        )   

    def forward(self,x):
        return 2* self.mlp(x)
```

1. **学系数:** LHUCBlock 本身就是一个极简的系数生成器：`mlp(·)` 输出维度与主干特征维度相同，且经过 Sigmoid 压缩到 (0,1)，再×2 拉到 (0,2)。于是每个样本、每个维度都会得到一个 0–2 之间的缩放因子。

2. **做调权:** 

	1. EPNet 里：`gate_output \* x_dnn` ，对主干 DNN 的输入做一次逐维 re-weight。

```PlainText
class EPNet(nn.Module):
    def __init__(self,dnn_dim,gate_dim):
        """
        dnn_dim: 主特征dim;
        gate_dim: gate特征维度
        """
        super(EPNet, self).__init__()
        self.ep_gate=LHUCBlock(input_dim = dnn_dim+gate_dim, output_dim=dnn_dim)

    def forward(self,x_dnn,x_gate):
        #切断梯度
        gate_input = torch.cat([x_dnn.detach(),x_gate],dim=-1)
        gate_output = self.ep_gate(gate_input)
        return gate_output*x_dnn
```

	2. PPNet 里：每一层隐藏层在激活前都先 `x = x \* gate_out`，把 LHUC 做到了层级别。

```PlainText
class PPNet(nn.Module):
    def __init__(self,dnn_dim,gate_dim,dnn_hidden_dim):
        """
        dnn_dim: 主特征dim；
        gate_dim: 门控输入特征dim；
        dnn_hidden_dim: list ,隐藏层dimlist
        """
        super(PPNet,self).__init__()
   
        self.layers_dims = [dnn_dim]+list(dnn_hidden_dim)
        self.dnn_layers = nn.ModuleList()
        for in_dim, out_dim in zip(self.layers_dims[:-1], self.layers_dims[1:]):
            # 中间层: Linear -> BN -> ReLU
            if out_dim != self.layers_dims[-1]:  # 不是输出层
                self.dnn_layers.append(nn.Sequential(
                    nn.Linear(in_dim, out_dim),
                    nn.BatchNorm1d(out_dim),
                    nn.ReLU()
                ))
            else:  # 输出层: 仅Linear
                self.dnn_layers.append(nn.Linear(in_dim, out_dim))

        gate_input_dim = dnn_dim + gate_dim

        self.gate_nets = nn.ModuleList([
            LHUCBlock(input_dim = gate_input_dim, output_dim = dim ) for dim in self.layers_dims[:-1]
        ])

    def forward(self , dnn_input,gate_input):
        gate_input_all = torch.cat([dnn_input.detach(),gate_input],dim=-1)
        x = dnn_input
        for gate_net, dnn_layer in zip(self.gate_nets, self.dnn_layers):
            # 应用层级门控
            gate_out = gate_net(gate_input_all)
            x = x * gate_out
            
            # 应用DNN层
            x = dnn_layer(x)
        
        return x
```

### 2. PPNet(Per-Layer Personalized Net)

==它把一条普通 MLP 拆成== 主干网络 + 每层一个 LHUC 门控 ==两条并行通路：主干负责学什么，门控负责学怎么用。==

#### 1. 模型初始化：先搭一条标准 MLP

```PlainText

for in_dim, out_dim in zip(self.layers_dims[:-1], self.layers_dims[1:]):

            nn.BatchNorm1d(out_dim),

```

实际输入dnn_hidden_dim=\[512,512,256,128\], ==接下来用== `ModuleList` ==按“Linear→BN→ReLU”堆叠中间层，最后一层只留 Linear，得到：==

dnn_layers\[0\]: dnn_dim→512 (BN+ReLU)

dnn_layers\[1\]: 512→512 (BN+ReLU)

dnn_layers\[2\]: 512→256 (BN+ReLU)

dnn_layers\[3\]: 256→128 (Linear)

#### 2. 再为模型每一层配一个 LHUC 门控

```PlainText
gate_input_dim = dnn_dim + gate_dim     
self.gate_nets = ModuleList(
    LHUCBlock(gate_input_dim, dim)           # 输出维度=该层输入维度
    for dim in self.layers_dims[:-1]        
)
```

#### 3. 前向传播：每层先缩放再DNN(MLP)

```PlainText
def forward(self , dnn_input,gate_input):
    gate_input_all = torch.cat([dnn_input.detach(),gate_input],dim=-1)
    x = dnn_input
    for gate_net, dnn_layer in zip(self.gate_nets, self.dnn_layers):
        # 应用层级门控
        gate_out = gate_net(gate_input_all) # 0~2 的缩放向量，与 x 同维
        x = x * gate_out                    # 逐维 re-weight（LHUC 核心）
        
        # 应用DNN层
        x = dnn_layer(x)                    # 再进入 Linear/BN/ReLU 或输出层

    return x
```

PEPNet 核心思想与 PPNet 一脉相承，并更注重 多域 (multi-domain) 多任务 (multi-task) 上的建模。

==PEPNet 把是否连环派场景信号先送进 EP-Net 做==全局粗调==，再把司乘类别特征送进 3 路 PP-Net 做==每层细调==，最后 6 塔输出、用 0/1 场景位==软路由==，实现==同一网络、多个场景、多个任务、司乘个性化==一站式建模。==

```PlainText
class PEPModel(nn.Module):
    def __init__(self, n_sparse, n_dense, n_serial, n_nonserial, n_binary, n_poso, n_seq_pas, n_seq_driver, max_sparse, base_numeric, scale_numeric):
        super(PEPModel, self).__init__()
        self.n_sparse, self.n_dense, self.n_serial, self.n_nonserial, self.n_seq_pas, self.n_seq_driver = n_sparse, n_dense, n_serial, n_nonserial, n_seq_pas, n_seq_driver
        self.n_binary, self.n_poso = n_binary, n_poso
        self.max_sparse = max_sparse
        self.register_buffer('base_numeric', torch.tensor(base_numeric, dtype=torch.float32))
        self.register_buffer('scale_numeric', torch.tensor(scale_numeric, dtype=torch.float32))
        self.d_embed = 20
        self.n_task = 6
        
        self.embed = nn.ModuleList([
            nn.Embedding(max_sparse[i], self.d_embed)
            for i in range(n_sparse)
        ])
        
        # 初始化Scalar2Vec层
        self.scalar2vec = nn.ModuleList([
            nn.Sequential(
                nn.Linear(1, self.d_embed),
                nn.Sigmoid()  # 添加Sigmoid激活函数
            )
            for _ in range(n_dense + n_serial + n_nonserial)
        ])

        self.serial_embed = nn.Linear(1, self.d_embed)

        # 序列编码器
        self.seq_encoder = PositionalSelfAttention(d_model=self.d_embed)
        
        dnn_dim = (self.n_dense+self.n_serial+self.n_nonserial+ self.n_seq_pas//10+ self.n_seq_driver//10) * self.d_embed #) * self.d_embed
        
        ep_gate_dim = self.d_embed
        pp_gate_dim = self.d_embed * self.n_sparse

        self.epnet = EPNet(dnn_dim=dnn_dim, gate_dim=ep_gate_dim)

        self.ppnet_od = PPNet(dnn_dim=dnn_dim, gate_dim=pp_gate_dim, dnn_hidden_dim=[512,512,256,128])
        self.ppnet_o = PPNet(dnn_dim=dnn_dim, gate_dim=pp_gate_dim, dnn_hidden_dim=[512,512,256,128])
        self.ppnet_d = PPNet(dnn_dim=dnn_dim, gate_dim=pp_gate_dim, dnn_hidden_dim=[512,512,256,128])

        self.towers = nn.ModuleList([
            nn.Sequential(nn.Linear(128, 1), nn.Sigmoid())
            for _ in range(self.n_task)
        ])

    def forward(self,features):
        # 拆分输入特征
        split_indices = [self.n_sparse, self.n_dense, self.n_serial, self.n_nonserial, self.n_binary, self.n_poso, self.n_seq_pas, self.n_seq_driver]
        x_sparse, x_dense, x_serial, x_nonserial, x_binary, x_poso, x_seq_pas, x_seq_driver = torch.split(
            features, split_indices, dim=1
        )

        # 2. 序列特征 reshape -> (B, 10, 10) 并编码
        x_seq_pas   = x_seq_pas.view(-1, 10, 10)
        x_seq_driver = x_seq_driver.view(-1, 10, 10)
        x_seq_pas   = channel_norm(x_seq_pas)
        x_seq_driver = channel_norm(x_seq_driver)
        seq_pas_emb   = self.seq_encoder(x_seq_pas)      # (B, 10, d_model_seq)
        seq_driver_emb = self.seq_encoder(x_seq_driver)  # (B, 10, d_model_seq)
        
        
        # 类别型特征做截断
        for i, max_val in enumerate(self.max_sparse):
            x_sparse[:, i].clamp_(0, max_val - 1)
        x_sparse = x_sparse.long()
        
        # 类别型特征做Embedding
        x_embed = []
        for i in range(self.n_sparse):
            embed = self.embed[i](x_sparse[:, i])
            embed = embed.unsqueeze(1)  # [B, 1, D]
            x_embed.append(embed)
        x_embed = torch.cat(x_embed, dim=1)  # [B, n_sparse, D]
        
        # 数值型特征做归一化
        x_numeric = torch.cat([x_dense, x_serial, x_nonserial], dim=1)
        x_numeric = (x_numeric - self.base_numeric) / (self.scale_numeric + 1e-6)
        x_numeric = torch.clamp(x_numeric, 0.0, 1.0)  # [B, n_numeric]
        # 数值型特征做Scalar2Vec
        x_s2v = []
        for i in range(x_numeric.size(1)):
            s2v = self.scalar2vec[i](x_numeric[:, i].unsqueeze(1))
            x_s2v.append(s2v)
        x_s2v = torch.stack(x_s2v, dim=1)  # [B, n_numeric, D]
        x_s2v = torch.cat([x_s2v, seq_pas_emb, seq_driver_emb], dim=1)

        x_ep = self.serial_embed(x_binary)
        x_dnn = x_s2v.view(x_s2v.size(0),-1)
        x_pp = x_embed.view(x_embed.size(0),-1)

        x_ep_out = self.epnet(x_dnn, x_ep)
        x_pp_out_od = self.ppnet_od(x_ep_out, x_pp)
        x_pp_out_o = self.ppnet_o(x_ep_out,x_pp)
        x_pp_out_d = self.ppnet_d(x_ep_out,x_pp)

        towers_inputs = [x_pp_out_od,x_pp_out_od,x_pp_out_o,x_pp_out_o,x_pp_out_d,x_pp_out_d]

        tower_outputs = []
        for i, tower_input in enumerate(towers_inputs):
            tower_outputs.append(self.towers[i](tower_input))

        tower_outputs = [
            x_binary * tower_outputs[0] + (1.0 - x_binary) * tower_outputs[1],
            x_binary * tower_outputs[2] + (1.0 - x_binary) * tower_outputs[3],
            x_binary * tower_outputs[4] + (1.0 - x_binary) * tower_outputs[5]
        ]
        tower_outputs = torch.cat(tower_outputs, dim=1)
        return tower_outputs
```

```PlainText
class PositionalSelfAttention(nn.Module):
    def __init__(self, d_model=20, nhead=5, dropout=0.1, max_len=100):
        super().__init__()
        self.d_model = d_model
        self.in_proj = nn.Linear(10, d_model)

        pe = torch.zeros(max_len, d_model)  # (max_len, d_model)
        pos = torch.arange(0, max_len).unsqueeze(1).float()  # (max_len, 1)
        div_term = torch.exp(torch.arange(0, d_model, 2).float() *
                             -(math.log(10000.0) / d_model))  # (d_model/2,)
        pe[:, 0::2] = torch.sin(pos * div_term)   # 偶数维
        pe[:, 1::2] = torch.cos(pos * div_term)   # 奇数维
        self.register_buffer('pe', pe)            

        encoder_layer = nn.TransformerEncoderLayer(
            d_model=d_model,
            nhead=nhead,
            dim_feedforward=d_model * 4,
            dropout=dropout,
            batch_first=True
        )
        self.encoder = nn.TransformerEncoder(encoder_layer, num_layers=3)

    def forward(self, x):               # x: (B, 10, 10)
        B, L, _ = x.shape
        x = self.in_proj(x)             # (B, 10, d_model)
        x = x + self.pe[:L, :]          # (B, 10, d_model)
        x = self.encoder(x)             # (B, 10, d_model)
        x = torch.sigmoid(x)            # 压到 [0,1]
        return x
```

#### 2. 三级网络 —— EP → PP → Tower

**==2.1 EPNet（连环派场景 gating）==**

```PlainText
x_ep_out = EPNet(x_dnn, x_ep)
```

		- 主干输入：x_dnn（连续+序列）

		- gate 输入：x_ep（20 维场景向量）

		- 内部：x_dnn 与 x_ep → LHUCBlock → 生成与 x_dnn 同维的 0–2 系数 → 逐位乘回 x_dnn。

		- **作用**：根据“连环派场景位”对全部连续/序列特征做一层粗粒度的缩放。

**==2.2 三路 PPNet（Personalized gating）==**

```PlainText
x_pp_out_od = PPNet_od(x_ep_out, x_pp)
x_pp_out_o  = PPNet_o (x_ep_out, x_pp)
x_pp_out_d  = PPNet_d (x_ep_out, x_pp)
```

		- 主干：EPNet 的输出 x_ep_out（已受连环派场景调控）

		- gate 输入：x_pp（全部离散类别特征 embedding 拉平，司乘个性化信息）

		- PPNet 内部：每层隐藏单元先乘一个 LHUC 系数（由 x_pp 生成），再做 Linear/BN/ReLU。

		- **作用**：用司乘用户画像对网络逐层、逐维做细粒度调控，实现同一条网络，不同司乘不同激活路径。

**实验分析：**

1. PLE 引入序列后部分劣化**：**od_auc pp， o_auc  pp，d_auc  pp。

2. PEPnet 引入序列后整体提升**：**od_auc 显著 pp，  o_auc 显著 pp，d_auc 显著 pp。

PEPnet 天然接受多任务/多向量形式做 gating，序列特征与数值特征在每一层LHUC处自适应加权，既能让序列信号主导高活跃用户，也能让静态特征主导新用户（冷启动稀疏用户序列），避免噪声淹没主任务。

3. PEPNet论文中与PLE和PLE-multi domian的对比来看，在多域多任务下也有比较高的提升。

## 六、消融实验

序列特征提供了什么额外的信息，是序列本身的作用，还是仅特征多了？做了两个消融实验

- **对照组：**PEPnet + 订单序列 做 Positional Self-Attention（即让模型显式看到整条序列的时序关系）。

1. **消融组 1：**把序列的每一维直接压成一条固定长度的向量（scalar2vec），保持特征时序，再送进 PEPnet（特征多了，模型隐式学到时序特征）。

| valid_d_auc <br> | 0.884 <br> | 0.866 <br> | -0.018 <br> |

2. **消融组 2：**把序列先算成五个统计量（均值、方差、min、max、中位数），再做 scalar2vec 送进 PEPnet（仅特征多了，模型无法看到时序关系）。

## 七、总结

| Highlight <br> | 1. 序列信息显式输入效果最好，有 10 pp AUC 提升——PEPnet + Positional Self-Attention 三任务平均 +9.6 pp，而 PLE 平均 –2.1 pp。 <br><br>2. PEPnet 的 LHUC 门控可以更好提供序列开关：高活用户让序列Positional Self-Attention 主导，冷启动用户自动降权序列，回退静态特征，实现零样本稀疏用户冷启动也不崩。 <br><br>3. 消融实验连续削弱时序作用，通过序列直接压成向量（–2.5 pp）或序列仅留统计值（–3.0 pp）——证明增量不仅仅因为序列特征变多，而是来自**逐位时序感知**。 <br><br> |
| --- | --- |
| Lowlight <br> | 1. PLE 的 Shared-MoE 结构对时序无接口：序列embedding直接输出后，专家网络无法有效分工，反而引入噪声，导致 d/od 任务暴跌 –6.3 pp/–2.4 pp。序列特征在冷启动场景下天然稀疏，若模型缺乏门控式机制，极易变成纯噪声，可考虑加入poso做门控单元。 <br><br>2. 当前PEPnet实验仅离线，缺乏线上 A/B 与长周期漂移测试；序列模型对数据分布shift更敏感，线上结果不确定。 <br><br>3. 待补充序列长度对模型效果的影响，10订单长度做缩短到5或拓展至20，50看效果。 <br><br> |
