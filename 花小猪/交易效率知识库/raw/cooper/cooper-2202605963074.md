# 一、需求背景

目前自营侧订单价值(司机拒单取消率)XGB模型线上效果较差，因此在新增部分司机历史行为特征的基础上用最新数据进行训练部署后进行实验，对照新旧模型间对最终业务指标的影响。

# 二、需求类型归纳

实验配置需求；

# 二、需求收益判断

模型离线预测AUC**+11.2pp**，预估自营商家CR**+0.15pp**；

# 三、需求说明和功能点

## 需求说明：

	本次需求涉及交易引擎，为可快速介入需求；

## 功能点:

目前已支持分单侧按版本号调用模型；

1. 工程方协助check新版本模型返回值是否正常；

2. 支持配置两组流量调用不同模型及阈值进行乘客随机分流实验；

# 四、需求通用属性

覆盖范围：

交易分单环节common recall模块；

# 五、效果评估方案

乘客随机分流实验；

自营竞争CR；应答后BC取消；司机拒单率；
