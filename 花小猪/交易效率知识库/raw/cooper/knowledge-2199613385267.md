## 一、背景

pbd端，HH三方的pk参与率过低。原因为：

1、HH三方的分单间隔为2s，API的分单间隔为0s

2、dd的运力举手则立刻发起pk

3、当前pk的间隔为1～2s

所以对于HH三方而言，分单速度比API慢，举手速度比DD慢，故参与pk的比例低

## 二、增加HH三方参与pk比例的方法

1、增加pk间隔，让HH三方的运力，有充足的时间来参与举手

2、匹配环节HOLD DD运力，减少DD举手即发起pk的频率

## 三、前期验证

2022.3.30 调整昆明、苏州pk间隔为4s，同时hold滴滴运力3s

昆明从播单到举手的比例**提升23.5pp**，大盘成交率和滴滴竞争成交率**无负向；**苏州鸿鹄规模很小，数据没有参考价值

2022.3.31 调整佛山pk间隔为4s，同时hold滴滴运力3s

佛山从播单到举手的比例**提升37.1pp**，大盘成交率和滴滴竞争成交率**无负向。**

**平台CR（大盘CR，DDO口径）** 展开源码

```PlainText
with ord_all as (
    select
        dt,
        order_id,
        product_id,
        passenger_id,
        driver_id,
        level_2_product,
        level_3_product,
        call_city as start_city_id,
        is_td_call_flag,
        is_td_answer_flag,
        is_td_finish_flag,
        is_td_cancel_flag,
        is_grab_before_cannel_flag,
        is_grab_after_pas_cancel_flag,
        is_grab_after_dri_cancel_flag,
        cancel_type,
        --1应答前乘客取消、2应答后乘客取消、3司机取消、4客服取消、5系统取消（快车排队场景，勾选“同时匹配拼车”，匹配成功会自动取消快车单场景） 0其他
        source_type,
        est_arrive_dur,
        est_arrive_dis,
        answer_dur,
        --应答时长
        row_number() over(
            partition by passenger_id,
            trace_order_id,
            is_td_answer_flag
            order by
                call_time desc
        ) as answer_time_rn_desc
    from
        (
            select
                *,
                if(
                    source_type <> 2,
                    order_id,
                    reassign_origin_order_id
                ) as trace_order_id -- 原单和其改派单的trace订单
            from
                decdm.dwd_gflt_ord_order_base_di -- 订单表
            where
                dt between '2022-04-15'
                and '${BIZ_DATE_LINE}'
                and call_time >= '2022-04-15 13:09:00'
        ) as a --改派单id
    where
        call_city in (3, 18, 26, 53, 58, 86, 157)
),
pbd as (
    select
        distinct order_id,
        dt,
        case
            when substr(cast(order_id as string), -1, 1) in ('8', '9')
            or (
                substr(cast(order_id as string), -2, 1) = '7'
                and substr(cast(order_id as string), -1, 1) in ('0', '1', '2', '3', '4')
            ) then '25%实验组'
            else '75%对照组'
        end exps_tag
    from
        dd_cdm.dwd_trip_trd_order_anycar_di
    where
        dt between '2022-04-15'
        and '${BIZ_DATE_LINE}'
        and call_time >= '2022-04-15 13:09:00'
        and channel_id in (1000001, 1010001) --来自PBD渠道
        and start_city_id in (3, 18, 26, 53, 58, 86, 157)
)
select
    exps_tag,
    count(
        distinct if(
            is_td_call_flag = 1
            and source_type <> 2,
            a.order_id,
            null
        )
    ) as call_cnt,
    count(
        distinct if(
            is_td_finish_flag = 1,
            a.order_id,
            null
        )
    ) as finish_cnt,
    count(
        distinct if(
            is_td_finish_flag = 1,
            a.order_id,
            null
        )
    ) / count(
        distinct if(
            is_td_call_flag = 1
            and source_type <> 2,
            a.order_id,
            null
        )
    ) cr
from
    ord_all as a
    join pbd on a.order_id = pbd.order_id  
group by
    exps_tag
order by
    exps_tag;
```
