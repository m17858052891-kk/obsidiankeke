**anycar表预估价缺失值占比** 展开源码

```PlainText
select
    count(
        case
            when est_price_amt > 0 then 1
            else null
        end
    ) / count(1)
from
    kflower_dw.dwd_kf_trd_order_anycar_di
where
    dt between date_sub('$[YYYY-MM-DD - 1D]',6) and '$[YYYY-MM-DD - 1D]'
    and is_td_call = 1
    and source_type <> 2
```
