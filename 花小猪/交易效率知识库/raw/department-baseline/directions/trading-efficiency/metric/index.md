## 目标口径

| 目标 | 目标指标 | 验收约束 | 使用项目 | 当前状态/备注 |
| --- | --- | --- | --- | --- |
| 双边交易效率 | ETP + 司机接驾时长 -1.5%；接驾距离绝对值 1650m | CR 不负 | PK 优化、匹配联合决策、交易价值统一 | P0，方向核心目标 |
| 乘客体验 | delta 乘客取消率 -1.2pp | 关注远接驾、长应答的极端值占比 | 乘客交易、体验留存归因 | P0，需结合应答后乘客取消率、单均应答时长、单均呼叫-计费时长、单均 ETP 观察 |
| 司机效率 | 降低司机接驾时间占用，提高送驾时长占比 | 不以牺牲乘客体验和履约质量换取单点司机效率 | 分单召回优化、匹配联合决策 | 过程目标，重点看司机视角时长 |
| PK 排序质量 | 履约率、举手率、PK 胜出率稳定或改善 | 不牺牲取消率、接驾距离和乘客等待体验 | PK 优化、交易价值统一 | 商家维度过程指标 |

## 指标定义

| 指标 | 定义 / 口径 | 关联指标 | 使用场景 | 注意事项 / 待确认项 |
| --- | --- | --- | --- | --- |
| 应答率 | `应答量 / 竞争呼叫`。应答量使用剔除改派后的应答订单数；竞争呼叫使用小猪端竞争呼叫订单数。 | 竞争呼叫、应答量、CR、完单 | 判断召回、分单、派单模式对交易链路承接能力的影响。 | 分子是否使用含改派应答量需与看板版本保持一致。 |
| 应答后乘客取消率 | `应答后乘客取消量 / 应答量（含改派）`。分子使用剔除改派后的应答后乘客取消订单数；分母使用含改派应答量。 | 应答率、应答后司机取消率、单均应答时长、平均接驾距离 | 评估乘客体验、远接驾/长等待、换车等策略对取消的影响。 | 当前是混合口径：分子不含改派，分母含改派；使用前需确认看板口径。 |
| 应答后司机取消率（含改派） | `应答后司机取消量（含改派） / 应答量（含改派）`。分子包含司机取消后触发改派的订单。 | 应答率、应答后乘客取消率、送驾时长占比、司机有责取消 | 评估派单质量、司机接单后稳定性、改派策略和交易生态风险。 | 指标名称明确为含改派；不含改派版本需单独命名。 |
| 平均接驾距离 | `预估接驾距离 / 应答量（含改派）`。预估接驾距离是司机应单时到乘客发单地的路面距离，单位建议统一为米或 km。 | 单均 ETP、单均接驾时长、应答后乘客取消率、接驾距离目标 | 评估 PK、分单召回、匹配联合决策是否降低乘客和司机侧接驾负担。 | 这是预估接驾距离，不是真实行驶距离。 |
| 单均接驾时长 | `修正后接驾时间 / 应答订单量`。修正后接驾时间按可控运力/非可控运力、连环派/非连环派分别计算后汇总。 | 单均 ETP、平均接驾距离、送驾时长占比、应答后取消率 | 衡量司机从应答到到达/取消前的接驾时间占用。 | 司机视角指标；单指标文件需维护完整修正逻辑。 |
| 送驾时长占比 | `送驾时间 / (接驾时间 + 送驾时间)`。送驾时间按开始计费到结束计费计算；接驾时间使用修正后接驾时间。 | 单均接驾时长、司机效率、完单、GMV | 衡量司机有效载客时间占比。 | 司机视角指标；接驾时间必须使用修正后口径。 |
| 单均应答时长 | `呼叫-首次应答时长 / 应答量（不含改派）`。呼叫-首次应答时长为同一次原始发单中第一次应答时间减第一次呼叫时间。 | 应答率、应答后乘客取消率、单均呼叫-计费时长 | 衡量乘客从发单到首次有司机应答的等待体验。 | 乘客视角指标；需过滤未应答换车子单。 |
| 单均呼叫-计费时长 | `呼叫-计费时长 / 完单量`。呼叫-计费时长为同一次原始发单中首次开始计费时间减第一次呼叫时间。 | 单均应答时长、单均 ETP、乘客取消率 | 衡量乘客从发单到司机开始计费的真实等待链路。 | 乘客视角指标；终点是开始计费，不是司机到达。 |
| 单均 ETP | `呼叫-司机到达上车点时长 / 到达样本量`。按同一次原始发单，从第一次呼叫时间到司机点击到达上车点时间计算。 | 平均接驾距离、单均接驾时长、单均呼叫-计费时长、双边交易效率目标 | 衡量乘客从发单到司机到达上车点的等待体验。 | 乘客视角指标；与单均呼叫-计费时长的差异在终点：ETP 到司机到达，呼叫-计费到开始计费。 |
| 履约率 | `履约数 / PK 获胜数`。履约定义：这一单在应答后没有司机取消或乘客取消。 | PK 胜出率、应答后取消率、平均接驾距离 | 评估 PK 获胜订单是否真正稳定履约。 | 商家维度指标；分母限定 PK 获胜订单。 |
| 举手率 | `举手数 / 播单数`。衡量播单后司机举手响应比例。 | only 举手率、both 举手率、应答率 | 评估商家播单后的司机响应意愿。 | 商家维度指标；举手数和播单数需保持同一去重粒度。 |
| only 举手率 | `只有一个司机举手的 PK 数 / 参与 PK 数`。only 举手指只有一个司机举手，直接获胜。 | 举手率、both 举手率、PK 胜出率 | 诊断仅一个司机响应时的 PK 结构和直接获胜占比。 | 商家维度指标；only 举手直接获胜。 |
| both 举手率 | `多于一个司机举手的 PK 数 / 参与 PK 数`。both 举手指有多于一个司机举手。 | 举手率、only 举手率、PK 胜出率 | 诊断多司机响应场景下的竞争充分度。 | 商家维度指标；与 only 举手率共同拆解参与 PK 流量。 |
| PK 胜出率 | `胜出订单数 / 参与 PK 数`。 | 绝对 PK 胜出率、履约率、举手率 | 评估参与 PK 后最终产生胜出订单的比例。 | 商家维度指标；分母为参与 PK 数。 |
| 绝对 PK 胜出率 | `both 举手胜出数 / both 举手参与 PK 数`。 | PK 胜出率、履约率、平均接驾距离 | 评估 both 举手竞争场景下的胜出比例。 | 商家维度指标；分母限定 both 举手参与 PK 数。 |

## 视角划分

| 视角 | 指标 | 说明 |
| --- | --- | --- |
| 司机视角 | 单均接驾时长、送驾时长占比 | 衡量司机时间占用和有效载客效率。 |
| 乘客视角 | 单均应答时长、单均呼叫-计费时长、单均 ETP | 衡量乘客从发单开始被占用的等待体验。 |
| 交易链路 | 应答率、应答后乘客取消率、应答后司机取消率（含改派）、履约率 | 衡量呼叫、应答、取消、履约的链路稳定性。 |
| 商家 / PK 响应 | 履约率、举手率、only 举手率、both 举手率、PK 胜出率、绝对 PK 胜出率 | 衡量商家维度下播单、举手、PK 胜出和履约效果。 |

## 必须拆分维度

| 维度 | 说明 |
| --- | --- |
| 日期 / 周 / 月 / 季度 | 适合看趋势和复盘。 |
| 城市 / 城市组 | 城市供需结构、接驾半径和司机取消行为差异明显。 |
| 是否工作日 / 周末 | 应答和接驾体验受高峰、平峰、周末影响明显。 |
| 运力类型 / 是否连环派 | 司机接驾时长和送驾时长占比必须区分可控运力、非可控运力、连环派、非连环派。 |
| 是否含改派 | 应答量、司机取消和乘客取消均存在含改派 / 不含改派版本，使用前必须确认口径。 |

## 常见误区

- 把预估接驾距离当作真实接驾行驶距离。
- 混用含改派和不含改派的应答量、取消量。
- 用基础接驾时长直接计算所有连环派接驾时间，忽略上一单送驾时间扣减。
- 把单均呼叫-计费时长与单均 ETP 混为同一指标；前者到开始计费，后者到司机点击到达上车点。
- 只看应答率或 PK 胜出率提升，不同步观察取消率、履约率、CR、完单和司机效率。
