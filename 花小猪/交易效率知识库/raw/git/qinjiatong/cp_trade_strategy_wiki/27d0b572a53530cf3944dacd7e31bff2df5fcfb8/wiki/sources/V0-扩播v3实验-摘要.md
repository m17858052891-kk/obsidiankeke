# 扩播V3 系列实验

## V3.1：模型过滤实验

### 背景
V2 策略（长单扩播+模型过滤）在部分城市有效，改为全国随机分流验证。

### 实验设计
- 全国乘客随机分流
- 对照组(90%)：长单10s扩播，无模型过滤
- 实验组1(5%)：长单30s扩播，无模型过滤
- 实验组2(5%)：长单5s扩播，**取消率模型过滤**（阈值0.3564）

### 实验结果

| 指标 | 变化 |
|------|------|
| 竞争AR | **-0.2pp** |
| 竞争CR | -0.12pp |
| 应答后B取消 | -1.4pp |
| 应答后C取消 | +0.5pp |

### 结论
模型过滤对应答率折损较大（AR -0.2pp），虽然降低了B取消，但整体效果负向。

## V3.2：无过滤提前扩播

### 背景
V3.1 证明模型过滤折损AR，因此直接将扩播时间提前到5s，不进行模型过滤。

### 实验设计
- 对照组(90%)：长单10s扩播，无模型过滤
- 实验组1(5%)：长单30s扩播，无模型过滤
- 实验组2(5%)：长单**5s**扩播，**无模型过滤**（阈值设为1.0）

### 实验结果

| 指标 | 变化 |
|------|------|
| 竞争AR | +0.2pp |
| 竞争CR | **-0.02pp（不显著）** |
| 应答后B取消 | -0.33pp |
| 应答后C取消 | +0.72pp |

### 结论
5s无过滤扩播：AR小幅正向，CR基本持平，但C取消明显上升。纯提前扩播的天花板到了。

---

## V3 系列的整体启示

1. **模型过滤在扩播场景效果有限**：过滤掉的连边虽然高取消风险，但也是应答率的来源，折损太大
2. **纯时间提前的边际递减**：10s→5s 的增量远不如 30s→10s
3. **为 V1 动播统一框架提供了必要性论证**：单纯在扩播方向迭代已到天花板
