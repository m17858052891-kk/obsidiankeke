# 扩播迭代V2 — 策略方案

## 核心思路

在 V1（提前扩播时间）的基础上，V2 引入**取消率模型过滤**：更早扩播 + 模型把关质量。

## 策略方案

1. 接入扩播场景乘客取消模型（深度模型，新容器部署）
2. 乘客扩播配置增加模型过滤阈值参数
3. 实验支持：订单分流 + 乘客分流 + 时间片轮转 + ≥3组参数对比
4. 模型兜底方案：
   - 访问不到模型 → 兜底公式：接驾距离/送驾距离，阈值 0.86
   - 访问不到配置 → 兜底阈值：0.39

## 模型信息

- **模型名称**：`hxz_pass_cancel_model_multi_scenario`
- **版本**：v2
- **场景标识**：scenario_feature = 2（固定值，表示扩播场景）

## 关键特征

| 特征 | 说明 | 备注 |
|------|------|------|
| left_lumian_distance | 连环派接驾第一段距离 | 扩播场景传入0 |
| dropoff_order_distance | 连环派接驾第二段距离 | - |
| total_lumian_dis | 连环派接驾总距离 | - |
| wait_time | 已等待时间 | - |
| scenario_feature | 场景特征 | 扩播=2 |
| level_type | 品类特征 | - |
| passenger_id | 乘客id | - |

## 工程配置

| 配置项 | 用途 |
|--------|------|
| AB扩播参数 | 扩播时机和距离 |
| AB模型过滤阈值 | 取消率过滤严格程度 |
| AB分流（自营） | 实验流量控制 |
| AB分流（宏鹄） | 宏鹄实验流量 |
