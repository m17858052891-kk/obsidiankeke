# 连环派策略

## 定义

连环派（Serial Dispatch）是指对**正在载客的司机**（载人车）进行订单派送。在当前订单即将结束时，提前为司机分配下一个订单，减少司机空驶时间。

## 距离计算

连环派的"接驾距离"由两段组成：
```
连环派接驾总距离 = 第一段距离(当前目的地到新订单起点) + 第二段距离(新订单起点到乘客)
```

对应参数：
- `left_lumian_distance`：第一段距离
- `dropoff_order_distance`：第二段距离
- `total_lumian_dis`：总距离
- `timeFilterDistanceLimitAC`：两段和距离限制

## 与播单半径的关系

在 V1.0 动播策略中：
- **空车司机**：直接用 BaseRadius 作为召回距离
- **连环派司机**：
  - 若 BaseRadius < 3000m → 两段和距离也限制为 BaseRadius
  - 若 BaseRadius ≥ 3000m → 两段和距离走正常配置（不受缩播影响）

## 取消率模型

连环派场景有独立的取消率模型需求：
- 连环派 XGBoost AUC = 0.6962（高于扩播场景的 0.6523）
- 多场景建模时，连环派未从 PPNet/PLE 中受益
- 可能原因：连环派特征模式与普通场景差异大，XGBoost 已能较好捕捉
