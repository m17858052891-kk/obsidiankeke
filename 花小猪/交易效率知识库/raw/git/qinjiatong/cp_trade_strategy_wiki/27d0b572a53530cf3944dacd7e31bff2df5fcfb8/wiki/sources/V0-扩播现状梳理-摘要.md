# 扩播现状梳理

## 核心信息

扩播距离由**两部分**取 min 构成：
```
最终播单距离 = min(订单播单距离, 司机听单距离)
```

## 订单扩播策略（乘客侧）

| 场景 | 触发条件 | 扩播结果 | 覆盖范围 |
|------|---------|---------|---------|
| 新乘客（完单数=0） | 10s未应答 | 扩至6000m | - |
| 长单（≥5km） | 10s未应答 | 扩至6000m | 全国 |
| 宏鹄实验 | 60s开始扩，105s达到 | 扩至6000m | 玉林 |
| ~~短单（<5km）~~ | ~~60s未应答~~ | ~~已下线~~ | - |

## 司机扩播策略（司机侧）

| 场景 | 触发条件 | 扩播结果 |
|------|---------|---------|
| 新司机（完单数=0） | 立即生效 | 听单范围6000m |
| 策略1（大部分城市） | 高下线概率60s / 低下线概率180s | 扩至5000m |
| 策略2（剩余城市） | 高下线概率60s / 低下线概率240s | 扩至4000m |
| 宏鹄实验 | 120s开始，240s达到 | 扩至6000m（玉林·麦田出行） |

## 关键洞察

- 司机侧用**下线概率模型**预测司机是否即将下线，对高下线风险司机提前扩大听单范围
- 订单侧和司机侧独立扩播，取两者 min，确保双向都在可接受范围内
- 宏鹄商家的扩播策略比自营更保守（更晚开始、更慢扩展）
