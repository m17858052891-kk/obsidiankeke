# V1.0 — 实验与参数配置

## 核心实验结论

**人均完单显著 +0.42%，自营竞争端内CR显著 +0.18pp。**

| 指标 | 实验组 | 对照组 | 变化 |
|------|--------|--------|------|
| 人均呼单 | 1.5887 | 1.5886 | 0.0%（无差异） |
| 人均完单 | 0.6699 | 0.6671 | **+0.42%（显著）** |
| 自营竞争端内CR | 42.17% | 41.99% | **+0.18pp（显著）** |
| 接驾距离 | 1672.9m | 1691.1m | **-1.07%** |
| 应答后C取消 | 11.9% | 12.06% | **-0.16pp** |

## 实验设计

- **方式**：PID随机分流
- **周期**：2024-04-02, 04-08, 04-09, 04-11, 04-12（5个工作日）
- **选城口径**：自营运力完单份额 ≥40% + 端内CR ≥70%
- **核心指标**：人均完单、自营竞争CR
- **过程指标**：接驾距离、应答后C取消

## 动播参数配置

基于空跑数据确定的正式参数：

| 参数 | 值 | 含义 |
|------|-----|------|
| N | 3.0 | 空闲运力数阈值 |
| S | 8.0 | 需供比阈值 |
| A1 | 1.0 | 应答率阈值（高） |
| A2 | 1.2 | 应答率阈值（低） |
| R1 | 1909m | 最小初始半径 |
| R2 | 2502m | 中间初始半径 |
| R3 | 2754m | 较大初始半径 |

## 早期实验配置（2023.09）

- 实验城市：东莞、绵阳、长沙、株洲、湘潭、呼和浩特、齐齐哈尔、昆明
- 流量：10%，司机随机分流
- 参数：需供比 ≥1.2 → 初始半径 2.5km
- 扩播配置：
  - 自营：90s开始扩，每秒10m，最大5000m
  - 宏鹄：90s开始扩，每秒10m，最大3000m

## 空跑数据观察

不同城市供需比和计算出的初始半径：

| 城市 | 需供比 | 计算半径 |
|------|--------|---------|
| 林芝 | 2 | 2178m |
| 呼伦贝尔 | 3 | 1936m |
| 绵阳 | 4 | 2257m |
| 舟山/营口 | 5 | ~2028m |
| 厦门 | 6 | 2023m |
| 唐山 | 7 | 2259m |
| 遵义 | 9.3 | 1614m |
| 儋州 | 10 | 1920m |
| 玉溪 | 13.5 | 1278m |
| 保山 | 14 | 1413m |

**规律**：需供比越高（供需越紧张），理论半径越小？实际不完全单调，可能还受城市路网影响。

## 关键洞察

1. 完单提升来源：缩播→接驾距离缩短→C取消降低→转化率上升
2. 呼单量不变说明策略不影响需求侧，纯粹优化供给匹配
3. 选城条件限制了实验在高供需城市进行，确保缩播有意义
