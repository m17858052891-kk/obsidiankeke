# 策略梳理

**V2.1相比V2.0迭代的最重要收益是收拢了apollo配置，提高了可维护性。**

**在具体策略层面，完善了参数配置，调整了阈值参数。**

1、非连环派新增接驾时间（eta）参数(包括召回限制和模型生效限制)，具体召回时取ETA&召回半径的交集；

原来只有距离（eda）过滤

2、连环派新增模型不生效过滤

原来是所有都需要模型过滤，现在改成eta和eda低于某个阈值（已经较近的）就不需要走模型过滤了

3、连环派司乘取消率模型和非连环派的合到一起了

访问同一个模型

- **所以相比V2.0，V2.1新策略 对连环派的过滤放松了、对非连环派的过滤更紧了。**

	- 组b相比组a，对于GS和TP的非连环派过滤更松（偏置项更小）
