
# PK深度模型v1.2离线评估

# 零、背景 

在 [PK可解释模型结构升级离线评估](https://cooper.didichuxing.com/knowledge/2199610335356/2206536768826) 上线实验后，各组单均接驾距离均上涨，分析原因是对照组LR将距离的权重\*2，导致对照组接驾距离小 [PK模型结构升级-实验评估](https://cooper.didichuxing.com/knowledge/2199610335356/2207211037501)

因此，通过相同的方式将新模型的距离/2，进行模型离线训练和实验。

# 二、模型效果

单独看司机或乘客履约，**距离权重调整前后结论不变**：Wide&Deep比两个或一个LR都更优；但整体看司乘履约，Wide&Deep打分加权不如一个LR。

**且调整距离权重前后，整体司乘履约 Wide&Deep与一个LR的差距减小。**

新旧模型建模空间不同，且都在各自建模空间下评估更优，离线难以比较，而线上能否表现更优，关键在于加权方式的效果。
