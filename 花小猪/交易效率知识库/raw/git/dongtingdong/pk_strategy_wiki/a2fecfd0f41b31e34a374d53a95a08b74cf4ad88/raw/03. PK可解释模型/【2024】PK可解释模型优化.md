# 背景

PK可解释模型V9已在全国取得正向收益，仅剩太原、沈阳两城未正向。当前模型存在的问题包括：

- 乘客侧：V9剩余负向两城乘客取消率增加，但接驾距离已经下降

	- 乘客取消可能受除接驾距离以外的其他因素影响，例如乘客对商家的偏好、对距离/价格的敏感度等

- 司机侧：未制约部分边界情况，包括司机换ID洗白（14d特征窗口）、司机引发的客服关单（无相应特征）等问题

	- 分析不同特征窗口对举手司机的覆盖率，14d能覆盖98.2%，28d能覆盖99.8%

# 模型优化

模型优化的方向为进一步降低应答后的乘客取消率，兼顾约束司机行为的平台导向

- 样本差异化加权

	- 完单：乘客取消：司机取消/拒单 = 1：1.5：0.5

- 距离权重扩大

	- 司机接驾距离的权重扩大到训练得到权重的1.5倍

- 特征优化

	- 乘客侧特征：与商家id交叉乘客X自营/三方取消率的两个特征，使其发挥线上区分度

	- 司机侧特征：建设司机28d被客服关单率的特征，同时追溯近14d的沉默司机在近28d的拒单率和取消率

# 特征重要性

特征重要性相对于V9的主要变化包括：

- 司机接驾距离权重的系数相对于V9有所下降

- 单公里价格、司机完单数的特征重要性上升，司机拒单率的特征重要性下降，更贴近于乘客视角

- 乘客X自营/三方取消率的特征重要性较高，推测在线上能有一定的区分度
