# 1、背景

[【LR25010】PK动态时间窗口策略V1](https://cooper.didichuxing.com/knowledge/2199610335356/2204562271351)将乘客取消率作为提前结束PK窗口的条件，全国统一阈值进行决策，取得了相对旧策略的成交率收益。

由于不同城市的履约表现存在差异，全国统一阈值必然不是最优解。如果能分城市设置阈值，则能够通过优化每个城市的成交率，取得更大收益。

# 2、阈值逻辑

# 3、工程开发

当前动态窗口的阈值配置已经收敛在实验平台，具体配置的实验层和实验如下。

> 实验层：[运筹可视化平台：动态获胜参数配置](https://yunchou.intra.xiaojukeji.com/experimentManage?layerId=276)

> 实验：[运筹可视化平台：动态PK窗口各功能阈值配置](https://yunchou.intra.xiaojukeji.com/experimentManage/2648)

基于以上配置方法，如果要实现分城市配置阈值，需要在实验层中给每个城市单独创建条件，例如：city=1、city=2等。

因此，需要工程开发可兼容统一阈值和分城市阈值的配置方法。考虑以引入一个参数threshold_config，用来表示分城市阈值列表。

例如：选择全国统一阈值，可表示为{0:0.9}；选择分城市配置阈值，可表示为{0:0.9, 1:0.88, 2:0.91}，其中key=0作用于未设置阈值的城市。
