# 源文档摘要：PK 动态窗口策略

> 覆盖 `raw/02. PK动态窗口策略/` 下 21 个文件（含 2 个废弃版本）

## 全局概览：[[wiki/entities/PK窗口.md|PK 窗口]]版本演进

| 版本 | 类型 | 窗口范围 | 决策依据 | CR 增量 vs 前版 |
|---|---|---|---|---|
| V1 静态 | 固定 | 4s | — | 基线 |
| V2 动态 V0 | 阈值 | 0-4s | Top1 概率（最短 ETP）| ==+0.20pp== |
| V3 动态 V1 | 阈值 | 0-8s | 乘客取消概率 | ==+0.12pp== |
| V4 RL | 强化学习 | 0-4s | Q-value 停/续 | ==+0.08pp== |

> [!warning] 关键发现
> 2026 年初静态窗口实验表明：==2s 窗口 CR 显著高于 4s 窗口 0.11pp==，3s 与 4s 无显著差异。更短窗口的预答前取消率优势超过了匹配质量损失。

## V0 策略详情

### 收益路径

```
PK 分 -4.55 → 答后取消率 +0.035pp（损失）
应答时长 -2.87s → 答前取消率 -0.20pp（收益）
→ 综合 CR > +0.1pp
```

- ==~70% 订单为独举手订单==（仅 1 个司机举手）
- ==~80% 胜者为第一个举手的司机==

### 模型：Top1 = 4s 内接驾时长最短的司机

- V1 模型 PID 实验（2023-11-16）：阈值 0.95 → CR ==+0.16pp==
- V2 模型时间片实验（2024-01-05）：CR ==+0.17pp==，应答时长 ==-3.08%==

### 放量计划

1/23 全国 30% → 1/25 60% → 1/29 90%（保留 10% 用于训练和长期对照）

### 线上分析（2024-09）

| 触发类型 | 占比 | 说明 |
|---|---|---|
| Top1 独举手 → 提前结束 | 24.73% | 94.85% 在 0s 即提前胜出 |
| 非 Top1 独举手 → 4s 正常胜出 | 24.94% | |
| 非 Top1 多举手 → 4s 正常胜出 | 44.94% | |
| Top1 多举手 → 提前结束 | 5.39% | |

## V1 策略详情

### 核心思路：最优停止问题

秘书问题模拟结果：
- 最大 8s，1-10 司机：平均 6.03s，94.1% 找到最优
- +80% 独举手检测：平均 4.19s，87.6% 找到最优
- 最大 4s，1-5 司机：平均 2.10s，87.9% 找到最优

### 多任务模型（V1 核心）

| 目标 | AUC | 说明 |
|---|---|---|
| OD（司乘整体履约）| ==0.779== | 正样本 = 完单 |
| O（乘客履约）| ==0.768== | 正样本 = 乘客未取消 |
| D（司机履约）| ==0.855== | 正样本 = 司机未取消 |
| T（Top1 司机）| ==0.899== | 正样本 = 最优司机 |

模型架构：5×3 Expert（128→1024），POSO，10-gate softmax，165 特征。

### Only 举手概率模型

- XGB 模型，==AUC = 0.886==
- 最终阈值选择 ==0.98==（trigger rate 10.8%，precision 98.9%）

### PID 实验结果（2025-02-21，全国）

| 策略组 | PK 时间 | CR | 乘客取消 | 接驾距离 | 自营完单 | 宏鹄完单 |
|---|---|---|---|---|---|---|
| 空白 | 3.53s | 0.7414 | 0.1745 | 1734m | 基准 | 基准 |
| 线上 V0 | 2.57s | 0.7405 | 0.1778 | 1747m | +3.70% | -1.92% |
| 距离组 | 1.39s | 0.7365 | 0.1837 | 1801m | +5.32% | -5.64% |
| 司乘履约组 | 0.53s | 0.7345 | 0.1870 | 1873m | +18.17% | ==-21.62%== |
| 乘客履约组 | 0.24s | 0.7306 | 0.1918 | 1898m | +22.96% | ==-24.88%== |

> 策略越激进（PK 时间越短）→ 自营份额越高、宏鹄份额越低、CR 越低。

### 时间片实验：空白 vs 线上 V0（2025-03-18，10 城）

- 完单 +0.23%（P=0.052），CR +0.14pp（不显著）
- 自营完单 ==+2.01%==，宏鹄完单 ==-0.69%==

### 阈值配置

- 全国统一阈值 ==0.91==，trigger rate 32.4%，precision 94.4%
- 分城市阈值：范围 ==0.825-0.959==，目标 precision ~0.95

## RL 策略详情

### MDP 建模

| 要素 | 定义 |
|---|---|
| **状态** | s_t = (t, 公共特征, 胜者特征, 败者特征)，200+ 特征 |
| **动作** | {0=继续, 1=停止} |
| **奖励** | 非终态: -α·Δt + β·Δp; 终态: R₀ + R·完单 - α·Δt + β·Δp |

### 参数校准

| 参数 | 含义 | 值 | 推导 |
|---|---|---|---|
| R₀ | 基础奖励 | 5 | 保证终态奖励为正 |
| R | 完单奖励 | 15 | 完单 PK 分 0.65 vs 未完单 0.50 = 15pp 差异 |
| α | 等待惩罚 | 0.45 | 1s→+0.3pp 答前取消; 1pp PK 分→-0.6pp 答后取消 |
| β | 分数改善 | 0.5 | Δp 截断 30pp，缩放不超完单奖励 |

### 算法：DQN + 扩展 TD 目标

```
TD = r + γ^(t'-t) · max_a' Q(s', a'; θ⁻)
```

### 在线实验（2025-11-24，16 城）

| 指标 | 变化 | 显著性 |
|---|---|---|
| PK 窗口时间 | ==-1.61s==（2.87→1.25） | — |
| CR | +0.0008 | 不显著 |
| 自营完单 | ==-0.65%== | 显著 |
| 宏鹄完单 | ==+1.22%== | 显著 |
| API 完单 | ==-1.87%== | 显著 |

11/16 城 CR 正向。策略触发提前胜出比例：==73.2%==（对照 28.3%）。

### 策略迭代方向

- 区分不同取消类型的完单奖励
- 使用预倾斜 PK 分数或深度模型分
- 分城市参数校准
- PPO 算法替代 DQN
- 添加胜者-败者特征交互层

## 静态窗口回测（2026-01-30）

> 动态策略增量有限时，是否直接用更短的固定窗口？

| 对比 | CR 差异 | 关键发现 |
|---|---|---|
| 2s vs 4s | ==2s 高 0.11pp==（显著）| 2s 应答率 +0.41pp，答前取消 -0.40pp |
| 3s vs 4s | 无显著差异 | |

**结论**：更短的静态窗口（2-3s）在 CR 上可能优于 4s，因为答前取消率降低的收益超过了匹配质量损失。
