# PK 模型自动化更新机制

PK 模型自动化更新机制的目标是实现模型的**周级自动化迭代**，减少人工干预，确保模型始终使用最新数据训练。

## 自动化流水线

```
EVE 周级训练 → AUC 校验 → 5% 灰度发布 → AB 评估 → 自动全量
```

### 各阶段详情

| 阶段 | 说明 |
|---|---|
| **EVE 训练** | 在 EVE 平台上使用最近数据自动触发模型训练 |
| **AUC 校验** | 新模型 AUC 必须满足约束条件（不低于基线）|
| **灰度发布** | 5% 流量灰度，观察核心指标 |
| **AB 评估** | 使用周二全天数据评估，基于乘客维度分流 |
| **自动全量** | 平台完单数非负时自动推全 |

## 实验设计

- 实验平台：Apollo
- 流量分割：基于乘客维度
- 评估指标：平台完单数为核心，兼顾 CR、取消率等
- 决策规则：完单数非负 → 自动推全；否则回退
