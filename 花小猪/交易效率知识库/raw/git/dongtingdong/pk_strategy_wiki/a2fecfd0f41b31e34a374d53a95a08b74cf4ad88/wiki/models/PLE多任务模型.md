# PLE 多任务模型

PLE（Progressive Layered Extraction）多任务模型是 [[wiki/entities/PK窗口.md|PK 动态窗口]] V1 策略的核心预测模型，通过联合预测司乘履约、乘客履约、司机履约和 Top1 司机四个任务，为窗口缩短/延长决策提供概率依据。

## 模型概况

| 属性 | 值 |
|---|---|
| **架构** | PLE + POSO + Scalar2Vec + DCN |
| **预测目标** | 4 个任务联合预测 |
| **特征数** | ==165== 个 |
| **状态** | 动态窗口 V1 扩量失败，模型未独立上线 |

## 多任务预测目标

| 任务 | 正样本定义 | [[wiki/concepts/AUC.md\|AUC]] | 用途 |
|---|---|---|---|
| **OD**（司乘整体履约） | 完单 | ==0.779== | PK 窗口缩短判断 |
| **O**（乘客履约） | 乘客未取消 | ==0.768== | PK 窗口延长判断 |
| **D**（司机履约） | 司机未取消 | ==0.855== | 辅助决策 |
| **T**（Top1 司机） | 接驾距离最短 | ==0.899== | 提前结束判断 |

### 标签定义

| 样本类型 | OD | O | D | T |
|---|---|---|---|---|
| 完单 | 1 | 1 | 1 | 0/1 |
| 乘客取消 | 0 | 0 | 1 | 0/1 |
| 司机取消 | 0 | 1 | 0 | 0/1 |
| 司机未胜出 | 0 | 0 | 0 | 0/1 |

## 特征空间

| 特征类型 | 代表性特征 | 数量 |
|---|---|---|
| 传入特征 | 商家 id、城市 id、接驾距离、是否连环派 | 27 |
| 供需特征 | 起点格子 5 分钟内空车司机数等 | 28 |
| 乘客历史 | 乘客近 28 天三方/自营取消率 | 16 |
| 司机实时 | 司机当天截止当前完单数 | 24 |
| 司机历史 | 司机近 28 天连环派/非连环派完单数 | 70 |

## 模型结构与参数

| 模块 | 参数 | 值 |
|---|---|---|
| Embedding & [[wiki/models/组件技术.md#Scalar2Vec\|Scalar2Vec]] | d_embed | 20 |
| Expert | 数量 × 组 | ==5×3==（连环派 / 非连环派 / 共享） |
| Expert | 隐藏层 | [128] → ReLU → 1024 → ReLU |
| [[wiki/models/组件技术.md#POSO\|POSO]] | 输出维度 | 1024，Sigmoid |
| Gate | 输出维度 | 10，Softmax |
| Tower | 输出维度 | 1，Sigmoid |
| 训练 | loss / optimizer / lr / batch | BCE / Adam / 0.01 / 1024 |

### PLE 分场景设计

- [[wiki/concepts/连环派.md|连环派]]/非连环派场景下[[wiki/concepts/接驾距离.md|接驾距离]]语义不同
- `is_serial` 特征决定最终输出分支
- 不同模型间通过保序回归进行校准
