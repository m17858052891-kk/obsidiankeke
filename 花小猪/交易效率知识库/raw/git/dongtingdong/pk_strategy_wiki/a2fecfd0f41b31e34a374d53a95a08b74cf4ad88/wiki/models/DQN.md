# DQN 深度 Q 网络

DQN（Deep Q-Network）是 [[wiki/entities/PK窗口.md|PK 动态窗口]] RL 策略的核心算法，将窗口控制建模为马尔可夫决策过程（MDP），学习在每个举手时刻"继续等待"还是"立即结束"的最优策略。当前在线 5% 流量实验中，每日自动策略迭代。

## 模型概况

| 属性 | 值 |
|---|---|
| **算法** | DQN + 扩展 TD 目标 |
| **建模框架** | MDP（马尔可夫决策过程） |
| **特征维度** | 200+ 特征（通用 + 胜者 + 败者三组） |
| **动作空间** | {继续等待, 结束窗口} |
| **状态** | ==在线 5% 流量实验，每日自动策略迭代== |

## MDP 定义

| 要素 | 设计 |
|---|---|
| **状态** | $s_t = (t, [f_c], [f_w], [f_l])$ — PK 时刻 + 通用特征 + 胜者特征 + 败者特征 |
| **动作** | $a_t \in \{0, 1\}$ — 0=继续等待，1=结束窗口 |
| **奖励** | 非终态: $-\alpha \Delta t + \beta \Delta p$；终态: $R_0 + R \cdot 完单 - \alpha \Delta t + \beta \Delta p$ |

### 奖励参数

| 参数 | 含义 | 值 | 推导 |
|---|---|---|---|
| $R_0$ | 基础奖励 | 5 | 保证终态奖励为正 |
| $R$ | 完单奖励 | 15 | 完单 PK 分 0.65 vs 未完单 0.50 = 15pp 差异 |
| $\alpha$ | 等待时间惩罚 | 0.45 | 1s→+0.3pp 答前取消；1pp PK 分→-0.6pp 答后取消 |
| $\beta$ | PK 分改善调节 | 0.5 | $\Delta p$ 截断 30pp，缩放不超完单奖励 |

## 模型结构

```
   通用特征         胜者特征         败者特征
      │                │                │
   [DNN]           [DNN]            [DNN]
      │                │                │
      └───────┬────────┘                │
              └───────────┬─────────────┘
                       [Concat]
                          │
                    ┌─────┴─────┐
                    │ Q(s, a=0) │  ← 继续等待的价值
                    │ Q(s, a=1) │  ← 结束窗口的价值
                    └───────────┘
```

三个维度的特征分别经过单独网络，拼接后输出 Q 值对，两个元素分别代表继续和结束 PK 窗口的动作价值。

## 算法细节

### TD 目标（扩展版）

由于 PK 不是固定时间步长决策，将衰减因子 $\gamma$ 变换为 $\gamma^{t'-t}$：

$$\text{TD Target} = r + \gamma^{t'-t} \max_{a'} Q(s', a'; \theta^-)$$

### 训练机制

- **Off-policy 学习** + 经验回放
- **$\epsilon$-贪婪探索**
- **双网络**：主网络 $\theta$ + 目标网络 $\theta^-$
- **损失函数**：MSE
- **线上批次更新**：每天收集前一天交互数据，更新模型后重新部署

### 策略迭代

```
T0：收集线上主策略（动态窗口 V0）的数据 → 训练 T0 策略
T1：收集 T0 策略的交互数据 → 训练 T1 策略
...
Tn：收集 T(n-1) 策略的交互数据 → 训练 Tn 策略
```

每天 EVE 平台自动调度。

## 特征空间

| 特征维度 | 特征子维度 | 示例特征 |
|---|---|---|
| **通用特征** | PK 窗口信息 | 当前 PK 时刻 |
| | 订单信息 | 城市、订单里程、起终点 |
| | 供需情况 | 格子近 X 分钟发单数、空车司机数 |
| | 乘客历史 | 近 X 天应答后取消数 |
| **胜者特征** | PK 画像 | PK 打分、举手时的 PK 时刻 |
| | 司乘组合 | 派单模式、接驾距离、预估价 |
| | 司机历史 | 近 X 天应答数、完单数 |
| **败者特征** | （同上） | 与胜者特征平行 |

## 在线实验结果

### T8-T14 策略（第 2 周）

| 指标 | 线上策略 | DQN 策略 | 变化 |
|---|---|---|---|
| PK 窗口长度 | 2.64s | 1.35s | ==-1.30s== |
| 成交率 | 0.7823 | 0.7824 | +0.01pp |
| 应答率 | 0.9042 | 0.9053 | +0.11pp |
| 应答前乘客取消 | 8.62% | 8.49% | -0.12pp |
| 应答后乘客取消 | 12.42% | 12.55% | +0.13pp |
| 应答后司机取消（含改派） | 6.87% | 6.83% | -0.03pp |

**策略触发提前胜出比例**：==73.2%==（对照 28.3%）

> [!warning] 核心 trade-off
> DQN 大幅缩短 PK 窗口（-1.3s），降低了答前取消（-0.12pp），但略微增加了答后取消（+0.13pp），综合 CR 微正。

## 演进方向

| 维度 | 优化点 | 方案 |
|---|---|---|
| 概念定义 | 完单奖励差异化 | 四类未完单赋予不同权重 |
| 概念定义 | 完单率预测优化 | 使用倾斜前 PK 打分或深度模型打分 |
| 参数测算 | 分城市测算 | 封装进自动迭代链路 |
| 算法实现 | 衰减因子设置 | 理清 $\gamma$ 和 $\alpha$ 的联合作用 |
| 算法对比 | **PPO 替代 DQN** | 验证基于策略的方法是否更优 |
| 模型结构 | 网络结构优化 | 引入胜者-败者特征交互层 |
| 策略迭代 | 探索率衰减 | 设计自动衰减函数 |
