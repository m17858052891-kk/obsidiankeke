# 倾斜策略

倾斜策略是 PK 打分中在模型计算之外叠加的分数调整机制。通过对特定商家或司机群体施加正向或负向倾斜，实现业务层面的目标（如扶持新司机、惩罚差体验司机、调节商家间竞争关系等）。

> **PK 打分 = [[wiki/entities/PK模型.md|模型计算]] + 打分倾斜**

## CP（商家）维度倾斜

| 倾斜类型 | 说明 | 配置 |
|---|---|---|
| 默认 CP 倾斜 | Apollo 配置，可设定商家和倾斜力度 | `kflower_grab_order_cp_tilt_conf` |
| 挑单倾斜 | 公式计算，限定负向倾斜 | `kflower_cp_pack_order_conf` |
| 滴滴倾斜 | 根据 TiltMode，UFS 和 Apollo 都可配置 | — |

## 司机维度倾斜

| 倾斜类型 | 说明 | 配置 |
|---|---|---|
| 全职司机倾斜 | 权益/先锋/星辰三档，锚定 IPH 水位周级自动计算 | PBD/联盟端 + 小猪端分别配置 |
| 新司机倾斜 | 在全职司机倾斜力度上随时间递减 | `allmatch_pk_new_driver_tilt` |
| 差体验司机负向倾斜 | 最终判断，命中时==所有正向倾斜不生效==（包括 CP 倾斜）| `allmatch_pk_tilt_govern_conf` |

> [!warning] 优先级规则
> - 司机命中多个全职倾斜时，只生效倾斜力度最大的
> - 差体验司机负向倾斜会**覆盖所有正向倾斜**，是最终兜底机制

## 全职司机倾斜计算

- 锚定 wyc（网约车）的 IPH（每小时收入）水位
- 每周自动计算产出倾斜分数
- 倾斜名单也支持手动配置
