## A. [[wiki/entities/毛利因子.md\|毛利因子]]（7 个文件）

### 机制设计

> 1pp 毛利率差 → [[wiki/concepts/接驾距离.md\|接驾距离]]特征 ==+100m==（因距离权重 2 倍，等效 +50m 缩放距离）

- 调整范围：±1000m
- 100m 接驾距离 ≈ +0.7pp 司乘取消率
- 冷启动：新商家使用其 SaaS 级整体毛利率
- 宏鹄/灵犀/鲲鹏享受 ==+2pp== 调整（等效少惩罚 200m）

### 各商家毛利率

| 商家 | 毛利率 |
|---|---|
| API 商家 | ==6.03%== |

| 鲲鹏托管 | -2.04% |
| 灵犀托管 | ==-2.39%== |

### 扩量计划与受阻

**77 个"双正"城市**（完单和毛利率均为正）被选为一期扩量目标，覆盖 42% 全国完单。

扩量时间线：
- 2025-04-14：通知商家
- 2025-04-28：30%
- 2025-05-06：60%
- 2025-05-09：90%

> [!warning] 扩量失败
> 经规则评审通过，但遭==商家阻挠==，扩量失败。商家（尤其宏鹄体系）对毛利因子改变竞争格局存在顾虑。

### 实验复盘：事故与教训

1. **宏鹄分系统未区分**：应将宏鹄拆分为直营/灵犀托管/鲲鹏托管，实际按整体调整
2. **EVE 特征类型错配**：毛利特征配置为 int 类型，离线正常但线上截断为 0
3. **教训**：P0 — 概念模糊时验证数据特征；P0 — 提前核查实验结果；P1 — 严格按评审方案做离线模拟

## B. [[wiki/entities/治理因子.md\|司机长时取消因子]]（5 个文件）

### 数据发现

累积司机取消时长分布（改派链前向完单率）：

| 累积取消时长 | 占比 | 前向完单率 |
|---|---|---|
| [0, 5s] | 2.36% | 59.76% |
| (5s, 10s] | 26.39% | 60.89% |
| (1m, 1m20s] | 3.18% | 63.99% |
| (4m, 6m] | 2.00% | 57.12% |
| (6m, 10m] | 1.74% | 51.24% |
| **(10m, +)** | **1.94%** | **==23.21%==** |

> 取消时长超 10 分钟的订单，前向完单率仅 23%。

### 一期权重方案

用 LR 拟合前向完单率：`p_i = 1/[1+exp(-(w*t+b))]`

| 取消时长 | 完单率 | 加权系数 |
|---|---|---|
| 0.5min | 0.654 | 1.000 |
| 4min | 0.584 | 1.120 |
| 8min | 0.500 | 1.308 |
| 12min | 0.416 | 1.573 |
| 16min | 0.336 | 1.945 |
| >16min | <0.336 | ==2.000（封顶）== |

### 一期实验结果（2025-04-09）

| 指标 | 变化 | 显著性 |
|---|---|---|
| 完单 | -0.20% | 不显著 |
| 自营 | +0.96% | 显著 |
| 宏鹄 | -1.82% | 显著 |
| API | +3.82% | 显著 |
| 长时取消司机中标占比 | ==-0.90pp== | — |

> 发现问题：坏司机变得更坏，好司机面对更松竞争环境后行为也略有恶化。

### 二期权重方案（更陡峭曲线，4 分钟起步）

|---|---|
| <4min | 1.000 |
| 6min | 1.409 |

### 三期实验结果（2025-06-12，最新）

| 指标 | 变化 | 显著性 |
|---|---|---|
| 全平台指标 | 无显著变化 | — |
| 4 分钟以上取消占比 | ==-0.21pp==（12.98%→12.77%）| — |

> [!warning] 策略天花板
> 三期结论：==策略优化天花板较低==。司机当前取消行为与历史长时取消的相关性不够高（14d 取消数 vs 次日取消：r = 0.1586），限制了因子的效果。
