## 1. [[wiki/entities/PK可解释模型.md\|模型版本全谱系]]（V1-V10）

| 版本 | 类型 | 关键变化 | 在线状态 |
|---|---|---|---|
| V1-XGB | XGB | 基线 | 仅对照组 |
| V2-XGB | XGB | 连环派/非连环派特征分离 | 对照组 |
| V3-LR | LR | 首次从 XGB 迁移到 LR | 未上线 |

| V9-LR | LR | 更新取消率定义，刷新权重 | 全国（除沈阳太原）|
| V10-LR | LR | 样本加权（完单:C取消:D取消:D拒单=1:1.5:0.5:0.5）; 距离权重 1.5x; 乘客×商家取消率交叉; 28d 兜底 | 全国 5% |

### 核心特征权重演进（driver_start_dis 接驾距离）

```
V3: -0.050 → V6: -0.361 → V7: -0.399 → V8: -0.800 → V9: -0.801 → V10: -0.692
```

距离权重在 V8 后显著提升，成为最强特征。

## 2. [[wiki/concepts/特征工程.md\|特征工程]]深度分析

### 时间窗口选择

| 窗口 | AUC |
|---|---|
| 1d | 0.7136 |
| 3d | 0.7295 |
| 7d | 0.7393 |
| **14d** | **0.7457** |
| 28d | 0.7498 |

结论：==14d 是最优权衡==（边际收益递减，但覆盖率 98.2%，28d 为 99.8%）。

### 数据差分

- 加入 14d diff 特征（拒单率差、取消率差）→ AUC ==+0.24pp==
- 差分特征捕捉"行为趋势"：近期变好/变差

### 数据离散化

- 接驾距离与完单率单调递减 → 不宜离散化（损失信息）
- 送驾距离呈倒 U 型（10-35km 完单率最高）→ 二值化 `is_medium_range` → AUC ==+0.14pp==
- 差分 + 离散化组合 → AUC ==+0.38pp==

### 司机特征重建

旧特征问题：散落 4 张 Hive 表、null vs 0 混淆、内置处理逻辑降低迭代灵活性。

新统一表 `kflower_strategy.pk_hxz_driver_feature`：
- 格式：`d_(non)serial_{refuse|answer|reassign|dri_cancel|pas_cancel|close|finish}_cnt_{x}d`
- 明确区分 null（无行为）vs 0（有行为但计数为零）

## 3. [[wiki/concepts/接驾距离.md\|接驾距离]]增加问题深度分析

V6 全国实验后接驾距离显著增加 ==+91m==，原因分析：

**近距离司机败北时的 PK 打分分解**：

| 因素 | 近距离司机（败者）| 远距离司机（胜者）| PK 分差 |
|---|---|---|---|
| 14d 完单数 | 50 | 126 | ==-0.295== |
| 14d 拒单率 | 11.2% | 3.1% | ==-0.158== |
| 14d 取消率 | 30.2% | 19.2% | ==-0.147== |
| 接驾距离 | 1340m | 1988m | ==+0.219== |

> 距离优势（+0.219）不足以克服履约劣势（-0.599）

**距离权重 2 倍模拟**：原始 1600m → 2 倍后 ==1448m==（减少 102m）

## 5. 子项目：[[wiki/concepts/半指派.md\|半指派]]模式区分

将司机特征从 2 维（连环派/非连环派）扩展为 4 维：

| | 连环派 | 非连环派 |
|---|---|---|
| **半指派** | 拒单率 / 取消率 / 完单数 | 同左 |
| **非半指派** | 拒单率 / 取消率 / 完单数 | 同左 |

新增工程字段：`dispatch_type`（1=抢单, 2=半指派, 3=全指派, 5=挑单）

## 6. 子项目：连环派乘客取消优化

- 同接驾距离下，连环派 C 取消率 >> 非连环派
- 绕路比 R = (AB+BC)/AC 越大，取消率越高
- 新增特征：`direct_distance`（AC 路面距离）、`detour_ratio`、`bac_angle`、`acb_angle`
- 分类：绝对顺路（R=1）/ 高顺路（R≤1.2）/ 低顺路（R>1.2）/ 不顺路

---

## 7. 子项目：司机判责分析

- 82.09% 司机无判责历史
- 判责比例与历史取消率单调递增：0%判责→0.139取消率，60-100%判责→0.468取消率
- 应用方式：建设判责数特征 / 优化取消特征组合权重 / 高判责司机负向倾斜

## 8. 结构升级方案：Wide&Deep

### 动机

LR 模型 AUC 比深度模型低 ==~3pp==

### 架构

| 模块 | 作用 | 影响排序？ |
|---|---|---|
| **Deep**（乘客画像 + 供需画像）| 捕捉非线性模式 | ❌ 不影响 |
| **Wide**（订单+司机+骑乘特征）| 可解释排序 | ✅ 影响 |
| **输出**（两个子 LR）| 乘客完单率 + 司机完单率 | — |
| **融合**（外部配置）| 线性融合：pas_weight + dri_weight | — |

### 深度模型 v1.1 → v1.2 实验与最终放量

v1.1 因距离权重不一致被叫停（LR 2 倍，Deep 未倍增）

v1.2（距离/2 输入等效 2 倍权重）实验结果（2026-04-07）：

旧摘要按 CR 增益把 0.8:0.2 组称为“最优”；最终 LR26-010 评审把完单/CR 作为约束、交易效率作为主要收益，选择并推全 0.9:0.1 组：

| 指标 | 最终 0.9:0.1 放量组 |
|---|---|
| 人均完单 | -0.16%（不显著） |
| CR | +0.03pp（不显著） |
| 乘客 ETP / 司机接驾时长 | **-1.64% / -2.41%** |
| C 取消 | **-0.16pp**（显著）|
| B 取消（含改派）| **+0.44pp**（显著）|
| 接驾距离 | **-60.32m**（显著）|
| 自营 / 宏鹄 / API 完单 | +1.27% / -1.08% / +0.51% |

放量节奏：2026-06-24 30% → 2026-06-26 80% → ==2026-07-03 100%==。详见 [[wiki/sources/09-LR26-010-DeepWide-V1.0.md]]。

> [!warning] 深度模型 vs LR 排序一致性
> SENet 模型实验表明：==89.6%== 的司乘对排序与 LR 一致。53% 订单仅 1 个司机（无需排序），47% 有多司机参与排序。
