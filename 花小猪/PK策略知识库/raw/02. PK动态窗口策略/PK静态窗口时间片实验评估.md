
# PK静态窗口时间片实验评估

# 1、实验背景

历次PK动态窗口策略迭代的实验结果表明：

- 动态窗口策略V0相对于固定4秒窗口的收益不大（CR+0.20pp）

- 动态窗口策略V1和强化学习方案相对于动态窗口策略V0的收益也不大（CR+0.12pp、CR+0.08pp）

因此，计划进行固定时间窗口之间的实验，看下只是单纯缩短窗口能否也有少量收益。

如果有，就撤下线上策略，改用效果最好的固定窗口。

# 2、实验方案

实验时间：2026-01-30～2026-02-12

- 时间片实验1（1小时轮转）

	- 城市：8,85,18,58,38,125,153,14,74,81,254

	- 对照组：固定2秒窗口

	- 实验组：固定4秒窗口

- 时间片实验2（1小时轮转）

	- 城市：26,25,13,16,19,6,24,29,21,17

	- 对照组：固定3秒窗口

	- 实验组：固定4秒窗口
