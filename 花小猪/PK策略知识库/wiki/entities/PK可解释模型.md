# PK 可解释模型

PK 可解释模型从 2024 年的 LR 权重透明化，演进到 2026 年的 V4 Deep&Wide：司机与司乘差异化特征仍保留线性权重，乘客和供需特征通过 Deep 模块形成画像。V4 已于 ==2026-07-03 全国推全==。

## 动机

XGBoost 模型虽然 [[花小猪/PK策略知识库/wiki/concepts/AUC.md|AUC]] 更高（0.7345），但商家无法理解：
- 为什么自己的司机 PK 胜率低？
- 改善哪些维度的运力指标能提高胜率？
- 接驾距离、取消率等因素各自的影响有多大？

LR 模型的权重直接对应每个特征的影响方向和力度，可以向商家提供清晰的优化指引。

## 模型定义

```
y = sigmoid(w1*x1 + w2*x2 + ... + wk*xk)
```

## 特征体系 → [[花小猪/PK策略知识库/wiki/concepts/特征工程.md]]

| 维度 | 核心特征 | 说明 |
|---|---|---|
| **订单** | [[花小猪/PK策略知识库/wiki/concepts/接驾距离.md|接驾距离]]（==权重 2 倍==）、单位距离价格、订单距离、等待时间 | 接驾距离是影响力最大的特征 |
| **司机** | 取消率、拒单数、完单数（近 14 天） | 按[[花小猪/PK策略知识库/wiki/concepts/连环派.md|连环派]]/非连环派场景隔离 |
| **乘客** | 自营应答后取消率、三方应答后取消率（近 28 天） | |
| **供需** | 近 5 分钟起点格子的发单数、空车司机数 | |

**特征处理**：
- 空值：均值填充
- 标准化：特征标准化
- 特征隔离：分场景（连环派/非连环派）的司机特征硬隔离

## 版本迭代

| 版本 | 代号 | 核心改进 |
|---|---|---|
| V0 → LR | 2024年终 | 从 XGB 到 LR；特征筛选；司乘取消率合并；接驾距离权重 2 倍 |
| V1 | LR25012 | 连环派接驾距离统一用 AB+BC；优化司机维度特征和空值填充逻辑 |
| V2 | LR25033 | 重建司机维度特征：区分"是否[[花小猪/PK策略知识库/wiki/concepts/半指派.md|半指派]] × 是否连环派"四种场景 |
| V3 | LR25050 | 建设连环派接驾特征（距离+夹角）；增加绕路比特征 |
| **V4 结构升级** | **LR26-010** | Deep&Wide 双任务；最终权重 0.9:0.1；约束完单/CR，优化 ETP 与接驾时长；==2026-07-03 推全== |
| **V5 范式重构** | **2026 Q2 方案** | ==**优化目标改为「约束 CR、最小化接驾距离」**==；模型升级为多域多专家 3 分类；LR 蒸馏深度模型 |

> [!note] V5 的范式转变
> V4 的打分公式仍是履约概率加权，但放量决策已将完单/CR 作为约束、将交易效率作为主要收益；V5 进一步把约束显式写入**打分公式**（拉格朗日松弛形式 PK 分 = λf − d）。
> 详见 [[花小猪/PK策略知识库/wiki/entities/约束履约率最小化接驾距离策略.md]]。

## 实验评估

> [!warning] 关键实验数据
> LR 模型相较 XGB 的实验结果：
> - 人均[[花小猪/PK策略知识库/wiki/concepts/履约率.md|完单]]：==-0.13%==
> - CR：==-0.4pp==
> - 司机取消：==-0.9pp==（主要来自改派）
> - 乘客取消：==+0.6pp==
> - 平均接驾距离：==+2.57%==
> - 宏鹄人均完单：==+10%==

模型在不同商家间的影响不均匀：对宏鹄等三方商家有利，对自营可能有轻微影响。

## 扩量进展

实验采用分期扩量策略：
- 一期 → 二期 → 三期，逐步覆盖更多城市
- 按 30% → 60% → 90% 流量递增

## 最新线上策略（V4 Deep&Wide）

- 最终融合：`0.9 × P(乘客履约) + 0.1 × P(司机履约)`
- 全国 PID：人均完单 -0.16%（不显著）、CR +0.03pp（不显著）、乘客 ETP -1.64%、司机接驾时长 -2.41%、接驾距离 -60.32m
- 风险：司机取消（含改派）+0.44pp；宏鹄人均完单 -1.08%
- 80% 放量复验：ETP -1.81%、司机接驾时长 -2.45%、完单/CR 不显著负
- 路线图：2026 Q3 OneTrans + 司乘序列特征；2026 Q4 乘客个性化
