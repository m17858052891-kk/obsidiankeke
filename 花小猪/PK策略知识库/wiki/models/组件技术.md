# 组件技术

以下技术作为模块化组件被整合到 PK 决策系统的主模型中，或在离线实验中被探索。它们不独立部署，而是嵌入 [[花小猪/PK策略知识库/wiki/models/PLE多任务模型.md|PLE]]、[[花小猪/PK策略知识库/wiki/models/Wide&Deep.md|Wide&Deep]] 等主模型架构中。

## Scalar2Vec

Dense 特征 Embedding 技术。

| 属性 | 值 |
|---|---|
| **作用** | 将连续型（dense）特征通过 DNN 映射到与稀疏特征对齐的 embedding 空间 |
| **[[花小猪/PK策略知识库/wiki/concepts/AUC.md\|AUC]] 增益** | ==+0.8pp== |
| **应用** | 集成在 PLE 多任务模型中（d_embed=20） |
| **对比** | AutoDis 收益甚微，Scalar2Vec 效果更优 |

**机制**：dense 特征过一层 DNN，拉齐 embedding 维度，使 dense 和 sparse 特征在同一空间中交互。

---

## AutoInt

Multi-Head Attention 特征交叉技术。

| 属性 | 值 |
|---|---|
| **作用** | 通过多头注意力机制（MHA）实现不同特征间的自动交叉 |
| **AUC 增益** | ==+2.8pp==（司乘履约模型迭代中） |
| **问题** | 参数多、训练慢、离线结果不稳定 |
| **状态** | ==已被排除==（在 PLE 模型优化中明确标注废弃："参数多训练慢，离线结果无提升且不稳定"） |

---

## POSO

Personalized Cold-Start Optimization，基于模型的[[花小猪/PK策略知识库/wiki/entities/冷启动系统.md|冷启动]]优化。

| 属性 | 值 |
|---|---|
| **作用** | 基于司机近 14 天完单量的个性化编码，优化新司机预测 |
| **AUC 增益** | ==+0.08pp== |
| **应用** | 集成在 PLE 多任务模型的 Expert 层后 |

**机制**：
1. 将司机近 14 天完单量作为个性化编码输入
2. 过一层 DNN（d_expert_out=1024, sigmoid）
3. 与 Expert 网络输出进行 element-wise 乘法
4. 不同完单量的司机产生不同的个性化编码，模型效果个性化

---

## ESSM / ESCM

全样本空间建模，解决司机/乘客取消概率的训练域-测试域偏移。

| 属性 | 值 |
|---|---|
| **作用** | 解决司机取消在前导致乘客取消被"遮盖"的样本选择偏差 |
| **AUC 增益** | 未报告 |
| **状态** | 仅离线探索 |

**条件概率建模**：

| 真实取消方 | 乘客履约概率 | 司机履约概率 |
|---|---|---|
| 司机取消在前 | P(司机履约) × P(乘客履约 \| 司机履约) | P(司机履约) |
| 乘客取消在前 | P(乘客履约) | P(乘客履约) × P(司机履约 \| 乘客履约) |
| 司乘皆履约 | P(乘客履约) | P(司机履约) |

核心动机：司机取消时间提前会导致乘客取消减少，但乘客意愿可能也在变化，全样本空间建模可以充分利用已有数据。

## 知识蒸馏（Teacher-Student + PID）

利用乘客 ID（PID）特征进行知识蒸馏。

| 属性 | 值 |
|---|---|
| **作用** | 利用 PID 特征的丰富信息提升乘客[[花小猪/PK策略知识库/wiki/concepts/履约率.md|履约]]预测 |
| **机制** | Teacher 模型含 PID → Student 模型不含 PID，蒸馏学习 |
| **AUC 增益** | ==+0.2pp==（Teacher 模型，28 天数据） |
| **未上线原因** | 内存限制，PID 需切分后 embedding，收益太小 |

**动机**：特征重要性排序通常为 ID 类特征 > 统计特征 > 画像特征，乘客对不同品牌的认可度和接驾距离接受度是个性化的。

---

## SENet

可解释性评估基准模型。

| 属性 | 值 |
|---|---|
| **作用** | 作为深度模型基准，评估 [[花小猪/PK策略知识库/wiki/models/LR逻辑回归.md|LR 模型]]的可解释占比 |
| **架构** | SENet + 三输出（is_do_finish, is_o_finish, is_d_finish） |
| **AUC** | do_finish: ==0.7719==, o_finish: 0.7276, d_finish: ==0.8928== |
| **对比** | LR is_do_finish: 0.7347 |
| **关键结论** | ==89.6%== 的司乘对排序与 LR 一致 |
| **状态** | 仅作为参考基准，不用于 PK 打分 |

| 属性 | 值 |
|---|---|

| **状态** | 当前使用中（在 PLE 模型内） |

## 候选但未实现的架构

以下架构在文档中被提及为优化方向，但尚未实现：

| 架构 | 类型 | 应用方向 | 说明 |
|---|---|---|---|
| **PPO** | 强化学习 | PK 动态窗口 | 替代 [[花小猪/PK策略知识库/wiki/models/DQN.md\|DQN]]，验证策略方法是否更优 |
| **MMoE** | 多任务学习 | PLE 消融实验 | 验证分置 Expert 结构的增益 |
| **STAR / HiNet / PEPNet** | 多场景建模 | PLE 升级 | 多场景建模架构 |
| **DeepFM** | 特征交叉 | PLE 升级 | FM 系特征交叉 |
| **GDCN** | 特征交叉 | PLE 升级 | DCN 系升级 |
| **AutoGroup** | 特征交叉 | PLE 升级 | 自动特征分组 |
| **AutoDis** | 特征 embedding | PLE | 自动离散化，收益甚微 |
