# XGBoost 模型

XGBoost 是 PK 决策系统的初始打分模型，也在动态窗口模块中作为举手概率预测模型使用。在 PK 打分场景已被 [[花小猪/PK策略知识库/wiki/models/LR逻辑回归.md|LR 模型]]替代。

## 一、PK 打分（已下线）

| 属性 | 值 |
|---|---|
| **预测目标** | 司乘组合胜出完单概率（二分类） |
| **特征数** | ==40+== 个特征 |
| **[[花小猪/PK策略知识库/wiki/concepts/AUC.md\|AUC]]** | ==0.7345==（PBD 验证集）/ 0.737（全城离线） |
| **训练数据** | PBD 端 2023/12/29 |
| **验证集** | PBD 端 2024/01/02 - 2024/01/15 |
| **部署** | Ether 平台 deploy/4965 |
| **下线原因** | 模型不可解释，商家无法理解胜率变化 |

### 特征类别分布

| 类别 | 代表特征 | 特征数 |
|---|---|---|
| 订单属性 | 城市、商家、发单时间、预估价、距离 | ~8 |
| 地理位置 | 起终点经纬度 | 4 |
| 司机行为 | 完单、拒单、取消、改派、应答时长（分连环派/非连环派 × 1d/3d/7d/14d/21d/28d）| ~30 |

### 兜底公式

Ether 模型服务请求失败时使用距离公式兜底：
```
EtherValue = 0.881 - 0.0432 * PickUpDis / 500.0
```

### AUC 细分

| 条件 | AUC |
|---|---|
| PBD 验证集 | ==0.7345== |
| 全城全样本 | 0.737 |
| 实验城市全样本 | 0.7452 |
| 不含司机取消 | 0.742 |

### 版本记录

| 版本 | 说明 | 状态 |
|---|---|---|
| V1-XGB | 基线模型 | 仅对照组 |
| V2-XGB | 连环派/非连环派特征分离 | 对照组 |

> [!warning] 关键认知修正
> 后续 LR 上线后发现，LR 离线 AUC（0.756）实际**高于** XGB（0.737）。原因是 LR 更好地校准了预测值（well-calibrated），而 XGB 预测普遍偏高（label 均值 0.645，XGB 预测均值 0.81）。
