# 源文档摘要：【LR26-010】PK 可解释 Deep&Wide 模型 V1.0

本文档是 V4 Deep&Wide 策略的最终评审、实验与放量记录。虽然文档编号为“LR26-010”，本次上线模型并非新的逻辑回归版本，而是从 V3 LR 升级到双任务 Deep&Wide；截至 ==2026-07-03 已完成 100% 流量放量==。

> [!info] 版本名说明
> - **策略代际**：V4 Deep&Wide
> - **LR 评审编号**：LR26-010
> - **文档版本**：V1.0
> - **模型实验版本**：历史材料中的 deep v1.2 / `pk_deep_explained_model v2`

## 1. 策略定位

### 目标变化

| 阶段 | 决策目标 |
|---|---|
| 原始目标 | CR +0.1pp |
| 最终放量目标 | **约束完单和 CR 不显著负**；交易效率（乘客 ETP + 司机接驾时长）优化至少 0.1%；应答后乘客取消 -0.1pp |

V4 的模型打分仍为双履约概率加权，并没有像 [[花小猪/PK策略知识库/wiki/entities/约束履约率最小化接驾距离策略.md|V5 方案]]那样把约束直接写入 `λf-d` 打分公式；但其线上放量标准已经从“只看 CR 增长”转为“CR/完单作为约束，交易效率作为主要收益”。它是旧打分范式向约束优化范式过渡的线上版本。

## 2. 模型方案

### 双任务建模

| 任务 | 样本空间 | 正样本 | 负样本 |
|---|---|---|---|
| `is_o_finish`（乘客履约） | PK 获胜且司机未取消/拒单 | 完单 | 乘客取消 |
| `is_d_finish`（司机履约） | PK 获胜且乘客未取消 | 完单 | 司机取消/拒单 |

最终 PK 模型分：

```text
score = α · P(is_o_finish) + (1-α) · P(is_d_finish)
```

司机取消后仍可能改派并最终完单，而乘客取消会直接丢单，因此乘客履约权重更高。最终放量取 `α=0.9`。

### Deep&Wide 分工

| 模块 | 输入与职责 | 可解释性 |
|---|---|---|
| Deep | 乘客特征生成乘客画像；供需特征与订单特征生成供需画像 | 非司机差异化，不直接改变同单司机排序 |
| Wide | 原始司机特征、司乘特征、画像和订单特征进入线性层 | 司机和司乘差异化特征保留原始形态，可输出权重 |
| Output | 分别输出乘客履约率和司机履约率 | 等价于两个共享画像输入但不完全独立的 LR |

### 离线 AUC

| 目标 | Wide&Deep | 两个 LR | 一个 LR | Wide&Deep vs 一个 LR |
|---|---:|---:|---:|---:|
| 乘客履约 | 0.701 | 0.682 | 0.675 | +2.6pp |
| 司机履约 | 0.825 | 0.809 | 0.788 | +3.7pp |
| 司乘履约 | 0.683（0.9:0.1） | — | 0.722 | -3.9pp |

> [!warning] 离线与线上目标不完全一致
> 两个子任务 AUC 均提升，但加权后的司乘履约 AUC 低于单一 LR。最终是否上线不能只按综合 AUC 判断，而要看权重选择带来的线上交易效率、取消和完单结果。

## 3. 全国 PID 实验

- 周期：2026-04-07 至 2026-04-13
- 城市：全国
- 分流：乘客随机分流
- 对照：V3 LR，88% 流量
- 实验：Deep&Wide，4 组各 3% 流量，乘客:司机权重依次为 0.9:0.1、0.8:0.2、0.7:0.3、0.6:0.4

### 最终放量组：实验组 1（0.9:0.1）

| 指标 | 相对对照 | 显著性/说明 |
|---|---:|---|
| 人均完单 | -0.16% | 不显著 |
| CR | +0.03pp | 不显著 |
| 应答后乘客取消 | **-0.16pp** | 显著 |
| 应答后司机取消（含改派） | **+0.44pp** | 显著，核心风险 |
| 单均预估接驾距离 | **-60.32m** | 显著 |
| 单均预估接驾时长 | **-9.6s** | 显著 |
| 司机接驾时长 | **-2.41%** | 显著 |
| 乘客 ETP | **-1.64%** | 显著 |
| 自营人均完单 | +1.27% | 商家结构变化 |
| 宏鹄人均完单 | -1.08% | 商家结构变化 |
| API 人均完单 | +0.51% | 不显著 |

### 为什么最终不是 0.8:0.2

0.8:0.2 组的 CR 为 +0.17pp、应答后乘客取消 -0.20pp，按传统 CR 目标看更好；但最终策略目标改为在完单/CR 不负约束下优先优化交易效率。因此选择 ETP、司机接驾时长和接驾距离降幅最大的 0.9:0.1 组。

## 4. 机制分析

### 权重迁移

- V4 相比 V3，司机接驾距离权重占比增加约 22pp，使接驾距离下降 60.32m，并带动答后乘客取消下降 0.16pp。
- 司机拒单率、司乘取消率和司机取消率的负向权重占比下降，导致司机取消（含改派）上升 0.44pp。

### 改派与乘客取消

- 司机取消改派从 0 次增加到 1 次时，应答率约下降 6pp，应答后乘客取消率约上升 15pp。
- “更重乘客履约”一方面选出更近司机、降低乘客取消；另一方面弱化司机履约约束、增加改派。两种效应叠加后，乘客取消随权重变化并不单调。
- 后续模型应加入司机取消改派次数特征。
