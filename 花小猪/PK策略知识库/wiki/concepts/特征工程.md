# 特征工程

特征工程是 [[花小猪/PK策略知识库/wiki/entities/PK模型.md|PK 模型]]从原始数据中提取、构造、选择有效特征的过程。PK 模型经历了从 XGB 的 40+ 特征到 LR 的精选特征的演进，核心挑战在于平衡特征的**表达力**与**可解释性**。

## 特征维度

### 订单特征

| 特征 | 说明 | 备注 |
|---|---|---|
| [[花小猪/PK策略知识库/wiki/concepts/接驾距离.md|接驾距离]] | 司机到乘客的距离 | 权重最大（LR 中 2 倍）|
| 单位距离价格 | 每公里价格 | |
| 订单距离 | 送驾距离 | |
| 发单后等待时间 | 乘客已等待的时间 | |
| 预估价 | 订单预估金额 | XGB 中重要性 2063 |

## 特征处理技术

| 技术 | 说明 |
|---|---|
| **特征隔离** | 分场景（连环派/非连环派，[[花小猪/PK策略知识库/wiki/concepts/半指派.md|半指派]]/非半指派）的司机特征硬隔离 |
| **空值填充** | 均值填充（LR）/ 城市中位数填充（[[花小猪/PK策略知识库/wiki/entities/冷启动系统.md|冷启动]]）|
| **特征标准化** | LR 模型要求特征标准化 |
| **数据差分** | diff_7d、diff_14d — 捕捉特征的变化趋势 |
| **离散化** | 连续特征分桶（深度模型中使用）|
| **Scalar2Vec** | 标量特征的向量化嵌入（深度模型）|
| **AutoInt** | 多头注意力实现特征自动交互（深度模型）|

## 特征演进（可解释模型各版本）

| 版本 | 特征改进 |
|---|---|
| V0 | 精选特征 + 司乘取消率合并 + 接驾距离权重 2 倍 |
| V1 | 连环派接驾距离统一 AB+BC + 优化空值填充 |
| V2 | 司机特征按"半指派 × 连环派"四象限重建 |
| V3 | 新增连环派接驾特征（距离+夹角）+ 绕路比 |

## 深度模型特征方案

- **PLE（Progressive Layered Extraction）**：场景（连环派/非连环派）专属 Expert 网络
- **POSO**：基于完单量的个性化冷启动嵌入
- **ESSM/ESCM**：多任务建模，分别预测司机取消和乘客取消
- **知识蒸馏**：利用 PID（后验）特征辅助训练
