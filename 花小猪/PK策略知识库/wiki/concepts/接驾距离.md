# 接驾距离

接驾距离（Pickup Distance）是指司机接到订单后前往乘客上车点的距离。在 [[花小猪/PK策略知识库/wiki/entities/PK模型.md|PK 模型]]中，它是**影响力最大的特征**，在可解释模型中权重被放大到 ==2 倍==。

## 在 PK 系统中的角色

- **XGB 模型**：`driver_start_dis` 重要性排名第 4（importance = 2582）
- **LR 模型**：权重放大到 2 倍，是影响 PK 打分最大的单一因子
- **兜底公式**：`EtherValue = 0.881 - 0.0432 * PickUpDis / 500.0`，接驾距离直接决定兜底分数

## 关键影响

接驾距离越大：
- 司机行驶成本越高 → 拒单/取消概率上升
- 乘客等待时间越长 → 乘客取消概率上升
- 整体[[花小猪/PK策略知识库/wiki/concepts/履约率.md]]下降

## 连环派场景的特殊处理 → [[花小猪/PK策略知识库/wiki/concepts/连环派.md]]

| 场景 | 接驾距离定义 | 说明 |
|---|---|---|
| 非连环派 | A → C（司机到乘客直线距离）| 标准定义 |
| 连环派（自营）| A → B + B → C | A=当前位置，B=当前订单终点，C=新乘客 |
| 连环派（其他商家）| A → C | 早期未区分，可能造成商家胜率偏差 |

> [!warning] 潜在问题
> 连环派场景下自营使用 AB+BC 而其他商家使用 AC，一般 AB+BC > AC，可能导致自营在连环派场景下的接驾距离特征偏大，影响胜率公平性。V1（LR25012）已将连环派接驾距离统一为 AB+BC。

## 接驾距离过滤

举手前置过滤中有接驾距离上限：

| 商家类型 | PBD 端/滴滴端 | 小猪端 |
|---|---|---|
| 滴滴系运力 | 不受限制 | 不受限制 |
| 宏鹄 | 6km | 6km |
| 花小猪 | 6km | 不受限制 |
| 其他运力 | 5km | 5km |

## 相关指标

- **平均接驾距离**：LR 模型实验后 ==+2.57%==（因权重调整）
- **接驾时间**（`est_pick_dur`）：预估接驾时长，与接驾距离强相关
- **绕路比**：V3（LR25050）引入的特征，考核连环派场景的路径合理性

## V4 Deep&Wide 线上结果

最终放量的 0.9:0.1 组将接驾距离权重占比相对 V3 提高约 22pp：

| 指标 | 全国 PID | 80% 放量复验 |
|---|---:|---:|
| 单均预估接驾距离 | **-60.32m** | — |
| 单均预估接驾时长 | **-9.6s** | — |
| 司机接驾时长 | **-2.41%** | **-2.45%** |
| 乘客 ETP | **-1.64%** | **-1.81%** |

代价是司机取消（含改派）+0.44pp、宏鹄完单 -1.08%。这说明距离、乘客取消与司机履约之间存在明确跷跷板。

## 范式转变：从"特征"到"显式优化目标"

> [!info] 2026 Q2 V5 范式
> [[花小猪/PK策略知识库/wiki/entities/约束履约率最小化接驾距离策略.md|V5 约束-最小化策略]] 将接驾距离从"模型特征"提升为"显式优化目标"。

| 角色 | V0-V4 | **V5** |
|---|---|---|
| 模型角色 | 输入特征（权重 2 倍）| 同左（仍是特征）|
| **打分角色** | 通过 [[花小猪/PK策略知识库/wiki/concepts/履约率.md\|履约率]] 间接影响 | **显式从 PK 分中减去**：`PK 分 = λf − d` |
| 优化目标 | 隐式最小化 | **显式最小化** s.t. CR 不显著负 |

### 兑换比（关键数据）

V1.1 离线模拟 λ=5340 时：

```
5.34 m 接驾距离 ↔ 0.1 pp 履约率
```

也就是 1 pp 履约率值 53.4 m 接驾距离 ⇒ **比 V4 最终组的 -60.32m / CR +0.03pp（不显著）含义完全不同**：
- V4：通过双履约概率和距离权重间接选择近司机，放量时用 CR/完单做约束
- V5：直接拿 CR 预算（≤ 0.2pp）换距离下降（目标 -20m / -1.21%）

### 离线模拟数据（V1.1）

| 指标 | λ=5340 时模拟值 |
|---|---|
| 满足约束订单占比 | 96.39% |
| 能选到更近司机的订单占比 | 3.81% |
| 整体平均接驾距离 | -20m (-1.21%) |
| 整体履约率 | -0.14pp（在 0.2pp 约束内）|
