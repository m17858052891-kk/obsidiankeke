### 早期版本的先后与日期缺口

- **V1 → V2**　V1 在等待超过 60 秒后向自营或宏鹄找车，每次呼叫两个品牌。V2 按场景改为 30 或 60 秒，并试验呼叫两个车型或全部候选。原文给出了版本顺序，各版实验起止、切换日期未列。[[预分单策略整理#V1 到 V4 改了什么，实验看到什么|V1 与 V2 原始对照]]
- **V3 → API 接入 → V4**　V3 用接受度模型筛车型。随后 API 接入，CR 约 +0.15 个百分点来自接入前后对比。V4 改为按格子供需定触发时机。端内实验按应答率 0.76、0.84 两道阈值，分别在 0、15、40 秒找车，每轮三个品牌。二期调参后大盘 CR +0.14 个百分点。[[预分单触发提效实验（端内）|端内实验参数]] · [[预分单策略整理#V1 到 V4 改了什么，实验看到什么|版本与比较口径]]
- **V4 二期放量节奏**　原文列全国乘客流量 12-18 到 30%、12-20 到 70%、12-22 到 100%。年份和各档实际执行日待核。已知 V4 曾在线，具体投产日、旧版下线日待核。[[升舱工程文档|当时线上配置]] · [[预分单策略提效放量节奏#放量节奏|放量节奏原表]]

## 哪些推荐有真实反馈

普通预分单先找候选，再向乘客询问。做接受度回放时，先按候选车型和价差统计实际展现量，再对有明确反馈的展现统计接受率。某类候选从未展示过，仅凭历史日志无法估计乘客对它的接受率。查[[知识体系/04-因果推断/02-调整、IPW与双重稳健#2. IPW：用处理选择概率还原目标总体|选择概率与样本重叠]]，再按[[花小猪/交易策略/02. 交易专项与模型自进化/05-模型自进化/00-模型自进化#预分单：哪些推荐有真实反馈|预分单的样本、训练与验证路线]]区分展示、超时和被原车型截断。
