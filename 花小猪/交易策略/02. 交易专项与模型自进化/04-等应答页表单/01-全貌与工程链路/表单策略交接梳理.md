### 2 模型

#### 2.1 问题抽象

##### 2.1.1 符号定义

| 符号 | 含义 |
| --- | --- |
| $$i$$ | 呼叫 |
| $$j$$ | 商家 |
| $$k$$ | 发单状态，即发单优先级 <br>1. 小猪特价104、特价盒子105、幸运盒子107 <br><br>2. 普通品类0、小猪一口价102、小猪打车103 <br><br>3. 特快盒子200、小猪特快101 <br> |
| $$p_{ijk}$$ | 呼叫$$i$$商家$$j$$真实的发单状态，one-hot变量 |
| $$\hat f_{ijk}$$&gt; 0 | 模型预测：呼叫$$i$$商家$$j$$在发单状态$$k$$时对该呼叫的完单贡献 |
| $$\hat {cpf}_{ijk}$$&gt; 0 | 模型预测：呼叫$$i$$商家$$j$$在发单状态$$k$$时以商家$$j$$完单的贡献 |
| $$cr_{i}$$ | 呼叫$$i$$的完单概率 |
| $$cpcr_{ij}$$ | 呼叫$$i$$以商家$$j$$完单的概率 |
| $$a_{ij}$$ | 呼叫$$i$$以商家$$j$$单独发单时，商家$$j$$应答的概率 |

##### 2.1.2 建模目的

1. 区分同一商家在【特价盒子内、盒子外、特快盒子内】的cr差异

2. cr与商家顺序无关

3. 需要获取某一商家完单的概率，用于下游联合决策的求解

#### 2.2 模型建模

- 呼叫完单率：$$\hat {cr}_i=(\sigma(\sum_j \hat f_{ijk}*p_{ijk})-0.5)*2$$

- 商家完单率：$$\hat {cpcr}_{ij}=\frac{e^{\hat {cpf}_{ijk}*p_{ijk}}}{\sum_j e^{\hat{cpf}_{ijk}*p_{ijk}}}$$ (softmax)

- 商家应答率：$$\hat a_{ij}$$
