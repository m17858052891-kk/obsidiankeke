## 二、表单列表展示

### 2.1 默勾

#### 2.1.0 默勾规则

1. 默勾策略不会对任何商家倾斜

2. 价格锚点相关数据向所有商家提供足够的多的数据（考虑信息安全）

3. 按照价格排序，不做跳勾处理（乘客黑名单除外）

4. 对无运力商家统一治理

#### 2.1.1 默勾策略V1

| 策略背景 | 背景介绍 | 默勾策略是一个重要的流量抓手，同时也是商家流量的第一个漏斗，如何在**确保乘客体验的同时，最大化平台规模**，是默勾策略需要解决的问题。 <br>在建设智能默勾策略之前，线上采用的是规则版的默勾——「**必勾到一口价**」，具体为默勾到自营一口价，并且保证价格低于「最低价乘以某一价格系数」的品牌都被默勾（该价格系数取决于用户上一单的发单的最高价除以最低价）。 <br>但这种规则版策略存在很多不合理的地方， <br>- 对自营的倾斜，属于反垄断法中的“自我优待”情形 <br><br>- 对自营的保护，无法充分释放商家竞争活力，不利于小商家规模增长，不符合聚合战略导向。 <br><br>为此，在2022年7-8月战略讨论后，明确了以下默勾规则，作为默勾策略迭代的基本准则。 |
| --- | --- | --- |
| 目标&约束 | **【目标】**平台效率——最大化完单 <br>**【约束】**乘客体验——默勾接受度绝对值 商家体验——公平、规则透明、单均完单里程不负（不短单倾斜） <br> |
| 产品形态 | ![](f40afe3d7560bcd8-image.png) |
| 策略方案 | BRD | |
| PRD | |
| 一句话方案 | 综合考虑用户对不同价格的默勾接受度，以及勾选车型组合的预估累计应答率，最大化完单 |
| 收益链路 | - 在供需平衡的时候，让用户以更低的价格打到车，强化了产品的低价心智； <br><br>- 在差应答场景，通过自适应加勾，提升差应答场景的CR（差应答场景用户的价敏程度会降低，对于能打到车的诉求会更迫切） <br> |
