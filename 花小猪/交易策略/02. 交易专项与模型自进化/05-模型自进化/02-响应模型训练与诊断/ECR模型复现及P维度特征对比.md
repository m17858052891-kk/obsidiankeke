# ECR模型复现及P维度特征对比

[Cooper 原文](https://cooper.didichuxing.com/knowledge/2199610335356/2204556000311)

## 模型复现

**线上模型：**16种折扣组合，训练数据周期是2024-11-08 -- 2024-11-28，离线auc: 0.7544

**复现数据：**5种折扣，只有特价盒子有折扣，训练数据周期是2025-02-26 -- 2025-03-12，离线auc: 0.7242

![](982f2d820b3acb35-image.png)

## 增加P维度特征

新增[p维度特征实验报告](https://cooper.didichuxing.com/knowledge/2199610335356/2204316054918)中全量用户建模top50特征，去掉实时特征（实时特征回溯不了3月份的数据），共43个特征。固定参数，训练五次，取最优结果

| | 没有p维度特征 | 增加p维度特征 |
| --- | --- | --- |
| AUC | 0.7242 | 0.7598 |
| MTAUCC_AREA | 0.1373 | 0.2277 |
| MTAUCC | ![](f0db7c6c2fe233e4-image.png) | ![](7fea22f13646524b-image.png) |
