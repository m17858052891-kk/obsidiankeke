## 预分单：哪些推荐有真实反馈

普通预分单先向候选车型发单、找到运力，再询问乘客是否接受。旧模型 `pre_dispatch_acc__v4` 曾给未发单、没有结果的候选按规则补标签。训练和测试沿用同一种补标规则，容易高估模型对真实反馈的预测能力。[[预分单接受度模型#离线训练|原模型与补标规则]]

**2024-09-04，线上日志单日回放。** 原文 SQL 取当天的乘客决定，与同一天的模型打分按订单、车型关联。按原口径，0 为接受，1 和 3 作拒绝，排除 2。这一批订单—车型对的 **AUC 约 0.63**。后续改用真实标签重训，原文的取数窗口为 **2024-08-11 至 09-11**，独立测试集的起止未单列。[[预分单接受度模型#效果评估|单日回放 SQL 与 AUC]] · [[预分单接受度模型#新模型训练|重训取数窗口]]

| 下一轮迭代 | 建议怎样做 |
|---|---|
| 构造样本 | 按原需求、决策轮次和候选车型，区分发单、举手、实际展现、乘客决定。对已展现的车型和价格记录主动接受或拒绝；超时默认拒绝单列，未展现、被原车型先应答截断的接受标签留空。先查真实展现能否关联到该轮候选。[[01 决策日志与训练样本#标签在什么条件下成立\|事件与标签对照]] |
| 训练与回放 | 按时间留出同一批有真实反馈的样本，按车型、等待时长、价差与人群检查样本量、排序、预测概率和实际接受率。量化旧策略很少展示的候选覆盖；对缺反馈的动作，需要额外的对照或探索数据。核同一模型版本的线上输入和离线特征。[[预分单接受度模型在离线一致性检验\|逐单校验方法]] |
| 线上验证与回流 | 对比模型时固定触发、候选与报价规则，按原分流单位看全部需求的最终完单和等待；再拆找到运力、实际展现、接受、正式应答。若接受率改善而完单未变，查原车型是否先应答、接受后是否取消。结果成熟后，把策略版本、实际动作和终态接回下一轮样本。[[02 模型迭代与上线验证#哪一步先出现差异\|定位首个差异]] |

## 升舱：同样预算能多完成几单

新流升舱用普通预分单的真实反馈，估计乘客自付差价的接受概率。复盘时，可以分别核对模型的排序、预测均值和实际补差带来的完单。

- **模型排序的样本期**　训练集为 **2025-06-01 至 07-31**，留出测试集为 **2025-08-01 至 08-07**。新旧 XGBoost 在相同测试数据上比较，新流 AUC 从 0.663 到 0.717，整体从 0.692 到 0.737。[[新流升舱：接受度模型、取消分析与实验结果#用预分单接受度估计补差能改变多少完单|训练、测试与分人群结果]]
- **接受率均值的样本期**　阈值测算记录里，旧模型预测新流接受率为 0.149，新模型为 0.288，实际约 0.295。原文只说明新旧模型对齐了训练集和测试集，未单列均值的统计起止，也未说明是否只取上述测试周。该批样本的平均预测更接近实测。[[新流升舱：决策公式、预算与工程链路#旧阈值怎样换算，最后实际上线多少|三项均值原记录]]
- **线上策略的评估期**　**2025-10-25 至 10-31** 的新流实验同时改变了运力、策略和触发场景。判断补差带来多少增量完单，要看当期的实际分组与补贴。[[花小猪/2025年LR/【LR25051】新流升舱策略优化v2#3.1 新流升舱评估|新流线上实验]]

| 下一轮迭代 | 建议怎样做 |
|---|---|
| 构造样本 | 保留可升舱候选、决策前价差和可用运力，再追预算拦截、实际发单、举手、应答、履约和补贴结算。补贴组只观察到补贴后的结果；乘客本会自付以及原车型本会完单，都要靠对照估计。[[新流升舱：决策公式、预算与工程链路#从一次预分单看升舱改变了什么\|升舱、自付预分单与原车型]] |
| 训练与回放 | 分开检查自付接受概率和目标运力履约机会。在同批候选、同预算约束下回放新旧策略，标出哪些单从自付变成了补差、哪些受预算或供给限制。若可升舱单增多而有司机举手的单没增加，优先查目标车型供给。[[新流升舱：决策公式、预算与工程链路#预算怎样变成逐单决策\|历史预算和钱效假设]] |
| 线上验证与回流 | 按原实验分配单位比较同预算的全量归一完单，或同增量完单的实际补贴；同时拆原勾选、自付预分单和升舱三条路径。保留实验组、对照组、城市时段与结算窗口，再分析车型或品牌间转移。样本回流时把原策略分配、实际执行和最终结算分别记录。[[新流升舱：接受度模型、取消分析与实验结果#两期实验怎样比较\|新增场景、旧策略与空白组分别怎么比]] |
