## 3 业务基础

### 3.1 非0TR

司乘分离计价

乘客侧：

- GMV = 乘客应付 = 定价日志中的pfp(passenger fixed price) = 乘客基础定价pep\*C一口价上下探系数 + 动调金额

- C补 = GMV - 乘客实付，C补率 = C补 / GMV

司机侧：

- online_driver_divide = 在线司机分成 = 司机应收 = 司机基础定价dep \* B一口价上下探系数 + 动调金额

- B补 = 司机实收 - 司机应收，B补率 = B补 / GMV

平台：

- 应付抽成比例 = 应付TR（Take Rate ） = 1 - 司机应收/GMV，无定语时的TR一般指应付TR

- 实付抽成比例 = 实付TR = 1 - 司机应收/乘客实付

- 业务毛利率 = TR - B补率 - C补率 - 税率

### 3.2 0TR

司乘一口价相同，记为p

乘客侧加收4%服务费，

- 乘客应付=1.04p

- 服务费不参与优惠，例如有8折券，乘客实付为0.8p+0.04p=0.84p

司机侧抽固定金额信息费，司机应收=p-信息费

平台抽成 = (信息费+0.04p) / 1.04p
