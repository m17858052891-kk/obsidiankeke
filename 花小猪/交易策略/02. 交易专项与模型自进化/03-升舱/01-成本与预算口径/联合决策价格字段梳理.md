# 联合决策价格字段梳理

[Cooper 原文](https://cooper.didichuxing.com/knowledge/2199610335356/2206374872090)

先核对 basic_total_fee、pas_total_fee 和不可抵扣费项，再看 API、特价盒子与幸运盒子的数值例子。表中“策略预期”与“工程实现的现状”是原记录中的对照；未填写的单元格保留为空。

**阅读定位**　[[#API 传给dups的字段|API 传给dups的字段]] · [[#API商家示例|API商家示例]] · [[#特价盒子示例|特价盒子示例]] · [[#幸运盒子示例|幸运盒子示例]] · [[#影响面|影响面]]

## API 传给dups的字段

- 不可抵扣费 = 节假日服务费 + 跨城费（暂未开发）

- basic_total_fee = 参与优惠计算的金额

- pas_total_fee = basic_total_fee - api三方优惠 + 不可抵扣费项

	- 待提需字段

## API商家示例

| 处理环节 | 字段或计算方式 | 盒子外API商家-策略预期 | 盒子外API商家现状，应付没有api三方优惠 |
| --- | --- | --- | --- |
| API内部逻辑 | 节假日服务费 | 5 | 5 |
| API内部逻辑 | 跨城费 | 10 | 10 |
| API内部逻辑 | api三方优惠：API商家的优惠，是一个负数 | -20 | -20 |
| API传给联合决策字段 | 不可抵扣费项 = 节假日服务费 + 跨城费 | 15 | 15 |
| API传给联合决策字段 | basic_total_fee = 参与优惠计算的金额 | 80 | 80 |
| API传给联合决策字段 | pas_total_fee = basic_total_fee - api三方优惠 + 不可抵扣费项 | 80-(-20)+15 = 115 | 80+15 = 95 |
| 联合决策内部处理逻辑 | 前置最大优惠额，API不可核销其他券 | 0 | 0 |
| 联合决策内部处理逻辑 | 呼返金额（对应cost）= 0，API商家不给呼返 | 0 | 0 |
| 联合决策内部处理逻辑 | 最终实付GMV = basic_total_fee - 前置最大优惠额 - 呼返金额 + 不可抵扣费项 | 80-0-0+15 = 95 | 80-0-0+15 = 95 |
| 联合决策内部处理逻辑 | 最终应付GMV = pas_total_fee | 115 | 95 |

## 特价盒子示例

| 处理环节 | 字段或计算方式 | 特价盒子 |
| --- | --- | --- |
| API内部逻辑 | 节假日服务费 | 5 |
| API内部逻辑 | 跨城费 | 10 |
| API内部逻辑 | api三方优惠：API商家的优惠，是一个负数，盒子无api三方优惠 | 0 |
| API传给联合决策字段 | 不可抵扣费项 = 节假日服务费 + 跨城费 | 15 |
| API传给联合决策字段 | basic_total_fee = 参与优惠计算的金额 | 80 |
| API传给联合决策字段 | pas_total_fee = basic_total_fee - api三方优惠 + 不可抵扣费项 | 80+15 = 95 |
| 联合决策内部处理逻辑 | 前置最大优惠额 | 90折对应 0.1\*80 = 8 |
| 联合决策内部处理逻辑 | 呼返金额（对应cost）= (basic_total_fee - 前置最大优惠额) \* (1 - 呼返折扣） | 90折对应(80-8)\*0.1=7.2 |
| 联合决策内部处理逻辑 | 最终实付GMV = basic_total_fee - 前置最大优惠额 - 呼返金额 + 不可抵扣费项 | 80-8-7.2+15=79.8 |
| 联合决策内部处理逻辑 | 最终应付GMV = pas_total_fee | 95 |

## 幸运盒子示例

athena：hongyan,chenchen

现有字段梳理：

- 传给dups

	- dups_gmv_atm = 预估原价的basic_total_fee，不包含节假日服务费

- dups传给api的实付：=(特价盒子basic_total_fee - 特价盒子前置最大优惠额) \* 幸运盒子折扣，不包含不可抵扣费项

- 传给athena ，pas_total_fee，dups传给api的实付 + 不可抵扣费项；全部改为平台推荐GMV+不可抵扣费项

	- 预估：dups改价后的值

	- 发单：dups改价前的值

	- 等待应答页预估：

		- ==UpdateWaitReplyRecommend：==若幸运盒子已发单，为改价之前的值；未发单，改价后的值；等应答预估

		- ==GetWaitReplyPredict：==若幸运盒子已发单，为改价之前的值；未发单，不传；除等应答预估外的轮询

确认下游对pas_total_fee的使用方式；确认api的幸运盒子实付处理，是否添加了不可抵扣费项
