## 1. 背景

MTAUCC 和 MTAUPC 在模型结构与训练数据相同、仅训练 Seed 不同的情况下，仍表现出较大的结果差异；部分折扣档位甚至出现符号翻转的情况。因此，单个 checkpoint 的评估结果难以稳定代表模型能力。本文围绕 MTAUCC 的不稳定原因、MTAUCC 的修改尝试，以及 MTAUPC 的稳定性消融实验展开分析。

## 2. MTAUCC 不稳定分析

### 2.1 问题

1. 收益与成本的归因口径不一致：`delta_BCR` 来自三维联合决策，而 `delta_cost` 主要只覆盖特价盒子成本；

2. 单调过滤的决策过多：由于非单调删除了70.220%的决策，导致剩下的决策过少；

3. 真实决策支持度不足：样本真实决策匹配率仅约为 1.36%，需要进行 72～74 倍扩样。

### 2.2 边际ROI 存在归因不一致

当前候选决策是三维联合决策：

```PlainText
T = (幸运盒子折扣, 特价盒子折扣, 默勾位置)
```

当前候选成本仅计算特价盒子的预测补贴成本：

```PlainText
Cost_u(T)
= BCR(T)
  × P(特价盒子完单 | 已完单, T)
  × p_u_prime
  × (1 - 特价盒子折扣 / 100)
```

其中，`p_u_prime` 取自字段 `uabox_after_pre_coupon_fee_amt`。

对单个样本，候选点先按预测 Cost 从小到大排序，然后依次进行：

1. 同 Cost 去重，只保留 BCR 最大的决策；

2. 单调过滤，只保留能够刷新历史最高 BCR 的点；

3. Cost–BCR 上凸包过滤；

4. 对相邻决策点计算边际 ROI：

```PlainText
delta_BCR  = BCR(T2) - BCR(T1)
delta_cost = Cost_u(T2) - Cost_u(T1)
ROI        = delta_BCR / delta_cost
```

最后将所有样本的 ROI 线段放在一起做全局降序排序。

当前决策的相邻决策可能同时改变幸运盒子折扣、特价盒子折扣和默勾位置，但 ROI 的分母仅包含特价盒子的预测补贴成本。因此，分子中的 BCR 增益并不完全来自于分母中的成本变化，Cost 与 BCR 也不具备天然的单调关系。

例如，决策上的两个相邻决策是：

```PlainText
T1 = (幸运盒子100折, 特价盒子90折, 默勾5)
T2 = (幸运盒子82折,  特价盒子90折, 默勾10)
```

这次决策变化中：

- 特价盒子折扣没有改变；

- 幸运盒子补贴明显加深；

- 默勾位置发生变化；

- `BCR`可能由于幸运盒子折扣加深而增加；

- `cost`可能由于特价盒子完单概率降低而降低。

因此，当前公式可能将幸运盒子折扣加深带来的预测收益归因于特价盒子补贴投入，无法严格解释为“特价盒子每增加一分钱成本所带来的完单增量”。

### 2.3 真实数据不满足 Cost 与 BCR 单调变化

在同一特价盒子折扣下，幸运盒子折扣加深时，整体 BCR 可能提高；但幸运盒子完单概率增加后，特价盒子完单品类概率可能下降，导致公式中的特价盒子预测 Cost 反而降低。

因此真实数据可能出现：

```PlainText
幸运盒子折扣加深
→ 整体 BCR 增加
→ 特价盒子完单占比降低
→ 特价盒子预测 Cost 降低
```

换言之，BCR 增量并不一定由当前分母所定义的特价盒子 Cost 单独带来，甚至可能出现 Cost 下降、BCR 上升的反向变化。

### 2.4 单调过滤的决策较多

上面说的归因问题会导致当cost较小的时候BCR会很大，因此每个样本会由于单调性删除很多决策，下面是样本候选决策删除漏斗：

| 阶段 | 总量 | 每个有效样本平均 | 相对原始候选 |
| --- | ---: | ---: | ---: |
| 原始候选决策 | 169,183,824 | 136.385 | 100.000% |
| 同 Cost 删除 | 42,060,827 | 33.907 | 24.861% |
| 单调删除 | 118,800,374 | 95.769 | 70.220% |
| 凸包删除 | 2,802,791 | 2.259 | 1.657% |
| 最终前沿点 | 5,519,832 | 4.450 | 3.263% |
| 最终 ROI 线段 | 4,279,344 | 3.450 | — |

1. **会发生大量单调删除，原因在于收益与成本的归因口径不一致不同。**当cost很小的时候会由于幸运盒子折扣较深导致BCR很高，因此会删除后面的决策点，极端情况当cost=0的时候，由于幸运盒子折扣很深，导致BCR最大，后续决策点的BCR都无法超过这个值，因此会删除很多决策点。

2. **同 Cost 删除仍具有结构性。** 共删除 42,060,827 个候选，占 24.861%。当特价盒为 100 折时，当前预测成本公式恒为 0，不同幸运盒和默勾候选会折叠到同一 Cost，只保留 BCR 最大者。

3. **凸包不是主要删除步骤。** 删除 2,802,791 个候选，占 1.657%；但相比参考 MMOE 结果的 1.067% 有所增加，说明单调模型保留了更多严格上升点，随后有更多点需要由边际斜率的凸包条件筛除。

### 2.5 真实决策匹配率过低

在每个截断点，评估器先汇总该截断点之前已进入的 ROI 线段，并为每个样本保留当前预测 Cost 最大的决策，再将该决策与 RCT 中的真实执行决策进行匹配。

MTAUCC 要求三维决策完全一致：

```PlainText
预测幸运盒子折扣 = 真实幸运盒子折扣
预测特价盒子折扣 = 真实特价盒子折扣
预测默勾位置   = 真实默勾位置
```

只有匹配成功的 Treatment 样本才用于计算真实 Cost 和真实 Finish，随后再扩样至全部 Treatment 样本：

```PlainText
x_cost = 匹配样本 actual_uabox_cost 之和 × n_trt / n_matched

y_finish_gain = 匹配Treatment完单数 × n_trt / n_matched - Control完单数 × n_trt / n_ctrl
```

在完整实验中，最终三维精确匹配率仅约为 1.36%～1.39%，对应约 72～74 倍的扩样系数。这意味着少量匹配样本的 Finish 或真实 Cost 变化会被放大。

## 3. MTAUCC 修改尝试

为缓解 MTAUCC 中“幸运盒子、特价盒子和默勾同时变化，但成本仅计算特价盒子”的归因问题，可以固定幸运盒子折扣 `X`，仅在同一幸运盒子档位内比较特价盒子决策。

固定幸运盒子后：

```PlainText
幸运盒子折扣 = X
候选决策   = (特价盒子折扣, 默勾位置)
```

固定幸运盒子折扣后，可以避免将幸运盒子折扣变化产生的 BCR 增益除以特价盒子 Cost 变化。两个 Seed 的部分逐档结果如下：

| 幸运盒子折扣 | Seed1 | Seed2 | 绝对差 |
| --- | --- | --- | --- |
| 100 | -0.2762 | -0.0331 | 0.2431 |
| 94 | 1.8968 | 0.5009 | 1.3959 |
| 91 | -12.8593 | 0.0406 | 12.8999 |
| 88 | -0.3097 | 0.8866 | 1.1962 |
| 85 | 0.2595 | 0.0477 | 0.2117 |
| 82 | 0.1976 | -0.0671 | 0.2647 |

实验结果表明，固定幸运盒子折扣后，MTAUCC 仍然不稳定，Random 基线的波动和真实决策匹配是其中重要因素。为进一步识别不稳定来源，下面转向同样固定一个补贴维度的 MTAUPC，并逐步开展消融实验。
