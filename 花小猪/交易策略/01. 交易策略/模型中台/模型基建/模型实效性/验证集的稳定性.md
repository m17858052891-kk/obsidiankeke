# 实验一(验证集以"周"为单位)

## 实验设计与方法说明

| **要素** <br> | **内容** <br> |
| --- | --- |
| **训练集** <br> | 固定单窗口：2026-03-01 \~ 03-23（模型全程不变） <br> |
| **验证集（6 个）** <br> | 每月 **24\~30 日**：验证集1 = 03-24\~03-30（**基线**，紧接训练窗口）/ 验证集2 = 04-24\~04-30 / 验证集3 = 05-24\~05-30 / 验证集4 = 06-24\~06-30 / 验证集5 = 07-24\~07-30 / 验证集6 = 08-24\~08-30 <br> |
| **设计亮点** <br> | 6 个验证集**等长（7 天）且月内位置一致（均在月末）**，消除了"月内位置效应"这一混杂；验证集1 与训练窗口无缝衔接，构成"零延迟"参照点 <br> |
| **评估指标** <br> | 离线 AUC（6 指标）+ σ~AUC~ <br> |

**设计层面的根本局限（必须先讲）：**==本实验固定模型、变化验证集，观察到的 AUC 差异 === **数据分布变化 + 验证集差异**==的混合，==**不含任何模型时效性信息**==（模型没变）。它无法直接回答"模型实时更新对离线效果的影响"这一问题；要回答该问题必须固定验证集、变化模型，或做完整的交叉矩阵。==
