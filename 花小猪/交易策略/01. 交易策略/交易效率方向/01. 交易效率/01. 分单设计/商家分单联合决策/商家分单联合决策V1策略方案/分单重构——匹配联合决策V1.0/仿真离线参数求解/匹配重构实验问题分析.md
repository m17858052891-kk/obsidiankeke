# 三、派单模式决策空间问题分析

1、模型落日志时不同OD会命中不同策略（作用于DO上），派单模式受策略影响转变原因有如下代码块中几类，且其中能由合决策派单模式不能生效的有==order_origin =3，level_type= 104，105，107== 这几类，约占65.6%，预估线上能真实由联合决策派单模式的OD占比仅有**34.4%**。

```PlainText
// 派单模式转变原因
const (
	ReasonNone                        DispatchTypeReason = 0  // 宏鹄先锋司机
```

举例说明：一个max_score决策胜出动作为全指派的OD因为策略作用只能生效半指派和对应Score得分，而该半指派对应的Score显著低于全指派Score，在O选D匹配中OD得分也不占优势，原本可能胜出的匹配结果因为Score变化不再能胜出【原本该OD的max_score在所有OD连边中最大分归一化Score最大，但当改为半指派动作下的归一化Score后得分为0.13691832，有其他OD的Score会胜出】

解决思路：

1）最小改动：虽然被策略影响派单模式决策，但仍生效max_score作为OD的打分；

2）收益空间修改：根据现有策略生效的OD情况，模拟匹配时因为未考虑这些策略在全收益空间测算的参数有问题，后续可以考虑策略实际生效动作，在参数测算的时候对这些OD固定选择策略生效的Score，在这样的收益空间下测算参数。

	- 获取召回矩阵中的DispatchType，当派单模式策略命中不能生效的司机开关，只用DispatchType对应的派单模式拿到Score；

	- 对能由联合决策派单模式的OD适用max_score决策派单模式，在这样的参数空间下测算参数。

3）直接获取召回矩阵中的DispatchType，用该派单模式对应的Score作为算法优化目标（本期不改造派单模式决策，只修改O对D打分）
