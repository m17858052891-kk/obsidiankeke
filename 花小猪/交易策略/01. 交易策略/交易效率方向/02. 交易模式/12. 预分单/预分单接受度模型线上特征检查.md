## 这次检查发现什么

乘客历史特征从 Hive 周期任务产出，经 DUFE 更新后由在线模型读取，请求时实际用到的值才会落入 ODS。排查时应区分三种情况：乘客本来没有历史、当天分区尚未更新、供数任务已停。天气则来自线上外部服务。以下任务状态均为该次检查记录。模板：[预分单接受率模型特征](https://dufe.intra.hongyibo.com.cn/templates/1102)。

| 特征 | 任务和核对结果 |
| --- | --- |
| 近 n 天预分单弹窗量、默认拒绝率、拒绝率、接受率 | [历史预分单供数任务](https://schedule.data.didichuxing.com/v5/cycle/task/detail/kflower_marketplace.fastload_dictkflowerprice_py_dict_auto_hive2ddict_hxz_pre_dispatch_history_features?projectId=1142)当时正常，v4 源表 `kflower_strategy.passenger_pre_dispatch_history_accept_rate`。根据特征空值估算，约 27% 的乘客有预分单触达。任务通常在 08:00～09:00 完成，之前的线上请求取不到昨天刚产出的值。之后再按同一乘客查询 DUFE，最新值可能与此前 ODS 不同。 |
| 乘客消费能力 | [`dict_hxz_pas_portrait_info`](https://schedule.data.didichuxing.com/v5/cycle/task/detail/kflower_marketplace.fastload_dictkflowerprice_py_dict_hxz_pas_portrait_info?projectId=1142#tab=dag) 已停，两个上游也已停，原因未明（[上游任务](https://schedule.data.didichuxing.com/v5/cycle/task/detail/kflower_marketplace.data_h2d_common_features_pas_portrait?projectId=1142)）。模型仅用其中一个特征，约一半样本非空；影响较小是原文估计。 |
| 近 n 天单均里程、冒泡数 | [`dict_hxz_pas_order_statistics`](https://schedule.data.didichuxing.com/v5/cycle/task/detail/kflower_marketplace.fastload_dictkflowerprice_py_dict_hxz_pas_order_statistics?projectId=1142#tab=baseInfo) 曾停，后已重启。v4 源表为 `kflower_marketplace.dwm_trip_pas_statistics_days_total_di`。重启后 DUFE 与 Hive 一致，这部分缺失来自调度中断，无需重新配置。 |
| 天气 | [天气调度](https://schedule.data.didichuxing.com/v5/cycle/task/detail/kflower_marketplace.data_h2d_fe_fex_ecr_weather?projectId=1142#tab=baseInfo)已启用但上游依赖丢失，未执行。模型的天气由线上外部传入，所以该任务未跑不能直接解释其空值率。 |
