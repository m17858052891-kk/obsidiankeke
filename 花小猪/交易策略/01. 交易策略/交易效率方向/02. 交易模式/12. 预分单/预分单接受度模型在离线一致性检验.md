## 检查结果与后续动作

乘客历史特征按分区、模型版本和请求时间对齐后，原记录的特征比对通过。预测回放发现一个需要工程处理的输入问题：同一订单、乘客、商家、trace 下，同时在特快盒子内外的运力被传入两个预估价；升舱需求应使用盒子外价格。已向工程提报，此页附有训练数据修复 SQL。其余结果中，不足 0.1% 的样本因线上线下小数保留位数不同，预测相差约 $10^{-3}$，其余符合预期。

## 特征怎样核对

> 预分单日志表：kflower_ods.ods_log_kflower_ether_hxz_pre_dispatch_accept_model_h

### 乘客历史、天气和实时字段

乘客历史核对两张离线表：`kflower_strategy.passenger_pre_dispatch_history_accept_rate`、`kflower_marketplace.dwm_trip_pas_statistics_days_total_di`。先在模型 ODS 限定分区、版本和请求时间，按乘客及日期对离线值（线上日期 = 离线分区日期 + 1 天）。再用同一乘客抽查 DUFE 模板；预览展示最新值，须核对当时离线调度是否已经产出。

天气经 DUSE 访问中台服务，以经纬度 `flat`、`flng` 为键，缓存每 5 分钟刷新。`estimate_fee_amt`、`call_hour`、`order_waiting_period` 等由工程实时传入。

## 离线回放时怎样避免误判

选取上游离线任务已完成后的请求，否则线上可能读取上一版本的特征。EVE 离线预测结果表会将原始空值写成 `-9999`，训练和线上推理则将原始 null 直接送入模型；核对时应区分输入值和落表展示。原图及逐步排查 SQL 如下。

```SQL
with history_acc_rate AS (
    SELECT
        pid AS passenger_id,
        dt,
        passenger_pre_dispatch_cnt_28day,
        passenger_pre_dispatch_cnt_14day,
        passenger_pre_dispatch_accept_cnt_28day,
        passenger_pre_dispatch_accept_cnt_14day,

        passenger_pre_dispatch_refuse_cnt_14day,
```

```SQL
    FROM
        kflower_strategy.passenger_pre_dispatch_history_accept_rate
    WHERE
        dt BETWEEN '2024-07-31'
        AND '2024-09-14'
),
pas_days_cnt_data AS (
    SELECT
        passenger_id,
        dt,
        bubble_cnt_7d AS pas_last_7day_bubble_cnt_kf,
        bubble_cnt_14d AS pas_last_14day_bubble_cnt_kf,
        bubble_cnt_28d AS pas_last_28day_bubble_cnt_kf,
        avg_start_dest_dis_14d AS pas_last_14day_avg_start_dest_dis_kf,
        avg_start_dest_dis_28d AS pas_last_28day_avg_start_dest_dis_kf,
        asp_amt_28d AS pas_last_28day_asp_amt_kf
    FROM
        kflower_marketplace.dwm_trip_pas_statistics_days_total_di
    WHERE
        dt BETWEEN '2024-07-31'
        AND '2024-09-14'
),
basic_feature_data AS (
    SELECT
        concat_ws('-', year, month, day) AS dt,
        param ['order_id'] AS order_id,
        param ['passenger_id'] AS passenger_id,
        param ["traceid"] AS trace_id,
        cast(param ["business_id"] AS bigint) business_id,
        cast(param ['city'] AS int) AS city,
        cast(param ["flat"] AS float) AS flat,
        cast(param ["flng"] AS float) AS flng,
        cast(param ["tlat"] AS float) AS tlat,
        cast(param ["tlng"] AS float) AS tlng,
        cast(param ['start_dest_distance'] AS float) AS start_dest_distance,
        cast(param ['estimate_fee_max'] AS float) AS estimate_fee_max,
        cast(param ['estimate_fee_min'] AS float) AS estimate_fee_min,
        cast(param ['basic_total_fee_amt'] AS float) AS basic_total_fee_amt,
        cast(param ['estimate_fee_amt'] AS float) AS estimate_fee_amt,
        CASE

        cast(param ['call_hour'] AS int) AS call_hour,
        cast(param ["predict_scene"] AS float) AS predict_scene,
        cast(param ["default_select_high_fee"] AS float) AS default_select_high_fee,
        cast(param ["default_selected_num"] AS int) AS default_selected_num,
        cast(param ["wait_relay_selected_num"] AS int) AS wait_relay_selected_num,
        cast(param ["call_week"] AS int) AS call_week,
        cast(
            param ['pas_portrait_consume_ability_kf'] AS float
        ) AS pas_portrait_consume_ability_kf,
        cast(param ['coord_start_humidity'] AS float) AS coord_start_humidity,
        cast(param ['coord_start_temperature'] AS float) AS coord_start_temperature,
        cast(param ['coord_start_intensity'] AS float) AS coord_start_intensity,
        cast(param ['coord_start_skycon'] AS float) AS coord_start_skycon

        kflower_ods.ods_log_kflower_ether_hxz_pre_dispatch_accept_model_h

        concat_ws('-', year, month, day) BETWEEN '2024-08-01'
        AND '2024-09-15'
),
feature_tb AS (
    SELECT
        t1.*,
        cast(t2.passenger_pre_dispatch_cnt_14day AS int) AS passenger_pre_dispatch_cnt_14day,
        cast(t2.passenger_pre_dispatch_cnt_28day AS int) AS passenger_pre_dispatch_cnt_28day,

            t2.passenger_pre_dispatch_accept_cnt_14day / t2.passenger_pre_dispatch_cnt_14day AS float
        ) AS passenger_pre_dispatch_accept_rate_14day,

            t2.passenger_pre_dispatch_accept_cnt_28day / t2.passenger_pre_dispatch_cnt_28day AS float
        ) AS passenger_pre_dispatch_accept_rate_28day,
        cast(
            t2.passenger_pre_dispatch_refuse_cnt_14day / t2.passenger_pre_dispatch_cnt_14day AS float
        ) AS passenger_pre_dispatch_refuse_rate_14day,
        cast(
            t2.passenger_pre_dispatch_refuse_cnt_28day / t2.passenger_pre_dispatch_cnt_28day AS float
        ) AS passenger_pre_dispatch_refuse_rate_28day,
        cast(
            t2.passenger_pre_dispatch_default_cnt_14day / t2.passenger_pre_dispatch_cnt_14day AS float
        ) AS passenger_pre_dispatch_default_rate_14day,
        cast(
            t2.passenger_pre_dispatch_default_cnt_28day / t2.passenger_pre_dispatch_cnt_28day AS float

        AND t1.dt = date_add(t3.dt, 1)

    CASE
        WHEN a.is_refused = 0 THEN 1 --is_refused=0为接受
        ELSE 0
    END AS label,
    b.*

    (
        SELECT
            DISTINCT order_id,
            product_id,
            is_refused,
            estimate_fee
        FROM
            kflower_dw.dwd_kf_trd_pre_dispatch_decision_di
        WHERE
            dt BETWEEN '2024-08-01'
            AND '2024-09-15'
            AND is_refused <> 2
            AND action = 'passenger_decision'
    ) a
    INNER JOIN -- 特征表
    (
        SELECT
            t3.*,
            t4.estimate_id
        FROM
            (
                SELECT
                    t1.*,
                    t2.product_id
                FROM
                    feature_tb t1
                    LEFT JOIN (
                        SELECT
                            DISTINCT business_id,
                            product_id
                        FROM
                            kflower_dw.dim_kf_trd_pbd_product_info_df
                        WHERE
                            dt between '2024-08-01' and '2024-09-15'
                    ) t2 ON t1.business_id = t2.business_id
            ) t3
            JOIN (
                SELECT
                    DISTINCT order_id,
                    bubble_trace_id AS trace_id,
                    product_id,
                    estimate_id
                FROM
                    kflower_dw.dwd_kf_trd_order_anycar_di
                WHERE
                    dt BETWEEN '2024-08-01'
                    AND '2024-09-15'
                    AND estimate_id is NOT null
                    AND lane_type <> 2
            ) t4 ON t3.order_id = t4.order_id
            AND t3.product_id = t4.product_id
            JOIN (
                SELECT
                    DISTINCT estimate_id,
                    round(estimate_fee_amt / 100, 1) AS estimate_fee_amt
                FROM
                    kflower_dw.dwd_kf_trd_bubble_base_all_di
                WHERE
                    dt BETWEEN '2024-08-01'
                    AND '2024-09-15'
                    AND estimate_id is NOT null
                    AND estimate_fee_amt <> 0
                    AND estimate_fee_amt is NOT NULL
            ) t5 ON t3.estimate_fee_amt = t5.estimate_fee_amt
            and t4.estimate_id = t5.estimate_id
    ) b ON a.order_id = b.order_id
    AND a.product_id = b.product_id
```
