# 升舱策略记录 · 预算求解和分桶查验

## 复算预算时看哪三件事

1. **固定预算如何得到逐单动作。** 将城市和补贴率映射到 λ，比较逐单预期完单增量与价差补贴的代价。给定 λ，是否升舱只有两个选择；利用对偶目标的凸性用三分法求解。下文保存原始 Python、样本 SQL 和补贴率对应表。
2. **预算是否真的守住。** 原文在求解样本上核验各档 C 补花费均未超过预算 B。再分别按价差、AR 差值、预分单接受度的十分位检查升舱占比；看接受度时需控制零价差订单占比，避免把样本构成误判为模型偏好。
3. **GMV 从哪里来。** 当时查验的升舱单中，68% 的升舱价低于已勾车型最高价，无需补价；用券前价乘应答概率差计算的是 GMV 增加期望，线上收益需另看对照实验。业务评估见[[升舱策略评估与优化思路]]，后续新流方案见[[新流升舱：决策公式、预算与工程链路]]。

> Q1:如何求解内部minimize优化问题?

> A1:z_i为0-1变量，将lambda视为常数时，内部优化问题等价于min(f(0), f(1))

> [!info]- Python 求解实现
> ```Python
> func = lambda l: -l * gmv * subsidy_rate + sum(
>         np.minimum(
>             l * (np.maximum(upgrade_price - base_price, 0)) * ar_upgrade
>             - (1 - pre_dispatch_acc) * (ar_upgrade - ar_base),
>             0,
>         )
>     )
> ```

> Q2:如何求解补贴率对应下的最优lambda

> A2:在确定z_i的前提下，L(lambda)是凸函数，使用三分法求解

> [!info]- Python 求解实现
> ```Python
> def triple_search(left: int, right: int, epsilon: float, func: Callable) -> float:
>     """三分法求凸函数的极点
>
>     Args:
>         l (int): 所求变量的下界
>         r (int): 所求变量的上界
>         epsilon (float): 精确度要求
>         func (Callable): 凸函数
>
>     Returns:
>         float: 凸函数的极点
>     """
>     while right - left > epsilon:
>         m1 = left + (right - left) / 3
>         m2 = right - (right - left) / 3
>         if func(m1) > func(m2):
>             right = m2
>         else:
>             left = m1
>         sys.stdout.write(f"\r当前的lambda为{(left + right) / 2}")
>         sys.stdout.flush()
>     sys.stdout.write("\n")
>     logger.info(f"最终的lambda为{(left + right) / 2}")
>     return (left + right) / 2
> ```

$$\tau_{i}^{r}$$表示完单增量

$$\tau_{i}^{c}$$表示C补

## 求解结果查验

### lambda卡预算

经过验证，当前模型求解方式的实际升舱C补花费均在对应的预算B内，无问题

### 按价差分桶

按10%分位数为间隔进行分桶，不同分桶内升舱占比如下图所示，价差越低的桶内升舱比例越高，符合模型数学规律和预期

![](6024c4474a1c1c3d-image.png)

因此，升舱前后价差较小时决定升舱，价差越高则升舱的可能性越小（当价差为0或者升舱价低于勾选最高价时，基本全部升舱）

### 按AR差值分桶

按10%分为数为间隔进行分桶，不同分桶内升舱占比如下图所示，可知当接受度差值位于高位时，升舱比例随该差值的增加而出现显著上升趋势，符合我们期望大盘完单提升的预期

### 按预分单接受度分桶
