$$max \sum_{i,j,p,k} gmv_{ijkp} \times z_{ijpk}$$

**$$= min_{\lambda \geq 0 , \mu\geq0  } \sum_{i,j} max _{p,k} \left [  (asp \times P_{p} )(1+\lambda\times s) +\mu) \times finish_{ijkp} -\lambda \times cost_{ijk} -\mu \times finish_{ij00} \right ]$$**

## 动调调度融合方案v2

原目录：13.动调调度 › 【当前迭代】 › 融合无单调度和动调调度 · [动调调度融合方案v2（Cooper 原页）](https://cooper.didichuxing.com/knowledge/2199610335356/2204903882810) ^eco-2204903882810


### 1. 背景

- **存在的问题**：当前线上的 动调调度融合调度方案 的核心思路是对所有召回的动调格子，对司机分别预测 无单调度 和 动调调度 下的 gmv 和 cost，并赋予动调调度相应的调权因子以此来增加动调的优先级：**倍数因子profit_weight_dyn 和 cost_weight_dyn，**并通过统一的运筹规划来对司机下发策略。该方案的核心问题包括：

	- **缺少合理的效果评估指标**：由于调度和动调是独立进行优化，而不是协同优化，离线缺少一个能跟线上实验效果方向保持一致的评估指标，这使得即使两个项目都得到了离线评估效果的提升，也无法确定是否能得到整体线上效果的提升

	- **非全局最优**：两个问题实际上是==耦合==和交叉的，具体的一个例子是对一个长时听不到单的司机，对某个格子而言可以是动调司机，也可以是无单调度司机，两者所在的空间是相互交叉的、相互争夺的。因此线上的方案仅仅是在各自的空间去优化，一定会带来全局最大化优化目标（完单）的折损。因此我们本次提出的方案的本质是联合决策调度和动调，期望得到一个全局的最优解

 

- **拟解决的问题**：针对上述线上存在的问题，本方案做出了如下核心改进：

	- 可以通过离线指标来评估来模拟线上收益：**动调调度AUCC**

	- 动调和调度联合决策

 

- **额外好处****：**

	- **降低维护成本**：此方案包括三个功能：时空动调， 动调调度， 司机无单调度， 并且

		- 可自动切换到最优的策略

		- 可灵活关闭某些功能（可以只开司机无单调度功能）

### 2. 运筹规划问题

#### 2.1 问题定义

|   <br> |  含义 <br> |
| --- | --- |
| D(i)  <br> | 格子i可以调的司机  <br>$$D(i) = \{  driver | \text{driver not on hot grid and driver go to grid i < 10min}\}$$ <br> |
| i <br> | 格子ID <br> |
| j <br> | 司机ID,  司机ID等于0 时不调司机 <br> |
| p <br> | 调价系数 ， p=0 不调价 $$Price =\{0, 0.05, 0.1,0.15,0.20,0.25\}$$ <br> |
| $$Finish_{ijp}$$ <br> | 如果司机j调度格子i并且格子i价格涨1+p 的完单量 <br> |
| B <br> | 总预算 <br> |
| $$z_{ijp}$$ <br> | 决策变量 （如果$$z_{ijp} = 1 则在i格子调司机j并且价格涨100*p \%$$） <br> |
| HotGrid <br> | 热格子 <br> |
| $$d_j$$ <br> | 司机j <br> |
| $$\sigma(D(i))$$ <br> | 所有司机组合 <br>如果 $$D(i) = \{ d_1 , d_2, d_3 \}$$则 <br>$$\sigma(D(i)) = \cup_{e\in\mathcal{P(D(i))}} e= \{  a_{\{d_1\}}, a_{\{d_2\}},a_{\{d_3\}},  a_{\{d_1, d_2\}} , a_{\{d_1, d_3\}} , a_{\{d_2, d_3\}},  a_{\{d_1,d_2, d_3\}} \}$$ <br>$$｜\sigma(D(i))｜= 2^{ |D(i)|} -1$$ <br> |
| k <br> | 司机组合  <br> |
| d <br> | 是否下发调度 $$d \in \{0,1\}$$ <br> |
| $$cost_{ijpk}$$ <br> | 司机真实收到的调度补贴（里程费+ 无单补贴） <br> |

$$\max   \sum_{i \in HotGrid} \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} }   Finish_{ijpk} \times z_{ijpk}$$

$$st  \quad  \sum_{i \in HotGrid} \sum_{j \in \sigma(D(i)) } \sum_{p \in  Price }   \sum_{d \in  \{0,1\} } cost_{ijpd} \times z_{ijpd} \leq B \quad \text{ 预算约束}$$

$$\quad  \quad \forall i  \in HotGrid \quad \sum_{k \in \sigma(D(i)) } \sum_{p \in  Price } \sum_{d \in  \{0,1 \} }  z_{ijpk} = 1 \quad  \text{每个格子都需要下发一个策略, 调j组合的司机到i格子并且价格涨100*p\%}$$

$$\quad  \quad \forall j \in D(i) \quad  \sum_{i \in HotGrid}  \sum_{p \in Price} z_{ijp1}  \leq 1$$  每个司机只能调到一个格子

$$\quad  \quad \forall i,j,p,k \quad z_{ijpk} \in \{0,1 \}$$

由于$$\sigma(D(i))$$的空间超大为了简化问题我们把$$\sigma(D(i))$$限制成$$D(i)$$(每个格子最多只能调一个司机)

所以最终的优化问题变成：

$$\max  \sum_{i \in HotGrid} \sum_{j \in D(i) } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} } Finish_{ijpd} \times z_{ijpd}$$

$$st  \quad  \sum_{i \in HotGrid} \sum_{j \in D(i)} \sum_{d \in  \{0,1\} } cost_{ijpd} \times z_{ijpd} \leq B \quad \text{ 预算约束}$$

$$\quad  \quad \forall i  \in HotGrid \quad \sum_{j \in D(i) } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} }z_{ijpd} = 1 \quad  \text{每个格子都需要下发一个策略,每个格子只能调度一个司机}$$

$$\quad  \quad \forall j \in D(i) \quad  \sum_{i \in HotGrid}  \sum_{p \in Price} \sum_{d \in  \{0,1\} } z_{ijp1}  \leq 1$$  每个司机只能调到一个格子

$$\quad  \quad \forall i,j,p,d \quad z_{ijpd} \in \{0,1 \}$$

#### 2.2 从PRIMAL问题改成 DUAL问题

首先为了简化优化问题先不考虑司机约束， 导致优化问题变成  
$$\max  \sum_{i \in HotGrid} \sum_{j \in D(i) } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} } Finish_{ijpd} \times z_{ijpd}$$

$$st  \quad  \sum_{i \in HotGrid} \sum_{j \in D(i)} \sum_{d \in  \{0,1\} } cost_{ijpd} \times z_{ijpd} \leq B \quad \text{ 预算约束}$$

$$\quad  \quad \forall i  \in HotGrid \quad \sum_{j \in D(i) } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} }z_{ijpd} = 1 \quad  \text{每个格子都需要下发一个策略,每个格子只能调度一个司机}$$  

$$\quad  \quad \forall i,j,p,d \quad z_{ijpd} \in \{0,1 \}$$

##### **拉格朗日及对偶变换**

**PRIMAL PROBLEM**

==为了将带约束的优化转化成无约束的优化，我们将目标函数f转化成拉格朗日乘==子形式

$$\max_{Z} \min_{\lambda \geq 0}   \sum_{i \in HotGrid}  \sum_{j \in D(i) } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} } Finish_{ijpd}\times z_{ijpd}  - \lambda \times [ \sum_{i \in HotGrid}  \sum_{j \in D(i) } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} } cost_{ijpd} \times z_{ijpd} -B ] \quad,  \forall i  \in HotGrid   \ \sum_{j \in D(i) } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} }z_{ijpd} = 1$$  
$$\Leftrightarrow \max_{Z} \min_{\lambda \geq 0}  \sum_{i \in HotGrid}  \sum_{j \in D(i) } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} }  [ Finish _{ijpd} - \lambda cost_{ijpd} ] \times z_{ijpd} + \lambda \times B \quad,   \forall i  \in HotGrid   \ \sum_{j \in D(i) } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} }z_{ijpd} = 1$$

$$\Leftrightarrow \max_{Z} \min_{\lambda \geq 0}  \sum_{i \in HotGrid}  \sum_{j \in D(i) } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} }  [ Finish _{ijpd} - \lambda cost_{ijpd} ] \times z_{ijpd}  \quad,   \forall i  \in HotGrid   \ \sum_{j \in D(i) } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} }z_{ijpd} = 1$$

==因此，我们要优化的原问题(Primal problem)即为== $$\max_{Z} \min_{\lambda \geq 0}  \sum_{i \in HotGrid}  \sum_{j \in D(i) } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} }  [ Finish _{ijpd} - \lambda cost_{ijpd} ] \times z_{ijpd}$$ ==。因为Z的搜索空间远大于==λ==的搜索空间，原问题求解比较不直观，为了使求解更方便，我们可将其转化为对偶==

**DUAL PROBLEM** 

$$\min_{\lambda \geq 0}  \max_{Z} \sum_{i \in HotGrid}  \sum_{j \in D(i) } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} }  [ Finish _{ijpd} - \lambda cost_{ijpd} ] \times z_{ijpd}  \quad,   \forall i  \in HotGrid   \ \sum_{j \in D(i) } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} }z_{ijpd} = 1$$

$$\Rightarrow   \min_{\lambda\geq 0} \sum_{i \in HotGrid}   \sum_{j \in D(i) } \max_{ ( p, d) \in Price \times \{0,1\}}   Finish_{ijpd} - \lambda \times cost_{ijpd} ,   \forall i  \in HotGrid   \ \sum_{j \in D(i) } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} }z_{ijpd} = 1$$

#### 2.3 最优解

如果找到最优$$\lambda ^*$$最优格子，司机组合如下：

$$\forall i,j,p,d \in HotGrid\times D(i) \times Price \times \{0,1\}  ,z_{ijpd}=1 \Leftrightarrow  \forall i, j \in HotGrid \times D(i) ,\ (p,d)(i) = \argmax_{ (p,d) \in  Price \times \{0,1\} }   Finish_{ijpd} - \lambda^*\times cost_{ijpd}  ， \forall i  \in HotGrid   \ \sum_{j \in D(i) } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} }z_{ijpd} = 1$$

这里的目标是判断每个格子需要下发哪一个策略， 这个决策个拆成两步：

- 判断哪些需要下发策略 (过滤)

- 下发哪个策略 （greedy 排序）

#### 2.4 FROI 条件 (保证预算)

按照以上的公式，需要对每个lambda ， 格子i  $$Finish_{ijpd} - \lambda^*\times cost_{ijpd}$$的排序需要准才能做的最佳的决策，所以我们模型的性能依赖于不同 lambda。

**问题：**

•按照以上的公式，需要对每个λ,i,j  的排序需要准才能做的最佳的决策，所以我们模型的性能依赖于不同λ

•很难评估以上的公式的排序能力

**调度成本：**

- case 1 : $$(p^*,d^*)(i) = (0,0) \ \text{(\textcolor{red}{格子i不需要调度司机并且不需要动调})}$$ 

$$\forall i \in HotGrid,  z_{ij00} =1\Leftrightarrow \forall j, p,d \  Finish_{ij00} - \lambda^*\times cost_{ij00} \geq Finish_{ijpd} - \lambda^*\times cost_{ijpd}$$

$$\quad \quad \quad \quad \quad \quad \quad \quad \quad  \quad \quad \quad  \ \ \ \Leftrightarrow  \forall j, p ,d\  \frac{Finish_{ijpd} - Finish_{ij00}}{ cost_{ijpd} - cost_{ij00}}\leq\lambda^*$$ 

$$\quad \quad \quad \quad \quad \quad \quad \quad \quad  \quad \quad \quad  \ \ \ \Leftrightarrow  \forall j, p ,d\  FROI_{ijpd} \leq\lambda^*$$

- case 2 : $$(j^*,p^*)(i) \neq (0,0) \ \text{(\textcolor{green}{格子i需要调度/动调/动调调度})}$$ 

$$\forall i \in HotGrid,  z_{ij*p*} =1\Leftrightarrow \forall j, p,d \  Finish_{ijp^*d^*} - \lambda^*\times cost_{ijp^*d^*} \geq Finish_{ijpd} - \lambda^*\times cost_{ijpd}$$

$$\quad \quad \quad \quad \quad \quad \quad \quad \quad  \quad \quad \quad  \ \ \ \Rightarrow \forall j, p,d ,\  ,\  Finish_{ijp^*d^*} - \lambda^*\times cost_{ijp^*d^*} \geq Finish_{ij00} - \lambda^*\times cost_{ij00}$$ 

$$\quad \quad \quad \quad \quad \quad \quad \quad \quad  \quad \quad \quad  \ \ \ \Rightarrow \forall j, p,d ,\  ,\  \frac{Finish_{ijp^*d^*} - Finish_{i00}}{ cost_{ijp^*d^*} - cost_{ij00}} \geq \lambda^*$$

$$\quad \quad \quad \quad \quad \quad \quad \quad \quad  \quad \quad \quad  \ \ \ \Rightarrow  \forall j, p,d ,\  ,\  FROI_{ijp^*d^*} \geq \lambda^*$$

#### 2.5 保证动调调度的约束 

##### 决策约束（格子维度）

每个格子最多只能下发一个策略， 但以上FROI条件无法保障这个约束（$$｜\{ (j,p,d) \in (D(i) )\times Price \times\{0,1\}| FROI_{ijpd} \geq \lambda   \}｜> 1$$）。

为了保证决策约束我们使用二次过滤方法，在每个$$\{ (j,p,d) \in (D(i) )\times Price \times\{0,1\}| FROI_{ijpd} \geq \lambda   \}$$空间中选择$$Finish$$最高的格子。

##### 司机约束（司机维度）

每个司机j最多只能调到一个格子， 但以上FROI条件无法保障这个约束 （$$｜\{ (i,p) \in D(j)^{-1} \times Price| FROI_{ijp} \geq \lambda   \}｜> 1$$）

为了保证决策约束我们使用二次过滤方法，在每个$$\{ (i,p) \in D(j)^{-1} \times Price| FROI_{ijp} \geq \lambda   \}$$空间中选择$$Finish$$最高的格子。

## 动调调度融合方案v3

原目录：13.动调调度 › 【当前迭代】 › 融合无单调度和动调调度 › 动调调度融合方案v3 · [动调调度融合方案v3（Cooper 原页）](https://cooper.didichuxing.com/knowledge/2199610335356/2205951245020) ^eco-2205951245020


### 1. 背景

- **存在的问题**：当前线上的 动调调度融合调度方案 的核心思路是对所有召回的动调格子，对司机分别预测 无单调度 和 动调调度 下的 gmv 和 cost，并赋予动调调度相应的调权因子以此来增加动调的优先级：**倍数因子profit_weight_dyn 和 cost_weight_dyn，**并通过统一的运筹规划来对司机下发策略。该方案的核心问题包括：

	- **缺少合理的效果评估指标**：由于调度和动调是独立进行优化，而不是协同优化，离线缺少一个能跟线上实验效果方向保持一致的评估指标，这使得即使两个项目都得到了离线评估效果的提升，也无法确定是否能得到整体线上效果的提升

	- **非全局最优**：前动调调度方案是分开做决策， 判断动调系数后再进行调度决策，分开做决策导致决策空间有限因此无法达到全局最优。

 

- **拟解决的问题**：针对上述线上存在的问题，本方案做出了如下核心改进：

	- 可以通过离线指标来评估来模拟线上收益：**动调调度AUCC**

	- 动调和调度联合决策

 

- **额外好处****：**

	- **降低维护成本**：此方案包括三个功能：时空动调， 动调调度， 司机无单调度， 并且

		- 可自动切换到最优的策略

		- 可灵活关闭某些功能（可以只开司机无单调度功能）

- 融合方案和单策略决策的差异：

	- 融合方案： 调度和动调决策同时进行

	- 单策略决策 ： 先判断动调后在进行调度

- 时空动调，司机无单调度和动调调度的差异：

	- 时空动调 ： 判断每个时空不同调价的完单uplift最大的调价并且生效

	- 司机无单调度 : 判断在预算内完单最大的uplift的策略（调度vs不调度）并且生效

	- 动调调度 ： 判断在预算内完单最大的uplift的策略（调度司机组合和调价）并且生效

#### 2.1 问题定义

|   <br> |  含义 <br> |
| --- | --- |
| i <br> | 格子ID <br> |
| j <br> | 司机ID,  司机ID等于0 时不调司机 <br> |
| HotGrid <br> | 热格子（前10分钟呼叫大于1（格子维度）+ 前10分钟应答率&lt;阈值） <br> |
| D(i)  <br> | 格子i可以调的司机集合  <br>$$D(i) = \{  driver | \text{driver not on hot grid and driver go to grid i < 10min}\}$$ <br> |
| $$\sigma(D(i))$$ <br> | ==格子i可以调的所有司机组合== <br>如果 $$D(i) = \{ j_1 , j_2, j_3 \}$$则 <br>$$\sigma(D(i)) = \cup_{e\in\mathcal{P(D(i))}} e= \{  k_{\{j_1\}}, k_{\{j_2\}},k_{\{j_3\}},  k_{\{j_1, j_2\}} , k_{\{j_1, j_3\}} , k_{\{j_2, j_3\}},  k_{\{j_1,j_2, j_3\}} , k_{\varnothing} \}$$ <br>$$｜\sigma(D(i))｜= 2^{ |D(i)|}$$ <br>k表达具体的司机组合 <br> |

| $$Finish_{ikp}$$ <br> | 如果调第k组合的司机到i格子并且价格涨p%的完单量 <br> |
| B <br> | 总预算 <br> |
| $$z_{ikp}$$ <br> | 决策变量 （如果$$z_{ikp} = 1 则在i格子调司机组合k并且价格涨100*p \%$$） <br> |
| $$cost_{ikp}$$ <br> | 司机真实收到的调度补贴（里程费+ 无单补贴） <br> |

$$\max   \sum_{i \in HotGrid} \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     F_{ikp} \times z_{ikp}$$

$$st  \quad  \sum_{i \in HotGrid} \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     cost_{ikp} \times z_{ikp} \leq B \quad \text{ 约束一 ： 预算约束 }$$

$$\quad  \quad \forall i  \in HotGrid \quad \sum_{k \in \sigma(D(i)) } \sum_{p \in  Price }  z_{ikp} = 1 \quad  \text{约束二 ：每个格子都需要下发一个策略, 调第k组合的司机到i格子并且价格涨100*p\%}$$

$$\quad  \quad \forall j  \in \text{所有司机} \quad \sum_{i \in \{ 司机j可调度的格子\}}   \sum_{k \in \{  司机j参与的调度组合\}}  \sum_{p \in  Price }  z_{ikp} \leq 1 \quad  \text{约束三：每个司机只能调到一个格子}$$

$$\quad  \quad \forall i,k,p \quad z_{ikp} \in \{0,1 \}  \quad \text {约束四： 决策变量只能等于1或0}$$

#### 2.2 从PRIMAL问题改成 DUAL问题

首先为了简化优化问题， 我们只考虑约束一、二、四， 后续会在算法中调整来满足约束三

$$\max   \sum_{i \in HotGrid} \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     Finish_{ikp} \times z_{ikp}$$

$$st  \quad  \sum_{i \in HotGrid} \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     cost_{ikp} \times z_{ikp} \leq B \quad \text{ 预算约束}$$

$$\quad  \quad \forall i  \in HotGrid \quad \sum_{k \in \sigma(D(i)) } \sum_{p \in  Price }  z_{ikp} = 1 \quad  \text{每个格子都需要下发一个策略, 调第k组合的司机到i格子并且价格涨100*p\%}$$

$$\quad  \quad \forall i,k,p \quad z_{ikp} \in \{0,1 \}$$

##### **拉格朗日及对偶变换**

**PRIMAL PROBLEM**

==为了将带约束的优化转化成无约束的优化，我们将目标函数f转化成拉格朗日乘==子形式

$$\max_{Z} \min_{\lambda \geq 0}    \sum_{i \in HotGrid} \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     Finish_{ikp} \times z_{ikp} -\lambda\times [ \sum_{i \in HotGrid} \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     cost_{ikp} \times z_{ikp} - B ], \forall i  \in HotGrid \quad \sum_{k \in \sigma(D(i)) } \sum_{p \in  Price }  z_{ikp} = 1$$  
$$\Leftrightarrow \max_{Z} \min_{\lambda \geq 0}    \sum_{i \in HotGrid} \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     [ Finish_{ikp} - \lambda \times cost_{ikp} ]\times z_{ikp} +\lambda\times  B , \forall i  \in HotGrid \quad \sum_{k \in \sigma(D(i)) } \sum_{p \in  Price }  z_{ikp} = 1$$

==因此，我们要优化的原问题(Primal problem)即为== $$\max_{Z} \min_{\lambda \geq 0}  \sum_{i \in HotGrid}  \sum_{j \in D(i) } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} }  [ Finish _{ijpd} - \lambda cost_{ijpd} ] \times z_{ijpd} + \lambda \times B$$ ==。因为Z的搜索空间远大于==λ==的搜索空间，原问题求解比较不直观，为了使求解更方便，我们可将其转化为对偶==

**DUAL PROBLEM** 

$$\min_{\lambda \geq 0}  \max_{Z}  \sum_{i \in HotGrid} \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     [ Finish_{ikp} - \lambda \times cost_{ikp} ]\times z_{ikp} +\lambda\times  B , \forall i  \in HotGrid \quad \sum_{k \in \sigma(D(i)) } \sum_{p \in  Price }  z_{ikp} = 1$$

为了简化问题我们先不考虑格子抢占司机的问题， 所以 $$max \sum = \sum max$$

$$\min_{\lambda \geq 0} \sum_{i \in HotGrid}  \max_{Z}   \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     [ Finish_{ikp} - \lambda \times cost_{ikp} ]\times z_{ikp} +\lambda\times  B , \forall i  \in HotGrid \quad \sum_{k \in \sigma(D(i)) } \sum_{p \in  Price }  z_{ikp} = 1$$

#### 2.3 最优解

如果找到最优$$\lambda ^*$$，每个格子i的最优策略（调价，调度司机组）如下：

$$k^*,p^* = \argmax_{k,p} [Finish_{ikp} - \lambda^* \times cost_{ikp}  ]$$

#### 2.4 FROI 条件 (保证预算)

**问题：**

按照以上的公式，需要对每个$$\lambda$$、格子i，  $$Finish_{ikp} - \lambda  \times cost_{ikp}$$的排序需要准才能做最佳的决策，所以我们模型的排序依赖于不同 $$\lambda$$。

**目的：** 我们希望得到一个不依赖于$$\lambda$$的值来进行决策

- case 1 : $$(k^*,p^*)(i) = (0,0) \ \text{(\textcolor{red}{格子i不需要调度司机并且不需要动调})}$$ 

$$\forall i \in HotGrid,  z_{i00} =1\Leftrightarrow \forall k,p \  Finish_{i00} - \lambda^*\times cost_{i00} \geq Finish_{ikp} - \lambda^*\times cost_{ikp}$$

$$\quad \quad \quad \quad \quad \quad \quad \quad \quad  \quad \quad \quad  \ \ \ \Leftrightarrow  \forall k,p\  \frac{Finish_{ikp} - Finish_{i00}}{ cost_{ikp} - cost_{i00}}\leq\lambda^*$$ 

$$\quad \quad \quad \quad \quad \quad \quad \quad \quad  \quad \quad \quad  \ \ \ \Leftrightarrow  \forall k,p\  FROI_{ikp} \leq\lambda^*$$

- case 2 : $$(k^*,p^*)(i) \neq (0,0) \ \text{(\textcolor{green}{格子i可以调度/动调/动调调度})}$$ 

$$\forall i \in HotGrid,  z_{ik*p*} =1\Leftrightarrow \forall (k,p) \neq (k^*,p^*) \  Finish_{ik^*p^*} - \lambda^*\times cost_{ik^*p^*} \geq Finish_{ikp} - \lambda^*\times cost_{ikp}$$

$$\quad \quad \quad \quad \quad \quad \quad \quad \quad  \quad \quad \quad  \ \ \ \Rightarrow  \  Finish_{ik^*p^*} - \lambda^*\times cost_{ik^*p^*} \geq Finish_{i00} - \lambda^*\times cost_{i00}$$ 

$$\quad \quad \quad \quad \quad \quad \quad \quad \quad  \quad \quad \quad  \ \ \ \Leftrightarrow \frac{Finish_{ik^*p^*} - Finish_{i00}}{ cost_{ik^*p^*} - cost_{i00}} \geq \lambda^*$$

$$\quad \quad \quad \quad \quad \quad \quad \quad \quad  \quad \quad \quad  \ \ \ \Leftrightarrow   \  FROI_{ik^*p^*} \geq \lambda^*$$

以上的决策公式相对比原始的决策公式，不依赖于$$\lambda$$因此我们只需要保障FROI的排序准确即可。

### 一、背景： 

#### 1.1 业务背景

司机无单调度是指将长时间听不到单的司机从接单概率低的区域牵引到接单概率更高的区域，带来司机应答率的提升，**带来司机完单和gmv的提升**。不同于热力图，仅仅推荐给司机一些热区， 调度希望更“强制”迁移司机到一些热区。 目前常见的**“强制”**迁移方式如下：区域发放红包， 时长保底（买断司机时间）。本次方案选择了里程费+ 无单补贴的发放的形式来吸引司机迁移到热区。

#### 1.2 初期方案介绍

初期的司机无单调度策略整体分为两步：ML (Machine Learning) + OR（Operation Research）：

- **ML部分预测运筹规划求解需要的gmv、cost**，该部分会建立5个模型*（**司机起点格子接单概率*‏、*司机终点接单概率*‏、*司机中途接单概率模型*‏、*司机接受度*‏、*未播订单数模型）*，分别预测链路中的各个环节，通过上述模型结果去计算司机调度*(司机-格子对)*带来的gmv提升和对应的cost；

- **OR部分基于ML给出的司机-格子对的gmv、cost，求解【roi约束下最大化gmv目标】的调度策略**，并下发给司机。ML部分预测的gmv、cost输入到黑盒的运筹规划当中，**ML的误差会在运筹规划中被进一步叠加，同时OR部分会对绝对值的准确率更敏感。**

### 二、技术方案

#### 2.1 问题定义

我们的目标是在ROI的约束条件下最大化司机的GMV，这个问题可以用以下的公式来描述：

![](efc5aca94c64f116-image.png)

每一轮的调度策略会影响下一轮，但是轮次之间的影响难以刻画，因此该版本问题由全局最优（Global）简化为单轮最优：

![](4edc6be1b8ca6296-image.png)

==由于仅需确保整体ROI符合预设的ROI约束条件，我们可以将整体ROI分解为各轮次的ROI（==$$\text{ROI}_{\text{round}}$$==），随后通过实时调控每一轮的ROI，以保障整体ROI满足约束要求==

![](69ebcd05ac980d1e-image.png)

**参数定义 :**

| ==数学符号== <br> | ==含义== <br> |
| :---: | :---: |
| $$i$$ <br> | 司机 <br> |
| $$j$$ <br> | 格子 <br> |
| $$k$$ <br> | $$第k个策略$$ <br>（策略0 ：不下发调度 <br>策略1 ： 调度补贴金额1 <br>策略2 ： 调度补贴金额2） <br> |
| $$z_{ijk}$$ <br> | 决策变量（0，1） <br> |
| $$ROI_{round}$$ <br> | 本轮的ROI约束 <br> |

**原问题 ：**

$$\max \text{GMV}_{\text{round}} = \sum_{i=1}^n \sum_{j=1}^m \sum_{k=0}^{K-1} \text{gmv}_{ijk} \times z_{ijk}$$*（**单轮优化目标**：最大化单轮gmv）*

st.

$$\ \sum_{i=1}^n \sum_{j=1}^m \sum_{k=0}^{K-1} (\text{gmv}_{ijk} - \text{gmv}_{ij0} )\times z_{ijk} \geq  \text{ROI}_{\text{round}} \sum_{i=1}^n \sum_{j=1}^m \sum_{k=0}^{K-1} (\text{cost}_{ijk} - \text{cost}_{ij0} )\times z_{ijk}$$*（**roi约束**：调度roi大于*$$ROI_{round}$$*）*

$$\sum_{k=0}^{K-1} z_{ijk} =1$$*（**决策变量约束**：每个司机-格子对需要下发一个策略）*

$$\sum_{j=1}^{m} z_{ij1} \leq1$$*（**司机约束**：每个司机i最多能调度到一个格子）*

$$\sum_{i=1}^{n} z_{ij1} \leq未播订单数$$*（**格子约束**：每个格子j最多只能接受未播订单数个司机）*

上述问题中，单轮GMV可以用所有格子-司机对的gmv的和来表示，同时我们需要满足如下约束：

- 调度需要满足roi的约束

- 对一个司机来说至多只能调度到一个格子

- 1个格子当前轮次能调度的司机至多为N个（N为未播订单数，因为当前**召回的格子99.4%的未播订单数小于等于1，因此后续该约束为1**）

- 由于目前我们只有一种调度金额这个策略所以K=2

#### 2.2 贪心求解 & 决策函数

我们希望通过贪心策略来求解上述的最大化问题：类似于广告投放和实时竞价，我们希望能够对**司机-格子对统一评判打分、排序、截断topN输出**，希望从gmv最大化的角度对收益最大的司机-格子对下发调度。为了**明确司机-格子对价值的评判标准**，我们下面将进行对偶问题的转化和贪心求解：

![](d61427d49fce0b88-image.png)

原始问题转化为对偶问题以后，假设我们已经确定当前轮次最优的,我们可以基于贪心的思想求解，**在这部分我们先只考虑红框中的约束（后面通过过滤逻辑来满足另外两个约束条件）通过贪心推导得到决策函数**，具体的，对应每一个司机-格子对，只有当调度带来的gmv大于不调度的gmv且整体满足roi约束，我们才会考虑下发调度，即：

$$^*roi_{ij} = \frac{ \Delta \text{gmv}_{ij}}{\Delta \text{gmv}_{ij}} =  \frac{ \text{gmv}_{ij1} - \text{gmv}_{ij0}}{\text{cost}_{ij1} - \text{cost}_{ij0}} \geq ^*阈值$$

#### 2.3 排序 & 过滤保证调度约束

在2.2章节中，我们明确将司机与格子对调度的投资回报率（roi）作为调度的决策指标。对于那些调度roi较高的司机-格子组合，我们需要优先进行调度下发。线上生效流程具体如下：

- **步骤1**：在每一轮中，召回司机-格子对，并对司机-格子对的roi及GMV进行预测

- **步骤2**：将司机-格子对按照roi进行降序排序，并依据阈值确定可用于下发调度的司机-格子候选集合。具体而言，我们使用ROI限制和DISPATCH AUCC曲线来初始化阈值，此方法将在4.4 - 4.5部分进行详尽阐述，其核心思路在于离线确定累计增益值最高的点

- **步骤3**：为确保满足决策约束条件，我们采用二次过滤方法：

- 

- **司机约束**：每个司机i最多仅能被调度至1个格子。

- **格子约束：**每个格子j最多只能接受1个司机

为确保满足此约束条件，针对每位司机，我们仅保留预测GMV最高的格子，

#### 2.7 评估指标

**核心解决的问题**：uplift模型可以通过AUCC来评估模型排序的好坏，并判断线上收益的正向程度，确保离在线的一致性。但在调度场景这个一致性是不成立的，原因在于DPoi对的干预不是独立的，对同一个司机我们只能给定一个策略，即司机最多只能调度到一个格子，同样对格子而言，最多只能被调入一个司机。但是在计算AUCC的时候，二次过滤不允许下发的调度任务会被计算A在TE中， 此时ATE和实际ATE存在误差。因此我们基于AUCC设计了一个适配二次过滤的评估指标，DISPATCH-AUCC。

### 动调调度融合方案v3-0211修改版

### 1. 背景

- **存在的问题**：当前线上的 动调调度融合调度方案 的核心思路是对所有召回的动调格子，对司机分别预测 无单调度 和 动调调度 下的 gmv 和 cost，并赋予动调调度相应的调权因子以此来增加动调的优先级：**倍数因子profit_weight_dyn 和 cost_weight_dyn，**并通过统一的运筹规划来对司机下发策略。该方案的核心问题包括：

	- **缺少合理的效果评估指标**：由于调度和动调是独立进行优化，而不是协同优化，离线缺少一个能跟线上实验效果方向保持一致的评估指标，这使得即使两个项目都得到了离线评估效果的提升，也无法确定是否能得到整体线上效果的提升

	- **非全局最优**：前动调调度方案是分开做决策， 判断动调系数后再进行调度决策，分开做决策导致决策空间有限因此无法达到全局最优。

 

- **拟解决的问题**：针对上述线上存在的问题，本方案做出了如下核心改进：

	- 可以通过离线指标来评估来模拟线上收益：**动调调度AUCC**

	- 动调和调度联合决策

 

- **额外好处****：**

	- **降低维护成本**：此方案包括三个功能：时空动调， 动调调度， 司机无单调度， 并且

		- 可自动切换到最优的策略

		- 可灵活关闭某些功能（可以只开司机无单调度功能）

- 融合方案和单策略决策的差异：

	- 融合方案： 调度和动调决策同时进行

	- 单策略决策 ： 先判断动调后在进行调度

- 时空动调，司机无单调度和动调调度的差异：

	- 时空动调 ： 判断每个时空不同调价的完单uplift最大的调价并且生效

	- 司机无单调度 : 判断在预算内完单最大的uplift的策略（调度vs不调度）并且生效

	- 动调调度 ： 判断在预算内完单最大的uplift的策略（调度司机组合和调价）并且生效

### 2. 运筹规划问题

#### 2.1 问题定义

|   <br> |  含义 <br> |
| --- | --- |
| i <br> | 格子ID <br> |
| j <br> | 司机ID,  司机ID等于0 时不调司机 <br> |
| HotGrid <br> | 热格子（前10分钟呼叫大于1（格子维度）+ 前10分钟应答率&lt;阈值） <br> |
| D(i)  <br> | 格子i可以调的司机集合  <br>$$D(i) = \{  driver | \text{driver not on hot grid and driver go to grid i < 10min}\}$$ <br> |
| $$\sigma(D(i))$$ <br> | ==格子i可以调的所有司机组合== <br>如果 $$D(i) = \{ j_1 , j_2, j_3 \}$$则 <br>$$\sigma(D(i)) = \cup_{e\in\mathcal{P(D(i))}} e= \{  k_{\{j_1\}}, k_{\{j_2\}},k_{\{j_3\}},  k_{\{j_1, j_2\}} , k_{\{j_1, j_3\}} , k_{\{j_2, j_3\}},  k_{\{j_1,j_2, j_3\}} , k_{\varnothing} \}$$ <br>$$｜\sigma(D(i))｜= 2^{ |D(i)|}$$ <br>k表达具体的司机组合 <br> |
| p <br> | 调价系数 ， p=0 不调价 $$Price =\{0, 0.05, 0.1,0.15,0.20,0.25\}$$ <br> |
| $$Finish_{ikp}$$ <br> | 如果调第k组合的司机到i格子并且价格涨p%的完单量 <br> |
| B <br> | 总预算 <br> |
| $$z_{ikp}$$ <br> | 决策变量 （如果$$z_{ikp} = 1 则在i格子调司机组合k并且价格涨100*p \%$$） <br> |
| $$cost_{ikp}$$ <br> | 司机真实收到的调度补贴（里程费+ 无单补贴） <br> |

$$\max   \sum_{i \in HotGrid} \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     F_{ikp} \times z_{ikp}$$

$$st  \quad  \sum_{i \in HotGrid} \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     cost_{ikp} \times z_{ikp} \leq B \quad \text{ 约束一 ： 预算约束 }$$

$$\quad  \quad \forall i  \in HotGrid \quad \sum_{k \in \sigma(D(i)) } \sum_{p \in  Price }  z_{ikp} = 1 \quad  \text{约束二 ：每个格子都需要下发一个策略, 调第k组合的司机到i格子并且价格涨100*p\%}$$

$$\quad  \quad \forall j  \in \text{所有司机} \quad \sum_{i \in \{ 司机j可调度的格子\}}   \sum_{k \in \{  司机j参与的调度组合\}}  \sum_{p \in  Price }  z_{ikp} \leq 1 \quad  \text{约束三：每个司机只能调到一个格子}$$

$$\quad  \quad \forall i,k,p \quad z_{ikp} \in \{0,1 \}  \quad \text {约束四： 决策变量只能等于1或0}$$

#### 2.2 从PRIMAL问题改成 DUAL问题

首先为了简化优化问题， 我们只考虑约束一、二、四， 后续会在算法中调整来满足约束三

$$\max   \sum_{i \in HotGrid} \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     Finish_{ikp} \times z_{ikp}$$

$$st  \quad  \sum_{i \in HotGrid} \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     cost_{ikp} \times z_{ikp} \leq B \quad \text{ 预算约束}$$

$$\quad  \quad \forall i  \in HotGrid \quad \sum_{k \in \sigma(D(i)) } \sum_{p \in  Price }  z_{ikp} = 1 \quad  \text{每个格子都需要下发一个策略, 调第k组合的司机到i格子并且价格涨100*p\%}$$

$$\quad  \quad \forall i,k,p \quad z_{ikp} \in \{0,1 \}$$

##### **拉格朗日及对偶变换**

**PRIMAL PROBLEM**

==为了将带约束的优化转化成无约束的优化，我们将目标函数f转化成拉格朗日乘==子形式

$$\max_{Z} \min_{\lambda \geq 0}    \sum_{i \in HotGrid} \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     Finish_{ikp} \times z_{ikp} -\lambda\times [ \sum_{i \in HotGrid} \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     cost_{ikp} \times z_{ikp} - B ], \forall i  \in HotGrid \quad \sum_{k \in \sigma(D(i)) } \sum_{p \in  Price }  z_{ikp} = 1$$  
$$\Leftrightarrow \max_{Z} \min_{\lambda \geq 0}    \sum_{i \in HotGrid} \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     [ Finish_{ikp} - \lambda \times cost_{ikp} ]\times z_{ikp} +\lambda\times  B , \forall i  \in HotGrid \quad \sum_{k \in \sigma(D(i)) } \sum_{p \in  Price }  z_{ikp} = 1$$

==因此，我们要优化的原问题(Primal problem)即为== $$\max_{Z} \min_{\lambda \geq 0}  \sum_{i \in HotGrid}  \sum_{j \in D(i) } \sum_{p \in  Price }  \sum_{d \in  \{0,1\} }  [ Finish _{ijpd} - \lambda cost_{ijpd} ] \times z_{ijpd} + \lambda \times B$$ ==。因为Z的搜索空间远大于==λ==的搜索空间，原问题求解比较不直观，为了使求解更方便，我们可将其转化为对偶==

**DUAL PROBLEM** 

$$\min_{\lambda \geq 0}  \max_{Z}  \sum_{i \in HotGrid} \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     [ Finish_{ikp} - \lambda \times cost_{ikp} ]\times z_{ikp} +\lambda\times  B , \forall i  \in HotGrid \quad \sum_{k \in \sigma(D(i)) } \sum_{p \in  Price }  z_{ikp} = 1$$

为了简化问题我们先不考虑格子抢占司机的问题， 所以 $$max \sum = \sum max$$

$$\min_{\lambda \geq 0} \sum_{i \in HotGrid}  \max_{Z}   \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     [ Finish_{ikp} - \lambda \times cost_{ikp} ]\times z_{ikp} +\lambda\times  B , \forall i  \in HotGrid \quad \sum_{k \in \sigma(D(i)) } \sum_{p \in  Price }  z_{ikp} = 1$$

#### 2.3 最优解

如果找到最优$$\lambda ^*$$，每个格子i的最优策略（调价，调度司机组）如下：

$$k^*,p^* = \argmax_{k,p} [Finish_{ikp} - \lambda^* \times cost_{ikp}  ]$$

#### 2.4 FROI 条件 (保证预算)

**问题：**

按照以上的公式，需要对每个$$\lambda$$、格子i，  $$Finish_{ikp} - \lambda  \times cost_{ikp}$$的排序需要准才能做最佳的决策，所以我们模型的排序依赖于不同 $$\lambda$$。

**目的：** 我们希望得到一个不依赖于$$\lambda$$的值来进行决策

- case 1 : $$(k^*,p^*)(i) = (0,0) \ \text{(\textcolor{red}{格子i不需要调度司机并且不需要动调})}$$ 

$$\forall i \in HotGrid,  z_{i00} =1\Leftrightarrow \forall k,p \  Finish_{i00} - \lambda^*\times cost_{i00} \geq Finish_{ikp} - \lambda^*\times cost_{ikp}$$

$$\quad \quad \quad \quad \quad \quad \quad \quad \quad  \quad \quad \quad  \ \ \ \Leftrightarrow  \forall k,p\  \frac{Finish_{ikp} - Finish_{i00}}{ cost_{ikp} - cost_{i00}}\leq\lambda^*$$ 

$$\quad \quad \quad \quad \quad \quad \quad \quad \quad  \quad \quad \quad  \ \ \ \Leftrightarrow  \forall k,p\  FROI_{ikp} \leq\lambda^*$$

- case 2 : $$(k^*,p^*)(i) \neq (0,0) \ \text{(\textcolor{green}{格子i可以调度/动调/动调调度})}$$ 

$$\forall i \in HotGrid,  z_{ik*p*} =1\Leftrightarrow \forall (k,p) \neq (k^*,p^*) \  Finish_{ik^*p^*} - \lambda^*\times cost_{ik^*p^*} \geq Finish_{ikp} - \lambda^*\times cost_{ikp}$$

$$\quad \quad \quad \quad \quad \quad \quad \quad \quad  \quad \quad \quad  \ \ \ \Rightarrow  \  Finish_{ik^*p^*} - \lambda^*\times cost_{ik^*p^*} \geq Finish_{i00} - \lambda^*\times cost_{i00}$$ 

$$\quad \quad \quad \quad \quad \quad \quad \quad \quad  \quad \quad \quad  \ \ \ \Leftrightarrow \frac{Finish_{ik^*p^*} - Finish_{i00}}{ cost_{ik^*p^*} - cost_{i00}} \geq \lambda^*$$

$$\quad \quad \quad \quad \quad \quad \quad \quad \quad  \quad \quad \quad  \ \ \ \Leftrightarrow   \  FROI_{ik^*p^*} \geq \lambda^*$$

以上的决策公式相对比原始的决策公式，不依赖于$$\lambda$$因此我们只需要保障FROI的排序准确即可。

1.  随机选择两个格子A和B（B和A的近距离大于==4个格子直径==）

3. 计算A和他的计算环内的指标（完单）/ 计算B和他的计算环内的指标（完单）（ *ps ：由于保护环中存在网络效应（吸引司机）我们无法使用这个环中的数据计算A/B的标签）*

#### 2.1 问题定义

目标：降低端内差供需时空下的冒泡占比

- 模型一预测策略对差时空冒泡率的影响（目标）

- 模型二预测策略对完单的影响（约束）

但是差时空冒泡率的建模比较复杂，所以将原问题进行转换，动调调度的决策空间（调价和调度司机组合的叉乘）关于调价部分不会出现降价的操作，因此下发任何一个动调调度策略，假设完单不变的前提下，都会使CR增加（呼叫降），因此，原目标中为了降低差供需时空的冒泡占比（提高差供需时空CR），可以转化成**最大化完单**。

> 【最大化完单】和【降低端内差供需时空下的冒泡占比】是同向变化的，但是完单最大化的解可能是【降低端内差供需时空下的冒泡占比】的次优解。

#### 2.2 贪心算法

为了简化问题求解， 我们先考虑约束一、三， 后续会在算法中调整来满足约束二 。

> 为什么舍弃约束二而不是约束三，因为约束三和优化目标的sum 粒度是一样所以后续可以合并进行贪心算法而约束二的sum粒度不一样

$$\max   \sum_{i \in HotGrid} \sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     \Delta Finish_{ikp} \times z_{ikp}$$

$$\quad  \quad \forall i  \in HotGrid \quad \sum_{k \in \sigma(D(i)) } \sum_{p \in  Price }  z_{ikp} = 1 \quad  \text{每个格子都需要下发一个策略, 调第k组合的司机到格子i并且价格涨100*p\%}$$

$$\quad  \quad \forall i,k,p \quad z_{ikp} \in \{0,1 \}$$

由于格子之间争抢司机难以刻画， 本方案先假设这个问题不存在，因此可以认为格子之间是独立的（$$\max \sum_{grid} = \sum_{grid} \max$$）

$$\sum_{i \in HotGrid} \max\sum_{k \in \sigma(D(i))  } \sum_{p \in  Price }     \Delta Finish_{ikp} \times z_{ikp}$$

$$\quad  \quad \forall i  \in HotGrid \quad \sum_{k \in \sigma(D(i)) } \sum_{p \in  Price }  z_{ikp} = 1 \quad  \text{每个格子都需要下发一个策略, 调第k组合的司机到格子i并且价格涨100*p\%}$$

$$\quad  \quad \forall i,k,p \quad z_{ikp} \in \{0,1 \}$$

$$\Leftrightarrow \forall i \in HotGrid \ k^*,p* = \arg \max_{k,p} \Delta Finish_{ikp}$$

直接使用argmax进行决策，这个决策公式可以拆成两个决策（cf appendix A）：

1. **某个格子是否需要下发动调调度策略** ：这个格子如果**存在策略k、p导致**$$\Delta Finish_{ikp} > 0$$**，**那么说明该格子应该下发动调调度策略，反之则不应该触发；

2. **格子下发哪一个策略**：在每个格子满足$$\Delta Finish_{ikp} > 0$$的策略中选择使得$$\Delta Finish_{ikp}$$**最大化的k和p策略**。

上面直接用0作为阈值的决策，可能因**【模型偏差】导致没有实现整体完单最大**（比如对下发策略的完单整体低估，预测$$\Delta Finish_{ikp} < 0$$，但是真实情况的完单增量 > 0），为缓解该问题，我们可以0改成阈值$$\lambda$$：

- **某个格子是否需要下发动调调度策略：** 这个格子时候存在一个策略k、p导致$$\Delta Finish_{ikp} >\lambda$$

- **格子下发哪一个策略：** 在满足$$\Delta Finish_{ikp} > \lambda$$的策略中选择 k和p导致$$\Delta Finish_{ikp}$$最大化

>  $$\lambda$$通过离线AUUC曲线选定。

#### 2.3 保证动调调度的约束二

基于前面推理$$\Delta Finish_{ikp} > \lambda$$只是满足了约束一和约束三，关于约束二【每个司机j最多只能调到一个格子】（$$\sum_{i \in \{ 司机j可调度的格子\}}   \sum_{k \in \{  司机j参与的调度组合\}}  \sum_{p \in  Price }  z_{ikp} \leq 1$$）还没有满足，我们使用二次过滤方法来满足约束二：每个司机选择$$\Delta Finish$$最高的格子的策略。

### 2. 问题定义

#### 2.1 原始问题

目标：降低端内差供需时空下的冒泡占比

> 差供需时空：格子5分钟时空里的呼叫>=5并且CR<0.5

> 差供需时空下的冒泡占比 : 差供需时空里的冒泡量/大盘的冒泡量

约束：端内完单不显著负

#### 2.2 原始问题

| 原始问题的方案及缺点 <br> | 转化后的求解方式 <br> |
| --- | --- |
| **目标：** $$\begin{aligned} \min\;  R(p,K) = \frac{ \sum_{(g,t)\in S_{bad}(p,K)} B_{g,t} }{ \sum_{(g,t)\in S_{all}} B_{g,t} } \end{aligned}$$，因**策略不改变冒泡量**，故原目标可以转化为: <br>$$\begin{aligned}  \min \sum_{(g,t)\in S_{bad}(a)} B_{g,t} &= \min \sum_{g,t} B_{g,t}\cdot \mathbf{1}\big[(g,t)\in S_{bad}(p,K)\big] \\ &= \min \sum_{g,t} B_{g,t}\cdot \mathbf{1}\big(call_{g,t}\ge5,\; CR_{g,t}<0.5\big)  \end{aligned}$$ <br>**约束：**$$Finish_{all}(p,S) \ge Finish_{all}(\text{baseline})$$ <br>> **差时空定义：**$$S_{bad}​={(g,t):call_{g,t​}≥5, CR_{g,t}​<0.5}$$，p：调价系数；K：调度司机组合；g：格子，空间；t：时间 <br><br> <br>如果直接解原问题，带约束的优化问题一般是进行拉格朗日松弛，那么最终需要搭建的模型为： <br>- 预测格子在不同treatment是否为差时空格子（bad 指标） <br><br>	- 预测每个treatment 下的时空级 finish 、call；*（误差累积）* <br><br>	- 或者作为一个分类问题来解：直接预测不同treatment下是否为差时空； <br><br>- 预测大盘（无策略影响）各个时空对应的冒泡量、完单量； <br><br>- 离线求解 λ\*，然后在拉格朗日决策式中挑最优： <br><br>	- 决策公式中必须含有λ，首先λ范围比较难确认，其次步长选择也是一个关键问题 <br><br>	- 完单约束下的最小化差时空冒泡率，因不同treatment下完单非单调(调价系数增加，完单可能增加也可能降低)，导致决策公式没办法转换成 f(格子， 策略) &gt; g( \\lambda )形式， <br><br> <br>> $$\Delta bubble_{格子， 决策} -  \lambda \times  \Delta finish_{格子， 决策} \geq 0$$ <br>$$\Leftrightarrow \Delta bubble_{格子， 决策} \geq  \lambda \times  \Delta finish_{格子， 决策}$$ <br>由于$$\Delta finish_{格子， 决策}$$的sign不是固定导致没法转换成f(格子， 策略) &gt; g($$\lambda$$)形式的决策公式 <br><br> | 原目标更适合作为治理评估指标，而不适合作为策略优化目标。在求解阶段采用“最大化完单”作为 proxy 目标，那么上面的问题迎刃而解： <br>1. 因为动调调度的决策空间（调价和调度司机组合的叉乘）关于**调价部分不会出现降价操作**，因此下发任何一个动调调度策略，假设完单不变的前提下，**都会使CR增加（呼叫降）**，因此，原目标中为了降低差供需时空的冒泡占比（提高差供需时空CR），可以转化成**最大化完单**。 <br><br>2. 策略直接作用于完单，将问题转化为max 完单，在求解阶段采用更连续、更稳定、且与原目标方向是一致的。 <br><br>3. 只需要大家不同时空不同treatment的完单模型即可，不需要像接原问题一样要预测多个模型； <br><br> <br>ps:【最大化完单】和【降低端内差供需时空下的冒泡占比】是同向变化的，但是完单最大化的解可能是【降低端内差供需时空下的冒泡占比】的次优解。 <br> <br> <br> |
