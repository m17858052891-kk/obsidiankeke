# 应答后换车怎么决策、怎么评估

司机已经应答，乘客还在等接驾。此时换车有两种理由：**另一位司机能更早到**，或者**原司机很可能不来接**。要评价换车，先认出是哪条策略触发，再把父单、子单串回乘客的同一次叫车。本文的阈值和实验结果按原版本记录。

## 顺着一笔需求看两条路

|           | 接驾远换车                                                    | 低接驾意愿换车                                                       |
| --------- | -------------------------------------------------------- | ------------------------------------------------------------- |
| 为什么找新司机   | 原司机接驾较远。比较继续等待与重新找车的预计等待，部分版本结合预估取消率。                    | 原司机拒接、停留、偏航等信号提示履约有风险。区分高风险直接干预与较低风险问询。                       |
| 谁决定       | 文档中有自动换和询问乘客两种产品形式。策略版本、是否连环派及风险档位会影响判定。                 | V1 高诱导由平台替乘客取消并重新发单；低诱导弹窗，乘客点换后才进入换车。未点换继续原单。此处「诱导」是策略输出的风险档。 |
| 找不到新司机怎么办 | 保留父单找更优司机的流程中，原司机继续接驾；新候选满足换车条件再交给新司机。还需检查找车期间父单被取消时的改派。 | 先取消重发的路径已经释放父单。子单未应答会留下新的流失，需单独记录。                            |
| 分析粒度      | 看乘客累计等了多久，同时看父子司机各自的接驾和空驶。                               | 看风险命中、自动或问询、乘客点换、子单应答、最终完单，以及误换与司机体验。                         |

历史梳理记录两类策略各自轮询、先命中先执行。因此一单进入某一条分支，也要留意另一条策略是否原本有触发机会。[换车流程和产品形式](04%20换车%20·%20接驾风险、实验与误伤.md#^eco-2206125519934) · [接驾远换车版本与改派问题](https://cooper.didichuxing.com/knowledge/2199610335356/2206104789270)

## 低接驾意愿从规则演进到碰面保护

| 版本 | 当时解决的问题 | 复盘时要保留的区别 |
|---|---|---|
| V0 原规则 | 看拒接或失联、司机 IM 要求取消、停留在抢单点三类信号。 | 原规则一旦命中就可能改变原单取消状态。直接把该状态当作模型预测正确会高估效果。 |
| MVP，V1 的规则部分 | 扩展 IM、偏航、异常停留、提前点击到达、到达后走远和接驾速度慢等信号，多个场景同时命中时取高风险。 | 线上 V0 与新增模块并存时，V0 命中优先。评估「MVP 增量」只统计 V0 未先命中的部分。 |
| V1 模型与规则 | 按可配置时间轮询。模型结合接驾轨迹、司乘联系与 IM 文本、司乘和供需特征，分别输出取消和司机低意愿风险。新增模块内，MVP 规则或模型任一达到高风险就输出高风险，其次才是低风险。 | 历史联合阈值按「低意愿分、取消分」排列：问询档 (0.25, 0.13)，直接换档 (0.42, 0.13)。事件触发是方案中的后续优化。原有 V0 的优先级与新增模块内部的优先级要分开看。 |
| V2 碰面保护 | 路口、马路对面或刚驶过上车点，司机可能已在乘客眼前。该版针对 V1 高风险直接换车的误伤。技术方案列出三项碰面条件，任一命中即可：司乘直线距离 ≤100 米、司机距起点直线距离 ≤100 米、司乘导航距离 ≤120 米。缺哪项特征，该项就不命中。 | 文末针对第一项最终选定 100 米。表内 50 米对应离线影响面测算。其余两项是否按草案上线、100 米版本上线后减少多少误换，原页均未报告。 |

V1 训练材料记录了 2025-07-05 至 07-11 约 400 万笔去重应答订单、1,600 万条轮询样本，按去重订单 4∶1 随机切分。低意愿标签来自判责结果或乘客取消原因勾选。复用这批结果应保留两层区分：第一次和最后一次轮询掌握的信号不同，同一订单的多次轮询也不能当成多笔独立出行。[规则与离线测算](04%20换车%20·%20接驾风险、实验与误伤.md#^eco-2204699277404) · [V1 模型与训练口径](04%20换车%20·%20接驾风险、实验与误伤.md#^eco-2205174551833) · [V1 策略与联合阈值](04%20换车%20·%20接驾风险、实验与误伤.md#^eco-2205271536563) · [V2 路口误伤复盘](04%20换车%20·%20接驾风险、实验与误伤.md#^eco-2206459842171)

## 看实验时先对齐分母和对照组

| 实验 | 比的是什么 | 可以带走的结论 |
|---|---|---|
| MVP 规则，07-24 至 08-06 | 空白、V0、V0 + MVP 三组。以下业务结果是新增 MVP 相对 V0。 | 成交率显著 +0.11 个百分点，应答后乘客取消率显著 −0.09 个百分点，人均完单 +0.03%、不显著。按抽单外推，新增命中的诱导精确率 64.89%、召回率 19.09%。 |
| V1，2025-08-30 至 09-12 | 在乘客被应答时按乘客分流，模型加原规则 40%、原规则 40%、空白 20%。下列数字均比较前两组。 | 在含改派应答单中，触发率由 1.05% 升至 3.99%。归一最终乘客取消率显著 −1.20 个百分点，成交率在自营与宏鹄显著 +0.37 个百分点，在小猪端全运力显著 +0.51 个百分点。除呼叫量和特别标注的指标外，原评估默认统计端内自营与宏鹄。 |

**同一个实验会同时看到大盘改善、子单履约变差。** V1 相对原规则，换车子单应答后乘客取消率 +3.80 个百分点、司机取消率 −1.76 个百分点、完单率 −1.93 个百分点。高低风险命中的范围都扩大了，进入子单的订单来自不同的筛选过程，因此这组三个数本身无法说明由谁换车会使同一笔订单更难履约。复盘时分别记录“全部原始需求最后完成多少”和“进入子单的这批需求在哪一步流失”。V1 原页的部分准召数字与文字方向矛盾，“诱导换车占比”的两组数与所列百分点差也不一致，引用这些明细前应回到原始抽单或报表重算。[MVP 实验结果](04%20换车%20·%20接驾风险、实验与误伤.md#^eco-2205022407650) · [V1 乘客分流实验](04%20换车%20·%20接驾风险、实验与误伤.md#^eco-2205442333239)

## 复盘时沿五步找损失

1. **进入接驾。** 以首次应答开始计时，标记接驾远或低意愿、命中时间和版本。拆直接换、问询和未触发，只有问询组有“乘客点换率”。
2. **执行换车。** 保留是否弹窗、是否点换、父单保留或释放、是否生成子单、子单是否应答和进入履约。区分乘客主动取消重发、平台替乘客取消换车和司机取消改派。
3. **回到乘客。** 用 `origin_order_id` 归一，取最后一单状态。归一最终乘客取消率的分母是归一应答订单。累计应答后等待从首次应答计到最终取消或开始计费，跨越中间的父子单。再核对最终完单、司机取消中等待超 10 分钟的占比及诱导相关投诉。
4. **回到司机。** 核查原司机释放时点、新司机接驾耗时、原司机是否已抵达或接近乘客。历史接驾远实验曾遇到 ETA 接口不准、连环派 ETA 判近错误，以及子单发出后 15 秒内父单被司机取消无法改派。判定模型或阈值效果前要排除这些执行问题。[接驾远历次实验](https://cooper.didichuxing.com/knowledge/2199610335356/2206104789270)
5. **估计避免了多少诱导。** 成功换车后，原司机本来会怎么做已无法直接观察。文档在三组“未换车且乘客取消”的订单中抽单人工标注，按抽样比例还原到相同订单规模，再比较残余诱导量；估计命中真阳性时还要计回点换但未换成的诱导样本。V1 人判外推的诱导／应答占比分别为 0.77%（实验）、1.74%（原规则）、2.02%（空白）。这套设计可借给预分单和升舱，用来判断策略动作改变了哪些可观察的标签。[抽单评估方法](04%20换车%20·%20接驾风险、实验与误伤.md#^eco-2204959891717) · [V1 抽单结果](04%20换车%20·%20接驾风险、实验与误伤.md#^eco-2205442333239)

## 查特征与后续探索

策略特征入口是 `kflower_strategy.hxz_picking_up_induce_dri` 与 `kflower_strategy.hxz_picking_up_induce_pas`，适合从单笔异常回到当时可见的司机、乘客侧信号。另有一份编辑态草稿按司机杀端持续时长回放阈值：在其 SQL 已限定的杀端时长大于零的样本内，60 秒档触发 4,543 单，最终取消率 79.2%，正常单误换占样本 6.3%。它说明延长阈值会同时改变覆盖和误伤；原页线上实验栏为空。[版本总览、工程和数据入口](04%20换车%20·%20接驾风险、实验与误伤.md#^eco-2206519902552) · [杀端阈值离线测算草稿](04%20换车%20·%20接驾风险、实验与误伤.md#^eco-2209603779180)
