# 营销因果决策论文精读

这两篇论文回答同一条下游问题：预测到 uplift 后，怎样在预算约束下真正分配营销资源。

1. [[自动出价论文精读/出价因果决策论文精读/01_DFCL：怎样让因果预测直接服务营销资源分配|01_DFCL：怎样让因果预测直接服务营销资源分配]]：把“预测误差最小”改为“决策效果更好”，直接学习服务资源分配；
2. [[自动出价论文精读/出价因果决策论文精读/02_Bi-DFCL：怎样用RCT与OBS共同优化营销决策|02_Bi-DFCL：怎样用RCT与OBS共同优化营销决策]]：在 DFCL 上进一步结合 OBS 的规模与 RCT 的可信因果锚点。

阅读前提：先掌握 [[知识体系/04-因果推断/04-CATE：从元学习到表示学习|01_Uplift基础、识别与策略学习]] 的 estimand、OPE 与预算约束，再理解 [[ecr/项目指标：AUCC与MTAUCC|02_Uplift评估与模型选择]] 的离线验证边界。

闭环是：**估计个体增量 → 在约束下形成策略 → 以决策损失训练/筛选 → 用 RCT 评估和校正。**
