# 时间与空间复杂度

时间复杂度描述算法的运行时间如何随输入规模 $n$ 增长；空间复杂度描述算法额外占用的内存如何随 $n$ 增长。它们关注的是增长趋势，而不是某台机器上的实际秒数或字节数。

## 1. 时间复杂度怎么计算

基本步骤：

1. 确定输入规模 $n$。
2. 找出执行次数最多的核心操作。
3. 写出操作次数关于 $n$ 的表达式。
4. 忽略常数、系数和低阶项，用大 $O$ 表示。

例如：

```python
for i in range(n):
    print(i)
```

循环执行 $n$ 次，因此：

$$
T(n)=n=O(n).
$$

### 顺序执行：复杂度相加，保留最高阶

```python
for i in range(n):       # O(n)
    pass

for i in range(n * n):   # O(n^2)
    pass
```

$$
O(n)+O(n^2)=O(n^2).
$$

### 嵌套循环：复杂度相乘

```python
for i in range(n):
    for j in range(n):
        pass
```

内外层分别执行 $n$ 次，总操作数为 $n\times n=n^2$，所以时间复杂度是 $O(n^2)$。

注意，嵌套循环不一定都是 $O(n^2)$：

```python
for i in range(n):
    for j in range(i):
        pass
```

总操作数为：

$$
1+2+\cdots+(n-1)=\frac{n(n-1)}2=O(n^2).
$$

### 每次将问题规模减半：$O(\log n)$

```python
while n > 1:
    n //= 2
```

假设执行 $k$ 次后结束，则：

$$
\frac{n}{2^k}=1
\quad\Rightarrow\quad
k=\log_2 n.
$$

因此时间复杂度是 $O(\log n)$。大 $O$ 表示中通常不写对数底数，因为不同底数之间只相差常数倍。

### 条件分支：通常分析最坏情况

```python
if condition:
    linear_operation()       # O(n)
else:
    quadratic_operation()    # O(n^2)
```

最坏时间复杂度为 $O(n^2)$。如果题目明确要求平均复杂度，则需要结合不同分支出现的概率计算期望。

## 2. 递归复杂度

递归算法通常先写递推式，再分析递归深度和每层工作量。

### 二分查找

$$
T(n)=T(n/2)+O(1).
$$

问题规模每次减半，共有 $O(\log n)$ 层，因此时间复杂度为 $O(\log n)$。

### 归并排序

$$
T(n)=2T(n/2)+O(n).
$$

递归树共有 $O(\log n)$ 层，每层合并操作的总工作量为 $O(n)$，所以：

$$
T(n)=O(n\log n).
$$

### 普通递归斐波那契

$$
T(n)=T(n-1)+T(n-2)+O(1).
$$

它会重复计算大量子问题，时间复杂度约为 $O(2^n)$；加入记忆化后，每个状态只计算一次，可降为 $O(n)$。

## 3. 空间复杂度怎么计算

空间复杂度通常指算法使用的**额外空间**，不包含输入数据本身。主要考虑：

- 局部变量；
- 新创建的数组、哈希表、矩阵等数据结构；
- 递归调用栈。

### 固定数量的变量：$O(1)$

```python
total = 0
maximum = 0
```

无论 $n$ 多大，都只使用固定数量的变量，所以额外空间复杂度为 $O(1)$。

### 长度为 $n$ 的数组：$O(n)$

```python
result = [0] * n
```

新数组随输入规模线性增长，因此空间复杂度为 $O(n)$。

### $n\times n$ 矩阵：$O(n^2)$

```python
matrix = [[0] * n for _ in range(n)]
```

矩阵共有 $n^2$ 个元素，所以空间复杂度为 $O(n^2)$。

### 递归调用栈

```python
def f(n):
    if n == 0:
        return
    f(n - 1)
```

递归深度为 $n$，每层需要保存一次函数调用，因此栈空间为 $O(n)$。二分查找的递归深度是 $O(\log n)$，所以递归版本会额外使用 $O(\log n)$ 的栈空间。

## 4. 常见复杂度速查

| 场景 | 常见复杂度 |
|---|---:|
| 固定次数操作 | $O(1)$ |
| 每次将规模减半 | $O(\log n)$ |
| 单层完整遍历 | $O(n)$ |
| 分治且每层处理全部数据 | $O(n\log n)$ |
| 两层完整嵌套循环 | $O(n^2)$ |
| 枚举所有子集 | $O(2^n)$ |
| 枚举所有排列 | $O(n!)$ |

常见增长速度从快到慢（性能从好到差）为：

$$
O(1)<O(\log n)<O(n)<O(n\log n)<O(n^2)<O(2^n)<O(n!).
$$

## 5. 面试中的分析模板

可以按照下面的顺序回答：

1. 令输入规模为 $n$。
2. 说明核心操作执行了多少次。
3. 忽略常数和低阶项，得到时间复杂度。
4. 列出额外数据结构和递归深度，得到空间复杂度。
5. 明确说清分析的是最坏、平均还是最好情况，以及空间复杂度是否包含输入。
