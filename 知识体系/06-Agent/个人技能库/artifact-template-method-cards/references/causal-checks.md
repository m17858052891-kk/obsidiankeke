# 因果效应检验图的内容核验

只在当前主题涉及 uplift、CATE、平均响应、DR 或 R-risk 时使用。此文件沉淀易错点，不规定所有项目必须采用原图的评估实现。

## 先确认评估目标

- 事实响应：实际分到 a 档的样本，预测均值与实际结果均值比较。
- 潜在响应：在同一目标样本上，对全部样本假设给 a 档，比较预测平均响应与 DR 等估计参照。DR 不是真值；若其结果模型就是被评估模型且倾向概率固定，该偏差与事实响应偏差可能等价或近似重复，不渲染成独立证明。
- 平均因果增量：同一目标样本中 a 相对基准档的平均效应；不要用不同实际组的模型均值之差冒充同一人群的预测 ATE。
- 个性化效应：模型估计的是条件平均处理效应，不是已观测到的每个个体真实因果效应。

## 四类人群检验各自说明什么

1. 分组效应校准：按预测 CATE 分箱，组内预测平均效应与实验/DR 参照比较。不是随机分组；不能把组内总体均值准确描述成每人效应准确。RMSE 的分母、权重、跨档聚合需与实现一致。
2. 方向与幅度：含截距回归 psi = c + s*tau_hat + error。s 的区间下界大于 0 支持整体正向线性关系；0<s<1 表示线性意义下预测差距偏大，s>1 表示差距偏小；理想线性校准为 c=0、s=1。区间包含理想值不等于证明完全校准，不能只看斜率漏掉截距。散点纵轴为带噪声的 DR 效应伪标签，不标成“真实个体效应”。
3. 高低响应区分：按预测效应选高/低组，使用效应参照计算高减低；不能用两组原始完单率差代替效应差。Top/Bottom 比例按项目实际约定，图形比例与文字一致。
4. 个性化增量价值：同一评估样本、同一套辅助预测下，Delta R = R_global - R_personalized。全局基线是每个非基准档各自一个固定效应，不是所有档位同一个值，也不是固定绝对完单率。正差值表示损失降低，区间下界大于 0 才是相应显著性判据；不写成完单率或利润已提升。基线拟合口径有来源才写，否则标为建议。

## 公式与数据范围

DR 响应伪标签：phi_ia = q_a(X_i) + 1(T_i=a)/e_a(X_i) * (Y_i-q_a(X_i))；效应伪标签 psi_ia = phi_ia-phi_i0。

多档位 R-risk：mean_i[(Y_i-m(X_i)-sum_{a!=0}(1(T_i=a)-e_a(X_i))*tau_a(X_i))^2]。

- m(X) 是当前分档机制下 E[Y|X]，不是基准档响应 mu_0(X)。
- 全档联合评估与仅 a/基准档两组评估不能混用：筛两组时，分配概率和混合结果模型须对应两组条件分布。
- 区分训练内部辅助模型的交叉拟合与完整效应模型的折外评估。独立测试集和完整 OOF 是两种评估设计，不称作同一固定模型扩大测试集。
- 重复乘客数据可采用乘客级切分与聚类 bootstrap；是否采用、是否调整多重检验必须查原始方案，不凭参考图认定做过。
- RCT 中已知随机分配概率可直接使用；观察数据中的残差化不能自动消除未观测混杂或缺乏重叠的问题。
- 不把同一指标改称后重复算作新增验证证据；总体均值、分组校准、排序和整体效应损失不是相互替代的结论。
