# 论文来源与获取策略

论文来源分为“正文/版本来源”“会议与期刊正式来源”“发现与元数据来源”“代码来源”。播报中的论文链接优先指向正文或正式出版页面；发现网站不能替代正文证据。

## 一、正文与版本来源

按以下顺序尝试：

1. **arXiv**：机器学习、推荐、广告和仿真方向的预印本、版本历史、摘要和 PDF。记录 arXiv ID，并优先使用论文的稳定 `abs` 页面；如需复现实验，确认引用的是哪个版本。
2. **OpenReview**：ICLR、部分 NeurIPS/ICML 及其他使用 OpenReview 的会议或期刊。记录论文状态（submitted/accepted/published）以及 PDF 页面；评审意见只作为补充证据。
3. **正式出版页面**：会议或期刊官网、PMLR、NeurIPS Proceedings、JMLR、ACL Anthology、ACM Digital Library、IEEE Xplore、AAAI Digital Library 等。优先使用正式版本；若只能访问摘要或付费墙，明确标记全文未核验。
4. **作者项目页或机构仓库**：仅当正式页面或 arXiv 没有可访问全文时使用，并记录它是作者版本还是最终出版版本。

## 二、每日核心召回与去重

每天对同一组检索词并行查询三个核心来源：OpenAlex、Crossref、arXiv。arXiv 提供新近预印本和正文线索，OpenAlex 负责广泛召回、摘要与引用元数据，Crossref 负责 DOI 和正式出版元数据补全。跨源候选依次按 arXiv ID、DOI、规范化标题合并。

OpenAlex、Crossref 的元数据不能单独支撑“方法有效”“有消融”或“可复用模块”等结论；正文仍需回到第一节的来源。

## 三、代码与复现来源

优先链接论文作者或实验室的官方 GitHub/GitLab 仓库；其次是论文页面直接指向的代码仓库。Papers with Code 可用于发现实现和 benchmark，但不作为代码归属或结果真实性的唯一证据。记录 commit/tag（若可获得），不要只保存仓库首页。

## 四、并行检索范围

每个周期至少分别执行两组检索，再合并去重。不能只从自动出价关键词出发。

### 用户侧价格与激励检索

覆盖网约车/出行市场中面向乘客的动态报价、fare、surge、券、折扣与激励，以及接受/拒绝/取消/完单、需求弹性、收益管理、序列决策和预算约束。营销 uplift、用户处理分配和资源分配作为相邻补充召回；广告自动出价、merchant bidding 和拍卖支付不作为常规召回方向。

### 仿真与数据检索

覆盖用户/请求/会话生成、乘客选择与状态转移、价格响应、接受/拒绝/取消/延迟转化/复购、合成用户轨迹、历史日志回放、反事实数据、离线策略评估、响应模型校准和 sim-to-real。检索时排除以 individual vehicle、driver dispatch、matching、rebalancing、fleet sizing 或 traffic network 为核心的论文；供需与等待可作为聚合上下文保留。

两组候选使用同一套论文级评分。某篇论文只贡献于用户侧仿真与数据，不需要同时包含定价模型；某篇营销/广告论文则必须额外通过“平台对用户动作”迁移检查。

## 五、内部来源记录

每篇入选论文及其模块在内部记录中至少保存：

- `paper_url`：正文或正式出版页面；
- `paper_version`：arXiv 版本、会议版本或作者版本；
- `code_url`：官方代码或 `unknown`；
- `source_type`：`preprint`、`openreview`、`published`、`author_copy`；
- `evidence_type`：`paper_claim`、`measured_run`、`inference` 或 `unverified`；
- `access_note`：全文不可访问、版本不一致、代码缺失等限制。

同一论文若同时有 arXiv 和正式版本，保留两个链接但只建立一个 `paper_id`。正式版本用于引用，arXiv 用于版本追踪；不要把同一论文重复计入增量播报。

群播正文只在论文标题处内联论文链接，并在确有官方实现时附代码链接。不要单列“来源与不确定性”章节，也不要把版本号、来源类型、访问限制和证据类型堆到群消息里。只有当来源问题会使论文无法入选时，才在筛选阶段排除；具体理由留在内部记录。

## 六、定时运行规则

工作日定时扫描使用可重叠的滚动日期窗口：先合并 OpenAlex、Crossref、arXiv 三源结果，再和持久化论文历史去重，只对首次发现的论文评分。论文通过日期核验、目标问题相关性、网约车场景迁移、方法清晰度、证据强度和信息增量筛选后即可进入播报；不要再用“是否能映射到既有锚点”或“单个模块是否立即有用”作为二次门槛。合格论文不设固定数量上限；没有新的合格模块时保持群静默，但保留检索和筛选状态供以后查重。
