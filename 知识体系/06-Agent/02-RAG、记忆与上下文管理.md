# RAG、记忆与上下文管理

先修：[[知识体系/03-LLM/01-分词、自回归与语言建模|分词与语言建模]]、[[知识体系/06-Agent/01-Agent：状态、工具与控制循环|Agent状态与工具循环]]。RAG 的问题是如何在生成时提供相关证据；记忆管理的问题是哪些历史信息值得保存、何时读取、何时作废。二者有交集，但不能用“接一个向量库”概括。

## 1. 参数知识与外部证据

语言模型权重存储经过训练压缩的规律，难以直接追溯每条事实来源；外部文档可更新、引用并按权限检索。RAG 将外部信息与生成结合，原始研究还讨论对检索文档作概率边缘化的训练框架。[RAG 原论文](https://arxiv.org/abs/2005.11401)

工程中常见的 retrieve-then-read 并不一定联合训练。可概括为先选择证据集合 $D_q$，再生成 $p_\theta(y\mid q,D_q)$。只有证据被找对、读对且答案遵循证据，最终结论才可靠。

## 2. 检索链路中的错误可以逐层定位

文档解析 → 分块 → 索引 → 查询构造 → 候选召回 → 重排 → 上下文组合 → 生成与引用。错误可能发生在任何一层：表格列对齐丢失、公式被拆碎、检索偏向旧版本、重排漏掉反证、生成器忽略适用条件。

例如问“某实验提升是否显著”，只检索到汇报标题“提升 3%”不足以回答。还需要样本量、方差、实验单位、指标口径与时间。查询改写应表达缺失证据，而非仅重复原问题的同义词。

## 3. 稀疏、稠密与重排为何互补

稀疏检索利用词项匹配，适合精确术语、编号和罕见实体；稠密检索用向量相似性捕捉表述接近，但可能把“否定、例外、版本号”区分不够。两者都依赖文本解析与查询信息。

双塔分数常为 $s(q,d)=f(q)^\top g(d)$，文档可预编码，适合大候选池。Cross-encoder 将问题与文档共同输入，更充分建模交互，但难以预计算全部配对，因此常用于较小候选集重排。具体表示与负采样见 [[知识体系/07-检索与推荐/01-检索：表示、负采样与ANN|检索表示与负采样]]。

融合时不能直接相加未经校准的不同量纲分数。基于排名的融合或训练式融合有各自假设；检索到同一来源的重复段落也不等于获得独立证据。

## 4. Chunk 大小是在语义完整与定位精度间取舍

太小会把结论与前提、表头与数值、定义与公式分开；太大则向量被多个主题混合，占用上下文且影响精确定位。固定 token 长度可以作为基础，但应结合标题、段落、表格和代码结构。

可用小块检索、父段扩展阅读的方式兼顾定位与上下文。重叠块改善边界信息，却增加重复召回；需要去重与来源标识。没有一个适合所有文档的最佳 chunk token 数。

对你的知识库，章节标题、先修关系和项目证据链接本身就是可检索元数据。通用原理与某次实验结果分开存放，能避免模型把历史项目结论误当成领域定律。

## 5. 长上下文不等于有效记忆

能容纳很多 token，不保证模型能同样可靠地使用其中任意位置的信息。历史研究观察到证据位置影响任务表现；具体程度依模型和任务变化，不应把早期结果当所有新模型的固定曲线。[Lost in the Middle](https://arxiv.org/abs/2307.03172)

上下文预算 $B$ 下，可把选择问题理解为：在总长度限制内选择一组有用、非冗余且符合权限的证据。单独对每块相关性排序会忽略互补性：一个给出结论，另一个给出限定条件，二者一起才完整。

摘要会压缩信息，也会丢掉细节或引入误差。好的摘要保留可回溯的来源、关键数字、单位、否定条件与待确认事项；需要精确引用时重新读取原文，不用摘要代替原始证据。

## 6. 记忆需要区分生命周期

短期工作记忆保存当前目标、执行进度与最近观察；长期偏好记忆保存稳定且有依据的用户偏好；知识记忆保存可复用事实及来源。临时猜测不应悄悄升级为长期事实。

更新策略应考虑时间、冲突和来源权威：新结果可能推翻旧结论，也可能只适用于不同实验条件。最好保留“哪一次、什么条件下成立”，而不是让一条最新文字覆盖所有版本。

缓存答案还需考虑失效：源文件变化、权限变化或问题语义变化，都可能使缓存不再可用。相似问题并不总能共享答案，特别是日期、主体或约束发生变化时。

## 7. 如何分开评估检索和生成

检索侧看目标证据 Recall@k、排序与多跳证据覆盖；生成侧看结论正确性、证据忠实性、引用定位、遗漏条件和无答案时行为。最终任务成功率才是整个链路指标。

可以做一个有解释力的对照：用人工确认的证据输入生成器。如果仍错，问题更多在阅读、推理或生成；若明显好转，则应检查召回、重排与上下文组合。再加入无关文档或冲突版本，观察鲁棒性，能比只看平均答案分数更容易定位问题。

引用存在不等于引用支持。必须检查文档是否真的陈述对应主张、适用范围是否一致，以及答案是否从多个弱证据推到过强结论。

## 8. 自检与解析

**问：RAG 能消除幻觉吗？** 不能。检索错误、证据过时、阅读错误与无依据补全都仍可能出现；它提供证据通道而非正确性保证。

**问：top-k 越大越好吗？** 不一定。召回可能提升，也增加噪声、冲突和上下文成本。应看任务所需证据覆盖与生成表现。

**问：向量相似度高能证明两段结论一致吗？** 不能。相似主题中可能包含反驳、否定或不同实验条件，必须读取语义和来源。
