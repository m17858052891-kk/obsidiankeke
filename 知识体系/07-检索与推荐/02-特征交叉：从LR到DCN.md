# 特征交叉：从 LR 到 DCN

先修：[[知识体系/01-统计与优化/02-似然、交叉熵与KL|似然、交叉熵与KL]]、[[知识体系/02-神经网络与Transformer/01-反向传播、初始化与残差|反向传播与残差]]。特征交叉回答“一个特征的作用是否依赖另一个特征”。模型差别在于怎样参数化交互，以及如何在稀疏数据中共享信息。

## 1. LR 的线性是对 log-odds 而言

二分类 LR 使用 $p=\sigma(w^\top x+b)$，所以 $\log[p/(1-p)]=w^\top x+b$。若没有显式交叉，某维特征对 log-odds 的增量固定；对概率的影响仍因 sigmoid 非线性和其他特征而变化。

要表达“周末对某类商品的作用更强”，可加 $x_{weekend}x_{category}$ 项。显式枚举所有组合会迅速增加参数和稀疏性。LR 的限制是所选特征空间中的线性结构，不是完全不能表达非线性规律——特征映射本身可以复杂。

## 2. FM 用低秩共享二阶交互系数

二阶 FM：

$$\hat y=w_0+\sum_iw_ix_i+\sum_{i<j}\langle v_i,v_j\rangle x_ix_j.$$

每个特征的向量 $v_i$ 被其所有交互复用。即使某对特征一起出现次数很少，也能借助两者在其他组合中的数据估计其内积。但这也施加了低秩兼容结构，不能表示任意独立二阶系数。[FM 原论文](https://jame-zhang.github.io/assets/algo/Factorization-Machines-Rendle2010.pdf)

逐维展开可得：

$$\sum_{i<j}\langle v_i,v_j\rangle x_ix_j
=\frac12\sum_{f=1}^k\left[\left(\sum_iv_{if}x_i\right)^2-\sum_iv_{if}^2x_i^2\right].$$

平方包含所有 $(i,j)$ 有序对，减去对角项后每对出现两次，故乘 $1/2$。计算从显式两两交互的 $O(d^2k)$ 化为 $O(dk)$；稀疏输入可按非零特征数计。

## 3. DeepFM 与 MLP 的交互方式

DeepFM 将 FM 与深层网络组合，常共享底层 embedding：FM 强化二阶结构，DNN 通过非线性组合学习更复杂关系。[DeepFM](https://arxiv.org/abs/1703.04247)

“显式”指交互形式在结构中可写出，不代表每个 learned embedding 维度都有可读业务含义；“隐式”也不代表 MLP 无法表达某阶交叉。差别更多在归纳偏置、参数效率、优化和数据需求。

共享 embedding 还使两条损失路径的梯度相互影响，不是两个模块完全互不干扰。是否改善应在相同数据和参数预算下检验。

## 4. DCN v1 的结构约束应该怎样说

Cross 层为：

$$x_{l+1}=x_0(w_l^\top x_l)+b_l+x_l.$$

交互增量 $x_0(w_l^\top x_l)$ 是输入向量乘一个输入相关标量，所以该增量与 $x_0$ 平行。但**完整输出还包含偏置和残差**，不能无条件说输出方向永远不变。

忽略偏置且从 $x_l=x_0$ 开始，可以归纳输出为 $x_0$ 乘多项式标量；它仍生成交叉项，只是系数结构受约束。叠 $L$ 个无额外非线性的 cross 层，最高多项式阶数可到 $L+1$，不是每层阶数翻倍。

## 5. DCN v2 用矩阵扩展交互自由度

常见矩阵 cross 形式：

$$x_{l+1}=x_l+x_0\odot(W_lx_l+b_l).$$

每个输出维度可使用不同的线性组合与 $x_0$ 对应维相乘。第一层第 $i$ 维包含 $\sum_jW_{ij}x_ix_j$，比共享一个标量具有更灵活的交叉系数。[DCN v2](https://arxiv.org/abs/2008.13535)

$W_l$ 参数量为 $d^2$；低秩参数化 $W\approx UV^\top$ 将主要参数与乘法降为约 $2dr$，但 rank 变小会限制表示能力。它不是无需代价地同时获得全矩阵自由度和向量复杂度。

DCN v2 还讨论低秩专家混合等扩展；DCN-Mix 是相关变体，不应把 v2 与 Mix 视为完全同义。一般矩阵变换包含缩放、剪切、投影等，也不能一律描述成“旋转”。

## 6. 串联、并联改变信息和梯度路径

并联把 cross 与 deep 输出拼接后预测；串联让 cross 输出再进 deep 网络。前者给最终层两种表征，后者让后续非线性处理交叉结果。二者没有脱离任务的普适优劣。

参数量、激活、交互层数和训练设置都需对齐。三层百万参数矩阵是否超过延迟预算取决于硬件和服务负载，不能直接称为“必然压垮服务器”。

## 7. GBDT 是另一种交互归纳偏置

一条树路径连续按多个特征分裂，表达分段条件交互；梯度提升依次拟合损失的负梯度方向。将叶 ID 作为 LR 特征，是先由树构造分区再线性组合。

树擅长处理某些表格阈值关系，但对高基数稀疏 ID、复杂序列与向量共享需求，代价和泛化方式不同。模型比较应联系数据结构，而不是按“深度越大越先进”排序。

## 8. 自检与解析

**问：FM 没见过某对特征一起出现，如何估交互？** 两个 embedding 在各自其他组合中获得训练，内积可泛化；可靠性仍取决于共享结构是否适合。

**问：DCN v1 的交互增量平行于输入，是否完全没用？** 不是。标量依赖输入，能产生多项式交叉；限制在系数结构，不是没有非线性。

**问：显式 cross 能否取代序列模型？** 不能直接等同。静态特征交叉与序列信息流关注不同结构，下一章讨论后者。
