# 多任务、排序与约束决策

先修：[[知识体系/02-神经网络与Transformer/01-反向传播、初始化与残差|反向传播与残差]]、[[知识体系/01-统计与优化/01-条件期望、估计目标与预测|条件期望与估计目标]]。训练多个预测任务、对候选排序、在约束下决策属于不同层次。把它们分清，才能解释 loss 权重和线上权重为什么不能互相替代。

## 1. 标签空间先于网络结构

CTR 是曝光条件下点击概率，post-click CVR 是点击条件下转化概率；在转化必须经过点击的定义下：

$$P(C=1,V=1\mid x)=P(C=1\mid x)P(V=1\mid C=1,x).$$

这是链式法则，不需要假设点击与转化独立。未点击曝光的联合点击转化标签可为零，但“假如点击后的转化标签”不能简单当作观察到的 CVR 负例。延迟转化还需要明确成熟窗口。

ESMM 利用全曝光空间的 CTR 与 CTCVR 监督连接 CVR 分支，缓解直接在点击样本上训练的部分问题。其概率分解与共享结构不意味着所有选择偏差、不可识别区域和模型错设自动消失。[ESMM](https://arxiv.org/abs/1804.07931)

## 2. 多任务负迁移可以从梯度理解

总损失 $L=\sum_k\lambda_kL_k$，共享参数更新方向为 $-\sum_k\lambda_kg_k$。任务 $j$ 的一阶损失变化近似：

$$\Delta L_j\approx-\eta g_j^\top\sum_k\lambda_kg_k.$$

若某个 $g_j^\top g_k<0$，改善任务 $k$ 的方向可能局部伤害 $j$。但单次梯度夹角不是全程收益的完整描述，标签噪声、尺度、覆盖和模型容量都会影响它。

某任务样本多、损失数值大或梯度范数高，会占据更新；调整权重改变训练偏好，却不等于保证某个线上约束。

## 3. Shared Bottom、MMoE 与 PLE

Shared Bottom 所有任务共享一个表示再分头。MMoE 使用共享专家 $f_e(x)$ 与任务专属 gate：

$$h_k(x)=\sum_eg_{k,e}(x)f_e(x).$$

不同任务可选择不同混合，增加共享方式的灵活性；专家依然受多个任务梯度影响。[MMoE](https://research.google/pubs/modeling-task-relationships-in-multi-task-learning-with-multi-gate-mixture-of-experts/)

PLE 加入任务专属与共享专家并逐层提取。典型 CGC 中，任务 gate 读取自己的专属专家和共享专家；中间层的 shared gate 可以汇集各任务专属与共享专家，为下一层产生共享表示。不能写成“shared gate 只能看 shared experts”。最终任务层是否保留共享输出按具体实现决定。[PLE 原论文（RecSys 2020）](https://doi.org/10.1145/3383313.3412236)

这种结构提供更有选择性的路径，但不保证任意任务组合都比 MMoE 更好；额外容量、标签条件和优化成本也要比较。

## 4. Dense MMoE 与 sparse MoE 的“死专家”不同

标准 softmax 混合通常计算所有专家，低 gate 权重可能让某些专家贡献和梯度很弱，但不意味着它们没有被执行。稀疏 top-k MoE 才通常只把 token 派到少量专家，还涉及容量和 token 丢弃等问题。

因此处理 gate 塌缩应先看实现：记录权重分布、贡献、梯度与任务覆盖。熵正则或专家 dropout 可尝试，强制均匀又可能破坏专业化。不能把 LLM sparse MoE 的全部负载策略直接照搬到推荐 dense MMoE。

## 5. 多目标排序需要效用定义

假设模型输出点击、转化、时长和成本，线上 score 可能为加权效用或约束优化的解。权重反映业务价值、量纲与风险；不是从多任务 loss 权重自动推导出来。

预测概率用于 $p\times value$ 时，校准非常重要。两个模型排序相同但概率相差一倍，AUC 一样，却可能产生完全不同的出价与预算分配。见 [[知识体系/07-检索与推荐/05-评估、校准与实验|评估校准与实验]]。

Pareto 最优表示无法在不损害其他目标的前提下改善一个目标；它不指定唯一最佳点。选择哪一点仍需要价值判断和约束。

## 6. 约束优化从拉格朗日形式看

若最大化收益 $E[R]$，要求成本 $E[C]\le B$，可构造 $E[R]-\lambda(E[C]-B)$。固定 $\lambda$ 时策略权衡收益与成本；再根据预算满足程度调节对偶变量。

但固定惩罚不等于逐次动作满足硬约束。总预算、单用户频控、库存和体验限制可能需要可行性过滤或明确状态。预算跨时间消耗时，还与 [[知识体系/05-强化学习/01-MDP与Bellman|MDP与Bellman]] 的机会成本相连。

出价响应或补贴响应的预测也不能直接代替干预效应。若想知道“提高出价/加券”带来多少额外收益，需要 [[知识体系/04-因果推断/05-评估、策略学习与序贯因果|因果评估与策略学习]] 的识别与评估。

完整推导见 [[知识体系/01-统计与优化/05-约束优化：拉格朗日、对偶与KKT|拉格朗日、对偶与KKT]]。固定候选的分配、在线消耗控制与延迟反馈分别见 [[知识体系/08-预算分配与反馈控制/02-静态预算分配：背包、边际收益与影子价格|静态分配]]、[[知识体系/08-预算分配与反馈控制/05-在线对偶更新与预算消耗节奏|在线对偶]]、[[知识体系/08-预算分配与反馈控制/06-延迟、噪声、限幅与抗积分饱和|延迟与限幅]]；它们和训练时的多任务 loss 权重属于不同决策层。

## 7. 自检与解析

**问：任务 A 提升、任务 B 下降，先换 PLE 吗？** 先检查标签定义、采样、损失尺度、泄漏和评估分布，再判断是否为共享结构问题。

**问：MMoE gate 很集中就一定坏吗？** 不一定，专业化也会集中。关键是是否长期浪费容量、弱化任务或导致不稳定，而非每个样本都均匀。

**问：训练时提高 GMV loss 权重，就能保证线上 GMV 最大吗？** 不能。训练优化预测目标，线上决策还受候选、校准、成本、用户反馈和约束影响。
