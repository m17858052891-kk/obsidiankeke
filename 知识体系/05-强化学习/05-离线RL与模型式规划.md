# 离线 RL 与模型式规划

先修：[[知识体系/05-强化学习/02-价值学习：MC、TD与Q-learning|价值学习与TD]]、[[知识体系/05-强化学习/04-PPO与SAC：约束与熵|PPO与SAC]]、[[知识体系/04-因果推断/05-评估、策略学习与序贯因果|因果评估与策略学习]]。离线 RL 只能使用已收集数据，核心困难是学习改进策略时会访问数据没有充分覆盖的状态动作。

## 1. 外推误差怎样被最大化放大

设日志在状态 $s$ 只尝试动作 A，真实回报为 1。网络因外推给未见动作 B 估值 10。策略选 B，并通过 $r+\gamma\max Q(s',a')$ 把这份虚高传播到之前状态。在线可以尝试 B 后纠错，离线没有这一步。

因此固定数据上的低 Bellman loss 可能与好策略无关：损失只约束观测动作，策略却专挑未约束区域的最大误差。更大模型可能改善泛化，也可能更灵活地利用空白，不能靠容量保证。

## 2. 行为克隆是重要的比较基线

Behavior cloning 最大化日志动作似然，学习 $b(a\mid s)$ 的近似。它不直接用奖励区分好坏轨迹，但无需依赖未知动作的 Q 外推。高质量示范数据下，它可能是很强的基线。

不足在于会模仿低质量行为，部署时状态偏离日志后也可能累积错误。离线 RL 试图利用奖励与轨迹结构超过行为策略，但需要让改进仍处在有证据支撑的范围。

## 3. BCQ、CQL、IQL 约束的是不同位置

BCQ 从行为模型生成候选动作并限制扰动，再在候选中比较价值，约束“策略可考虑哪些动作”。生成模型若不能覆盖有效行为，也会限制上限。[BCQ 原论文](https://arxiv.org/abs/1812.02900)

CQL 对价值施加保守正则。离散动作的一种代表形式为：

$$L_{CQL}=L_{TD}+\alpha E_s\left[\log\sum_a e^{Q(s,a)}-E_{a\sim D(\cdot\mid s)}Q(s,a)\right].$$

第一项倾向压低所有动作的聚合高值，第二项相对保护数据动作。其目的是减少策略利用未覆盖动作的乐观估计；理论下界有具体假设，不意味着训练后的每个 Q 都是逐点可信下界。[CQL 原论文](https://arxiv.org/abs/2006.04779)

IQL 用数据动作 Q 的上 expectile 拟合 $V$：

$$L_V=E_D[|\tau-1\{u<0\}|u^2],\quad u=Q(s,a)-V(s),\quad \tau>0.5.$$

较大的 $\tau$ 更强调高于当前 V 的数据动作价值；再以 $r+\gamma V(s')$ 更新 Q，最后用优势加权行为克隆提取策略。典型 actor 权重为 $\exp(\beta[Q-V])$，实际常截断以控制数值。[IQL 原论文](https://arxiv.org/abs/2110.06169)

Expectile 是非对称平方损失的解，不是分位数；分位数对应非对称绝对损失。IQL 避免在 critic 备份中直接查询当前策略的未见动作，但函数泛化和提取出的 actor 仍可能产生分布外行为，不能宣布彻底消除支持问题。

## 4. 集成分歧不是天然可信的不确定性

多个 Q 模型意见不同，可能提示认知不确定性；但共享数据、结构和错误归纳偏置时，它们也可能一致地错。取均值、最小值或方差惩罚是不同启发与假设。

特别要区分环境随机性与模型无知。一个充分观测但结果本来随机的动作，可有高回报方差却不代表模型缺乏数据；一个未见动作的单网络输出很稳定，也不代表可信。

## 5. 模型式 RL：把转移模型用于规划

学习 $\hat P(s'\mid s,a)$ 和 $\hat r(s,a)$，即可在模型中评估候选动作序列：

$$a_{0:H-1}^*=\arg\max E_{\hat P}\left[\sum_{t=0}^{H-1}\gamma^t\hat r(s_t,a_t)+\gamma^HV(s_H)\right].$$

MPC 每次规划一段，只执行第一步，再根据真实新状态重新规划。这样能不断用真实反馈纠正轨迹，但模型误差和终端价值误差仍然影响选择。

短 rollout 降低误差积累，却可能看不到长期收益；长 rollout 能规划更远，却更容易进入模型训练分布之外。模型预测一步准确，不代表多步模拟准确：预测误差改变下一步输入分布，再引发更多误差。[模型式策略优化中的短 rollout 思路](https://arxiv.org/abs/1906.08253)

## 6. 决策器会主动寻找模型漏洞

假设响应模型在高出价端错误预测极高转化，优化器就会反复选择那里。随机测试平均误差不高，也可能掩盖最优化会利用的局部错误。这是为什么仿真系统应关注候选策略访问区间，而不只是日志分布上的平均 MSE。

你的出价仿真材料可作为这个问题的案例：[[生成式出价-仿真系统/当前结论与下一步|当前结论与下一步]]、[[生成式出价-仿真系统/因果响应模型迭代记录|因果响应模型迭代记录]]。阅读时区分历史拟合结果、OOF/OOT 验证、支持区域和待验证假设，不能把模型内最优值当真实线上增益。

## 7. Return-conditioned 序列建模与 RL 的关系

Decision Transformer 将轨迹表示为回报条件、状态、动作序列，通过条件模仿生成动作。它不需要传统 Bellman 备份，但目标回报条件超出数据支持时，不保证模型能实现该回报；随机环境中的高回报轨迹还可能包含运气因素。

所以“把 return token 调高”不是策略改善的理论保证。它与价值方法的差异在于训练目标和泛化方式，而不是有没有使用 Transformer 就算一种更高级 RL。已有论文拆解：[[自动出价论文精读/01_Decision Transformer：RL怎样改写成序列建模|01_Decision Transformer：RL怎样改写成序列建模]]。

## 8. 离线评估为何仍是核心难题

Fitted Q Evaluation 固定待评策略做价值备份，IS/DR 通过行为概率校正，模型仿真通过转移模型估计。三者依赖不同形式的函数准确性和支持条件；多个指标一致能增加信心，但共同的数据盲区仍可能存在。

使用评估集反复调策略会造成选择偏差。应保留独立评估、做支持与敏感性诊断，并在可能时用受控交互检验。学习可以止于理解这些证据边界，不要求为了学习算法就进行真实高风险探索。

## 9. 自检与解析

**问：离线数据超过十亿条，为什么仍可能不能学新策略？** 数量不等于相关状态动作覆盖。若都来自狭窄确定策略，关键反事实仍缺失。

**问：CQL 越保守越好吗？** 不一定。过强惩罚可能压低真正好动作，退化为过度模仿；需要在支持、误差和改进之间权衡。

**问：模型式 RL 的模拟收益提高就能证明真实收益提高吗？** 不能。策略可能只学会利用模型误差，尤其在训练支持之外。
