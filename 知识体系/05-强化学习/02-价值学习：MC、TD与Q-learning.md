# 价值学习：MC、TD 与 Q-learning

先修：[[知识体系/05-强化学习/01-MDP与Bellman|MDP与Bellman]]。学习价值可以直接等到整段回报，也可以借用当前估计补全未来。后者称为 bootstrapping，是 TD 方法的核心。

## 1. Monte Carlo 与 TD 的目标差异

Monte Carlo 用实际完整回报 $G_t$ 更新：

$$V(S_t)\leftarrow V(S_t)+\alpha[G_t-V(S_t)].$$

在正确采样下 $G_t$ 是相应价值的无偏样本，但长轨迹会累积随机性，需要等到可获得回报时。TD(0) 用：

$$\delta_t=R_{t+1}+\gamma V(S_{t+1})-V(S_t),\quad V(S_t)\leftarrow V(S_t)+\alpha\delta_t.$$

它借用下一状态的估计，所以可以边走边学，通常降低目标方差，却带入 bootstrap 估计误差。这里的“偏差—方差”是目标估计的权衡，最终算法性质还取决于函数类与采样。

例：当前奖励 1，下一状态估值 4，$\gamma=0.9$，TD target 为 4.6。如果完整实现回报恰为 8，MC 与 TD 给出不同更新；这并不自动说明其中一方代码错了。

## 2. n-step return 在二者之间连接

$$G_t^{(n)}=\sum_{k=0}^{n-1}\gamma^kR_{t+k+1}+\gamma^nV(S_{t+n}).$$

更长的 $n$ 使用更多真实奖励，减少对近处 bootstrap 的依赖，同时包含更多轨迹随机性。真正终止后未来价值为零；如果只是采样器达到时间上限而任务仍继续，通常应保留正确 bootstrap。把 truncation 与 termination 混为一谈会低估长程价值。

## 3. SARSA 与 Q-learning：跟随谁的下一步

SARSA 使用实际下一动作：

$$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha[R_{t+1}+\gamma Q(S_{t+1},A_{t+1})-Q(S_t,A_t)].$$

若行为来自当前策略，它评估包含该策略探索行为的价值。Q-learning 使用：

$$Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha[R_{t+1}+\gamma\max_aQ(S_{t+1},a)-Q(S_t,A_t)].$$

它以贪心最优性备份为目标，数据却可由另一探索策略收集，因此是 off-policy。Off-policy 指学习目标策略与采样策略不同；offline 则指只能用固定日志、不能继续交互，两者不是同义词。

在有限表格、有足够访问、适当步长等条件下，Q-learning 有收敛结论；函数逼近、有限支持和优化误差会改变问题。

## 4. DQN 为什么使用经验回放和目标网络

DQN 用神经网络 $Q_\theta$，常见目标是：

$$y=r+\gamma(1-d)\max_{a'}Q_{\bar\theta}(s',a'),\quad L=E[(Q_\theta(s,a)-y)^2].$$

$d$ 表示真正终止，$\bar\theta$ 为延迟更新的目标参数。对 $y$ 通常停止梯度，进行 semi-gradient 更新。经验回放降低相邻样本相关性并复用数据；目标网络让标签短期更稳定。这些是稳定训练的机制，不构成任意任务的收敛保证。[DQN 2015 论文](https://doi.org/10.1038/nature14236)

回放也改变数据分布。旧数据在环境变化后可能过时，优先回放可能需要校正采样权重；只说“越大的 buffer 越好”缺少条件。

## 5. Max 为什么产生过高估计

设两个动作真值均为 0，估计分别为随机噪声 $\epsilon_1,\epsilon_2$，各自均值为 0。$E[\max(\epsilon_1,\epsilon_2)]\ge0$，通常严格为正。取最大值更容易选择正误差，因此反复 bootstrap 可传播高估。

Double DQN 用在线网络选动作、目标网络评估该动作：

$$y=r+\gamma Q_{\bar\theta}(s',\arg\max_aQ_\theta(s',a)).$$

它减少选择与评价完全共用误差带来的偏差，但两个网络仍相关，并不保证误差归零。[Double DQN](https://arxiv.org/abs/1509.06461)

## 6. “致命三角”指出的是稳定性风险

函数逼近、bootstrapping、off-policy 三者结合可能导致发散或不稳定。直觉是：一个状态动作上的拟合会通过共享参数改变其他状态；bootstrap 又把这些预测当标签；off-policy 分布可能不给被改变的区域足够校正。

这不是说三个因素一出现就必然失败，而是不能沿用简单表格 on-policy 情形的直觉。目标网络、保守约束、合适表示和数据覆盖都在控制相关问题。

## 7. 价值误差如何变成策略错误

如果两个动作的真实 Q 分别为 10 和 9.9，预测误差 0.2 就可能颠倒选择；若真实 Q 分别为 10 和 0，同样误差不太影响决策。对策略而言，动作间差距与误差位置比平均 MSE 更有意义。

因此评价 critic 时不仅看训练 Bellman loss。错误模型也可能在数据支持区域实现低残差，却在策略将访问的新区域严重失真。离线问题见 [[知识体系/05-强化学习/05-离线RL与模型式规划|离线RL与模型式规划]]。

## 8. 自检与解析

**问：TD target 含模型预测，是不是在拿自己证明自己？** 它利用 Bellman 自洽关系逐步传播真实奖励，但需要覆盖与稳定更新；缺少这些条件时确实可能形成错误自洽。

**问：目标网络为什么不每步完全同步？** 同步越快，标签变化越快；太慢又可能传播信息缓慢。它在目标稳定与及时性间取舍。

**问：低 Bellman loss 是否证明策略好？** 不证明。还需确认数据支持、函数误差、目标定义和实际回报。
