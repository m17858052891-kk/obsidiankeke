# 迁移与勘误说明

2026-10-29：统一为七个领域、33 篇主线正文。旧笔记的独有专题、项目指标与长问答保留；重复基础由完整新章节承接。原始非隐藏文件已在工作区完整快照保存，项目当前结论与原论文附件继续保留。

## 已修正的重点

- Attention 缩放与 QK-Norm 分开，纠正原 Llama 3 QK-Norm 混淆。
- Jacobian 奇异值与特征值分开；梯度检查阈值不再被写成绝对 Bug 判据。
- Checkpointing 解释为显存与重算权衡，不列为梯度爆炸解决方法。
- LayerNorm 仿射参数不再被解释为必然恢复全部丢失信息。
- DCN v1 的交互增量与完整输出分开；v2、低秩与 Mix 不再等同。
- PLE shared gate 的输入范围修正；dense MMoE 与 sparse MoE 路由问题分开。
- AUC 补齐平分项；CATE 排序、校准、策略价值分别说明。
- AIPW/DML 补误差乘积、识别条件与交叉拟合边界。
- SAM、GC、PCGrad 删除全局最优、必然降范数及有限步长无损害等过强说法。
