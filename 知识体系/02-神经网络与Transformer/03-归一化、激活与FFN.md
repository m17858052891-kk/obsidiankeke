# 归一化、激活与 FFN

本章从统计轴与结构关系展开，第 9—14 节进一步推导运行统计、LN Jacobian 与 Pre/Post-LN 梯度。各激活的定义、导数和例子见 [[知识体系/02-神经网络与Transformer/专题/激活函数：定义、导数与梯度行为|激活函数专题]]。[[八股/README|返回八股复习入口]]。

Attention 负责跨 token 的信息读取；FFN 在每个 token 内进行特征变换；归一化与残差决定这些变换如何稳定地堆叠。三者的分工比“某种归一化更先进”更重要。

## 1. 归一化首先是选择统计轴

设输入形状为 $(B,L,D)$。LayerNorm 通常对一个 token 的 $D$ 个隐藏分量计算：

$$
\mu=\frac1D\sum_jx_j,\quad
\sigma^2=\frac1D\sum_j(x_j-\mu)^2,\quad
y_j=\gamma_j\frac{x_j-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta_j.
$$

其统计量不跨其他 token 或其他样本。对这个 token 的输入确定后，BN 式的“训练 batch 变了所以均值变了”不会出现。

BatchNorm 则通常按通道、跨 batch 及适用的空间轴统计。训练使用 batch 统计量，常规推理使用运行统计量。小 batch 可能让估计噪声更大，但不能断言小 batch 一定崩溃；效果还依赖空间样本数、相关性、任务和实现。LN 在训练、推理使用相同形式的统计计算，这是它适合变长序列的重要原因。[LayerNorm 原论文](https://arxiv.org/abs/1607.06450)

## 2. RMSNorm 少了什么，也失去了什么

RMSNorm 常写为：

$$
y_j=\gamma_j\frac{x_j}{\sqrt{D^{-1}\sum_kx_k^2+\epsilon}}.
$$

它不减均值。忽略 $\epsilon$ 时，对正尺度变换 $x\mapsto cx$ 具有缩放不变性，但不具有 $x\mapsto x+a\mathbf 1$ 的平移不变性。

例子：$x=(1,3)$ 与 $x'=(11,13)$。LN 的标准化方向相同，因为均值整体平移被消去；RMSNorm 输出方向不同，因为原点到向量的方向已经改变。中心化并非一句“可有可无”就能概括，而是对哪些变化应被忽略的选择。

RMSNorm 可以减少某些运算和归约，但端到端收益依赖 kernel、模型和硬件，不能将某论文的局部加速百分比当作所有 Transformer 的固定收益。[RMSNorm 原论文](https://arxiv.org/abs/1910.07467)

## 3. 仿射参数不等于恢复所有被删除的信息

LN 中的 $\gamma,\beta$ 是跨样本共享的可学习参数。它们能调整通道尺度和偏移，却无法一般性恢复每个样本被消去的均值与尺度，因为不同样本可能被映射到同一个标准化表示。

因此“归一化后再用 $\gamma,\beta$ 完整还原原分布”是过强解释。残差路径、其他特征及模型结构可能保留相关信息，但不能把这种能力全部归给仿射参数。

## 4. Pre-Norm 与 Post-Norm：公式的位置改变梯度路径

$$
\text{Pre-Norm}:\quad h'=h+F(\operatorname{Norm}(h)),
$$

$$
\text{Post-Norm}:\quad h'=\operatorname{Norm}(h+F(h)).
$$

Pre-Norm 的直接残差路径含单位 Jacobian，Post-Norm 的直接路径也需经过 Norm。前者通常更容易训练很深的堆叠，但“训练更稳定”不等于任何设置下最终效果都更好，具体还涉及深度利用、初始化和学习率计划。[归一化位置的理论与实验分析](https://arxiv.org/abs/2002.04745)

模型末尾的 final norm、Attention 前的 norm、Q/K 向量上的 norm 是不同位置，不能因为都叫 RMSNorm 就视为同一个结构。

## 5. 激活函数如何改变表示和梯度

若所有层都是仿射变换，多层串联仍可折叠为一个仿射变换。非线性激活让不同输入区域使用不同的局部映射。

| 激活 | 定义或关键形式 | 需要理解的边界 |
|---|---|---|
| ReLU | $\max(0,x)$ | 负区间梯度为零；并非每个负激活都意味着神经元永久死亡 |
| GELU | $x\Phi(x)$ | 平滑地按输入大小调制；不是简单把负数全部置零 |
| SiLU | $x\sigma(x)$ | 负区间可有非零输出，导数不等于 sigmoid 本身 |
| Sigmoid | $1/(1+e^{-x})$ | 两端饱和；适合概率或门控，但深层隐表示反复使用会影响梯度 |
| Tanh | 双曲正切 | 输出有界且零中心，但两端同样会饱和 |

激活的数值范围、光滑性、饱和和计算实现都重要。选型不能只按“越新越好”。

## 6. FFN 为什么升维再降维

传统 FFN 采用：

$$
f(x)=W_2\phi(W_1x+b_1)+b_2.
$$

中间宽度 $m$ 提供多个可组合的非线性特征方向，输出再映回残差维度 $d$。忽略偏置，其参数约 $2dm$，每 token 计算同阶。它逐 token 应用同一函数，不直接读取别的 token，但输入已经包含前面 Attention 混合的信息。

门控 FFN（例如 SwiGLU）可写成：

$$
f(x)=W_o\big[\operatorname{SiLU}(W_gx)\odot(W_ux)\big].
$$

一个分支调制另一个分支的特征。这不是把整个向量乘同一个标量，而是逐通道门控。忽略偏置时约有 $3dm$ 参数；与两矩阵 FFN 做公平比较时要调整中间宽度，而不是固定 $m$ 后宣称所有收益都来自激活形式。[GLU 变体研究](https://arxiv.org/abs/2002.05202)

## 7. MoE 怎样扩展 FFN，以及它不等于什么

稀疏 MoE 令路由器为每个 token 选择少数专家，输出为被选专家结果的加权组合。总参数可以很大，但每 token 只激活其中一部分。需要同时报告总参数、激活参数、路由与通信代价。

推荐中的 MMoE 常按任务学习不同门控、组合共享专家；LLM 的稀疏 token routing 主要控制每 token 激活哪些专家。二者共享“专家加门控”的思想，但门控粒度、稀疏性、目标和工程瓶颈不同。更多细节见 [[知识体系/07-检索与推荐/04-多任务、排序与约束决策|多任务与约束决策]]。

## 8. 自检与解析

**LN 后再做线性层，为什么不能把 LN 吸收到权重里？**LN 的均值和方差依赖当前输入，不是固定仿射算子。

**FFN 不跨 token，为什么会影响语言能力？**每个 token 的表示已经承载上下文；FFN 对这些上下文特征做非线性重组，决定哪些信息被保留和放大。

**两个模型 hidden size 相同，就有相同容量吗？**FFN 宽度、门控、专家数、层数和参数共享都可不同，不能只用一个维度判断。

## 9. 用一个具体张量比较 BN 与 LN

设输入形状为 $(B,L,D)=(2,2,2)$：

$$
X_1=\begin{pmatrix}1&10\\3&30\end{pmatrix},
\qquad
X_2=\begin{pmatrix}5&50\\7&70\end{pmatrix}.
$$

每一行是一枚 token，两列是两个隐藏特征。若按特征通道、跨 $B,L$ 做标准批归一化，第一通道的值是 $(1,3,5,7)$，第二通道是 $(10,30,50,70)$：

$$
\mu_{\mathrm{BN}}=(4,40),\qquad
v_{\mathrm{BN}}=(5,500).
$$

这里使用除以样本数的批方差。忽略 $\epsilon$、取 $\gamma=1,\beta=0$，第一枚 token 归一化后两个分量均约为 $-1.3416$。它们相同是因为两列恰好相差十倍，而 BN 分别消去了每列的尺度。

LN 则只看第一枚 token 的 $(1,10)$，均值为 5.5，方差为 20.25，归一化后是 $(-1,1)$。其他 token 或其他样本变化，不会改变这一枚 token 的 LN 统计量。

这两个结果说明：归一化不是对同一组数套不同名字，而是**统计的集合不同**。套接口前先写张量形状和归约轴；例如常见 BatchNorm1d 的三维输入约定为 $(B,C,L)$，不能把 $(B,L,D)$ 原样传入后以为自动沿隐藏维处理。[PyTorch BatchNorm1d 文档](https://docs.pytorch.org/docs/stable/generated/torch.nn.BatchNorm1d.html)

### Padding 与自回归为什么重要

如果变长序列的 padding 零也参与跨 $B,L$ 统计，真实 token 的归一化结果会随 padding 比例改变。可设计 masked statistics 排除 padding，但这增加了统计与实现约束；LN 的 token 内统计天然不跨这些位置。

在自回归训练中，若跨整段序列计算 BN 统计，未来 token 还可能通过均值和方差影响过去 token 的表示。仅给 Attention 加 causal mask 无法自动切断这条统计路径。因此“不能读未来”要检查整张计算图，不只是 Attention。

LN 不依赖 batch 统计，不表示其输入永远不受其他 token 影响：Attention 已经可能把可见上下文混入输入。应区分归一化算子自身的统计依赖与上游网络的信息依赖。

## 10. BN 的训练与推理为什么不同

训练时通常用当前批次均值和方差标准化，同时维护运行统计量。以运行均值为例：

$$
m_t=(1-\alpha)m_{t-1}+\alpha\mu_t.
$$

这里 $\alpha$ 是新统计量权重。不同库对 momentum 的命名约定可能相反，不能把它与优化器动量系数直接互换。常规推理使用保存的运行统计，减少对当前请求 batch 组成的依赖。

需要分别区分三件事：用于当前输出的批方差、用于维护运行估计的方差、运行估计的指数平均系数。有的实现对前两者采用不同的有偏/无偏约定。例如 PyTorch BN 的训练标准化使用有偏方差，而更新运行方差时使用无偏估计。小批量下，这个差别不能忽略。若关闭运行统计，某些实现推理时仍使用当前批统计，也就不再符合“推理一定用固定统计”的说法。[BN 统计与模式定义](https://docs.pytorch.org/docs/stable/generated/torch.nn.BatchNorm1d.html)

小 batch 的问题是有效统计样本较少或相关性较强，而不是看到 batch size 为 1 就能断言数学上不可用。在图像/序列 BN 中还可能沿空间/时间维归约；但若每通道实际只有一个有效元素，训练模式可能无法按接口要求计算估计。反过来，即使像素很多，高相关性也不等于同样多的独立观测。

BN 的批次噪声有时产生正则化作用，不能等同于 Dropout 的随机失活。推理时域分布发生变化，保存的运行统计也可能不合适；这与训练不收敛是不同问题。

## 11. LN 的 Jacobian 如何说明信息与梯度

忽略仿射参数，令：

$$
\begin{aligned}
\mu&=\frac1D\mathbf1^\top x,\qquad c=x-\mu\mathbf1,\\
s&=\sqrt{\frac1D c^\top c+\epsilon},\qquad \hat x=c/s.
\end{aligned}
$$

对 $x$ 求微分：$dc=(I-\mathbf1\mathbf1^\top/D)dx$，又有 $ds=c^\top dx/(Ds)$，因此：

$$
J_{\mathrm{LN}}
=\frac1s\left[
I-\frac{\mathbf1\mathbf1^\top}{D}
-\frac{cc^\top}{Ds^2}
\right].
$$

若包含逐通道 $\gamma$，再在左侧乘 $\operatorname{diag}(\gamma)$；$\beta$ 不改变对输入的 Jacobian。

从公式可以直接读出：

- $J_{\mathrm{LN}}\mathbf1=0$：给所有分量加相同常数的方向被消去。
- 忽略 $\epsilon$ 且方差非零时，$J_{\mathrm{LN}}c=0$：沿中心化向量整体缩放的方向也被消去。
- 保留 $\epsilon$ 时，$J_{\mathrm{LN}}c=(\epsilon/s^3)c$：尺度不变性是近似的，不能忽略 $\epsilon$ 后又把结论称为精确。

这解释了为什么跨样本共享的 $\gamma,\beta$ 不能恢复每个样本已经消失的均值和尺度。它们增加后续变换的自由度，但并没有得到每个样本原来的两个统计量。

还可以看到因子 $1/s$：方差很小、仿射尺度很大时，局部梯度尺度可能变大。归一化不是梯度范数必然变小的投影；稳定性还需要完整 Jacobian、残差和优化器共同分析。

## 12. Pre-LN 与 Post-LN 的梯度路径展开

设 $N$ 为归一化，$F_l$ 为子层。两种结构的 Jacobian 分别为：

$$
\begin{aligned}
\text{Pre-LN}:\quad
x_{l+1}&=x_l+F_l(N(x_l)),\\
J_l&=I+J_{F_l}J_N,\\[4pt]
\text{Post-LN}:\quad
x_{l+1}&=N(x_l+F_l(x_l)),\\
J_l&=J_N(I+J_{F_l}).
\end{aligned}
$$

这里每个 Jacobian 都在其对应输入点取值，矩阵次序不能随意交换。Pre-LN 中的恒等项无需经过该层 Norm；Post-LN 中，即使走残差支路，也要经过外部 Norm。

Pre-LN 堆叠可展开为：

$$
x_L=x_0+\sum_{l=0}^{L-1}F_l(N(x_l)).
$$

这是沿残差流保留旧表示、逐层增加修正的代数关系。每一项仍依赖前面层的计算，不能将它理解为彼此独立的并行补丁，也不能推出输出总能无损恢复原始输入。

反向涉及 $\prod_l(I+J_{F_l}J_N)$，保留恒等路径有利于梯度传播，但多个矩阵的乘积仍可能放大、抵消或变得病态。末尾的 Final Norm 也仍需经过，不能说“梯度从损失到最底层完全不用穿过任何 Norm”。

### 深度利用不足怎样理解

一个说明性的情形是：残差分支的典型量级大致稳定，而残差流的量级随层数增长，那么后面每层新增修正相对于已有表示会变小。归一化后的相邻层表示可能越来越接近，增加深度的收益也可能下降。但分支间相关性、缩放和训练会改变这一行为，不能把它当作所有 Pre-LN 模型必然发生的结论。

Post-LN 每层重新规范输出尺度，代价是初始化与深层优化更敏感。选择取决于深度、初始化、残差缩放、warm-up 与任务，而不是“Pre-LN 永远更强”。Pre-LN 的初始化梯度分析可参考 [Xiong 等人的研究](https://proceedings.mlr.press/v119/xiong20b.html)；日程展开见 [[知识体系/01-统计与优化/专题/学习率日程：预热、衰减与重启|学习率日程]]。

## 13. RMSNorm、LN、GN 与 IN 怎样归类

LN 减均值再按标准差缩放；RMSNorm 按均方根缩放，通常只带可学习缩放参数。二者的区别首先是平移与尺度处理，不只是运算数量。还要区分“子层前使用 RMSNorm”和“投影后分别对 Q/K 做归一化”；这不是同一个位置。

对视觉张量 $(B,C,H,W)$，InstanceNorm 常按每个样本、每个通道跨空间维统计；GroupNorm 则在每个样本内，对一组通道及其空间位置统计。它们提供了其他统计轴选择，不依赖跨 batch 的当前样本集合。实际仿射参数与运行统计选项仍取决于实现。

对 Transformer 的 $(B,L,D)$，本章 LN 指每 token 沿 $D$ 归约。不能只说“LN 沿除 batch 外所有轴”，否则可能误把不同 token 一起归一化。讲轴比背名字更可靠。

## 14. 面试短答与继续追问

**Transformer 为什么通常用 LN 而非 BN？**LN 按 token 沿隐藏维统计，不依赖其他样本；标准用法下训练与推理统计方式一致，适配变长与逐 token 生成。BN 跨样本/位置统计，需额外处理 padding、运行统计和可能的未来信息依赖。这是匹配程度的问题，不是 Transformer 在数学上绝对不能用 BN。

**RMSNorm 为什么可能更快？**它省去中心化和相应统计运算；实际收益取决于融合 kernel、访存与整体模型。不能把某个测试中的加速百分比推广到所有模型。

**Pre-LN 里的恒等路径是什么意思？**写出 $J=I+J_FJ_N$，指出 $I$ 来自残差直通；再说明完整乘积仍可能失稳、末尾 Final Norm 仍参与反向。这样比“有残差就不会梯度消失”更准确。

**给单个 token 的每一维加同一个数，LN 与 RMSNorm 怎样变化？**LN 的中心化结果保持不变；RMSNorm 一般改变。可用 $(1,3)$ 与 $(11,13)$ 验算，并区分平移与正比例缩放。

**为何保留归一化后还要激活函数？**标准化调整当前表示的统计结构，激活与 FFN 学习输入相关的非线性特征组合，作用并不重合。各激活的导数和失效例子见 [[知识体系/02-神经网络与Transformer/专题/激活函数：定义、导数与梯度行为|激活函数专题]]。
