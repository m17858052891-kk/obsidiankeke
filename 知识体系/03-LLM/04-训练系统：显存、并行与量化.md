# 训练系统：显存、并行与量化

先修：[[知识体系/02-神经网络与Transformer/01-反向传播、初始化与残差|反向传播与残差]]、[[知识体系/01-统计与优化/04-优化器、学习率与梯度稳定|优化器与梯度稳定]]。训练能否放进显存、训练数值是否稳定、训练速度是否快，是三个相关但不同的问题。

## 1. 显存账本：参数只是其中一部分

训练显存可分为参数、梯度、优化器状态、激活、临时工作区与通信缓冲。以一种常见混合精度 Adam 配置举例：低精度参数 2 字节、低精度梯度 2 字节、FP32 主参数 4 字节、两份 FP32 动量共 8 字节，合计约 16 字节/参数。7B 参数仅这部分约 112 GB（十进制），尚未包含激活。

这不是每个实现的固定常数：梯度精度、是否保留主参数、优化器状态精度、分片方式都会改变账本。讨论“某模型需要多少显存”必须先说明推理或训练、全量或适配器、batch 与长度。

激活通常随 micro-batch、长度、层数和隐藏维度增长；保存完整 attention 矩阵还可能引入长度平方项。高效 attention 避免某些中间量，不能消除网络所有激活。

## 2. Checkpointing 是重算换空间

正常反向需要前向中间量。Activation checkpointing 只保留选定边界，反向到该段时重新计算内部前向，从而减少常驻激活。切分越细、保留越少，通常重算越多；最优策略依赖运算和通信成本。

它不直接限制 Jacobian 或梯度大小，因此不是梯度爆炸的数学解决方案。它也没有固定的“只慢 20%”或普适 $O(\sqrt L)$ 显存保证；这些结果依赖具体切分与简化假设。涉及随机操作、可变状态时，重算必须与前向语义一致。[PyTorch checkpoint 文档](https://docs.pytorch.org/docs/main/utils/checkpoint.html)

## 3. 数据并行与梯度累积

数据并行让各设备计算不同样本的梯度，再聚合以更新同一参数。若各设备样本数相同，对局部平均梯度再平均得到全局平均；样本数不同则需要正确加权。

梯度累积在多个 micro-batch 后才更新参数。它能降低单次激活峰值，但不会自动降低参数与优化器状态显存。与一个大 batch 等价需要 loss 缩放正确、更新次数对应，且没有会因 micro-batch 划分改变语义的操作；BatchNorm 统计等就是常见差异。

增加设备或累积步数会改变有效 batch；如果仍固定总更新步数，就改变了看过的 token 数。比较实验应同时对齐数据量、更新次数和学习率日程含义。

## 4. ZeRO 分片消除什么冗余

传统数据并行在每张卡复制参数、梯度、优化器状态。ZeRO 分阶段分片这些对象：Stage 1 分优化器状态，Stage 2 再分梯度，Stage 3 再分参数。计算某层时可能需要收集对应参数，计算后再释放或重新分片。[ZeRO 原论文](https://arxiv.org/abs/1910.02054)

节省显存伴随通信与调度需求。Stage 3 不是让每张卡只执行固定的三分之一网络；这种理解更接近另一种模型切分。它仍可以为数据并行副本提供完整计算，只是参数按需可用。

## 5. 模型并行的切分维度

| 方式 | 切什么 | 主要代价 |
|---|---|---|
| 张量并行 | 一层矩阵运算的维度 | 层内频繁集合通信 |
| 流水线并行 | 不同层或层组 | 流水线气泡、微批调度 |
| 序列/上下文相关并行 | token 或相关激活维度 | 跨分区 attention 与通信 |
| 专家并行 | MoE 的不同专家 | token 路由、负载不均衡 |

例如 $Y=XW$，将 $W$ 按输出列切分，可独立得到 $Y$ 的不同列；若下一步需要完整 $Y$，就要收集或设计匹配的后续切分。并行方法的本质是计算图中的张量依赖如何跨设备传播，而非给 GPU 数量乘一个理想倍数。

选择方式要联系设备间带宽。高频小通信跨慢网络，可能让算力增加但总速度下降。模型状态、激活和通信的主要瓶颈不同，常需要组合而非单选。

## 6. 低精度与量化：表示误差从哪里来

均匀仿射量化可写为：

$$q=\operatorname{clip}(\operatorname{round}(x/s)+z,q_{\min},q_{\max}),\qquad \hat x=s(q-z).$$

$s$ 为尺度，$z$ 为零点。误差包括舍入和截断；离群值扩大范围后会增大多数数值的量化步长。分组、分通道尺度可减少这种冲突，但需要保存额外元数据。

例：用间距 0.1 的网格表示 0.26，会得到约 0.3；若一个离群值迫使间距变为 1，0.26 可能变成 0，小数信息丢失显著。对向量点积，误差又会经过后续层累积或被归一化缓解，不能只根据单个权重均方误差判断最终任务质量。

FP16、BF16 是浮点格式；int8/int4 等是另一类量化表示。BF16 有较宽指数范围，但尾数更短；宽动态范围有助于减少溢出，不表示没有舍入误差。混合精度常保留部分累加、归一化或优化器计算在较高精度。

权重量化主要减少权重存储与读取；激活量化、KV 量化是不同对象。实际加速还依赖算子和硬件能否高效执行低精度运算，频繁反量化可能抵消部分收益。

## 7. 不要把三个“稳定”混在一起

数值稳定指避免溢出、下溢和严重消减；优化稳定指更新不发散、损失行为可控；统计稳定指对样本和分布扰动不过度敏感。FP32 可以解决部分数值问题，却不能修复错误标签或混杂；梯度裁剪限制某次梯度范数，却不能保证最优解；checkpointing 腾出显存，却不能证明模型学到正确规律。

## 8. 自检与解析

**问：显存不足，先缩短序列还是减参数？** 看账本。激活随长度占主导时前者有效；优化器状态占主导时分片、适配器或状态精度更直接。没有统一答案。

**问：8 卡训练一定比 4 卡快一倍吗？** 不一定。通信、同步、流水线气泡和每卡工作量会限制扩展效率。

**问：量化后参数误差很小，能直接认定模型等价吗？** 不能。需要检查输出分布、长序列积累、关键任务和低概率行为；小参数误差并不保证所有输入上的小功能误差。
