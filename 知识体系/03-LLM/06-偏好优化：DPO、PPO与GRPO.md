# 偏好优化：DPO、PPO 与 GRPO

先修：[[知识体系/01-统计与优化/02-似然、交叉熵与KL|似然、交叉熵与KL]]、[[知识体系/03-LLM/05-SFT、LoRA与任务适配|SFT与LoRA]]。涉及 PPO/优势估计的部分，可结合 [[知识体系/05-强化学习/03-策略梯度、Actor-Critic与GAE|策略梯度与GAE]] 阅读。偏好训练的核心问题是：如何把“哪个回答更好”转成参数更新，并避免模型只利用评分漏洞。

## 1. 偏好标签与奖励模型不是同一对象

对于同一问题 $x$ 的胜出回答 $y_w$ 与落选回答 $y_l$，Bradley–Terry 模型假设：

$$P(y_w\succ y_l\mid x)=\sigma(r(x,y_w)-r(x,y_l)).$$

用交叉熵拟合这类比较，可训练奖励函数 $r_\phi$。相同问题下给所有奖励加同一个常数，比较概率不变，说明偏好数据只约束差值。人类比较可能含噪声、群体差异或非传递偏好，不能把一个标量奖励等同于唯一客观质量。

经典 RLHF 先获得示范模型，再训练奖励模型，随后优化策略并控制其偏离参考模型的程度。[InstructGPT 论文](https://arxiv.org/abs/2203.02155)

## 2. KL 正则的作用可以直接从最优解看出

对固定问题，考虑：

$$\max_\pi\ \mathbb E_{y\sim\pi}r(x,y)-\beta D_{KL}(\pi(\cdot\mid x)\Vert\pi_{ref}(\cdot\mid x)).$$

在适当支持条件下，理想最优分布满足：

$$\pi^*(y\mid x)=\frac{1}{Z(x)}\pi_{ref}(y\mid x)\exp(r(x,y)/\beta).$$

这表示在参考分布上按奖励指数重加权。$\beta$ 越大，偏离的成本越高。若奖励差是 1，参考概率相同，在 $\beta=1$ 时最优概率比为 $e$，在 $\beta=0.5$ 时为 $e^2$。这是理想解的比较，不等于实际神经网络训练中每个超参变化都有同样单调效果。

KL 约束不会保证事实正确。若参考模型有偏差，或奖励鼓励错误内容，较小偏离只能限制变化范围，不能凭空引入真实证据。

## 3. DPO：把奖励差改写成策略概率比

从上式反解：

$$r(x,y)=\beta\log\frac{\pi^*(y\mid x)}{\pi_{ref}(y\mid x)}+\beta\log Z(x).$$

同一问题的两个回答相减，未知 $Z(x)$ 消失。将参数化策略代入偏好概率，得到：

$$
L_{DPO}=-\mathbb E\log\sigma\left(\beta\left[\log\frac{\pi_\theta(y_w\mid x)}{\pi_{ref}(y_w\mid x)}-\log\frac{\pi_\theta(y_l\mid x)}{\pi_{ref}(y_l\mid x)}\right]\right).
$$

这里的序列对数概率通常为回答 token 对数概率之和；随意改为平均值就改变了目标。DPO 用成对分类直接训练策略，标准离线流程不需要显式学习奖励网络或在每次更新时重新采样。[DPO 原论文](https://arxiv.org/abs/2305.18290)

令方括号内含 $\beta$ 的整体为 $z$，则对其梯度为 $\sigma(z)-1$：越没学会区分的偏好对，梯度系数越大。由于所有回答概率需要共同归一化，优化相对概率差不保证胜出回答的绝对概率每步都增加；其他回答也会受到参数共享影响。

DPO 的推导依赖偏好模型和正则化目标等假设，有限数据训练还受分布覆盖与优化误差影响。因此不能把“有闭式理想策略”解读为“离线 DPO 精确解决所有在线探索问题”。

## 4. PPO 在 LLM 中怎样对应状态、动作和奖励

状态可取 prompt 加当前前缀，动作是下一个 token，完整回答构成一段轨迹。奖励可在末尾给出，也可含过程分数与逐步 KL 惩罚。Value model 用于估计未来回报，优势估计指导哪些 token 动作应增加概率。

PPO 使用当前策略与采样旧策略的概率比，并通过裁剪的替代目标限制部分过度更新倾向，见 [[知识体系/05-强化学习/04-PPO与SAC：约束与熵|PPO与SAC]]。要特别区分两个参照：旧策略用于近端更新的概率比；参考策略用于偏好训练中限制长期漂移。它们可以起初相同，训练中扮演的角色不同。[PPO 原论文](https://arxiv.org/abs/1707.06347)

如果只在回答结尾评分，把该信号用于前面 token 是信用分配问题。文本更长就有更多动作，不合理的长度归一化或奖励设计可能诱导冗长、过早结束等行为。

## 5. GRPO：用同题回答组提供相对基线

GRPO 的常见结果奖励设置：对同一问题采样 $G$ 个回答，得到 $r_1,\ldots,r_G$，构造相对优势：

$$\hat A_i=\frac{r_i-\bar r}{\operatorname{std}(r_{1:G})+\epsilon}.$$

再将这个相对信号用于相应回答的 token 策略优化，并结合概率比裁剪与 KL 等项。其重要区别是使用组内奖励比较构造基线，省去单独训练一个价值模型；不同后续实现对归一化、长度与 KL 项有修改，不能只看“GRPO”名称认定目标完全相同。[DeepSeekMath 的 GRPO 定义](https://arxiv.org/abs/2402.03300)

自己计算一个例子：四个回答奖励为 $(0,0,1,1)$，使用总体标准差时均值 $0.5$、标准差 $0.5$，优势为 $(-1,-1,1,1)$。若全为 0 或全为 1，中心化奖励都为零，单靠这一组没有区分方向，但 KL 等其他项仍可能产生梯度。

归一化也改变了不同题目的权重：奖励方差不同的题目会受到不同缩放。增加采样组大小能提供更多比较机会，同时消耗更多生成成本；它不保证为所有困难题创造成功样本。

## 6. 验证器奖励与偏好奖励的边界

数学答案检查、编译、单元测试可以提供比模糊主观偏好更明确的信号，但只覆盖验证器定义的条件。通过有限测试不等于程序普遍正确；答案正确也不证明中间论证有效。

Reward hacking 是策略利用评分方式与真实目标之间的差距。若评审偏好长回答，模型可能通过冗长获得分数；若只检查格式，模型可能生成格式正确却内容错误的结果。应将训练奖励、独立评估、对抗边界与真实使用效用分开。

## 7. 方法选择的核心差异

| 路径 | 直接数据/信号 | 关键收益 | 主要限制 |
|---|---|---|---|
| SFT | 示范回答 | 学目标行为分布 | 模仿质量与覆盖受示范限制 |
| 离线 DPO | 同题偏好对 | 无需显式奖励模型的偏好更新 | 静态数据覆盖、偏好噪声 |
| PPO 类 RLHF | 当前策略采样、奖励与价值估计 | 可针对当前输出持续优化 | 生成成本、价值误差、奖励漏洞 |
| GRPO 类训练 | 同题多次采样与组内比较 | 不需独立价值模型 | 组内无差异、归一化偏差、采样成本 |

## 8. 自检与解析

**问：DPO 完全没有 reward 吗？** 它没有必需的显式奖励网络，但通过策略相对参考分布的对数比隐含参数化奖励差。

**问：GRPO 省掉 critic，是否省掉了信用分配难题？** 没有。整段奖励如何指导各 token、不同长度如何加权、何时获得有区分度的样本，仍需要处理。

**问：奖励升高能证明推理能力提高吗？** 只能先证明当前评分下表现提高。还应看独立任务、验证器之外的错误、采样预算是否一致以及是否发生奖励投机。
