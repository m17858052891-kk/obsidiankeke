# SFT、LoRA 与任务适配

先修：[[知识体系/03-LLM/01-分词、自回归与语言建模|分词与语言建模]]、[[知识体系/03-LLM/04-训练系统：显存、并行与量化|训练系统与量化]]。SFT 是训练目标与数据形式；LoRA 是参数更新方式；量化是数值表示方式。这三个维度可以组合，不能把它们当作相互替代的算法。

## 1. SFT 在拟合哪一个分布

给定问题 $x$ 与示范回答 $y$，常见目标为：

$$L_{\mathrm{SFT}}=-\mathbb E_{(x,y)\sim D}\sum_t m_t\log\pi_\theta(y_t\mid x,y_{<t}),$$

其中 $m_t$ 指定计分位置。回答长度和样本加权方式会改变各任务贡献。SFT 让模型在给定提示和格式下模仿示范；它既可能学行为，也可能学新知识，效果取决于数据覆盖、容量和训练量，不能断言“只能学格式”或“给一次材料就永久记住”。

例如示范总是先解释再给答案，模型会受到这种风格的正向梯度；但若示范解释中包含错误推导，损失仍会鼓励模仿它。正确答案与可靠推理过程应分别检查。[指令微调与后续偏好训练的经典流程](https://arxiv.org/abs/2203.02155)

## 2. 微调前先确定问题出在哪一层

如果缺少最新、可引用的事实，检索可能比把全部资料写入权重更合适；如果不遵守稳定格式或领域操作规范，SFT 可能直接作用于行为；如果模型能给出多种答案但偏好排序不合适，偏好训练可能更相关。

这些不是绝对分工。检索也会失败，SFT 也能吸收事实，偏好训练也会改变能力。区分的目的，是明确想改变的变量与验证方式。例如“报告引用必须存在”需要验证引用和来源，而不只是训练一个更喜欢写引用格式的模型。

## 3. LoRA 的低秩参数化

对原始权重 $W_0\in\mathbb R^{d_{out}\times d_{in}}$，冻结 $W_0$，训练：

$$W=W_0+\frac{\alpha}{r}BA,\qquad B\in\mathbb R^{d_{out}\times r},\ A\in\mathbb R^{r\times d_{in}}.$$

新增可训练参数为 $r(d_{in}+d_{out})$，而全量更新为 $d_{in}d_{out}$。若两维均为 4096、$r=8$，前者为 65536，后者为 16777216，约为后者的 $1/256$。这只计算该矩阵，不包含其他适配层与非冻结参数。[LoRA 原论文](https://arxiv.org/abs/2106.09685)

限制的是单个更新矩阵的秩，**不是整个模型功能只剩低秩**。$W_0$ 仍在，多个层与非线性相互组合。反过来，也不能保证任意全量微调都可由很小的 $r$ 复现。

## 4. 为什么通常不能把 A、B 都初始化为零

忽略缩放，若损失对 $W$ 的梯度为 $G$，则：

$$\nabla_B L=GA^\top,\qquad \nabla_A L=B^\top G.$$

若 $A=B=0$，两者梯度均为零，适配器无法启动。常见做法让一个矩阵随机、另一个为零，使初始 $BA=0$ 保持原模型输出，同时至少一侧能收到非零梯度。这个细节来自链式法则，而不是“经验规定”。

初始化、rank、缩放和学习率共同决定更新幅度；比较不同 rank 时不能只看可训练参数。把 LoRA 插到 Q/V、所有注意力投影或 FFN，会改变可调整的功能范围。

## 5. 节省了什么，没自动节省什么

LoRA 显著减少可训练参数的梯度和优化器状态，但前向仍需经过基础模型，反向通常也要传播到适配器位置。长序列激活可能依然占用大量显存。因此“只训练 1% 参数”不意味着训练成本降到 1%。

对固定适配器，在线性层可将 $BA$ 合并到基础权重；这能避免单独适配分支的推理计算，但合并到低精度权重时可能发生重新量化误差。需要动态切换多个适配器时，保留独立分支也有价值。

QLoRA 将量化的冻结基础权重与可训练低秩适配器结合。其 NF4、双重量化和分页优化器分别处理权重表示、量化元数据和内存峰值等问题；它不是用 4 bit 精度完成全部训练算术。[QLoRA 原论文](https://arxiv.org/abs/2305.14314)

## 6. 数据边界比“训了几轮”更关键

按随机问答行划分可能让同一文档的改写版本同时出现在训练与测试。若目标是新文档或新问题泛化，应按文档来源、题目族、时间或用户分组。需要同时看训练目标上的改善和通用能力退化。

多轮对话还需要明确上下文是否完整、工具结果来自何时、示范的中间消息是否真实可获得。把答案解析写进本来预测前不可见的输入，模型会学到无效捷径。

优质示范不只是长、格式齐全。应有代表性任务、困难边界、合理的不确定性表达和必要的反例。对知识类任务，答案可以很短但依据必须可靠；把未经核实的长解释堆入训练集，可能强化表面流畅。

## 7. 自检与解析

**问：LoRA 和 SFT 哪个更好？** 这是不同维度。可以用 LoRA 做 SFT，也可以全量做 SFT；应比较同一任务、数据和预算下的参数化选择。

**问：LoRA 为什么能适配新任务？** 预训练权重已有大量表示，任务改变可能只需在多个层内调整有限方向。但这是一种有效的归纳偏置与经验现象，不是任意任务的低秩保证。

**问：训练 loss 很低，回答仍不可信，先查什么？** 查训练/测试分布、示范可靠性、泄漏、过拟合、输出评价目标，以及模型是否缺少所需信息；不能仅以增加轮数回应。
