## 三条阅读路径

**理解现有 Buffer：** 01 → 03 → 04 → 06 → 08。先弄清观测口径和反馈时序，再看公式，不必先学完整 RL。

**理解因果预算分配：** 拉格朗日基础 → 01 → 02 → 05 → 07。和因果章节中的响应估计、ECR 的多档评估对照，区分估计、分配和控制。

**理解自动出价与约束 RL：** 02 → 05 → 07 → CMDP，再回到 GRM、PRIME-PPO 等论文。先建立通用机制，再判断论文到底修改了哪个环节。

## 统一符号与时间尺度

| 符号 | 本领域默认含义 |
|---|---|
| B、B_rem | 总预算、当前剩余可支配预算 |
| c_i(a)、C_t、S_t | 单个动作成本、时间桶成本、累计成本 |
| b_t | 第 t 桶的参考预算；不同于最终硬预算 |
| r_t、y_t、u_t | 控制目标、观测输出、控制输入；r 在 RL 篇另表示奖励 |
| λ | 约束的非负影子价格，不是任意 Buffer 的别名 |
| t、k、n | 环境时段、优化/训练迭代、案例中同状态链更新次数 |

每篇以局部定义为准。尤其区分金额与百分点、每步积分系数与连续时间增益、预测成本与已结算成本。

## 学到什么程度算理解

能够手算一轮 PI 和乘子更新；推导一个标量闭环的稳定范围；给出比率贪心失败、期望预算满足但实际超支的反例；解释真实 Buffer 公式中哪个条件来自源码、哪个条件只是教学模型假设。每篇末尾均有带解析的自检题。

读书依据分别是 [Convex Optimization](https://web.stanford.edu/~boyd/cvxbook/)、[Feedback Systems](https://www.cds.caltech.edu/~murray/FBS/Second_Edition.html)、[Model Predictive Control](https://sites.engineering.ucsb.edu/~jbraw/mpc/)。约束 RL 的原始来源见 CMDP 正文。
