## 1. 优化器

**短答。**SGD 沿当前梯度更新，Momentum 利用历史方向，Adagrad 用累计平方梯度缩放坐标步长，Adam 对一二阶矩做指数平均并校正零初始化偏差，AdamW 把权重衰减从自适应梯度统计中解耦。

**应能写出。**五种方法的更新式；一维二次函数中 $\theta_{t+1}=(1-\eta\lambda)\theta_t$ 的稳定条件；Adam 的 $\hat m,\hat v$ 为什么需要除以 $1-\beta^t$。

**继续追问。**

- 同一个学习率，SGD 和 Adam 的更新幅度相同吗？不相同，动量、坐标预处理和历史状态都影响更新。
- Adagrad 为什么适合一些稀疏参数？少更新坐标的累计平方梯度可能较小，但并非“出现少就一定应该大步更新”。
- AdamW 修正的是预测偏差吗？不是，它解耦衰减；bias correction 处理的是另一件事。

主线之外，[[知识体系/01-统计与优化/专题/梯度修正：SAM、GC与PCGrad|SAM、GC、PCGrad]]分别处理邻域目标、梯度预处理与多任务方向冲突，不应笼统并作同一种优化器。

## 2. 学习率

**短答。**日程控制全局更新尺度。Warm-up 从较小步长起步，衰减改变后期收敛与噪声水平，warm restart 周期性重新提高学习率；必须说明日程按参数更新、epoch 还是 token 计数。

**应能算出。**总进度 10000、预热 1000、峰值 $10^{-3}$、终值 $10^{-5}$ 时，衰减中点在 5500，学习率为 $0.000505$。

**继续追问。**

- 为什么余弦分母是 $T-W$？它描述的是预热后剩余阶段，而不是整段训练长度。
- Warm restart 会重新随机初始化模型吗？通常只重新提高学习率；权重、动量是否重置需按算法定义。
- 固定 weight decay，改变学习率日程会改变累计收缩吗？会，衰减因子包含 $\eta_t$。

完整分段公式、带噪声二次模型和诊断表在 [[知识体系/01-统计与优化/专题/学习率日程：预热、衰减与重启|学习率专题]]。

## 3. 归一化

**短答。**先指定统计轴。标准 Transformer LN 对每个 token 的隐藏维统计；BN 常跨 batch 及空间/时间轴；RMSNorm 不减均值。Pre/Post-Norm 改变归一化与残差的位置，因此改变梯度路径。

**应能画出。**$(B,L,D)$ 中 LN 与序列 BN 的统计集合；Pre-LN 的 $I+J_FJ_N$ 与 Post-LN 的 $J_N(I+J_F)$。

**继续追问。**

- $\gamma,\beta$ 能恢复每个样本被去掉的均值和尺度吗？一般不能，共享参数没有得到原样本统计量。
- 只给 Attention 加 causal mask，能防止跨全序列 BN 的未来信息泄漏吗？不能，统计路径也可能访问未来。
- Pre-LN 是否保证梯度稳定和效果最优？不保证，完整 Jacobian 乘积与训练设置仍重要。

具体张量手算、运行统计、LN Jacobian 与四个高频口述问题见 [[知识体系/02-神经网络与Transformer/03-归一化、激活与FFN|归一化正文]]。

## 4. 激活函数

**短答。**激活提供非线性，同时通过局部导数调节反向信号。选型要区分隐藏层、输出层与门控；是否平滑、饱和、允许负值，都需要放进完整结构中判断。

**应能推导。**$\sigma'=\sigma(1-\sigma)$、$\tanh'=1-\tanh^2$、$\mathrm{GELU}'=\Phi+x\varphi$、$\mathrm{SiLU}'=\sigma+x\sigma(1-\sigma)$；说明 ReLU 零点与 PReLU 斜率参数的梯度。

**继续追问。**

- Sigmoid 饱和，BCE 为什么仍可产生很大的 logit 梯度？该组合对 logit 的导数化简为 $p-y$，但隐藏层仍可能饱和。
- GELU 是否每次随机丢弃单元？标准实现是确定性函数，随机门只是期望解释。
- SwiGLU 的门控等于稀疏 MoE 路由吗？不等于，标准 SwiGLU 仍执行稠密矩阵计算。

原来 Leaky ReLU/PReLU 的细节、GELU 近似式、SiLU 负导数例子和初始化联系均在 [[知识体系/02-神经网络与Transformer/专题/激活函数：定义、导数与梯度行为|激活函数专题]]。

## 5. 位置编码

**短答。**位置可以加在输入、加在 attention logits，或通过旋转 Q/K 进入内积。RoPE 用绝对位置旋转，但 $R_i^\top R_j=R_{j-i}$ 使旋转项只依赖相对位置。

**应能推导。**正弦 PE 的频率和固定偏移线性变换；T5 分桶如何共享偏置；ALiBi 的距离分差如何变成权重比；RoPE 二维旋转的相对关系。

**继续追问。**

- 无位置全可见 Attention 是置换不变吗？是置换等变，输出会随输入行一起重排；固定 causal mask 改变前提。
- RoPE 是否保证远距离内积单调下降？不保证，单频余弦会振荡。
- 可计算更长位置就代表长上下文能力达标吗？不代表，还涉及训练覆盖、相位分布、干扰与实际任务。

正文保留了几种机制的公式、算例、注入位置对照与 cache 边界：[[知识体系/02-神经网络与Transformer/04-位置编码与RoPE|位置编码专题]]。

## 6. 注意力模型

**短答。**Q 决定查询，K 决定匹配，V 是读取的内容；Softmax 沿 key 维归一化。多头在不同投影空间读取，再拼接映回残差维度。

**应能说明。**$QK^\top$ 和 $AV$ 的形状；独立、零均值等假设下点积方差随 $d_k$ 增长；causal mask、padding mask 和全屏蔽行的区别。

**继续追问。**

- Transformer 能并行，为什么生成仍逐 token？教师强制训练已知整段输入，普通自回归生成的下一输入仍依赖上一步。
- 增加 head 数一定增加总参数吗？总 hidden size 固定时不一定，每头维度同时变小。
- FlashAttention 是线性复杂度的近似 attention 吗？标准核心仍是精确稠密 attention 的计算重排，减少显存读写与中间量。

正文见 [[知识体系/02-神经网络与Transformer/02-Attention：数学、信息流与复杂度|Attention 原理]]；代码数据流见 [[知识体系/02-神经网络与Transformer/专题/MHA手撕代码与面试讲解|MHA 手撕讲解]]；缓存与分块归一化见 [[知识体系/03-LLM/03-推理：KVCache、FlashAttention与解码|推理专题]]。

## 7. 损失函数

**短答。**损失规定估计目标和优化信号。MSE 对应条件均值，MAE 对应条件中位数，分位数损失对应指定分位数；BCE/CE 来自对应概率模型的负对数似然。排序损失则可能直接关注候选之间的相对关系。

**应能推导。**MSE 的均值最优解、CE 对 logits 的 $q-p$ 梯度；写出 Huber、Focal、InfoNCE、Triplet、BPR，并说明各自比较对象。

**继续追问。**

- Focal 或类别加权会保持原总体概率吗？不自动保持，训练目标或样本权重已改变。
- 最小化 CE 何时等价于 KL？目标分布固定时，二者相差与待优化模型无关的熵项。
- Listwise 都是在乘 $\Delta\mathrm{NDCG}$ 吗？不是，ListNet 的列表概率目标与 LambdaRank 的成对梯度加权应分开。

读 [[知识体系/01-统计与优化/专题/损失函数选型与补充|损失函数选型]]，需要概率基础时回到 [[知识体系/01-统计与优化/01-条件期望、估计目标与预测|估计目标]]、[[知识体系/01-统计与优化/02-似然、交叉熵与KL|似然与 KL]]。

## 8. 模型评估指标

**短答。**先看业务是在排序、选阈值、使用概率、预测数值还是做干预。AUC、F1、NDCG、LogLoss 等不是彼此可替代的“好模型分数”。

**应能手算。**混淆矩阵、带平分的 AUC、AP、分组加权 GAUC、多等级 NDCG，以及 MAE/RMSE/$R^2$。能说清空分母、ties、候选池和权重约定。

**继续追问。**

- 对分数取负，AUC 还不变吗？变成 $1-\mathrm{AUC}$；保持不变要求严格单调递增变换。
- 单正例 HR 与 Recall 相同，能推广到多正例吗？不能，多正例只命中一个即可 HR=1。
- 校准好是否一定有区分能力？不一定，总预测总体正例率的常数模型也可能校准。

全部公式和统一样本例子见 [[知识体系/07-检索与推荐/专题/模型评估指标：定义、计算与选择|指标手算专题]]；采样校正、A/B 和 CUPED 见 [[知识体系/07-检索与推荐/05-评估、校准与实验|评估与实验]]。

## 9. 过拟合

**短答。**训练好、验证差是现象；先排查泄漏、切分、分布与标签差异，再判断估计方差或模型选择偏差。训练与验证都差，还要考虑表达、输入信息和优化问题。

**应能解释。**平方损失的偏差—方差分解；L1 稀疏、L2 收缩、Dropout 随机掩码、数据增强不变性先验、Early Stopping 限制训练路径。

**继续追问。**

- 没有用验证集反传，为什么也可能过拟合它？反复根据验证分数选模型仍使用了验证信息。
- 降低模型复杂度总能解决问题吗？不能修复数据穿越或目标错设，也可能加重欠拟合。
- 更多数据一定减少近似偏差吗？不一定，错的函数类或缺失输入仍可限制能力。

正文见 [[知识体系/01-统计与优化/03-泛化、正则化与统计不确定性|泛化与统计不确定性]]；具体诊断例子也保留在 [[知识体系/07-检索与推荐/专题/精排优化|精排优化]]。

## 10. 时间与空间复杂度

**短答。**先定义输入规模和计算阶段，再数主要操作与同时存活的内存。递归需同时分析调用次数与调用栈深度；大 O 是增长阶，不等于实际秒数。

**应能算出。**二分 $O(\log n)$、归并 $O(n\log n)$、朴素递归与记忆化的差别；Attention 的投影项与二次交互项；FFN 参数量与 KV cache 字节数。

**继续追问。**

- 嵌套循环必然 $O(n^2)$ 吗？要看各循环边界和总次数，不能只数缩进层数。
- 参数多就一定 FLOPs 多吗？Embedding 查少数行与稠密 FFN 全量计算不同。
- 显存少了是否代表算术量少了？重计算和 FlashAttention 等方法改变的成本维度不同。

基础例子保留在 [[知识体系/01-统计与优化/专题/时间与空间复杂度|算法复杂度]]；模型账本见 [[知识体系/03-LLM/04-训练系统：显存、并行与量化|训练显存与并行]]、[[知识体系/03-LLM/03-推理：KVCache、FlashAttention与解码|推理成本]]。

## 11. 精排优化

**短答。**先明确预测时点、样本空间与标签，再检查训练服务一致性、特征、样本和优化，然后讨论结构与 Scaling。最终同时看排序、校准、关键切片、线上业务效果与资源成本。

**应能展开。**MLP → 交叉特征 → 候选感知序列 → 多任务；序列长度、宽度、层数、FFN、Embedding 的成本；同预算与充分训练两种对照；旧模型蒸馏、真实标签和权重退火的作用。

**继续追问。**

- 大模型失败就说明到达模型上限吗？还要排查实现、欠训练、超参数、数据和信息路径。
- 加残差或教师分支能保证线上收益不下降吗？保留旧函数的初始化可以控制起点，后续训练与分布变化并无自动保证。
- 学生超过教师需要什么信息？真实标签、新数据、新特征、结构或正则优势可能提供改进来源，单纯复制教师不保证超越。

## 怎样判断一个主题已经学懂

对任一主题，尝试完成五步：说清定义；重写一个关键公式；解释其中一个等号或导数；算一个小例子；给出一个让无条件结论失效的反例。答不出时回到对应正文，短答只是提纲。

跨主题可连续追问：更换激活后为何需要重看初始化与学习率；采样率变化为何可能让 AUC 接近不变而概率失准；Pre-LN 与 warm-up 有何联系；长序列为何同时改变计算成本、位置分布与指标候选池。

因果与推荐长问答见 [[知识体系/复习/实验因果深度学习与推荐召回|原有长问答]]，因果短答见 [[知识体系/复习/05_因果推断与统计面试速记|因果与统计速记]]。本页的 11 个主题是基础复习目录，不代替 LLM、因果、RL、Agent 和预算控制的各领域主线。
