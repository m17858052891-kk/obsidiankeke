# 论文地图、证据边界与检索记录

本笔记完整列出本次采用的文献入口，并解释每篇在论证中承担什么角色。主文见[系统论证](./01_系统论证.md)，复现实验建议见[验证方案](./03_验证方案与数学例子.md)。

**检索截至 2026-11-06；纳入 41 篇文献，另列 1 条未采用的新线索。** 年份按表中的正式发表/预印本状态标注，不把首次 arXiv 上传年与会议年混为一谈。这是问题驱动的定向综述，不声称穷尽全部相关论文，也没有重新复现文献中的 benchmark。

核验层级：关键理论与核心比较查到原文公式、定理或实验部分；模型补充条目查原论文/作者正式入口中的相关机制。FM 使用作者官网入口；TabPFN 的直接页面打开曾遇到重定向错误，正文 Methods 由网页检索提取核对。未把所有补充论文逐节通读，也未把所有原论文图表搬入笔记。

## 4. 五篇优先阅读，以及如何顺着问题读

1. **T01 · V-information**：先区分“信息存在”与“对指定预测者可用”，建立整篇综述的语言。
2. **E03 · Numerical Embeddings**：看相同骨干改数值表示的直接实证；同时辨认监督编码与参数变化。
3. **E02 · Tree vs DL**：看旋转、无关特征等干预如何揭示模型偏好，注意不同干预并不都保信息。
4. **M10 · DCN V2**：读 cross 公式、参数共享与低秩扩展，弄清显式交叉到底提供了什么。
5. **E06 · TabM**：用现代强 MLP 学习程序校正“MLP 基线很弱”的先入判断，再按需补 T02 的条件增量视角。

若重点是数学：T03 → T04 → T08/T09 → T07。若重点是推荐模型：M04 → M05 → M07 → M10 → M13。若重点是“一个特征有没有新增价值”：T01 → T02 → T11，再配合本笔记的实验设计。

### 5.3 未纳入核心证据的新线索

[Do Tabular Foundation Models Still Need Feature Engineering?](https://arxiv.org/abs/2609.13202) 的检索页面与 HTML 显示编号 2609.13202v1、日期 2026-08-14，编号月份与显示日期不一致，本次未解决；PDF 获取也未成功。因此只保留检索线索，不将其发表时间与实验结论作为已充分核验事实。

可读取的正文自报 13 个数据集、30 splits、26 条特征工程条件，而且区分了事后 test-side 最佳变换的 oracle 与真实可选择收益。即使后续元数据核验通过，仍需检查模型默认配置、较小分类集、变换是否保信息及选择预算，不能直接推广“基础模型不再需要特征工程”。

### 5.4 范围与可能遗漏

本次重点是有监督表格/推荐任务与表示学习的理论桥梁。核方法、统计决策理论、因果表示和自监督表格模型没有做穷尽式检索。主文中的小型算例为独立数学推导；不能把它们冒充某篇论文在真实数据上的实验发现。没有使用二手排行榜作为架构优劣的依据。

## 6. 对纳入文献的综合观察

### Overview：覆盖了什么

41 篇条目覆盖 1989–2025 年的正式论文/预印本，检索窗口延伸到 2026-11-06。理论条目回答可用性与可训练性；模型条目说明内置操作；实证条目检查这些差异是否影响实际学习。2026 年疑点线索不计入 41 篇。

### Trends：能观察到的研究脉络

在这个定向样本中，可以看到从手工/低阶交互、显式交叉网络与注意力，到数值编码、强训练基线、检索、集成和预训练先验的拓展。这是选中文献的内容脉络，不是依据完整年度发文量得出的领域增长趋势。

NeurIPS、ICLR、ICML 侧重理论与表格学习比较；KDD、WWW、CIKM、RecSys 中有多篇推荐/点击率模型。Gorishniy 及合作者的一组工作连续涉及基线、数值编码、检索与集成；不能因为同一研究系列在本综述出现较多，就推断其在所有业务数据上最优。
