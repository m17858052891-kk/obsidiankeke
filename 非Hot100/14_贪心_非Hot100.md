# 非 Hot 100 — 贪心

> 这些题不属于正式 Hot 100，但仍有较高面试价值。

## 135. 分发糖果

**题目描述：** n 个孩子站成一排，每人有一个评分，要求评分高的孩子比相邻孩子获得更多糖果，每人至少 1 颗，求最少需要多少颗糖果。

**示例：** 输入：`ratings = [1,0,2]`；输出：`5`。

**思路：** 两次贪心。从左到右：比左邻高分则+1；从右到左：比右邻高分则取 max(当前, 右邻+1)。

**展开理解：** 一次从左到右只保证评分高于左邻时糖果更多，另一次从右到左补足高于右邻的约束。每个位置取两侧要求的最大值，既同时满足两个局部不等式，又不会额外增加糖果。

```python
def candy(ratings):
    n = len(ratings)
    candies = [1] * n
    # 从左到右
    for i in range(1, n):
        if ratings[i] > ratings[i - 1]:
            candies[i] = candies[i - 1] + 1
    # 从右到左
    for i in range(n - 2, -1, -1):
        if ratings[i] > ratings[i + 1]:
            candies[i] = max(candies[i], candies[i + 1] + 1)
    return sum(candies)
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)

## 406. 根据身高重建队列

**题目描述：** 每个人 `[h, k]` 代表身高 h，前面恰好有 k 个身高 >= h 的人。给定打乱后的队列，重建它。

**示例：** 输入：`people = [[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]`；输出：`[[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]`。

**思路：** 按身高降序、k 值升序排列后，依次将每个人插入到索引 k 处（身高较低的人插入不影响已插入高个子的 k 值）。

**展开理解：** 先放高个子，因为后续插入的矮个子不会计入高个子前方“不低于自己的人数”。同身高按 k 升序，随后把每个人插入下标 k；插入时列表中现有的人都不矮于他，因此位置 k 正好满足约束。

```python
def reconstructQueue(people):
    people.sort(key=lambda x: (-x[0], x[1]))
    res = []
    for person in people:
        res.insert(person[1], person)
    return res
```

**复杂度：**
- 时间：O(n²)（insert 操作 O(n)）
- 空间：O(n)

## 452. 用最少数量的箭引爆气球

**题目描述：** 给定气球水平直径的区间，一支箭能引爆所有包含该 x 坐标的气球，返回最少箭数。

**示例：** 输入：`points = [[10,16],[2,8],[1,6],[7,12]]`；输出：`2`。

**思路：** 按区间右端点排序，贪心：一支箭射在当前区间的右端，能引爆所有与其重叠的区间。

**展开理解：** 按右端点排序后，把箭放在第一个尚未覆盖区间的右端点，可以覆盖尽可能多的后续区间。若下一区间左端点大于箭位置才必须新开一箭；这是经典区间调度的交换论证。

```python
def findMinArrowShots(points):
    points.sort(key=lambda x: x[1])
    arrows = 1
    end = points[0][1]
    for start, finish in points[1:]:
        if start > end:   # 当前气球不被覆盖，需要新的箭
            arrows += 1
            end = finish
    return arrows
```

**复杂度：**
- 时间：O(n log n)
- 空间：O(1)

## 435. 无重叠区间

**题目描述：** 给定区间集合，找最少需要移除多少区间才能使剩下的区间互不重叠。

**示例：** 输入：`intervals = [[1,2],[2,3],[3,4],[1,3]]`；输出：`1`。

**思路：** 等价于找最多不重叠区间数（贪心：按右端点排序，尽量保留右端点小的区间）。结果 = 总区间数 - 最多不重叠数。

**展开理解：** 最少删除等价于保留最多互不重叠区间。每次保留右端点最小的可行区间，为后续留下最大空间；与当前末端重叠的区间删除即可，最后用总数减去保留数。

```python
def eraseOverlapIntervals(intervals):
    intervals.sort(key=lambda x: x[1])
    count = 0   # 需要移除的数量
    end = float('-inf')
    for start, finish in intervals:
        if start >= end:
            end = finish   # 保留该区间
        else:
            count += 1     # 移除该区间（与上一个重叠）
    return count
```

**复杂度：**
- 时间：O(n log n)
- 空间：O(1)
