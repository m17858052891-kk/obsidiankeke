# 非 Hot 100 — 动态规划

> 这些题不属于当前 LeetCode 官方 Hot 100，但仍有较高面试价值。

## 338. 比特位计数

**题目描述：** 给定 `n`，返回 `[0,n]` 中每个数的二进制中 1 的个数。

**示例：** 输入：`n = 5`；输出：`[0,1,1,2,1,2]`。

**思路：** 使用动态规划：`dp[i] = dp[i >> 1] + (i & 1)`。右移一位相当于删除二进制最低位，因此 `i` 中 1 的数量等于 `i >> 1` 中 1 的数量，再加上最低位是否为 1。

**展开理解：** 例如 `i=13`，二进制是 `1101`：

```text
13 >> 1 = 6      二进制 110
13 & 1  = 1      最低位是 1

bitcount(13) = bitcount(6) + 1
```

因为 `i >> 1` 一定小于 `i`，所以按 `1...n` 的顺序计算时，依赖状态已经得到。

```python
def countBits(n):
    dp = [0] * (n + 1)

    for i in range(1, n + 1):
        dp[i] = dp[i >> 1] + (i & 1)

    return dp
```

**复杂度：**
- 时间：O(n)
- 空间：O(n)，返回数组本身需要 O(n)
