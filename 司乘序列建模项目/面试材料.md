# 面试材料

## 1. 30 秒介绍

> 这是一个基于既有 PLE 架构来源开展的司乘履约离线序列化改造项目，预测乘客履约 D、司机履约 O 和司乘履约 OD。当前模型将乘客/司机历史和当前订单上下文统一 token 化，用 OneTrans 建模序列、跨司乘和序列—静态特征交互，并通过 PEPNet 的 EPNet/PPNet 在底层与任务层实现个性化。离线实验中，PEP × OneTrans 相对 `pep-seq` 的 OD/O/D AUC 分别提升 `0.82/2.74/6.61pp`；当前没有线上收益结论。

## 2. 3 分钟讲法

1. **问题：** 统计特征会压缩历史顺序、时间间隔和时空条件，也难把司机、乘客与当前订单放进同一交互框架。
2. **输入：** 以预测时点截断历史，将乘客序列、司机序列和当前订单/用户/上下文组织为一份不穿越样本。
3. **模型：** 先通过 EPNet 在底层表示上按场景做 gate；再把历史事件和静态字段统一 token 化，用 OneTrans 学习时序、跨序列和序列—静态特征关系；最后 OD/O/D 各自通过 PPNet 按任务先验逐层 gate 后输出履约分数。
4. **实验：** OneTrans 在 PEP × OneTrans、epoch=9 实验族内相对 `pep-seq` 的 D/O/OD 都有提升；O 更依赖长度、时空字段和训练协议，不能简单归因为多任务冲突或序列噪声。
5. **边界：** 当前是离线验证，真实 token 顺序、层数和 loss 以代码为准；不把 AUC 直接等同于 CR、取消率或接驾距离收益。

## 3. 高频追问

**为什么还需要 PEPNet，OneTrans 不够吗？**

OneTrans 解决统一 token 交互；PEPNet 解决样本、场景和任务差异。EPNet 调节底层特征通道，PPNet 调节 OD/O/D 的 hidden 通道，两者职责不同。

**为什么不是先分别编码序列再拼接？**

那样静态订单特征只能在序列压缩后参与交互。统一 token 可以让当前价格、接驾距离和供需直接影响模型从哪些历史事件中取信息。

**D/O/OD 怎么定义？**

D 是乘客履约，O 是司机履约，OD 是司乘履约率。三任务有关联，但并不必然同向，因此保留共享表示和任务级个性化路径。

**为什么 O 提升不稳定？**

拆 O tower 和移除 O 序列都没有解决问题；目前证据更支持 O 对序列窗口、时空字段和优化协议敏感。L20 在一组 6 月数据中有效，但未跨月稳定复现。

**+6.61pp 相对谁？**

严格相对 `pep-seq`，不是直接相对 PosSA。具体口径见 [[背景与实验]]。

**线上了吗？**

当前材料只支持离线 AUC；需要完成训练—线上序列一致性、延迟、A/B 和业务指标验证后才能回答线上效果。

## 4. 简历表述

**司乘履约双边行为序列建模（离线实验）**

- 基于既有 PLE 多任务架构来源，构建“事件—Attempt/订单宽表—双边历史序列”离线特征链路；以预测锚点截断历史，并采用“主体 ID + 时间戳”预排号与回表策略缓解亿级历史范围 Join 膨胀。
- 以 OneTrans 统一建模司乘历史与订单/上下文特征交互，结合 PEPNet 的 EPNet/PPNet 进行底层与任务级个性化，构建 D/O/OD 履约多任务预测。
- 在 PEP × OneTrans、epoch=9 离线实验族中，相较 `pep-seq`，OD/O/D AUC 分别 `+0.82pp/+2.74pp/+6.61pp`；完成序列长度、时空字段、Batch Size 与任务输入方式消融。

仅在真实参与且能接受深挖时使用“构建/完成/负责”；没有线上验证时不要写线上 CR、取消率或履约率收益。

## 5. 公式速查

$$
g(x)=2\cdot\sigma(\operatorname{MLP}(x)),\qquad \tilde h=h\odot g(x)
$$

EPNet 在 embedding/底层表示侧应用 gate；PPNet 在任务网络各层 hidden 前应用 gate。

$$
\operatorname{Attn}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^T}{\sqrt d}+M\right)V
$$

$$
\mathcal L=\lambda_{OD}\mathcal L_{OD}+\lambda_O\mathcal L_O+\lambda_D\mathcal L_D

## 6. 术语速查

| 术语 | 含义 |
|---|---|
| Attempt | 用于串联冒泡至完单事件的业务尝试粒度 |
| prediction_time | 当前样本预测时点；历史必须早于并在该时点可得 |
| PosSA | 带位置信息的序列自注意力 baseline |
| EPNet / PPNet | PEPNet 的底层 embedding 个性化 / 逐层 hidden 个性化模块 |
| S-token / NS-token | OneTrans 中的历史序列 token / 当前静态特征 token |
| train-serving skew | 训练与线上在截断、排序、特征可用时间等口径不一致 |
