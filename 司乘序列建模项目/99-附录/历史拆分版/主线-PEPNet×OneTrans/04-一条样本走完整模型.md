# 一条样本走完整模型

设当前订单在 `prediction_time` 需要预测履约：

```text
当前订单：价格、预估距离、接驾距离、起终点、时段、供需
乘客历史：最近 Lp 笔订单及其结果、距离、价格、时间差
司机历史：最近 Ld 笔服务及其接驾、履约、时空信息
```

## 1. 输入与 EPNet

历史订单按时间排序，当前订单不会进入历史。字段 Embedding 后得到乘客事件序列、司机事件序列和静态表示；EPNet 根据场景先验生成逐维 gate，先调节哪些底层维度更重要。

## 2. OneTrans

乘客/司机历史成为 S-token，当前订单与上下文成为 NS-token。注意力可以发现：当前长接驾距离是否与乘客近期取消、司机近期长接驾偏好和当前早高峰/供需条件共同构成风险模式。

## 3. PPNet 与输出

统一表示进入 OD/O/D 三个 PPNet。D 分支可更关注乘客历史取消与当前价格/接驾距离；O 分支可更关注司机近期服务和区域时空状态；OD 分支则学习双方条件的联合履约概率。

## 4. 预测阶段的约束

线上或离线推理只输入当前可得字段；真实履约结果只用于训练监督。时间截断、特征字典、padding 和 token 顺序必须与训练保持一致。

> 这个示例说明模型结构，不代表每个字段、token 顺序或因果方向都已在当前代码中确认。
