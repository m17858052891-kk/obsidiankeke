# 统计与数学思想如何成为神经网络的一部分

以预测乘客愿意等车多久为例，网络可以从行程、时段和历史行为中学习特征。**统计模型决定这些特征怎样用于借用群体信息、预测结果的分布，以及在新行为出现后更新判断。**

## 1. 个人记录少时，该相信谁？

新乘客只有两次记录，直接用个人平均值容易受偶然事件影响。贝叶斯收缩让个人参数从相似群体的先验出发，再按个人证据的可靠程度更新。若参照群体选错，这种借力也会把真实的少数人差异压小。

**一个数值例子。** 设个人偏移的群体均值为 0、方差为 1，单次观测的噪声方差为 9。个人观测的平均偏移同样是 4，只有 1 条独立记录时，后验平均偏移是 **0.4**，有 81 条时则是 **3.6**。[[02-贝叶斯收缩与个体建模|查看收缩权重的推导]]

## 2. 同样的平均等待时间，超时的可能性有多大？

编码器仍然可以很复杂。让它输出分布的位置、尺度或各成分的权重，就能计算“这位乘客愿意等超过 10 分钟的概率”。这个概率取决于所选的分布。等待时长只能取非负值，若有人很快离开、有人愿意等很久，还要检查单峰分布是否合适。

**为什么形状重要？** 对一个可正可负的连续结果，若观测集中在 −3 和 3 附近，可以找到均值和方差都与它相同的单峰高斯分布。前者在 0 附近几乎没有样本，后者的密度却恰好在 0 最高。[[03-条件分布建模|查看分布头与训练目标]]

## 3. 最近几趟的反应，会怎样改变下一趟的预测？

若一位乘客连续几次选择等待，隐状态模型会提高对“当前更可能愿意等”这一状态的估计。转移概率决定这个判断能延续多久。时段也可能造成连续变化，因此要在相同的历史和情境特征下，比较加入状态转移前后的预测。把状态命名为“赶时间”还需要独立证据。

**一次观测能改变多少？** 假设两种状态下选择等待的概率分别为 0.8 和 0.2，初始各占一半，下一次保持原状态的概率为 0.9。起初选择等待的概率是 **50%**。看到第一次选择等待，第二次的预测就升到 **64.4%**。[[04-潜在状态与混合模型|查看状态如何更新]]

## 怎样决定给模型加什么

先用预测时已经可见的特征训练共享模型。若稀疏用户的估计不稳定，比较不同程度的收缩。若均值误差小、预测区间却经常漏掉真实值，检查分布形状和校准。若加入可见历史后，误差仍连续成段出现，再检验显式状态转移的价值。在同一批留出数据上比较每次改变，才能判断具体是哪项能力有所改善。[[06-综合模型与验证方案|组合模型、对照实验与数值例子]]

其他数学结构也遵循同样的判断方式。单调约束可以让某个特征增加时预测始终不减，优化层可以让输出满足给定约束。这些选择使指定的性质可以直接检查。若假设错了，结构也会排除真实规律。拟合误差、概率校准、潜变量可识别性和因果效应，各自需要相应的证据。
