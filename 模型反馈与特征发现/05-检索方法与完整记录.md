# 检索方法与完整记录

## 范围与完成口径

研究问题是模型反馈如何指导显式特征发现，分为结构反馈、互补组合、跨模型复用三个方向。截止2026-11-06，API广搜集中于2024–2026，沿参考文献回溯较早的特征选择、符号回归、元学习与反馈可靠性研究。它是有针对性的广泛研究，不声称系统综述穷尽率。

去重后纳入 **79篇**，重点入口 **21篇**；实际打开并确认关联 **30个GitHub仓库**，其中 **18个读到源码**。这些是不同分母，均不等于运行复现。原始分题记录共89项，按同一论文标识、题名与方法名合并；一个论文的多个版本只计一次。选入的相邻理论单独分类，不冒充直接AutoFE实证。

## 检索路径

| 目的 | 已使用的查询族或追踪方式 |
|---|---|
| 广搜 | automated feature engineering；精确短语“feature engineering”；2024–2026 |
| 结构反馈 | feature engineering + SHAP / residual / error feedback / decision tree / reflection |
| 互补搜索 | interaction information、conditional mutual information、whole representation、genetic programming、differentiable feature selection、pairwise exploration |
| 跨模型 | feature engineering transfer、multiple learners、model-agnostic、meta-learning、tabular foundation model |
| 反馈训练生成器 | feature engineering DPO、preference optimization、reason generation、historical evaluations |
| 证据核查 | 精确题名查官方论文页；指定版本正文与附录；作者GitHub目录、README、关键函数 |

LLMFE、OCTree、IIFE、FEAT等作为种子；向后追踪基线和理论，向前检索近期延伸。对陌生或新论文，优先打开作者/会议/arXiv原文；第三方摘要只用于发现，不承担性能结论。GitHub优先用连接器实际读取，区分找到链接、README、源码与运行。

## 六来源API的实际结果与限制

统一脚本尝试arXiv、DBLP、OpenAlex、Semantic Scholar、Crossref、OpenReview。最初环境缺依赖且网络受限，出现全0返回；随后在临时环境补充依赖并重试，arXiv和Crossref成功。OpenAlex仍有Python3.9类型语法兼容错误，DBLP返回解析失败，Semantic Scholar出现限流及SSL失败，OpenReview没有返回条目。失败不代表相应来源不存在相关研究，也不算完成覆盖。

三次保存的API查询共返回 **110条原始记录**（含重复与无关项），按来源累加：open_alex=0；openreview=0；dblp=0；crossref=40；semantic_scholar=0；arxiv=70。这些原始命中不与纳入文献数量相加。人工定向检索和引文追踪是主要补充路径。

完整返回表见 [[模型反馈与特征发现/附录/allinone|API检索全量返回表]]。原始JSON及stderr/stdout日志位于本专题 `附录/检索原始记录/`。人工查询族、访问失败与具体核查过程保留在 `附录/分题证据报告/`；这些是按研究过程整理的日志，不冒充逐条完整浏览器历史。

## 纳入、降级与排除

直接讨论特征生成/选择反馈、组合搜索、模型适配的论文进入主体；信息论、表示迁移与自适应反馈理论进入相邻类别。仅有官方摘要的候选仍可以保留，但笔记明确阅读限制，不引用未核表格数字。

排除与本问题无直接关系的应用论文、3D视觉octree同名结果、未确认的同名GitHub项目和纯第三方性能总结。反事实动作建议不等于为预测器重新训练发现特征，未并入核心方法。无法核实的SSRN广搜命中只保留在原始返回表中。

Rogue One、FEAML、KnowFeat、Human-LLM、From Prompts to Trees等只达到候选或定向阅读层级；PIFE全文访问受验证页阻挡。它们提供后续检索入口，不与已有消融和代码证据混算。

## 证据等级与合并规则

| 维度 | 本研究怎样记录 |
|---|---|
| 文献阅读 | 官方摘要/元数据、方法定向核查、方法与结果表核查分别注明 |
| 代码 | 来源链接、实际打开README/目录、源码核查、运行复现分别注明；最后一项本次为0 |
| 发表状态 | 官方会议、预印本、投稿、README自述分别注明 |
| 效果归因 | 作者报告的组合收益不自动归给单个组件；缺失基线直接标缺失 |
| 数学判断 | 构造反例与公式推导标为本研究解释，不伪装成业务实验 |
| 版本 | 同一论文按最终主报告引用版本解释表号；旧版记录保留来源 |

原始分题记录存在交叠，最终优先采用实际读到完整方法/表格的记录，保留各来源在 `附录/证据台账.json`。主报告与数学解释经过独立阅读复核，修正了OR标签与AutoML最优目标的差别、残差推导条件、IIFE估计器表述及平均秩的解释。

检索未按引用次数给论文排名：接口中的0可能是默认值，新论文也天然缺少累计引用。重点顺序按与三个问题的直接相关性、证据完整度与方法差异确定。
