# AutoCross: Automatic Feature Crossing for Tabular Data in Real-World Applications

> [!summary] 为什么读这篇
> 用特征集为搜索树节点，每次加入一个两两cross；候选用field-wise logistic regression和successive mini-batch GD近似评估；多粒度离散化。

[论文/作者来源](https://doi.org/10.1145/3292500.3330679)

**版本与发表状态：** KDD 2019  
**实际阅读范围：** 核心：作者托管PDF§4/§5  
**本研究定位：** 互补搜索与可微构造；补充阅读。未运行算法。

## 反馈怎样进入搜索

**反馈内容：** 候选集合的验证表现；计算上固定已有field参数主要估计新cross的价值。

**搜索单位：** 特征集节点，但相邻节点只加一列cross；实际论文展示/算法每层走最佳一个孩子。

**机制：** 用特征集为搜索树节点，每次加入一个两两cross；候选用field-wise logistic regression和successive mini-batch GD近似评估；多粒度离散化。

## 对两个关键问题的意义

**互补组合：** 递归cross可形成高阶交叉；搜索深度增长不等于并行保留多种互补组。原文明确局部方案、排除部分子集。

**跨模型或跨任务：** 论文报告AutoCross生成列可提升线性和deep模型；具体迁移由cross_model核。

## 已核的验证与效果

**设置：** §5将特征/模型在训练与验证（需时训练的20%）学习，测试报告AUC；benchmark与企业任务。

**结果：** 本次研究不转录表格汇总收益，以避免未完整核查数据集/基线对应。

以上保留论文实际设置。若只读摘要或定向段落，不从未读表格补写数值；作者报告与本研究是否复现是两件事。

## 局限与取舍

beam名义不代表保证多束/全局；高基数cross和离散化偏差；以LR近似筛选会有评价器偏差。

**可以支持的判断：**

高阶cross可通过递归成对构造

集合节点依然可采用贪心路径

**不能据此推出：**

已找到全局最优集合

beam必然跨越零增益中间步骤

其中对搜索盲区、适用范围与缺失对照的解释，是本研究根据方法或表格作出的判断；不把它们冒充作者报告的实验损失。
