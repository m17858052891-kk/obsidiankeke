
## 一、 DeR-CFR 的理论初衷

在因果推断中，影响用户转化（打车）的因素错综复杂。DeR-CFR（Learning Decomposed Representations for Treatment Effect Estimation）试图构建一个极致纯粹的理论模型，其核心思想是将所有特征严格“解耦”到三个独立的表征桶中：

1. **工具变量 (Instrumental Variable,** $I$**)：** 仅影响干预分配（发何种券 $T$），完全不直接影响最终结果（打车 $Y$）。
    
2. **调整变量 (Adjustment Variable,** $A$**)：** 仅影响最终结果（打车 $Y$），与干预分配（发何种券 $T$）无关。
    
3. **混淆变量 (Confounding Variable,** $C$**)：** 同时影响干预分配（$T$）和最终结果（$Y$）。
    

**理论期待：** 如果能通过神经网络将这三类变量彻底分离（尤其是把 $I$ 从 $C$ 中剥离，以减小因果效应估计的方差），就能极其精准地计算出发券带来的真实因果收益。

## 二、 DeR-CFR 落地痛点

尽管 DeR-CFR 理论上更加完备，但在实际的工业界多折扣干预场景中，却面临着严重的落地痛点，主要体现在以下三个方面：

### 1. 参数爆炸与过拟合陷阱 (结构瓶颈)

- **痛点：** 论文原版往往采用多头结构，即为每个折扣档位建立一个复杂的“专家网络”。在多档位折扣场景下，网络参数量随折扣数量成倍增长。
    
- **后果：** 由于细分到每个折扣组内的用户数据量有限，庞大的网络参数无法得到充分训练，极易导致过拟合，线上泛化表现差。
    
- **当前优化：** 采用双塔模型（或底层强共享结构）代替多头结构，是解决此类参数冗余和过拟合的有效手段。
    

### 2. 目标冲突与调参灾难 (Loss 瓶颈)

- **痛点：** 为了保证 $I, A, C$ 三个桶绝对干净，DeR-CFR 引入了正交正则化（要求向量内积为0）和自适应权重等机制，足足设计了 5 个惩罚 Loss。
    
- **后果：** 这五个优化目标在训练时往往相互拉扯，产生严重的梯度冲突（Gradient Conflict）。模型在多目标优化中迷失方向，导致极难寻找完美的超参数组合，最终可能哪个目标都学不好。
    

### 3. Batch Size 悖论 (对齐瓶颈)

- **痛点：** 模型要求不同干预组（各折扣组）人群的混淆变量 $C$ 的分布必须一致。DeR-CFR 使用推土机距离（Wasserstein Distance）来衡量和最小化这一分布差异。
    
- **后果：** Wasserstein 距离要求在一个 Batch 内包含所有组别的大量样本才能准确计算。为此，被迫将 Batch Size 开到 4096 甚至更大。然而，在深度学习中，过大的 Batch Size 会削弱 SGD 的随机性，导致模型陷入局部最优，丧失泛化能力，在新数据上表现拉垮。
    

## 三、 DeR-CFR 与 DR-CFR 的架构辨析

为了理解为何 DeR-CFR 落地如此困难，我们需要追溯到它的前身 DR-CFR，并对比两者在处理“解耦”时的底层差异。

### 1. DR-CFR：务实的“两路拆分”（2.5 桶）

- **名义与实际：** DR-CFR 提出了特征解耦的思想，但其底层结构本质上是“两路拆分”。
    
- **提纯** $A$**：** 专门建立网络提取只影响 $Y$ 的特征。这部分特征**只用于预测结果，严格禁止参与分布对齐**。
    
- **提纯** $C$**：** 建立网络提取同时影响 $T$ 和 $Y$ 的特征。这部分特征不仅要预测结果，还要**强制进行组间的分布对齐**以消除选择偏差。
    
- **被忽视的** $I$**：** DR-CFR 并没有花大力气显式、严格地剥离 $I$。它默认未对齐的特征可能包含 $I$，但没有设计独立的 Loss 去监督 $I$ 的纯净度。
    
- **总结：** DR-CFR 务实地在一堆混杂特征中，优先保住了不影响分布对齐的纯粹 $A$，避免了过度对齐。
    

### 2. DeR-CFR：执着的“真·三塔结构”

- **分歧点：** DeR-CFR 认为 DR-CFR 分得不彻底，混在 $C$ 里的 $I$ 会放大误差。
    
- **结构升级：**
    
    - 分出 $A$ 拟合 $Y$。
        
    - **分出** $I$：专门拟合倾向分（预测 $T$），且**严格限制其拟合** $Y$。
        
    - 分出 $C$：同时预测倾向分和 $Y$。
        
- **现实困境：** 在真实业务中，寻找一个“只影响发券但不影响打车”的完美工具变量 $I$ 犹如大海捞针。几乎所有特征最终都会收敛到用户的活跃度或价格敏感度（即混淆变量 $C$）。
    
- **结论：** DeR-CFR 为了剥离现实中几乎不存在的工具变量 $I$，强行搭建了复杂的网络结构并引入冲突的 Loss。耗费大量算力维护一个“空桶”，必然导致泛化性能下降和欠拟合。
    

## 四、 寻找“中间态”模型的演进策略


### 1. 结构降维：果断丢弃工具变量 $I$

- **策略：** 既然业务中难以找到完美的工具变量，不如放弃对其的强制剥离。
    
- **收益：** 直接将模型从“三桶”回退到“两桶”（只解耦 $C$ 和 $A$）。这相当于直接砍掉了一部分网络参数和至少 2 个冲突的 Loss，大幅降低训练难度，回归 DR-CFR 务实的本质。
    

### 2. 度量降维：替换距离计算方式以破解 Batch Size 困局

- **策略：** 放弃对 Batch Size 要求极高的 Wasserstein 距离，改用 **MMD (最大均值差异, Maximum Mean Discrepancy)**。
    
- **收益：** MMD 类似于抽样调查，仅需较少的样本就能估算分布差异。这允许我们将 Batch Size 从 4096 降回至正常的 256 或 512，从而恢复模型的泛化能力。
    

### 3. 训练降维：解耦两阶段训练 (Two-Stage Training)

- **策略：** 避免多目标同时优化的混乱，实施分步训练。
    
    - **阶段一（打地基）：** 暂时屏蔽结果 $Y$，仅使用无监督方式将用户特征强行分类打包（特征表征阶段）。
        
    - **阶段二（盖大楼）：** 冻结底层的特征表征参数，仅利用真实的转化结果 $Y$ 去微调最后一层的预测参数。
        
- **收益：** 极大降低调参难度，明确问题出在“特征未解耦”还是“下游未拟合”。
    

### 4. 终极业务降维：引入 Dose-Response 结构

- **策略：** 打破将多档折扣视为离散、独立类的固化思维，**将折扣力度视为一个连续的数值特征**直接喂给模型。
    
- **收益：** 促使模型拟合出一条平滑的“折扣-收益曲线”，彻底解决数据因过度切割而导致的样本稀疏问题。
