# Qini 波动时怎样选模型：稳健性优先，但不迷信“平均分”

## 1. 结论

不要只凭单个 Epoch 的 Best Qini 选模型，也不要机械地认为“平均/稳定的一定更好”。正确做法是把平均表现、波动范围、置信区间、多 seed、OOT、treatment-ratio、分桶 uplift 和业务约束一起看。

单点峰值可能是幸运波动；但若它能在独立时间切片和不同随机种子中复现，也可能是真实收益，不能先验丢弃。

## 2. 为什么 Qini 容易震荡？

### 2.1 反事实评估的高方差

同一用户不能同时观察 treatment 与 control 结果，Qini 是群体增量的有限样本估计。样本量小、某些 score 区间 treatment/control 不平衡、极端 IPW 权重或头部少数样本都可能放大方差。

“反事实不可观测”不等于 Qini 必然有偏；偏差还取决于分流机制、倾向校正、评估器和样本选择。但它确实要求更谨慎地估计不确定性。

### 2.2 训练目标与评估目标不同

训练的 factual loss、MSE 或 surrogate rank loss 通常连续平滑；Qini 是基于排序与累计曲线的指标。少量临界样本换序，Loss 可能几乎不变，Qini 却会明显变化。

### 2.3 验证集被反复挑选

不断查看同一验证集、选取最高点，本质上会对验证集过拟合。这个风险不是 Uplift 独有，但在高方差指标上更明显。

## 3. 正确的模型选择流程

### 第一步：保留候选，不只留 Best

记录单点 Best、滑动窗口均值较高且方差较低的 checkpoint，以及早停附近 checkpoint。不要在第一次观察后立刻只保留一个模型。

### 第二步：做不确定性比较

对各候选 checkpoint 在相同验证集做 bootstrap，报告 Qini/AUCC 的均值和置信区间；再用多个训练 seed 或时间切片确认差异是否可复现。

### 第三步：做 OOT 验证

营销、价格、补贴等任务要在未来时间段评估。随机切分高分而 OOT 回落，通常说明模型学习了历史策略、季节性或特征分布捷径。

### 第四步：检查策略安全性

除 Qini/AUCC 外，至少同时看：

- treatment-ratio：头部是否异常富集某一 treatment；
- decile uplift：头部增量是否更高，且样本量/置信区间是否可信；
- factual LogLoss 与 calibration：排序提升是否严重损害响应概率；
- 分城市、人群、档位的稳定性。

## 4. 滑动平均、EMA、SWA 怎么理解？

滑动平均用于观察趋势，不是新的真实指标。EMA/SWA 对参数做时间平均，有时能降低训练噪声、改善泛化；但它们不是必然有效，必须重新评估 Qini、校准和约束指标。不能因为权重平均后的曲线更平滑，就默认线上更好。

## 5. 分桶是否必须完美单调？

不必。有限样本下，相邻桶的真实增量可能落在重叠置信区间内。更合理的标准是：头部相对随机策略是否有可信增量、排序趋势是否整体合理、是否存在明显反常的大桶，以及该结果能否在 OOT 复现。

## 6. 面试回答

> Qini 单点最高不一定最优，因为 Uplift 指标高方差且我们会反复用验证集挑 checkpoint。我会保留 Best 和稳定候选，用多 seed、bootstrap 置信区间和 OOT 验证比较；同时看 treatment-ratio、头部分桶 uplift、factual 校准和分人群稳定性。稳定模型通常风险更低，但如果单点峰值能在独立验证中稳定复现，也不应仅因它波动就放弃。
