# 13 术语表

| 术语                   | 中文解释                  | 面试中的一句话                                           |
| -------------------- | --------------------- | ------------------------------------------------- |
| ItemCF               | 基于 item 共现的协同过滤       | 直接用共现关系做邻居召回                                      |
| Co-occurrence        | 共现                    | 同一用户相近行为中的 item pair                              |
| Item2Vec             | item 版 skip-gram      | 用正负 item pair 学 item embedding                    |
| Sparse Embedding     | 稀疏 embedding          | 只更新当前 batch 访问的行                                  |
| Negative Sampling    | 负采样                   | 用少量负例近似大规模分类目标                                    |
| Collaborative Signal | 协同信号                  | 从用户行为共现中学习的相似性                                    |
| Content Signal       | 内容信号                  | 从标题、类目、图像等学习的相似性                                  |
| VQ                   | Vector Quantization   | 用 codebook 中最近向量表示连续向量                            |
| RQ                   | Residual Quantization | 对量化残差逐级编码                                         |
| RQ-VAE               | 残差量化自编码器路线            | 用重构和量化损失学习离散 code                                 |
| Codebook             | 码本                    | 每个 level 中可被选择的向量集合                               |
| Commitment Loss      | 承诺损失                  | 让 encoder 输出靠近选中的 code                            |
| Straight-Through     | 直通估计                  | 前向离散、反向近似传递连续梯度                                   |
| Codebook Collapse    | 码本坍缩                  | 大量 item 只使用少数 code                                |
| Semantic ID          | 语义 ID                 | 用多个离散 code 表示一个 item                              |
| Collision            | 编码碰撞                  | 多个 item 获得相同基础 SID                                |
| Collision Token      | 碰撞 token              | 追加 code 区分同一 SID 下的 item                          |
| Prefix Tree          | 前缀树                   | 保存有效 SID 的合法下一跳                                   |
| HSTU                 | 推荐序列建模结构              | 参考 gated interaction 和 pointwise activation 的推荐模型 |
| Relative Bias        | 相对偏置                  | 根据位置差或时间差调整交互分数                                   |
| Pointwise SiLU       | 逐点 SiLU               | 不做 softmax 归一化的激活形式                               |
| Gated Residual       | 门控残差                  | 用门控控制交互信息写回输入                                     |
| Teacher Forcing      | 教师强制                  | 训练时使用真实前缀预测下一个 code                               |
| Exposure Bias        | 曝光偏差                  | 训练 prefix 和推理 prefix 分布不一致                        |
| Beam Search          | 束搜索                   | 同时保留多个高分生成前缀                                      |
| Prefix Constraint    | 前缀约束                  | 只允许生成有效 SID 路径                                    |
| HR@K                 | 命中率                   | 真实 target 是否在 top-K                               |
| NDCG@K               | 归一化折损累计增益             | 越靠前命中得分越高                                         |
| Coverage             | 覆盖率                   | 推荐列表涉及的不同 item 占比                                 |
| OOV                  | 未登录目标                 | target 不在训练期 SID 表中                               |
| OOT Split            | 时间外推切分                | 用未来时间窗口做验证/测试                                     |
| Cold Start           | 冷启动                   | 新用户或新 item 缺乏历史行为                                 |
