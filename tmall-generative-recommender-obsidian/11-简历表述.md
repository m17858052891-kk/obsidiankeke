# 11 简历表述

## 推荐项目标题

**基于协同 Semantic ID 与 HSTU 的电商生成式推荐系统｜天池 Tmall**

## 版本 A：稳健、适合真实项目

- 针对百万级商品直接 ID 预测输出空间大、item ID 缺乏结构的问题，基于行为类型、时间距离、序列位置和用户活跃度构造稀疏 item-item 加权共现图，使用 Weighted Item2Vec 学习协同 item embedding。
- 基于 RQ-VAE 风格残差量化将 item embedding 编码为 3 级离散 Semantic ID，建立 item↔SID、SID↔item 及前缀索引，并通过 collision token 处理多商品量化冲突。
- 将历史 SID、行为类型与时间差输入 HSTU-style 序列编码器，采用 teacher forcing 逐级预测目标 SID；推理阶段使用 prefix-constrained beam search 生成有效商品候选，并结合 seen-item 过滤。
- 完成 ItemCF、item-ID 序列模型、metadata SID 和 collaborative SID 的 baseline/ablation 设计，从 HR@K、NDCG@K、coverage、diversity、collision/OOV 等维度评估模型效果与候选质量。

## 版本 B：更短的一页简历版

- 构建“加权稀疏共现 → Item2Vec → RQ-VAE Semantic ID → HSTU 自回归解码 → 约束 Beam Search”的电商生成式推荐 pipeline，降低超大 item 空间直接分类的建模难度。
- 使用 3 级残差量化 code 表示商品并通过 collision token 消歧；融合 SID、行为类型、时间差和相对时间偏置建模用户序列，完成多级 SID 生成与有效候选映射。
- 设计 ItemCF、item-ID HSTU、metadata SID 等对照实验，联合 HR/NDCG、coverage、多样性、SID collision rate 和 OOV rate 评估推荐效果与结构质量。

## 不建议写的表述

- “使用 LLM/SFT 完成推荐”：不准确。
- “实现工业级 TIGER”：当前代码不足以支持。
- “端到端训练 RQ-VAE + HSTU”：当前是分阶段训练。
- “解决冷启动”：collaborative SID 不能单独解决。
- “线上 CTR/GMV 提升”：没有线上实验就不能写。
- “复现官方 HSTU”：应改为“HSTU-style/参考 HSTU 思路实现”。
