# LoRA-SFT：从通用兴趣模型到购买目标模型

## 1. 是什么

多行为预训练学习：

$$
P(\text{下一交互商品 SID}\mid\text{多行为历史})
$$

购买 SFT 学习：

$$
P(\text{下一购买商品 SID}\mid\text{多行为历史})
$$

SFT 仍然输入点击、收藏、加购、购买的完整历史，只把“购买位置”选为监督目标。它不是纯购买序列，也不是简单提高购买行为权重。

## 2. 为什么先预训练再 SFT

数据中点击约405万条，购买只有约9.6万条。直接用购买样本从头训练，容易出现监督不足和过拟合。

两阶段训练的分工是：

```text
全行为全参数预训练
  → 学习商品迁移、行为关系、时间模式和SID生成

购买目标 LoRA-SFT
  → 在保留通用能力的基础上调整购买商品分布
```

正式实验中，预训练有486,020条训练样本，购买SFT只有37,368条。购买样本约为预训练样本的八分之一，因此参数受限的微调更稳妥。

## 3. 购买样本怎么构造

对用户行为按时间排序，找出购买位置 $p_1,p_2,\ldots,p_n$：

```text
p1 ～ p(n-2) → Train
p(n-1)       → Validation
pn           → Test
```

例如：

```text
历史：点击A → 收藏B → 点击C → 加购D → 点击E
目标：购买商品F的四级SID
```

每个样本最多保留目标之前最近100条行为。只有至少包含3个有效购买位置的用户才能同时形成训练、验证和测试样本。

## 4. LoRA 如何工作

预训练线性层为：

$$
y=Wx
$$

LoRA 冻结 (W)，增加两个低秩矩阵：

$$
A\in\mathbb R^{r\times d_{in}},\qquad
B\in\mathbb R^{d_{out}\times r}
$$

前向计算变为：

$$
y=Wx+\frac{\alpha}{r}BAx
$$

当前使用 $r=16,\alpha=16$，所以缩放系数为1：

$$
y=Wx+BAx
$$

可以把它理解为：

$$
W_{buy}=W_{pretrain}+\Delta W_{buy},\qquad
\Delta W_{buy}=BA
$$

预训练权重保存通用兴趣能力，低秩增量只学习购买任务需要的修正。

## 5. 为什么初始化稳定

项目中 (A) 随机初始化，(B) 初始化为0。SFT开始时：

$$
BA=0
$$

因此 LoRA 模型最初与预训练模型输出完全一致，再逐步学习购买增量，不会在第一步破坏预训练能力。

## 6. LoRA 插入位置

HSTU Encoder 中加入 LoRA 的线性层：

```text
Q / K / V 投影
U 门控投影
Attention 输出投影
FFN Gate / Value / Output 投影
```

SID Decoder 中加入 LoRA 的线性层：

```text
Q / K / V 投影
Attention 输出投影
FFN 投影
用户兴趣条件映射
```

SFT 时可训练：

```text
所有 LoRA A/B
四级 SID 输出头
```

冻结：

```text
原始线性层 W
SID Embedding
Behavior Embedding
时间偏置
LayerNorm
Decoder Token / Position Embedding
```

输出头需要训练，是因为“任意下一行为商品”和“下一购买商品”的 SID 分布并不相同。

## 7. 参数量

| 参数 | 数量 | 占总模型比例 |
|---|---:|---:|
| 总参数 | 5,678,176 | 100% |
| LoRA Adapter | 466,944 | 8.22% |
| SID 输出头 | 222,048 | 3.91% |
| 总可训练参数 | 688,992 | 12.13% |

“LoRA 可训练比例12.13%”准确地说是 Adapter 与输出头之和，纯 Adapter 为8.22%。

## 8. SFT 目标函数与梯度

目标购买商品 SID 为 $[c_1,c_2,c_3,c_4]$，仍使用 Teacher Forcing 和四级交叉熵：

$$
\mathcal L_{SFT}=\frac{1}{4}\sum_{l=1}^{4}CE(\hat c_l,c_l)
$$

梯度路径为：

```text
购买SID交叉熵
  → SID输出头：更新
  → Decoder LoRA：更新
  → HSTU LoRA：更新
  → 原始预训练主干：冻结
```

SID、RQ-VAE 和 Item2Vec 都已固定，不参与此阶段反向传播。

## 9. 训练配置与结果

```text
LoRA Rank：16
学习率：5×10⁻⁴
Batch Size：128
训练精度：BF16
Epoch：5
训练样本：37,368
验证样本：13,374
```

| Epoch | Train Loss | Validation Loss |
|---:|---:|---:|
| 1 | 3.8135 | 3.6712 |
| 2 | 3.6419 | **3.6515** |
| 3 | 3.5085 | 3.6554 |
| 4 | 3.3858 | 3.6746 |
| 5 | 3.2705 | 3.7063 |

训练损失持续下降，但验证损失从第3轮开始上升，因此最终使用第2个 Epoch 的最佳 checkpoint。这也说明购买数据较少，限制可训练参数和 Early Stopping 都有必要。

## 10. 为什么这里使用 LoRA 有价值

### 保留通用知识

冻结主干可以减少购买梯度覆盖多行为预训练知识，降低灾难性遗忘风险。

### 降低过拟合

购买样本远少于预训练样本。低秩增量限制了模型的自由度，相当于结构化正则化。

### 减少训练资源

只为12.13%的参数维护梯度与优化器状态，训练显存、checkpoint 和切换成本更低。

### 支持多任务复用

同一预训练主干可以分别挂载购买、加购、点击等 Adapter，不必复制完整模型。

### 可合并部署

部署前可计算：

$$
W_{merged}=W+\frac{\alpha}{r}BA
$$

合并后仍是普通线性层，不必保留额外 LoRA 分支。

## 11. 当前结论边界

当前购买模型在一万条测试样本上得到 HR@10 0.0048、NDCG@10 0.00281，优于全局加权热门基线。但尚未在同一购买测试集上完成以下严格消融：

```text
预训练模型，不做SFT
只训练SID输出头
LoRA Rank 4/8/16/32
全参数购买微调
```

因此可以说 LoRA-SFT 参数高效、训练稳定并完成购买对齐，但不能声称它已经被证明优于全参数微调。

## 12. 一分钟回答

> 我先用全部行为做全参数 HSTU 预训练，学习通用商品迁移、行为关系和时间模式；再只选择购买位置作为目标进行监督微调。因为购买训练样本只有3.7万条，远少于预训练样本，所以我冻结预训练主干，在 HSTU 和 SID Decoder 的主要线性层中插入 Rank-16 LoRA，同时放开四级 SID 输出头。这样最终权重可以理解成通用预训练权重加一个低秩购买增量，既能减少过拟合和灾难性遗忘，也能降低训练参数与多任务维护成本。实验中可训练参数占12.13%，最佳验证结果出现在第2个 Epoch；但要证明 LoRA 本身优于全参数微调，还需要补充同测试集的消融实验。
