# 00 项目总览

## 项目定位

这是一个基于协同 Semantic ID 和 HSTU-style 序列模型的电商生成式推荐离线原型，数据来自天池 Tmall 用户行为日志，字段包括 `User_id`、`Item_id`、`Action` 和 `Vtime`。

项目的核心思路是：先从用户多行为日志中学习商品协同表示，再把连续商品向量离散化成 Semantic ID，最后根据用户历史 SID 序列生成下一个商品的 SID。

## 解决的问题

直接预测全量 Item ID 时，输出空间随着商品数增长，Item ID 也没有可利用的语义结构。Semantic ID 将一个商品拆成多个离散 code，使模型可以在较小词表中逐级生成，并复用商品表示的局部结构。

## 模块职责

- `01 数据与样本构造`：日志清洗、时间排序、训练样本和防泄漏。
- `02 加权共现与 Item2Vec`：从行为共现学习商品协同 embedding。
- `03 RQ-VAE 与 Semantic ID`：把连续商品向量量化成多级 SID，并处理 collision。
- `04 HSTU 序列建模`：融合 SID、行为类型和时间信息，建模用户历史兴趣。
- `05 SID 自回归解码`：Teacher Forcing、多级交叉熵、前缀约束和 Beam Search。
- `06 训练工程`：分阶段训练、内存、产物版本和故障定位。
- `07 评估设计`：baseline、消融、时间切分和生成质量指标。
- `08 HSTU 原理与复杂度`：标准 Attention、Pointwise Attention、Gate 和效率边界。
- `09 面试题库`：按面试主题整理的短答案。
- `10 公式与代码速查`：只保留复习所需的核心公式、张量和伪代码。

## 当前边界

当前 Item2Vec、RQ-VAE/SID 和 HSTU 是分阶段训练；RQ-VAE 是确定性残差量化自编码器，不包含标准 VAE 的 Gaussian posterior 和 KL loss；HSTU 是参考结构的 HSTU-style 原型。Prefix Constraint 只能保证 SID 结构和商品映射合法，不能单独保证推荐质量、库存或其他业务规则。
