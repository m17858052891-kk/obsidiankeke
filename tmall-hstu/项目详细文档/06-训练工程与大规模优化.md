# 06 训练工程与大规模优化

## 三阶段训练

1. 行为日志生成加权稀疏共现，训练 Weighted Item2Vec；
2. Item2Vec embedding 训练 RQ-VAE tokenizer，生成并固定 item-to-SID 表；
3. 将历史 SID、行为和时间输入 HSTU，训练 SID 自回归生成。

分阶段训练便于定位 embedding、量化和序列建模各自的问题；缺点是商品语义重构目标和推荐生成目标没有联合优化，当前不是严格端到端。

## 资源控制

- 不建立 dense item-item 矩阵；
- 不把 13 亿行日志一次性读入 pandas；
- 共现 pair 保留窗口内稀疏边和 top-N 邻居；
- 大 embedding 使用 sparse update 和 `SparseAdam`；
- SID 解码使用前缀索引，避免遍历 (K^L) 个组合；
- 长序列控制最近行为数、padding 和 mask，必要时使用 mixed precision。

## 训练稳定性和版本

使用梯度裁剪防止梯度爆炸；Item2Vec 相似度前做 L2 normalization；RQ-VAE 监控 code 使用率、熵和重构误差；decoder 可使用轻微 label smoothing。用同一个 `sid_version` 绑定 embedding、codebook、item-to-SID、SID-to-item、prefix index 和 HSTU checkpoint，避免 token 含义不一致。

## 常见故障

- Item2Vec loss 不降：检查 pair 权重、正负样本和 score 分布；
- code 使用集中：检查 codebook collapse；
- invalid SID 多：检查 SID 表和 prefix index 是否一致；
- HR 升但 coverage 降：检查热门度分桶和长尾召回；
- 候选不足：检查 OOV、seen filter 和 collision rate；
- OOT 指标低：检查时间泄漏、数据漂移和训练/测试 SID 版本。
