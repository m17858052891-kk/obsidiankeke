# GBDT：梯度提升树与叶子特征

> GBDT（Gradient Boosting Decision Tree）按顺序叠加多棵弱树，每棵新树拟合当前损失的负梯度。树的分裂路径天然是“特征阈值与组合规则”，特别擅长结构化表格数据的非线性。

## 1. 为什么叫 Gradient Boosting？

整体是加法模型：

$$F_M(x)=\sum_{m=1}^M\eta f_m(x).$$

第 $m$ 棵树拟合当前模型输出处的负梯度：

$$r_{im}=-\left.\frac{\partial L(y_i,F(x_i))}{\partial F(x_i)}\right|_{F=F_{m-1}}.$$

平方误差时它等于残差 $y-F(x)$；对于 LogLoss，严格说是 logit 空间的负梯度，不能笼统说“GBDT 每棵树拟合残差”。

## 2. 它如何自动学习交叉？

一条路径如：

```text
活跃天数 > 5 → 客单价 > 100 → 城市是一线 → 叶子分数
```

本质上是带阈值的高阶特征组合。相比 LR 人工枚举交叉，树按增益自动选择有效切分；相比 FM 的平滑内积，树擅长不连续的阈值规则。

## 3. GBDT + LR 为什么经典？

```text
原始特征 → GBDT → 每棵树落到的 Leaf ID → 多棵树 One-hot 拼接 → LR
```

GBDT 把连续、类别和组合关系变成离散叶子特征；LR 再对这些规则线性加权。它是深度 Embedding 模型流行前经典的 CTR 架构。

## 4. 与 RF、XGBoost、LightGBM 的关系

- Random Forest 是 Bagging：树可并行，通过随机性降方差；
- GBDT 是 Boosting：树串行，逐步降低偏差；
- XGBoost、LightGBM 是 GBDT 的工程化实现，并非与 GBDT 互斥。

XGBoost 强调二阶近似、显式正则；LightGBM 使用 histogram、leaf-wise、GOSS/EFB 等优化大规模训练。

## 5. 过拟合与复杂度

控制深度/叶子数、最小叶样本，减小学习率配合更多树，使用行列采样、正则和早停。粗略而言，$M$ 棵树、$N$ 个样本、有效特征数 $D'$、深度 $H$ 的训练成本与 $MND'H$ 同阶；单样本推理约为 $O(MH)$。

树按排序和阈值切分，单调缩放通常不改变样本排序，所以一般不需要标准化。但 Target Encoding 必须 OOF 或时间切分，避免标签泄漏。

## 6. 高频问答

### 为什么 GBDT 不适合直接处理超高基数 ID？

每个 ID 被切成规则会造成样本碎片、模型巨大且难泛化。通常先做统计/编码、用叶子特征，或让 Embedding 模型处理原始 ID。

### 为什么难在线增量？

新树依赖已有模型的预测；分布变化后仅追加树可能累积偏差。相较于小步更新的 LR/深度模型，增量维护更复杂。

### 何时优先选树？

中小规模表格、规则阈值强、特征以连续统计值为主、需要解释性时，树往往很强；大规模稀疏 ID、复杂序列更常采用深度模型。

## 7. 30 秒回答

> GBDT 是加法树模型，每棵新树拟合当前损失的负梯度，所以树之间串行。每条根到叶路径就是多个阈值条件的非线性高阶组合，特别适合表格数据。CTR 中常用它产生叶子 one-hot 特征再接 LR；调参重点是学习率、树复杂度、采样和早停。
