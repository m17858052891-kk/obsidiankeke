在推荐系统中，特征交叉（Feature Crossing）是提升点击率预估（CTR）精度的核心。比如，“性别=男”和“商品=口红”单独看可能都有较高权重，但它们交叉在一起时，购买概率会极低。

DNN（多层感知机）虽然能隐式地学习特征交叉，但效率很低。**DCN (Deep & Cross Network)** 的核心思想就是：**不仅要隐式交叉，还要用一套明确的数学公式，强制让原始特征** $x_0$ **参与每一层的显式、高阶交叉。**

# 1. DCN v1：天才的想法与致命的数学缺陷

# 1.1 核心公式

在 DCN v1 的 Cross Network 中，第 $l+1$ 层的输出公式为：

$$x_{l+1} = x_0 x_l^T w_l + b_l + x_l$$

- $x_0$：最原始的输入特征（比如 100 维）。
- $x_l$：第 $l$ 层的输出。
- $w_l$：一个可学习的**一维权重向量**（维度也是 100）。

# 1.2 为什么说它“只改变大小，没改变方向”？

这是 DCN v1 最大的痛点，我们用简单的线性代数来拆解中间的那一坨交叉项：$x_0 x_l^T w_l$。

根据矩阵乘法结合律，我们可以先算后面两个：

$$x_l^T w_l$$

注意，$x_l$ 是一维列向量（$100 \times 1$），转置后是（$1 \times 100$）。$w_l$ 也是（$100 \times 1$）。 **向量的内积（点乘），得到的是一个标量（Scalar，就是一个具体的数字，比如 5.2）！** 设 $c = x_l^T w_l$，那么交叉项就变成了：

$$c \cdot x_0$$

**数学意义：** 无论你的网络怎么训练，无论 $w_l$ 怎么变，产生的新交叉特征 $c \cdot x_0$ 永远只是原始特征 $x_0$ 的一个等比例缩放（拉伸或压缩）。 在多维空间中，**它的方向被死死地锁在了** $x_0$ **的方向上，完全没有发生任何旋转（Rotation）。** 这种交叉的表达能力极其受限，这就是常说的“DCN v1 表达能力不足”。

# 2. DCN v2 (DCN-Mix)：矩阵升维与工程降维

为了解决 v1 的“标量枷锁”，谷歌在 2020 年推出了 DCN v2。

# 2.1 矩阵升维：打破枷锁

既然一维向量 $w_l$ 只能产生标量，那就把它升级成一个二维的**全连接权重矩阵** $W_l$（维度 $d \times d$）。

公式进化为：

$$x_{l+1} = x_0 \odot (W_l x_l + b_l) + x_l$$

_(注：_$\odot$ _表示哈达玛积，即按元素逐一相乘)_

**数学意义：** 现在，$W_l x_l$ 是一次完整的矩阵乘法。它把 $x_l$ 投射到了一个全新的线性空间，**既改变了大小，又改变了方向（产生了旋转）**。然后再与原始特征 $x_0$ 进行按元素相乘，实现了极其充分、自由的特征交叉。

# 2.2 工程降维：Low-Rank (低秩逼近) 拯救线上延迟

理论很完美，但工业界要看 RT（响应延迟）。 假设输入特征维度 $d = 1000$。在 v1 中，$w_l$ 只有 1000 个参数。但在 v2 中，$W_l$ 是 $1000 \times 1000 = 100万$ 个参数！如果 Cross Network 叠了 3 层，参数量和矩阵乘法的计算量会直接把线上推理服务器压垮。

**解法：低秩矩阵分解 (Low-Rank Approximation)** 基于奇异值分解（SVD）的思想，一个巨大的矩阵 $W_l \in \mathbb{R}^{d \times d}$，可以被近似拆解为两个瘦长矩阵的乘积：

$$W_l \approx U_l \cdot V_l^T$$

其中，$U_l \in \mathbb{R}^{d \times r}$，$V_l \in \mathbb{R}^{d \times r}$。这里的 $r$ 是我们人为设定的一个小数字（比如 $r=32$）。

**计算加速魔法：** 计算 $W_l x_l$ 时，变成了 $U_l (V_l^T x_l)$。

1. 先算 $V_l^T x_l$：得到一个 $r$ 维的小向量（计算量极小）。
2. 再算 $U_l$ 乘以这个小向量：还原回 $d$ 维。 参数量从 $d^2$ 骤降到 $2 \times d \times r$。完美实现了“既要有矩阵的旋转表达力，又要有向量的计算速度”。

# 3. 并联 vs 串联：双剑合璧的两种姿势

DCN 网络从来不是孤立工作的，它总是和普通的 MLP（Deep 网络）搭配使用。

# 3.1 并联架构 (Parallel Structure) - 默认与主流

- **做法：** 原始特征 $x_0$ 像流水线分流一样，同时喂给左边的 Cross Network 和右边的 MLP。各自跑完后，把结果拼在一起（Concat），再经过一个全连接层输出预测概率。
- **业务直觉：** “我全都要”。Cross 网络负责死记硬背（Memorization），精准捕捉“男+口红”这种显式高阶规律；MLP 负责泛化（Generalization），发掘未知的隐式关联。两者互不干扰，极其稳健，是各大厂的默认首选。

# 3.2 串联架构 (Stacked/Serial Structure)

- **做法：** 原始特征 $x_0$ 先送入 Cross Network 叠几层，进行充分的显式特征交叉。然后，把 Cross 网络的输出，**作为输入**直接喂给后接的 MLP。
- **业务直觉：** “先精加工，再深加工”。把 Cross 网络当成一个极其强大的**特征工程提取器 (Feature Extractor)**。它先把散乱的特征揉碎、交叉好，喂给 MLP 的就不再是生肉，而是“半成品特征”，让 MLP 的非线性提炼更加轻松。
- **风险：** 容易梯度消失或过拟合。因为网络变得更“深”了，调参难度大于并联架构。
