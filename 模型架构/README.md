## 6. 面试建议

每个模型按“问题 → 旧方案为何不足 → 输入/输出 → 一个 Block 的数据流 → 复杂度/工程 → 边界 → 项目中是否使用”来讲。不要把论文结构、项目实现和通用结论混在一起。
