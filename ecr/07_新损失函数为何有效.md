# 引入新损失函数为什么能解决问题：CFR 为什么不够，为什么用 Corr 而非 MSE

## 30 秒回答

CFR 的分布拉齐只是在表示层降低 treatment/control 的差异，让反事实估计更可行；factual BCE 仍在优化 observed-arm response，并没有直接优化“增量大的用户排前面”。IPW 伪标签为排序提供方向后，Corr 只要求预测分数与伪 uplift 的相对变化一致，不强迫模型拟合高方差、尺度不可信的伪标签绝对值，因此比 MSE/Huber 更贴近 AUCC。代价是 Corr 梯度强、会放大 assignment artifact，必须通过按档校准、Pairwise、TwoStage 与软解冻限制它。

## 1. 原始 CFR 已经做了什么

CFR 学习共享 representation，并用 imbalance/约束项减少组间表征差异；再用各 arm 的 factual BCE 拟合观测 outcome。若随机试验成立，它为估计 $\mu_t(x)-\mu_c(x)$ 提供了合理的函数逼近起点。

## 2. 为什么“拉齐分布”仍然不够

表征分布接近不等于以下任一件事：

- 各 treatment head 的反事实概率误差小；
- 两个概率相减后的 uplift 误差小；
- uplift 分数前 10% 正好是最大增量人群；
- score 不包含高频曝光、样本过滤或 treatment assignment 的捷径。

特别是 BCE 的梯度只来自实际 arm 的 response。它可以把自然高响应者预测得非常准确，却没有理由把他们从高 uplift 位置降下来。因此 factual AUC 很高、Call AUCC 仍低是正常现象。

## 3. MSE/Huber 的问题

若以 $\hat\tau$ 直接回归 IPW pseudo：

$$
\mathcal L_{MSE}=\frac1n\sum_i(\hat\tau_i-z_i)^2
$$

会假定每个伪标签的绝对值与数值尺度都可信。但 IPW 有 inverse propensity 放大，二元 outcome 噪声大，深档位样本少、方差更高，且伪标签的任务定位本来只是总体方向而非 individual ITE。Huber 仅对大残差更稳，仍然在要求绝对回归值匹配。

## 4. Corr 为什么对齐目标

$$
\mathcal L_{corr}=1-Corr(\tilde q,z)
$$

Pearson correlation 关注协方差相对于方差的方向：统一平移不会改变它，正比例缩放也不会改变它。这符合 ranking 的本质：只要高伪 uplift 人群获得更高 score，绝对刻度可以另行校准。相比 pointwise MSE，Corr 是 batch/listwise 信号，与 AUCC 的累计排序更接近。

这并不表示 Corr 直接等价于 AUCC，也不保证它是无偏 surrogate；它只是针对当前 noisy pseudo 与排序目标的工程上更合适的近似。评价仍应回到独立集上的 AUCC/Qini/ratio。

## 5. 为什么 Corr 又会造成 treatment-ratio 不稳

Corr 使用 batch 内密集统计量，任何与 pseudo 同方向的结构都有收益：真实异质性如此，treatment assignment、档位样本比例、高频 PID、重复曝光和泄漏特征也可能如此。随着 Corr 权重增大，模型可为了损失下降而重构 shared bottom，这会使 score 与实验组身份相关；表现为 AUCC 看似大幅升高，但 Qini 前段 ratio 异常。

## 6. 为什么新方案能缓解而不是“彻底解决”

| 设计 | 解决的风险 |
| --- | --- |
| $2y-1$ pseudo | no-call 证据坍缩，方向信息不足 |
| 按 treatment 独立 Corr | 跨档位尺度与比例混杂 |
| Z-score + Tanh | 均值/方差漂移、长尾极值主导梯度 |
| Matched Pairwise | Corr 缺乏局部可比顺序 |
| TwoStage anchor | 一开始就让 noisy rank 梯度污染表征 |
| progressive soft-unfreeze | 全冻无收益、全开易带偏的两难 |
| factual loss 保留 | 阶段二偏离可用 response model |

这些是风险控制，而非因果保证。当前结论应表述为“在已有离线证据中降低了 ratio 风险并保留排序收益”；真正的增量价值仍需更稳健的伪标签、外推验证和线上实验确认。
