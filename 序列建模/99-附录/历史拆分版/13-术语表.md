# 术语表

| 术语 | 含义 | 面试中的一句话 |
|---|---|---|
| Attempt | 覆盖冒泡到完单链路的业务尝试粒度 | 用于串起发单前后事件，避免只依赖可能为空的 order_id。 |
| prediction_time | 当前样本的预测时点 | 所有历史特征必须早于并在该时点可用。 |
| D / O / OD | 乘客履约 / 司机履约 / 司乘履约率 | 三个相关但并不完全同向的多任务目标。 |
| CAA | 司乘应答后取消率 | 材料中作为 DO 价值相关信号。 |
| CR | 呼叫完单率 | 乘客侧业务目标之一。 |
| PLE | Progressive Layered Extraction | 用共享/任务专家做多任务建模的架构。 |
| Expert | PLE 中的一个 MLP 子网络 | 不同任务通过 gate 或分组组合专家输出。 |
| PosSA | Positional Self-Attention | 在序列内引入顺序信息的注意力编码。 |
| PEPNet | Parameter and Embedding Personalized Network | 用 EPNet/PPNet 按样本和任务调节共享网络。 |
| EPNet | Embedding Personalized Network | 在底层特征/embedding 表示侧做个性化 gate。 |
| PPNet | Parameter Personalized Network | 在每层 hidden 前做任务/样本级 gate。 |
| LHUC | Learning Hidden Unit Contributions | 用逐维缩放系数调节隐藏单元的思想来源。 |
| OneTrans | Unified Feature Interaction and Sequence Modeling | 统一序列 token 与静态 token 交互的 Transformer 路线。 |
| S-token / NS-token | 序列 token / 非序列 token | OneTrans 中来自历史行为与静态字段的两类 token。 |
| Pyramid | 逐层压缩历史 token 的设计 | 用于降低长序列 Transformer 的计算开销。 |
| KV Cache | 复用历史 Key/Value 的推理缓存 | 是潜在工程优化，当前项目未证实线上收益。 |
| Batch Size | 一次参数更新的样本数 | 在当前序列实验中是强影响因素，但机制仍待控制变量验证。 |
| train-serving skew | 训练与线上输入口径不一致 | 序列截断、排序、可用时间不一致会造成该问题。 |
